# 工业设备智能运维（PHM）知识库大纲

> **定位**：面向工业设备运维工程师的通用业务百科全书（非具体设备配套档案）  
> **设计原则**：支持「生命周期 × 数据模态 × 设备类型 × 业务角色 × 运维策略」多维检索  
> **迭代说明**：新增设备全生命周期、多模态看护、设备失效模式库、运维策略、检修业务、标准规范、技术工具、经济性等 8 个业务维度，形成从“选型采购”到“报废更新”的完整知识闭环。

## 1. 设备全生命周期管理

  - 1.4.1 点检 / 巡检体系设计

- **1.5 维护检修与故障处置**
  - 1.5.1 保养策略（润滑 / 清洁 / 紧固 / 调整）
  - 1.5.2 故障应急处置与降级运行方案
- **1.6 技术改造与性能升级**
  - 1.6.1 能效提升与自动化改造

## 3. 设备类型与失效模式库
*（对象维度：回答“某类设备出现某故障怎么处理”）*

- **3.1 旋转机械**
  - 3.1.1 离心泵：常见失效模式 / 诊断特征 / 检修要点
  - 3.1.2 风机 / 压缩机：常见失效模式 / 诊断特征 / 检修要点
  - 3.1.3 电机 / 齿轮箱：常见失效模式 / 诊断特征 / 检修要点
- **3.2 静止设备**
  - 3.2.1 换热器 / 管道 / 储罐：腐蚀 / 结垢 / 泄漏 / 壁厚减薄
  - 3.2.2 阀门 / 密封件：内漏 / 外漏 / 卡涩 / 冲蚀
- **3.3 电气设备**
  - 3.3.1 变压器：绕组 / 铁芯 / 绝缘油 / 套管故障
  - 3.3.2 开关柜 / 电缆 / UPS：局放 / 温升 / 电池老化
- **3.4 特种设备**
  - 3.4.1 起重机械 / 电梯 / 厂车：机械 / 电气 / 安全保护装置
  - 3.4.2 压力容器：疲劳 / 腐蚀 / 变形 / 安全附件
- **3.5 通用失效机理**
  - 3.5.1 磨损 / 腐蚀 / 疲劳 / 蠕变
  - 3.5.2 松动 / 不对中 / 不平衡 / 共振

- **3.6 故障现象 → 根因 → 对策知识图谱**
  - 3.6.1 典型故障现象枚举（温升异常 / 振动增大 / 噪声异响 / 性能下降）
