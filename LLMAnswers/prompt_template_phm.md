# 工业设备智能运维（PHM）知识库大纲 - Prompt 模板

---

## Prompt 模板（直接复制使用）

```
请为"工业设备智能运维（PHM，Prognostics and Health Management）"领域生成一份知识库目录大纲。

## 重要领域约束（必须严格遵守）

### 1. 领域定义
- 本知识库面向的是"工业设备"的智能运维，而非IT运维（AIOps）
- 核心目标：实现工业设备的故障诊断、健康管理和预测性维护
- 关键能力：状态监测、故障诊断、剩余寿命预测（RUL）、维护决策优化

### 2. 设备类型范围
- 旋转机械：压缩机、泵、风机、汽轮机、电机、齿轮箱等
- 静设备：管道、换热器、储罐、阀门、反应器等
- 生产线设备：数控机床、工业机器人、输送设备等
- 不要涉及：服务器、容器、微服务、Kubernetes、数据库中间件等IT对象

### 3. 数据来源与采集
- 传感器数据：振动、温度、压力、流量、电流、声学、油液分析等
- 工控协议：Modbus、OPC UA、PROFINET、EtherCAT等
- 控制系统：PLC、SCADA、DCS、MES
- 不要以IT监控工具（Prometheus、ELK、Grafana等）为主要数据源

### 4. 核心分析技术
- 信号处理：时域分析、频域分析（FFT）、时频分析（小波变换）
- 振动分析与诊断：频谱分析、包络分析、阶次分析
- 故障模式识别：不平衡、不对中、轴承故障、齿轮磨损、叶片裂纹等
- 剩余寿命预测（RUL）：基于物理模型、数据驱动、混合方法
- 工况分析与设备关联：工况传播分析、设备关联拓扑分析
- 不要以IT运维算法（日志异常检测、调用链分析、微服务根因定位）为核心

### 5. 告警与运维场景
- 告警场景：设备振动超标、温度异常、压力波动、性能退化等工业场景
- 维护策略：预防性维护、预测性维护、基于状态的维护（CBM）
- 自愈场景：设备切换、负荷调整、冗余切换、安全停机
- 不要以IT告警（服务超时、Pod重启、数据库慢查询）为主要场景

### 6. 安全要求
- 工控网络安全：工控系统隔离、工业防火墙、安全审计
- 功能安全：SIL等级、安全仪表系统（SIS）
- 不要以IT安全（WAF、DDoS、CVE漏洞）为主要安全内容

## 输出要求
1. 以"工业设备"和"PHM"为核心视角组织内容
2. 每个章节必须与工业设备/工业场景直接相关
3. 涉及算法或技术时，应结合工业设备的具体应用场景说明（如：振动异常检测、轴承RUL预测）
4. 目录层级建议：一级目录 ≥ 10个，二级目录每个 ≥ 4个子项
5. 请用Markdown格式输出
```
