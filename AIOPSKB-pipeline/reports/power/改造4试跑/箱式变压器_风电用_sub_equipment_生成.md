| 子设备名称 | 描述 |
| :--- | :--- |
| 美式箱变（组合式变压器） | 将变压器器身、高压负荷开关、熔断器等高压元件共置于一个全密封的油箱内，结构紧凑、占地面积小，适合塔筒外的平地或基础平台安装，广泛应用于陆地及近海风电场。 |
| 欧式箱变（预装式变电站） | 将变压器、高压开关柜、低压配电装置等功能单元分别布置在相互独立的金属隔室内，壳体防护等级高、通风散热条件好，可灵活配置油浸式或干式变压器，适用于对电磁干扰和运维独立性要求较高的风电场。 |
| 华式箱变（一体化变电站） | 在吸收美式与欧式箱变优点基础上，将变压器本体置于独立散热隔间，高压开关等元件布置在另侧，兼具美变结构紧凑与欧变运行可靠性高的特点，特别适应国内风电场高温、高湿、风沙等复杂户外环境。 |
