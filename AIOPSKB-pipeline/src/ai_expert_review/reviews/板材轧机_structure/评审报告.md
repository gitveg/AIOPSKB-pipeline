### 2.3 遗漏项

- **张力传感器**（DeepSeek）: 薄膜张力是厚度和板形控制的基础参数，轧机出口和入口通常设置张力计或张力测量辊，其信号需接入控制系统，缺失将导致检测链路不完整。
- **工作辊窜辊执行装置（液压缸、导向滑板、锁紧块等）**（DeepSeek）: 现有结构仅覆盖中间辊窜辊，而常见板材轧机（如CVC-4、UCM）均需工作辊轴向窜动以控制板廓，缺失会造成板形控制功能不完整。
- **夹送辊轴承（如调心滚子轴承）**（DeepSeek）: 上下夹送辊旋转需要轴承支撑，属于可更换的磨损元件，检修时需独立检查和更换。
- **夹送辊密封件**（DeepSeek）: 轴承座需要密封防止润滑脂流失和冷却水进入，属于常规消耗件，应纳入零件清单。
- **换辊装置系统**（Kimi）: 换辊是板材轧机维持生产的核心辅助功能，具有独立的机械、液压及电气故障模式，应作为独立子系统存在，以系统化组织换辊相关故障与维护知识。
- **上输出轴 / 下输出轴**（Kimi）: 齿轮座目前仅列出输出齿轮和轴承，缺少输出轴本体；输出轴是承受扭矩并可能扭断、弯曲的独立失效件，应与输入齿轮轴同级列出。
- **滤芯**（Kimi）: 滤芯是双筒过滤器最核心的易损可更换件，同级的冷却液过滤器、润滑油过滤器均已列出，此处遗漏破坏粒度一致性。
- **接轴托架（或接轴平衡装置）**（Kimi）: 万向接轴通常配有托架或平衡装置以补偿自重、防止接轴下垂，是独立安装、独立维护的单元，缺失导致接轴支撑相关故障无法精准挂载。

### 2.4 冗余项

- **液压管线与管接头**（Kimi）: 管网非独立总成，且其组成元素（钢管、软管、旋转接头）已在其他部件（如旋转接头、循环管路）中分散体现，作为独立部件导致边界模糊，与失效独立性原则冲突。

### 待裁定分歧

- **DeepSeek 单方** 检测与控制系统 — 功能完备性: 缺少张力测量元件（如张力计或板形辊中的张力检测功能），而薄膜张力控制是板材轧制厚度、板形控制的关键回路，检测环节不应遗漏。
  - 建议: 在检测与控制系统下增加“张力传感器”部件，至少包含板形测量仪内的张力测量单元或独立的张力计，并拆分必要的零件。
- **DeepSeek 单方** 板形控制与工艺介质系统 — 功能完备性: 仅包含中间辊窜辊相关部件，未覆盖常见的工作辊窜辊执行机构。在四辊或CVC轧机中，工作辊轴向窜动是板形控制的重要手段，当前结构会导致该功能完全缺失。
  - 建议: 增加工作辊窜辊执行液压缸、导向滑板、锁紧装置等部件及对应零件，或补充可通用的窜辊功能说明（如用同一组窜辊部件同时适配工作辊与中间辊）。
- **DeepSeek 单方** 入口夹送辊 — 拆解充分性: 部件下仅列出了上、下夹送辊和液压缸，缺少直接与辊轴配合的轴承、密封等关键易损件，导致维护和备件清单不完整，无法独立开展检修策划。
  - 建议: 在入口夹送辊部件下增加零件：如“夹送辊轴承”（可拆分调心滚子轴承等）和“夹送辊密封件”，并标记易损属性。
- **DeepSeek 单方** 压下螺丝副 — 信息完整性: 部件描述字段为空，缺少功能、结构简述，不利于理解其作为独立维护单元的定义。
  - 建议: 参照其他部件，补充压下螺丝副的描述，例如“合金锻钢梯形螺纹副，安装在机架顶部，通过旋转实现上辊缝调整”。
- **DeepSeek 单方** 冷却液流量控制阀组 — 命名正确性: 部件名称“冷却液流量控制阀组”与描述不符。实际该阀组用于调节弯辊和窜辊控制回路中的液压油，而非冷却液，容易造成介质混淆。
  - 建议: 将部件名称改为“弯辊/窜辊流量控制阀组”，或在原名称后添加“(液压回路)”进行澄清。
- **DeepSeek 单方** 分段冷却控制阀箱 — 零件覆盖: 分段冷却阀箱集成大量高速开关电磁阀，但仅列出“气动薄膜执行器”一个易损零件，高频动作的电磁阀（线圈、阀芯）更易损耗，缺失关键易损件。
  - 建议: 在分段冷却控制阀箱下增加“高速开关电磁阀”或“电磁阀线圈”作为易损零件。
- **DeepSeek 单方** 电机端齿式联轴器 — 零件覆盖: 该联轴器未列出端盖及密封件，而联轴器脂密封是常见泄漏点，缺少此类易损件会影响备件管理。
  - 建议: 在电机端齿式联轴器部件下增加“端盖及密封”零件，并标记为易损件。
- **Kimi 单方** 板材轧机 — 功能完备性: 缺少换辊装置子系统（如工作辊换辊小车、支承辊换辊横移车、推拉机构、轨道及定位装置等）。换辊是板材轧机维持轧制线运行的关键辅助功能，其机构具有独立的失效模式、维护策略和备件体系，缺失导致知识体系无法覆盖换辊相关故障与检修知识，严重破坏功能完备性。
  - 建议: 增设“换辊装置”子系统，按工作辊换辊、支承辊换辊等功能划分部件，包含换辊小车/横移车、钩挂装置、推拉缸、轨道及定位机构等独立维护单元。
- **Kimi 单方** 窜辊锁紧装置 / 窜辊锁紧楔块 — 层级语义一致性: 窜辊锁紧装置与窜辊锁紧楔块作为同级部件并列，存在层级语义倒置。楔块实质是锁紧装置的核心执行零件/子总成，且锁紧装置未挂载任何零件，而锁紧楔块却挂载了密封件，破坏了“部件—零件”的层级语义和失效独立性，导致故障知识无法准确挂载与检索。
  - 建议: 将窜辊锁紧楔块及其下属零件（锁紧缸密封件）统一归入窜辊锁紧装置作为零件；若楔块需独立更换，可建立四级结构（部件→子部件→零件），或在三级结构中仅保留锁紧装置，将楔块、锁紧缸等均列为其零件。
- **Kimi 单方** 冷却液流量控制阀组 — 层级语义一致性: 部件名称与描述严重不符：名称为“冷却液流量控制阀组”，但描述明确其为“弯辊及窜辊控制回路中液压油”的阀组。冷却液与液压油为不同介质，此错误将导致介质属性分类混乱，故障检索时无法按工艺介质精准定位。
  - 建议: 更名为“板形控制液压阀组”或“弯辊窜辊液压控制阀组”，并在描述中统一为液压油介质；若确为冷却液阀组，则修正描述并调整至冷却介质回路。
- **Kimi 单方** 升降导卫台框架 — 归属正确性: 升降导卫台框架描述为“为入口导卫及侧导板的安装基础”，却挂载在“侧导板”部件下。该框架主要服务于入口导卫装置的升降换辊功能，与侧导板仅为空间并列关系，并非侧导板的组成部分，归属错误将导致换辊故障检索路径错误。
  - 建议: 将升降导卫台框架从侧导板下移出，作为“入口导卫装置”的零件；若其同时承载侧导板且结构独立，则提升为“板材输送与导卫系统”下的独立部件（升降导卫台）。
- **Kimi 单方** 液压管线与管接头 — 失效独立性: 将遍布全机的液压管网聚合为一个“液压管线与管接头”部件，不满足失效独立性。管线由多段独立钢管、软管、接头组成，各段独立失效、独立更换，聚合后导致故障边界模糊，无法精准定位泄漏或爆裂点位，不利于故障知识的精准检索。
  - 建议: 取消该独立部件，将管路按所属功能系统（如弯辊管路、压上管路）或物理区段拆分，作为相关部件（如液压缸、阀台）的关联零件或独立管路部件；旋转接头已独立成件，予以保留。
- **Kimi 单方** 前工作辊道 / 后工作辊道 / 夹送辊 — 粒度一致性: 前后工作辊道及出入口夹送辊的拆解粒度不一致：前工作辊道挂载了“辊道轴承座”，后工作辊道缺失轴承座；入口夹送辊未挂载轴承类零件，出口夹送辊却挂载了“调心轴承”。同级同类部件的零件模板不统一，影响故障知识组织的规范性和检索对称性。
  - 建议: 统一前后辊道及出入口夹送辊的零件模板：补充缺失的轴承座/轴承零件，或统一不拆解至轴承层，保持粒度一致。
- **Kimi 单方** 双筒过滤器 — 粒度一致性: 同级的冷却液过滤器、润滑油过滤器均挂载了“滤芯”作为核心易损零件，但双筒过滤器下未挂载滤芯，导致同类过滤部件的粒度不一致，且滤芯是过滤器最主要的维护更换件。
  - 建议: 在双筒过滤器部件下补充“滤芯”零件，并标记为易损件。
- **Kimi 单方** 传感器类 — 粒度一致性: 过程连接类传感器的零件拆解程度不一致：仅压力传感器和液位传感器挂载了“O形密封圈”和“电气插头”，而位移传感器、温度传感器、增量式编码器等未按相同逻辑拆解。温度传感器描述中提及保护套管，但零件中未体现。
  - 建议: 统一传感器零件模板：所有带过程接口的传感器均补充密封件、连接器等可更换易损零件；或统一在部件层描述维护要点，不再向下拆分密封件，以保持全文粒度一致。
- **Kimi 单方** 检测与控制系统各部件 — 数据一致性: 易损标识列存在编码冲突：检测与控制系统使用“Y”/“N”，其余子系统使用“是”/“否”，破坏全文数据一致性，影响基于易损属性的筛选和精准检索。
  - 建议: 全文统一将易损标识为“是”/“否”，替换检测与控制系统中所有的“Y”和“N”。
- **Kimi 单方** 压下螺丝副 — 层级语义一致性: 压下螺丝副部件缺少描述信息，且其与压下传动装置、压下螺丝锁紧装置的功能边界在部件层未清晰界定，可能导致故障知识挂载时的职责不清。
  - 建议: 补充压下螺丝副的描述，明确其作为“可独立更换的螺纹传动副总成”的定位，阐明与传动装置、锁紧装置的接口边界。

### 待新增条目

- 新增 `张力传感器` → 检测与控制系统（原因: 薄膜张力是厚度和板形控制的基础参数，轧机出口和入口通常设置张力计或张力测量辊，其信号需接入控制系统，缺失将导致检测链路不完整。）
- 新增 `工作辊窜辊执行装置（液压缸、导向滑板、锁紧块等）` → 板形控制与工艺介质系统（原因: 现有结构仅覆盖中间辊窜辊，而常见板材轧机（如CVC-4、UCM）均需工作辊轴向窜动以控制板廓，缺失会造成板形控制功能不完整。）
- 新增 `夹送辊轴承（如调心滚子轴承）` → 入口夹送辊（原因: 上下夹送辊旋转需要轴承支撑，属于可更换的磨损元件，检修时需独立检查和更换。）
- 新增 `夹送辊密封件` → 入口夹送辊（原因: 轴承座需要密封防止润滑脂流失和冷却水进入，属于常规消耗件，应纳入零件清单。）
- 新增 `换辊装置系统` → 板材轧机（原因: 换辊是板材轧机维持生产的核心辅助功能，具有独立的机械、液压及电气故障模式，应作为独立子系统存在，以系统化组织换辊相关故障与维护知识。）
- 新增 `上输出轴 / 下输出轴` → 齿轮座（原因: 齿轮座目前仅列出输出齿轮和轴承，缺少输出轴本体；输出轴是承受扭矩并可能扭断、弯曲的独立失效件，应与输入齿轮轴同级列出。）
- 新增 `滤芯` → 双筒过滤器（原因: 滤芯是双筒过滤器最核心的易损可更换件，同级的冷却液过滤器、润滑油过滤器均已列出，此处遗漏破坏粒度一致性。）
- 新增 `接轴托架（或接轴平衡装置）` → 主传动系统（原因: 万向接轴通常配有托架或平衡装置以补偿自重、防止接轴下垂，是独立安装、独立维护的单元，缺失导致接轴支撑相关故障无法精准挂载。）

### 待移除条目

- 移除 `液压管线与管接头`（原因: 管网非独立总成，且其组成元素（钢管、软管、旋转接头）已在其他部件（如旋转接头、循环管路）中分散体现，作为独立部件导致边界模糊，与失效独立性原则冲突。）
