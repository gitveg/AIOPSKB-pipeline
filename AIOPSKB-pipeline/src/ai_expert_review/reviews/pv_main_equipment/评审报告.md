## 三、第2轮评审：全覆盖审查（2026-05-29）

### 3.1 专家评分

| 专家 | 评分 | 核心发现 |
|------|------|---------|
| DeepSeek | 7.5/10 | MLPE分类错误；缺关口计量；升压站边界模糊 |
| Kimi | 6.5/10 | MLPE违反功能等效原则；交流汇流柜边界跨越；电缆与集电线路重叠 |
| Claude（主智能体） | 7.0/10 | 综合评估：MLPE是硬伤，其余可接受 |

### 3.2 两位专家共识

| 共识点 | 意见 |
|--------|------|
| MLPE拆分 | 微型逆变器功能等效逆变器→主设备；功率优化器→辅助设备 |
| 补充关口计量 | 并网法定设备，当前缺失 |
| 升压站边界 | 与主变、无功补偿等存在包含歧义 |

### 3.3 分歧点

| 分歧点 | DeepSeek | Kimi |
|--------|---------|------|
| 交流汇流及并网柜 | 维持辅助设备 | 拆分为"交流汇流柜（辅助）"+"并网柜（公用）" |
| AGC/AVC | 补充为公用系统 | 未特别提及 |
| 直流电源系统 | 补充为公用系统 | 未特别提及 |
| 箱变与主变"同构异类" | 未提及 | 需显性化分类准则 |

### 3.4 主智能体仲裁

#### ✅ 采纳项

**1. MLPE拆分为两条（两位专家一致）**

微型逆变器完成 DC→AC 核心转换，按四维原则第2条"与能量转换核心的距离"判定，与组串式逆变器处于同一位置，功能完全等效。功率优化器仅做 DC/DC MPPT 优化，不改变电形态，归辅助设备。

**2. 升压站/GIS描述修正（两位专家一致）**

添加排除条款，消除与主变、无功补偿等已独立列项设备的包含歧义。

**3. 补充关口电能计量装置（两位专家一致）**

并网点高精度电能表是并网结算法定设备。

**4. 电缆与集电线路描述优化（Kimi提出）**

电缆限定为"发电单元内部"，集电线路限定为"子阵至升压站传输段"，消除范围重叠。

**5. 箱变描述补注判定依据（Kimi提出）**

箱变与主变同属变电设备大类，分类差异来自配置粒度（单元级 vs 站级）。在描述中显性化此判定依据，消除"同构异类"困惑。

#### ❌ 不采纳项

**6. AGC/AVC独立条目（DeepSeek建议）**

光伏中 AGC/AVC 通常由 SCADA 系统集成实现，不单独成设备。如后续部件拆解发现需单独列，再补充。

**7. 交流汇流及并网柜拆分（Kimi建议）**

并网柜在集中式光伏中偏公用侧，分布式光伏中偏单元侧。拆分后在跨场景知识库中反增"哪个条目适用"的歧义。维持辅助设备，描述中保留"集中式光伏中逆变器直接接入箱变时此设备可能不存在"的注明。

**8. 防孤岛保护/直流电源系统独立条目（DeepSeek建议）**

防孤岛保护功能已由逆变器（主设备）和并网柜（辅助设备）承载；直流电源系统包含在"站用电系统"中。不新增条目。

## 五、修改后完整设备清单

> 以下为两轮评审裁定全部落地后的预期设备清单。共 **29 项**（4 主设备 / 7 辅助设备 / 18 公用系统）。

### 主设备（4项）

| 设备名称 | 描述 |
|---------|------|
| 光伏组件 | 将太阳辐射能直接转化为直流电能的核心发电单元，由多个光伏电池片串联/并联封装而成，是光伏电站最核心的能量转换设备（光能→直流电能） |
| 光伏逆变器 | 将光伏组件产生的直流电转换为符合并网要求的交流电的核心设备（直流→交流），具备MPPT最大功率点跟踪、并网保护、电能质量控制等功能 |
| 箱式变压器 | 集变压器、高压开关、低压开关于一体的组合式变配电设备，将逆变器输出的低压交流电升压至集电线路电压等级（如35kV）。按1~2MW发电单元配置，单元制接线（一单元一变），故障导致该发电单元停运。**按发电单元配置，配置粒度单元级→归主设备；站级主变服务全站→归公用系统** |
| **微型逆变器** | **安装于单个光伏组件上，直接完成组件级直流到交流转换的小型逆变器，功能等效于组串式逆变器。故障导致对应组件支路失电** |

### 辅助设备（7项）

| 设备名称 | 描述 |
|---------|------|
| 汇流箱 | 将多路光伏组串的直流电流汇集后输出至逆变器，减少直流侧电缆敷设量，具备防反充、过流保护及监测功能 |
| 直流配电柜 | 接收汇流箱输出的直流电能并进行分配和保护，为逆变器提供直流输入接口 |
| 光伏支架 | 用于固定和支撑光伏组件的结构系统，包括固定支架和可调角度支架，直接影响组件的受光角度和发电效率 |
| 跟踪系统 | 太阳跟踪支架系统，通过单轴或双轴跟踪太阳位置，使光伏组件始终保持最佳受光角度，提高发电量。具备独立的机电传动机构和控制单元 |
| 交流汇流及并网柜 | 汇集多台逆变器交流输出并实现与电网安全连接的配电设备，含断路器、保护装置、电能计量等。集中式光伏中逆变器直接接入箱变时此设备可能不存在 |
| **功率优化器** | **安装于单个光伏组件上，实现组件级 MPPT 控制和直流电压优化的电力电子设备，不改变电形态（DC/DC），辅助提升发电效率** |
| 电缆及接线系统 | **发电单元内部的**直流电缆、交流电缆、通信电缆及接线端子等，实现发电单元内各设备之间的电气连接和信号传输 |

> **注**：电缆及接线系统描述已从原"电站各设备之间"限定为"发电单元内部"，避免与站级集电线路重叠。

### 公用系统（18项）

| 设备名称 | 描述 |
|---------|------|
| 主变压器 | 升压站核心设备，将集电线路汇集的电能升至并网电压等级（如110kV/220kV/330kV）。全场公用升压站，汇集全站电能统一升压并网，故障影响全站 |
| 无功补偿装置（SVG/SVC） | 全站共用无功补偿设备，安装于升压站侧，响应调度指令调节全站并网点无功功率和电压稳定 |
| 一次调频装置 | 全站级并网响应系统，响应电网频率变化快速调节全站有功功率输出，参与电网频率调节 |
| 电能质量监测装置 | 监测全站并网点电压、频率、谐波、三相不平衡等电能质量指标的装置 |
| 功率预测系统 | 基于气象数据和电站运行数据，预测短期和超短期光伏发电功率的全站级系统，服务电网调度 |
| 集电线路 | **将各光伏阵列单元经箱变升压后的电能汇集输送至升压站的站级输电线路**，包括架空线路和电缆线路 |
| 升压站/GIS开关站 | 全站共用的变电和配电设施，包括GIS组合电器、断路器、隔离开关、互感器等，实现电能升压并网**（不含已独立列项的主变压器、无功补偿装置、电能质量监测等）** |
| 防雷接地装置 | 全站防雷和接地基础设施，包括避雷针、避雷器、接地网等，覆盖光伏区和升压站 |
| SCADA监控系统 | 全站实时数据采集与监控系统，对光伏组件、逆变器、变压器等设备进行远程监控、数据分析和运行管理 |
| 站用电系统 | 为光伏电站内各辅助设备、监控系统、照明等提供厂用电源的配电系统 |
| 通信系统 | 包括光纤通信、有线/无线网络等，实现电站内部设备间及电站与调度中心的数据传输和远程通信 |
| 消防系统 | 全站消防安全设施，包括火灾报警系统、灭火器、消防栓、消防水池等 |
| 暖通空调系统 | 为升压站控制室、逆变器室等提供温度和湿度调节，保障设备在适宜环境下运行 |
| 照明系统 | 全站正常照明和应急照明设施，保障夜间运维和紧急情况下的工作环境 |
| 给排水系统 | 为电站提供生活用水、设备清洗用水及雨水排放等功能的基础设施 |
| 视频安防系统 | 包括视频监控摄像头、入侵报警、电子围栏等，实现电站周界安全和设备运行状态的实时可视化监控 |
| 气象监测站 | 安装辐照仪、温度计、风速仪等气象传感器，实时监测太阳辐射、环境温湿度、风速风向等气象参数，为功率预测提供数据支持 |
| **关口电能计量装置** | **安装于并网点的高精度电能计量设备，满足电网调度和结算要求，是并网运行的法定设备** |
