# 输电子行业设备分类评审

> 请你作为电力行业设备分类专家，审查以下输电子行业的设备清单，重点评审**主设备**的分类是否合理。

## 背景

我们正在构建工业设备智能运维知识库，结构为"行业→子行业→设备→部件→故障"。每个子行业需要将设备分为三类：
- **主设备**：核心能量转换/传输设备，独立采购、独立检修班组、独立KKS编码
- **辅助设备**：支持主设备运行的设备
- **公用系统**：全厂共用、服务多台设备的基础设施

### 已完成的评审结论（供参考）

已完成火电、水电、风电、光伏、核电五个子行业的三专家评审，确立了以下主设备判定方法论：

1. **L1 核心能量转换设备**：直接完成能源形态转换，无争议为主设备
2. **L2 主工艺链关键节点设备**：不直接转换能量，但处于主工艺链不可绕过的关键节点，且具备独立性强、投资大、停机影响全局的特征
3. **"全场公用"降级规则**：全场共用设备降级为公用系统
4. **"依附性"降级规则**：功能上完全依附于主设备的控制系统归辅助设备（如励磁系统→辅助设备）
5. **"子行业归属"原则**：跨子行业共享的设备应在对应子行业中独立维护
6. **"构筑物 vs 设备"区分**：建筑结构不纳入设备体系

**跨行业先例**：
- 火电/水电/核电主变压器：**主设备**（一机一变，单元制接线）
- 风电/光伏主变压器：**公用系统**（全场公用升压站）
- 火电/水电凝汽器：**主设备**（朗肯循环冷端关键节点）
- 火电GCB：**主设备**（主电气连接关键控制节点）
- 风电/光伏箱变：**主设备**（一机/一单元一变）
- 励磁系统（火电/水电）：**辅助设备**（依附于发电机）
- 核电安全壳：**移出设备清单**（构筑物，非机械设备）

## 评审要求

### 1. 主设备分类审查

当前38项主设备，请逐一审查：
- 哪些应**保留**？理由？
- 哪些应**降级**（辅助设备或公用系统）？理由？
- 是否有**辅助设备应升级**为主设备？

### 2. 设备粒度问题（重点）

当前输电将不同型号的同一类设备列为独立主设备项：
- **导线**：5种（ACSR、铝合金、碳纤维、扩径、耐热）→ 是否应合并为"导线"1项？
- **杆塔**：4种（角钢塔、钢管塔、钢管杆、混凝土杆）→ 是否应合并为"杆塔"1项？
- **绝缘子**：4种（瓷质、玻璃、复合、支柱）→ 是否应合并为"绝缘子"1项？
- **金具**：悬垂线夹/耐张线夹为主设备，连接/接续金具为辅助设备 → 这个拆分是否合理？

**核心问题**：其他子行业（如火电）不会把不同型号锅炉分开列，输电行业的设备是否应合并为大类，在部件层区分型号/材质？

### 3. 继电保护装置的分类

线路保护装置（差动/距离/纵联）和自动重合闸装置被列为主设备。但在火电/水电中，继电保护装置归辅助设备。请评估：
- 输电线路保护是否具有足够独立性可以列为主设备？
- 还是应与其他子行业保持一致，归为辅助设备？

### 4. HVDC设备

换流阀、换流变压器、平波电抗器等高压直流输电专用设备被列为主设备。请确认：
- 这些设备的分类是否合理？
- 换流站设备与变电设备有重叠（如换流变压器vs变压器、直流断路器vs断路器），如何划定边界？

### 5. 公用系统偏少

当前仅3项公用系统（载波机、光端机、电缆敷设通道），是否合理？以下设备是否应归入公用系统：
- 通信设备
- 在线监测装置
- 故障录波器/测距装置

### 6. 删除或合并建议

- 是否有设备项应删除或合并？
- 是否有遗漏的重要设备？

如果你对某个分类不确定，可以自行调用自己的网络搜索能力，结合实际工程资料来回答。

请按上述6个方面逐一回复，每项给出明确结论（保留/升级/降级/删除/移动/新增/合并）和理由。
