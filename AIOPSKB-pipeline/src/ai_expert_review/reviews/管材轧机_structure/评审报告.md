### 2.3 遗漏项

- **轧辊换辊装置**（DeepSeek）: 管材轧机频繁更换轧辊是典型维护作业，换辊装置（如换辊机械手、换辊小车及导轨）是保证换辊效率和安全的独立可维护总成，应作为部件纳入主机系统进行管理。
- **蓄能器皮囊**（DeepSeek）: 蓄能器皮囊是主要的可更换易损件，其破裂将导致蓄能功能丧失，必须列入零件清单并标记为易损件。
- **进出料输送系统**（Kimi）: 管材轧机必须包含入口受料、输送辊道、推料对齐及出口辊道等功能链，当前完全缺失，导致输送设备故障无法检索和系统化维护。
- **芯棒**（Kimi）: 芯棒是管材轧机核心工艺件，具备独立失效模式（磨损、热裂、弯曲、表面粘结），需作为独立部件管理其寿命、维护和报废。
- **导板**（Kimi）: 导板（入口导板/出口导板/侧导板）是直接参与变形的易损工艺件，需独立部件节点以覆盖其磨损、烧粘、开裂等故障知识。
- **万向接轴中间托架**（Kimi）: 长万向接轴的中间支撑是保障传动稳定性、防止接轴下垂振动的必要功能部件，缺失导致传动链不完整。
- **压下止推轴承（或压下球面垫）**（Kimi）: 压下丝杆与上轴承座之间通常设有止推轴承或球面垫以传递轧制力并自适应调心，缺失导致压下系统力传递链和失效模式覆盖不完整。

### 2.4 冗余项

- **液压与气压系统 -> 轧辊平衡液压缸**（DeepSeek）: 该液压缸已在“轧机主机系统”的“上轧辊平衡装置”中作为关键零件/子部件出现，此处重复。应统一归属，避免双重记录。
- **上轧辊平衡装置 -> 平衡液压缸**（DeepSeek）: 将整个液压缸作为零件粒度不当，且与液压系统中的“轧辊平衡液压缸”重复，应调整层级后移除该处的“平衡液压缸”零件行。
- **液压与气压系统-轧辊平衡液压缸**（Kimi）: 与'轧机主机系统-上轧辊平衡装置'中的平衡液压缸为同一物理单元，重复定义，违背部件失效独立性及知识树唯一性。
- **液压与气压系统-轧辊平衡控制阀组**（Kimi）: 其功能是为上轧辊平衡装置提供液压控制，应与平衡装置聚合或归属液压动力源统一分配，不应独立于主机系统重复存在。

### 待裁定分歧

- **DeepSeek 单方** 上轧辊平衡装置 — 粒度一致性 / 拆解充分性: 部件“上轧辊平衡装置”下将“平衡液压缸”整体作为一个零件，但液压缸是可独立更换、包含内部易损件的功能总成，其本身应当是部件，不应降级为零件。同时，该结构树又在“液压与气压系统”中列出了“轧辊平衡液压缸”作为部件，造成同一液压缸的双重归属与层级混乱。
  - 建议: 将“平衡液压缸”从零件提升为“上轧辊平衡装置”的子部件（或将该装置拆为多个部件），并将其从液压系统中移除，避免重复。也可保持液压缸在液压系统中，而将“上轧辊平衡装置”仅作为机械连杆总成，不含液压缸。
- **DeepSeek 单方** 供水离心泵组 / 润滑油泵组 — 拆解充分性 / 失效独立性: “供水离心泵组”和“润滑油泵组”中，将“泵驱动电机”“油泵驱动电机”列为零件，但电机是独立的驱动单元，可整体更换、独立检修，且存在独立失效模式（如绕组烧毁），其体量和维护价值应当是部件。作为零件会掩盖独立的维护需求，且违背“部件为可独立更换的总成”的粒度要求。
  - 建议: 将泵组拆分为“泵头”和“驱动电机”两个部件，或将电机列为独立的部件，不再作为零件。例如可设部件：“冷却水泵头”“冷却水泵电机”；“润滑油泵头”“润滑油泵电机”。
- **DeepSeek 单方** 蓄能器组 — 聚焦易损/可更换件: 液压系统中的“蓄能器组”标为易损（是），但其零件单元格为空，未列出皮囊、密封件等关键易损可更换件，导致该部件无零件支撑，无法反映真实的维护对象。
  - 建议: 在“蓄能器组”部件下增加零件，如“皮囊”“密封组件”“充气阀总成”等，并正确标记易损标识。
- **DeepSeek 单方** 主传动系统 vs 冷却与润滑系统 — 边界清晰: 主传动系统中包含“稀油润滑站”为减速机、齿轮座提供稀油润滑；而“冷却与润滑系统”中“润滑油泵组”描述包含“传动件润滑”，未明确排除减速机等传动件，存在功能重叠或模糊的风险。
  - 建议: 明确冷却与润滑系统的润滑油泵组仅用于工艺润滑（如轧辊润滑、芯棒润滑）及可能的小型滑动件润滑，不包含主传动齿轮箱润滑。在描述中注明“不含主减速机及齿轮座稀油循环”，或将该泵组并入工艺润滑子系统并更名。
- **DeepSeek 单方** 辊缝斜楔调整装置 — 聚焦易损件: 该部件下零件“锁紧螺母”标记为不易损（否），该零件属于通用连接件，无显著磨损或定期更换需求，纳入零件表会稀释对关键易损件的关注度。
  - 建议: 考虑移除“锁紧螺母”零件行，或将其标记保持为“否”但仅当存在失效历史、影响安全时才保留。
- **DeepSeek 单方** 压下减速机 — 粒度一致性: “压下减速机”作为部件，其零件中包含“蜗杆轴”与“蜗轮”，但蜗杆轴两端的轴承未列出（仅列出油封）。通常蜗杆轴的支撑轴承是重要易损件，应予以关注。
  - 建议: 在“压下减速机”下增加“蜗杆轴前/后轴承”等零件，完善易损件清单。
- **Kimi 单方** 液压与气压系统 / 轧机主机系统 — 边界清晰: 轧辊平衡功能在'轧机主机系统-上轧辊平衡装置'与'液压与气压系统-轧辊平衡液压缸/轧辊平衡控制阀组'中双重定义，同一物理单元被重复挂载，破坏知识树唯一性，导致故障检索时出现歧义和挂接混乱。
  - 建议: 删除'液压与气压系统'下的'轧辊平衡液压缸'及'轧辊平衡控制阀组'；将其液压缸、活塞密封、防尘圈等零件迁移至'轧机主机系统-上轧辊平衡装置'下作为其零件；液压系统仅保留液压泵站、蓄能器、通用阀组及管路等动力源与分配单元。
- **Kimi 单方** 管材轧机整体 — 功能完备性: 缺少'进出料输送系统'子系统，管材轧机的入口受料、输送辊道、对齐推料、出口辊道及横移机构等功能链完全缺失，仅在'液压与气压系统'中零散出现一个'输送辊道气动马达'，无法支撑输送设备故障的系统化检索与维护。
  - 建议: 新增'进出料输送系统'子系统，至少包含入口辊道组件、出口辊道组件、推料/挡料机构等部件，并将'输送辊道气动马达'调整至对应辊道部件下作为驱动零件或子部件。
- **Kimi 单方** 工模具操作系统 — 功能完备性: 工模具操作系统缺少'芯棒'和'导板'本体部件，仅包含操作机构、锁紧装置及辅助设备。芯棒与导板是独立失效、定期更换且需寿命管理的关键工艺件，其磨损、变形、粘结、热裂等故障模式无法被当前结构覆盖。
  - 建议: 在'工模具操作系统'下新增'芯棒'部件（含芯棒本体、连接器等零件）和'导板'部件（含导板本体、导板底座/衬板等零件），并挂载相应的维护与报废策略。
- **Kimi 单方** 主传动系统-稀油润滑站 — 层级语义一致性: 稀油润滑站属于辅助润滑功能单元，不应挂在以'扭矩传递'为功能边界的主传动系统下，违背'子系统按功能分'的原则；且与'冷却与润滑系统'存在功能重叠和边界模糊，易造成知识体系分类混乱。
  - 建议: 将'稀油润滑站'从'主传动系统'移除，并入'冷却与润滑系统'子系统，并更名为'主传动稀油润滑站'以明确其服务对象，保持主传动系统仅包含机械传动链。
- **Kimi 单方** 轧机主机系统-压下电机/压下减速机/压下丝杆与螺母副 — 粒度一致性: 压下相关单元被拆分为三个独立部件，与'上轧辊装配''机架'等复杂总成部件粒度严重失衡；压下功能被过度碎片化，不利于压下系统整体故障关联分析和知识检索。
  - 建议: 将'压下电机''压下减速机''压下丝杆与螺母副''安全臼'聚合为一个'压下装置'部件，原内容降为其下的零件或子部件；或在'轧机主机系统'下增设'压下与辊缝调整'子系统以统一承载压下、斜楔调整等功能。
- **Kimi 单方** 主传动系统-万向接轴 — 功能完备性: 长万向接轴通常配置中间托架或平衡悬挂装置以防止接轴下垂、振动及偏心，当前结构缺失该支撑功能部件，导致接轴传动链功能描述不完整。
  - 建议: 在'主传动系统'下新增'万向接轴中间托架'部件，包含托架轴承、横梁等零件。
- **Kimi 单方** 液压与气压系统-蓄能器组 — 失效独立性: 蓄能器组被整体标记为'易损'，但蓄能器壳体通常不易损，易损件为内部皮囊/活塞；整体挂载易损标识会导致故障粒度粗化，与'部件应是独立失效单元'的原则存在偏差。
  - 建议: 在蓄能器组部件下新增'蓄能器皮囊（或活塞密封）'零件并标记为易损，将部件级易损标识改为'否'，或补充壳体与内胆的区分。
- **Kimi 单方** 冷却与润滑系统-供水离心泵组/润滑油泵组 — 粒度一致性: 泵组作为部件时，其下的'泵驱动电机'被列作零件，但电机为标准独立部件且具备独立失效模式，列在零件层粒度偏细，且其维护/报废信息缺失。
  - 建议: 将'泵驱动电机'从零件层移除，由电气系统统一管控；若保留在泵组下，应补充其维护与报废方法或明确引用电气系统相关节点。

### 待新增条目

- 新增 `轧辊换辊装置` → 轧机主机系统（原因: 管材轧机频繁更换轧辊是典型维护作业，换辊装置（如换辊机械手、换辊小车及导轨）是保证换辊效率和安全的独立可维护总成，应作为部件纳入主机系统进行管理。）
- 新增 `蓄能器皮囊` → 蓄能器组（原因: 蓄能器皮囊是主要的可更换易损件，其破裂将导致蓄能功能丧失，必须列入零件清单并标记为易损件。）
- 新增 `进出料输送系统` → 管材轧机（原因: 管材轧机必须包含入口受料、输送辊道、推料对齐及出口辊道等功能链，当前完全缺失，导致输送设备故障无法检索和系统化维护。）
- 新增 `芯棒` → 工模具操作系统（原因: 芯棒是管材轧机核心工艺件，具备独立失效模式（磨损、热裂、弯曲、表面粘结），需作为独立部件管理其寿命、维护和报废。）
- 新增 `导板` → 工模具操作系统（原因: 导板（入口导板/出口导板/侧导板）是直接参与变形的易损工艺件，需独立部件节点以覆盖其磨损、烧粘、开裂等故障知识。）
- 新增 `万向接轴中间托架` → 主传动系统（原因: 长万向接轴的中间支撑是保障传动稳定性、防止接轴下垂振动的必要功能部件，缺失导致传动链不完整。）
- 新增 `压下止推轴承（或压下球面垫）` → 轧机主机系统（原因: 压下丝杆与上轴承座之间通常设有止推轴承或球面垫以传递轧制力并自适应调心，缺失导致压下系统力传递链和失效模式覆盖不完整。）

### 待移除条目

- 移除 `液压与气压系统 -> 轧辊平衡液压缸`（原因: 该液压缸已在“轧机主机系统”的“上轧辊平衡装置”中作为关键零件/子部件出现，此处重复。应统一归属，避免双重记录。）
- 移除 `上轧辊平衡装置 -> 平衡液压缸`（原因: 将整个液压缸作为零件粒度不当，且与液压系统中的“轧辊平衡液压缸”重复，应调整层级后移除该处的“平衡液压缸”零件行。）
- 移除 `液压与气压系统-轧辊平衡液压缸`（原因: 与'轧机主机系统-上轧辊平衡装置'中的平衡液压缸为同一物理单元，重复定义，违背部件失效独立性及知识树唯一性。）
- 移除 `液压与气压系统-轧辊平衡控制阀组`（原因: 其功能是为上轧辊平衡装置提供液压控制，应与平衡装置聚合或归属液压动力源统一分配，不应独立于主机系统重复存在。）
