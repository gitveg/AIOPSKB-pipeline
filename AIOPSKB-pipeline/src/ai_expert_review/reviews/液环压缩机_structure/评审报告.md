### 2.3 遗漏项

- **安全阀**（双方）: 液环压缩机排气侧必备超压保护装置，法定安全附件，独立失效模式如起跳压力漂移、密封不严、卡涩需独立挂载。
- **进气过滤器**（双方）: 防止固体颗粒进入叶轮，保护主机，独立可更换滤芯结构，有独立失效模式。
- **润滑组件**（DeepSeek）: 主轴轴承润滑（油嘴、油杯或稀油管路）是独立的失效链，润滑不良直接导致轴承失效，需独立部件以支持故障归因。
- **轴承润滑组件**（Kimi）: 主轴轴承的润滑（油嘴、油杯、润滑管路或脂嘴）是独立失效链，润滑不良直接导致轴承失效，应在主机系统或主轴部件下独立挂载以支持故障归因。

### 2.4 冗余项

- **进气法兰盘**（双方）: 法兰盘通常与壳体或接管焊接/整体加工，非现场独立更换零件，无运维意义。
- **进气法兰螺栓组**（双方）: 标准紧固件组，违背零件层不罗列无运维意义紧固件的原则，应删除。
- **排气法兰盘**（双方）: 同进气法兰盘，非独立可更换零件，应删除。
- **排气法兰螺栓组**（双方）: 标准紧固件组，无独立失效与运维意义，应删除。
- **地脚螺母**（双方）: 标准紧固件，与螺栓成套使用，无独立失效和更换意义，拆分过细。
- **地脚垫圈**（双方）: 标准紧固件，应与螺栓组件合并，现拆分无运维意义。
- **轴套**（DeepSeek）: 与轴封装置功能强耦合，通常与机械密封同步检修更换，应降级为零件，作为独立部件导致故障知识分散。
- **气液分离器 → 罐体**（双方）: 气液分离器本身即压力容器，罐体是其主体，无法独立更换，作为零件列出无实际维护和备件意义，层级混淆。

### 待裁定分歧

- **DeepSeek 单方** 进气法兰 / 排气法兰 — 粒度一致性: 法兰盘通常与壳体或管路焊接/铸造成一体，非独立可更换单元；拆分为法兰盘、密封垫、螺栓组导致零件层出现大量标准紧固件，严重违背“不罗列无运维意义紧固件”原则。
  - 建议: 取消法兰盘与螺栓组零件拆分，仅保留“密封垫”作为零件；或直接将进/排气法兰收敛为“进气接管”、“排气接管”部件，不再拆解。
- **Kimi 单方** 进气法兰 / 排气法兰 — 层级语义一致性: 法兰盘通常与壳体或管路焊接/铸造成一体，并非可独立更换单元；将其拆分为法兰盘+密封垫+螺栓组导致零件层出现大量标准紧固件和静密封件，与零件层不罗列无运维意义的紧固件之原则严重冲突。
  - 建议: 将进气法兰、排气法兰收敛为进气接管、排气接管部件（若含缓冲/消声功能）或直接作为壳体/管路的接口属性；零件层仅保留密封垫片作为易损件，取消法兰盘与螺栓组的零件拆分。
- **Kimi 单方** 轴封装置 — 拆解充分性: 轴封装置作为易损部件，描述已指明含动静环、弹簧和辅助密封圈，但在部件下未拆分出这些关键易损零件，不利于备件管理的精细化和针对性的失效分析。（部分认同另一位专家意见；但若现场采用集装式机械密封，整体更换属性应优先保留）
  - 建议: 若为散装机械密封或填料密封，建议在零件层拆分出动环、静环、弹簧、辅助密封圈（均标易损）；若为集装式机械密封，建议在部件描述中明确“集装式总成”，故障知识通过部件层故障词条覆盖关键失效模式，无需强制拆分为零件。

### 待新增条目

- 新增 `安全阀` → 支撑与辅助系统（原因: 液环压缩机排气侧必备超压保护装置，法定安全附件，独立失效模式如起跳压力漂移、密封不严、卡涩需独立挂载。）
- 新增 `进气过滤器` → 支撑与辅助系统（原因: 防止固体颗粒进入叶轮，保护主机，独立可更换滤芯结构，有独立失效模式。）
- 新增 `润滑组件` → 主轴（原因: 主轴轴承润滑（油嘴、油杯或稀油管路）是独立的失效链，润滑不良直接导致轴承失效，需独立部件以支持故障归因。）
- 新增 `安全阀` → 支撑与辅助系统（原因: 液环压缩机必须在排气侧配置安全阀以防止超压，属于法定安全附件和独立失效/维护单元，其失效模式（起跳压力漂移、密封不严、卡涩）需独立挂载。）
- 新增 `进气过滤器` → 支撑与辅助系统（原因: 防止固体颗粒进入叶轮导致液环压缩机叶轮损坏或液环污染，是主机保护链的关键环节，通常为独立可更换滤芯结构，具有独立失效模式。）
- 新增 `轴承润滑组件` → 主轴（原因: 主轴轴承的润滑（油嘴、油杯、润滑管路或脂嘴）是独立失效链，润滑不良直接导致轴承失效，应在主机系统或主轴部件下独立挂载以支持故障归因。）
