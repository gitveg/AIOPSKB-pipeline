### 2.3 遗漏项

- **下部导轴承（介质润滑滑动轴承）**（DeepSeek）: 立式筒袋泵通常在下端（吸入侧）设有介质润滑的滑动轴承（如赛龙轴承），为细长转子提供径向支撑，防止轴系振动，是保障转子稳定运行的关键部件。现有结构中仅提及“径向滑动轴承”，未明确覆盖这一底部导轴承，构成功能缺失。
- **底座与安装支撑**（Kimi）: 立式筒袋泵需泵座/底座连接外筒袋与基础，承担整机重量、弯矩及振动传递，是独立功能链和可维护单元。
- **密封腔盖/压盖**（Kimi）: 安装机械密封静环、形成密封腔的关键静子部件，可独立拆装更换，是轴封功能链的必要组成。
- **油冷却器**（Kimi）: 当前作为零件挂在油润滑系统下，应提升为独立部件以与密封冷却器保持粒度一致，且属于可独立更换的热交换总成。
- **轴承端盖/压盖**（Kimi）: 轴承箱的轴向定位与密封件，防止润滑油泄漏和轴承外移，属于独立可更换部件，缺失导致轴承系统功能不完整。
- **止动垫圈**（Kimi）: 锁紧装置描述中明确包含的一次性易损件，应作为零件展开以支持精准维护与更换。
- **推力轴承调整垫片**（Kimi）: 调整推力间隙/游隙的关键可更换零件，直接影响轴承安装精度与寿命，属于支撑系统的关键维护件。

### 2.4 冗余项

- **泵盖连接螺栓**（Kimi）: 标准紧固件，标记不易损，无独立失效模式与独立运维意义，不应在零件层单独存在，建议仅在泵盖部件描述中体现。
- **联轴器螺栓组件**（Kimi）: 虽为受力件，但标记不易损，通常随联轴器套件整体更换或按标准件管理，单独列零件增加检索噪声。
- **中间筒**（Kimi）: 标记不易损，属于联轴器的结构性延伸件，无独立维护报废意义，建议合并至联轴器部件描述。
- **级间轴套**（Kimi）: 标记不易损，属于轴套的保护性/定位性结构，通常随轴套或主轴整体维护，独立列零件意义不大。
- **弹簧（机械密封）**（Kimi）: 机械密封弹簧通常随密封总成整体更换，不单独维护，在零件层冗余。
- **平衡管**（Kimi）: 标记不易损，为平衡管线总成的普通连接管段，无独立更换价值，应在部件描述中说明材质规格即可。
- **冲洗管**（Kimi）: 标记不易损，属于冲洗冷却管路的普通连接管，冗余，应在管线部件描述中体现。
- **截止阀**（Kimi）: 标记不易损，作为管路附件且非易损件，列零件层冗余；如需保留应升格为独立部件“管路阀组”。

### 待裁定分歧

- **DeepSeek 单方** 多级叶轮 — 拆解充分性: 将全部多级叶轮合并为一个部件，粒度过粗。实际检修中各级叶轮是独立的可更换单元，每级叶轮都可能因汽蚀、磨损等单独失效，需要按级分别进行维护和备件管理。
  - 建议: 拆分“多级叶轮”为各级叶轮，可先按“首级叶轮”与“次级叶轮（2~N级）”分组，或按每一级单独列出，以支持精确故障定位和备件更换。
- **DeepSeek 单方** 导叶 — 拆解充分性: 同样将全部导叶合并为一个部件，不符合独立维护单元的粒度要求。各级导叶独立安装于中段内，可单独更换，且失效模式（冲蚀、尺寸变化）按级不同。
  - 建议: 将“导叶”拆分为各级导叶，至少按首级导叶与次级导叶分开（首级导叶常带防冲导流板），以匹配实际检修与备件策略。
- **DeepSeek 单方** 中段泵壳 — 拆解充分性: 将全部中段泵壳视为一个部件，粒度过粗。多级泵的每一段泵壳是独立的承压和流道单元，可单独更换，存在独立失效（如密封面腐蚀、止口变形），需要分列管理。
  - 建议: 拆分为各级中段泵壳，或按首段、中间段、末段分类，确保每一个可独立更换的泵壳段作为单独的部件。
- **DeepSeek 单方** 拉紧螺栓（中段泵壳下零件） — 易损标识合理性: 拉紧螺栓在正常使用中不属于典型的易损件，更多是长期承载后可能疲劳或拆卸损伤，标注为易损件可能造成过度预防性更换。
  - 建议: 建议将拉紧螺栓的“易损标识”改为“否”，或在备注中说明其仅在检查发现异常时才更换。
- **Kimi 单方** 泵盖连接螺栓、联轴器螺栓组件、中间筒、级间轴套、弹簧、平衡管、冲洗管、截止阀 — 零件聚焦易损件原则: 零件层充斥大量标记为不易损（否）的标准紧固件、结构件或低值通用件（如泵盖连接螺栓、联轴器螺栓、中间筒、级间轴套、机械密封弹簧、平衡管、冲洗管、截止阀等），严重违背零件层“聚焦易损/可更换/关键失效件”的层级语义，导致故障知识检索噪声大、精准度下降。
  - 建议: 统一清理：删除所有易损标识为“否”且无独立关键失效模式/无独立运维价值的零件条目，将其并入所属部件的描述或维护方法中；零件层仅保留易损件（是）或虽不易损但属于关键昂贵功能件（如推力盘）的条目。
- **Kimi 单方** 油冷却器 — 粒度一致性: 轴封子系统中“密封冷却器”为独立部件，而支撑子系统中“油冷却器”却作为“油润滑系统”的零件，同级换热器单元粒度严重不一致，破坏结构扁平化检索规则。
  - 建议: 统一提升为部件：将“油冷却器”从“油润滑系统”零件提升为支撑与轴承系统下的独立部件“油冷却器”，与“密封冷却器”同级；原“油润滑系统”保留油箱、油泵、滤网等。
- **Kimi 单方** 拉紧螺栓 — 归属合理性: 拉紧螺栓（穿杠）贯穿各级中段泵壳，属于跨级整体连接件，并非单个“中段泵壳”的专属零件，挂在中段泵壳下导致父部件边界模糊；且中段泵壳为多件重复件，拉紧螺栓独立失效和维护。
  - 建议: 将“拉紧螺栓”从“中段泵壳”零件中移除，在“增压级组”下升格为独立部件“级间拉紧装置（穿杠组）”，作为可整体更换的受力单元，并挂载相应的维护与报废方法。
- **Kimi 单方** 整体结构 — 功能完备性: 缺少“底座/泵座与安装支撑”子系统。立式筒袋泵（VS6）的泵座/底座（含电机支座、对中调整垫片等）是连接外筒袋、轴承箱与混凝土基础的关键承载结构，承担整机静载、动载及弯矩传递，缺失导致支撑功能链不完整。
  - 建议: 新增子系统“底座与安装支撑”，下设部件“泵底座/安装板”“电机支座”“对中调整垫片组”等，覆盖安装、对中、承载及基础连接功能。
- **Kimi 单方** 密封腔盖/压盖 — 功能完备性: 轴封系统缺少“密封腔盖（密封压盖/静环座）”部件。该部件是安装机械密封静环、形成密封腔、连接轴封冲洗管线的关键静子件，属于独立可更换总成，缺失导致轴封功能链断裂。
  - 建议: 在轴封系统下新增部件“密封腔盖/压盖”，描述其承压、安装静环及形成液膜腔功能，并下设零件如“静环座”“压盖垫片”等。
- **Kimi 单方** 锁紧装置 — 拆解充分性: 锁紧装置作为部件，其描述明确包含圆螺母与止动垫圈，但零件层完全未展开；而止动垫圈为典型一次性易损件，缺失导致无法精准定位失效和维护对象。
  - 建议: 在“锁紧装置”下新增零件“止动垫圈”（易损标识：是）、“圆螺母”（易损标识：否但关键），与部件描述保持一致。
- **Kimi 单方** 冷却水管路 — 拆解充分性: 冷却水管路作为部件无下属零件，而同子系统“油润滑系统”有下属零件；同时与轴封系统的“冲洗冷却管线”（有零件）粒度不一致，且管路系统中通常包含软管、接头密封垫等易损件。
  - 建议: 补充零件层：至少增加“软管/波纹管”（易损）和“管路密封垫”（易损）；或将“冷却水管路”并入“油润滑系统”作为其子部件以统一粒度。
- **Kimi 单方** 导叶 — 边界清晰: “导叶”作为通用多级部件，其零件“防冲导流板”通常仅首级导叶配置，作为所有导叶的公共零件存在边界歧义，易误导非首级导叶的维护检索。
  - 建议: 将“防冲导流板”从“导叶”零件中移除，作为“首级吸入段”或独立的“首级导叶”部件下的零件，以明确仅首级具备该结构。
- **Kimi 单方** 径向轴承支架 — 粒度一致性: 径向轴承支架与轴承箱在功能上存在重叠与边界模糊。立式筒袋泵的径向轴承通常直接集成于轴承箱或泵盖内，单独拆分“径向轴承支架”可能导致层级过细且与“轴承箱”承载边界不清。
  - 建议: 复核工程实际：若径向轴承支架为轴承箱的延伸或集成结构，建议将其降级为“轴承箱”的零件；若确为独立外接支撑筒体，保留但需在描述中明确与轴承箱的力学分界及定位关系。

### 待新增条目

- 新增 `下部导轴承（介质润滑滑动轴承）` → 支撑与轴承系统（原因: 立式筒袋泵通常在下端（吸入侧）设有介质润滑的滑动轴承（如赛龙轴承），为细长转子提供径向支撑，防止轴系振动，是保障转子稳定运行的关键部件。现有结构中仅提及“径向滑动轴承”，未明确覆盖这一底部导轴承，构成功能缺失。）
- 新增 `底座与安装支撑` → 立式筒袋泵（原因: 立式筒袋泵需泵座/底座连接外筒袋与基础，承担整机重量、弯矩及振动传递，是独立功能链和可维护单元。）
- 新增 `密封腔盖/压盖` → 轴封系统（原因: 安装机械密封静环、形成密封腔的关键静子部件，可独立拆装更换，是轴封功能链的必要组成。）
- 新增 `油冷却器` → 支撑与轴承系统（原因: 当前作为零件挂在油润滑系统下，应提升为独立部件以与密封冷却器保持粒度一致，且属于可独立更换的热交换总成。）
- 新增 `轴承端盖/压盖` → 支撑与轴承系统（原因: 轴承箱的轴向定位与密封件，防止润滑油泄漏和轴承外移，属于独立可更换部件，缺失导致轴承系统功能不完整。）
- 新增 `止动垫圈` → 锁紧装置（原因: 锁紧装置描述中明确包含的一次性易损件，应作为零件展开以支持精准维护与更换。）
- 新增 `推力轴承调整垫片` → 推力轴承（原因: 调整推力间隙/游隙的关键可更换零件，直接影响轴承安装精度与寿命，属于支撑系统的关键维护件。）

### 待移除条目

- 移除 `泵盖连接螺栓`（原因: 标准紧固件，标记不易损，无独立失效模式与独立运维意义，不应在零件层单独存在，建议仅在泵盖部件描述中体现。）
- 移除 `联轴器螺栓组件`（原因: 虽为受力件，但标记不易损，通常随联轴器套件整体更换或按标准件管理，单独列零件增加检索噪声。）
- 移除 `中间筒`（原因: 标记不易损，属于联轴器的结构性延伸件，无独立维护报废意义，建议合并至联轴器部件描述。）
- 移除 `级间轴套`（原因: 标记不易损，属于轴套的保护性/定位性结构，通常随轴套或主轴整体维护，独立列零件意义不大。）
- 移除 `弹簧（机械密封）`（原因: 机械密封弹簧通常随密封总成整体更换，不单独维护，在零件层冗余。）
- 移除 `平衡管`（原因: 标记不易损，为平衡管线总成的普通连接管段，无独立更换价值，应在部件描述中说明材质规格即可。）
- 移除 `冲洗管`（原因: 标记不易损，属于冲洗冷却管路的普通连接管，冗余，应在管线部件描述中体现。）
- 移除 `截止阀`（原因: 标记不易损，作为管路附件且非易损件，列零件层冗余；如需保留应升格为独立部件“管路阀组”。）
