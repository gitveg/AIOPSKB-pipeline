### 2.3 遗漏项

- **支撑与防护系统**（DeepSeek）: 当前“公共底座”和“联轴器护罩”被归入“驱动系统”，功能上不匹配。缺少一个系统来承载所有安装、支撑和对中保障的功能。该系统应包括公共底座、联轴器护罩、地脚螺栓组等。这有利于理清责任和故障分析（例如，基础沉降导致的对中问题应归属此系统）。
- **进口滤网**（DeepSeek）: 卧式离心泵，尤其是水泥行业的工艺水泵，入口通常配置Y型或篮式滤网，防止焊渣、结块等杂物进入泵体损坏叶轮。这是保护泵体及水力系统的第一道防线，是标准的可维护部件，其堵塞是常见故障。当前结构遗漏了此部件。
- **振动开关/变送器一体单元**（DeepSeek）: 除了‘振动监测组件’用于4-20mA信号输出，水泥厂中为简化控制，常采用一体化的振动开关用于紧急停机保护。或者，如果认为振动监测组件已覆盖，但描述中未明确其兼具开关量功能，这是一个可能的遗漏点。
- **电机接线端子/接线盒**（DeepSeek）: 是电机电气连接的关键点，接线端子松动、氧化、绝缘损坏是电机无法启动或缺相运行的常见失效原因，属于需要检查和独立更换的易损/关键件。
- **排气阀座/丝堵**（DeepSeek）: 泵壳顶部或高点处的排气孔及丝堵/管线接口，虽小，但缺失会导致无法灌泵排气，是启泵操作和维护中必须检查的功能点。
- **螺杆转子（或齿轮副）**（Kimi）: 辅助油泵通常为螺杆泵或齿轮泵，需拆分出做功转子/齿轮以与主润滑油泵保持粒度一致，支持故障精准定位
- **机械密封/轴封**（Kimi）: 辅助油泵作为旋转机械，轴封是常见泄漏点，需作为易损零件列出
- **降压节流套（平衡套）**（Kimi）: 部件描述已包含，且该套筒磨损直接影响平衡力建立与轴向窜动，是关键易损件
- **电磁线圈**（Kimi）: 停机电磁阀作为关键安全执行器，线圈烧毁是独立失效模式，拆分后可精准定位故障
- **阀芯/阀杆组件**（Kimi）: 阀芯卡涩、密封面磨损是电磁阀常见失效模式，需作为独立零件支持故障知识组织
- **微动开关/弹性sensing元件**（Kimi）: 压力开关的核心失效件为微动开关触点或弹性元件，拆分有助于故障知识组织
- **再循环管路（含弯头、法兰、支架）**（Kimi）: 与润滑系统下“冷却水管路”对应，若管路属成套供货，应统一粒度；若不属，则冷却水管路亦不应单列

### 2.4 冗余项

- **拉杆**（DeepSeek）: 在零件层应聚焦于易损件和关键失效件。“拉杆”属于结构性支撑件，非易损，其失效模式（如松动）通常通过定检可以发现，但极少需要作为备件储备，建议移除，或将其置于部件描述中说明。
- **水封环**（DeepSeek）: “水封环”是填料函中的一个功能结构件，通常非易损。虽然它对于液封功能至关重要，但除非破损（罕见），否则不参与周期性更换。其功能比它作为“可更换件”的意义更大。若零件层的重点是“备品备件管理”，水封环通常不作为常备件，可以考虑移除。如果保留，则无大碍，但略显琐碎。

### 待裁定分歧

- **DeepSeek 单方** 驱动系统 — 划分逻辑一致: 子系统划分逻辑不统一。大部分子系统按功能划分（如密封、润滑），但在“驱动系统”中混入了“公共底座”和“联轴器护罩”这类功能上属于“支撑/防护”的部件，而不是“提供旋转机械能”的动力源功能，导致边界模糊，功能不单一。
  - 建议: 建议将“公共底座”和“联轴器护罩”从“驱动系统”中移出，可考虑新增“支撑与防护系统”子系统，或将其归入更通用的“结构支撑”子系统，以确保“驱动系统”纯粹涵盖能量转换与传递的功能链（电机、齿轮箱、联轴器）。
- **DeepSeek 单方** 主电动机 — 拆解充分性: “主电动机”作为一个庞大的总成，仅拆解了两个轴承零件，拆解粒度严重不足。电机还包括定子、转子、接线盒、冷却风扇等重要可维护/易损部件，当前的拆分无法支持故障诊断和备件管理。
  - 建议: 建议将“主电动机”下的零件进行必要扩充，至少应增加“电机定子绕组”、“电机转子”、“电机冷却风扇”等关键的可更换/易损件。虽然电机通常是整体更换，但其内部仍有独立的易损和可维护单元，需要被识别。
- **DeepSeek 单方** 膜片联轴器 — 拆解充分性: “膜片联轴器”下只拆解了“膜片组”一个零件，遗漏了“中间节”和“连接螺栓组”等关键的可更换零件。中间节长度影响对中，螺栓松动或断裂是常见失效模式。
  - 建议: 建议在“膜片联轴器”部件下，增加“中间节”和“连接螺栓组”作为零件，这些是独立可更换的标准件，属于易损件范畴。
- **DeepSeek 单方** 平衡装置 — 拆解充分性: “平衡装置”部件本身的描述中提到了‘降压节流套’，但该结构在零件列表中被遗漏。节流套（或衬套）是与平衡盘/板配合的关键间隙件，其磨损直接影响平衡效果，属于核心易损件。
  - 建议: 建议在“平衡装置”部件下，增加“节流套”或“平衡衬套”作为零件，以确保易损件清单的完整性。
- **DeepSeek 单方** 锁紧螺母 — 归属正确: “锁紧螺母”挂在“泵轴”部件下，但其功能描述是‘轴向固定叶轮、轴套及推力盘’。从功能归属和工程实践看，锁紧螺母在解体时通常随叶轮或轴套一同拆下，也可以考虑作为叶轮或转子组件的零件。虽然逻辑上说得通，但更常见的BOM结构中，它常与所固定的零件（如叶轮）关联。当前归属不算错误，但值得商榷。
  - 建议: 建议维持现状，但确认在维护规程中应明确检查和更换锁紧螺母的场景，通常建议每次拆卸都更换，属于一次性易损件。
- **DeepSeek 单方** 机械密封 — 维护/报废挂载合理性: “机械密封”部件本身被标记为“是”（易损），这在逻辑上是正确的。但其维护和报废方法直接写在部件层，内容又是针对内部零件的。正确的粒度应该是：维护和报废方法挂在部件层，描述是针对整个总成的（如更换整个集装式机封），而零件的失效模式（如静环磨损）则挂在零件层。当前写法混在了一层。但本结构规定维护/报废方法挂在部件层，所以这里没问题。然而，存在一个致命问题：‘机械密封’作为一个整体被标记为易损件是对的，但描述中写到‘更换损坏组件后需重新进行静压试验’，暗示它不是整体报废，而是可修复的。如果它是可修复的，那么它的正确层级应该是子系统，而不是部件。这造成了严重的粒度不一致。
  - 建议: 明确处理方式：1) 如果“机械密封”是按整体更换管理的集装式机封，则部件报废方法应明确为‘整体更换，无修复价值’。零件层仅提供故障分析用。2) 如果它是可修复的（如分体式机封），则应将其提升为“密封系统”下的一个更细的子系统，然后将静环、动环等作为部件。根据描述，建议按方案1处理，保持为部件，但修改报废方法，强调整体更换。
- **DeepSeek 单方** 填料函 — 拆解充分性: “填料函”部件下，虽然列出了“填料”、“填料压盖”、“水封环”，但“轴套”是填料函密封系统中必不可少的组成部分。填料是压在轴套上实现密封的，轴套的磨损是导致填料密封失效的主要原因之一。当前“轴套”作为零件挂载在“泵轴”下，在“填料函”部件下没有体现其关联，这会在进行填料函故障分析时遗漏关键点。
  - 建议: 无需修改结构树位置，只需在“填料函”部件描述中强调其性能高度依赖于“泵轴-轴套”的表面状态。或者，也可考虑将“轴套”在填料函下复制引用，但鉴于结构规定，当前归属可接受，但需留意其维护关联性。
- **DeepSeek 单方** 最小流量再循环阀 — 功能完备性: “最小流量再循环阀”部件下缺少关键的附件——“阀杆”。阀杆是传递执行机构作用力、带动阀芯运动的关键承力运动件，频繁发生的阀杆卡涩、断裂是核心失效模式，属于关键零件。
  - 建议: 建议在“最小流量再循环阀”部件下，增加“阀杆”作为零件。
- **DeepSeek 单方** 拉杆 — 聚焦易损/可更换件: “膨胀节”下的“拉杆”被标记为“否”（非易损），这没问题。但从聚焦易损件角度看，它作为一个非易损的结构件被单独列出，价值不高。真正需要在膨胀节上关注的易损件是“波纹管”和“内衬导流筒”。
  - 建议: 建议移除“拉杆”，并考虑增加“内衬导流筒”作为零件。导流筒的焊口开裂、冲蚀减薄是限制膨胀节寿命的关键，是重要的可更换件。
- **DeepSeek 单方** 排污阀 — 聚焦易损/可更换件: “润滑油箱”下的“排污阀”被标记为非易损件。然而，阀门是独立的可更换总成，其阀芯密封面在长期使用中可能磨损导致内漏，属于有运维意义的可更换件。将其作为非易损件列出，粒度与其他如“油位计”等非易损件一致，逻辑合理。但“排污阀”本身就是一个阀门总成，包含阀体、阀芯、密封圈等，将其作为“零件”可能粒度略粗。
  - 建议: 当前粒度可接受。若要精益求精，可将“排污阀”视为一个独立部件，挂载在“润滑与冷却系统”下，但目前作为润滑油箱的附件，也属常见。维持现状即可。
- **Kimi 单方** 整体结构树 — 功能完备性与对象一致性: 评审主题与内容对象严重不一致：讨论主题写为“立式筒袋泵”，但待审数据全部内容实际为“卧式离心泵”的结构，二者在转子支撑方式（立式悬吊/卧式筒体）、电机布置、底座形式等核心结构上完全不同，导致知识树对象完全错位
  - 建议: 将主题统一修正为“卧式离心泵”；若确需构建立式筒袋泵结构树，则需按立式泵真实特征重新划分子系统（如增加泵座、水下轴承、筒体、推力轴承组件等）
- **Kimi 单方** 辅助油泵 — 粒度一致性: 辅助油泵作为总成部件未拆分至关键零件（如螺杆/齿轮、轴承、轴封），而同子系统下的主润滑油泵已拆分至驱动齿轮/从动齿轮/轴承级，同级部件粒度严重不一致，无法在知识库中精准定位辅助油泵的失效模式
  - 建议: 将辅助油泵拆分为螺杆（或齿轮副）、轴承、机械密封/轴封等关键易损零件，或与主润滑油泵统一拆分深度
- **Kimi 单方** 停机电磁阀/压力开关/流量变送器 — 粒度一致性: 仪表控制系统中多个集成仪表与执行器未拆分（停机电磁阀、压力开关、流量变送器、转速探头），而同子系统下的振动监测组件、温度监测组件、控制柜已拆分至探头/电缆/模块级，粒度不一致，降低故障检索精度
  - 建议: 对停机电磁阀补充阀芯、线圈；对压力开关补充微动开关/弹性元件；对流量/压力变送器补充传感器膜片或电子单元等关键模块，统一拆分深度
- **Kimi 单方** 冷却水管路及补偿器 — 粒度一致性: 润滑与冷却系统中单列了“冷却水管路及补偿器”部件，但辅助工艺管路系统中的再循环、暖泵、排空等仅有阀门与滤网而无管路本体部件，管路级粒度不统一，破坏结构对称性，且冷却水管路与密封系统、润滑系统的边界模糊
  - 建议: 要么在辅助工艺管路系统下补充“再循环管路”“暖泵管路”“排空管路”等管路部件（含波纹管/补偿器零件），要么将冷却水管路及补偿器拆散归入冷油器与密封冲洗冷却器，不作为独立管路部件
- **Kimi 单方** 平衡装置-降压节流套 — 关键失效覆盖: 平衡装置部件描述明确包含“相应的降压节流套”，但零件层仅列出平衡盘与平衡板，遗漏该关键节流元件；降压节流套（或平衡套）磨损/冲蚀会直接导致平衡腔压力失控与轴向力失衡，是常见失效源
  - 建议: 在平衡装置部件下补充零件“降压节流套/平衡套”，并标识为易损件
- **Kimi 单方** 排空阀-阀球 — 归属正确性: 部件“排空阀”描述为“手动针型或球阀”，但零件仅列“阀球”；若实际配置为针型阀，则不存在阀球，零件与部件描述不匹配，导致结构错误
  - 建议: 将零件名修改为“阀芯（阀球/阀针）”以兼容两种阀型，或按实际供货配置细化部件描述
- **Kimi 单方** 节流孔板 — 易损标识合理性: 部件描述明确指出“孔板孔径因冲蚀扩大至设计极限值以上”是其典型报废原因，但易损标识为“否”；冲蚀是该零件的核心时效模式，应属易损件
  - 建议: 将节流孔板的易损标识由“否”修正为“是”

### 待新增条目

- 新增 `支撑与防护系统` → 卧式离心泵（原因: 当前“公共底座”和“联轴器护罩”被归入“驱动系统”，功能上不匹配。缺少一个系统来承载所有安装、支撑和对中保障的功能。该系统应包括公共底座、联轴器护罩、地脚螺栓组等。这有利于理清责任和故障分析（例如，基础沉降导致的对中问题应归属此系统）。）
- 新增 `进口滤网` → 泵体及水力系统（原因: 卧式离心泵，尤其是水泥行业的工艺水泵，入口通常配置Y型或篮式滤网，防止焊渣、结块等杂物进入泵体损坏叶轮。这是保护泵体及水力系统的第一道防线，是标准的可维护部件，其堵塞是常见故障。当前结构遗漏了此部件。）
- 新增 `振动开关/变送器一体单元` → 仪表控制系统（原因: 除了‘振动监测组件’用于4-20mA信号输出，水泥厂中为简化控制，常采用一体化的振动开关用于紧急停机保护。或者，如果认为振动监测组件已覆盖，但描述中未明确其兼具开关量功能，这是一个可能的遗漏点。）
- 新增 `电机接线端子/接线盒` → 主电动机（原因: 是电机电气连接的关键点，接线端子松动、氧化、绝缘损坏是电机无法启动或缺相运行的常见失效原因，属于需要检查和独立更换的易损/关键件。）
- 新增 `排气阀座/丝堵` → 泵壳体（原因: 泵壳顶部或高点处的排气孔及丝堵/管线接口，虽小，但缺失会导致无法灌泵排气，是启泵操作和维护中必须检查的功能点。）
- 新增 `螺杆转子（或齿轮副）` → 辅助油泵（原因: 辅助油泵通常为螺杆泵或齿轮泵，需拆分出做功转子/齿轮以与主润滑油泵保持粒度一致，支持故障精准定位）
- 新增 `机械密封/轴封` → 辅助油泵（原因: 辅助油泵作为旋转机械，轴封是常见泄漏点，需作为易损零件列出）
- 新增 `降压节流套（平衡套）` → 平衡装置（原因: 部件描述已包含，且该套筒磨损直接影响平衡力建立与轴向窜动，是关键易损件）
- 新增 `电磁线圈` → 停机电磁阀（原因: 停机电磁阀作为关键安全执行器，线圈烧毁是独立失效模式，拆分后可精准定位故障）
- 新增 `阀芯/阀杆组件` → 停机电磁阀（原因: 阀芯卡涩、密封面磨损是电磁阀常见失效模式，需作为独立零件支持故障知识组织）
- 新增 `微动开关/弹性sensing元件` → 压力开关（原因: 压力开关的核心失效件为微动开关触点或弹性元件，拆分有助于故障知识组织）
- 新增 `再循环管路（含弯头、法兰、支架）` → 辅助工艺管路系统（原因: 与润滑系统下“冷却水管路”对应，若管路属成套供货，应统一粒度；若不属，则冷却水管路亦不应单列）

### 待移除条目

- 移除 `拉杆`（原因: 在零件层应聚焦于易损件和关键失效件。“拉杆”属于结构性支撑件，非易损，其失效模式（如松动）通常通过定检可以发现，但极少需要作为备件储备，建议移除，或将其置于部件描述中说明。）
- 移除 `水封环`（原因: “水封环”是填料函中的一个功能结构件，通常非易损。虽然它对于液封功能至关重要，但除非破损（罕见），否则不参与周期性更换。其功能比它作为“可更换件”的意义更大。若零件层的重点是“备品备件管理”，水封环通常不作为常备件，可以考虑移除。如果保留，则无大碍，但略显琐碎。）
