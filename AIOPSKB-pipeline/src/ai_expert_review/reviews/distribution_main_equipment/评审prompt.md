# 配电子行业设备分类评审

> 请你作为电力行业设备分类专家，审查以下配电子行业的设备清单，重点评审**主设备**的分类是否合理。

## 背景

我们正在构建工业设备智能运维知识库，结构为"行业→子行业→设备→部件→故障"。每个子行业需要将设备分为三类：
- **主设备**：核心能量转换/传输设备，独立采购、独立检修班组、独立KKS编码
- **辅助设备**：支持主设备运行的设备
- **公用系统**：全厂共用、服务多台设备的基础设施

### 已确立的方法论

1. **L1 核心能量转换设备**：直接完成能源形态转换
2. **L2 主工艺链关键节点设备**：不可绕过的关键节点，独立性强、投资大、停机影响全局
3. **"全场公用"降级规则**：全场共用设备降级为公用系统
4. **"依附性"降级规则**：功能依附于主设备的控制系统归辅助设备
5. **"粒度合并"规则**：不同材质/型号的同功能设备合并为1项，在部件层区分

### 跨行业先例（输电+变电评审结论）

- 变电变压器：合并主变+联络变为1项"变压器"
- 变电断路器：合并SF6+真空为1项"断路器"
- 变电互感器：合并CT+PT+CVT为1项"互感器"
- 变电继电保护：降级辅助（所有子行业一致）
- 变电避雷器：降级辅助
- 变电SVC/SVG：降级辅助（电能质量治理）
- 输电导线：合并5种为1项
- 输电电缆附件：保留主设备（终端头、中间接头）

## 评审要求

### 1. 主设备分类审查

当前14项主设备，请逐一审查。特别关注：
- 哪些应保留？理由？
- 哪些应降级？理由？

### 2. 变压器粒度

4种配电变压器（柱上/箱式/配电室/地下）是否应合并为1项"配电变压器"？参照变电合并主变+联络变的先例。

### 3. 开关柜粒度

环网柜、中压断路器柜、负荷开关柜是否应合并？还是作为不同功能设备分别保留？柱上开关是否应与上述开关柜合并？

### 4. 低压设备的分类

低压开关柜、配电箱、低压断路器被列为主设备。这些是配电末端设备，在变电中没有将低压开关柜列为主设备。请评估：
- 低压开关柜和配电箱是否应降级为辅助设备？
- 低压断路器作为保护控制元件，是否适用"依附性"降级？

### 5. 线路的分类

架空配电线路和电缆配电线路被列为主设备。参照输电导线和电力电缆的先例（保留主设备），配电线路是否应同样保留？电缆分支箱与输电电缆终端/中间头的关系？

### 6. 与变电/输电的一致性

- 互感器（已辅助）和避雷器（已辅助）是否与变电一致？
- 继电保护（已辅助）是否一致？

请给出明确的最终主设备清单。
