### 2.3 遗漏项

- **润滑油蓄能器**（DeepSeek）: 高速泵在停机过程中极易因润滑油泵停转导致高速轴轴承干摩擦烧毁，通常都必须配置润滑油蓄能器（皮囊式或活塞式）在停机瞬间提供短时的保压润滑油，它是保障核心轴承安全的关键独立部件。
- **密封冲洗隔离阀组**（DeepSeek）: 对于配备 API Plan 52/53 冲洗方案的机械密封，现场需配置双截断排放阀组或三通切换阀，以保证在运行状态下能安全地切换、更换或隔离冲洗液罐及过滤器，是关键的维护通道部件。
- **承压壳体/泵壳**（Kimi）: 高速泵的承压壳体是独立承压边界，需挂载壳体裂纹、腐蚀、冲蚀、壁厚减薄等故障，当前仅列蜗壳无法覆盖承压壳体失效。
- **径向轴承总成**（Kimi）: 轴承是独立于主轴的失效/维护单元，当前被错误地挂在主轴部件下，作为独立总成在结构中实际缺失。
- **推力轴承总成**（Kimi）: 同上，推力轴承应作为独立部件，与主轴分开，以便于按独立失效单元组织故障知识。
- **轮毂/半联轴器**（Kimi）: 联轴器与电动机轴和齿轮箱轴连接的关键零件，存在磨损、裂纹等独立失效模式，且可独立更换。
- **轴承端盖**（Kimi）: 齿轮箱轴承端盖是常见可更换零件，涉及密封失效和润滑油泄漏，应作为零件列出。

### 待裁定分歧

- **DeepSeek 单方** 转子与支承系统 — 粒度一致性: 该子系统仅有“主轴”1个部件，而其他子系统平均包含3-10个部件，粒度显著过粗。齿轮箱和密封系统都拆到了独立总成，但转子系统却将轴和所有轴承混为一个部件，不符合部件粒度一致性与可独立维护性要求。
  - 建议: 建议将“主轴”拆解为“主轴组件”、“径向轴承总成”、“推力轴承总成”和“轴套/密封轴套”等多个独立部件，以匹配其他子系统的部件粒度与可更换单元定义。
- **DeepSeek 单方** 主轴 — 拆解充分性: 目前的“主轴”部件混合了主轴本体、径向瓦块、推力瓦块、衬套、推力盘、锁紧螺母等多个独立的可更换总成。这完全不符合“部件应拆解到独立失效/可独立更换的检修单元”的评审标准，在实际检修中不会将轴和瓦块同时更换。
  - 建议: 建议将其拆解为：1）“主轴组件”（带推力盘、主轴键和锁紧螺母）；2）“径向轴承”（包含衬套和瓦块）；3）“推力轴承”（包含推力瓦块）；4）“轴套”。将相应的零件重新挂载到拆分后的部件下。
- **DeepSeek 单方** 仪表与监测元件 — 粒度一致性: 润滑部分的“仪表与监测元件”作为一个总成部件，其下列出了供油压力表、油流视镜等独立可更换件。这与“机组监控与保护系统”将各类传感器、变送器直接作为独立部件的划分逻辑不一致，导致跨子系统的部件粒度不平衡。
  - 建议: 为保持全树结构一致性，建议将“供油压力表”和“油流视镜”从零件层提升到“润滑与冷却系统”的独立部件层，与监控系统的仪表粒度相统一；或者在其所属的部件（如供油管路）下作为一种特定功能的零件挂载。
- **DeepSeek 单方** 密封冲洗液罐 — 关键失效覆盖: API Plan 52/53 密封冲洗液罐除了液位计和压力释放装置外，通常必设压力变送器或压力开关以实现密封腔压力超高/低报警及联锁保护，且报废方法中提到了“压力释放件失效”，但零件层中未将“爆破片/安全阀”列为关键易损件。
  - 建议: 建议在“密封冲洗液罐”下至少补充“爆破片/安全阀”为易损零件。如果实际配置了压力保护仪表，也需补充“压力变送器”或“压力开关”。
- **Kimi 单方** 主轴 — 失效独立性/归属合理性: 主轴部件下挂载了径向轴承瓦块、推力轴承瓦块、径向轴承衬套，这些属于轴承总成而非主轴转子。轴承是独立于主轴的失效/维护单元，其失效模式、检修策略与主轴完全不同。当前归属导致故障知识无法按独立维护单元精准检索，且破坏了“部件按总成分”的层级语义。
  - 建议: 将转子与支承系统拆分为“转子部件”（主轴、推力盘、轴套、锁紧螺母、主轴键）和“轴承部件”（径向轴承总成、推力轴承总成），轴承总成下再挂瓦块、衬套等零件。
- **Kimi 单方** 过流增压系统 — 功能完备性: 缺少承压壳体（泵壳/壳体）部件。对于高速泵，承压壳体是独立的承压边界和关键过流部件，其腐蚀、冲蚀、裂纹等故障无法挂载。当前仅有蜗壳及壳体口环，但蜗壳往往只是壳体内的衬套或流道组件，不能替代壳体本体的故障知识。
  - 建议: 在过流增压系统下增加“承压壳体/泵壳”部件，涵盖进口段、出口段、筒体等承压边界；将原壳体口环视结构关系调整至该部件或蜗壳部件下。
- **Kimi 单方** 联轴器 — 拆解充分性: 联轴器部件缺少轮毂（或半联轴器/法兰盘）零件。轮毂是与电动机轴和齿轮箱轴连接的关键零件，存在磨损、裂纹等独立失效模式，且可独立更换。缺少该零件导致联轴器与轴配合处的故障无法精准定位。
  - 建议: 在联轴器部件下增加“轮毂/法兰盘”零件，描述其与轴的配合及膜片连接关系。
- **Kimi 单方** 弹性元件(弹簧) — 易损标识合理性: 机械密封的弹性元件（弹簧或波纹管）是机械密封的核心易损件，长期运行后会发生疲劳、应力松弛，导致密封比压不足而泄漏。当前标识为“否”不合理。
  - 建议: 将弹性元件(弹簧)的易损标识改为“是”。
- **Kimi 单方** 测速齿轮 — 归属合理性/失效独立性: 测速齿轮物理安装在高速轴端，随转子旋转，属于转子本体的一部分。其失效模式（齿面磨损、断齿）属于转子机械故障，而非监控系统电子故障。当前挂在监控系统下导致转子故障知识分散，且其维护（紧固锁紧螺钉）通常在转子检修时进行。
  - 建议: 将测速齿轮移至“转子与支承系统”下作为部件（或主轴部件下的零件），在监控系统中保留“转速传感器”部件与之配合。
- **Kimi 单方** 增速齿轮箱 — 拆解充分性/粒度一致性: 增速齿轮箱作为部件，其零件仅列出轴和轴承，缺少齿轮啮合副中的关键零件“齿轮”（若采用套装齿轮结构时）以及箱体关键密封件（如轴承端盖、密封件）。虽然齿轮轴一体化时无需单独列出齿轮，但结构说明中“齿轮副”的故障无法精准定位到齿轮本体。
  - 建议: 若齿轮与轴为分体式，增加“大齿轮”零件；或明确为齿轮轴一体化。同时增加“轴承端盖/密封”等可独立更换的易损零件。
- **Kimi 单方** 轴端密封系统 — 粒度一致性: 轴端密封系统包含了泵本体密封部件（机械密封、压盖、腔体、节流衬套）和外部辅助设备（冲洗液罐、换热器、过滤器），跨度较大。冲洗辅助系统与本体密封件在维护策略、故障模式上差异显著，全部挤在一个子系统下导致该子系统过于庞大。
  - 建议: 建议将密封冲洗过滤器、液罐、换热器独立为“密封辅助系统”子系统；或在轴端密封系统下明确区分“本体密封组件”和“密封冲洗辅助组件”两组部件，保持同级子系统粒度相当。
