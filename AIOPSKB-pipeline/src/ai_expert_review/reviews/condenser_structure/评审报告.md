### 2.3 遗漏项

- **热井**（DeepSeek）: 凝结水最终汇集的空间，包含壳体底部、防腐衬里、液位接口等，是凝汽器的关键结构，必须有独立的部件进行维护管理。
- **除氧装置**（DeepSeek）: 凝汽器通常内置除氧装置（如淋水盘、鼓泡除氧等）以降低凝结水溶解氧，是重要的腐蚀控制措施，应作为可维护单元列出。
- **防腐衬里/涂层**（DeepSeek）: 热井内壁需防腐，与进出水室类似，应有此易损件。
- **液位计接口/液位计**（DeepSeek）: 监控热井水位，保护凝结水泵，属于关键仪表件。
- **空气冷却区挡板/空气抽出管（如归入壳体或管束则需明确）**（DeepSeek）: 虽然真空维持系统有导流挡板，但空气冷却区本身的管束布置和挡板是蒸汽冷凝系统的一部分。当前结构已由真空维持系统的气体导流挡板覆盖，但若物理上属于壳侧，需统一。
- **胶球清洗装置（收球网、收球阀等）**（DeepSeek）: 许多火电厂凝汽器自带胶球清洗管路和收球装置，属于本设备维护范围，如果缺失会影响在线清洗功能的完整性。请根据设备实际配置判断，若外部独立系统可不列入。
- **热井本体**（Kimi）: 热井是凝结水收集与暂存的核心容器，为凝结水泵提供吸入压头，是凝结水收集与除氧子系统存在的前提，必须作为独立部件挂载。
- **除氧元件（淋水盘/鼓泡管）**（Kimi）: 凝汽器热井通常设置淋水盘或鼓泡除氧装置以去除凝结水中溶解氧，防止腐蚀，属于该子系统核心功能件，缺失则除氧功能无法落地。
- **汽水分离器**（Kimi）: 当前被内含于水环式真空泵组中，但作为可独立维护更换的总成，应提升为独立部件以匹配粒度一致性要求。
- **工作液冷却器**（Kimi）: 水环真空泵系统必备的工作液冷却换热设备，为独立可维护总成，当前缺失导致真空泵组冷却功能知识无法挂载。
- **工作蒸汽阀组/隔离阀**（Kimi）: 射汽抽气器需工作蒸汽进口阀、级间隔离阀等阀门控制，为易损可更换件，缺失导致抽气器启停控制与隔离功能知识缺失。
- **空气冷却区管束模块**（Kimi）: 大型凝汽器通常设置独立的空气冷却区以冷却不凝结气体，其管束结构、布置与主凝结区不同，应作为独立部件以支撑差异化的失效模式与维护策略。

### 2.4 冗余项

- **凝结水收集与除氧子系统（当前为空壳）**（DeepSeek）: 如果无法补充有效内容，或可考虑将其合并回蒸汽冷凝子系统，将凝结水出口段和热井整合为蒸汽冷凝系统的底部结构，避免留空或造成虚假分层。但更推荐补充后保留。
- **管侧密封件（作为独立部件冗余）**（DeepSeek）: 它并非独立可更换总成，而是管束维护的附属工作，作为零件挂在管束或管板下更合理，避免将其提升为部件。

### 待裁定分歧

- **DeepSeek 单方** 蒸汽冷凝系统 — 划分逻辑一致: 蒸汽冷凝系统包含了凝结水出口段，而凝结水出口段通常属于凝结水收集与除氧子系统的物理部分，造成两个子系统功能重叠或边界模糊。按功能划分，蒸汽冷凝系统应侧重相变换热，凝结水收集与除氧侧重汇集、储水、除氧，凝结水出口段（集水槽及接管）实际是热井的一部分，应归入凝结水收集与除氧子系统。
  - 建议: 将凝结水出口段及其零件（滤网、防涡流装置、法兰垫片）移至凝结水收集与除氧子系统下，或将其重命名整合进热井。蒸汽冷凝系统保留至凝结水出口接口即可，避免跨系统重复。
- **DeepSeek 单方** 冷却水系统 — 功能完备性: 冷却水系统仅覆盖了水侧流道，但凝汽器冷却水还依赖反冲洗系统、胶球清洗系统等在线维护装置，这些通常被视为冷却水系统的附属功能模块，缺失可能影响可靠性和维护策略的完整性。如果将这些归入外部循环管路，需明确边界。
  - 建议: 建议明确冷却水系统的边界：若凝汽器本体的胶球清洗管路、反冲洗阀组属于本设备范围，则应增加相应部件（如胶球收集网、收球网、反冲洗阀）。至少在描述中说明外部循环管路接口的界限，或增加一个子系统'在线清洗系统'。
- **DeepSeek 单方** 蒸汽冷凝系统 / 真空维持系统 — 边界清晰: 蒸汽冷凝系统的管束描述中提到'空气冷却区'，而真空维持系统中包含'气体导流挡板'和'抽气口滤网'，实际上空气冷却区是管束布置的一部分（通常为管束末尾段），挡板也安装于壳侧，两者物理上交织，边界不够清晰。
  - 建议: 在蒸汽冷凝系统壳体内明确包含空气冷却区（可不单独拆件），真空维持系统只需从抽气口开始。当前将挡板和抽气口滤网划入真空维持系统符合功能逻辑，但需在描述中说明安装位置在凝汽器壳体内部，避免物理位置上的混淆。
- **DeepSeek 单方** 射汽抽气器 — 拆解充分性: 部件描述提及'两级结构，配备级间冷却器'，但零件仅列出了喷嘴、扩压管、级间冷却器，未包括二级的类似零件（第二级喷嘴、扩压管），若两级共用一个部件节点，零件列表不完整。如果两级独立，部件应拆为一级抽气器和二级抽气器。
  - 建议: 如果射汽抽气器作为一个整体部件，则需补充第二级喷嘴、第二级扩压管等零件；或者拆分为'一级射汽抽气器'和'二级射汽抽气器'两个部件，各自包含对应的喷嘴、扩压管，并共享级间冷却器或将其独立。
- **DeepSeek 单方** 抽气管道 — 维护/报废挂载合理性: 抽气管道部件下挂载了维护方法和报废方法，但该方法描述中混合了管道本体、膨胀节、阀门连接处的维护。膨胀节已作为零件列出，但维护方法未明确区分。
  - 建议: 将维护方法中针对膨胀节的内容间接挂载到膨胀节零件（或部件层保留整体描述，但需说明膨胀节单独维护），保证维护操作的针对性。
- **DeepSeek 单方** 管侧密封件 — 功能完备性: 该部件描述为涂覆密封胶或填充环氧树脂，属于施工工艺而非独立可更换的总成，但作为部件存在，且其维护方法'涂胶或注胶堵漏'更接近修复操作，不符合常规可更换部件定义。
  - 建议: 建议将其归类为管束或管板的零件，命名为'胀口密封胶/环氧封堵'，并将维护/报废描述挂载到管束部件层，作为管束泄漏处理的一部分。或者作为管束的一个维护项而非独立部件。
- **DeepSeek 单方** 凝结水出口段 - 防涡流装置 — 易损标识合理性: 防涡流装置标识为'否'，但在实践中，不锈钢十字板长期受水流冲刷可能产生疲劳断裂或腐蚀，有一定易损性，可根据实际运维数据评估。但当前标识合理。
  - 建议: 建议根据实际失效频率判定，如冲刷严重可标识为易损件。当前可保留。
- **DeepSeek 单方** 蒸汽进口段 - 导流板 — 归属正确: 蒸汽进口段描述及零件列表中提到了导流板（在描述中），但零件列表未单独列出导流板，而是列出了防冲板。实际上导流板与防冲板有时为同一装置，名称需统一。
  - 建议: 明确防冲板是否就是导流板，若不同，需补充导流板零件；若相同，则统一名称为'防冲/导流板'。
- **Kimi 单方** 蒸汽冷凝系统 / 凝结水收集与除氧子系统 — 边界清晰: 蒸汽冷凝系统已包含凝结水出口段（壳体底部集水槽及接管），而凝结水收集与除氧子系统又试图独立覆盖热井及集水功能，两者在物理空间与功能上高度重叠，边界划分模糊，易导致知识挂载冲突。
  - 建议: 重新定义边界：将壳体底部热井/集水槽及除氧元件整体划归凝结水收集与除氧子系统；蒸汽冷凝系统仅覆盖蒸汽进口至凝结水落至热井之前的冷凝空间，杜绝重复收纳。
- **Kimi 单方** 管板 — 失效独立性: 管板与凝汽器壳体通常为焊接一体结构，现场不具备整体拆卸更换条件，不属于可独立更换/检修的总成单元，作为部件挂载独立维护/报废方法缺乏工程可操作性。
  - 建议: 将管板降格为蒸汽冷凝系统-壳体部件下的一个关键零件；其维护/报废方法随壳体整体管理，或在壳体部件下增加管板专项维护条目。
- **Kimi 单方** 射汽抽气器 — 粒度一致性: 射汽抽气器作为总成部件，内部包含了级间冷却器这一完整壳管式换热器，却仅被列为其下的零件，粒度与同级部件不一致；且级间冷却器自身具备独立失效模式与维护需求。
  - 建议: 将级间冷却器提升为真空维持系统下的独立部件，按壳管式换热器结构进一步拆解管束、壳体等零件；射汽抽气器本身保留喷嘴、扩压管等内件。
- **Kimi 单方** 气体导流挡板 — 层级语义一致性: 气体导流挡板安装于凝汽器壳侧空气冷却区，属于凝汽器本体内部结构，按功能/能量流划分应归属于蒸汽冷凝系统的气流组织功能，现挂在真空维持系统下造成跨边界归属。
  - 建议: 将气体导流挡板调整至蒸汽冷凝系统子系统下，作为壳体或独立气流组织部件，或作为空气冷却区模块的组成部分。
- **Kimi 单方** 管侧密封件 — 失效独立性: 管侧密封件（密封胶/环氧树脂填充层）本质上是维护耗材与工艺措施，并非可独立更换的机械总成，其失效通常表现为管束-管板连接泄漏，难以作为独立单元进行更换或报废。
  - 建议: 取消管侧密封件作为独立部件，将其维护方法（涂胶、注胶）合并至管束或管板部件的维护条目中；若需保留，则降格为管束部件下的维护操作零件。
- **Kimi 单方** 支撑隔板 — 功能完备性/归属: 支撑隔板与管束存在紧密的结构与功能耦合（隔板管孔与管子配合），且通常随管束抽芯整体更换，作为与管束平级的独立部件可能导致故障关联检索时割裂。
  - 建议: 将支撑隔板调整为管束部件下的子部件或关键配套零件；若需保留为独立部件，应在描述中明确其与管束的耦合关系及协同报废条件。

### 待新增条目

- 新增 `热井` → 凝结水收集与除氧子系统（原因: 凝结水最终汇集的空间，包含壳体底部、防腐衬里、液位接口等，是凝汽器的关键结构，必须有独立的部件进行维护管理。）
- 新增 `除氧装置` → 凝结水收集与除氧子系统（原因: 凝汽器通常内置除氧装置（如淋水盘、鼓泡除氧等）以降低凝结水溶解氧，是重要的腐蚀控制措施，应作为可维护单元列出。）
- 新增 `防腐衬里/涂层` → 热井（原因: 热井内壁需防腐，与进出水室类似，应有此易损件。）
- 新增 `液位计接口/液位计` → 热井（原因: 监控热井水位，保护凝结水泵，属于关键仪表件。）
- 新增 `空气冷却区挡板/空气抽出管（如归入壳体或管束则需明确）` → 蒸汽冷凝系统（原因: 虽然真空维持系统有导流挡板，但空气冷却区本身的管束布置和挡板是蒸汽冷凝系统的一部分。当前结构已由真空维持系统的气体导流挡板覆盖，但若物理上属于壳侧，需统一。）
- 新增 `胶球清洗装置（收球网、收球阀等）` → 冷却水系统（原因: 许多火电厂凝汽器自带胶球清洗管路和收球装置，属于本设备维护范围，如果缺失会影响在线清洗功能的完整性。请根据设备实际配置判断，若外部独立系统可不列入。）
- 新增 `热井本体` → 凝结水收集与除氧子系统（原因: 热井是凝结水收集与暂存的核心容器，为凝结水泵提供吸入压头，是凝结水收集与除氧子系统存在的前提，必须作为独立部件挂载。）
- 新增 `除氧元件（淋水盘/鼓泡管）` → 凝结水收集与除氧子系统（原因: 凝汽器热井通常设置淋水盘或鼓泡除氧装置以去除凝结水中溶解氧，防止腐蚀，属于该子系统核心功能件，缺失则除氧功能无法落地。）
- 新增 `汽水分离器` → 真空维持系统（原因: 当前被内含于水环式真空泵组中，但作为可独立维护更换的总成，应提升为独立部件以匹配粒度一致性要求。）
- 新增 `工作液冷却器` → 真空维持系统（原因: 水环真空泵系统必备的工作液冷却换热设备，为独立可维护总成，当前缺失导致真空泵组冷却功能知识无法挂载。）
- 新增 `工作蒸汽阀组/隔离阀` → 射汽抽气器（原因: 射汽抽气器需工作蒸汽进口阀、级间隔离阀等阀门控制，为易损可更换件，缺失导致抽气器启停控制与隔离功能知识缺失。）
- 新增 `空气冷却区管束模块` → 蒸汽冷凝系统（原因: 大型凝汽器通常设置独立的空气冷却区以冷却不凝结气体，其管束结构、布置与主凝结区不同，应作为独立部件以支撑差异化的失效模式与维护策略。）

### 待移除条目

- 移除 `凝结水收集与除氧子系统（当前为空壳）`（原因: 如果无法补充有效内容，或可考虑将其合并回蒸汽冷凝子系统，将凝结水出口段和热井整合为蒸汽冷凝系统的底部结构，避免留空或造成虚假分层。但更推荐补充后保留。）
