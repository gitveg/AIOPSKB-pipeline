# 火电主设备分类评审报告

> 日期: 2026-05-13
> 评审方式: 三方商榷（Claude主智能体 + DeepSeek专家 + Kimi专家）
> 评审对象: 火电（thermal）子行业 equipment_registry.md 中的设备分类
> 关联文件: `src/data/power/thermal/equipment_registry.md`
> 关联先例: `src/docs/review_hydro_main_equipment/`（水电评审）

## 一、评审背景

水电子行业完成主设备分类评审后，对火电子行业进行同样的评审。火电当前有 **8项主设备、50项辅助设备、18项公用系统**，共74项。本轮评审将完整设备清单发给两位专家，确保评审在完整上下文下进行。

## 二、两位专家意见汇总

### 2.1 主设备部分

| 设备 | DeepSeek | Kimi | 共识 |
|------|---------|------|------|
| 锅炉 | 保留 | 保留 | **保留** |
| 汽轮机 | 保留 | 保留 | **保留** |
| 发电机 | 保留 | 保留 | **保留** |
| 主变压器 | 保留 | 保留 | **保留** |
| 凝汽器 | **降为辅助** | **保留为主设备** | **分歧** |
| 励磁系统 | **降为辅助** | **降为辅助** | **降为辅助** |
| 冷却塔/空冷岛 | 有条件保留，需拆分 | **降级并拆分** | **降为辅助** |
| 发电机断路器(GCB) | **新增为主设备** | **升级为主设备** | **新增为主设备** |

### 2.2 凝汽器的分歧

- **DeepSeek（降为辅助）**：凝汽器本质上是服务于汽轮机的"排气回收与真空维持系统"，故障通常不瞬间跳闸，处理可计划安排。把它和三大主机并列拔高了层级。
- **Kimi（保留为主设备）**：凝汽器是朗肯循环的必需冷源，决定循环热效率。类比水电进水阀——都不直接能量转换，但都是主工艺链关键节点。降级会导致冷端重大故障在知识库中层级下沉。

### 2.3 辅助设备部分

两位专家一致认为：**50项辅助设备中无应升级为主设备的**。

额外建议：
- **给水泵汽轮机(#12)** → 并入"汽动给水泵组"(两位均建议)
- **励磁变压器(#46)** → 并入"励磁系统"(两位均建议)
- **飞灰含碳在线检测装置(#49)** → 删除，粒度过低(Kimi建议)
- **高低压配电装置(#35)** → 拆出GCB后更名为"厂用配电装置"(两位均建议)
- **启动/备用变压器(#26)** → 移入公用系统(Kimi建议)
- **冷却塔/空冷岛** → 拆分为湿冷塔(公用系统) + 空冷岛(辅助设备)(两位均建议)
- **GIS** → 火电维持辅助设备，不与水电统一(两位一致：火电GIS是升压站，多机组公用)

## 三、最终裁定

### 3.1 裁定结果

**火电主设备调整为6项**：

| # | 设备名称 | 设备类型 | 核心理由 |
|---|---------|---------|---------|
| 1 | 锅炉 | 主设备 | 化学能→热能，三大主机之一 |
| 2 | 汽轮机 | 主设备 | 热能→机械能，三大主机之一 |
| 3 | 发电机 | 主设备 | 机械能→电能，三大主机之一 |
| 4 | 凝汽器 | 主设备 | 朗肯循环冷端关键节点，类比水电进水阀 |
| 5 | 主变压器 | 主设备 | 电能外送枢纽，电压等级转换核心 |
| 6 | 发电机出口断路器(GCB) | 主设备 | 主电气连接关键控制节点，水电先例一致 |

**从主设备中降级（2项）**：
- 励磁系统 → 辅助设备（依附于发电机，水电先例一致）
- 冷却塔/空冷岛 → 拆分降级（见下文）

### 3.2 凝汽器保留为主设备的理由

采纳Kimi的意见，理由：
1. 凝汽器与水电进水阀处于同等地位——都不直接能量转换，但都是主工艺链不可绕过的关键节点
2. 凝汽器故障虽不瞬间跳闸，但真空恶化会迅速迫使机组降负荷甚至停机，后果等同于主设备故障
3. 作为独立大型压力容器/换热器，投资高、故障诊断知识体系独立
4. 保持与水电评审逻辑的一致性：水电进水阀"破格保留"，火电凝汽器同理

### 3.3 冷却塔/空冷岛的处理

采纳两位专家拆分建议：
- **湿冷冷却塔** → 公用系统（全厂多机共用，与主工艺链隔有凝汽器和循环水泵）
- **空冷岛(ACC)** → 辅助设备（本质是凝汽器的空冷化延伸，投资大但不是独立能量转换设备）

### 3.4 辅助设备条目调整

| 操作 | 条目 | 说明 |
|------|------|------|
| 拆出新增 | "高低压配电装置"中拆出GCB | GCB升级为主设备，剩余更名为"厂用配电装置" |
| 合并 | 给水泵汽轮机(#12) → 并入汽动给水泵组(#9) | 子设备与父设备不应并列 |
| 合并 | 励磁变压器(#46) → 并入励磁系统 | 励磁系统降为辅助后，变压器是其组成部件 |
| 拆分 | 冷却塔/空冷岛 → 湿冷塔(公用) + 空冷岛(辅助) | 技术路线不同，分类应区分 |
| 降级 | 励磁系统(原主设备) → 辅助设备 | 依附于发电机 |
| 降级 | 冷却塔/空冷岛(原主设备) → 拆分降级 | 见上 |
| 待定 | 启动/备用变压器 → 公用系统 | Kimi建议，需确认是否多机共用 |
| 待定 | 飞灰含碳检测装置 → 删除 | Kimi认为粒度过低 |
