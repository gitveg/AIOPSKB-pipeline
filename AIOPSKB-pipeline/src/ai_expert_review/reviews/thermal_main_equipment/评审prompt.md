# 火电主设备分类评审

## 背景

我们正在构建工业设备智能运维知识库。水电子行业刚刚完成主设备分类评审（由Claude+DeepSeek+Kimi三方商榷），结果是从11项缩减为7项主设备。现在对火电子行业进行同样的评审。

设备分类原则：
- **主设备**：直接参与能量转换/生产过程的核心设备，投资占比大、停机影响全局
- **辅助设备**：为核心设备提供支持的配套设备
- **公用系统**：全厂共用、不直接参与单台机组生产过程的基础设施

## 火电当前主设备清单（8项）

| # | 设备名称 | 描述 |
|---|---------|------|
| 1 | 锅炉 | 燃料燃烧加热给水产生蒸汽，化学能→热能 |
| 2 | 汽轮机 | 蒸汽热能→旋转机械能 |
| 3 | 发电机 | 机械能→电能 |
| 4 | 凝汽器 | 汽轮机排汽口建立真空，冷凝乏汽回收工质 |
| 5 | 主变压器 | 发电机电压升压至输电电压 |
| 6 | 励磁系统 | 向发电机转子提供直流电流，建立旋转磁场 |
| 7 | 冷却塔/空冷岛 | 释放循环水热量到大气，实现热力循环冷端冷却 |

## 水电评审先例

水电站评审结论为7项主设备（水轮机、水泵水轮机、水轮发电机、主变压器、进水阀、发电机断路器、GIS）。其中：
- 进水阀和发电机断路器虽非能量转换设备，但因处于"主工艺链关键节点"、独立性强、故障后果严重而保留为主设备
- 离相封闭母线、高压电缆/GIL、中性点接地装置、高压开关柜归为辅助设备
- **励磁系统**两位专家一致认为应归为辅助设备："功能上完全依附于发电机"

## 需要评估的问题

1. **励磁系统**：水电评审中两位专家一致认为应归辅助设备（依附于发电机）。火电的励磁系统是否同理应降为辅助设备？
2. **冷却塔/空冷岛**：是否属于主设备？它的功能是热力循环的冷端散热，本身不进行能量转换，但故障会导致机组停运。
3. **凝汽器**：是否应保留为主设备？它创造了汽轮机运行所需的真空环境，是朗肯循环的关键环节，但也有观点认为它是汽轮机的配套设备。
4. **是否有遗漏**：是否有当前归为辅助设备但应升级为主设备的？

请从工程实际和知识工程两个角度给出明确判定意见。
