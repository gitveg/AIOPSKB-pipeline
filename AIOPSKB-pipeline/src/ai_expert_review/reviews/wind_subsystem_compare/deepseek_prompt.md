# 风电机组三子设备子系统划分横向对比评审

> 请作为你是一位检修/可靠性工程师，拥有20年工业设备检修和可靠性管理经验。你熟悉设备的功能分解、备件管理体系、检修规程和FMEA分析。在本次评审中，你的职责是审查设备的子系统/部件/零件三级结构——子系统划分是否与真实工程结构一致、部件是否拆到了合理的可维护单元粒度、零件是否聚焦于易损件和关键失效件、维护方法和报废方法是否挂载在正确的层级。你会关注：粒度是否适合故障诊断和备件管理，是否有过粗或过细的拆分。，对风电机组三种技术路线子设备的**子系统划分**进行横向对比评审。

## 评审背景

风电机组（设备）拆分为三种技术路线子设备：
- **双馈异步风电机组（DFIG）**：多级齿轮箱增速 + 双馈异步发电机 + 部分功率变流器
- **直驱永磁同步风电机组（PMSG）**：无齿轮箱 + 永磁同步发电机 + 全功率变流器
- **半直驱（中速永磁）风电机组**：一级/两级齿轮箱 + 永磁同步发电机 + 全功率变流器

三者拓扑结构差异主要在传动与发电环节，但同属"风电机组"，子系统划分应在保证各自技术特征的前提下，尽量保持**命名一致、粒度相当、边界对齐**，以支持跨机型的知识复用与故障检索。

## 评审依据：子系统维度

### A. 各子设备子系统划分的固有质量（逐个评估）
- **功能完备性**：是否覆盖该机型所有主要功能链/能量流环节（风能捕获→传动→发电→变流并网→偏航→控制→支撑→辅助），无关键功能缺失
- **划分逻辑一致**：是否统一按"功能/能量流"划分，不混用物理位置维度
- **粒度一致性**：各子系统粒度相当
- **边界清晰**：子系统间无功能重叠、无重复
- **符合真实工程结构**：与该机型真实的系统划分一致

### B. 三子设备的横向一致性（核心）
- **命名对齐**：功能等价的子系统是否用了对应可辨识的名称（如三者都应有"偏航""控制""支撑"类子系统）
- **粒度对齐**：同一功能域在三机型中的拆分粒度是否相当（如"风轮+变桨"有的合并有的拆分，是否合理）
- **边界对齐**：同一功能在三机型中划归的子系统边界是否一致（如冷却/润滑：DFIG 独立成子系统 vs PMSG 归入"辅助系统"，是否造成知识挂载不对齐）
- **拓扑差异的合理体现**：传动/发电环节的差异（DFIG 多级齿轮箱、PMSG 直驱、半直驱中速）是否在子系统划分中得到恰当体现，而非过度趋同或过度发散

### 子设备：双馈异步风电机组（DFIG）（9 个子系统）

| # | 子系统名称 | 描述 |
|---|-----------|------|
| 1 | 风能捕获子系统 | 包含叶片、轮毂与变桨机构，负责将风能转化为机械扭矩。功能边界包括气动效率调节与极限风速下的顺桨保护，不涉及后续的机械传动与发电环节。 |
| 2 | 机械传动子系统 | 由主轴、齿轮箱、高速轴及机械制动器构成，将风轮的低速高扭矩传递并增速至发电机所需转速。覆盖从轮毂输出到发电机转子输入的机械能路径，不含发电磁电转换。 |
| 3 | 双馈发电子系统 | 以绕线式异步发电机为核心，包括定子、转子绕组、滑环及碳刷，实现机械能到电能的转换。定子直接并网，转子通过变流器馈电，功能边界限于发电机本体机-电接口。 |
| 4 | 功率变换子系统 | 包含转子侧变流器、直流母线及网侧变流器，负责转子滑差功率的双向流动控制与网侧电能质量调节。实现发电机变速恒频运行，不包含整机逻辑控制功能。 |
| 5 | 偏航子系统 | 由偏航驱动、偏航轴承和制动器组成，根据风向信号调整机舱方向，使风轮对准风向。功能范围限于机舱绕塔架轴线的定位与锁定，不涉及桨距或发电控制。 |
| 6 | 整机控制与保护子系统 | 涵盖主控PLC、变桨/变流/偏航执行器接口及保护硬件（如Crowbar），执行最大功率跟踪、并网调节、故障穿越与安全连锁。负责协调各子系统，确保机组在各类工况下的稳定运行，不包含被控对象的物理功能实现。 |
| 7 | 塔架与支撑子系统 | 包括塔筒、基础及机舱底板，提供整机重力与风推力载荷传递路径，确保各子系统在预定高度和姿态下稳定工作。功能边界为结构承载，不参与能量转换或主动控制。 |
| 8 | 冷却系统 | 为发电机、变流器等发热设备提供空气或水冷却，含发电机空冷器、冷却风扇、变流器散热风机、冷却水泵及循环管路；功能范围限于冷却介质的循环与热量交换基础设施，齿轮箱油冷归润滑系统，不含被冷却设备本体（如发电机绕组、功率模块）。 |
| 9 | 润滑系统 | 为齿轮箱、主轴承等运动部件提供强制润滑，含润滑油泵、滤芯、油冷器、分配管路、油箱及油位监测装置；功能范围限于润滑油的存储、加压、输送、过滤与冷却回路，不含被润滑设备本体的内部油道。 |

### 子设备：直驱永磁同步风电机组（PMSG）（7 个子系统）

| # | 子系统名称 | 描述 |
|---|-----------|------|
| 1 | 风轮与变桨系统 | 实现风能捕获并转换为旋转机械能，包含叶片、轮毂及变桨机构。通过调节桨距角控制气动转矩与转速，在紧急情况下提供气动刹车，覆盖从气流到主轴输入端的功能边界。 |
| 2 | 传动系统 | 将风轮的低速旋转直接传递给发电机转子，无齿轮箱。包含主轴、主轴承及联接部件，承担支撑风轮、传递扭矩与轴向推力，覆盖从风轮接口到发电机转子的机械连接。 |
| 3 | 发电系统 | 将机械能转换为变频变压交流电能，采用永磁同步发电机制。转子永磁体与定子绕组耦合，输出全功率变流器所需的变频电源，覆盖从转子输入端到变流器输入端的功能。 |
| 4 | 电力变换系统 | 将发电机输出的变频交流电通过全功率变流器转换为恒频恒压电能并馈入电网。包含机侧/网侧变流器、直流环节、滤波器及升压变压器，覆盖从发电机输出到电网连接点的电力变换与并网控制。 |
| 5 | 偏航系统 | 根据风向变化驱动机舱绕塔架轴线旋转，保持风轮准确对风。包含偏航电机、偏航轴承、偏航制动及齿圈，覆盖机舱方位调节与大风解缆保护。 |
| 6 | 控制系统与传感器 | 实时监控机组运行状态，协调各子系统动作，完成发电控制、安全保护与通信。包含主控制器、变桨/变流/偏航控制器、风速风向仪、编码器等传感器，覆盖全机决策逻辑与闭环调节。 |
| 7 | 辅助系统 | 提供冷却散热、机械制动、液压动力及润滑等保障功能。包含水冷/风冷散热回路、高速轴制动器、液压站与润滑泵，覆盖各子系所需的辅助动力与温度、摩擦管理，确保可靠运行。 |

### 子设备：半直驱（中速永磁）风电机组（8 个子系统）

| # | 子系统名称 | 描述 |
|---|-----------|------|
| 1 | 风轮系统 | 包括叶片、轮毂和导流罩，将风动能转化为主轴上的机械扭矩，通过气动设计实现功率捕获，紧急时可提供气动刹车。功能边界为轮毂与主轴法兰面，是风能至机械能的入口。 |
| 2 | 变桨系统 | 包括变桨电机、减速器、变桨轴承、备用电源（超级电容或电池）及分控单元，根据主控指令独立调节叶片节距角，用于气动功率控制、启停平衡和紧急顺桨制动。边界覆盖从变桨控制柜到叶片根部的完整执行链路。 |
| 3 | 传动系统 | 包括主轴、主轴承、中速齿轮箱和高速联轴器，传递风轮扭矩并将转速提升至发电机所需工作转速，同时承受气动推力与弯矩。功能边界从主轴与轮毂接口至齿轮箱输出轴与发电机接口。 |
| 4 | 发电系统 | 包括永磁同步发电机及其集成冷却装置，将传动系统输入的机械能转换为频率和电压变化的交流电，无需外部励磁。功能边界为转子输入轴至定子输出接线盒，与变流器直接相连。 |
| 5 | 变流与并网系统 | 包括全功率变流器（机侧/网侧）、网侧滤波器和升压变压器，将发电机输出的变频变压交流电转换为符合电网要求的恒频恒压电能，实现有功/无功调节与低电压穿越。边界覆盖发电机电缆至风电场集电网连接点。 |
| 6 | 偏航系统 | 包括偏航驱动电机、偏航轴承、减速器及液压制动器，根据风向信号驱动机舱围绕塔架中心线转动，实现主动对风和解缆，并依靠制动器提供偏航阻尼与定位保持。边界为机舱底盘至塔架顶法兰的旋转接口。 |
| 7 | 控制系统 | 包括主控PLC、机舱控制柜、塔基控制柜、各类传感器（风速、温度、振动等）及场内通信网络，负责整机状态监控、逻辑调度、安全保护链执行与远程通信，是机组运行的大脑。边界覆盖所有子系统的信号交互和指令下发。 |
| 8 | 支撑与辅助系统 | 包括主机架、塔筒、机舱罩、集中液压站、润滑泵站、散热风机、管路阀门及消防报警等，为偏航制动、主轴制动提供液压动力，为齿轮箱和发电机提供润滑油循环与强制散热，并提供结构承载与环境防护，保障各子系统长期稳定运行。 |
