# 风电机组三子设备子系统统一迁移 — 执行报告

> 日期: 2026-06-25
> 关联文档: 本目录 `仲裁报告.md`、`deepseek_response.json`、`kimi_response.json`
> 数据位置: `src/data/power/wind/风电机组/{DFIG, PMSG, 半直驱}/`

---

## 一、背景

三AI专家横向对比评审（DeepSeek 5.2分 / Kimi 5.5分，均判"需修订"）发现：风电机组三种技术路线子设备的子系统划分在**命名、粒度、边界**三方面严重不一致，导致同类故障（变桨失效、冷却风机故障、塔架裂纹等）在三机型下挂载到不同知识路径，无法跨机型同位检索。

经主智能体仲裁，统一为 **10 个功能域子系统骨架**，三机型共用，拓扑差异（齿轮箱级数、双馈/永磁）仅在传动、发电、变流子系统的**描述**中体现。

核心约束：**DFIG 和半直驱已生成完整故障（202 + 215 = 417 个），迁移必须零丢失**。

---

## 二、统一的 10 子系统骨架

| # | 子系统名称 | 功能域 |
|---|-----------|--------|
| 1 | 风轮系统 | 风能捕获（叶片、轮毂、导流罩） |
| 2 | 变桨系统 | 桨距调节与紧急顺桨（独立） |
| 3 | 传动系统 | 主轴/主轴承/齿轮箱/机械制动器 |
| 4 | 发电系统 | 发电机本体 + 内置冷却 |
| 5 | 变流与并网系统 | 变流器 + 直流母线 + 升压变压器 + 并网开关 |
| 6 | 偏航系统 | 对风与解缆 |
| 7 | 控制系统 | 主控 + 保护 + 传感器 + 消防报警 |
| 8 | 塔架与支撑系统 | 塔筒/基础/主机架/机舱罩 |
| 9 | 冷却与散热系统 | 发电机/变流器/齿轮箱散热 |
| 10 | 润滑与液压系统 | 润滑循环 + 液压动力 |

## 三、关键操作（三机型改动明细）

### 操作分类原则

故障挂在**部件/零件层**，子系统重组对故障的影响分三类：

| 类型 | 对故障影响 | 操作方式 |
|------|-----------|---------|
| ① 纯改名 | ✅ 零影响 | 改子系统目录名 + 更新 sub_system.md |
| ② 部件目录迁移 | ✅ 故障跟随移动 | `mv` 部件目录到新子系统，faults/ 自动跟随 |
| ③ 新增部件 | ⚠️ 需新生成 | 仅建 components.md 行，故障后续用 pipeline fault 生成 |

### DFIG（9 → 10 子系统，202 故障零丢失）

| 操作 | 明细 |
|------|------|
| **纯改名** | 风能捕获→风轮系统、机械传动→传动系统、双馈发电→发电系统、功率变换→变流与并网系统、偏航子系统→偏航系统、整机控制与保护→控制系统、塔架与支撑子系统→塔架与支撑系统、冷却系统→冷却与散热系统、润滑系统→润滑与液压系统 |
| **部件迁移** | 风能捕获子系统拆分：变桨机构总成及 8 个零件目录（共 9 个故障目录）迁入新建的变桨系统；叶片总成、轮毂总成留在风轮系统 |
| **新增部件** | 变流与并网系统补"升压变压器总成"+"并网开关柜"（components.md 行，故障待生成） |
| **未新增** | 塔架与支撑系统已有"机舱底板支承系统"实质覆盖主机架承载功能，无需单独新增主机架 |

### 半直驱（8 → 10 子系统，215 故障零丢失）

| 操作 | 明细 |
|------|------|
| **纯改名** | 无（命名已较好，仅统一后缀） |
| **部件迁移** | 支撑与辅助系统拆分为三：① 塔架与支撑系统（主机架/弹性支撑/塔筒/法兰螺栓/塔筒门/机舱罩/密封胶条，7 个目录）② 润滑与液压系统（集中液压站/液压油泵/液压控制阀组/蓄能器/压力滤油器/润滑泵站/润滑油滤器/板式热交换器/管路阀门/高压液压软管/卡套式管接头/球阀，12 个目录）③ 冷却与散热系统（散热风机/风扇叶轮/驱动电机，3 个目录） |
| **消防归类** | 消防报警系统及其 3 个零件目录迁入控制系统（安全保护归类），并在控制系统 components.md 登记 |
| **边界微调** | 发电系统描述明确"仅含本体+内置冷却，外置冷却回路归冷却与散热系统" |

### PMSG（7 → 10 子系统，0 故障，从零建）

| 操作 | 明细 |
|------|------|
| **纯改名** | 控制系统与传感器→控制系统、电力变换系统→变流与并网系统 |
| **部件迁移** | 风轮与变桨系统拆分：变桨轴承/变桨驱动装置/变桨控制柜（11 行）迁入新建变桨系统；叶片/轮毂/法兰螺栓（7 行）留风轮系统。辅助系统拆分：水冷散热器/冷却液循环泵/膨胀罐/冷却液管路/温度传感器（10 行）→冷却与散热系统；液压站总成/自动注油润滑泵（10 行）→润滑与液压系统 |

## 五、过程中修复的代码 Bug

**`src/ai_expert_review/AI_Expert.py` 的 `call_api` 推理模型判断缺陷**

- 问题：原代码仅 `model.startswith("kimi-k")` 才识别为推理模型（给 8192 max_tokens），DeepSeek-V4-Pro 走 4096。DeepSeek-V4 是深度推理模型，4096 token 全用于"思考"，实际 content 输出为空，导致 JSON 解析失败。
- 修复：`is_reasoning = model.startswith("kimi-k") or "deepseek-v4" in model`，DeepSeek-V4 也获得 8192 max_tokens；同时新增 `max_tokens_override` 可选参数。
- temperature 强制 1.0 仍只对 kimi 生效（deepseek 允许自定义温度）。
