# 进度报告: steel - phase3.1_steel_轧机_棒线轧机_sub_system
> 时间: 2026-07-21 11:03:43

| 子系统名称 | 描述 |
| :--- | :--- |
| 主传动系统 | 将电能转化为旋转机械能并传递至轧辊，实现金属连续压缩变形。覆盖从主电机、减速机、齿轮座、万向接轴到联轴器的完整传动链，提供轧制所需扭矩与精确转速，确保负载剧烈波动时动力输出稳定。 |
| 轧制执行与辊缝调整系统 | 直接对坯料施加压力实现塑性变形与断面减缩，并精确设定控制辊缝。涵盖水平/立式轧辊组、轴承座、压下/压上及平衡装置，承担咬入、延伸成型全过程，实时调整压下力与成品截面尺寸精度。 |
| 机架与支撑系统 | 承载轧制过程中的巨大轧制力、冲击载荷及振动，保持辊系空间几何精度。由轧机牌坊、底座、地脚螺栓及横梁等构成，将载荷有效传递至基础，保证各机组间的对中稳定性与设备结构安全。 |
| 导卫与工艺冷却系统 | 引导轧件按预定路径精确进出孔型，并对轧辊与轧件实施在线控温冷却。涵盖进出口滚动/滑动导卫、扭转导管及穿水冷却装置，防止堆钢缠辊，控制轧辊热疲劳及轧件温度场与微观组织。 |
| 润滑与辅助流体系统 | 对主传动轴承、轧辊轴承、齿轮啮合面及滑动调整面提供强制润滑、冷却和清洁。覆盖稀油/干油集中润滑站、管路分配网络、循环过滤冷却器及密封组件，减少设备摩擦与热变形，保障机械稳定运行。 |
| 电气传动与自动化控制系统 | 实现轧机速度、位置、张力及设备协同的精确闭环控制，涵盖变频/直流传动柜、PLC/DCS控制器、HMI及测径仪等检测仪表。完成轧制程序逻辑执行、工艺参数实时调节、质量在线监测及数据采集诊断。 |
