# 进度报告: steel - phase3.1_steel_轧机_板材轧机_sub_system
> 时间: 2026-07-21 12:34:09

| 子系统名称 | 描述 |
|------------|------|
| 轧制承载结构系统 | 由机架、轧辊、轴承座及平衡装置等组成，承受并传递轧制力与弯矩，提供稳定的轧制线基准，确保各部件在载荷下保持精确的相对位置，是完成金属塑性变形的核心受力框架。 |
| 主传动系统 | 将主电机的动力经联轴器、减速机、齿轮座及万向接轴传递至轧辊，驱动上、下工作辊同步旋转，提供板材连续咬入与延伸变形所需的转速与扭矩，实现主轧制运动的能量供给。 |
| 轧辊位置与辊缝调节系统 | 通过电动压下、液压压上及微调机构，精确设定并动态调整工作辊之间的辊缝开度，控制板材出口厚度，实现厚度自动控制（AGC）功能，是保证纵向厚差的关键执行系统。 |
| 板形控制执行系统 | 利用工作辊与中间辊的弯曲、轴向往复窜动以及精细分段冷却等手段，在线调整辊缝的凸度与轮廓，补偿轧制过程中的轧辊弹性变形和热凸度波动，从而主动控制板材的平直度和横向厚度分布。 |
| 工艺冷却与润滑系统 | 包含泵站、喷淋集管、过滤及循环管路，向变形区与辊面定压定量供给冷却液与工艺润滑油，控制轧辊热凸度、降低摩擦并带走碎屑，同时为关键轴承提供集中润滑，确保温度与膜厚达标。 |
| 检测与控制系统 | 集成压力、位移、温度、厚度、板形等传感器，配合PLC、工业计算机及伺服驱动单元，实时采集过程数据并进行逻辑运算与闭环调节，对传动、辊缝、板形、冷却等子系统进行协同控制与人机交互。 |
| 板材输送与导卫系统 | 包括前后工作辊道、夹送辊、导卫装置和侧导板，负责将板坯正确导入辊缝、引导轧件按中心线运行并顺利输出，覆盖从进料至出料全过程的物料输送与导向。 |
| 辅助动力与介质系统 | 包含液压站、气动系统、除尘装置及稀油润滑站等，为轧机各类执行机构提供基础动力与工作介质，保障设备辅助功能的稳定运行并满足环境合规要求。 |
