# 进度报告: steel - phase3.1_steel_轧机_管材轧机_sub_system
> 时间: 2026-07-21 13:49:53

| 子系统名称 | 描述 |
|-------------|------|
| 主传动系统 | 包括主电机、减速机、齿轮座和万向接轴等部件，负责将电机动力传递至轧辊，提供轧制所需的扭矩和转速调节，确保轧辊稳定旋转。其边界止于轧辊输入端，不涉及轧辊的装配与变形功能。 |
| 轧机主机系统 | 包含机架、轧辊装配、压下装置、辊缝调整机构和平衡装置等，直接承受和传递轧制力，完成管材的径向减壁和延伸变形。覆盖从辊缝设定到变形区金属流动控制的功能，不包含工模具的独立操作。 |
| 工模具操作系统 | 面向芯棒、导板等工艺工装，实现芯棒的穿入、抽出、冷却、润滑及限位支撑，以及导板的更换与调整。保证变形工具的位置精度和循环使用，与轧辊变形功能松耦合，避免与主机系统重叠。 |
| 冷却与润滑系统 | 提供轧辊外冷、芯棒内冷及轧制工艺润滑，控制轧辊和工件的温度场，减小摩擦和粘结，延长工具寿命。包括供水泵站、喷淋装置、润滑油站和过滤循环管路，覆盖整个热影响区域的介质供给。 |
| 液压与气压系统 | 为压下锁紧、轧辊平衡、工装夹紧及输送辊道等提供可靠的液压和压缩空气动力，包含泵站、控制阀组、蓄能器和执行元件。作为全机辅助动力源，不承担直接成形动作，与主传动和执行机构功能分离。 |
| 电气与自动化控制系统 | 集成PLC、变频驱动、传感器和人机界面，实现轧制速度同步、张减径张力控制、辊缝自动调节、故障诊断和数据采集。对整个轧制过程进行实时监控、联锁保护和参数优化，确保设备协同运行。 |
