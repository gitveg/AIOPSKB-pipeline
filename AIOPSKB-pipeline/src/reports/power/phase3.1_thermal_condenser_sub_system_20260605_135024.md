# 进度报告: power - phase3.1_thermal_condenser_sub_system
> 时间: 2026-06-05 13:50:24

| 子系统名称 | 描述 |
| :--- | :--- |
| 蒸汽导流与分配系统 | 承接汽轮机末级排汽，利用壳体内置的导流板、扩散管结构对高速汽流进行减速与均匀分配，使蒸汽无死角、低阻力地覆盖所有管束区域，避免局部流速过高冲刷管束并降低压力损失。 |
| 冷凝换热管束系统 | 核心功能子系统，由大量薄壁传热管按一定排列构成换热面。管外通饱和蒸汽，管内通循环冷却水，利用蒸汽汽化潜热快速冷凝成液态水，并形成局部负压，决定凝汽器的热力性能与极限真空能力。 |
| 真空建立与抽气系统 | 用于汇集并抽出冷凝过程中析出的不凝结气体。在管束内部构建空气冷却区，将不凝气体引至抽气口，通过真空泵或抽射器连续排出，建立并维持汽轮机排汽口的严密真空，保障机组效率。 |
| 凝结水收集与回热系统 | 由集水盘与底部的热井构成，接收从管束滴落的所有凝结水。热井具备足够储存容积，缓冲瞬态工况下的水位波动，为凝结水泵提供稳定的净正吸入压头，并回收具有回热价值的优质蒸馏水。 |
| 冷却水流通与密封系统 | 包含密封垫、水室与管板，负责循环冷却水的引入、分配与汇集。引导冷却水流经换热管的内腔形成单流程或多流程，带走废热，并靠管胀接与密封设计实现冷却水与蒸汽侧的绝对隔离。 |
