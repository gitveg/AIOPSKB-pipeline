# 进度报告: power - phase2_thermal_equipment
> 时间: 2026-04-29 16:10:13

| 设备名称 | 设备类型 | 描述 |
| :--- | :--- | :--- |
| 锅炉 | 主设备 | 通过煤粉燃烧将给水加热为高温高压蒸汽，为汽轮机提供做功工质。 |
| 汽轮机 | 主设备 | 将高温高压蒸汽的热能转换为机械能，驱动发电机转子旋转。 |
| 发电机 | 主设备 | 利用电磁感应原理将汽轮机传来的机械能转换为电能。 |
| 主变压器 | 主设备 | 将发电机发出的低电压大电流电能转换为高电压等级电能，便于输送。 |
| 一次风机 | 辅助设备 | 干燥原煤并向磨煤机或炉膛提供输送煤粉所需的一次风。 |
| 送风机 | 辅助设备 | 克服空气预热器和风道阻力，向炉膛提供助燃的二次风。 |
| 引风机 | 辅助设备 | 抽取炉膛烟气，维持炉膛负压，并引导烟气通过尾部受热面及环保设备排向烟囱。 |
| 磨煤机 | 辅助设备 | 将原煤研磨成满足燃烧细度要求的煤粉，并进行干燥和分离。 |
| 空气预热器 | 辅助设备 | 利用锅炉尾部烟气余热加热燃烧所需空气，降低排烟温度，提高锅炉效率。 |
| 给煤机 | 辅助设备 | 根据负荷指令称量并定量将原煤均匀送入磨煤机。 |
| 电除尘器 | 辅助设备 | 利用高压静电原理去除锅炉尾部烟气中的粉尘颗粒，保持烟尘排放达标。 |
| 脱硫系统 | 辅助设备 | 通过石灰石等吸收剂去除烟气中的二氧化硫，防止大气污染。 |
| 脱硝系统 | 辅助设备 | 利用选择性催化还原等工艺去除烟气中的氮氧化物。 |
| 炉水循环泵 | 辅助设备 | 在锅炉启动或低负荷时建立并维持蒸发系统内部介质的强制循环。 |
| 除氧器 | 辅助设备 | 采用热力喷雾等方式去除锅炉给水中的溶解氧及其他气体，防止设备腐蚀。 |
| 高压加热器 | 辅助设备 | 利用汽轮机高压段抽汽加热锅炉给水，提高循环热效率。 |
| 低压加热器 | 辅助设备 | 利用汽轮机低压段抽汽加热凝结水，提高循环热效率。 |
| 凝汽器 | 辅助设备 | 接收汽轮机排汽并将其冷凝为水，同时建立和维持汽轮机排汽口真空。 |
| 凝结水泵 | 辅助设备 | 将凝汽器热井中的凝结水升压，经各级低压加热器送往除氧器。 |
| 汽动给水泵组 | 辅助设备 | 由小汽轮机驱动，向锅炉提供高质量的给水（通常为运行泵）。 |
| 电动给水泵组 | 辅助设备 | 由电动机驱动，在启停机或汽动泵故障时提供锅炉给水备用。 |
| 给水泵汽轮机 | 辅助设备 | 专门用于驱动大容量给水泵的蒸汽轮机，直接利用蒸汽动力。 |
| 循环水泵 | 辅助设备 | 向凝汽器连续供应冷却水（海水或淡水），以凝结汽轮机排汽。 |
| 柴油发电机组 | 辅助设备 | 在全厂失电的紧急情况下启动，为保安负荷或机组安全停机提供电源。 |
| 高压旁路系统 | 辅助设备 | 将锅炉产生的蒸汽不经过汽轮机高压缸而直接减温减压后引入再热器或凝汽器。 |
| 低压旁路系统 | 辅助设备 | 将再热蒸汽不经过汽轮机中低压缸而直接减温减压后引入凝汽器。 |
| 捞渣机 | 辅助设备 | 将锅炉炉膛底部燃烧产生的灰渣通过水封冷却捞出并输送至渣仓。 |
| 碎煤机 | 辅助设备 | 将大块原煤破碎至皮带输送系统或磨煤机可接受的颗粒度。 |
| 静电除尘器变压器/高频电源 | 辅助设备 | 将工频交流电转换为高压直流电或高频脉冲电，为电除尘器提供强电场。 |
| 闭式冷却水泵 | 辅助设备 | 驱动除盐水在闭式回路中循环，对汽机等转机的轴承及辅机进行冷却。 |
| 活化给煤机 | 辅助设备 | 安装在煤仓下方，利用振动防止原煤起拱堵塞，并定量向下级给料。 |
| 四大管道 | 辅助设备 | 指主蒸汽、再热热段、再热冷段及高压给水管道，承载高温高压介质。 |
| 发电机出口断路器 | 辅助设备 | 开断发电机与主变压器之间的电气连接，实现机组并网或快速保护解列。 |
| 机械真空泵 | 辅助设备 | 抽出凝汽器内不凝结气体，建立系统初始真空及维持运行真空。 |
| 胶球清洗装置 | 辅助设备 | 通过循环投放海绵胶球在线擦洗凝汽器换热管内壁，维持传热效率。 |
| 汽轮机油系统 | 辅助设备 | 为汽轮机控制保护系统提供动力油，并向各轴承提供润滑油和顶轴油。 |
| 励磁系统 | 辅助设备 | 向发电机转子绕组提供可调节的直流电流，建立磁场并控制机端电压和无功。 |
| 厂用变压器 | 辅助设备 | 将发电机出口或电网电压降至6kV/380V，为全厂辅机及照明提供工作电源。 |
| 启动备用变压器 | 辅助设备 | 在机组启停或厂用变故障时，从电网获取电源并保证厂用电的连续运行。 |
| 翻车机 | 公用系统 | 通过翻转铁路敞车车厢，实现散装煤炭或物料的机械化卸载。 |
| 斗轮堆取料机 | 公用系统 | 大型煤场机械，用于煤料的堆存和取用，完成卸煤与上煤任务。 |
| 皮带输送机 | 公用系统 | 构成输煤栈桥主干，连续输送煤炭至各个转运点、煤仓或煤场。 |
| 化学水处理系统 | 公用系统 | 将天然水或城市中水经沉淀、过滤、离子交换或反渗透处理，制备合格除盐水。 |
| 凝结水精处理系统 | 公用系统 | 对凝结水进行全流量除盐和过滤，去除凝结水中的腐蚀产物和微量溶解盐分。 |
| 除灰系统 | 公用系统 | 收集电除尘器及省煤器灰斗中的干灰，通过气力或水力方式输送至灰库。 |
| 压缩空气系统 | 公用系统 | 提供符合压力、品质要求的仪表用气、检修用气及杂用气。 |
| 卸船机 | 公用系统 | 用于海运来煤的码头卸煤作业，将煤抓取至码头皮带输送线上。 |
| 冷却塔 | 公用系统 | 利用空气对流和蒸发换热原理，降低循环冷却水温度实现循环利用。 |
| 网控继电器室设备 | 公用系统 | 包含线路保护、母线保护、断路器保护等二次设备，监控电力外送通道。 |
| 500kV 气体绝缘开关设备 | 公用系统 | 利用SF6气体绝缘，将隔离开关、断路器、主母线等紧凑封装于GIS厂房内。 |
| 氢气系统 | 公用系统 | 向发电机定子绕组提供高纯度氢气作为冷却介质，并维持压力与纯度控制。 |
| 废水处理系统 | 公用系统 | 收集并处理含煤废水、脱硫废水、酸碱废水等，实现达标排放或回收利用。 |
| 输煤程控系统 | 公用系统 | 完成输煤皮带的启停联锁、路径选择、信号采集，实现上煤配煤自动化。 |
| 分散控制系统 | 公用系统 | 火电厂核心控制系统，对锅炉、汽机及主要辅机进行实时监控和保护联锁。 |
| 厂级监控信息系统 | 公用系统 | 采集全厂生产实时数据，提供性能计算、优化指导、寿命管理等高级应用功能。 |
| 消防水系统 | 公用系统 | 提供覆盖油库、变压器、煤场、电子间等全域的自动喷淋或消火栓水源。 |
| 暖通空调系统 | 公用系统 | 维持集控室、电子间、配电室等区域的温度、湿度及洁净度要求。 |
| 启动锅炉 | 公用系统 | 在主机冷态启动或调试试运期间，提供全厂辅汽吹管、重油加热及生活采暖用汽。 |
| 燃油泵房系统 | 公用系统 | 在锅炉点火及低负荷稳燃时，向炉前油枪提供一定压力和流量的助燃油。 |
| 除铁器 | 公用系统 | 布置于输煤皮带上方或头部，利用电磁力去除煤炭中混杂的铁磁性杂物。 |

| 发电机-变压器组保护 | 辅助设备 | 由差动、过流、过激磁等多种保护继电器构成，对发电机和主变压器内部及其引出线故障进行快速检测与跳闸。 |
| 蓄电池及直流系统 | 公用系统 | 在全厂交流电源消失时，由蓄电池组向控制、保护、通信、事故照明等关键负荷提供不间断直流电源。 |
| 交流不停电电源系统(UPS) | 公用系统 | 为分散控制系统、厂级监控信息系统、电子仪表等对供电质量极为敏感的负荷提供无扰动、稳压稳频的交流电源。|
| 调度交换机/通信系统 | 公用系统 | 提供与电网调度端之间的调度电话、远动数据传输及保护信号传输通道，确保电厂与系统间的实时协调控制。 |
| 排粉风机 | 辅助设备 | 在中间储仓式制粉系统中，将粗粉分离器后的乏气及煤粉抽吸输送至锅炉燃烧器入口。 |
| 低加疏水泵 | 辅助设备 | 将低压加热器中产生的疏水加压回收至主凝结水管道，以减少工质和热量损失。 |
| 炉膛安全监控系统(FSSS) | 辅助设备 | 对锅炉点火、燃烧及熄火过程进行逻辑控制和保护联锁，防止炉膛内积聚可燃混合物引发爆燃。 |
| 汽轮机数字电液控制系统(DEH) | 辅助设备 | 接收转速及负荷指令，通过电液伺服机构精确控制汽轮机进汽阀门开度，实现机组的转速与负荷调节。 |
| 变频器 | 辅助设备 | 通过改变电机供电频率，实现对风机、水泵等辅机的调速运行，以降低节流损失并实现节能。 |
| 入厂/入炉煤机械采样装置 | 公用系统 | 按照标准自动截取输煤皮带上的煤流全断面样品，用于煤质化验分析。 |
| 筛煤机 | 公用系统 | 布置于碎煤机前，通过筛分将合格粒度原煤直接旁路，仅对大块煤进行破碎，以降低碎煤机负荷。 |
| 输煤系统除尘器 | 公用系统 | 捕集输煤转运站、碎煤机室等场所产生的煤尘，降低粉尘浓度，防止粉尘爆炸和保障职业健康。 |
| 汽机房行车/桥式起重机 | 辅助设备 | 用于汽轮机本体、发电机定转子、凝汽器等大型设备在安装及检修时的吊装就位与翻身。 |
| 氧化风机 | 辅助设备 | 为脱硫吸收塔浆液池提供强制氧化空气，将亚硫酸钙氧化生成可回收利用的二水石膏晶体。 |
| 增压风机 | 辅助设备 | 配置于无GGH或有旁路的脱硫系统中，用以克服脱硫系统的额外烟道阻力，确保锅炉背压稳定。 |
| 烟囱 | 公用系统 | 将经过净化处理的锅炉排烟提升到一定高度扩散排放，以降低地面污染物浓度。 |
