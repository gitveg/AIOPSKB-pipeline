# 进度报告: power - phase3.1_wind_风电机组_半直驱（中速永磁）风电机组_sub_system
> 时间: 2026-06-23 18:21:05

| 子系统名称 | 描述 |
|------------|------|
| 风轮系统 | 包括叶片、轮毂和导流罩，将风动能转化为主轴上的机械扭矩，通过气动设计实现功率捕获，紧急时可提供气动刹车。功能边界为轮毂与主轴法兰面，是风能至机械能的入口。 |
| 变桨系统 | 包括变桨电机、减速器、变桨轴承、备用电源（超级电容或电池）及分控单元，根据主控指令独立调节叶片节距角，用于气动功率控制、启停平衡和紧急顺桨制动。边界覆盖从变桨控制柜到叶片根部的完整执行链路。 |
| 传动系统 | 包括主轴、主轴承、中速齿轮箱和高速联轴器，传递风轮扭矩并将转速提升至发电机所需工作转速，同时承受气动推力与弯矩。功能边界从主轴与轮毂接口至齿轮箱输出轴与发电机接口。 |
| 发电系统 | 包括永磁同步发电机及其集成冷却装置，将传动系统输入的机械能转换为频率和电压变化的交流电，无需外部励磁。功能边界为转子输入轴至定子输出接线盒，与变流器直接相连。 |
| 变流与并网系统 | 包括全功率变流器（机侧/网侧）、网侧滤波器和升压变压器，将发电机输出的变频变压交流电转换为符合电网要求的恒频恒压电能，实现有功/无功调节与低电压穿越。边界覆盖发电机电缆至风电场集电网连接点。 |
| 偏航系统 | 包括偏航驱动电机、偏航轴承、减速器及液压制动器，根据风向信号驱动机舱围绕塔架中心线转动，实现主动对风和解缆，并依靠制动器提供偏航阻尼与定位保持。边界为机舱底盘至塔架顶法兰的旋转接口。 |
| 控制系统 | 包括主控PLC、机舱控制柜、塔基控制柜、各类传感器（风速、温度、振动等）及场内通信网络，负责整机状态监控、逻辑调度、安全保护链执行与远程通信，是机组运行的大脑。边界覆盖所有子系统的信号交互和指令下发。 |
| 支撑与辅助系统 | 包括主机架、塔筒、机舱罩、集中液压站、润滑泵站、散热风机、管路阀门及消防报警等，为偏航制动、主轴制动提供液压动力，为齿轮箱和发电机提供润滑油循环与强制散热，并提供结构承载与环境防护，保障各子系统长期稳定运行。 |
