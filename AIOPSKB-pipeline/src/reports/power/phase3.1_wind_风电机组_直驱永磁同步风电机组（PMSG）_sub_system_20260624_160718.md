# 进度报告: power - phase3.1_wind_风电机组_直驱永磁同步风电机组（PMSG）_sub_system
> 时间: 2026-06-24 16:07:18

| 子系统名称 | 描述 |
|------------|------|
| 风轮与变桨系统 | 实现风能捕获并转换为旋转机械能，包含叶片、轮毂及变桨机构。通过调节桨距角控制气动转矩与转速，在紧急情况下提供气动刹车，覆盖从气流到主轴输入端的功能边界。 |
| 传动系统 | 将风轮的低速旋转直接传递给发电机转子，无齿轮箱。包含主轴、主轴承及联接部件，承担支撑风轮、传递扭矩与轴向推力，覆盖从风轮接口到发电机转子的机械连接。 |
| 发电系统 | 将机械能转换为变频变压交流电能，采用永磁同步发电机制。转子永磁体与定子绕组耦合，输出全功率变流器所需的变频电源，覆盖从转子输入端到变流器输入端的功能。 |
| 电力变换系统 | 将发电机输出的变频交流电通过全功率变流器转换为恒频恒压电能并馈入电网。包含机侧/网侧变流器、直流环节、滤波器及升压变压器，覆盖从发电机输出到电网连接点的电力变换与并网控制。 |
| 偏航系统 | 根据风向变化驱动机舱绕塔架轴线旋转，保持风轮准确对风。包含偏航电机、偏航轴承、偏航制动及齿圈，覆盖机舱方位调节与大风解缆保护。 |
| 控制系统与传感器 | 实时监控机组运行状态，协调各子系统动作，完成发电控制、安全保护与通信。包含主控制器、变桨/变流/偏航控制器、风速风向仪、编码器等传感器，覆盖全机决策逻辑与闭环调节。 |
| 辅助系统 | 提供冷却散热、机械制动、液压动力及润滑等保障功能。包含水冷/风冷散热回路、高速轴制动器、液压站与润滑泵，覆盖各子系所需的辅助动力与温度、摩擦管理，确保可靠运行。 |
