# 进度报告: power - phase1_sub_industry_seeded
> 时间: 2026-04-29 15:35:53

| 子行业名称 | 描述 |
|------------|------|
| 火电 | 利用煤、石油、天然气等化石燃料燃烧产生热能，推动汽轮机发电的方式，是当前电力系统的基础电源和调峰主力。 |
| 水电 | 利用河流、湖泊等水体的势能或动能，通过水轮机转换成电能的清洁能源发电方式，包括常规水电和抽水蓄能发电。 |
| 风电 | 利用风力驱动风轮旋转，将风能转换为电能的发电方式，分为陆上风电和海上风电，是可再生能源的重要组成部分。 |
| 核电 | 通过核裂变或核聚变反应释放热能，产生蒸汽驱动汽轮机发电的方式，具有高能量密度、低碳排放的特性。 |
| 光伏 | 利用半导体材料的光生伏特效应，将太阳光直接转换为电能的发电方式，包括集中式光伏电站和分布式光伏系统。 |
| 输电 | 将发电厂产生的电能通过高压或超高压线路进行远距离输送的环节，连接电源中心与负荷中心，是电网的主干网络。 |
| 变电 | 通过变压器等设备对电压等级进行变换，以适应输电、配电和用电不同环节需求的中间设施，包括升压、降压和联络变电站。 |
| 配电 | 将来自输电网络或降压变电站的电能按电压等级和用户需求进行分配和供应的环节，覆盖城市、农村及各类终端用户的接入网络。 |
| 储能 | 通过物理、化学等方法将电能存储并在需要时释放的系统，包括抽水蓄能、电化学储能、压缩空气储能等，用于调峰、调频和提升新能源消纳能力。 |
| 售电与交易 | 在电力市场化环境下，向终端用户销售电能并参与电力批发市场交易的服务环节，包括售电公司、电力营销、需求侧响应和电力金融交易等。 |
