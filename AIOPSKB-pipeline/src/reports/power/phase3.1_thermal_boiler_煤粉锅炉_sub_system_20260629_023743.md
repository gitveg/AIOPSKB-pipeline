# 进度报告: power - phase3.1_thermal_boiler_煤粉锅炉_sub_system
> 时间: 2026-06-29 02:37:43

| 子系统名称 | 描述 |
|------------|------|
| 燃料制备与供给系统 | 负责原煤的接收、储存、研磨和分离，将原煤磨制成细度合格的煤粉，并通过一次风将煤粉气力输送至燃烧器，同时调节煤粉流量以适应负荷变化。该系统确保燃料连续、均匀、可控地供给炉膛，覆盖从原煤仓至燃烧器入口的全过程。 |
| 燃烧系统 | 组织煤粉与助燃空气在炉膛内充分混合、着火和稳定燃烧，通过燃烧器布置、配风方式及炉膛结构控制火焰形状和温度场，并将燃烧释放的辐射热传递给水冷壁等受热面。该系统涵盖炉膛、燃烧器和点火装置，完成化学能到热能的转化。 |
| 汽水系统 | 吸收炉膛和烟道内的热量，完成给水预热、蒸发、汽水分离及蒸汽过热全过程，产生符合参数要求的蒸汽。系统包括省煤器、汽包（或分离器）、水冷壁、过热器和再热器等部件，实现工质状态的逐级转变和热量梯级利用。 |
| 风烟系统 | 提供燃烧所需的一次风、二次风及密封风等，并克服风道和烟道阻力，将烟气从炉膛抽出，经受热面换热后送入烟气净化装置，最终排入烟囱。系统涵盖送风机、引风机、空气预热器和连接管道，负责空气供给与烟气导流的连续性。 |
| 烟气净化与排放系统 | 对燃烧产生的烟气进行除尘、脱硫、脱硝等处理，去除飞灰、二氧化硫和氮氧化物等污染物，使排放符合环保标准，并通过烟囱将洁净烟气高空排放。该子系统与风烟系统在接口处衔接，边界为脱硫塔入口至烟囱出口。 |
| 除灰渣系统 | 收集和处理燃烧过程产生的炉底渣和烟气中分离出的飞灰，通过干式或湿式方式将灰渣输送至渣仓或灰库，实现灰渣的安全排放、储存和综合利用。覆盖范围从炉底排渣口、除尘器灰斗到灰渣外运接口。 |
| 热工控制系统 | 监测锅炉各子系统运行参数（温度、压力、流量、水位等），通过自动化装置和逻辑组态调节燃料量、风量、给水量等，实现负荷控制、安全保护及联锁逻辑，确保锅炉高效、稳定、安全运行。该系统覆盖检测、执行及人机交互全部控制功能。 |
