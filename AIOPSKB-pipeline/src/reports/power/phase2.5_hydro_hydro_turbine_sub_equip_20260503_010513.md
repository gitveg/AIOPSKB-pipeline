# 进度报告: power - phase2.5_hydro_hydro_turbine_sub_equip
> 时间: 2026-05-03 01:05:13

| 子设备名称 | 描述 |
| :--- | :--- |
| 混流式水轮机 | 水流径向流入、轴向流出转轮，结构简单、效率高、适用水头范围广，是应用最广泛的机型。 |
| 轴流转桨式水轮机 | 水流轴向通过转轮，转轮叶片可随工况自动调节，高效率区宽，适应水头和负荷变化能力强。 |
| 轴流定桨式水轮机 | 水流轴向通过转轮，转轮叶片固定不可调，结构简单、成本低，但偏离设计工况时效率急剧下降。 |
| 斜流式水轮机 | 水流斜向进出转轮，叶片可调节，兼具轴流转桨式高效率区和混流式抗空化、强度高的优点，结构复杂。 |
| 灯泡贯流式水轮机 | 发电机安装在灯泡形密封壳体内，置于流道中，水流轴向直贯流过，适用于低水头、大流量电站。 |
| 轴伸贯流式水轮机 | 卧式布置，转轮主轴穿过流道弯管与外部发电机相连，结构较简单，适用于低水头电站。 |
| 竖井贯流式水轮机 | 发电机布置在流道上游侧的混凝土竖井内，水流顺畅，适用于低水头电站。 |
| 全贯流式水轮机 | 发电机转子安装在转轮叶片外缘，流道平直，效率高，但旋转密封困难，应用较少。 |
| 水斗式水轮机 | 喷嘴将水流动能转化为高速射流，切向冲击转轮水斗，适用于高水头、小流量电站。 |
| 斜击式水轮机 | 喷嘴射流以一定角度斜向冲击转轮叶片，适用于中高水头、功率较小的小型电站。 |
| 双击式水轮机 | 水流先后两次冲击转轮叶片做功，结构简单，适用于中低水头、小流量的微型或小型电站。 |
| 可逆式水泵水轮机 | 可双向运行，兼具水轮机发电和水泵抽水功能，是抽水蓄能电站的核心设备。 |
