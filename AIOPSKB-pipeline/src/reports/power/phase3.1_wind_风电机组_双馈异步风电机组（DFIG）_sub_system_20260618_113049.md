# 进度报告: power - phase3.1_wind_风电机组_双馈异步风电机组（DFIG）_sub_system
> 时间: 2026-06-18 11:30:49

| 子系统名称 | 描述 |
|------------|------|
| 风能捕获子系统 | 包含叶片、轮毂与变桨机构，负责将风能转化为机械扭矩。功能边界包括气动效率调节与极限风速下的顺桨保护，不涉及后续的机械传动与发电环节。 |
| 机械传动子系统 | 由主轴、齿轮箱、高速轴及机械制动器构成，将风轮的低速高扭矩传递并增速至发电机所需转速。覆盖从轮毂输出到发电机转子输入的机械能路径，不含发电磁电转换。 |
| 双馈发电子系统 | 以绕线式异步发电机为核心，包括定子、转子绕组、滑环及碳刷，实现机械能到电能的转换。定子直接并网，转子通过变流器馈电，功能边界限于发电机本体机-电接口。 |
| 功率变换子系统 | 包含转子侧变流器、直流母线及网侧变流器，负责转子滑差功率的双向流动控制与网侧电能质量调节。实现发电机变速恒频运行，不包含整机逻辑控制功能。 |
| 偏航子系统 | 由偏航驱动、偏航轴承和制动器组成，根据风向信号调整机舱方向，使风轮对准风向。功能范围限于机舱绕塔架轴线的定位与锁定，不涉及桨距或发电控制。 |
| 整机控制与保护子系统 | 涵盖主控PLC、变桨/变流/偏航执行器接口及保护硬件（如Crowbar），执行最大功率跟踪、并网调节、故障穿越与安全连锁。负责协调各子系统，确保机组在各类工况下的稳定运行，不包含被控对象的物理功能实现。 |
| 塔架与支撑子系统 | 包括塔筒、基础及机舱底板，提供整机重力与风推力载荷传递路径，确保各子系统在预定高度和姿态下稳定工作。功能边界为结构承载，不参与能量转换或主动控制。 |
| 辅助子系统 | 包含冷却与润滑装置，为发电机、齿轮箱等关键部件提供散热和润滑，保障设备可靠运行。功能范围限于辅助支持，不涉及能量转换或主动控制。 |
