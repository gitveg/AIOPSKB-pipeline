# 进度报告: power - phase3.1_thermal_boiler_循环流化床锅炉（CFB）_sub_system
> 时间: 2026-06-29 09:50:57

| 子系统名称 | 描述 |
|------------|------|
| 燃料供给与制备系统 | 负责原煤、生物质及石灰石等燃料的破碎、筛分与输送，通过给料设备将其连续、定量地送入炉膛密相区，确保入炉粒径符合流化要求，并防止高温烟气反窜，功能边界止于炉膛入口。 |
| 布风与流化燃烧系统 | 由风机群、空预器、布风装置及炉膛构成。一次风经布风板使燃料与床料流化并燃烧，二次风分级补氧，高压风松动回料。系统覆盖配风、流态化混合、高效燃烧及炉内脱硫全过程。 |
| 物料循环系统 | 以旋风分离器为核心，将高温烟气中的固体颗粒分离，经立管和回料阀将未燃尽物料送回炉膛，维持炉内物料浓度与循环倍率，延长颗粒停留时间，边界从分离器入口至回料阀出口。 |
| 蒸汽发生与汽水系统 | 由汽包、水冷壁、过热器、省煤器等受热面组成。吸收炉膛与烟道热量完成给水预热、蒸发及蒸汽过热，产出合格参数蒸汽供应汽轮机，覆盖给水进口至主蒸汽出口的全部热交换过程。 |
| 尾部烟气与净化排放系统 | 包含尾部受热面、除尘器、脱硫脱硝装置及引风机等。继续回收烟气余热加热给水与空气，分离飞灰并脱除有害气体，最终由引风机将达标烟气排入大气，覆盖炉膛出口至烟囱。 |
| 除渣与飞灰收集系统 | 负责处理炉底沉积的粗颗粒底渣及烟气分离的飞灰。高温底渣经冷渣器回收显热后输送至渣仓，飞灰由气力或机械方式收集排出，实现固体废弃物安全输出，维持床层压差稳定。 |
| 测量与控制系统 | 集成温度、压力、流量等仪表及DCS控制，实时调节燃料、风量、物料循环及排渣量，保障锅炉安全稳定运行与环保排放达标，覆盖全系统的参数监测、自动调节与联锁保护。 |
