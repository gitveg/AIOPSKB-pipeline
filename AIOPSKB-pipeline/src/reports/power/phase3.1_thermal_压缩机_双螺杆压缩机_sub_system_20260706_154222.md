# 进度报告: power - phase3.1_thermal_压缩机_双螺杆压缩机_sub_system
> 时间: 2026-07-06 15:42:22

| 子系统名称 | 描述 |
|------------|------|
| 压缩转子系统 | 由一对精密啮合的阴阳螺杆转子及同步齿轮构成，通过旋转过程中齿间容积的周期性变化，完成气体吸入、压缩及排出的核心功能。该系统定义了压缩机的热力性能与容积效率。 |
| 驱动与传动系统 | 将电动机或发动机的动力安全、高效地传递给阳转子，通常包含驱动电机、联轴器或增速齿轮。其功能是提供压缩转子所需的转矩和转速，确保主机在额定工况下稳定运行。 |
| 润滑与冷却系统 | 负责向压缩腔、轴承和齿轮喷射润滑油，实现密封间隙、带走压缩热、润滑运动部件三重功能。包含油泵、温控阀、油冷却器及油过滤器，维持油路循环与适宜的工作温度。 |
| 气体净化与分离系统 | 处理压缩后油气混合物，通过多级分离（如碰撞、离心、精滤）将润滑油与压缩气体分离，确保排出气体的含油量达标。同时包含进气过滤器，去除吸入空气的尘埃微粒。 |
| 容量与调节系统 | 根据下游用气需求自动调节压缩机的排气量，典型方式包括进气节流、滑阀调节或变频调速。其边界涵盖进气控制阀、容量调节滑块及相应执行机构，以维持管网压力稳定并实现节能。 |
| 监控与保护系统 | 实时采集压力、温度、电流等运行参数，进行逻辑判断与故障报警，实现自动启停、加卸载控制及紧急停机保护。包含传感器、控制器及电气元件，保障机组在安全边界内可靠运行。 |
| 结构支撑与密封系统 | 提供整体机架、壳体及连接法兰，承受内压、转子作用力及管道载荷。同时包含轴端机械密封或迷宫密封，防止气体向大气泄漏或润滑油进入压缩腔，确保结构完整与介质隔离。 |
