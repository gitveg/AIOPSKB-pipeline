| 电缆本体 | 电缆及接线系统 | 包含导体和绝缘层的载流组件，用于长距离、安全地输送电能或信号。（来源：Electrical cable - Wikipedia） | 否 | — | — |
| 导体 | 电缆本体 | 由铜或铝制成的单股或多股金属丝，主要用于承载电流。其截面积决定了载流量。（来源：Electrical cable - Wikipedia） | 否 | 巡检时检查导体末端氧化变色情况；日常无需特别维护。（来源：综合实践） | 当导体因过载或短路出现熔断、截面严重氧化发黑脆断且无法可靠连接时，判定为报废。拆除需切断电源，包好同回路其他导体接头。（来源：综合实践） |
| 绝缘层 | 电缆本体 | 包覆在导体外的聚氯乙烯(PVC)、交联聚乙烯(XLPE)或聚丙烯(PP)等材料，用于隔离导体、防止漏电和短路。（来源：Reflections from Wire 2026: Growing Momentum for PP Cable Materials） | 是 | 定期（1年）使用绝缘电阻测试仪测量相间及对地绝缘电阻值；观察外表有无龟裂、碳化痕迹。（来源：综合实践） | 当绝缘电阻值持续低于规定标准，或外表出现无法修复的贯穿性破损、大面积老化开裂时需报废。拆除时要注意避免扳折导体。（来源：综合实践） |
| 护套层 | 电缆本体 | 作为电缆的最外层保护，通常由耐磨、耐腐蚀、阻燃材料（如聚乙烯）制成。防止机械损伤、潮气和化学物质侵蚀。（来源：Electrical cable - Wikipedia） | 是 | 外观巡检（半年），检查有无鼠咬、破皮、鼓包；清洁表面积污。（来源：综合实践） | 当护套破损导致绝缘层外露、或出现严重硬化脆裂失去保护功能，且无法通过绝缘包扎修复时报废。拆除时应做好标记。（来源：综合实践） |
| 屏蔽层 | 电缆本体 | 位于绝缘层和护套层之间的金属编织网或铝箔，用于防止外部电磁干扰(EMI)和内部信号辐射，确保信号完整性。（来源：Structured Cabling and Media Distribution Diagram） | 否 | 巡检（1年），检查接地连接是否可靠；配合整体电缆测试屏蔽效能。（来源：综合实践） | 仅当发生开路或严重腐蚀导致屏蔽失效且无法重做接头时，随整根电缆一同报废。（来源：综合实践） |
| 铠装层 | 电缆本体 | 包裹在护套层内的钢带或钢丝编织层，用于增加电缆的机械强度和抗拉能力，防止挖掘或重物砸伤。（来源：Electrical cable - Wikipedia） | 否 | 巡检时检查铠装接地连接是否完好；在外力破坏处检查铠装是否锈蚀。（来源：综合实践） | 仅在机械损伤严重导致铠装断裂或深度锈蚀失去保护作用时，随整根电缆一同报废。（来源：综合实践） |
| 填充与成缆结构 | 电缆本体 | 用于多芯电缆中填充空隙、保持圆整度及固定缆芯位置的纤维绳或挤塑骨架，提升抗压和抗拉能力。（来源：综合实践） | 否 | 通常无需单独维护，仅在整根电缆受外力损伤后暴露检查是否吸水受潮。（来源：综合实践） | 一旦填充物受潮严重，导致内部绝缘性能下降时，需随整根电缆报废。（来源：综合实践） |
| 接线端子与连接器 | 电缆及接线系统 | 实现电缆与设备或电缆之间电气连接的机械部件，通过压接、焊接或螺纹紧固的方式实现低接触电阻的连接。（来源：苹果笔记本电源接口 MagSafe 的结构） | 否 | — | — |
| 铜鼻子/接线耳 | 接线端子与连接器 | 电缆末端压接的镀锡铜片，用于与设备桩头进行螺丝紧固连接，适用于大电流传输。（来源：综合实践） | 是 | 巡检（季度），使用力矩扳手检查紧固螺丝是否松动；观察接触面有无过热变色产生的氧化铜层；测量接触电阻。（来源：GB 50303-2015） | 若螺孔滑丝、压接管开裂，或接触面因严重电弧烧蚀导致无法可靠压紧，则进行报废。拆除时应先拆负荷侧后拆电源侧。（来源：综合实践） |
| 中间接头 | 电缆及接线系统 | 用于两段电缆互相连接的装置，常见形式有热缩式、冷缩式等，用来恢复连接处的绝缘、屏蔽和密封性能。（来源：综合实践） | 否 | — | — |
| 接头绝缘密封体 | 中间接头 | 由热缩管或冷缩硅橡胶管构成的复合绝缘层，包裹在导体连接处，对外提供爬电距离和密封防水。（来源：综合实践） | 是 | 巡检（半年，重点关注地沟内电缆），观察接头外皮有无变形、放电烧痕；使用红外测温仪检查接头温度，对比同负载其他部分。（来源：综合实践） | 当检测到内部存在击穿放电、持续高温过热，或密封失效导致进水受潮时，整只中间接头报废。拆除时需剥除对应部分电缆绝缘。（来源：综合实践） |
| 导体连接管 | 中间接头 | 位于接头内部中心，通过压接或螺栓剪切连接两段电缆导体的金属管，保证电流传导的通断。（来源：综合实践） | 否 | 无需单独日常保养。接头发生故障解体时检查是否因压接不紧密导致发热。 | 一旦熔焊或断裂，无法修复，随整只中间接头报废处理。对电缆重新做头并更换新的连接管。（来源：综合实践） |
| 终端头 | 电缆及接线系统 | 装设于电缆线路末端，用于保证电气安全距离、提供外绝缘和密封的装置。户外终端头常带雨裙。（来源：GB 50303-2015） | 否 | — | — |
| 应力控制部件 | 终端头 | 包裹于电缆绝缘切断处的部件（如应力锥），用于均匀电场分布，防止局部放电击穿。（来源：综合实践） | 是 | 巡检（1年），使用紫外成像仪检查是否有局部放电；观察应力锥表面是否有龟裂、积污。（来源：综合实践） | 一旦发生不可恢复的局部放电、出现老化裂纹导致内部受潮，需整只终端头报废。拆除时防止电缆绝缘层剥落。（来源：综合实践） |
| 绝缘子/雨裙 | 终端头 | 户外终端头的瓷套或硅橡胶伞裙，用于增大爬电距离并提供支撑，防止污水桥接造成闪络。（来源：综合实践） | 是 | 巡检（季度），擦拭表面灰尘；检查有无裂纹或破损；在大雾小雨后特别观察有无放电痕迹。（来源：综合实践） | 出现瓷套破碎、硅橡胶撕裂或老化失去憎水性，导致在大雾天气频繁闪络时，应报废更换。拆除需将电缆恢复至绝缘层。（来源：综合实践） |
| 电缆桥架/线槽 | 电缆及接线系统 | 由金属或非金属材料制成的连续刚性结构，用于支撑和保护敷设的电线电缆。（来源：GB 50303-2015） | 否 | — | — |
| 支架与吊架 | 电缆桥架/线槽 | 固定支撑线槽和桥架的横担、立柱和吊杆等金属构件，承受电缆及桥架自重。（来源：综合实践） | 否 | 巡检（半年），检查有无锈蚀、松动、变形；紧固螺栓；补涂防腐漆。（来源：综合实践） | 当支架发生大面积严重锈蚀导致结构强度不足、或受力变形无法校正时，需进行局部切除更换。（来源：综合实践） |
| 跨接与地线 | 电缆桥架/线槽 | 用于桥架伸缩缝及拼接处的铜编织带或黄绿导线，保证整个金属桥架系统的电气连续性及可靠接地。（来源：GB 50303-2015） | 是 | 巡检（季度），利用力矩扳手测试连接紧固性；测试跨接点导通电阻，不应明显大于同长度导线阻值。（来源：综合实践） | 出现编织线断裂、氧化松动失去导通性时，进行报废更换。断开旧跨接线时须确认旁路无感应电。（来源：综合实践） |
| 电缆保护管 | 电缆及接线系统 | 穿入电缆的金属或绝缘管材，用于保护电缆免受机械性挤压、磨损及外部火灾影响。（来源：GB 50303-2015） | 否 | 巡检（1年），检查管口有无割伤电缆护套、防水封堵是否脱落；金属管重点检查防腐层。（来源：综合实践） | 保护管出现严重腐蚀穿孔、机械性断裂无法修复时，需抽出电缆后拆除更换。（来源：综合实践） |
| 封堵系统 | 电缆及接线系统 | 在电缆贯穿墙体、楼板、柜体开孔处使用的防火泥、防火包或模块，用于防火、防小动物和防水汽蔓延。（来源：GB 50303-2015） | 是 | 巡检（半年），查看封堵泥有无干裂、塌陷脱落；检查有无鼠咬痕迹或缝隙。（来源：综合实践） | 出现大面积硬化、脱落，或因线路增容导致封堵不严时，需清除旧封堵材料并重新制作封堵。（来源：综合实践） |
