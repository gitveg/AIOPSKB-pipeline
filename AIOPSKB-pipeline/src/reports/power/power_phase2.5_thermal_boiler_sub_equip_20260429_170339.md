# 进度报告: power - phase2.5_thermal_boiler_sub_equip
> 时间: 2026-04-29 17:03:39

| 子设备名称 | 描述 |
| :--- | :--- |
| 火管锅炉（锅壳锅炉） | 烟气在管内流动加热管外的水，结构简单，适用于低压小容量场景，热效率相对较低。 |
| 水管锅炉 | 水在管内流动被管外的烟气加热，承压能力高，适合大容量高参数工况，热效率较高。 |
| 水火管锅炉 | 结合了水管与火管结构，燃烧室采用水管，对流受热面采用火管，兼具安全性与换热效率。 |
| 自然循环锅炉 | 依靠下降管和上升管中介质密度差形成水循环，结构成熟，广泛应用于电站和工业领域。 |
| 强制循环锅炉 | 借助炉水循环泵推动工质流动，适用于高压以上或需要快速启动的锅炉系统。 |
| 直流锅炉 | 无汽包设计，给水一次性流经受热面变为蒸汽，启停速度快，但对水质和自动控制要求极高。 |
| 层燃锅炉 | 固体燃料在固定或移动的炉排上形成料层燃烧，包含链条炉排、往复炉排等型式。 |
| 室燃锅炉 | 燃料呈粉状或雾化后悬浮在炉膛空间内燃烧，如煤粉锅炉、燃油/燃气锅炉，是电站锅炉的主流燃烧方式。 |
| 流化床锅炉 | 燃料在布风板上被气流吹起成流态化燃烧，包含鼓泡床与循环流化床，燃料适应性强，可实现炉内脱硫。 |
| 旋风锅炉 | 利用高速切向气流在圆柱形炉膛内形成强烈旋转燃烧，可燃烧粗煤粉或煤屑，燃烧强度高。 |
| 余热锅炉 | 回收工业废气、废液或工艺流程中的高温余热产生蒸汽，结构形式需与上游工艺设备高度匹配。 |
| 电加热锅炉 | 利用电阻或电磁感应加热产生蒸汽或热水，无燃烧排放，结构紧凑，运行安静。 |
| 生物质锅炉 | 燃烧生物质颗粒、秸秆或废弃物等再生燃料，通常配有针对性的炉拱和供料系统以应对高挥发分燃料。 |
| 蒸汽锅炉 | 输出介质为饱和或过热蒸汽，用于工业生产、驱动汽轮机等需要特定温度和压力蒸汽的场景。 |
| 热水锅炉 | 输出介质为高温或低温热水，主要用于采暖、中央空调及生活热水供应，运行压力相对较低。 |
| 汽水两用锅炉 | 可同时或分别产生蒸汽和热水，具有更高的使用灵活性，适用于用热需求多样的小型工业或民用场合。 |
| 电站锅炉 | 专为发电设计，通常为高参数、大容量的室燃或循环流化床锅炉，产生过热蒸汽驱动汽轮机发电。 |
| 工业锅炉 | 为工业生产过程提供蒸汽或热水，涵盖范围广，参数和容量跨度大，满足各行业工艺加热需求。 |
| 超临界压力锅炉 | 主蒸汽压力超过22.1MPa，工质在超临界状态下一次性相变，机组效率远高于亚临界锅炉。 |
| 导热油锅炉（有机热载体炉） | 以导热油为传热介质，可在低压下获得高温，安全性好，精确控温，常用于化工、纺织等行业。 |
| 立式锅炉 | 锅筒或锅炉主体纵向布置，占地面积小，结构紧凑，多用于小型工业或生活场景。 |
| 卧式锅炉 | 锅筒或锅炉主体横向布置，换热面布置灵活，容量范围广，是工业及电站锅炉的主流结构型式。 |
