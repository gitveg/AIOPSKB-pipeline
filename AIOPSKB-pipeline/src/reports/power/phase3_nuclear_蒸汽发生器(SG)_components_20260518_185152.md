| 蒸汽发生器（SG） | — | 将一回路热量传递给二回路给水，产生饱和蒸汽；由下封头、管束、汽水分离器、壳体等组成 | 否 | — | — |
| 下封头组件 | 蒸汽发生器（SG） | 分隔一回路进出口冷却剂，安装管板，形成一次侧水室 | 否 | — | — |
| 隔板 | 下封头组件 | 分隔水室为进口腔和出口腔，确保冷却剂流过管束 | 否 | 每次换料大修检查表面腐蚀，清理异物 | 隔板严重腐蚀或变形导致流量分配失衡，且无法修复时，整体更换封头内件；注意一回路去污与辐射防护 |
| 管板 | 下封头组件 | 固定U形传热管，隔离一、二回路压力边界 | 否 | 大修期间进行目视及涡流检查管孔区域，清理泥渣沉积 | 管板裂纹扩展到无法补焊或管孔变形导致传热管无法密封时，整体更换管板（需剖切壳体）；执行一回路去污与严格辐射控制 |
| 人孔密封垫片 | 下封头组件 | 保证一回路水室人孔的密封性 | 是 | 每次开盖后更换；安装前检查密封面，均匀预紧螺栓至规定力矩 | 垫片永久变形、开裂或回弹率不合格时立即更换，拆下按放射性废物处理 |
| 人孔盖 | 下封头组件 | 安装在下封头人孔处，承受一回路压力，用于检修人员进入水室 | 否 | 每次开盖后检查密封面凹坑、螺栓孔螺纹，清洁并涂抹防咬合剂 | 人孔盖整体腐蚀减薄超标、密封面无法修复或出现贯穿裂纹时整体更换；更换时执行一回路开口辐射防护措施，新盖液压试验后安装 |
| 管束组件 | 蒸汽发生器（SG） | 由数千根U形传热管和支撑板构成，实现热量从一回路向二回路的传递 | 否 | — | — |
| U形传热管 | 管束组件 | 一回路冷却剂在管内流动，通过管壁将热量传给二回路给水 | 是 | 每次换料大修进行涡流检测，监测壁厚减薄、裂纹、凹痕；化学清洗去除管外沉积物 | 当涡流检测显示壁厚减薄超过40％或出现贯穿性裂纹、泄漏时，采用堵管方式报废；堵管使用专用堵头焊接，确保一回路压力边界完整；堵管数量超过设计限值时需卸载降功率或更换蒸汽发生器 |
| 支撑板 | 管束组件 | 支撑传热管防止流致振动，保持管束间距，同时为二回路水提供流道 | 是 | 可视检查，评估管孔磨损、腐蚀；必要时进行振动特性测试 | 支撑板严重腐蚀开裂、管孔扩大导致传热管未支承长度超标时，需更换整个管束组件；更换时需切割壳体，取出旧管束，安装新管束并恢复压力边界 |
| 防振条 | 管束组件 | 抑制U形管弯头段的流致振动，防止微动磨损 | 是 | 定期内窥镜检查弯头区域，确认无松脱、断裂 | 防振条断裂、松动或严重磨损导致传热管出现微动磨痕时，可更换单个防振条；通常需部分抽管作业，注意一回路开口后的辐射防护 |
| 汽水分离装置 | 蒸汽发生器（SG） | 将汽水混合物中的水分分离，保证出口蒸汽干度 | 否 | — | — |
| 旋叶式分离器 | 汽水分离装置 | 利用离心力将汽水混合物初步分离，水甩向壁面回流，蒸汽上升 | 否 | 每次大修检查叶片腐蚀、结垢、堵塞；清洗水垢 | 叶片大面积断裂、腐蚀穿孔导致分离效率不可接受时，整体更换分离器单元；拆除时注意防止异物落入管束区 |
| 蒸汽干燥器 | 汽水分离装置 | 由波纹板组构成，进一步去除蒸汽中残留的水滴 | 否 | 检查波纹板变形、腐蚀、积水；清洗沉积物 | 波纹板严重腐蚀或变形导致出口湿度超标时，更换干燥器模块；拆卸时需保护下方管束，作业后清点异物 |
| 给水环管 | 蒸汽发生器（SG） | 将二回路给水均匀分配到管束热段，避免局部过热和管振动 | 否 | 每燃料循环进行目视检查，察看环管定位焊缝、出水孔冲蚀；清理孔堵塞 | 环管穿孔、断裂或出水孔严重冲蚀导致流量分配不均时，更换给水环；切割旧环管，焊接新环管，焊接接头需进行100%射线探伤 |
| 给水滤网 | 蒸汽发生器（SG） | 安装在给水环管前端，拦截给水中的颗粒杂质，防止传热管冲蚀和堵塞 | 是 | 每次换料大修拆检清洗，检查网面破损和压降；必要时反冲洗或化学清洗 | 滤网大面积破损、网孔严重变形或堵塞无法清洗至设计流量时，更换滤网组件；更换时注意防止异物进入给水管 |
| 壳体筒体 | 蒸汽发生器（SG） | 构成二回路压力边界的主要圆柱及锥形段，连接下封头与上封头，容纳管束与汽水分离器 | 否 | 每燃料循环超声测厚、焊缝检查；清理外壁氧化皮 | 筒体大面积减薄至最小壁厚、出现无法补焊的裂纹或大面积腐蚀坑时，整体更换筒段；切割壳体，保护内部构件，焊接后热处理，执行水压试验 |
| 底部排污管 | 蒸汽发生器（SG） | 从二回路侧管板最低点引出，定期排放含泥渣的炉水，防止沉积物堵塞传热管间隙 | 是 | 定期吹通排污管防止堵塞；每燃料循环检查内壁冲刷减薄和管座焊缝 | 排污管壁厚减薄至最小允许厚度或焊缝泄漏时，停堆后切割更换；注意系统放空和干燥，避免湿气进入管束 |
| 上封头及蒸汽出口接管 | 蒸汽发生器（SG） | 汇集蒸汽并输送至主蒸汽管道，承受设计温度和压力 | 否 | 定期检查封头内壁腐蚀、衬里脱落；对接管进行超声测厚 | 封头及接管严重减薄、裂纹扩展至不可接受程度时，更换相应部件；更换需进行热处理恢复力学性能，执行二回路压力试验 |
| 仪表接管 | 蒸汽发生器（SG） | 为水位、压力等测量仪表提供接管座，含根部加强板，构成二回路压力边界 | 否 | 定期检查接管根部焊缝，进行测厚；吹扫或冲洗水位计管线防止堵塞 | 接管腐蚀减薄至最小壁厚、焊缝泄漏或管座根部裂纹时，停堆后切割更换，焊接后局部热处理和NDE，水压试验 |
| 壳体法兰垫片 | 蒸汽发生器（SG） | 保证上下壳体连接处的密封，防止二回路工质外漏 | 是 | 每次拆卸后更换；安装前检查法兰密封面，清洁并均匀施加螺栓力矩 | 垫片老化、损坏或密封性能丧失时立即更换；旧垫片按非放射性工业废物处置 |
| 保温绝热层 | 蒸汽发生器（SG） | 敷设在壳体及封头外表面，减少散热损失，降低环境温度，保护人员安全 | 是 | 每月巡检外观，发现破损、脱落及时修补；大修时检查防水层完整性，更换浸水受潮部分 | 绝热层大面积破损、纤维材料失效或吸水导致壳体外部腐蚀时，全面拆除并更换；拆除时禁止敲击，使用吸尘设备防粉尘扩散，按非放射性工业废弃物处理 |
| 设备支座 | 蒸汽发生器（SG） | 支撑蒸汽发生器重量，承受地震及管道载荷，允许热膨胀位移 | 否 | 每次大修检查焊缝裂纹、地脚螺栓紧固、滑动面润滑与间隙 | 支座主体严重变形、开裂或滑动面卡涩无法修复时，需卸载设备后切割更换或加固；顶升设备前保证支承基础稳固 |
