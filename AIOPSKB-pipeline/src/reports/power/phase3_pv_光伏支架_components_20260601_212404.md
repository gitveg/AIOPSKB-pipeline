| 地面支架系统 | 光伏支架 | 安装于地面的支架形式，通常采用立柱、横梁、斜撑等组成，可分单柱或双柱结构，适用于大型电站（来源：[8]） | 否 | — | — |
| 屋顶支架系统 | 光伏支架 | 安装于平屋顶或斜屋顶的支架形式，常采用U型梁、三角套件和夹具等实现免穿透或配重安装（来源：[5]） | 否 | — | — |
| 平屋顶支架系统 | 屋顶支架系统 | 适用于平屋顶的免穿透安装系统，依靠三角架和配重底座固定，无需破坏屋面防水层，倾角预设（来源：[5]） | 否 | — | — |
| 斜屋顶支架系统 | 屋顶支架系统 | 适用于斜屋顶的安装系统，采用挂钩和导轨匹配屋面坡度，将组件平行或微倾安装于屋面之上（来源：[5]） | 否 | — | — |
| 立柱（单柱） | 地面支架系统 | 承受竖向载荷并将光伏组件支撑至设计高度的主要构件，材质多为镀锌钢或阳极氧化铝（来源：[8][9]） | 否 | 每季度目视检查柱体垂直度和防腐层，清理根部积水（来源：[8]） | 柱体弯曲变形超过1/100或出现贯穿性锈蚀时无法修复，需拆除基础锚栓，切割移除并更换（来源：[8]） |
| 横梁（主梁） | 地面支架系统 | 连接各立柱，承载导轨并将荷载传递至立柱的水平结构件，确保整列支架的平面度（来源：[8]） | 否 | 每季度检查横梁平直度和连接螺栓扭矩（参照安装手册），补刷局部锈蚀涂层（来源：[8]） | 横梁发生永久弯曲（挠度>L/200）或截面严重腐蚀减薄时，松开连接件，整体拆换，注意卸除组件荷载后操作（来源：[8]） |
| 导轨/檩条 | 地面支架系统 | 直接承托光伏组件的纵向构件，通过压块将组件固定，并将荷载传递至横梁，材质通常为铝合金或镀锌钢（来源：[9]） | 否 | 每季度检查导轨直线度、防腐层及与横梁连接的螺栓紧固情况（来源：[9]） | 导轨出现严重腐蚀、变形或滑槽损坏导致无法固定组件时，需在卸除组件后分段拆换（来源：[9]） |
| 斜撑/拉杆 | 地面支架系统 | 提供侧向稳定，抵抗风载和地震作用，防止支架整体倾覆，常见交叉拉杆或三角撑（来源：[9]） | 否 | 每半年巡检一次，检查杆件有无松弛、变形，及时紧固花篮螺栓或锁紧螺母（来源：[9]） | 斜撑弯曲、断裂或连接孔撕裂时，无法直接修复；需在无风天气，临时加固后拆卸，回收钢材或报废（来源：[9]） |
| 基础（螺旋桩/混凝土） | 地面支架系统 | 将支架荷载传递至地基，螺旋桩用于快速安装，混凝土基础用于承载较大或冻土区域（来源：[8]） | 否 | 每年检查一次桩基沉降、倾斜，清除周围杂草和积水；混凝土基础检查裂纹（来源：[8]） | 桩基沉降超设计允许值或混凝土基础严重开裂、酥碎无法修复时，需重新打桩或浇筑，拆除时注意避开电缆（来源：[8]） |
| 组件压块/夹具 | 地面支架系统 | 将光伏组件可靠固定在导轨上的铝合金或不锈钢夹持件，并设有接地刺破点（来源：[9]） | 是 | 每次大风后检查压块螺栓是否松动，使用扭矩扳手校验（一般25-30N·m），更换锈蚀严重的紧固件（来源：[9]） | 压块变形导致组件滑移或接地失效、螺栓滑丝无法紧固时，将组件临时固定后逐一更换，旧件作为金属回收（来源：[9]） |
| 螺栓/紧固件 | 地面支架系统 | 用于支架各构件连接的镀锌或不锈钢螺栓、螺母、垫片，承受交变载荷（来源：[8]） | 是 | 每半年按30%比例抽检螺栓扭矩，发现松动立即复紧；对锈蚀紧固件涂抹防锈油或更换（来源：[8]） | 螺栓出现显著锈蚀减薄、螺纹损坏无法拧紧时，必须成套更换，拆除时防止组件移动，使用扭力扳手按规范安装（来源：[8]） |
| U型梁（导轨） | 平屋顶支架系统 | 承载光伏组件的纵向导轨，截面常为U型或C型，用压块固定组件，底部与三角架或夹具连接（来源：[5]） | 否 | 每季度检查导轨直线度、防腐层，检查与三角架连接螺栓（来源：[5]） | 导轨严重腐蚀或变形导致组件安装面不平整时，需拆下组件后更换单根导轨，注意载荷均衡（来源：[5]） |
| 三角架（支撑腿） | 平屋顶支架系统 | 提供设定倾角的三角形支撑结构，将U型梁连接至底座或夹具，常见于平屋顶免侵入安装（来源：[5]） | 否 | 每半年检查三脚架焊接点或螺栓连接，查看有无开焊、变形；清洁接触面（来源：[5]） | 三角架出现开焊、整体变形或连接孔断裂时，不能修复；卸除上部荷载后整体拆除，结构件废钢处理（来源：[5]） |
| 配重底座 | 平屋顶支架系统 | 放置于屋面，利用自身重量抵抗风吸力的混凝土或金属压载块，避免使用穿透固定（来源：[5]） | 是 | 每年检查一次底座是否位移，清理底座下积水及杂物，确保接触面贴合（来源：[5]） | 底座碎裂、严重风化或出现结构性裂纹无法承重时，需按原设计重量和规格更换预制块，逐一替换，防止支架失稳（来源：[5]） |
| 屋顶夹具 | 平屋顶支架系统 | 用于夹持屋面波峰的夹具，配合配重底座实现免穿透安装（来源：[5]） | 是 | 每季度检查夹具紧固情况、橡胶垫老化状况，必要时更换（来源：[5]） | 夹具锈蚀严重或橡胶垫老化龟裂导致夹持力不足时，需逐个更换（来源：[5]） |
| 屋面挂钩 | 斜屋顶支架系统 | 与屋面檩条或椽子固定，承受组件和导轨载荷，穿透屋面瓦片后需做好防水处理的不锈钢构件（来源：[5]） | 否 | 每年检查挂钩固定处防水密封是否老化、渗漏；检查与导轨连接的螺栓紧固情况（来源：[5]） | 挂钩明显变形、锈蚀或固定点防水反复失效无法修复时，需揭开局部瓦片，移除旧挂钩，换新并重做防水（来源：[5]） |
| 斜屋顶导轨 | 斜屋顶支架系统 | 平行于屋面安装，承载并固定光伏组件的轻质化铝型材导轨，通常顺坡面铺设（来源：[5]） | 否 | 每季度检查导轨防腐层及接头处的平整度，确保组件无异常应力（来源：[5]） | 导轨挤压变形、严重腐蚀或连接槽口损毁致无法固定组件时，需拆下受影响组件，更换整条导轨（来源：[5]） |
| 防腐涂层 | 光伏支架 | 镀锌、阳极氧化或涂装层，保护钢结构免受大气腐蚀，直接影响支架寿命（来源：[9]） | 是 | 每年全面检查涂层破损面积，局部除锈后补涂富锌漆；热浸锌构件注意避免碰损（来源：[9]） | 涂层大面脱落、基材出现深锈坑（深度超壁厚10%）且无法通过补涂恢复保护时，无独立报废，构件整体按相应部件报废处理（来源：[9]） |
