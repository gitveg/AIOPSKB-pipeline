# 进度报告: petrochemical - phase2.5_合成树脂_eq_2931_sub_equip
> 时间: 2026-05-02 18:51:26

| 子设备名称 | 描述 |
|---|---|
| 湿法高剪切造粒机 | 通过搅拌桨高速剪切将粉体与粘合剂液体快速混合制成高密度颗粒，常串联流化床干燥，是制药工业主流制粒设备。 |
| 流化床造粒机 | 利用热气流使粉料呈流态化，并通过顶喷/底喷/侧喷粘合剂完成造粒、干燥与包衣，适用于制药、食品和化工颗粒。 |
| 单罐式造粒干燥机 | 在同一罐内完成混合、造粒与真空干燥，可借助微波辅助干燥，适合溶剂法造粒及对水分敏感物料的小规模生产。 |
| 干法辊压造粒机 | 通过两根对压辊将粉末压实成条或片，再经粉碎、整粒得到均匀颗粒，全程无水无热，适用于水敏或热敏物料。 |
| 熔融造粒机 | 用可熔融的粘合剂代替液体粘合剂，依靠高剪切混合摩擦热或夹套加热使粘合剂熔化后包裹粉料，随后冷却形成颗粒。 |
| 连续造粒系统 | 由连续喂料、高剪切湿法制粒和分段干燥模块组成，制造过程实时控制，产物质量一致，适用于质量源于设计（QbD）工艺。 |
| 圆盘（转鼓）造粒机 | 利用倾斜旋转的圆盘（或转鼓）使粉料滚动、粘结和成球，颗粒圆整度高，广泛用于肥料、矿石和饲料行业。 |
| 搅齿造粒机 | 通过旋转的搅拌齿对物料进行强力挤压和搓动使其成粒，适用于有机肥、粘土等粘性物料的大产量造粒。 |
| 喷雾造粒机 | 将料浆或溶液通过雾化器喷入热风中，瞬间干燥成球形颗粒，一次性完成造粒与干燥，适合热敏性物料如药品、奶粉。 |
| 环模/平模挤压造粒机 | 利用压辊将粉料强行挤入环形（或平形）模具孔，挤出条状料后切断成颗粒，是饲料和生物质燃料制粒的标准设备。 |
| 塑料挤出造粒机（拉条/水下/模面热切） | 通过单/双螺杆挤出机将塑料熔融塑化，经模头挤出后采用冷切（拉条切粒）、水环或水下热切等方式制成塑料粒子。 |
| 回收塑料压实造粒系统 | 将破碎、压实、塑化和造粒功能一体化，适用于薄膜、拉菲草、废丝等低堆密度废塑料的再生造粒，节能高效。 |
| 滚筒式压实造粒机 | 卧式旋转滚筒使粉末原料在无粘结剂条件下通过压实和旋转成粒，用于化工、工程塑料和填料等物料的致密化造粒。 |
| 对辊成型造粒机 | 采用高压对辊将污泥、粉煤灰等工业固废挤压成料块或条状颗粒，用于废弃物无害化、减量化预处理及资源化利用。 |
