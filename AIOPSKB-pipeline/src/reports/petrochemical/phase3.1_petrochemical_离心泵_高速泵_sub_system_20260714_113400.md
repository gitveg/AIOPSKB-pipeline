# 进度报告: petrochemical - phase3.1_petrochemical_离心泵_高速泵_sub_system
> 时间: 2026-07-14 11:34:00

| 子系统名称 | 描述 |
| :--- | :--- |
| 动力输入与增速系统 | 负责连接电动机等原动机，通过增速齿轮箱将输入转速提升至泵工作所需的高转速，并将扭矩传递至泵轴。该系统包含联轴器及齿轮副，实现高效的动力传递与转速匹配。 |
| 过流增压系统 | 由叶轮、蜗壳及诱导轮等过流部件组成，通过叶轮高速旋转使液体获得动能，并在蜗壳内将动能转换为压力能，完成介质从进口到出口的增压输送。 |
| 转子与支承系统 | 包括主轴及高速推力轴承、径向轴承等，为全转子提供稳定的旋转支承，承受并平衡叶轮产生的轴向力与径向力。根据搜索结果，高速轴系统常配置双向倾斜瓦轴承，以适应高吸入压力工况下的长期运行。 |
| 轴端密封系统 | 安装在泵轴穿出泵壳处，通过机械密封、干气密封或其组合，建立起隔离介质与环境的可靠屏障，防止被增压介质沿轴向泄漏，并阻断空气进入泵内。 |
| 润滑与冷却系统 | 为增速齿轮和高速轴承提供强制循环的清洁润滑油，降低摩擦与磨损，并通过内置冷却器或外接换热装置带走高速运转产生的热量，确保运动部件始终处于安全工作温度。 |
| 机组监控与保护系统 | 集成转速、振动、温度及进出口压力等多种传感器，实时采集机组运行状态数据，实现参数越限报警、自动停机及状态趋势分析，保障高速泵在异常工况下自动连锁保护。 |
