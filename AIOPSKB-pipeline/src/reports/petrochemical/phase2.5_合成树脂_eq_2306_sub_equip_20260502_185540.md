# 进度报告: petrochemical - phase2.5_合成树脂_eq_2306_sub_equip
> 时间: 2026-05-02 18:55:40

| 子设备名称 | 描述 |
| :--- | :--- |
| 终缩聚釜 (Finisher) | 用于缩聚反应的最后阶段，通常采用卧式分室结构，在高真空及高温下处理高粘度熔体，确保产物达到最终聚合度。 |
| 预缩聚釜 (Pre-polycondensation Reactor) | 连接酯化与终缩聚的中间反应器，在较低真空条件下初步脱除小分子，为终缩聚提供合适粘度的预聚物。 |
| 列管式降膜缩聚釜 (Falling-film Tubular Reactor) | 利用列管结构使熔体在管内或管外形成降膜流动，具有极大的传质比表面积，能高效脱除小分子以快速提升分子量。 |
| 四釜/五釜连续缩聚装置 (Multi-stage Continuous Reactor System) | 由多个反应器串联组成的连续流程（如两酯化釜、两预缩聚釜、一终缩聚釜），通过分段精确控制温度和真空度，适合大规模稳定生产。 |
| 单釜/双釜间歇装置 (Batch Polymerization Reactor) | 在单一或两个釜内完成全部缩聚阶段，设备结构相对简单且操作灵活，适用于小批量、多品种的特种缩聚物生产。 |
| 圆形立式搅拌釜 (Vertical Agitated Polymerization Vessel) | 经典立式圆体封头釜型，配备强力搅拌器，主要应用于缩聚初期或中期阶段，处理中低粘度的反应体系。 |
| 笼式/网式搅拌反应釜 (Cage/Grid Agitated Reactor) | 专为高粘环境设计，其搅拌器呈笼状或网式结构，能促进熔体表面更新，在终缩聚阶段兼具高效脱挥功能。 |
| 双轴/多轴自清洁反应釜 (Twin-shaft Self-cleaning Reactor) | 其双轴或多轴相互啮合的搅拌设计能有效防止高粘物料在器壁上粘附滞留，具有极强的高粘相混合与传热能力。 |
| 板式降膜蒸发器 (Plate Falling-film Evaporator) | 采用板式降膜元件替代管式结构，成膜均匀且压降低，适用于要求极高比表面积和低停留时间的缩聚脱挥强化。 |
| 圆盘反应器 (Disc Ring Reactor) | 内部由多层圆盘/环板构成，允许气液逆流接触，专为高粘聚合物的终缩聚而设计，能平稳输送物料并提供巨大的自由蒸发表面。 |
| 薄膜蒸发器 (Thin-film Evaporator) | 利用旋转刮板或铰链叶片将物料刮成高度湍动的薄膜，配合真空实现秒级高效脱挥，常用于热敏性缩聚物的后处理或增粘。 |
| 卧式多室缩聚釜 (Horizontal Multi-chamber Polycondensation Reactor) | 卧式釜体内分隔为多个反应室，物料呈活塞流逐室推进，有效防止高粘物的返混，确保窄分子量分布。 |
| 卧式双轴盘式反应器 (Horizontal Twin-shaft Disc Reactor) | 双轴带动交错或啮合的圆盘旋转，兼具极强的自清洁、表面更新和轴向输送能力，是大规模熔融缩聚的关键装备。 |
