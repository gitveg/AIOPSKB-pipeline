# 进度报告: petrochemical - phase2.5_化肥_eq_2906_sub_equip
> 时间: 2026-05-02 19:34:19

| 子设备名称 | 描述 |
| :--- | :--- |
| 搅拌造粒机 | 利用圆盘、转鼓或锥形筒的回转搅拌，使粉末与液体粘合剂在滚动中团聚成粒。其中圆盘造粒机在倾斜旋转盘内靠离心力与摩擦力滚动成球，颗粒均匀强度高，为肥料与冶金球团核心设备；转鼓造粒机在倾斜旋转筒体中通蒸汽或喷洒粘合剂翻滚团聚，产量大、连续化程度高，用于大宗化肥。设备整体结构简单，单机产量大，但颗粒均匀性相对较差。 |
| 流化床造粒机 | 通过底部吹入的热风将粉料流化悬浮，结合顶部喷入的粘合剂液滴，在干燥同时一步完成造粒，所得颗粒疏松、溶解性好，多用于制药与食品行业。 |
| 喷雾干燥造粒机 | 将液态浆料通过喷嘴雾化成微小液滴，在高温热风中瞬间蒸发干燥形成多孔颗粒，适用于连续化大规模生产速溶类产品，但设备体积庞大，能耗较高。 |
| 压力成型造粒机 | 通过模压、挤压或辊压等方式对粉体物料施加外部压力使其密实成粒，成品颗粒具有强度高、粒度均匀的优点。包括：对辊挤压造粒机（干粉在相向旋转辊间高压成片后破碎筛分，无需液体粘合剂，适用于热敏性或遇水反应物料）、挤出滚圆造粒机（湿粉料挤出成条切断后，在离心滚圆盘中抛掷滚制成高真球度、高密度微丸）及螺杆挤出造粒等子类。 |
| 热熔融造粒机 | 将熔融状态的物料（如硫磺、石蜡、树脂）通过布料器均匀滴落在匀速运动的钢带上，经背面水冷固化形成片状或半球状颗粒，常用于化工与热溶胶领域。 |
| 混合造粒机 | 集高剪切混合、捏合与造粒功能于一体，能在同一设备内同步完成粉体混合与颗粒制备，易控制颗粒强度与粒径，生产效率高，适用于陶瓷、耐材等行业。 |
| 单锅造粒干燥机 | 将高剪切混合造粒与真空/微波干燥功能集成在单个密闭锅体内，可在不转移物料的情况下完成制粒与干燥，有效防止交叉污染，适于高致敏性或含有机溶剂的制药工艺。 |
| 塑料回收挤出造粒机 | 采用单螺杆或双螺杆挤出机将废塑料熔融塑化，经精密过滤后通过模头挤出，再经切粒方式制成可再生颗粒。切粒方式包括水环热切、水下拉条切、冷切等；其中冷切造粒是将挤出片材经水槽冷却硬化后由切粒机切成规则颗粒，适用于PET、ABS等共混改性塑料。广泛用于PE、PP、PET等塑料循环再生。 |
