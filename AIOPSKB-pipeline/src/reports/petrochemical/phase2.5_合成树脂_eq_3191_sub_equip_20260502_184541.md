# 进度报告: petrochemical - phase2.5_合成树脂_eq_3191_sub_equip
> 时间: 2026-05-02 18:45:41

| 子设备名称 | 描述 |
|-------------|------|
| 单螺杆挤出机 | 利用单根螺杆在加热料筒中旋转输送和塑化物料，结构简单，广泛用于通用挤出成型。 |
| 平行同向双螺杆挤出机 | 两根螺杆同向旋转且全啮合，混炼和分散能力强，主要用于共混改性与造粒。 |
| 平行异向双螺杆挤出机 | 两根螺杆异向旋转且啮合，剪切温和、输送稳定，适合热敏性物料及型材挤出。 |
| 锥形双螺杆挤出机 | 两根锥形异向旋转螺杆，加料段直径大、压缩比高，特别适用于PVC型材挤出。 |
| 三螺杆挤出机 | 三根平行螺杆啮合同向旋转，增加揉捏次数和界面更新，低能耗高产量，用于高填充混炼。 |
| 双阶串联挤出机 | 上阶用双螺杆快速混炼塑化，下阶用单螺杆低速建压挤出，适合热敏或高填充物料。 |
| 往复式单螺杆挤出机 | 螺杆在旋转的同时做轴向往复运动，通过销钉与螺棱相互作用实现良好分散混合，常用于色母粒和填充改性。 |
| 柱塞式挤出机 | 无螺杆，靠柱塞推压物料通过模具，结构简单但塑化效果差，主要用于聚四氟乙烯等难塑化材料挤出。 |
| 单螺杆排气挤出机 | 在单螺杆机筒上设有排气口和排气段，能够在线排除物料中的水分、单体及挥发分，适合吸湿性或脱挥需求物料。 |
| 非啮合异向双螺杆挤出机 | 两根异向旋转螺杆不啮合或部分啮合，物料在两螺杆间交换对流，分布混合温和且排气面积大，适用于高填充脱挥和反应挤出。 |
