# 进度报告: petrochemical - phase3.1_petrochemical_压缩机_往复式压缩机_sub_system
> 时间: 2026-07-16 15:19:58

| 子系统名称 | 描述 |
| :--- | :--- |
| 传动子系统 | 负责将外部驱动端的旋转动能转换为活塞的直线往复运动。主要由曲轴、连杆、十字头及主轴承等部件构成，承受交变载荷并精确控制活塞的行程规律与运动时序，是往复式压缩机的核心动力传递机构。 |
| 压缩子系统 | 通过活塞在气缸内的往复运动，配合进气阀与排气阀的周期性自动开闭，依次完成气体的吸入、封闭压缩与高压推出，是直接实现气体增压的核心功能单元，主要包括气缸、活塞、气阀等部件。 |
| 密封子系统 | 核心功能是防止压缩气体在压缩过程中的泄漏，保证容积效率与运行安全。包括用于活塞与气缸壁之间密封的活塞环，以及用于密封活塞杆与缸体间隙的填料函，适配多种工况下的动密封要求。 |
| 冷却子系统 | 专门用于对压缩过程中产生高温的气缸、缸盖及压缩气体进行强制散热。通常采用冷却水套或风冷翅片结构，旨在控制排气温度、防止润滑油炭化及析碳，从而提升压缩机的热力性能与运行可靠性。 |
| 润滑子系统 | 持续向曲轴、连杆大头瓦、十字头滑道及活塞环等各摩擦副供应清洁的加压润滑油，以形成有效油膜减少磨损，同时辅助带走摩擦热量并冲洗杂质。部分工艺压缩机对气缸采用无油或微油润滑设计。 |
| 控制与保护子系统 | 集成压力、温度等传感器与逻辑控制器，对压缩机的启停、卸荷与气量进行自动调节；同时配置安全阀、报警及联锁装置，实现超压、超温等异常工况下的即时保护，确保设备处于安全、受控的运行状态。 |
