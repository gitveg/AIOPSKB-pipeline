# 进度报告: petrochemical - phase2.5_石油炼制_eq_9600_sub_equip
> 时间: 2026-05-02 18:04:56

| 子设备/技术路线名称 | 描述 |
| :--- | :--- |
| 固定床渣油加氢反应器 | 催化剂以固定颗粒形式分层填装于反应器内，形成静态床层。工艺成熟度高、应用最广泛，但对原料杂质含量要求较严格。 |
| 沸腾床（膨胀床）渣油加氢反应器 | 通过流体流速使催化剂颗粒在反应器内处于悬浮的“沸腾”运动状态，可在线更换催化剂。相比固定床，能够处理金属含量和残炭值更高的劣质渣油，实现深度转化。 |
| 浆态床（悬浮床）渣油加氢反应器 | 采用粉末状催化剂与原料油预先混合形成浆态体系，自下而上流动进行反应。原料适应性最强，渣油转化率可达90%以上，反应器结构简单，无床层堵塞风险，但催化剂回收和运行成本较高。 |
