# 进度报告: petrochemical - phase2.5_化肥_eq_4421_sub_equip
> 时间: 2026-05-02 19:35:59

| 子设备名称 | 描述 |
| :--- | :--- |
| **固定床间歇式气化炉** | 以无烟块煤或焦炭为原料，采用空气和蒸汽交替送风制取半水煤气，工艺成熟但吹风气排放量大。 |
| **固定床连续式气化炉（碎煤加压）** | 以碎煤为原料，在加压条件下连续气化，可处理褐煤等劣质煤，但产生的煤气洗涤水含酚、焦油等污染物。 |
| **流化床粉煤气化炉（如恩德炉）** | 利用粉煤在沸腾状态下与气化剂反应，气化强度高，对原料煤的粒径和粘结性有一定要求。 |
| **水煤浆加压气化炉（如GE、多喷嘴）** | 将煤制成浓度约60-65%的水煤浆，在高压下与纯氧进行部分氧化反应，技术成熟，气化效率高。 |
| **粉煤加压气化炉（如壳牌、GSP）** | 采用干煤粉与纯氧在高压下载流床中反应，碳转化率高，有效气成分高，但对原料干燥和输送系统要求高。 |
| **天然气一段转化炉（顶烧/侧烧）** | 在含镍催化剂作用下，利用外部燃烧供热将烃类蒸汽转化为合成气，炉管需耐高温合金钢。 |
| **天然气二段转化炉（自热式）** | 在一段转化气中直接通入空气，利用部分氢气燃烧为残余甲烷提供转化热量，是合成氨中温度最高的反应设备。 |
| **重油部分氧化炉** | 将重油或渣油与氧气、蒸汽混合，在高温下发生部分氧化反应生成合成气，对喷嘴及耐火衬里要求高。 |
| **焦炉气转化炉** | 以炼焦副产的焦炉气为原料，经净化、蒸汽转化及补充氮气后制取合成气，属废物资源化利用。 |
| **新型高炉/转炉煤气转化装置** | 以钢铁冶炼副产的高炉煤气或转炉煤气为原料，经净化重整后制取合成氨原料气，实现区域废气循环利用。 |
