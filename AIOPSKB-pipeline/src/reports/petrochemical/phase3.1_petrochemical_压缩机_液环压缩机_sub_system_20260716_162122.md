# 进度报告: petrochemical - phase3.1_petrochemical_压缩机_液环压缩机_sub_system
> 时间: 2026-07-16 16:21:22

| 子系统名称 | 描述 |
|------------|------|
| 驱动与传动系统 | 将电动机等原动机的旋转动力传递给压缩机主轴，包含驱动电机、联轴器或皮带轮等传动部件。其功能边界止于主轴输入端，确保转子获得稳定转速和扭矩，实现整机的动力注入。 |
| 压缩主机系统 | 由壳体、转子、叶轮及液环共同构成的核心压缩单元，通过转子旋转形成偏心液环，使工作腔容积周期性变化，完成气体吸入、压缩和排出的全过程，是气体增压的核心功能模块。 |
| 工作液管理子系统 | 负责向压缩主机供给并维持形成液环所必需的密封液（通常为水或其它工艺液体），同时通过气液分离器回收排气携带的液滴，实现工作液的补充、分离和初步净化，封闭在主机与分离设备之间。 |
| 冷却与热管理子系统 | 带走压缩过程产生的热量，维持工作液及压缩气体温度在允许范围内。通常由换热器、冷却介质管路及温度调节阀组成，可串接在工作液循环回路或气体排出路径中对液体或气体直接进行冷却。 |
| 控制与监测保护系统 | 实时采集压力、温度、液位、振动等运行参数，通过控制器或继电器逻辑对启停、加载卸载、补液及故障报警进行自动管理，并驱动安全阀、联锁停机等保护动作，保障机组在安全边界内运行。 |
| 支撑与辅助系统 | 提供设备整体结构支撑与管路连接，包括公共底座、地脚螺栓、进排气法兰、排污管路、仪表现场安装附件及隔音罩等辅助设施，确保各功能子系统定位准确、连接可靠且便于现场布置和维护。 |
