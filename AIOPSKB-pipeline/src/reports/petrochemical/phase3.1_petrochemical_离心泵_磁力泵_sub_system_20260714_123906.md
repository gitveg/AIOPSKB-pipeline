# 进度报告: petrochemical - phase3.1_petrochemical_离心泵_磁力泵_sub_system
> 时间: 2026-07-14 12:39:06

| 子系统名称 | 描述 |
| :--- | :--- |
| 动力输入系统 | 包含电动机及联接结构，将电能转化为旋转机械能，为磁力泵提供稳定扭矩与转速。功能边界界定至电机输出轴，与磁力传动系统外磁转子相连，不包含传动过程及流体介质端。 |
| 磁力传动系统 | 由外磁转子、隔离套和内磁转子组成，利用磁场穿透隔离套实现无接触扭矩传递，驱动泵端旋转。作为无泄漏静密封核心单元，完全替代传统机械密封，实现动力与介质的安全隔离。 |
| 过流泵送系统 | 涵盖叶轮、蜗壳、泵盖及进出口等过流部件，通过叶轮旋转产生离心力，将机械能转化为流体动能与压力能。边界包括所有与介质直接接触并参与液体吸入、加速与加压排放的零件。 |
| 转子支撑系统 | 由泵轴、径向滑动轴承、止推轴承及轴套组成，承受叶轮与内磁转子的径向及轴向载荷。功能为精确维持旋转与静止部件运转间隙，保证回转精度与水力效率，并将载荷传递至基座。 |
| 密封隔离系统 | 以隔离套为主体，配合O型圈等静密封元件，将泵内介质与外界及电机完全隔离。提供绝对静密封边界，是磁力泵实现零泄漏、保障危险和有毒介质安全输送的关键功能模块。 |
