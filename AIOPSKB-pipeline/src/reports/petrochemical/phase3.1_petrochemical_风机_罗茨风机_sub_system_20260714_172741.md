# 进度报告: petrochemical - phase3.1_petrochemical_风机_罗茨风机_sub_system
> 时间: 2026-07-14 17:27:41

| 子系统名称 | 描述 |
| :--- | :--- |
| 驱动系统 | 提供罗茨风机旋转所需的机械动力，通常由电动机或内燃机组成，通过联轴器或皮带轮将扭矩传递至风机主动轴。其边界涵盖原动机及其与风机主机的连接部件，确保稳定的转速和转矩输出。 |
| 风机主机 | 核心压缩功能模块，由机壳、一对相互啮合的叶轮（如三叶型）、主动轴、从动轴及同步齿轮构成。通过叶轮在机壳内同步反方向旋转，周期性地形成工作容积，完成气体从吸入到排出的无内压缩输送过程。 |
| 润滑系统 | 负责向同步齿轮啮合面及转子轴端轴承提供润滑油，以减少摩擦磨损并带走热量。常见为内置飞溅润滑或外置强制循环润滑方式，功能边界包括油箱、油泵、过滤器及供油管路，确保传动件得到充分润滑。 |
| 冷却系统 | 控制风机在运行中的工作温度，防止因气体压缩及摩擦导致的过热。包含风冷式（通过散热片及冷却风扇）或水冷式（如水冷罗茨风机设备中的循环水套及管路），覆盖整机及气体的降温，保障设备在热允许范围内可靠运行。 |
| 进排气系统 | 管理气体的进入与排出，包含进气过滤器、进气消音器、排气消音器及安全阀等。该子系统确保洁净气体被吸入，并降低气动噪声，同时通过管道接口连接外负载，实现气力输送或通风功能。 |
| 控制系统 | 对罗茨风机进行运行监测与逻辑控制，包含启动停止、参数显示（温度、压力、振动）、过载保护及报警连锁。通过电控柜、传感器及执行器，实现手动/自动操作，保障设备安全，并可与上位分散控制系统（DCS）集成。 |
