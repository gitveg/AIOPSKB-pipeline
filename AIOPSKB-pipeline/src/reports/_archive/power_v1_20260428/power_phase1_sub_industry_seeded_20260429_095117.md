# 进度报告: power - phase1_sub_industry_seeded
> 时间: 2026-04-29 09:51:17

基于专业判断，用户提供的“火电、水电、风电、核电、光伏、输电、变电、配电、储能”九个子行业已经覆盖了电源和电网的主要环节，但也存在一些在当前电力格局中日益重要的领域未被纳入。建议在保持原有分类不变的基础上，补充以下子行业，以使行业划分更全面、更具时代特征。

| 子行业名称 | 描述 |
|---|---|
| 火电 | 利用煤炭、石油、天然气等化石燃料燃烧产生的热能发电，是当前基荷电力的主力电源。 |
| 水电 | 利用江河水流势能或动能推动水轮机组发电，包含常规水电与抽水蓄能（此处尊重用户原有分类，抽蓄也可在储能中体现）。 |
| 风电 | 将风能转换为机械能再转换为电能，分为陆上风电与海上风电。 |
| 核电 | 通过核裂变释放热能产生蒸汽驱动汽轮机组发电，具有清洁、高能量密度的特点。 |
| 光伏 | 利用半导体材料的光生伏特效应直接将太阳光能转化为电能，包括集中式与分布式光伏。 |
| 输电 | 将发电厂发出的电能通过高压或超高压网络进行远距离输送，连接电源与负荷中心。 |
| 变电 | 通过变电站实现电压等级变换、电能汇集与分配，是电网的关键枢纽。 |
| 配电 | 将电能从变电站逐级配送到终端用户，包含中低压配电网及配网自动化系统。 |
| 储能 | 通过物理或化学方式存储电能并在需要时释放，涵盖抽水蓄能、电化学储能、压缩空气储能等多种形式。 |
| 生物质发电 | 将农林废弃物、城市垃圾、沼气等生物质能通过燃烧或发酵等方式转化为电能，是可再生能源的重要补充。 |
| 电力市场与售电 | 围绕电力商品交易、零售服务及辅助服务市场展开，是电力体制改革和新型电力系统运行的核心环节。 |
| 智能电网与电力数字化 | 运用传感、通信、大数据、人工智能等技术实现电网的智能感知、控制与优化，涵盖调度自动化、虚拟电厂、微电网等新兴形态。 |

**补充说明：**
- **生物质发电**在我国装机容量和发电量中已形成稳定的细分市场，且与“火电”“水电”等并无明确包含关系，因此建议独立列出。
- **电力市场与售电**是发输配储之外的独立商业环节，随着电力现货市场、绿电交易、需求侧响应等快速发展，已成为影响行业格局的关键领域。
- **智能电网与电力数字化**反映了当前电网升级的核心理念，将变电、配电的智能化延伸与新技术业态（如虚拟电厂、微电网、车网互动）纳入统一视角，避免分散在原有粗粒度划分中而被忽视。

以上补充均未与用户原有的九个子行业重叠，且符合新型电力系统建设的逻辑框架。
