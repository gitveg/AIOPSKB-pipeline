# 进度报告: power - phase1_sub_industry
> 时间: 2026-04-29 10:23:11

评估用户的电力行业子行业划分，覆盖了发电侧主流能源类型、输配环节和储能，整体框架合理。但发电侧目前主要吸纳了一次能源中规模最大的几种形式，遗漏了同样具备一定体量且政策支持力度较大的生物质发电。因此，补充“生物质发电”一项，使可再生能源品类更完整。其他环节无遗漏。

| 子行业名称 | 描述 |
|---|---|
| 火电 | 以煤、天然气、石油等化石燃料燃烧产生的热能驱动汽轮机发电，是当前电力系统的基荷主力。 |
| 水电 | 利用河流、湖泊等水体的势能或动能，通过水轮机转换为机械能再带动发电机发电，是最成熟的清洁可再生电源。 |
| 风电 | 将风能通过风力机转换为机械能，再驱动发电机产生电能，包含陆上风电和海上风电。 |
| 核电 | 利用核裂变或核聚变释放的热能产生蒸汽，驱动汽轮发电机组发电，具有高能量密度、低碳排放的特点。 |
| 光伏 | 利用半导体界面的光生伏特效应，将太阳光能直接转换为电能，包括集中式光伏电站和分布式光伏。 |
| 生物质发电 | 将农林废弃物、城市生活垃圾、沼气等生物质资源通过直接燃烧、气化或厌氧发酵等方式转化为电能，是零碳或低碳的可再生能源。 |
| 输电 | 通过高压或特高压线路，将发电厂产生的电能进行远距离、大容量输送，连接发电侧与负荷中心。 |
| 变电 | 通过变电站内的变压器等设备，实现电压等级的升降和电网的互联，是电力系统电压变换与分配的关键节点。 |
| 配电 | 将来自输电网或本地电源的电能，经过中低压配电网逐级分配至终端用户，是电力服务的“最后一公里”。 |
| 储能 | 通过抽水蓄能、电化学储能、压缩空气储能等方式，实现电能的时空转移和功率调节，提升电力系统的灵活性与稳定性。 |
