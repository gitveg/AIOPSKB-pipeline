# 进度报告: power - phase1_sub_industry
> 时间: 2026-04-29 09:55:50

经过评估，您提供的电力行业子行业划分从“源—网—储”的关键技术类型出发，已经覆盖了主要发电方式、电网核心环节及当前重要的灵活性资源，整体框架清晰且合理。燃气发电可归入“火电”大类，其他少量新型发电方式占比较低，无需强行增设。因此，在保持原清单完整性的基础上，确认以下子行业清单及描述：

| 子行业名称 | 描述 |
|---|---|
| 火电 | 以煤、油、天然气等化石燃料燃烧产生的热能驱动发电机组发电的方式，是当前电力系统的基础主力电源。 |
| 水电 | 利用河流、湖泊等水体的势能或动能，通过水轮机转换为机械能再带动发电机发电，是清洁可再生的调峰调频优质电源。 |
| 风电 | 将风能转换为机械能再转换为电能，包括陆上风电和海上风电，是发展最快的新能源发电方式之一。 |
| 核电 | 通过核反应堆中核裂变释放的热能产生蒸汽，驱动汽轮发电机组发电，具有基荷稳定、低碳高能量密度的特点。 |
| 光伏 | 利用半导体界面的光生伏特效应将太阳辐射能直接转换为电能，包含集中式光伏电站与分布式光伏发电。 |
| 输电 | 将发电厂产生的电能通过高压或超高压线路进行远距离、大容量输送的关键环节，连接电源与负荷中心。 |
| 变电 | 通过变电站对电压进行升压或降压变换，以适应输电、配电及用户接入的不同电压等级要求。 |
| 配电 | 将来自输电网或本地区电厂的电力，经过中低压配电网逐级分配至终端用户，是电力送达千家万户的“最后一公里”。 |
| 储能 | 通过物理、化学等方式存储电能并在需要时释放，为电力系统提供调峰、调频、备用等多维服务，是新型电力系统的重要支撑。 |
