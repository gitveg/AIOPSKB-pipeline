9. **编码**：`{行业2}[-子行业2]-设备3-...`；水泥无子行业，编码如 `CM-001-...`（导出期生成）
10. **置信标注**：D5参数 + D11-D15 每条带"置信：标准值/经验值/待核实"

## 8. 经验教训（风电+火电+石化+钢铁沉淀，水泥避免重蹈）

1. **collector.py 行业分支**：新行业必先加 industry_anchor，否则故障层火电污染（钢铁验证）
2. **C方案复用**：结构层可复制，**故障层必须目标行业 prompt 重生** + 三AI评审 + 工况清洗
3. **新生成漏核心件**：DeepSeek 倾向漏静止承载件（回转窑筒体/托轮、立磨磨盘）→ 三AI评审补（§8.5）
4. **评审 1 轮**：多轮辩论评分漂移（钢铁 R1 7.5→R3 4.5），用 --rounds 1
5. **故障层 nohup**：脱离 harness（turn结束不被kill），cron 监控
6. **治理脚本 DRY-RUN→apply→复验**：不接受表面通过
7. **子系统精简 ≤6**：避免部零件/故障跨子系统重合
8. **真实有效**：dry-run→apply→复验，关键改动加自检兜底，**不接受表面通过/循环论证/数据污染**
