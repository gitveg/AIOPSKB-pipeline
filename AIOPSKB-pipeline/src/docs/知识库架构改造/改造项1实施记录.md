## 1. 改造目标

两位专家独立得出同一结论：当前表头术语不准确，需重命名。

| 现状列名 | 改为 | 理由 |
|---------|------|------|
| 设备名称（锅炉、发电机…）| **设备类型名称** | 内容本质是设备的"类"而非带编号的实例 |
| 设备类型（主设备/辅助设备/公用系统）| **设备属性** | "设备属性"更准确（属性分类）|

知识库定位：本库是**类型级知识模板**（所有"主变压器"共享一套故障知识），非设备实例台账。

## 3. JSON 字段决策
