## 2. 逐路线分析（复用 DFIG 路线编号）

### 路线 2：D1 物理属性非枚举（6处）【🔴待治理】

D1 必须是 `机械/电气/绝缘/热/化学/控制/环境`。半直驱 6 处违规：
- `偏航液压制动器.md` D1='液压' → 应为"机械"
- `电机轴承.md` D1='电' → 截断，应为"电气"
- `永磁同步发电机总成.md` D1='电磁' → 应为"电气"
- 其余类似（截断或介质当D1）

**修复**：批量脚本清洗 D1 到 7 枚举（DFIG 路线2 同款 `_fix_d1.py` 逻辑）。

### 路线 3：故障类别白名单（30文件/48自创值）【🔴待治理】

1036 条故障类别中 48 处自创值（24种），0 半角分号、0 超量（prompt 约束已生效✓）。自创值分两类：

**A. 物理属性当故障类别（LLM 混淆 D1 与故障类别）**：
- `机械故障`(9)、`电气故障`/`绝缘故障`/`控制故障`/`通信故障`/`环境故障`/`综合故障`、`绝缘`(8)、`机械`/`电气`/`环境` → 应映射到具体失效模式

**B. 简写/变体（应规范到枚举全称）**：
- `跑圈`(4) → "跑圈（走圈或蠕动）"
- `破损`(2) → "破裂"
- `疲劳`(3) → "裂纹"（疲劳导致裂纹）
- `对中不良` → "不对中"
- `过热`(2) → "温度异常"
- `胶合` → "齿面胶合"
- `塑性变形` → "变形"
- `表面退化` → "性能退化"
- `老化/劣化`、`老化/破裂`（半角/）→ "老化"（改全角分号）
- `其他元件故障` → "其他"

**修复**：严格按 failure_categories.yaml 枚举映射，不可映射→"其他"（DFIG 路线3 原则：禁止自创）。

### 路线 4：D5/D6 互填（1处）【🟡边缘】

`润滑分配器.md` 第7行 D5 疑似监测手段（含"传感器"无阈值）→ 应填 D6。单处，validate 已是优化后规则（DFIG 路线4 修过阈值判断）。

### 路线 5：D2 严重度偏置（2处）【🟢可接受】

`密封胶条`(3/3严重)、`润滑泵站`(5/5严重) 100%严重。DFIG 路线5 判定：关键承载/密封部件故障客观同质时为合理分布。需人工确认，大概率合理。

### 路线 6：D5 置信标注缺失（36处）【🔴待治理】

D5 参数缺"置信：标准值/经验值"标注。如 `主轴.md` 3/17、`主轴承.md` 1/13 未标注。
**修复**：批量补"置信：经验值"（DFIG 路线6 同款）。

### 路线 7：D8 级别标注缺失（80处）【🔴待治理】

D8 缺 `[规程级]`/`[经验级]` 标注。如 `中速齿轮箱.md` 6/6、`主轴.md` 7/7 全未标注。这是半直驱最大问题项（38%文件）。
**修复**：批量补级别标注（DFIG 路线7 同款）。

### 路线 8：检维修置信缺失（25处）【🔴待治理】

D11-D15 缺置信标注。如 `前锁紧螺母.md` 25/25、`润滑分配器.md` 30/30 全未标注。
**修复**：批量补检维修置信（DFIG 路线8 同款）。

### 路线 10：标准版本时效（116处）【🟢可接受】

DL/T 869-2012、GB/T 3608-2008 等旧标准引用。DFIG 路线10 判定：旧标准仍有效，可接受。

### 新：故障文件对应（1处）【🔴编码问题】

**修复**：部件名"/"改全角"／"或重命名，重新生成该部件故障。
