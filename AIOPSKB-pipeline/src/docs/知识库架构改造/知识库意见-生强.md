1. 主设备、辅助设备、公用系统这三个原本叫做设备类别的改为叫做设备属性
2. 部件层进行拆分，不再像当前这种父部件子部件这样的树状结构。 改为子系统、部件、零件三层级结构。如果这三层级无法覆盖，那就部件再拆成父部件和子部件。 这样在表格中的显示会更加清晰，原本全部簇拥在部件层的内容也会更加层级分明。
例如，在某个设备下，泵--电机--电机上的定子转子， 可以抽象成子系统--部件--零件这三层结构。 例如风电下的风电机组设备，风轮系统是子系统，齿轮箱是部件，齿轮箱上的行星级齿圈是零件。

3. 子设备的划分不合理。 审核了风电，发现风电机组下分的那些子设备不太恰当。可以减少分类，比如分为直驱风电机组、双馈分电机组等，这样就可以简洁概括。
