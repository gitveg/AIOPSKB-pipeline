## 一、调研发现汇总

### 1.1 官方定义（construct_guide.md）

- **8 层结构**：行业→[子行业]→设备→[子设备]→**子系统→部件→零件**→故障（子系统/部件/零件为固定层）
- **部件 = 可独立更换/检修的总成单元**（如齿轮箱、联轴器）—— L26
- **零件 = 部件下更细粒度可拆卸件**（如行星齿轮、太阳轮），允许短链（零件列填"—"）—— L27
- **"总成"不是独立层级**：全文 7 处"总成"全部修饰"部件"（部件=总成单元），无独立"总成"层 —— 命名**不必带"总成"后缀**（官方示例一律不带：齿轮箱、联轴器、水冷壁）
- **官方示例**：齿轮箱=部件 / 行星齿轮、太阳轮=零件；水冷壁=部件 / 水冷壁管=零件；凝汽器本体=部件 / 冷却管=零件
- **两个留白**（方案需补强）：① 部件 vs 零件的多维判定准则（仅有单句定义）；② 零件拆解粒度下限（未禁"轴承拆外圈/内圈"，ISO 14224 未被引入）

## 二、核心问题诊断

### 问题根源：construct_guide 的两个留白 + 缺硬约束
1. 部件/零件只有单句定义，无多维判定表 → LLM 各机型自由发挥
2. 零件粒度无下限 → PMSG 拆到轴承外圈/内圈（不可独立拆换）
3. "总成"是命名习惯非层级，但三机型滥用（DFIG 45% 部件带"总成"）

### 表现（三机型）
- **命名乱**：主轴总成 / 主轴 / 主轴本体 三种叫法并存
- **归属乱**：主轴承三机型三种归属
- **粒度乱**：大总成（主轴）塞零件列；小件（传感器）塞部件列；轴承拆到外圈

## 三、层级判定标准（补强 construct_guide 留白）

### 3.1 部件 vs 零件 判定准则（三是否）

> 某件是否满足以下**全部三条**？
> 1. **可独立拆卸**（从设备/子系统上拆下，不破坏母件）
> 2. **可独立发生故障**（有独立的失效模式，PHM 能监测）
> 3. **可独立更换/检修**（有独立备件号、可单独采购更换或检修）
>
> - 三条都满足 → **部件**（若是功能总成）或 **零件**（若是部件下属件）
> - 不可独立拆（拆了母件报废，如轴承外圈）→ **不该出现**

附判定维度：

| 维度 | 部件（总成级）| 零件（可拆卸件）|
|------|--------------|----------------|
| 粒度 | 功能总成（齿轮箱/发电机/主轴）| 部件下属件（太阳轮/密封/膜片）|
| 更换 | 整体更换/大修 | 单独拆换 |
| 故障 | 总成级失效（齿轮箱断齿）| 具体失效（太阳轮点蚀）|
| 维护 | 有独立维护/报废规程 | 随部件维护 |

### 3.2 零件粒度下限（禁止过度细化）

**禁止**出现以下"不可独立拆换"的子件：
- 轴承外圈 / 内圈 / 滚动体 / 保持架 / 圆锥滚子（拆了轴承报废）
- 绕组单匝 / 铁芯单片 / 齿轮单齿（同理）

**允许短链**：部件无需拆零件时，零件列填"—"（construct_guide L27 已允许）。

### 3.3 故障层跨层去重（部件故障 vs 零件故障）

**问题**：故障是知识库核心信息项，部件级（如"齿轮箱总成"）和零件级（如"太阳轮"）都挂故障，存在**跨层重合**风险。

**实锤**（DFIG 齿轮箱调研）：部件级 7 个故障中 2 个越界——"行星级偏载与齿面剥落""齿面胶合与高温烧结"与零件级（太阳轮/齿圈/高速轴齿轮的"齿面剥落/胶合/点蚀"）重复，**越界率 ~28%**。

**重合的两类**：
1. **越界**：部件级登记了本属零件级的具体失效（"齿面剥落"应挂太阳轮/齿圈，不该挂齿轮箱总成）
2. **因果链双登记**：零件失效（根因）+ 部件现象（表现）各成一故障（如"太阳轮磨损"+"齿轮箱振动"）

**construct_guide 原则**：部件故障=总成级失效，零件故障=具体失效（L122）。

**去重原则**（核心：一个故障只挂一层，按能否定位到具体零件判定）：
1. **能定位到具体零件** → 只挂**零件级**（太阳轮断齿、齿圈点蚀）；部件级不重复笼统说
2. **无法定位到单一零件的整体性/综合性失效** → 挂**部件级**（整体振动、油质劣化、接口泄漏、多点耦合退化）
3. **因果链只挂根因**：零件失效导致的部件现象，只登记零件故障，现象作 D4 征兆描述，**不单独成部件故障**
4. **失效模式不跨层重复**："齿面剥落/胶合/点蚀"若零件级已有，部件级不再登记同模式

**部件级故障的合理边界**（只描述零件级无法表达的整体性失效）：
- ✅ 整体性能/振动/噪声（无法定位单一零件）
- ✅ 油路/油质/润滑系统整体（跨零件）
- ✅ 接口/连接/密封整体
- ✅ 多点耦合退化（综合性）
- ❌ 禁止：可定位到零件的具体失效（"齿面剥落""轴承磨损"应属零件级）

**机制**（三层防护）：
1. **collector fault prompt**：明确部件级故障边界（整体性/综合性，禁止登记可定位零件的失效）
2. **judge 审查**：增加"部件级故障是否与零件级重复（同失效模式跨层）"审查项
3. **validate 校验**：部件级故障名含零件关键词（太阳轮/齿圈/齿面/轴承内圈等）→ 越界告警

## 四、轴承归类决策（★ 重点，需重新确认）

### 4.1 矛盾呈现

| 立场 | 依据 |
|------|------|
| **轴承=零件**（您先前判断）| 轴承整体更换；拆外圈/内圈太细；PHM 标签到轴承级 |
| **轴承=部件**（火电/水电惯例 + construct_guide 定义）| 火电/水电一致把轴承当部件（下挂轴瓦/推力瓦）；大型轴承是可独立检修的总成；符合"部件=总成单元"定义 |

**关键洞察**：您"轴承=零件"的逻辑基于"轴承当部件就会拆外圈/内圈"——但这是可避免的。**轴承当部件 + 零件列填"—"（短链）**，既保留部件语义，又不拆外圈/内圈。火电/水电正是这么做（轴承=部件，拆轴瓦/密封，不拆外圈/内圈）。

### 4.2 两个方案对比

| | 方案A：轴承=零件 | 方案B：轴承=部件+短链（推荐）|
|---|---|---|
| 您的痛点（不拆外圈内圈）| ✅ 解决 | ✅ 解决（短链不拆）|
| 火电/水电一致性 | ❌ 不一致（它们是部件）| ✅ 一致 |
| construct_guide 定义 | △ 大型轴承是总成，当零件略勉强 | ✅ 符合"总成单元" |
| 跨行业通用组件库 | ❌ 风电轴承零件 vs 火电轴承部件冲突 | ✅ 统一 |
| 大型轴承（主/偏航/变桨）语义 | ❌ 总成级件当零件，偏轻 | ✅ 总成级件当部件，准确 |
| 实施复杂度 | 中（三机型对齐）| 中（三机型对齐 + 短链）|

### 4.3 我的推荐：方案B（轴承=部件，短链不拆内部）

**理由**：
1. **三方一致**：construct_guide（部件=总成）+ 火电 + 水电 都指向"轴承=部件"
2. **物理实际**：风电主轴承（双列圆锥滚子，直径1-2米）、偏航/变桨轴承（回转支承，外径2-3米）是**大型总成**，与火电汽轮机轴承、水电推力轴承同级，本就是独立机电单元
3. **短链解决您的痛点**：轴承=部件，零件列填"—"（不拆外圈/内圈/保持架），或仅挂"密封圈/润滑件"（可独立换的）
4. **跨行业统一**：未来建通用组件库时，轴承在所有行业都是部件，不冲突

**方案B 下的轴承处理**：
```
部件: 主轴承    → 零件: —（短链，不拆外圈/内圈）
部件: 偏航轴承  → 零件: —（或挂"偏航轴承密封圈"）
部件: 变桨轴承  → 零件: —（或挂"变桨轴承密封圈"）
部件: 齿轮箱    → 零件: 齿轮箱轴承（嵌入式标准轴承，整体换，作零件合理）
```

> **注**：嵌入式标准轴承（齿轮箱轴承/电机轴承/泵轴承，整体更换的小轴承）仍可作**零件**挂在所属部件下——它们是部件的零件，不是独立总成。即"独立大型轴承=部件，嵌入式小轴承=零件"，按"是否独立总成"区分，而非一刀切。

### 4.4 决策点

**请重新确认**：基于火电/水电调研新证据，我推荐**方案B**（轴承=部件+短链）。若您仍倾向方案A（统一零件），也可行，但会与火电/水电不一致。**这是与您先前判断不同的建议，请您拍板。**

## 五、命名规范

### 5.1 "总成"后缀

- **决策**：不引入"总成"层级（construct_guide 已明确无此层）。部件命名**默认去掉"总成"后缀**（"主轴总成"→"主轴"、"齿轮箱总成"→"齿轮箱"）。
- **例外**：极少数行业约定俗成的固定术语可保留（如"轮毂总成"若为标准叫法），但需评审确认。默认一律去后缀。
- **依据**：火电主流纯名词（主轴/叶轮/汽缸）、水电用"装配"、construct_guide 示例都不带"总成"——"总成"是冗余修饰。

### 5.2 "本体"

- **决策**：**"本体"仅用于部件/设备顶层节点**（如"凝汽器本体"=部件，火电"汽轮机本体"=顶层），**禁止作为零件名**。
- **处理**：删除现有"主轴本体/齿轮箱本体/罩壳本体"等零件（它们是部件自身，部件行已描述）。
- **依据**：construct_guide 示例"凝汽器本体"是部件名（L132），无"XX本体"零件概念。

### 5.3 其他命名

- 部件/零件名禁止半角"/"（已有约束）
- 优先用简洁通用名（"防冲导流板"而非"防冲/导流板"）

## 六、风电部件/零件标准清单（草案）

### 6.1 部件（可独立更换的功能总成）

**传动**：主轴、齿轮箱（DFIG/半直驱）、联轴器、机械制动器、**主轴承**（方案B）、胀紧套
**发电**：发电机、定子、转子、滑环装置、冷却风扇
**变流**：变流器、升压变压器、断路器、滤波器、直流母线
**风轮/变桨**：叶片、轮毂、变桨驱动、变桨控制柜、**变桨轴承**（方案B）
**偏航**：偏航驱动、偏航制动器、**偏航轴承**（方案B）
**支撑/辅助**：塔筒、主机架、机舱罩、液压站、润滑泵站、冷却水泵、散热器
**控制**：主控柜、变流控制柜

### 6.2 零件（部件下可独立拆换件）

**传动零件**：齿轮箱轴承（嵌入式）、太阳轮、行星轮、齿圈、行星架、高速轴齿轮、膜片、摩擦片、锁紧螺母、密封件

**变流零件**：IGBT模块、电容、电抗器、避雷器
**通用零件**：密封圈、垫片、滤芯、蓄能器、螺栓组、传感器（温度/振动/编码器——挂所属部件下）

### 6.3 删除/降级清单

- ❌ 轴承外圈/内圈/滚动体/保持架/圆锥滚子（不可独立拆）—— 全删
- ❌ "主轴本体/齿轮箱本体/罩壳本体"（=部件自身）—— 全删
- ⚠️ 主轴承/偏航轴承/变桨轴承：方案B 提为部件（短链）；方案A 保持零件
- ⚠️ "XX总成"后缀：全部去掉

## 十、遗留与风险

1. **表头格式**（观察项，本次不改）：火电/水电用"部件名称/父部件"表达多层树，风电压成"部件/零件"2层。construct_guide 示例用"部件/零件"。改表头是更大改造，本次保持"部件/零件"，仅靠命名+层级标准解决混淆。未来若需多层树可再议。
2. **轴承方案A vs B**：若选A（零件），与火电/水电不一致，未来通用组件库需特殊处理；若选B（部件+短链），三行业一致但需接受"轴承是部件"的语义。
3. **目录重命名风险**：子设备名简化 + 部件去总成后缀，涉及大量目录/路径/编码变更，需严谨的脚本 + 备份 + 全量验证。
