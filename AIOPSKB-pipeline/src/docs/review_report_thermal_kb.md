### ~~2.1 锅炉子设备拆分完全不合理~~ ✅ 已修正（2026-05-12）

**文件**: `thermal/boiler/sub_equipment.md`

**问题描述**:
该文件列出了22种"子设备"：火管锅炉、水管锅炉、水火管锅炉、自然循环锅炉、强制循环锅炉、直流锅炉、层燃锅炉、室燃锅炉、流化床锅炉、旋风锅炉、余热锅炉、电加热锅炉、生物质锅炉、蒸汽锅炉、热水锅炉、汽水两用锅炉、电站锅炉、工业锅炉、超临界压力锅炉、导热油锅炉、立式锅炉、卧式锅炉。

**问题分析**:
1. 这些不是某个具体锅炉的"子设备"，而是**锅炉分类维度的混杂罗列**（按循环方式、燃烧方式、压力等级、用途、结构形式、介质类型）。
2. 这些维度之间是**交叉关系**而非并列关系。例如"电站锅炉"可以是"直流锅炉"也可以是"自然循环锅炉"，可以是"立式"也可以是"卧式"。
3. 对于火电厂，合理的子设备拆分应基于**技术路线**：如煤粉炉、循环流化床锅炉（CFB）、燃气锅炉、余热锅炉等。

**结论**: ~~该文件需要**推倒重做**。~~ ✅ 已按煤粉锅炉/CFB/余热锅炉三条技术路线重写。

**建议**: ~~按以下技术路线重新拆分子设备：~~ ✅ 已执行
- ~~- 煤粉炉（含切圆燃烧、对冲燃烧、W型火焰等）~~ → 煤粉锅炉
- ~~- 循环流化床锅炉（CFB）~~ → 循环流化床锅炉（CFB）
- ~~- 燃气-蒸汽联合循环余热锅炉（HRSG）~~ → 余热锅炉（HRSG）

### ~~2.2 发电机轴承类型错误（重大行业知识错误）~~ ✅ 已修正（2026-05-12）

**文件**:
- `thermal/generator/components.md`（轴承部件描述）
- `thermal/generator/faults/轴承.md`（全部故障条目）

**问题描述**:
- 部件描述中写"采用滚动轴承或短圆柱轴承"。
- 故障文件中全部故障都是**滚动轴承**的内容：滚动接触疲劳剥落、保持架损坏、密封失效、微动腐蚀磨损、疲劳破裂（套圈断裂）、蠕变（蠕动腐蚀）等。

**问题分析**:
- 大型汽轮发电机（火电主力机组，100MW~1000MW+）的轴承**全部是滑动轴承（轴瓦）**，包括：
  - 径向轴承：椭圆瓦、多油楔瓦、可倾瓦
  - 推力轴承：密切尔式（Michell）、金斯伯里式（Kingsbury）可倾瓦轴承
- 滚动轴承只用于小型发电机（如柴油发电机、小型水轮发电机等），**不用于火电汽轮发电机组**。

**结论**: ~~发电机轴承的**部件描述和全部故障知识需要重写**，应改为滑动轴承/轴瓦的故障模式。~~ ✅ 已修正：components.md改为"滑动轴承（椭圆瓦/可倾瓦）"，轴承.md重写为8条滑动轴承故障。

**建议故障条目**（供参考）：
- ~~乌金（巴氏合金）磨损/脱胎~~ → 已纳入"巴氏合金脱胎"+"轴瓦磨损"
- ~~烧瓦（油膜破裂导致轴瓦熔化）~~ → 已纳入"轴瓦烧损"
- ~~油膜振荡/油膜涡动~~ → 已纳入"油膜振荡"
- ~~轴瓦温度异常升高~~ → 已纳入"润滑油温过高致轴承异常"
- ~~轴颈拉伤/磨损~~ → 已纳入"轴颈拉伤"
- ~~推力瓦块不均匀磨损~~ → 未纳入（当前仅覆盖径向轴承）
- ~~润滑油系统污染导致轴瓦损伤~~ → 已在"轴瓦磨损"中涵盖
