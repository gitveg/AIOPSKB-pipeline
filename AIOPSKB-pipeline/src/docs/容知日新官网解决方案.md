# 电力

## 传动链智能监测方案

容知日新传动链智能监测方案通过智能加速度传感器，采集主轴承、齿轮箱、发电机等部位振动数据，监测设备运行状态，通过故障诊断技术，评估传动链大部件状态，定位故障根源，预测部件剩余寿命，实现设备状态的掌控。

监测痛点：

检维修工作量大
风电机组运行期间，轴承、齿轮箱内部日常巡检难以发现故障，检维修工作量大。

故障影响大
主轴、发电机、齿轮箱关键机械部件发生故障导致机组非正常停机，严重降低发电效率，增加检维修成本。

## 变桨轴承智能监测方案

变桨轴承是大型风电机组控制系统的核心部分之一，通过控制叶片的角度来控制风轮的转速，进而控制风机的输出功率，并能够通过空气动力制动的方式使风机安全停机，一旦出现故障造成停机更换轴承，严重故障造成叶片失衡掉落的后果，因此对变桨轴承进行早期故障在线监测有着重要意义。容知日新变桨轴承智能监测方案，有效解决风电机组变桨轴承3大运维痛点与3大监测难题。

监测痛点


磨损、疲劳失效时有发生
变桨轴承承受交变多源载荷，工作环境严酷，所以磨损、疲劳失效问题时有发生。

检修难度高
变桨轴承工作环境复杂，检修难度较高，传统的人工检维修方式效率低，有迟滞。

故障影响大
人工排查时肉眼较难发现前期裂纹类故障，若前期裂纹等故障未有效识别并处理，故障严重后导致叶片失衡掉落，安全与经济损失巨大。

故障信号获取难
变桨在线监测早期故障信号微弱，常规振动监测方式难以捕捉，故障信号获取难。

整体状态识别难
传统监测对风机变桨状态无法精准判断，无法有效定位变桨故障，整体状态识别难。

## 螺栓智能监测方案

容知日新螺栓智能监测方案通过实时采集螺栓连接法兰面间隙位移数据、螺栓预紧力数据，判断螺栓运行状态，避免因螺栓松动、断裂导致的机组重大损伤和停机维修发电损伤，为风机运行的安全性与可靠性提供数据支持，保障运维人员实时、准确地掌握螺栓运行的实时状态，提高管理水平。

监测痛点

故障易发生
风电机组塔筒、叶片、变桨轴承等部分法兰螺栓由于承受一系列复杂多变的负荷，螺栓预紧力会降低，此时存在螺栓松动脱落或断裂的风险。

可靠性不足
国内塔筒越来越高，叶片长度也越来越长，但关键连接处的螺栓技术和可靠性却并未得到充分提升。尤其是叶根螺栓，螺栓故障率逐渐上升。


## 火电主辅机智能监测方案

全面、实时监控项目相关区域的关键设备运行状态，当设备异常时，能提前预警和诊断，指导设备管理人员及时采取应对措施，进行精准检维修，提高维修内容的针对性、有效性，防止预防性维修中的过度维修及欠维修，避免突发故障的发生，减少非计划故障停机时间，降低维修成本，并通过数据积累与分析，为检修维护方案制定提供科学依据；提升关键设备巡检检修质量与智能化水平；用智能传感器减少对人工依赖，用传感器与规则替代或减少现场日常设备点检负荷，提高劳动效率。

监测痛点

重要辅机设备
大量大型风机、水泵连续运行率高，故障率高，设备分布较广，预测性维护缺失导致运维难度高。

主机设备
大量采用国外进口系统，系统封闭性强，现场专业分析能力弱，国外厂商服务费用高昂。

皮带机设备
依赖人工巡检或定点摄像头，对整条皮带设备的全面感知能力弱，出现皮带撕裂快速劣化，存粉自燃等导致现场安全事故的问题无法及时发现。

点检设备
以人工点检为主，劳动强度大效率低，现场出现危险安全隐患大，依赖经验点检质量难保证，巡检过程数据难追溯。

## 齿轮箱润滑油智能监测方案

容知日新齿轮箱润滑油智能监测方案通过在线监测技术连续监测油品品质变化、磨粒的产生，发现齿轮箱润滑不良等早期故障。通过数据分析与诊断，指导现场人员做出设备维保决策，实现预测性维护与油品状态的可视化、实时显示、指标趋势分析。

监测痛点

实验室分析
传递和分析时间较长，时效性较差；取样过程可能对油液造成二次污染；数据呈现形式弱。

现场测试
需要购置专业设备，增加专业检测人员，成本及管理难度增加；油液状态背后的深层次设备故障原因无法分析。

## 叶片智能监测方案

容知日新叶片智能监测方案通过智能化监测传感器，采集叶片振动、温度、载荷等数据，利用智能算法结合风机运行状态，进行综合分析和预测叶片的潜在故障，提前对叶片作出预警分析，实现叶片状态评定、故障诊断，为叶片设备的维护管理决策提供服务。

监测痛点

故障易发生
叶片受无规律交变风力载荷，易产生表面损伤，如涂层剥落、点蚀、轻度裂纹等。同时叶片也易遭受雷击和覆冰。

事故影响大
风机轻度损坏日积月累，便可能导致叶片严重裂纹产生，严重者叶片断裂和扫塔倒塔，造成经济损失和安全事故。

## 塔筒晃动与基础沉降监测方案

容知日新塔筒晃动与基础沉降智能监测方案通过智能化监测系统，采集塔筒晃动倾角、振动、陀螺仪等数据，掌握塔筒健康状态，发现早期故障，避免突发故障发生，减少非计划停机，协助企业合理制定检维修计划，避免倒塔事件，避免重大安全事故的发生。

监测痛点

故障易发生
我国大部分风电风场地处草原、沙漠、沿海等环境恶劣复杂的地方，存在基础松动受损、塔筒焊缝开裂、塔筒弯曲变形等问题，从而导致塔筒运行过程风险增大。

事故影响大
一旦发生机组倾覆，将会造成极大经济损失和不良影响。
