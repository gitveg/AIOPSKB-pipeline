| 子系统名称 | 描述 |
|---|---|
| 驱动系统 | 为泵提供旋转机械能的动力源，通常为电动机（大型机组或特殊工况可用汽轮机），通过联轴器直驱或经减速齿轮箱传动。功能是驱动泵轴旋转，满足工艺介质输送的压力和流量需求，覆盖从动力输入轴到联轴器的全部传动链。 |
| 泵体及水力系统 | 将驱动系统的机械能高效转化为介质的压力能，由叶轮、导叶、泵壳等组成。核心功能是实现工艺介质（物料、冷却水、循环液等）的增压输送，耐受介质腐蚀性、温度及压力工况。 |
| 密封系统 | 针对工艺介质（腐蚀性、有毒），采用机械密封、填料或迷宫密封防止介质沿轴向泄漏。含机械密封、填料函、迷宫密封及密封冲洗辅助件（磁性滤网、节流孔板），是防止危险介质外泄的关键功能单元。 |
| 润滑与冷却系统 | 为轴承、齿轮箱提供清洁定温强制润滑油，并为密封腔、轴承提供冷却（密封冲洗冷却器、冷却水管路、空冷风扇）。形成油膜减小摩擦、带走运转热量，保障泵组长周期稳定运行。 |
| 仪表控制系统 | 采集泵组温度、振动、压力、流量、转速等运行参数，执行超温、超振、低油压等紧急保护逻辑与最小流量再循环自动调节，含控制柜、各类变送器与开关、监测组件及就地仪表，实现泵组自动启停与远程监控。 |
| 辅助工艺管路系统 | 提供最小流量再循环、暖泵、排空、疏水等工艺保护管路及膨胀补偿，保护泵体低流量不过热、启停排气防汽蚀并吸收管路热位移，含再循环阀、暖泵阀、排空阀、疏水器及补偿器。 |
