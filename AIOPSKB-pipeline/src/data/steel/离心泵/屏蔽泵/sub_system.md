| 子系统名称 | 描述 |
| :--- | :--- |
| 水力系统 | 由叶轮及泵体（蜗壳）构成，负责将驱动系统传递的机械能转换为流体的压力能和动能，实现液体的吸入与排出。其功能边界覆盖从泵入口法兰至出口法兰间的全部过流部件。 |
| 驱动系统 | 由电机定子与转子组成，定子线圈通电产生旋转磁场，驱动转子旋转，完成电能到机械能的转换。该系统与泵同轴一体，无需联轴器，是屏蔽泵的动力源头。 |
| 屏蔽隔离系统 | 核心功能部件为由不锈钢薄板制成的定子屏蔽套和转子屏蔽套，形成密封腔将输送介质与电机定子绕组完全隔离，实现绝对无泄漏，并承受系统压力。 |
| 轴承与支承系统 | 多为滑动轴承，利用输送介质润滑，承担旋转组件的径向与轴向载荷，并约束转子的运动轨迹，确保叶轮与屏蔽套间隙稳定，功能范围涵盖前后导轴承及推力盘等。 |
| 循环冷却与润滑系统 | 通常借助辅助叶轮或外部循环管，引出一股输送介质流经电机内部，带走定转子热量，同时为滑动轴承提供润滑与冲洗。该系统是设备热平衡与轴承寿命的根本保障。 |
| 监控与保护系统 | 集成温度传感器、液位开关、电流监测等器件，实时监测绕组温度、轴承状态及泄漏情况，触发报警或停机以保护设备安全，功能边界为控制柜及泵体上的所有传感单元。 |
