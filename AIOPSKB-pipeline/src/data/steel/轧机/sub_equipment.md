| 子设备名称 | 描述 |
| :--- | :--- |
| 棒线轧机 | 棒材/线材热连轧机组，由粗中轧机组、预精轧机组、精轧机组多机架连续组成，通过水平/立式轧辊对高温钢坯逐道次压下成型为棒材或高速线材盘卷；机架位置（粗中/精/预精）在故障 D5 参数标注，故障机理（轧辊磨损断辊、轴承发热、导卫卡钢、压下失效）通用。 |
| 板材轧机 | 中厚板/热连轧板带机组，由粗轧机（四辊可逆）与精轧机（四辊/六辊连轧）组成，宽辊面对板坯压下延展成板带，配 AGC 厚度控制与板形调节；含粗轧/精轧机架，故障机理通用，板形与厚度精度是特异故障载体。 |
| 管材轧机 | 无缝钢管穿孔+轧管机组，由穿孔机（斜轧/桶形辊+顶杆穿制毛管）与轧管机（连轧/自动轧管/周期轧管减壁延伸）组成，结构特异（斜轧辊、顶杆、芯棒、导盘），穿孔与轧管机理独立。 |
| 冷轧轧机 | 冷轧带钢机组，常温对热轧酸洗卷轧制减薄，由冷轧机架（五辊/六辊/二十辊）+开卷+卷取组成，配轧制乳化液润滑冷却、酸洗与板形控制（弯辊/串辊），工艺特异（冷轧辊磨损、乳化液润滑失效、板形不良、酸洗缺陷）。 |
