| 子系统名称 | 描述 |
|------------|------|
| 轧制执行系统 | 由机架、轧辊、轴承座及平衡装置组成核心受力框架，承受并传递轧制力与弯矩，提供稳定轧制线基准；通过电动压下、液压压上及微调机构精确设定并动态调整辊缝开度，控制板材出口厚度，实现厚度自动控制（AGC）。 |
| 主传动系统 | 将主电机的动力经联轴器、减速机、齿轮座及万向接轴传递至轧辊，驱动上下工作辊同步旋转，提供板材连续咬入与延伸变形所需的转速与扭矩。 |
| 板形控制与工艺介质系统 | 利用工作辊与中间辊弯曲、轴向往复窜动及精细分段冷却在线调整辊缝凸度与轮廓，主动控制板材平直度和横向厚度分布；含泵站、喷淋集管、过滤循环管路供给冷却液与工艺润滑油，控制轧辊热凸度、降低摩擦并为轴承提供集中润滑。 |
| 检测与控制系统 | 集成压力、位移、温度、厚度、板形等传感器，配合PLC、工业计算机及伺服驱动单元，实时采集过程数据并闭环调节，对传动、辊缝、板形、冷却等子系统协同控制与人机交互。 |
| 板材输送与导卫系统 | 包括前后工作辊道、夹送辊、导卫装置和侧导板，负责将板坯正确导入辊缝、引导轧件按中心线运行并顺利输出，覆盖进料至出料全过程。 |
| 辅助动力与介质系统 | 包含液压站、气动系统、除尘装置及稀油润滑站等，为轧机各类执行机构提供基础动力与工作介质，保障辅助功能稳定运行并满足环境合规要求。 |
