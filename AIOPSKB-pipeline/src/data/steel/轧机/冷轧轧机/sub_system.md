| 子系统名称 | 描述 |
| :--- | :--- |
| 主轧制系统 | 包含轧机机架、轧辊组（工作辊、支承辊）、轴承座及压下装置，是冷轧机完成金属塑性变形的核心机械执行单元。负责承受并传导轧制力，在辊缝处对带材实施压缩，实现厚度减薄与板形控制。 |
| 主传动系统 | 包含主传动电机、减速齿轮箱、联轴器、传动接轴及相关的速度/转矩调控装置。功能是为轧辊提供精确可控的旋转动力与转速，满足不同轧制道次对速度和张力的工艺要求。 |
| 液压伺服系统 | 覆盖液压泵站、伺服阀、液压缸及弯辊块等组件。主要功能是为辊缝微调（AGC）、弯辊力施加和轧辊平衡等提供高响应、高精度的动力源，是实现厚度和板形动态控制的关键执行系统。 |
| 工艺润滑与冷却系统 | 包含轧制油/乳化液的存储、过滤、温控、循环泵及喷射装置。功能是对辊缝变形区进行强制润滑以降低摩擦，同时控制轧辊和带钢的工艺温度，保证热稳定性与表面质量。 |
| 测量与控制系统 | 集成了测厚仪、测速仪、板形仪、压力传感器、张力计及过程控制计算机。功能是实时采集工艺参数，执行模型运算并形成闭环控制指令，实现对厚度、板形、张力的全自动精准调控。 |
| 辅助工艺系统 | 包含换辊装置、辊系锁紧机构、排雾系统及消防装置。功能是支持轧辊的快速更换与安全锁定，排除轧制中产生的油雾，并提供火灾监测与扑灭能力，保障连续生产和安全环保。 |
