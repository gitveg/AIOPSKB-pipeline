# 钢铁行业 · 设备枚举（equipment_registry）

> **组织方式**：钢铁不分子行业，整体设备枚举。按三大簇组织——通用动设备（跨工艺复用，可 C方案复用石化库）、轧钢线设备（钢铁核心特色，新生成）、原料/输送/起重（辅助）。静设备（高炉/转炉/连铸机/加热炉）数据缺位，按 GB 标准单独排期，不混入数据优先级。
> **设备属性**：通用动设备（泵/风机）= 辅助设备；轧机/卷取机等轧钢核心 = 主设备。
> **当前状态**：✅ 簇一 P0（离心泵/离心风机）C方案复用进行中；⏳ 簇二轧钢线、簇三、静设备后续按优先级铺开。

| 设备类型名称 | 设备属性 | 描述 |
| :--- | :--- | :--- |
| 离心泵 | 辅助设备 | 钢铁行业离心式泵类设备的通用检维修知识载体，按工作原理族（离心式叶片泵）组织。用于冷却循环水、液压系统供油、除鳞高压水、消防/除尘供水、水处理药剂输送等场景。故障机理（滚动/滑动轴承磨损、机械密封泄漏、叶轮汽蚀与磨粒磨损、口环磨损、泵轴弯曲与不平衡、联轴器对中不良）高度通用，PHM 振动诊断不分工况；工况特异（介质温度、含固量/颗粒磨损、除鳞高压、液压油清洁度）在故障特征参数 D5 层标注。子设备：卧式离心泵（普通离心泵，冷却/循环水主力）、立式筒袋泵（立式长轴，深井/冷却塔水池）、高速泵（高速离心，除鳞/高压供水）、屏蔽泵（无泄漏屏蔽套，水处理药剂/化学介质）、磁力泵（无泄漏磁力耦合，腐蚀性药剂/酸碱再生）。 |
| 风机 | 辅助设备 | 钢铁行业风机类设备的通用检维修知识载体，按工作原理族（离心式/容积式）组织。故障机理（叶轮磨损与积灰不平衡、轴承发热、喘振、调节机构失效、转子振动）通用，PHM 振动诊断不分工况；工况特异（高温含尘烟气磨粒磨损、烧结引风/高炉鼓风/除尘排风、重载长时连续运行）在故障特征参数 D5 层标注。子设备：离心风机（叶轮离心抛射，P0）、罗茨风机（双转子容积式，叶式风机，P1）。 |
| 压缩机 | 辅助设备 | 钢铁行业压缩机类设备的通用检维修知识载体，按工作原理族（容积式/动力式）组织。故障机理（气阀失效/活塞环磨损/十字头滑道磨损/曲轴连杆轴承/排气超温/气量衰减/振动）通用，PHM 振动诊断不分工况；工况特异（轧钢气动动力/仪表风/工艺气体介质/压力比）在故障特征参数 D5 层标注。子设备：往复式压缩机（活塞往复容积式，P1）。 |
| 轧机 | 主设备 | 钢铁核心特色轧钢设备，按产品类型分子设备。故障机理（轧辊磨损/断辊/剥落、轧辊轴承发热、压下机构失效、主传动齿轮磨损断齿、液压泄漏、冷却除鳞堵塞）通用，机架位置（粗中/精/预精）在故障特征参数 D5 层标注；产品特异（棒线导卫卡钢、板带板形、管材穿孔顶杆、冷轧润滑板形）在子设备结构层承载。子设备：棒线轧机（棒材/线材热连轧，含粗中+精+预精机架）、板材轧机（板带热轧，含粗轧+精轧机架）、管材轧机（无缝管穿孔+轧管）、冷轧轧机（冷轧带钢，润滑/板形/酸洗工艺特异）。 |
