| 子设备名称 | 描述 |
| :--- | :--- |
| 离心风机 | 离心式风机，叶轮高速旋转产生离心力将机械能转化为气体动能与压力能（轴向吸气、径向排气），覆盖石化工艺气体输送、尾气排放、通风排气等工况。本体结构故障机理通用（叶轮磨损/积垢/不平衡、轴承发热、机壳振动、进口导叶与风门调节失效），PHM 振动诊断不分工况；工况特异（含尘/腐蚀性/高温重载工艺气体、防爆区域）在故障特征参数 D5 层标注。无喘振（离心特性）。 |
| 罗茨风机 | 双转子容积式风机（双叶/三叶罗茨），靠两转子在机壳内同步反向旋转形成容积变化输送气体，用于石化低压工艺气体输送、气力输送、曝气等工况。故障机理与离心风机本质不同（转子啮合磨损/同步齿轮/脉动/气量衰减），独立成子设备。 |
