| 子设备名称 | 描述 |
| :--- | :--- |
| 离心风机 | 水泥行业离心式风机，叶轮高速旋转产生离心力将机械能转化为气体动能与压力能。用于窑尾高温含尘烟气引风、生料磨/水泥磨排风、除尘排风等工况。故障机理（叶轮磨损/积垢/不平衡、轴承发热、喘振、调节机构失效）通用，PHM 振动诊断不分工况；工况特异（高温含尘烟气磨粒磨损、重载长时连续运行）在故障特征参数 D5 层标注。无喘振（离心特性）。 |
| 罗茨风机 | 水泥行业双转子（双叶/三叶）容积式风机，靠两转子在机壳内同步反向旋转形成容积变化输送气体。用于水泥低压工艺气体输送、气力输送、库底/仓底气化、曝气等工况。故障机理（转子啮合磨损、同步齿轮磨损、气流脉动、气量衰减、轴承发热）与离心风机本质不同，独立成子设备；工况特异（含尘气体磨粒磨损、重载连续运行）在故障特征参数 D5 层标注。 |
