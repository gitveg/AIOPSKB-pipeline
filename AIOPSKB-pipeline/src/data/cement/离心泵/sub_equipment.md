| 子设备名称 | 描述 |
| :--- | :--- |
| 卧式离心泵 | 水泥行业卧式单级或多级离心泵，覆盖循环冷却水、液压系统供油、水处理药剂输送等卧式工况。泵本体故障机理（轴承磨损、机械密封泄漏、叶轮汽蚀与磨粒磨损、口环磨损、泵轴弯曲与不平衡、联轴器对中不良）通用，PHM 振动诊断不分工况；工况特异（介质温度、含固量/颗粒磨损、液压油清洁度）在故障特征参数 D5 层标注。 |
| 立式筒袋泵 | 水泥行业立式长轴离心泵（液下泵/立式管道泵），用于冷却塔水池、深井取水、集水坑排水等立式工况。立式轴系/导轴承/推力轴承/筒袋外壳结构异于卧式，故障模式有结构特异项（长轴挠度、导轴承磨损、推力平衡），独立成子设备。 |
