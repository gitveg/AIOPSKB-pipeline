# 水泥行业 · 设备枚举（equipment_registry）

> **组织方式**：水泥不分子行业——是"两磨一烧"一条连续生产线（生料磨 → 回转窑烧成 → 水泥磨），各工段物理连成一体无独立边界，直接整体设备枚举。工艺上按五大工段理解设备功能归属（生料制备 / 烧成 / 熟料冷却 / 水泥粉磨 / 输送包装），仅作功能分组，不构成子行业层。设备按两大簇组织——**簇一通用动设备**（跨行业复用，C方案复用钢铁库）、**簇二水泥工艺设备**（水泥核心特色，新生成）。
> **设备属性**：通用动设备（泵/风机）= 辅助设备；回转窑/磨机/辊压机等烧成粉磨核心 = 主设备。
> **数据基线**：PHM 17,072 台 / 78 企业，**C 级（设备级仅 28.4%，已分析行业最低）**，数据仅覆盖动设备，静设备数据基本为 0。数据只作旁证，以 JC/T 标准 + 专家为主。
> **当前状态**：✅ collector 水泥行业 prompt 分支已加（故障层不再火电污染）；⏳ 起步：风机/离心风机（C方案复用，链路验证）→ 回转窑（新生成，水泥核心）；其余簇按优先级铺开。
