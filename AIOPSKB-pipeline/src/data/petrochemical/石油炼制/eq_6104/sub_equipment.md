| 子设备名称 | 描述 |
| :--- | :--- |
| 硫酸法烷基化反应器（釜式） | 以硫酸为催化剂，采用机械搅拌的釜式反应器，通过强力混合实现酸烃充分接触，在较低温度下生产高辛烷值烷基化油。 |
| 硫酸法烷基化反应器（管式） | 以硫酸为催化剂，物料在管道内连续流动反应，通过分段控温实现精准温度管理，具有高转化率和连续化生产能力，适合处理高活性物料。 |
| 氢氟酸法烷基化反应器 | 以氢氟酸（HF）为催化剂，在温和条件下反应，HF兼具催化剂和冷却介质功能，反应器设计须满足强腐蚀性物料处理及严格安全防护要求。 |
| 固体酸（沸石）烷基化反应器 | 采用固体沸石等环境友好型催化剂，通常为固定床或流化床反应器，避免使用液体强酸，操作更安全，但催化剂易结焦失活，需频繁再生。 |
| 离子液体烷基化反应器 | 采用离子液体作催化剂，可通过调节结构优化选择性，属于清洁生产新技术，反应器需解决催化剂与产物的高效分离问题。 |
| 微通道连续流烷基化反应器 | 采用高通量微通道设计，传质传热效率远超传统反应器（约1000倍），基于特种玻璃或碳化硅材质，可实现无放大效应的连续流合成，适合强腐蚀性及快速强放热反应。 |
| Friedel-Crafts烷基化反应器 | 以路易斯酸（如AlCl₃）为催化剂，常用于苯环烷基化等有机合成，采用非连续搅拌釜式反应器，需严格控水，并通过分液、浓缩、结晶等后处理获得产物。 |
| 电化学烷基化反应器 | 利用电流驱动，在电极表面通过电化学还原或氧化实现烷基化，条件温和、选择性高，可在室温下进行，能实现传统Birch还原等过程，反应器结构围绕阴阳极及电解质设计。 |
| 固定床烷基转移反应器 | 装填特种沸石分子筛催化剂，用于将多烷基化副产物（如二乙苯）与原料（如苯）进行烷基转移，生成单烷基化目标产物（如乙苯），可单独设置或与烷基化反应器串联，提高工艺选择性。 |
| 连续搅拌罐式反应器级联 | 由多个搅拌釜式反应器串联而成，用于重氮甲烷等危险试剂的连续生产与即时消耗，可有效控制强放热反应的热量累积和有害中间体浓度，提升工艺安全性。 |
| 搅拌釜式烷基化反应器（多相） | 用于气-液-固三相并存的重质原料加工（如重质松节油催化加氢制备烷基化物），通过强力搅拌实现三相高效混合与传质，是处理复杂非均相反应的灵活方案。 |
