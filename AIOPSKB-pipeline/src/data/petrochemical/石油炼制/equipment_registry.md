| 加氢裂化反应器 | 主设备 | 在高温高压及氢气、催化剂作用下，使重质蜡油发生裂化和加氢反应，生产轻质石脑油、航煤、柴油和尾油。 |
| 蜡油加氢处理反应器 | 主设备 | 为催化裂化装置提供原料预处理，通过加氢脱硫、脱氮、芳烃饱和，改善蜡油裂化性能。 |
| 渣油加氢处理反应器 | 主设备 | 固定床或沸腾床反应器，处理最重的渣油原料，脱除其金属、硫、氮及残炭，转化为可裂化的轻质油。 |
| 减粘裂化反应器/加热炉 | 主设备 | 通过缓和热裂化降低减压渣油粘度，生产少量轻油和更稳定的燃料油，属于渣油改质装置。 |
| 延迟焦化焦炭塔 | 主设备 | 高温渣油在其中发生深度热裂化和缩合反应，生成石油焦，同时产出焦化气、汽油、柴油和蜡油。 |
| 焦化分馏塔 | 主设备 | 分离焦化反应产生的油气，切割为焦化富气、粗汽油、柴油和蜡油。 |

| 芳烃抽提塔 | 主设备 | 利用溶剂萃取原理，从重整生成油或裂解汽油中分离出苯、甲苯、二甲苯（BTX）等高纯度芳烃。 |
| 芳烃精馏塔 | 主设备 | 通过精馏将混合芳烃分离为纯苯、甲苯、二甲苯等单一产品。 |
| 异构化反应器 | 主设备 | 将直馏石脑油中的C5/C6正构烷烃转化为支链异构烷烃，以提高汽油前段辛烷值。 |
| 烷基化反应器 | 主设备 | 在酸催化剂作用下，使异丁烷与丁烯反应生成高辛烷值、无烯烃的烷基化油，是理想的汽油调和组分。 |
| 甲基叔丁基醚反应器 | 主设备 | 以甲醇和异丁烯为原料，在催化剂作用下反应生成MTBE，用于提高汽油辛烷值和氧含量。 |
| 汽油脱硫醇反应器 | 主设备 | 在碱液及催化剂存在下，将催化汽油中的硫醇转化为二硫化物，脱除臭味并降低硫含量。 |
| 轻烃回收装置换热器 | 主设备 | 通过加压、冷却、冷凝分离回收炼厂气中的液化石油气（LPG）和轻石脑油。 |
| 气体分馏塔 | 主设备 | 通过多塔精馏，将液化气分离为丙烷、丙烯、异丁烷、正丁烷、丁烯等单体烃产品。 |
| 酸性水汽提塔 | 主设备 | 处理含硫含氨污水，利用蒸汽汽提脱除硫化氢和氨，净化水循环利用，富集的酸性气送硫磺回收。 |

| 制氢转化炉 | 主设备 | 以天然气或轻烃为原料，在高温、催化剂和蒸汽作用下，发生烃类蒸汽转化反应，生成富含氢气的合成气。 |
| 制氢变换反应器 | 主设备 | 将转化气中的CO与水蒸气在催化剂作用下反应生成CO2和H2，增加氢气产率。 |
| 变压吸附提纯塔 | 主设备 | 利用吸附剂选择吸附原理，从变换气中分离出高纯度氢气，是制氢装置氢气提纯的核心设备。 |
| 丙烷脱沥青塔 | 主设备 | 以丙烷为溶剂，从减压渣油中萃取脱沥青油，用于生产高粘度润滑油基础油或作为催化裂化/加氢裂化原料。 |
| 聚丙烯反应器 | 主设备 | 炼厂气中的丙烯在此进行聚合反应，以生产聚丙烯产品，是油化结合的典型装置。 |
