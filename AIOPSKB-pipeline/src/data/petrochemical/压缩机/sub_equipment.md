| 子设备名称 | 描述 |
| :--- | :--- |
| 螺杆压缩机 | 双螺杆（阴阳转子啮合）为主、单螺杆（螺杆+星轮）为变体的回转容积式压缩机，覆盖石化工艺气体压缩、冷冻制冷、原料气输送等工况。故障机理通用（转子啮合磨损/咬死、同步齿轮磨损、主轴承发热、润滑油劣化、轴端密封泄漏、排气超温、气量衰减），PHM 振动诊断不分工况；工况特异（工艺气体腐蚀性/易燃易爆/含液/压力比）在故障特征参数 D5 层标注。 |
| 往复式压缩机 | 活塞往复容积式压缩机（含大型工艺活塞压缩机），覆盖石化高压工艺气体压缩、氢气/烃类压缩、大排气量工况。故障机理（气阀泄漏/磨损、活塞环磨损、活塞杆断裂、填料密封泄漏、曲轴连杆磨损、气缸磨损、十字头磨损）通用，PHM 振动诊断不分工况；工况特异（高压/易燃易爆/腐蚀性介质）在 D5 层标注。 |
| 离心压缩机 | 叶轮离心动力式压缩机（大型工艺离心压缩机），覆盖石化大流量工艺气体压缩、裂解气/丙烯/乙烯压缩、长输管线工况。故障机理（转子不平衡、叶轮磨损/冲刷、密封迷宫磨损、推力轴承失效、喘振、轴位移）通用，PHM 振动诊断不分工况；工况特异（高压比/大流量/工艺气体分子量）在 D5 层标注。 |
| 液环压缩机 | 液环（水环）容积式压缩机，靠叶轮旋转形成液环密封实现气体压缩，覆盖石化低压易燃易爆/有毒气体压缩、特殊工艺气体工况。故障机理（液环汽化/破裂、叶轮磨损、轴封泄漏、气量衰减）通用，工况特异（介质/工作液/真空度）在 D5 层标注。 |
