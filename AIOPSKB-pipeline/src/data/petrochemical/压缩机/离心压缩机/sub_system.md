| 子系统名称 | 描述 |
| :--- | :--- |
| 转子总成 | 由主轴、叶轮、平衡盘等旋转部件构成，通过与驱动机耦合获取动力，并对气体连续做功使其高速旋转，将机械能有效转化为气体的动能与压力能，是完成气体压缩的执行核心。 |
| 定子通流总成 | 包含进气室、扩压器、弯道、回流器及蜗壳等固定的过流部件，负责将气体均匀导入叶轮，并在叶轮出口处将高速气流的动能高效转化为静压能，最后通过蜗壳收集并排入管网。 |
| 支撑与轴承系统 | 由径向轴承和推力轴承组成，精确支撑转子部件，承受转子自重及气动作用力产生的径向与轴向载荷，严格保证转子的旋转间隙与动态稳定性，是机组平稳运行的核心承载部件。 |
| 密封系统 | 包括轴端密封（如干气密封或迷宫密封）与级间密封，形成有效的节流与隔离屏障，阻止压缩气体向外界泄漏及各压缩级间的反向窜流，保障机组的运行效率、安全与环保合规。 |
| 润滑油系统 | 为轴承、增速箱等运动副提供清洁、恒温且压力稳定的润滑油，承担润滑、散热与杂质清洗功能，确保传动部件在低摩擦、低磨损状态下可靠运行，通常包含油箱、泵、冷却器与过滤器。 |
| 控制与保护系统 | 集成转速、振动、位移、温度等监测仪表及防喘振控制回路，通过动态调节进气导叶或旁通阀流量，防止机组发生喘振危害，并实现自动启停、负荷调节及异常状态的安全联锁保护。 |
