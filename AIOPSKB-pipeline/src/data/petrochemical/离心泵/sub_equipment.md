| 子设备名称 | 描述 |
| :--- | :--- |
| 卧式离心泵 | 卧式单级或多级离心泵，覆盖石化工艺物料输送、冷却水循环等卧式工况。泵本体故障机理通用（轴承磨损/机械密封泄漏/叶轮汽蚀/口环磨损/泵轴振动），PHM 振动诊断不分工况；各工况参数差异（工艺介质腐蚀性/粘度/温度/压力）在故障特征参数 D5 层标注。 |
| 立式筒袋泵 | 立式筒袋型离心泵，典型为石化立式长轴泵（液下泵/立式管道泵）。立式轴系/导轴承/推力轴承/筒袋外壳结构异于卧式，故障模式有结构特异项（长轴挠度/导轴承磨损/推力平衡），独立成子设备。 |
| 高速泵 | 高速离心泵（增速齿轮箱驱动高转速，单级高扬程），用于石化高扬程小流量工况。高速转子动平衡/齿轮增速/高频振动/机械密封特异，独立成子设备。 |
| 屏蔽泵 | 无泄漏屏蔽泵（电机与泵壳一体，屏蔽套隔离定转子与介质），用于石化剧毒/易挥发/贵重介质输送。屏蔽套故障/介质循环冷却/石墨轴承特异，独立成子设备。 |
| 磁力泵 | 无泄漏磁力驱动泵（外磁转子-隔离套-内磁转子耦合传动，无动密封），用于石化腐蚀性/危险介质。磁耦合退磁/隔离套磨损/滑动轴承特异，独立成子设备。 |
