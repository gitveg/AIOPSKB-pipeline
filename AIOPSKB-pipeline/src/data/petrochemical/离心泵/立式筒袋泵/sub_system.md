| 子系统名称 | 描述 |
| :--- | :--- |
| 增压级组 | 由多级叶轮、导叶（径向导叶或空间导叶）及中段泵壳构成的水力核心部件，负责将驱动机输入的机械能逐级转化为流体的压力能与动能，实现流体从泵入口至末级出口的连续增压，所有过流表面均需满足抗汽蚀与介质兼容要求。 |
| 承压壳体 | 以立式外筒袋（吸入罐）为主体，结合泵盖、吐出段等构成的双层承压边界，将高压流体介质与大气环境完全隔离，并收集从增压级组排出的介质，将其引导至泵出口法兰，承受泵内全压力，同时为内泵芯的安装与定位提供刚性基础。 |
| 转子系统 | 包含主轴、装配于轴上的各级叶轮、轴套、联轴器及锁紧装置等旋转部件，负责将电动机扭矩精准传递至每一级叶轮，在高速旋转中维持动平衡，并将轴向水力载荷传递至平衡与轴承系统，功能边界覆盖所有随轴同步旋转的构件。 |
| 轴向力平衡系统 | 由平衡鼓/平衡盘、平衡管及对应的平衡腔室构成，通过产生与叶轮轴向水推力反向的流体压力差，自动抵消绝大部分残余轴向载荷，保证推力轴承在许用负载内运行，防止转子发生轴向窜动损伤，其平衡状态直接影响机械密封与轴承的使用寿命。 |
| 轴封系统 | 设置在转子穿出泵盖处的机械密封、节流衬套、辅助冲洗与冷却管线所组成的动密封体系，阻止高压、易汽化或有毒介质沿主轴泄漏至大气，同时控制密封端面液膜温升，实现介质的零逸出或受控泄漏，是安全和环保的关键功能屏障。 |
| 支撑与轴承系统 | 包括径向滑动/滚动轴承、推力轴承、轴承支架、润滑与冷却回路等，为立式超长转子提供稳定的径向支撑和残余轴向力承载，确保转子在各级对中精度下平稳旋转，将运行中产生的径向及推力载荷传递至泵底座及基础，并控制轴系振动在标准范围内。 |
