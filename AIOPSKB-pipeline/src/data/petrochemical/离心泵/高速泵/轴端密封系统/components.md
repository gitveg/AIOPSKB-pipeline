| 机械密封 | — | 核心密封单元，依靠弹性元件加载使动环与静环端面紧密贴合，形成极薄液膜或干运转密封，阻止介质沿轴向外漏。（来源：卧式高速泵培训.PPT；LMV 322高速离心泵手册） | 是 | 定期监测泄漏量，超过标准时停机检查；更换时成组更换并清洁密封腔；安装时确保压缩量正确，密封面涂抹洁净润滑油。 | 当端面磨损沟槽深度超过限值、出现热裂纹或气孔导致泄漏无法通过调整恢复时，整体件报废。 |
| 机械密封 | 动环 | 材质为碳化硅或硬质合金，端面研磨抛光，固定在轴上并随转子旋转，与静环端面形成主要密封。（来源：脱硫泵结构组成-三联泵业） | 是 | — | — |
| 机械密封 | 静环 | 采用碳石墨或浸渍石墨制成，安装于密封压盖内保持静止，端面与动环配对形成密封副。（来源：脱硫泵结构组成-三联泵业） | 是 | — | — |
| 机械密封 | 弹性元件(弹簧) | 多个周向布置的小圆柱弹簧或金属波纹管，提供初始端面比压并补偿磨损与轴向窜动，材质为不锈钢。（来源：卧式高速泵培训.PPT） | 否 | — | — |
| 机械密封 | 辅助密封圈 | O形圈或V形圈，材质为氟橡胶或全氟醚橡胶，用于静环与压盖、动环与轴套间的二次密封，防止静态泄漏。（来源：LMV 322高速离心泵手册） | 是 | — | — |
| 密封压盖 | — | 将静环压紧固定在密封腔体上，集成冲洗液接口和泄漏口，提供机械密封的定位与连接，通常为不锈钢或耐腐蚀合金加工件。（来源：Linquip离心泵工作原理） | 否 | 每次检修时清洗冲洗孔和内部积垢；检查密封面有无腐蚀；回装时按对角顺序均匀紧固螺栓。 | 发生严重腐蚀、变形或关键配合面破损导致无法保证密封安装精度时报废。 |
| 密封腔体 | — | 容纳机械密封并形成冲洗液循环腔室，实现节流和热屏障功能，可为泵壳一体式或插装式结构。（来源：LMV 322高速离心泵手册） | 否 | 定期清洗腔内沉积物，检查腔壁有无气蚀或腐蚀，确保冲洗流道通畅。 | 当壁厚减薄量超过设计值30%、出现贯穿裂纹或密封配合面严重冲蚀无法修复时，整体报废。 |
| 节流衬套 | — | 安装于密封腔入口处，采用碳化钨或陶瓷等耐磨材料，通过精密配合间隙（0.3~0.5mm）节流降压，控制进入密封腔的冲洗液量。（来源：卧式高速泵培训.PPT） | 是 | 测量内孔径和圆度，超差后更换；检查内孔有无偏磨或冲蚀沟槽。 | 内径均匀磨损超过公称值0.5mm或出现严重不均匀冲蚀时判废。 |
| 密封冲洗过滤器 | — | 安装在密封冲洗管线上，滤除冲洗液中的颗粒杂质，保护密封端面，壳体不锈钢，滤芯可清洗重复使用。（来源：API 682标准） | 是 | 每间隔运行周期检查压差，超限则清洗或更换滤芯；目视检查壳体有无腐蚀泄漏。 | 外壳严重点蚀或机械损伤导致无法承压，或滤网破损且无备件替换时，整体报废。 |
| 密封冲洗液罐 | — | 用于 API Plan 52/53 等密封冲洗方案，储存缓冲液或隔离液，配备液位计和压力释放装置，为双端面密封提供稳定清洁的液体环境。（来源：卧式高速泵培训.PPT；API 682 标准） | 否 | 定期检查液位并补充或更换缓冲液；清洗罐体内部沉积物；校验爆破片与液位计功能。 | 罐体出现腐蚀穿孔、壁厚严重减薄或压力释放件失效无法保证承压安全时，整体报废。 |
| 密封冲洗换热器 | — | 采用水冷或空冷方式冷却循环冲洗液，降低密封腔温度以延长密封件寿命，通常为管壳式热交换器，耐腐蚀材质。（来源：卧式高速泵培训.PPT） | 否 | 定期检查和清理管程水垢与沉积物，防止堵塞；进行壳体水压试验确认无内漏。 | 管束腐蚀穿孔导致冷却介质窜入冲洗液，或壳体壁厚减薄超出安全裕量时，整体报废。 |
