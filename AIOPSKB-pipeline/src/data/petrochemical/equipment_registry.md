| 设备类型名称 | 设备属性 | 描述 |
| :--- | :--- | :--- |
| 离心泵 | 辅助设备 | 石化行业离心式泵类设备的通用检维修知识载体，按工作原理族（离心式叶片泵）组织。离心泵故障机理（轴承磨损/机械密封泄漏/叶轮汽蚀/口环磨损/泵轴振动/不平衡）高度通用，PHM 振动诊断不分工况；各工况特异（腐蚀性介质/高温/易挥发/有毒物料）在故障特征参数 D5 层标注。子设备：卧式离心泵（普通离心泵）、立式筒袋泵（立式长轴结构）、高速泵（高速离心泵）、屏蔽泵（无泄漏屏蔽套结构）、磁力泵（无泄漏磁力耦合结构）。 |
| 容积泵 | 辅助设备 | 石化行业容积式泵类设备的通用检维修知识载体，按工作原理族（转子或齿轮啮合容积式）组织。故障机理（转子啮合磨损/咬死/密封泄漏/脉动/气量衰减）通用，PHM 振动诊断不分工况；工况特异（介质粘度/含固量/压力）在 D5 层标注。子设备：单螺杆泵、双螺杆泵、三螺杆泵、齿轮泵、计量泵、柱塞泵。 |
| 水环真空泵 | 辅助设备 | 利用水环在泵腔内形成可变密封实现抽真空的设备，主要用于石化工艺抽真空与排气系统。故障机理（水环汽化/叶片磨损/轴封泄漏）通用，工况特异（抽气量/真空度/介质）在 D5 层标注。 |
| 风机 | 辅助设备 | 石化行业风机类设备的通用检维修知识载体，按工作原理族（离心式/容积式）组织。故障机理（叶轮磨损/不平衡/轴承发热/喘振/调节机构失效）通用，PHM 振动诊断不分工况；工况特异（含尘烟气/防爆区域）在 D5 层标注。可按需要分子设备：离心风机（叶轮离心抛射）、罗茨风机（双转子容积式）。 |
| 压缩机 | 辅助设备 | 石化行业压缩机类设备的通用检维修知识载体，按工作原理族（容积式/动力式）组织。故障机理（转子啮合/轴承/润滑油/轴端密封/气阀/排气超温/气量衰减/振动）通用，PHM 振动诊断不分工况；工况特异（工艺气体压缩性/易燃易爆/腐蚀/压力比）在 D5 层标注。子设备：螺杆压缩机（双螺杆为主+单螺杆，回转容积式）、往复式压缩机（活塞往复，含大型工艺活塞）、离心压缩机（叶轮离心，动力式）、液环压缩机（液环容积式）。 |
| 搅拌机 | 辅助设备 | 用于石化反应釜/储罐等容器内物料混合的设备，包含搅拌轴、桨叶、密封、驱动等组件。故障机理（桨叶磨损/轴封泄漏/振动异常）通用，工况特异（介质腐蚀性/粘度/固含量）在 D5 层标注。 |
