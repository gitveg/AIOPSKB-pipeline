| 原料粉碎设备 | 辅助设备 | 用于将块状原料（如钾盐、磷矿、有机物料等）破碎至适宜粒度，满足后续工艺要求。 |
| 配料计量设备 | 辅助设备 | 根据配方要求，对多种固体或液体原料进行精确称量和配比，确保产品质量稳定。 |
| 混合/搅拌设备 | 主设备 | 将多种原料及返料进行充分混合均匀，为造粒或反应创造良好条件，如双轴搅拌机、盘式搅拌机。 |
| 造粒设备 | 主设备 | 将粉状或熔融物料制成一定形状和强度的颗粒，是化肥生产核心设备，如转鼓造粒机、圆盘造粒机、挤压造粒机、喷浆造粒机。 |
| 干燥设备 | 主设备 | 通过热风或烟气与物料接触，去除造粒后颗粒中多余水分，使其达到产品含水率要求，如回转干燥炉。 |
| 冷却设备 | 辅助设备 | 对出干燥机的热态化肥颗粒进行冷却，降低温度至规定要求(如<50℃)以利于后续筛分和包装，如回转冷却机、流化床冷却器。 |
| 成品筛分设备 | 辅助设备 | 对冷却后的颗粒进行粒径分级，分离出合格产品、大颗粒及细粉，保证成品粒度均匀，如滚筒筛、振动筛。 |
| 破碎设备 | 辅助设备 | 将筛分后的大颗粒返料粉碎成小颗粒或粉末，返回造粒系统重新利用，如链式破碎机、笼式破碎机。 |
| 成品包装设备 | 辅助设备 | 将合格成品按设定重量自动或不自动充填至包装袋，并进行封口，如自动包装秤、给袋式包装机。 |
| 成品包装计量设备 | 辅助设备 | 与包装设备配合，对包装好的成品进行精确称重和计量，确保每袋净含量符合标准。 |
| 气体除尘净化回收设备 | 辅助设备 | 将生产过程中各扬尘点及干燥尾气中的粉尘进行捕集和回收，减少物料损失并净化尾气，如旋风除尘器、袋式除尘器、洗涤塔。 |
| 排风设备 | 辅助设备 | 将净化后的废气排向大气，维持系统负压，如风机。 |
| 原料储库/料仓 | 公用系统 | 储存各种固体或液体原料，保证连续生产，如磷矿库、氨站、液氨贮槽、硫酸贮槽。 |
| 成品库 | 公用系统 | 储存包装好的袋装或散装成品，实现产储分离。 |
| 预热设备 | 辅助设备 | 在缓控释肥料生产中，对包膜核芯原料进行预热，使其达到适宜包膜温度，提高包膜效果。 |
| 包膜/喷涂设备 | 主设备 | 将包膜材料（如液硫、树脂等）均匀喷涂在肥料核芯表面，形成缓控释层，如喷涂转鼓。 |
| 包膜材料制备设备 | 辅助设备 | 用于制备或储存液状或固态的包膜材料，保证连续喷涂。 |
| 液硫储存及计量设备 | 辅助设备 | 针对硫包衣工艺，专门储存和精确计量液体硫磺，确保包膜厚度均匀。 |
| 有机质无害化处理设备 | 辅助设备 | 对自产的有机质原料（如滤泥、粪便等）进行发酵、除臭、灭菌等无害化处理。 |
| 发酵翻抛设备 | 辅助设备 | 在有机肥生产中，对堆置发酵的物料进行翻堆、抛送，促进好氧发酵，如槽式翻抛机、履带翻抛车。 |
| 粪便脱水设备 | 辅助设备 | 对高湿度的动物粪便等有机原料进行固液分离，降低水分以便于后续发酵和加工。 |
| 合成氨造气炉 | 主设备 | 将煤、焦炭、天然气等原料与气化剂反应，制取含有氢气和一氧化碳的粗合成气。 |
| 变换炉 | 主设备 | 在催化剂作用下，将粗合成气中的一氧化碳与水蒸气反应生成氢气和二氧化碳，调整氢氮比。 |
| 原料气净化设备 | 主设备 | 包括脱硫塔、脱碳塔、精脱硫塔等，用于脱除原料气中的硫化物、二氧化碳等，防止下游催化剂中毒。 |
| 合成气压缩机 | 主设备 | 将净化后的合格合成气压缩至高压，为氨合成反应提供压力条件。 |
| 氨合成塔 | 主设备 | 在高温、高压和催化剂作用下，将氮气和氢气合成为氨，是整个合成氨装置的核心设备。 |
| 吸收/解吸设备 | 辅助设备 | 在尿素生产中，用于吸收未反应的气相氨和二氧化碳，或通过解吸回收氨。 |
| 尿素合成塔 | 主设备 | 将液氨和二氧化碳在高温高压下反应生成氨基甲酸铵，进而脱水生成尿素熔融液。 |
| 浓缩设备 | 辅助设备 | 对湿法磷酸或尿素溶液等进行加热蒸发浓缩，提高有效成分浓度，如蒸发器。 |
| 磷酸反应槽 | 主设备 | 硫酸与磷矿浆在此进行萃取反应，生成磷酸和磷石膏。 |
| 过滤机 | 辅助设备 | 将反应后的磷酸料浆进行固液分离，分离出产品磷酸和副产品磷石膏。 |
| 氟吸收设备 | 辅助设备 | 回收磷肥生产过程中含氟废气，制成副产品（如氟硅酸），同时净化尾气。 |
| 钾盐浮选设备 | 辅助设备 | 对钾石盐矿进行浮选分离，获得高品质钾盐精矿，如浮选机、浮选柱。 |
| 钾盐结晶设备 | 主设备 | 对含钾卤水进行蒸发、冷却结晶，获得氯化钾或硫酸钾晶体，如蒸发结晶器。 |
| 高炉/电炉（钙镁磷肥） | 主设备 | 将磷矿石与助熔剂在约1400℃下熔融，水淬后得到钙镁磷肥半成品。 |
| 物料输送设备 | 辅助设备 | 将各工序间的物料通过机械或气力方式进行输送，如皮带输送机、斗式提升机、螺旋输送机。 |
| 加药/化学药剂泵 | 辅助设备 | 精确向系统内注入生产所需的各种液体化学药剂，如磷酸、硫酸、液氨等。 |
| 锅炉系统 | 公用系统 | 为生产装置提供所需规格的蒸汽，用于加热、反应、驱动透平等。 |
| 循环冷却水系统 | 公用系统 | 为压缩机、泵、换热器等设备提供冷却水，并循环利用，包括冷却塔、循环水泵。 |
| 空分/制氮/压缩空气站 | 公用系统 | 提供合成氨所需的高纯度氮气，并为各装置仪表、气动阀门等提供清洁、干燥的压缩空气。 |

| 水处理系统（环保） | 公用系统 | 对原水进行处理，并对生产过程中产生的废水进行收集和处理，实现达标排放或回用。 |
| 火炬/放空系统 | 公用系统 | 处理装置开停车或事故状态下排放的可燃、有毒气体，通过安全燃烧放空，包括火炬筒体、分子封、点火系统。 |
| 分析化验仪器 | 辅助设备 | 对原料、过程样、成品及公用工程介质进行化学分析和物理检验，监控生产过程和产品质量，如消化仪、蒸馏仪。 |
| 真空系统 | 辅助设备 | 为蒸发、结晶、过滤等工艺过程提供所需的真空环境，如液环真空泵、蒸汽喷射泵。 |
| 产品调理/包膜设备 | 辅助设备 | 在成品颗粒表面包裹防结块剂或松散剂，改善产品物理性状，防止储存结块，如肥料包膜机、油脂喷涂滚筒。 |
| 尾气洗涤/净化设备 | 辅助设备 | 对生产尾气进行洗涤、吸收，去除其中的氨、氟化物、粉尘等污染物后达标排放，如尾气洗涤塔。 |
| 除尘风机 | 辅助设备 | 专门为除尘系统提供动力，捕集扬尘，维持环境负压，如脉冲袋式除尘器风机。 |
| 仪表空气干燥/净化设备 | 公用系统 | 对源自空压站的压缩空气进行干燥和净化，确保仪表及调节阀用气的洁净度，如冷冻式干燥机、吸附式干燥机。 |
| 硫回收设备 | 主设备 | 将脱硫单元产生的酸性气转化为硫磺或硫酸，实现资源回收，如克劳斯反应器、加氢还原反应器。 |
| 造粒尾气风机 | 辅助设备 | 引导并输送造粒、干燥、冷却过程中产生的大量含尘、含湿尾气进入净化系统。 |
