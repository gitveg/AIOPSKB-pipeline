| 设备类型名称 | 设备属性 | 描述 |
| :--- | :--- | :--- |
| 裂解炉 | 主设备 | 用于将石脑油、轻烃等原料在高温下进行热裂解，生产乙烯、丙烯等基础烯烃的核心反应设备。 |
| 蒸汽转化炉 | 主设备 | 将天然气或石脑油与水蒸气在催化剂作用下反应，生产合成气（一氧化碳和氢气）的关键设备。 |
| 部分氧化反应器 | 主设备 | 利用氧气或空气对重质油或天然气进行不完全氧化，以获取合成气的高温反应设备。 |
| 催化重整反应器 | 主设备 | 在催化剂及高温条件下，将石脑油中的环烷烃和烷烃转化为芳烃（苯、甲苯、二甲苯）的核心设备。 |
| 裂解汽油加氢反应器 | 主设备 | 对裂解汽油中的不饱和烃进行催化加氢，使其饱和并脱除杂质，为芳烃抽提提供合格原料的设备。包含一段低温选择性加氢和二段高温加氢脱硫。 |
| 芳烃抽提塔 | 主设备 | 利用溶剂对芳烃和非芳烃溶解度的差异，从重整油或裂解汽油中分离出高纯度混合芳烃的液液萃取设备。 |
| 芳烃精馏塔 | 主设备 | 对混合芳烃进行连续精馏，利用沸点差分离获得高纯度的苯、甲苯、二甲苯等单一产品的塔设备。 |
| 二甲苯异构化反应器 | 主设备 | 将价值较低的二甲苯异构体（如间、邻二甲苯）在催化剂作用下转化为对二甲苯，以增产PTA原料的反应器。 |
| 甲苯歧化与烷基转移反应器 | 主设备 | 将甲苯与C9芳烃进行反应，生成混合二甲苯和苯，最大化生产二甲苯的催化反应设备。 |
| 乙烯氧化反应器 | 主设备 | 乙烯与氧气或空气在催化剂作用下反应，生产环氧乙烷、乙醛等有机化工中间体的核心设备。 |
| 乙炔发生器 | 主设备 | 通过电石与水反应，或天然气部分氧化法生产乙炔气体的设备。 |
| 羰基合成反应器 | 主设备 | 烯烃与一氧化碳和氢气在催化剂作用下反应，生产醛、醇等含氧化合物的设备。 |
| 甲醇合成反应器 | 主设备 | 将合成气在铜基催化剂作用下转化为粗甲醇的核心反应设备，操作压力通常为5-10MPa。 |
| 甲醇精馏塔 | 主设备 | 对粗甲醇进行多级精馏，脱除水、乙醇等杂质，获得精甲醇产品的塔设备。 |
| 丁二烯萃取精馏塔 | 主设备 | 在溶剂存在下，利用沸点差将C4馏分中的丁二烯与丁烷、丁烯分离，获得高纯度1,3-丁二烯的关键塔器。 |
| 选择性加氢反应器 | 主设备 | 对裂解C3或C4馏分中的炔烃（丙炔、丙二烯等）和二烯烃进行选择性加氢，使其转化为烯烃，以净化后续加工原料。 |
| 甲烷化反应器 | 主设备 | 在合成气净化过程中，将残余CO和CO2在催化剂下与氢气反应转化为甲烷，以保护下游加氢脱硫等催化剂。 |
| 烃类裂解气压缩机 | 辅助设备 | 将裂解炉产出的高温裂解气进行多段压缩，提升压力以满足后续深冷分离等工段要求的核心动力设备。 |
| 制冷压缩机 | 辅助设备 | 为深冷分离系统提供冷量，通过压缩制冷介质（如乙烯、丙烯）实现裂解气中各组分低温分离的关键设备。 |
| 循环氢压缩机 | 辅助设备 | 在加氢工艺中，维持反应系统氢气循环和压力，确保加氢反应连续进行的大型压缩机。 |
| 塔顶冷凝器 | 辅助设备 | 安装在精馏塔顶，用于将塔顶上升的蒸汽冷凝为液体，提供回流和采出产品的换热设备。 |
| 塔底再沸器 | 辅助设备 | 安装在精馏塔底，利用热源加热釜液，产生上升蒸汽，为精馏过程提供所需热量的换热设备。 |
| 进料加热器 | 辅助设备 | 对进入反应器或精馏塔的物料进行预热，使其达到所需温度，以节能降耗的换热设备。 |
| 废热锅炉 | 辅助设备 | 安装在高温反应设备（如裂解炉）出口，回收高温工艺气体的余热，产生高压蒸汽的能量回收设备。 |
| 急冷器 | 辅助设备 | 对高温裂解气等工艺介质进行快速冷却，终止副反应，并分离出重质焦油和焦炭的辅助设备。 |
| 干燥器 | 辅助设备 | 利用分子筛等吸附剂或溶剂吸收法，脱除原料或产品中微量水分，满足后续工艺对水含量严格要求的设备。 |
| 吸附塔 | 辅助设备 | 采用变压吸附或变温吸附等技术，从混合气中分离或提纯氢气、甲烷等组分，或用于有机废气净化的设备。 |
| 深冷分离冷箱 | 辅助设备 | 在极低温度下，通过一系列板翅式换热器和气液分离器，将裂解气分离为氢气、甲烷、乙烯、乙烷等组分的集成设备。 |
| 离心泵 | 辅助设备 | 为液态物料或冷热媒（如导热油）在管道和设备间的流动提供动力，是物料输送中使用最广泛的流体机械。 |
| 中间储罐 | 辅助设备 | 用于在生产流程中间环节暂时储存原料、中间产品或成品，缓冲上下游工序生产能力差异，确保生产连续性的容器。 |
| 催化剂再生器 | 辅助设备 | 在催化裂化或重整等工艺中，用于烧去催化剂表面积炭，恢复其催化活性的设备。 |
| 过滤器 | 辅助设备 | 安装在泵入口或工艺管线上，用于去除液态物料或气体中的固体颗粒、聚合物等杂质，保护下游设备。 |
| 油水分离器 | 辅助设备 | 利用重力沉降或聚结原理，分离工艺冷凝液、废水或产品流中的游离水或烃类，实现油水两相分离。 |
| 溶剂回收塔 | 辅助设备 | 在芳烃抽提等单元中，从富溶剂中分离出芳烃，并回收溶剂循环使用，通常带有侧线采出和汽提段。 |
| 氧化锌脱硫槽 | 辅助设备 | 填充氧化锌床层，在合成气或天然气进入蒸汽转化炉前，将硫化物（H2S、COS）脱除至ppb级，保护下游催化剂。 |
| 凝结水回收罐 | 辅助设备 | 收集来自蒸汽伴热和换热设备的凝结水，利用余压送回脱盐水站或作为锅炉补水，减少能耗和水耗。 |
| 蒸汽疏水阀 | 辅助设备 | 自动排除蒸汽管线和设备中产生的凝结水，同时阻止蒸汽泄漏，保障蒸汽系统高效传热并防止水击。 |
| 火炬分液罐 | 辅助设备 | 设置于火炬系统前，分离排放气中携带的大颗粒液滴或冷凝液，确保火炬燃烧稳定，防止“下火雨”的环保安全设备。 |
| 火炬水封罐 | 辅助设备 | 安装在火炬总管上，利用水封隔离火炬管网与系统，防止空气倒流入工艺装置形成爆炸性混合物，同时调节排放气背压。 |
| 火炬系统 | 公用系统 | 作为全厂安全设施，将工艺装置在开停车、事故或正常操作中排放的可燃、有毒气体集中燃烧后安全排放的环保与安全系统。 |
| 蒸汽锅炉 | 公用系统 | 为全厂提供所需工艺用蒸汽、伴热用蒸汽和动力蒸汽，是公用工程的重要组成部分。 |
| 循环冷却水系统 | 公用系统 | 提供连续流动的冷却水，通过冷却塔、循环水泵和管网，带走工艺设备换热后的热量，确保生产装置在额定温度下运行。 |
| 脱盐水站 | 公用系统 | 通过离子交换、反渗透等技术，将原水处理为满足工艺要求的高纯度脱盐水，供给锅炉、反应器热回收等环节。 |
| 仪表空气系统 | 公用系统 | 由空气压缩机、干燥器及净化设备组成，提供洁净、干燥、无油的压缩空气，用于全厂气动仪表和控制阀的驱动。 |
| 氮气站 | 公用系统 | 通过空分或变压吸附等方式制取氮气，为全厂提供密封气、保护气、吹扫气和置换气，确保生产安全。 |
| 污水处理场 | 公用系统 | 收集全厂生产废水和生活污水，通过物理、化学和生物方法进行处理，达标后排放或回用的环保设施。 |
| 废气处理系统 | 公用系统 | 对反应、蒸馏、干燥等过程中产生的挥发性有机物（VOCs）和酸性气体等进行燃烧、吸附或吸收处理，实现尾气达标排放。 |
| 变配电所 | 公用系统 | 接收外部电网输入的高压电，经变压器转换和配电柜分配，为全厂的电机、电控设备、照明等提供所需各电压等级的可靠电力。 |
| 燃料气配气站 | 公用系统 | 接收外部天然气或自产燃料气，经过滤、减压、稳压后，分送至各工艺加热炉和蒸汽锅炉，保障燃料压力稳定。 |
| 消防水稳压系统 | 公用系统 | 维持全厂消防管网水压，配备消防水泵和稳压罐，在火灾时提供足量高压消防水，确保装置和储罐区安全。 |
