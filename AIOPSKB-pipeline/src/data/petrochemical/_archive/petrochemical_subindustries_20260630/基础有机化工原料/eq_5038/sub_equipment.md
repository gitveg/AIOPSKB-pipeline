| 子设备名称 | 描述 |
|------|------|
| ICI冷激式反应器 | 绝热反应，段间喷入冷激气直接降温，结构简单易大型化，但催化剂床层温差大、合成效率较低。 |
| ICI逆流冷管反应器（LCM） | 冷原料气走内冷管逆流换热，出冷管后进入催化剂床层反应，床层温差较冷激式小，合成效率更高。 |
| Lurgi管壳式反应器 | 催化剂装于管内，管间沸腾水移热，温差小、副产蒸汽，但催化剂装填系数低、设备体积大。 |
| 三菱SPC超转化率塔 | 双套管结构，冷气走内冷管逆流换热，催化剂装于内外套管间，管间沸水移热，提高合成率但结构复杂。 |
| Linde螺旋管反应器 | 锅炉水走螺旋冷管移热，热应力缓解较好，加工难度大。 |
| MRF反应器（东洋工程） | 双套管，管内走锅炉水，催化剂床层内气体径向流动，阻力小但床层温差较大。 |
| DAVY径向水冷反应器 | 催化剂装壳程，管束水冷移热，气体径向流动，装填系数大但移热能力有限，循环比高。 |
| 林达均温型反应器（JW型） | 冷管胆自由伸缩，催化剂装管外，装填系数高，温差小，投资低，可副产蒸汽，易于大型化。 |
| 华东理工管壳外冷-绝热复合反应器 | 上段绝热、下段管壳外冷，锅炉水自然循环副产中压蒸汽，操作简便、安全稳定。 |
| Lurgi水冷-气冷联合反应器 | 水冷反应器与气冷反应器串联，降低循环比、提高醇净值，适用于特大型甲醇装置。 |
| 林达内冷-外冷串联反应器 | 内冷式自热反应器与外冷副产蒸汽反应器串联，优化轴向温度分布，提升出口甲醇浓度。 |
| 浆态床反应器 | 催化剂粉末悬浮于惰性液体介质中，气液固三相反应，传热优良、温度温和，单程转化率高。 |
| 膜反应器 | 集成选择性透过膜，原位移除水或添加氢气，打破热力学平衡限制，提高CO₂转化率和甲醇产率。 |
| 高压管式反应器 | 催化剂装于管程，反应压力30~35MPa、温度300~400℃，采用锌铬催化剂，结构简单但能耗高，已逐步淘汰。 |
| 流化床反应器 | 催化剂颗粒在气流中呈流化态，传热传质效率高，适用于CO₂加氢等新路线，但催化剂磨损和放大问题待解决。 |
