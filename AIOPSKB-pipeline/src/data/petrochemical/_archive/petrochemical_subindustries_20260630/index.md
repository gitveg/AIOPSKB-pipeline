| 子行业名称 | 描述 |
| :--- | :--- |
| 石油炼制 | 将原油通过常减压蒸馏、催化裂化、加氢精制等工艺转化为汽油、柴油、航空煤油、润滑油基础油等产品。 |
| 基础有机化工原料 | 以石脑油、轻烃、炼厂气等为原料，通过蒸汽裂解、催化重整、裂解、分离、合成等工艺生产乙烯、丙烯、丁二烯、苯、甲苯、二甲苯等基础有机原料。 |
| 合成树脂 | 以乙烯、丙烯等烯烃及苯乙烯等单体，通过聚合反应生产聚乙烯（PE）、聚丙烯（PP）、聚氯乙烯（PVC）、聚苯乙烯（PS）等高分子合成树脂，用于通用塑料与工程塑料。 |
| 合成纤维 | 以有机原料合成聚酯、聚酰胺、聚丙烯腈等高分子聚合物，再经纺丝及后处理工艺生产涤纶（聚酯纤维）、锦纶（聚酰胺纤维）、腈纶（聚丙烯腈纤维）等合成纤维。 |
| 合成橡胶 | 以丁二烯、苯乙烯、异戊二烯等单体经聚合生产顺丁橡胶、丁苯橡胶、丁基橡胶、乙丙橡胶等高分子弹性体产品。 |
| 化肥 | 以天然气、煤或重油为原料合成氨，进一步加工生产尿素、氮磷钾复合肥等。 |
