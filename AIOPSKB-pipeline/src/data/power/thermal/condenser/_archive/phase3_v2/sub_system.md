| 子系统名称 | 描述 |
| :--- | :--- |
| 蒸汽冷凝系统 | 负责将汽轮机排汽及旁路蒸汽导入冷凝区域，通过管束表面换热使蒸汽凝结为液态水，同时容纳汽水混合物体积变化，构成热力循环冷端热阱，保障汽轮机出口背压稳定。 |
| 真空维持与抽气系统 | 依靠抽气设备（射汽/射水抽气器或水环真空泵）连续抽出凝汽器内不凝结气体，维持壳侧高度真空，并配合轴封蒸汽冷凝器防止空气漏入，确保换热效率和设备安全。 |
| 循环冷却水系统 | 在凝汽器管侧提供持续流动的冷却介质（淡水或海水），带走蒸汽凝结释放的汽化潜热，维持管壁低温，并将热量排至冷却塔或环境水体，形成开路或闭路冷却回路。 |
| 凝结水汇集与输送系统 | 汇集凝汽器底部热井中的凝结水，经凝结水泵升压后送回给水系统，同时提供除氧器或补水接口，保证在机组启停及负荷变化时凝结水连续、稳定输出。 |
| 除氧与排空系统 | 在凝汽器内部利用热力除氧原理，将凝结过程中析出的溶解氧和不凝结气体汇集至冷却区域并排出，防止管路腐蚀，并配合排空阀在启停时建立真空或破真空。 |
| 旁路蒸汽接入与消能系统 | 接收汽轮机旁路系统的高温高压蒸汽，通过减温减压装置和专用消能组件将其导入凝汽器壳侧安全冷凝，避免直接冲击管束或破坏真空，在机组甩负荷或启动时保护设备。 |
