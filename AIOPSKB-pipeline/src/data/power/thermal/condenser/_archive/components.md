| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 凝汽器 | — | 表面式热交换器，将汽轮机排汽凝结为水，在排汽口建立并维持真空，同时汇集凝结水。 | 否 | 运行中监控凝汽器真空度、端差和凝结水过冷度，偏差增大应排查泄漏或结垢；定期进行真空系统查漏；大修时全面检查壳体、管束、水室和热井状态；根据运行年限和堵管率规划换管时机。 | 凝汽器整体换热效率严重下降（端差持续超过设计值10℃以上），堵管率超过15%，壳体大面积腐蚀或变形，经技术经济比较后整机更换。退役前排空冷却水和凝结水，拆除与汽轮机排汽口和循环水管的连接，整体或分段切割拆除。 |
| 喉部 | 凝汽器 | 连接汽轮机排汽口与主凝结区的过渡段壳体，引导排汽均匀进入管束区；可集成低压加热器、减温减压装置等。 | 否 | 大修时检查喉部壳体焊缝有无裂纹和腐蚀；检查导流装置和膨胀节状态；检查喉部与汽缸连接的密封性。运行中如真空异常下降应排查喉部膨胀节是否泄漏。 | 喉部壳体大面积腐蚀穿孔或焊缝开裂导致真空无法维持，且局部修补无效。需排空凝汽器后切割更换喉部壳体段。 |
| 喉部导流装置 | 喉部 | 设置在喉部内的弧形导流板或导流板组，用于优化蒸汽流场、减少涡流和流动阻力。 | 否 | 每次大修期间目视检查导流板有无变形、开裂或脱落；检查紧固件是否松动，必要时拧紧或更换；清除表面附着物和锈蚀。 | 导流板大面积变形无法校正，或焊缝多处开裂且补焊后仍反复开裂；固定支座锈蚀严重无法有效固定。拆除时从人孔门进入，逐块拆卸导流板及紧固件，注意防止碎块落入管束区。 |
| 膨胀节 | 喉部 | 安装在喉部与汽轮机排汽口连接处的橡胶补偿装置，用于补偿热位移和振动。 | 是 | 每次小修检查膨胀节表面有无龟裂、老化、鼓包或渗漏；检查卡箍紧力是否均匀；发现裂纹深度超过橡胶厚度的30%时应计划更换。运行中注意排汽温度不宜长时间超过设计值。 | 橡胶本体出现贯穿性裂纹、大面积脱层或鼓包，密封性能丧失且无法通过局部修补恢复。拆除前排空凝汽器内部积水并确认无真空，松开卡箍后整体取出膨胀节。安装新件时注意法兰面清洁、卡箍对角均匀紧固，预留规定的冷拉量。 |
| 壳体 | 凝汽器 | 构成蒸汽凝结空间的外壳，通过管板与冷却水侧隔离，常设加强槽钢和肋板以保证刚性。 | 否 | 大修时检查壳体外壁有无腐蚀、变形及焊缝裂纹；检查加强肋板焊缝是否开裂；对壁厚进行超声测厚，记录减薄趋势。外壁涂装防锈漆保持完好。 | 壳体壁厚减薄至低于计算最小需要壁厚，或出现大面积无法修复的裂纹导致真空无法维持。此时需评估整体更换凝汽器的经济性，而非单独更换壳体。 |
| 管板 | 凝汽器 | 用于固定管束并与壳体连接，将蒸汽凝结区与水室分隔，承受两侧压差。 | 否 | 大修时检查管板与冷却管胀接或焊接处有无腐蚀、泄漏痕迹；对管板表面进行渗透探伤检查裂纹；检查管板与壳体焊缝有无开裂。发现管孔腐蚀时可进行铰孔后重新胀接。 | 管板出现大面积贯穿性裂纹或管孔区腐蚀严重导致大量管口无法密封，堵管率超过设计允许上限，整体更换管板（通常需连同管束一起更换）。 |
| 管束 | 凝汽器 | 由大量冷却管按带状、辐射状等排列形成的换热核心区域，蒸汽在管外凝结，冷却水在管内流动。 | 否 | 运行中监控端差和凝结水水质（硬度、电导率），端差增大说明结垢或堵管，凝结水水质恶化说明冷却管泄漏；定期投运胶球清洗系统保持管内清洁；大修时统计堵管数量和分布，评估剩余换热能力。 | 堵管率超过10%且端差严重超标，整批换管经济上优于继续堵管；管束大面积腐蚀导致反复泄漏。整批换管需拆除旧管束，清理管板，穿入新管并逐根胀接或焊接，完成后整体水压试验。 |
| 冷却管 | 管束 | 组成管束的换热元件，材质多为铜、钛或不锈钢，管内流通冷却水，外部接受蒸汽凝结，易受腐蚀和结垢。 | 是 | 运行中监控循环水质，控制氯离子、pH和悬浮物浓度；每年小修时进行涡流探伤抽查冷却管壁厚和裂纹；根据水质情况定期进行胶球清洗或化学清洗；大修时重点检查管口胀接处有无泄漏，及时堵漏或换管。 | 单根冷却管出现以下情况应堵管或换管：管壁穿孔泄漏无法补焊、涡流探伤判定壁厚减薄超过50%、管口胀接处反复泄漏且重新胀接无效。当堵管数超过总管数10%时，应规划整批换管。换管时先割除旧管，清理管板孔，选用同材质新管重新胀接或焊接，逐根进行水压试验。 |
| 中间管板 | 凝汽器 | 设置于管束中部的支撑板，用于固定和定位冷却管，防止振动和下垂。 | 否 | 大修时检查中间管板有无变形、腐蚀及与冷却管的配合间隙是否增大；管板支撑螺栓有无松动。如发现冷却管振动加剧应排查中间管板是否失效。 | 中间管板严重变形导致冷却管支撑失效、大面积腐蚀减薄丧失刚度，或与壳体连接焊缝多处开裂。更换需拆除相关区域冷却管后进行，施工复杂度较高。 |
| 水室 | 凝汽器 | 分配和汇集循环冷却水的腔室，其盖板可拆卸，每个流道设有放水、放气接口。 | 否 | 小修时打开各水室盖板检查内壁腐蚀、淤积和涂层状态；清理沉积物；检查阴极保护系统运行情况；检查盖板密封垫状态。大修时对壁面做超声测厚记录减薄趋势。 | 水室壁板大面积腐蚀减薄导致多处泄漏，局部补焊无效。需切割更换壁板并重新涂覆防腐层。 |
| 进水水室 | 水室 | 循环冷却水首先进入的水室，位于凝汽器一侧。 | 否 | 小修时打开水室盖板检查内部淤积、腐蚀和阴极保护阳极块消耗情况；清理沉积物和贝壳类生物；检查防腐涂层是否脱落。停机期间排空水室并保持干燥。 | 水室壁板腐蚀穿孔或大面积减薄，无法通过局部补焊修复。更换时需割除旧壁板，焊接新板并重新涂覆防腐层。 |
| 回流水室 | 水室 | 冷却水从进水侧冷却管流出后转折返回的水室，位于凝汽器另一侧。 | 否 | 同进水水室。打开盖板后检查内壁腐蚀、淤积及隔板密封情况；重点检查拐角处冲蚀。 | 同进水水室。壁板严重腐蚀或隔板密封失效导致水流短路。 |
| 回水水室 | 水室 | 冷却水最终汇集并流回循环水管路的水室，与进水水室同侧。 | 否 | 同进水水室。检查出水格栅有无破损、内壁腐蚀情况。 | 同进水水室。 |
| 水室盖板密封垫 | 水室 | 水室可拆卸盖板与法兰间的密封件，防止冷却水泄漏和空气漏入破坏真空。 | 是 | 每次打开水室盖板后检查密封垫有无老化、变形、压痕过深或局部撕裂；如弹性尚可且无损伤可继续使用一个周期，但建议每次大修更换；安装时法兰面应清洁平整，螺栓对角均匀紧固。 | 密封垫出现断裂、严重变形或老化发硬失去弹性，导致水室漏水或空气渗入影响真空。拆除旧垫后彻底清理法兰面水垢和残留物，选用同规格耐候橡胶垫或缠绕垫片安装，注意垫片就位准确、不偏移。 |
| 热井 | 凝汽器 | 位于凝汽器下部的集水容器，汇集主凝结水和各种疏水，为凝结水泵提供灌注静压头。 | 否 | 大修时检查热井内壁腐蚀、沉积物堆积情况；清理底部淤泥和铁锈；检查水位计连通道是否通畅；防腐涂层完好性检查。 | 热井壁板严重腐蚀减薄或穿孔，影响凝结水水质。局部腐蚀可补焊，大面积损伤需更换热井壳体。 |
