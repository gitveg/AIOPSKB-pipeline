| 子系统名称 | 描述 |
|------------|------|
| 蒸汽冷凝系统 | 接收汽轮机排汽，通过壳体、冷凝管束、管板及支撑隔板使蒸汽在管外表面凝结为液态水，实现相变并释放潜热给冷却水。涵盖蒸汽进口段、管束布置（含空气冷却区），边界从蒸汽进口至凝结水落入热井之前的冷凝空间，不涉及凝结水收集与真空维持。 |
| 真空维持系统 | 通过抽气器或真空泵、连接管道及隔离阀，连续抽除凝汽器内部不凝结气体（如空气），保持并调节真空度以降低背压。子系统包括空气冷却区、气体导流挡板及抽气管接口，边界从抽气口至气体排出，不涵盖蒸汽凝结本身。 |
| 冷却水系统 | 为凝汽器提供持续冷源，冷却水经进水室、出水室、水室分隔墙及防腐蚀内衬均匀进入冷凝管，吸收蒸汽潜热后排出。功能范围限定于凝汽器本体水侧流道，不含外部循环水管路。胶球清洗装置按设备实际配置决定是否列入。 |
| 凝结水收集与除氧子系统 | 汇集冷凝后的凝结水至热井，通过内置除氧装置（淋水盘、鼓泡等）去除溶解氧，防止腐蚀，并为凝结水泵提供稳定吸入压头。涵盖热井、导流挡板、除氧元件及凝结水出口，具备储水缓冲功能。 |
