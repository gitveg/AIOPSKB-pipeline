| 永磁发电机 (PMG) | 励磁系统 | 提供与主机输出无关的恒定励磁电源，增强励磁系统抗波形畸变能力和短路电流支持能力，保证AVR以及数字式调节器可靠工作。 | 否 | 大修时测量PMG定转子绕组绝缘电阻和直流电阻；检查永磁体有无退磁迹象（输出电压下降）；检查轴承状态和气隙均匀度。 | 永磁体严重退磁导致输出电压显著下降；绕组烧毁或绝缘击穿。需整体更换或返厂维修。 |
| 励磁机定子 | 励磁系统 | 交流励磁机的磁场部分，由AVR供电产生静止磁场，安装于发电机后端盖内侧的支架上。 | 否 | 大修时测量励磁机定子绕组直流电阻和绝缘电阻；检查绕组表面有无过热变色和绝缘损伤；检查安装支架是否紧固。 | 绕组绝缘严重老化或烧毁；铁芯叠片松动。需重新绕制或更换定子。 |
| 励磁机转子 | 励磁系统 | 交流励磁机的电枢部分，与主发电机同轴旋转，产生三相交流电，经旋转整流桥为发电机转子供电。 | 否 | 大修时测量转子绕组直流电阻和绝缘电阻；检查绕组绑扎和固定有无松动；检查导电片和引出线有无裂纹。 | 绕组匝间短路或绝缘击穿；绑扎松动导致绕组位移。需返厂重绕。 |
| 旋转整流桥 | 励磁系统 | 盘式结构，将励磁机电枢输出的交流电转换为直流电，为发电机转子磁极线圈提供励磁电源。整流元件安装在两个半圆弧形导电板上。 | 否 | 大修时逐个测量整流元件正反向特性，不合格即更换；检查导电板和绝缘垫状态；测量整流桥对地绝缘电阻；检查紧固件力矩。运行中如励磁电流异常波动应排查整流桥元件。 | 整流桥大面积元件损坏或导电板严重烧蚀，且盘体结构变形无法继续安装元件。更换整流桥盘体时注意绝缘处理和元件安装力矩，完成后进行静态特性测试。 |
| 导电板 | 旋转整流桥 | 半圆弧形结构，用于安装和连接整流元件，形成整流桥的正极和负极输出端。 | 否 | 大修时检查导电板表面有无烧蚀和裂纹；检查与整流元件的连接是否紧固；检查绝缘垫有无老化破损。 | 导电板严重烧蚀或出现裂纹影响导电和安装；绝缘垫击穿。更换导电板时注意绝缘处理和元件安装力矩。 |
| 浪涌抑制器 | 旋转整流桥 | 连接在旋转整流桥正负极之间，抑制动态过程中转子绕组可能产生的过电压，保护整流元件。 | 否 | 大修时测量浪涌抑制器伏安特性，与出厂值对比判断是否劣化；检查外观有无击穿变色和裂纹。 | 伏安特性严重偏移或漏电流显著增大；外观可见击穿痕迹。更换时选用同规格备件，注意极性和安装力矩。 |
| 自动电压调节器 (AVR) | 励磁系统 | 实时检测发电机输出电压，自动调节励磁机定子磁场电流，以在不同负载工况下维持电压稳定。 | 否 | 定期通过软件或面板检查运行参数和故障记录；核对控制参数和保护定值；做手动/自动切换试验和阶跃响应试验；检查各I/O端口接线可靠性；备份参数设定。大修时做完整的静态特性和动态特性试验。 | 核心控制板损坏且无备件替代；多次故障导致运行不可靠。更换AVR后需通过专用软件下载参数并做空载和负载工况下的电压调节试验。 |
| 模拟式自动电压调节器 | 自动电压调节器 (AVR) | 通过模拟电路进行电压调节，具备基本的电压调节和手动/自动切换功能，可外接电位器远控调压。 | 否 | 定期检查各电位器旋钮有无松动、接触不良；检查印刷电路板有无虚焊、变色；核对电压整定值和调差率；定期做手动/自动切换试验。 | 核心模拟元器件失效且无备件替代；电路板大面积损坏。更换时按出厂参数重新整定各电位器。 |
| 数字式自动电压调节器 | 自动电压调节器 (AVR) | 采用微处理器进行数字信号处理与调节，参数需通过专用软件调整，可实现更复杂的控制、限制和保护功能。 | 否 | 定期通过专用软件读取运行参数和故障记录；检查各I/O端口接线是否可靠；核对控制参数和保护定值；备份参数设定。 | 主控板损坏无法修复或程序丢失且无法恢复；通讯接口全部失效。更换后需通过专用软件重新下载参数并做静态调试和动态试验。 |
| AVR内部电源模块 | 自动电压调节器 (AVR) | 将外部输入的交流或厂用直流电源转换为AVR工作所需的稳定直流电压，其故障会导致调节器失控。 | 是 | 定期检查电源模块输出电压是否在允许范围内；检查模块散热片有无过热变色；检查输入端接线是否牢固。运行中如AVR频繁复位或指示灯闪烁，应优先排查电源模块。 | 电源模块输出电压严重偏移或纹波超标，导致AVR工作异常；模块内部元器件烧毁。更换同型号电源模块后测量输出电压确认正常。 |
| 功率整流桥 | 励磁系统 | 采用可控硅或整流元件，将交流电转换为直流电，是励磁功率输出的核心通道，通常为三相全控或半控桥式结构。 | 是 | 定期测量各桥臂可控硅正反向阻断特性；检查散热器与元件接触面导热硅脂是否干涸；检查冷却风道是否通畅；紧固各接线端子。大修时逐个做可控硅触发特性测试。 | 可控硅击穿短路或正向压降严重超标；散热器严重氧化影响散热。更换可控硅时注意规格、耐压和触发电流参数一致，安装后做触发测试。 |
| 快速熔断器 | 励磁系统 | 串联在功率整流元件的支路中，用于在发生短路或严重过载时迅速熔断，切断故障电流。备品备件数量不少于使用量的30%。 | 是 | 定期巡检检查熔断器指示器是否弹出；测量熔断器两端电压降，压降异常增大说明接触不良或内阻增大；每次大修检查熔断器夹紧力和弹簧状态。备件库存保持充足。 | 熔断器熔断（指示器弹出）；底座或夹持件严重氧化导致接触不良。更换时选用同型号同规格产品，检查底座清洁后装入，确保接触可靠。 |
| 磁场断路器 | 励磁系统 | 安装在励磁回路中，用于正常停机时切断励磁电流，或在故障时执行快速灭磁操作。 | 是 | 定期检查主触头磨损和烧蚀情况；检查灭弧栅片有无严重烧损；测量合闸和跳闸线圈直流电阻；定期做合分闸操作试验验证动作可靠性。 | 主触头严重烧损经打磨后仍无法保证良好接触；灭弧栅片大面积烧损；操作机构卡涩无法修复。更换断路器时核对额定电流和灭磁参数，安装后做合分闸试验。 |
| 非线性电阻 | 励磁系统 | 在灭磁过程中接入磁场绕组两端，吸收磁场能量，限制灭磁过程中产生的过电压，保护发电机转子绝缘。 | 是 | 大修时测量非线性电阻伏安特性，与出厂值或上次记录对比判断劣化程度；检查外观有无裂纹、变色和放电痕迹；绝缘电阻测量。 | 伏安特性严重偏移（残余电压显著升高或漏电流增大）；外观可见裂纹或贯穿性击穿痕迹。更换时选用同型号备件，注意安装极性和绝缘距离。 |
| 可控硅跨接器 | 励磁系统 | 用于在灭磁或特定保护动作时，将灭磁电阻或其他保护元件接入励磁回路，实现快速灭磁或过电压保护。 | 是 | 大修时测量跨接器可控硅触发特性和正反向阻断电压；检查散热器安装是否牢固；定期做灭磁试验验证跨接器动作可靠性。 | 可控硅击穿或触发特性劣化无法可靠触发；散热器严重变形。更换可控硅后做触发试验和灭磁试验。 |
| 脉冲变压器 | 励磁系统 | 用于隔离和传输触发信号，驱动功率整流桥中的可控硅导通。其绝缘性能直接影响可控硅工作的可靠性。 | 是 | 大修时测量脉冲变压器绕组直流电阻和绝缘电阻；检查输出脉冲波形幅值和宽度是否满足可控硅触发要求；检查引出线绝缘有无破损。 | 绕组绝缘击穿或匝间短路导致输出脉冲异常；铁芯损坏。更换同规格脉冲变压器后测试脉冲输出波形。 |
| 脉冲线绝缘套管 | 励磁系统 | 套在脉冲变压器至可控硅的触发信号线上，防止高压窜入控制回路，避免因绝缘破损导致可控硅误导通或击穿。 | 是 | 大修时检查套管有无裂纹、老化和爬电痕迹；测量绝缘电阻。运行中如出现可控硅误触发现象，应排查脉冲线绝缘。 | 套管出现裂纹或绝缘电阻严重下降。更换时选用耐高压套管，确保密封良好。 |

| 电流互感器 (TA) | 励磁系统 | 测量发电机定子电流或励磁变压器电流，提供电流信号用于无功调差、补偿、过励限制等控制与保护功能。 | 否 | 同TV。定期校验变比和准确度；检查接线和端子状态；测量绝缘电阻。 | 绕组绝缘击穿或变比严重偏移。更换后重新校验并核对接线。 |
