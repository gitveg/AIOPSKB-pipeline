| 子系统名称 | 描述 |
|------------|------|
| 空气动力子系统 | 由叶轮、轮毂与叶片构成，是离心风机实现气体增压输送的核心能量转换单元。利用叶轮高速旋转产生的离心力，将机械能转化为气体的动能与压力能，使气体从轴向吸入、径向排出，形成连续的气流循环。 |
| 驱动子系统 | 包含电动机、联轴器和传动主轴，负责为叶轮旋转提供可控的机械动力。电动机将电能转换为旋转扭矩，通过联轴器与主轴将动力可靠传递至叶轮，满足风机在不同工况下对转速与功率的需求。 |
| 结构支撑与导流子系统 | 由机壳、进风口、出风口及底座组成，构成完整的气流通道与刚性支撑骨架。机壳收集从叶轮甩出的高速气体，将部分动压转为静压；进风口引导气体均匀进入叶轮；底座承受整机动静载荷，保证安装定位精度。 |
| 调节子系统 | 涵盖进口导叶、调节风门及配套执行机构，用于适应系统管网阻力变化，调节风机运行工况。通过改变导叶角度或风门开度控制风量与压力，实现变工况下的高效匹配，防止喘振并降低能耗。 |
| 控制与保护子系统 | 集成传感器、控制器与电气保护回路，对风机启停、转速、振动、温度和电流进行实时监测与闭环控制。具备过载、过热、振动超限等故障诊断与联锁停机功能，保障设备在安全边界内运行并支持远程运维。 |
| 辅助子系统 | 主要包含轴承润滑与冷却单元，为高速旋转的传动部件提供可靠润滑与散热。通过油脂润滑、油浴润滑或稀油站循环供油，减少轴承磨损，同时配合风扇或水冷盘管对轴承箱进行强制冷却，控制温升，延长部件寿命。 |
