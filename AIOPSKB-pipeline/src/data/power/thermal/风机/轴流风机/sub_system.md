| 子系统名称 | 描述 |
| :--- | :--- |
| 叶轮气动系统 | 由叶片和轮毂组成的旋转核心，承担将机械能转化为空气动能与压力能的功能。负责产生轴向气流，决定风机的风量、风压及效率，是流体输送的直接执行单元。 |
| 驱动电机系统 | 包含电动机及其冷却风扇，为叶轮旋转提供稳定扭矩和转速。功能边界覆盖电能输入到旋转机械能输出的全部过程，包括电机内部的电磁转换和热量管理，不涉及电机的控制指令生成。 |
| 传动与轴承系统 | 连接电机轴与叶轮轴，并支撑转子系统的旋转运动。通常为直联传动（包含联轴器）或皮带传动，轴承负责承受径向与轴向载荷，确保转动部件具有精确的对中和低摩擦运行状态。 |
| 导流与整流系统 | 包含集流器、扩散筒及可能的前/后导叶。功能是优化气流进出叶轮的流态，降低涡流损失，将部分出口动压转为静压，并引导气流按设计方向流动，实现风机内部流场的规则化。 |
| 机壳与支撑结构 | 由风机外壳、安装支架、底座及进出口法兰等构成。为各子系统提供精确的定位安装和物理防护，形成封闭的气流通道，并将风机所有静、动载荷安全传递至安装基础。 |
| 控制系统与传感监测 | 涵盖变频器、启动器、风阀控制器及振动、温度传感器等。根据外部指令调节风机的启停、转速和风量，实时获取运行状态参数，并对过载、过温、异常振动等实施保护性停机，确保设备在安全边界内运行。 |
