| 子设备名称 | 描述 |
|------------|------|
| 背压式汽轮机 | 排汽压力高于大气压且全部用于工业或供暖热用户，无凝汽器，综合热效率高。 |
| 凝汽式汽轮机 | 排汽在凝汽器中凝结成水并建立高度真空，主要用于纯发电，需配置冷却水系统。 |
| 抽汽凝汽式汽轮机 | 在通流中间抽出部分蒸汽供热，可调节抽汽量，剩余蒸汽继续做功后排入凝汽器。 |
| 抽汽背压式汽轮机 | 中间抽汽和最终排汽皆用于供热，实现蒸汽梯级利用，无凝汽器，热经济性突出。 |
| 湿蒸汽汽轮机 | 进汽为饱和或接近饱和参数，用于核电站或余热发电，需考虑湿蒸汽侵蚀与去湿设计。 |
| 工业汽轮机 | 用于驱动压缩机、泵等工业机械，常为变转速运行，注重调速性能与可靠性，非电网并网发电。 |
| 地热利用汽轮机 | 利用地热蒸汽或闪蒸汽做功，进汽参数较低，需抗腐蚀和防结垢特殊设计。 |
| 联合循环汽轮机 | 利用燃气轮机排气余热产生蒸汽驱动，与燃机组成联合循环，快速启停特性突出。 |
| 单轴联合循环汽轮机 | 汽轮机与燃气轮机同轴驱动同一台发电机，系统布置紧凑，对轴系稳定性和控制要求高。 |
| 高压汽轮机 | 进汽压力高，通常为超临界或超超临界参数，叶片较短，对材料耐高温高压性能要求极高。 |
| 中压汽轮机 | 接收高压缸排汽或再热蒸汽，工作于中间压力段，通常与高压缸或低压缸合缸布置。 |
| 低压汽轮机 | 工作于低参数、大容积流量蒸汽条件，末级叶片极长，多采用双分流结构排入凝汽器。 |
| 冲动式汽轮机 | 蒸汽主要在静叶中膨胀加速，在动叶中依靠汽流冲击产生轮周力，级内反力度很小。 |
| 反动式汽轮机 | 蒸汽在静叶和动叶均发生膨胀加速，利用气流动量和反作用力做功，级内反力度约50%。 |
