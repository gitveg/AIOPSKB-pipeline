| 设备类型名称 | 设备属性 | 描述 |
| :--- | :--- | :--- |
| 锅炉 | 主设备 | 通过燃烧煤炭等燃料加热给水，产生高温高压蒸汽，为汽轮机提供做功工质的热能转换核心设备。 |
| 汽轮机 | 主设备 | 将锅炉产生的高温高压蒸汽的热势能转换为转子旋转机械能的原动机，驱动发电机转动。 |
| 发电机 | 主设备 | 利用电磁感应原理，将汽轮机传递的机械能转换为电能的设备，通常为三相交流同步发电机。 |
| 凝汽器 | 主设备 | 在汽轮机排汽口建立并维持高度真空，将做完功的乏汽冷凝成水，回收工质并提高循环热效率。 |
| 主变压器 | 主设备 | 将发电机输出的低电压大电流电能转换为高电压等级，以便通过电网高效输送。 |
| 发电机出口断路器 | 主设备 | 装设于发电机出口与主变压器低压侧之间，用于机组并网、解列和切断故障电流的专用大容量断路器。 |
| 励磁系统 | 辅助设备 | 向发电机转子提供可调节的直流电流，建立旋转磁场，并维持机端电压恒定。主要由励磁变压器、励磁调节器、功率整流柜等组成。 |
| 空冷岛 | 辅助设备 | 在直接空冷机组中，汽轮机排汽直接进入空冷凝汽器完成相变，是凝汽器功能的空冷化延伸。 |
| 冷却塔 | 公用系统 | 将循环水热量释放到大气中的冷却构筑物，通常为多机共用的大型自然通风或机力通风冷却塔。 |
| 风机 | 辅助设备 | 火电送风机/引风机/一次风机（统称烟风系统风机）的通用检维修知识载体，按结构路线分子设备。风机故障机理（轴承/叶轮/转子/振动/喘振/磨损）通用，PHM振动诊断不分功能；工况（送风/引风含烟气磨损积灰/一次风）在故障参数层标注。子设备：离心风机（送风/一次风/小机组引风）、轴流风机（大机组引风/送风，动调/静调）。 |
| 离心泵 | 辅助设备 | 火电各系统离心泵（给水泵/循环水泵/炉水循环泵/凝结水泵）的通用检维修知识载体，按结构路线分子设备。离心泵故障机理（轴承/密封/叶轮/振动/汽蚀）高度通用，PHM振动诊断不分功能；各工况特异（给水高压/循环大流量）在故障参数层标注。子设备：卧式离心泵（覆盖给水泵/循环水泵/炉水循环泵工况）、立式筒袋泵（凝结水泵，立式结构异）。 |
| 给水加热器 | 辅助设备 | 利用汽轮机抽汽加热锅炉给水（高压加热器）或凝结水（低压加热器）的管壳式表面式换热器，提高循环热效率。子设备：高压加热器、低压加热器（同属管壳式换热器，故障机理同质，按结构和参数路线区分）。 |
| 除氧器 | 辅助设备 | 采用热力喷雾或旋膜方式除去给水中溶解的氧气及其他气体，防止热力设备腐蚀，是回热系统的核心设备之一。 |
| 凝结水精处理 | 辅助设备 | 对凝结水进行全流量或部分流量脱盐处理，去除因凝汽器泄漏或系统腐蚀带入的杂质，保障锅炉给水品质。 |
| 烟气余热利用 | 辅助设备 | 在脱硫塔前或烟道加装低温省煤器，回收尾部烟气余热加热凝结水或供厂区采暖，降低排烟温度、提高锅炉效率。 |
| 电气一次系统 | 辅助设备 | 实现厂用电能接收、变换与分配的高压及低压一次设备群，包括厂用变压器、GIS、封闭母线与厂用配电装置。子设备：高压厂用变压器、启动/备用变压器、户内/外GIS组合电器、封闭母线、厂用配电装置。 |
| 电气二次及电源系统 | 辅助设备 | 实现继电保护、自动控制、故障录波及交直流控制电源供应的二次设备与电源系统集群。子设备：继电保护装置、自动准同期装置、厂用电快速切换装置、故障录波器、直流电源系统、交流不间断电源(UPS)。 |
| 全厂水务系统 | 公用系统 | 涵盖原水取水、预处理、锅炉补给水除盐及废水处理的全厂水系统集群。子设备：取水泵房、原水预处理系统、化学水处理系统、废水处理系统。 |
| 辅机冷却水系统 | 公用系统 | 采用闭式除盐水或开式工业水为全厂辅机轴承及冷却器提供冷却介质的系统。子设备：闭式冷却水系统、工业水系统。 |
| 燃料供应系统 | 公用系统 | 负责燃煤接卸、储存、输送及点火助燃用油供应的燃料来源系统。子设备：输煤系统、燃油系统。 |
| 辅助及启动蒸汽系统 | 公用系统 | 提供机组启动、停机及低负荷用汽的蒸汽供应系统，含启动锅炉及辅助蒸汽母管。子设备：辅助蒸汽系统、启动锅炉。 |
| 分散控制系统(DCS) | 辅助设备 | 对机组主辅设备及工艺流程进行集中监控、数据采集、顺序控制和调节控制的计算机控制系统，跨专业且独立性强。 |
| 压缩机 | 辅助设备 | 火电厂用压缩机（仪用压缩空气供控制仪表和阀门、厂用压缩空气供检修吹扫）的通用检维修知识载体，按结构路线分子设备。压缩机故障机理（转子啮合/轴承/润滑油/轴端密封/气阀/排气超温/气量衰减/振动）通用，PHM振动诊断不分工况；工况特异（仪用高纯干燥/厂用大流量）在故障参数层标注。子设备：双螺杆压缩机（火电主力，双螺杆转子容积式压缩）。 |
| 暖通空调系统(HVAC) | 公用系统 | 维持电子间、集控室、配电室等对温度、湿度和洁净度有严格要求的设备及人员环境的建筑设施系统。 |
| 消防水系统 | 公用系统 | 提供全厂各区域，特别是变压器、油区、输煤栈桥、电缆夹层等重点防火部位的消防水源和泡沫设备，属强制独立安全设施。 |
| 柴油发电机组 | 辅助设备 | 在全厂失去交流外部电源的应急工况下，自动启动向重要保安负荷供电的保安应急电源，保障机组安全停机。 |
| 烟囱 | 辅助设备 | 将经过除尘、脱硫、脱硝并符合排放标准的烟气在高空排放的烟气排放构筑物，利用大气扩散稀释残余污染物。 |
| 汽机房行车 | 辅助设备 | 安装于汽机房顶部，用于汽轮机、发电机等主设备安装检修时大件吊装和转运的全厂公用检修起重装备。 |
| 抛煤机/链条炉排 | 辅助设备 | 在层燃锅炉中，通过机械抛煤或连续移动的链条炉排实现燃料的均匀布料和分层燃烧的设备，多见于工业锅炉及特殊炉型。 |
| 炉水循环泵 | 辅助设备 | 用于强制循环汽包锅炉（检维修知识见「离心泵/卧式离心泵」，强制循环工况；炉水循环泵为湿式/湿定子电机泵，结构特异项在卧式离心泵故障参数层补充）。 |
