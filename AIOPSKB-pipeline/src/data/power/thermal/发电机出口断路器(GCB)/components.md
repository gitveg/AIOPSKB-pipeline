| 灭弧室总成 | — | GCB核心开断单元。SF6型采用自能式（热膨胀+压气混合）灭弧原理，真空型采用密封真空灭弧室。额定短路开断电流可达63~110kA，开断时间<=60ms。含双触头系统（主触头承载额定电流、弧触头承担开断电弧）。典型代表：ABB/Hitachi Energy HEC/HECS系列（SF6）、Siemens HB3系列3AH36模块（真空）。 | 否 | 大修时测量灭弧室回路电阻，与出厂值比对；检查SF6气体密度/压力、微水含量；检查真空灭弧室真空度（可通过工频耐压或真空测试仪检测）；SF6型需检查弧触头烧损量；运行中通过GMS600等监测系统监控弧触头磨损状态和气体密度。 | SF6灭弧室内部弧触头烧损超过允许值（通常由累计开断次数和开断电流评估），或气体泄漏无法维持额定压力；真空灭弧室真空度下降至不合格水平。整体灭弧室报废时需由厂家回收更换，旧灭弧室由专业机构处理。 |
| 主触头 | 灭弧室总成 | 额定电流通流触头，由静主触头和动主触头组成。采用铜或银镀铜材质，低接触电阻设计，承担发电机满载电流（6000~13500A）。合闸时先于弧触头闭合，分闸时先于弧触头分离，不参与灭弧。 | 是 | 大修时测量主触头回路电阻，与出厂值比对判断接触状态；检查触头表面有无氧化、变色和过热痕迹；检查触头压力和超行程。运行中监控导电回路温升。 | 主触头表面严重氧化导致接触电阻显著增大；触头镀银层磨损露出铜基体；触头压力弹簧疲劳导致接触不良。更换主触头需拆卸灭弧室，由厂家或授权服务人员执行。 |
| 静主触头 | 主触头 | 固定于灭弧室内的电流承载触头，通常为花瓣式或指形结构，材质为铜基镀银。与动主触头配合构成低电阻通流回路。 | 是 | 大修时目视检查触指有无变形、烧灼痕迹；测量接触电阻。 | 触指变形或烧损导致接触电阻超标。需整体更换静触头组件。 |
| 动主触头 | 主触头 | 由绝缘拉杆驱动的运动触头，随操动机构动作与静主触头闭合/分离。材质为铜基镀银，设计确保合闸时先接触、分闸时先分离。 | 是 | 大修时检查动触头运动灵活性；检查触头表面状态和磨损情况；测量超行程和接触电阻。 | 触头表面严重烧蚀或磨损；运动卡涩无法通过润滑调整恢复。更换需拆卸灭弧室。 |
| 弧触头 | 灭弧室总成 | 专用于电弧开断的耐弧触头，由静弧触头和动弧触头组成。采用铜钨（CuW）或银钨（AgW）合金材料，耐受电弧高温（可达数万K）。合闸时晚于主触头闭合，分闸时晚于主触头分离，确保电弧仅在弧触头之间燃烧。 | 是 | 大修时测量弧触头超行程和接触电阻；通过累计开断电流（kA-次数）评估烧损程度；有条件时使用声发射监测技术评估弧触头磨损；GMS600等监测系统可在线估算弧触头电气寿命。 | 弧触头烧损量超过允许值（通常由超行程减小量和累计开断电流判定）。SF6型GCB满容量开断次数一般不超过5~30次（视型号而定），达到限值必须更换弧触头组件。更换需由厂家执行大修。 |
| 静弧触头 | 弧触头 | 固定于灭弧室内的耐弧触头，采用铜钨合金制造。与动弧触头配合在分闸过程中最后分离，承受电弧的全部热效应。 | 是 | 大修时检查弧触头端部烧损形态和长度变化；测量与动弧触头的接触超行程。 | 端部烧损导致超行程低于允许最小值；CuW合金体出现裂纹或严重烧蚀。更换由厂家执行。 |
| 动弧触头 | 弧触头 | 由绝缘拉杆驱动的运动耐弧触头，采用铜钨合金制造。分闸时最后与静弧触头分离引燃电弧，其运动同时驱动压气/吹弧动作。 | 是 | 大修时检查弧触头端部烧损和长度变化；测量超行程；检查运动灵活性。 | 端部烧损导致超行程低于允许值；运动部分磨损或变形导致卡涩。更换需由厂家执行大修。 |
| 喷口 | 灭弧室总成 | 导引SF6气流的耐弧喷管，采用聚四氟乙烯（PTFE）添加Al2O3或MoS2填料制造（真空型无此件）。位于弧触头周围，在分闸过程中通过拉瓦尔喷管效应将SF6气体以超音速喷射到电弧区，冷却并熄灭电弧。 | 是 | 大修时检查喷口内壁有无烧蚀、碳化和变形；测量喷口喉部直径变化量；喷口烧蚀程度与累计开断电流直接相关。 | 喷口内壁严重烧蚀导致喉部直径扩大超过允许值；PTFE材料碳化深度超标或出现贯穿性裂纹。喷口为SF6灭弧室中典型的易损替换件，达到磨损限值需更换。更换需由厂家执行，旧喷口按PTFE废料处置。 |
| 压气缸/压气室 | 灭弧室总成 | SF6型灭弧室中用于压缩SF6气体的机械腔体（真空型无此件）。分闸时由动触头系统驱动活塞压缩SF6气体，产生初始吹弧气流。与热膨胀室配合实现自能式灭弧。 | 否 | 大修时检查压气缸内壁和活塞密封面有无磨损和拉伤；检查活塞O形密封圈状态。 | 压气缸内壁严重磨损导致气压建立不足；活塞密封失效无法修复。需更换压气缸组件，由厂家执行。 |
| 热膨胀室 | 灭弧室总成 | SF6型灭弧室中的电弧能量利用腔体（真空型无此件）。电弧加热SF6气体产生高压，与压气作用叠加形成强力吹弧气流，实现大电流开断。 | 否 | 大修时检查热膨胀室内部有无积碳和异物；检查内壁有无烧蚀痕迹。 | 热膨胀室内壁严重烧蚀或变形影响灭弧性能。需由厂家评估修复或更换。 |
| 吸附剂（分子筛） | 灭弧室总成 | 装于SF6灭弧室内部的干燥/净化剂，通常为活性氧化铝或合成沸石分子筛。吸收SF6气体中的水分及电弧分解产物（如SF4、SOF2、HF等），维持气体纯度。 | 是 | 大修时检查吸附剂是否饱和（颜色指示或称重法）；SF6气体微水检测超标时应考虑更换吸附剂；每次灭弧室大修均应更换。 | 吸附剂吸水/吸酸饱和，颜色变化或重量增加超过规定值。更换旧吸附剂时需按含氟化合物危险废物处置，交由专业环保机构处理，不得随意丢弃。 |
| 屏蔽罩 | 灭弧室总成 | 真空灭弧室内部的金属屏蔽罩，通常采用无氧铜或不锈钢制造。吸附电弧产生的金属蒸气，保护绝缘外壳内壁，改善电场分布。SF6型中为均压屏蔽罩，优化电场。 | 否 | 大修时（真空型）检查屏蔽罩表面有无金属飞溅沉积和烧蚀；SF6型检查均压罩有无变形。 | 真空型屏蔽罩表面金属沉积严重导致绝缘性能下降，通常与真空灭弧室整体更换。SF6型均压罩变形需更换。 |
| 绝缘拉杆 | 灭弧室总成 | 连接操动机构与动触头系统的传动杆件，采用环氧树脂浇注绝缘或引拔绝缘杆制造。将操动机构的机械运动传递至灭弧室内动触头，同时提供高压带电体与地之间的绝缘隔离。 | 否 | 大修时检查绝缘拉杆表面有无裂纹、放电痕迹和机械损伤；测量绝缘电阻。 | 绝缘拉杆出现贯穿性裂纹或表面严重爬电；绝缘电阻低于允许值。更换需由厂家执行。 |
| 操动机构总成 | — | 驱动断路器分合闸操作的机械装置。SF6型GCB（ABB HEC/HGI系列）采用液压弹簧操动机构（HMB系列）；真空型GCB（Siemens HB3/3AH36）采用弹簧储能操动机构。具备储能-合闸-分闸完整操作循环，额定操作顺序为分-0.3s-合分-180s-合分。机械寿命通常>=10000~20000次。 | 否 | 定期检查机构动作计数器；大修时检查分合闸时间和速度特性；检查各传动部件有无磨损和松动；检查储能电机工作电流和储能时间；进行机械特性试验（分合闸时间、同期性、弹跳）。 | 操动机构机械寿命达到额定次数（通常10000~20000次CO循环）；关键传动部件（挚子、凸轮、连杆）出现疲劳裂纹或严重磨损。需由厂家执行机构大修或整体更换。 |
| 储能系统 | 操动机构总成 | 弹簧储能型：由储能电机、减速齿轮、合闸弹簧（螺旋弹簧或碟簧）、棘轮棘爪组成。液压弹簧型（ABB HMB）：由油泵、高低压油路、碟簧储能柱、换向阀组成。储能后具备分-合分完整操作能力。 | 否 | 定期检查储能时间和储能电机电流；检查储能状态指示是否正常；大修时检查弹簧有无疲劳变形和裂纹；液压型需检查油位、油质和系统密封性。 | 储能弹簧出现疲劳断裂或永久变形；液压系统碟簧柱失效；油路严重泄漏。更换储能弹簧或碟簧柱需由厂家执行。 |
| 合闸线圈（合闸电磁铁） | 操动机构总成 | 接收合闸命令后动作，释放合闸挚子使储能弹簧释放能量驱动触头闭合的电磁驱动元件。适用DC 110V/220V或AC 220V控制电源。 | 是 | 大修时测量合闸线圈直流电阻，与出厂值比对；检查铁芯运动灵活性；检查线圈绝缘电阻。 | 线圈断线、短路或绝缘电阻低于允许值；铁芯卡涩无法通过清洁润滑恢复。更换合闸线圈时需核对控制电压和接线极性。 |
| 分闸线圈（分闸电磁铁） | 操动机构总成 | 接收分闸/跳闸命令后动作，释放分闸挚子使分闸弹簧释放能量驱动触头快速分离的电磁驱动元件。GCB通常配置1个合闸线圈和最多3个分闸线圈（1个分励脱扣+2个保护脱扣）。 | 是 | 大修时测量分闸线圈直流电阻；检查铁芯运动灵活性和行程；检查线圈绝缘电阻；测试最低动作电压（应在30%~65%额定电压范围内可靠动作）。 | 线圈断线、短路或绝缘电阻低于允许值；铁芯卡涩无法恢复。更换分闸线圈时需核对型号和接线。 |
| 传动连杆系统 | 操动机构总成 | 由凸轮、拐臂、连板、轴销、拉杆等组成的机械传动链。将操动机构的旋转运动转化为动触头的直线运动，传递分合闸力。 | 否 | 大修时检查各轴销和轴承有无磨损、松动和卡涩；检查连杆有无变形和裂纹；检查开口销和锁紧螺母状态；对活动关节适量润滑。 | 连杆变形或出现裂纹；轴销磨损导致配合间隙过大影响分合闸特性。更换连杆和轴销后需重新调整和校验机械特性。 |
| 缓冲器 | 操动机构总成 | 安装于分合闸行程终端的吸能装置，通常为油缓冲器或液压缓冲器。在分合闸到位时平稳吸收剩余动能，减小机械冲击，保护灭弧室和机构部件。 | 是 | 大修时检查缓冲器有无漏油；检查缓冲效果是否正常（分合闸速度特性曲线末端应平滑减速）；检查固定螺栓有无松动。 | 缓冲器漏油导致阻尼功能丧失；活塞杆磨损严重。更换缓冲器后需重新校验分合闸速度特性。 |
| 辅助开关 | 操动机构总成 | 与断路器主触头机械联动的多触点开关（通常为4~8对常开/常闭触点）。将断路器的分合闸位置转换为电信号，供控制回路、联锁回路和信号回路使用。 | 是 | 大修时检查辅助开关触点有无烧蚀、氧化和接触不良；测量触点接触电阻；检查与主触头的动作时序配合是否正确。 | 触点严重烧蚀或氧化导致接触不良；动作时序与主触头不匹配。更换辅助开关后需校验时序配合。 |
| 机械位置指示器 | 操动机构总成 | 与传动系统机械联动的分合闸位置指示装置（通常为指针或标牌式）。直观显示断路器处于合闸（红）或分闸（绿）位置，不依赖电源。 | 否 | 定期检查指示是否与实际位置一致；检查指示器连接机构有无松动。 | 指示器损坏无法正确显示位置。更换指示器并重新校验位置指示。 |
| 储能电机 | 操动机构总成 | 为操动机构储能系统提供动力的电动机（通常为直流电机，DC 110V/220V）。驱动齿轮机构压缩合闸弹簧或驱动液压泵为碟簧储能。合闸操作后自动启动再储能。 | 是 | 定期检查储能电机运行声音和温度；大修时测量电机绝缘电阻和直流电阻；检查碳刷磨损情况（直流电机）；检查减速齿轮有无异常磨损。 | 电机绕组绝缘电阻低于允许值；碳刷磨损至限值（直流电机）；减速齿轮损坏。更换储能电机时需核对电压等级和旋转方向。 |
| SF6气体系统 | — | SF6型GCB专有的绝缘和灭弧介质管理子系统（真空型无此系统）。包括SF6气室、气体连接管路、密度继电器/压力表、充放气阀、气体干燥过滤等。SF6气体额定压力通常为0.5~0.7MPa(abs)@20C，年泄漏率<0.5%~1%。 | 否 | 定期记录SF6气体密度/压力值，比对温度换算曲线；定期检测SF6气体微水含量（应<=150ppm_v@20C）和纯度；检查气体管路和阀门有无泄漏（定性检漏）；大修时进行全面定量检漏。运行中通过密度继电器监控气体状态。 | SF6气体系统整体不单独报废。SF6气体需回收处理（见SF6气体条目），气室壳体损坏需由厂家评估修复或更换。 |
| SF6气体 | SF6气体系统 | 六氟化硫（SF6）气体，绝缘强度为空气的2.5~3倍，具有极强的电负性和灭弧能力。GCB气室充气量通常为数公斤至数十公斤。SF6是强温室气体，GWP为CO2的23500倍，受《京都议定书》和EU F-Gas法规管控。 | 是 | 定期检测SF6气体微水含量、纯度和分解产物含量；通过密度继电器监控气体泄漏情况；补气前检测新气质量应符合IEC 60376标准。 | SF6气体必须回收处理，严禁直接排放到大气中。使用SF6回收装置（如DILO气体回收车）将气体抽出、过滤、净化后循环使用。严重污染无法净化的SF6气体须按危险废物交由具备资质的环保机构处理，采用高温焚烧等方式销毁。EU法规要求2032年起新型断路器禁用SF6。 |
