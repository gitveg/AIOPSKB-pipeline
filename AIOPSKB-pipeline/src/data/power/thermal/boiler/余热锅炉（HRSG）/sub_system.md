| 子系统名称 | 描述 |
|-------------|------|
| 烟气换热与回收系统 | 覆盖从燃气轮机高温排气进入HRSG到降温排放的全路径。包含进出口烟道、导流板及顺序布置的各级受热面管束（省煤器、蒸发器、过热器、再热器），负责引导烟气流场、控制阻力，将烟气显热高效传递给管内工质，实现余热最大化回收。 |
| 汽水分离与循环系统 | 实现给水至饱和蒸汽的转化及高效分离。以汽包和蒸发器为核心，包含下降管、上升管及内部汽水分离装置。通过自然或强制循环维持连续稳定产汽，保证受热面可靠冷却以维持金属壁温安全，并向过热系统提供纯净的干饱和蒸汽，防止汽水共腾。 |
| 蒸汽过热与调温系统 | 负责提升与精确控制输出蒸汽的热力学参数。包含过热器、再热器管束、减温器（喷水或面式）、蒸汽旁路阀及连接管路。将饱和蒸汽加热至设计过热度或重新加热汽轮机排汽，并在烟气侧波动时调节蒸汽温度，满足汽轮机入口要求并防止管壁超温。 |
| 给水预热与处理系统 | 维持汽水循环所需的高品质给水。涵盖省煤器、给水泵、调节阀、加药装置、排污系统及在线取样仪表。利用尾部余热预热除氧给水送入汽包，同时调节炉水品质，去除悬浮物和溶解盐，防止结垢与腐蚀，确保给水化学指标与流量的精准匹配。 |
| 烟气净化与排放系统 | 负责降低最终排放大气的污染物浓度与噪声，满足环保标准。集成脱硝（SCR）装置、消声器及烟囱等部件。覆盖从尾部受热面出口到烟囱出口的流程，负责氮氧化物还原、噪声控制及烟气扩散，并维持烟道系统运行阻力在设计范围内。 |
| 控制与安全保护系统 | 对整体设备进行实时监测、自动调节与安全保护。以DCS或PLC为核心，集成各类传感器、安全阀及紧急旁路挡板。覆盖所有子系统的运行逻辑控制，自动调节水位、汽压等参数，实现异常工况下的故障报警、联锁与紧急停炉，确保无人值守安全运行。 |
