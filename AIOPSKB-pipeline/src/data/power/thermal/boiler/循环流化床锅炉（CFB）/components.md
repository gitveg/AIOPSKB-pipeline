| :--- | :--- | :--- | :--- | :--- | :--- |
| 锅炉 | — | 利用燃料燃烧放出的热能加热工质（水）以生产规定参数蒸汽或热水的设备，由本体受热面、燃烧系统和锅筒等构成。 | 否 | 按规程执行大修（通常4~6年）和小修（通常1年）；大修时对受压元件进行全面检查、测厚和无损检测；小修时对燃烧器、吹灰器和阀门等关键部件进行检查维护；运行中监控主蒸汽参数、炉膛负压、排烟温度和给水品质；定期进行化学清洗和水压试验。 | 锅炉累计运行超过设计寿命（通常30年），受压元件大面积减薄或多次爆管，经强度校核和寿命评估确认无法安全运行，或修复费用超过新炉投资的60%。退役时需排空工质，拆除保温层，按受压元件和钢结构分类拆除处置。 |
| 锅炉本体 | 锅炉 | 锅炉核心部分，包括炉膛、锅筒、水冷壁、过热器、再热器、省煤器、空气预热器及燃烧器等。 | 否 | 大修时对本体各受热面进行测厚、无损检测和金相分析；检查汽包内部装置和焊缝；校验安全阀；进行水压试验验证受压元件整体强度；运行中严格控制汽水品质、蒸汽参数和管壁温度。 | 本体受压元件大面积老化或损坏，经强度评估确认无法继续安全运行。本体更换等同于新建锅炉。 |
| 炉膛 | 锅炉本体 | 燃料燃烧的空间，内壁敷设水冷壁，承受高温火焰和烟气辐射，需保证燃料充分燃烧并防止结渣。 | 否 | 运行中合理配风防止火焰偏斜贴壁和结渣；定期吹灰保持受热面清洁；大修时检查炉墙密封、耐火内衬和看火孔；测量炉膛出口烟温分布评估燃烧均匀性。 | 炉膛严重变形或水冷壁大面积损坏，炉墙密封性丧失且无法修复。需制定专项方案进行炉膛重建。 |
| 耐火材料（炉墙内衬） | 炉膛 | 由耐火砖、浇注料、保温层构成，承受火焰冲刷和热应力，易发生开裂、脱落或结渣。 | 是 | 每次小修检查炉墙内衬有无开裂、脱落和结渣；大修时修补大面积脱落的耐火浇注料；定期吹灰减少渣块堆积；运行中控制炉膛温度避免局部超温。 | 耐火浇注料大面积脱落露出保温层或外壳；耐火砖碎裂导致炉墙密封性丧失。局部损坏可挖补修复，大面积失效需重新浇注，施工后按规范烘炉。 |
| 防爆门 | 炉膛 | 安装在炉膛或烟道上的安全泄压装置，当内部压力异常升高时自动爆破或打开，防止炉墙损坏。其爆破膜或密封垫为易损件。 | 是 | 每次小修检查防爆门密封面是否完好、锈蚀情况；检查爆破膜有无龟裂和老化；检查铰链机构灵活度；发现密封垫老化应更换。 | 爆破膜破裂后需更换同规格新膜片；门体严重变形无法密封；铰链断裂。更换膜片时注意安装方向和预紧力，确保密封可靠。 |
| 锅筒（汽包） | 锅炉本体 | 圆筒形高压容器，接收省煤器给水，进行汽水分离，储存饱和水并向过热器输送饱和蒸汽，装有水位表、安全阀等。 | 否 | 大修时打开人孔检查内部汽水分离装置、旋风分离器和清洗孔板；检查内壁有无腐蚀和裂纹；对焊缝和管座进行无损检测；校验安全阀整定压力；运行中严格控制水位在允许范围内，避免缺水和满水事故。 | 汽包筒体发现超标裂纹且位置不适宜补焊（如纵缝、环缝或下降管管座处），经强度评估无法安全运行。汽包报废需整台锅炉停运更换。 |
| 水位表 | 锅筒 | 玻璃管或云母窗组件，直观显示锅筒水位，易因腐蚀、老化导致泄漏或模糊不清。 | 是 | 每班冲洗水位表确认指示清晰；每次小修检查云母片或玻璃管有无裂纹、腐蚀和模糊；检查密封填料和阀门；发现泄漏应立即停用更换。 | 云母片碎裂或玻璃管裂纹导致泄漏；管体腐蚀穿孔；多次检修后密封面损伤无法密封。拆除旧水位表后清理接口，安装新水位表注意密封和各阀门开关灵活。 |
| 安全阀 | 锅筒 | 超压时自动开启排放蒸汽的弹簧式或杠杆式阀门，阀瓣与弹簧可能失效，需定期校验。 | 是 | 每年进行安全阀在线校验或离线校验，确认启跳压力和回座压力合格；每次小修检查阀体有无泄漏、腐蚀；检查弹簧有无裂纹和永久变形；阀瓣与阀座密封面研磨。运行中发现泄漏应安排检修。 | 弹簧出现裂纹或永久变形导致整定压力偏移；阀瓣或阀座密封面经多次研磨后仍泄漏；阀体出现裂纹。更换安全阀时核对口径、整定压力和排量，安装后需重新校验。 |
| 旋风分离器 | 锅筒 | 利用离心力将饱和蒸汽中的水滴粗分离出来的内件，内壁可能磨损或结垢。 | 否 | 大修时打开汽包人孔检查旋风分离器内壁磨损和结垢情况；检查固定支架有无松动和腐蚀；清除内部水垢；检查百叶窗波形板有无变形和脱落。 | 旋风筒本体大面积磨穿或严重变形导致分离效率显著下降；支架腐蚀断裂导致分离器脱落。更换旋风分离器需从汽包人孔进出，注意安装方向和固定可靠。 |
| 水冷壁 | 锅炉本体 | 由无缝钢管组成的膜式壁或排管，敷设于炉墙内表面，吸收辐射热加热管内工质，同时保护炉墙。 | 否 | 大修时对水冷壁管进行超声测厚抽查，重点检查燃烧器区域和折焰角附近；检查管外壁有无磨损、腐蚀和鼓包；割管取样检查内壁结垢和腐蚀；运行中监控壁温偏差，异常升高应排查结垢和堵塞。 | 管壁大面积磨损或腐蚀减薄，测厚值低于最小计算壁厚；管内结垢严重导致多次爆管；同一区域反复爆管累计更换超过一定比例。大面积更换水冷壁管需制定专项施工方案，更换后进行水压试验。 |
| 过热器 | 锅炉本体 | 将饱和蒸汽加热为过热蒸汽的受热面，通常分多级布置（屏式、高温等），提高蒸汽温度。 | 否 | 大修时对过热器管进行测厚和氧化皮检测；检查管卡、管夹和定位板；割管做金相分析评估管材老化程度；运行中严格控制过热汽温和管壁温度，超温运行是管材加速老化的主因。 | 过热器大面积管材老化或频繁爆管，堵管率超过允许上限，需整屏或整体更换过热器管排。更换后需进行焊接工艺评定、无损检测和水压试验。 |
| 过热器管 | 过热器 | 承受高温高压的合金钢管，运行中可能因超温、蠕变、氧化皮脱落或烟气腐蚀而爆管。 | 是 | 大修时对过热器管进行超声测厚和氧化皮检测；重点检查管卡、管夹处磨损；检查管排间距有无变形贴紧；割管取样做金相分析检查珠光体球化程度；运行中严格控制蒸汽和管壁温度不超过设计限值。 | 管壁测厚值低于最小计算壁厚；金相分析显示严重球化（4~5级）或蠕变孔洞；氧化皮大量脱落堵塞弯头。爆管后应扩大检查范围，更换管段需选用同材质、做焊接工艺评定和100%无损检测，更换后水压试验。 |
| 喷水减温器 | 过热器 | 安装在过热器级间的调温装置，将高压给水以雾化方式直接喷入蒸汽流以降低蒸汽温度，保护过热器管和汽轮机。喷嘴及调节阀易损坏。 | 是 | 每次小修检查喷嘴雾化效果（通过减温水流量与温降的关系判断）；大修时解体检查喷嘴有无堵塞、磨损和腐蚀；检查调节阀行程和泄漏量；检查内衬保护套有无冲蚀损坏。 | 喷嘴严重堵塞或磨损导致雾化不良；调节阀内漏严重无法修复；内衬保护套冲穿导致蒸汽管道受损。更换喷嘴时清理喷水管路，安装后做喷水试验验证雾化效果。 |
| 再热器 | 锅炉本体 | 将汽轮机高压缸排汽重新加热至额定温度的对流及半辐射受热面，提高循环效率。 | 否 | 大修时对再热器管进行超声测厚抽查；检查管排变形、磨损和腐蚀情况；检查管卡和定位板；重点检查高温段管材球化和氧化情况；运行中控制再热汽温不超过设计值。 | 同过热器管。管壁减薄至危险厚度或金相分析显示严重老化。更换管段后做焊接和无损检测，水压试验合格。 |
| 省煤器 | 锅炉本体 | 利用尾部烟气余热加热给水的对流受热面，降低排烟温度，节约燃料。 | 否 | 大修时对省煤器管进行测厚，重点检查烟气走廊和弯头磨损；检查防磨罩和均流板完好性；运行中监控排烟温度和给水温度，排烟温度异常升高应排查积灰和堵灰。 | 省煤器大面积磨损或腐蚀，堵管率超过允许上限，需整体更换管排。更换时选用耐磨管材并加装防磨罩。 |
| 省煤器管 | 省煤器 | 承受烟气飞灰冲蚀和给水腐蚀的钢管，易发生磨损减薄、点蚀泄漏。 | 是 | 大修时对省煤器管进行超声测厚，重点检查烟气走廊和弯头处磨损；检查防磨罩和均流板完好性；割管检查内壁腐蚀和结垢；运行中监控给水品质和排烟温度。 | 管壁磨损减薄至低于最小计算壁厚；同一区域反复泄漏；大面积飞灰磨损。更换磨损管段后加装或修复防磨罩，更换后水压试验。 |
| 空气预热器 | 锅炉本体 | 回收烟气余热加热送入炉膛助燃空气的换热器，改善燃烧条件，降低排烟损失。 | 否 | 运行中保持蒸汽吹灰和水冲洗正常投入，防止积灰和低温腐蚀；大修时检查蓄热元件腐蚀和堵塞情况；监控空气预热器出入口烟风温差和漏风率；冷段蓄热元件腐蚀严重时翻面使用或更换。 | 蓄热元件大面积腐蚀导致换热效率严重下降，漏风率超标且更换蓄热元件后仍无法改善；壳体严重变形。更换空气预热器为大修项目。 |
| 空气预热器蓄热元件 | 空气预热器 | 回转式预热器中的波纹钢板或陶瓷蜂窝体，易受低温露点腐蚀和积灰堵塞。 | 是 | 运行中保持蒸汽吹灰或水冲洗正常投入；大修时检查蓄热元件有无腐蚀穿孔、堵塞和变形；冷段蓄热元件腐蚀严重时可翻面使用或更换；监控排烟温度和空气预热器差压。 | 蓄热元件大面积腐蚀穿孔或堵塞严重导致风烟系统阻力大幅增加；冷段元件经翻面使用后仍严重腐蚀。更换冷段蓄热元件时按层装入，确保波形方向正确和间隙均匀。 |
| 燃烧器 | 锅炉本体 | 将燃料与空气按比例混合并喷入炉膛着火的装置，含喷嘴、调风器、点火器等。 | 否 | 每次小修清理燃烧器喷嘴和调风器积碳；检查点火系统（电极、电缆和点火变压器）；大修时检查燃烧器本体有无烧损变形；进行燃烧调整试验优化风煤比和火焰形态。运行中注意NOx排放和飞灰含碳量指标。 | 燃烧器本体严重烧损变形导致无法组织正常燃烧，且多个喷嘴同时损坏。更换燃烧器后需进行燃烧调整试验。 |
| 燃烧器喷嘴 | 燃烧器 | 燃料喷出口，易被积碳、焦油堵塞或高温烧损变形，影响火焰形态。 | 是 | 每次小修清理喷嘴积碳和焦油；检查喷口有无烧损变形和磨损；测量喷口尺寸与设计值对比；运行中注意火焰形态和烟气CO含量，异常时检查喷嘴。 | 喷口严重烧损变形导致燃料雾化或喷射角度偏离；多次清理后喷口尺寸扩大超出允许公差。更换喷嘴时选用同型号，安装后进行燃烧调整试验。 |
| 点火电极（点火棒） | 燃烧器 | 陶瓷绝缘体与金属电极，产生高压火花，易积碳、受潮或绝缘破裂导致点火失败。 | 是 | 每次小修检查电极表面有无积碳和油污，清除后保持干燥；检查陶瓷绝缘体有无裂纹和烧损；检查高压电缆绝缘；调整电极间隙至规定值。 | 陶瓷绝缘体碎裂导致对地放电短路；电极严重烧损无法产生有效火花；高压电缆绝缘击穿。更换点火电极时注意插入深度和电极间隙调整，安装后做点火试验。 |
| 下降管 | 锅炉本体 | 将锅筒中的水引至下联箱和水冷壁的粗径管路，保证水循环可靠。 | 否 | 大修时对下降管进行外观检查和超声测厚；检查保温层完好性；检查支吊架受力状态；重点关注弯头和焊缝处。运行中如发现水冷壁循环异常，应排查下降管是否堵塞。 | 管壁减薄至低于最小计算壁厚；焊缝出现超标缺陷无法返修。下降管更换为大修项目，需制定专项方案。 |
| 联箱 | 锅炉本体 | 连接多根受热面管的汇集与分配集箱，分为水冷壁联箱、过热器联箱等，起混合与分流作用。 | 否 | 大修时对联箱筒体和管座角焊缝进行无损检测（磁粉和超声波）；测量壁厚；检查内部隔板和消音器；监控联箱壁温变化速率避免热冲击。 | 联箱筒体出现深度裂纹或大面积热疲劳开裂，打磨消除后剩余壁厚不满足强度要求。联箱更换为重大检修项目。 |
| 过热器出口联箱 | 联箱 | 汇集不同蛇形管束出口处过热蒸汽的厚壁集箱，承受最高蒸汽压力和温度。内部易产生热疲劳裂纹。 | 是 | 大修时对联箱内外壁进行磁粉探伤和超声波探伤；重点检查管座角焊缝、接管座和筒体环缝；检查内部隔板和消音器；测量壁厚；运行中监控联箱壁温变化速率避免热冲击。 | 筒体或管座角焊缝出现深度裂纹且打磨消除后剩余壁厚不满足强度要求；大面积热疲劳开裂。联箱更换为重大检修项目，需制造厂配合。 |
| 再热器出口联箱 | 联箱 | 汇集再热器出口处高温再热蒸汽的集箱。同样承受高温高压，易产生热疲劳。 | 是 | 同过热器出口联箱。大修时进行无损检测，重点检查管座角焊缝和热疲劳区域。 | 同过热器出口联箱。 |
