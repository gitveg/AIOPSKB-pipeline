| 子设备名称 | 描述 |
| :--- | :--- |
| 煤粉锅炉 | 煤经磨煤机研磨成细粉后喷入炉膛悬浮燃烧，是大型火电站的主流锅炉型式。按水循环方式可分为自然循环（亚临界及以下）、控制循环（亚临界）和直流锅炉（超临界/超超临界）。典型容量300~1000MW。 |
| 循环流化床锅炉（CFB） | 燃料在布风板上被一次风吹起形成流态化，经旋风分离器将未燃尽颗粒返回炉膛循环燃烧。燃料适应性广（可燃劣质煤、煤矸石），可实现炉内添加石灰石脱硫，低NOx排放。典型容量135~350MW。 |
| 余热锅炉（HRSG） | 回收燃气轮机排烟余热产生蒸汽驱动汽轮机发电，是燃气-蒸汽联合循环（CCGT）的核心设备。分为自然循环和强制循环型，可带补燃。无独立燃烧器（或仅有补燃燃烧器），换热量取决于上游燃气轮机排烟参数。 |
