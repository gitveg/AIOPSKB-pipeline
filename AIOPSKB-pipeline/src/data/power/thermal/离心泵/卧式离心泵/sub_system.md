| 子系统名称 | 描述 |
|---|---|
| 驱动系统 | 为给水泵提供旋转机械能的动力源，通常包含大型电动机或汽轮机及其附属的调速机构。其功能是精确调节转速以满足锅炉给水压力和流量的变工况需求，覆盖从动力输入轴到联轴器的全部传动链。 |
| 泵体及水力系统 | 将驱动系统的机械能高效转化为流体的压力能，由多级叶轮、导叶、泵壳等组成。其核心功能是实现给水从除氧器到锅炉的持续高压输送，耐受超高温、高压工况，是增压的核心执行单元。 |
| 密封与冷却系统 | 针对高温高压给水，采用机械密封或迷宫密封防止介质泄漏，并通过强制循环冷却水或自冷却回路带走运转产生的热量。该系统确保轴承、密封腔体等关键部位在热应力和摩擦热下的可靠性与寿命。 |
| 润滑油系统 | 为高速旋转的轴承、齿轮联轴器及驱动端提供清洁、定温的强制润滑油，负责形成油膜以减小摩擦，并带走载荷产生的大量热量。这是保障大功率给水泵组高转速、长周期稳定运行的生命线。 |
| 控制与保护系统 | 通过传感器采集温度、振动、压力、流量等信号，自动调节泵组转速、再循环阀开度，并执行低油压、超温、超振等紧急跳闸保护逻辑。该系统覆盖就地仪表、控制柜及远程控制系统。 |
| 辅助管路与阀门系统 | 包含最小流量再循环管路、暖泵管路、排空管等工艺管道及相应阀门。该系统负责保护泵体在低流量时不过热、起停时均匀暖机，并在检修时隔离系统，确保泵组在各种工况下安全启停与正常运行。 |
