| 设备名称 | 设备类型 | 描述 |
|----------|----------|------|
| 反应堆压力容器（RPV） | 主设备 | 核岛核心设备，承载核燃料组件及堆内构件，承受高温高压放射性冷却剂，是核安全一级、质保一级的压力边界设备 |
| 蒸汽发生器（SG） | 主设备 | 核岛主设备，将一回路冷却剂携带的堆芯热量传递给二回路给水产生蒸汽，是一回路与二回路之间的热量交换边界，每台机组配置2~3台 |
| 稳压器 | 主设备 | 核岛主设备，通过电加热器和喷淋系统维持一回路系统压力稳定在设定值，防止冷却剂沸腾或系统超压，与RPV/SG/RCP共同构成一回路压力边界，核安全一级设备 |
| 主循环泵/反应堆冷却剂泵（RCP） | 主设备 | 核岛主设备，驱动反应堆冷却剂在一回路系统中强制循环，将堆芯热量带至蒸汽发生器，是一回路唯一的旋转设备，核安全一级设备 |
| 反应堆冷却剂主管道 | 主设备 | 核岛主设备，连接反应堆压力容器、蒸汽发生器和主泵的一回路大型管道，构成反应堆冷却剂系统的压力边界，核安全一级设备，具有独立的制造/监造/在役检查管理流程 |
| 堆内构件 | 主设备 | 核岛主设备，安装于反应堆压力容器内部的大型复杂机械结构，为燃料组件提供支撑和定位，引导冷却剂流道，支撑控制棒驱动机构。具有独立设计规范（RCC-M）、独立吊装程序和独立在役检查程序，核安全二级设备 |
| 控制棒驱动机构（CRDM） | 主设备 | 核岛主设备，通过步进电机驱动控制棒在堆芯内上下移动以控制反应性，实现反应堆启动、功率调节和停堆，是独立的机械执行机构，核安全关键设备 |
| 核燃料组件 | 主设备 | 核岛核心能量转换载体（消耗性主设备），由燃料棒（含二氧化铀芯块）、定位格架和上下管座组成，在堆芯内发生核裂变反应产生热能。定期更换（3~18个月），不可修复，故障模式包括包壳破损、格架磨蚀、辐照生长等 |
| 汽轮机 | 主设备 | 常规岛核心设备，将蒸汽发生器产生的高压蒸汽的热能转化为机械能，驱动发电机运转，通常为多缸多级凝汽式汽轮机（核电因饱和蒸汽参数，与火电汽轮机有显著差异） |
| 发电机 | 主设备 | 常规岛核心设备，将汽轮机输出的机械能转化为电能，通常为三相交流同步发电机，单机容量可达1000~1750MW |
| 凝汽器 | 主设备 | 常规岛主设备，将汽轮机排出的乏蒸汽冷凝为凝结水，维持汽轮机背压真空度，提高热力循环效率（参照火电评审结论，朗肯循环冷端关键节点） |
| 主变压器 | 主设备 | 常规岛主设备，将发电机输出的电能升压后送入电网。核电一机一变（单元制接线），独立采购、独立维护（参照火电/水电主设备先例） |
| 汽水分离再热器（MSR） | 主设备 | 常规岛主设备，分离汽轮机高压缸排汽中的水分并将蒸汽再热后送入低压缸，提高蒸汽干度和热力循环效率。核电因饱和蒸汽参数，MSR的重要性远超火电，独立布置、独立招标、独立检修 |
| 化学和容积控制系统（CVCS） | 辅助设备 | 核岛辅助系统，调节反应堆冷却剂的化学性质（除盐、除氧、加硼、加锂）、容积和硼浓度，维持冷却剂水质合格 |
| 安全注入系统（SIS） | 辅助设备 | 核岛辅助系统，在反应堆冷却剂丧失事故（LOCA）等事故工况下，向堆芯紧急注入含硼水，确保堆芯冷却和反应性控制，核安全二级系统 |
| 安全壳喷淋系统（CSS） | 辅助设备 | 核岛辅助系统，在失水事故或主蒸汽管道破裂事故时向安全壳内喷淋含硼水，降低安全壳内温度和压力，洗涤放射性物质 |
| 余热排出系统（RHR） | 辅助设备 | 核岛辅助系统，在反应堆正常停堆和事故停堆后，导出堆芯衰变热，将反应堆冷却剂系统冷却至冷停堆温度 |
| 设备冷却水系统 | 辅助设备 | 核岛辅助系统，为核岛各类热交换器和设备提供冷却水，将热量传递至重要厂用水系统，核安全三级系统 |
| 重要厂用水系统 | 辅助设备 | 核岛辅助系统，将设备冷却水系统传递的热量排至最终热阱（海水或冷却塔），是核安全相关的最终冷却链路 |
| 主给水泵 | 辅助设备 | 常规岛辅助设备，将除氧器水箱中的给水加压后输送至蒸汽发生器，维持二回路给水流量和蒸汽发生器水位 |
| 凝结水泵 | 辅助设备 | 常规岛辅助设备，将凝汽器热井中的凝结水升压后输送至低压加热器和除氧器 |
| 除氧器 | 辅助设备 | 常规岛辅助设备，利用加热蒸汽除去给水中溶解的氧气和其他气体，防止热力系统设备和管道腐蚀 |
| 高压加热器 | 辅助设备 | 常规岛辅助设备，利用汽轮机抽汽加热给水，提高进入蒸汽发生器的给水温度，提升热力循环效率 |
| 低压加热器 | 辅助设备 | 常规岛辅助设备，利用汽轮机低压缸抽汽加热凝结水，回收汽轮机抽汽热量，提高回热循环效率 |
| 给水调节阀 | 辅助设备 | 常规岛辅助设备，调节进入蒸汽发生器的给水流量，维持蒸汽发生器水位稳定，是二回路关键控制设备 |
| 循环水泵 | 辅助设备 | 常规岛辅助设备，为凝汽器提供大量冷却水（海水或淡水），将汽轮机排汽冷凝为水，维持凝汽器真空度 |
| 润滑油系统 | 辅助设备 | 常规岛辅助设备，为汽轮发电机组轴承提供润滑和冷却用油，保障机组安全运转 |
| 密封蒸汽系统 | 辅助设备 | 常规岛辅助设备，向汽轮机轴封供蒸汽，防止空气漏入凝汽器或蒸汽漏出，维持凝汽器真空 |
| 主蒸汽/主给水管道 | 辅助设备 | 常规岛辅助设备，连接蒸汽发生器与汽轮机（主蒸汽）及给水泵与蒸汽发生器（主给水）的高压管道，是二回路主工艺边界的关键管道系统 |
| 汽轮机旁路系统 | 辅助设备 | 常规岛辅助设备，在甩负荷或紧急停堆时将主蒸汽直接排入凝汽器，避免蒸汽发生器超压。核电旁路容量远大于火电，是二回路关键保护设备 |
| 发电机密封油系统 | 辅助设备 | 常规岛辅助设备，为发电机氢冷密封提供密封油，维持发电机内氢气压力和纯度，防止氢气泄漏 |
| 发电机定子冷却水系统 | 辅助设备 | 常规岛辅助设备，为大型水氢氢冷却方式的发电机定子绕组提供除盐水冷却，维持定子绕组温度在允许范围内 |
| 凝结水精处理系统 | 辅助设备 | 常规岛辅助设备，通过混床离子交换树脂去除凝结水中的溶解盐和悬浮物，控制二回路水质，防止蒸汽发生器腐蚀 |
| 核岛通风空调系统 | 辅助设备 | 核岛辅助系统，维持安全壳及核岛各厂房的温度、湿度和放射性浓度在允许范围内，保障设备运行环境和人员安全 |
| 放射性废物处理系统 | 辅助设备 | 核岛辅助系统，对气态、液态和固态放射性废物进行收集、处理、固化、暂存，包括废液处理系统、废气处理系统、固体废物处理系统 |
| 硼回收系统 | 辅助设备 | 核岛辅助系统，收集和处理反应堆冷却剂系统的下泄水，经除气、除硼、过滤后回收利用，减少放射性废液排放 |
| 反应堆厂房装卸运输设备 | 辅助设备 | 核岛辅助设备，包括环行吊车、燃料转运装置、装卸料机等，用于反应堆开盖、燃料装卸和设备检修 |
| 柴油发电机组（应急电源） | 公用系统 | 全厂共用的应急备用电源，在外部电网失电和厂用电故障时，为核安全相关系统（安注、余排、仪控等）提供可靠电力，每台机组配置2台以上 |
| 厂用电系统 | 公用系统 | 为全厂各系统设备提供电源的配电系统，包括高压厂用变压器、低压厂用变压器、中低压开关柜、蓄电池组、UPS不间断电源等 |
| 循环冷却水系统 | 公用系统 | 全厂共用的最终热阱冷却系统，通过取水口、循环水泵房、排水渠等设施，为凝汽器和设备冷却水系统提供充足的冷却水源 |
| 除盐水系统 | 公用系统 | 全厂共用的水处理系统，通过预处理、反渗透、离子交换等工艺制备满足核岛和常规岛水质要求的除盐水 |
| 压缩空气系统 | 公用系统 | 全厂共用的气源系统，提供仪用压缩空气（供气动仪表和阀门使用）和厂用压缩空气（供检修和吹扫使用） |
| 仪控系统（DCS） | 公用系统 | 全厂数字化控制系统，包括核岛控制系统、常规岛控制系统和保护系统，实现反应堆功率控制、过程参数监测、安全保护和数据采集 |
| 电气开关站 | 公用系统 | 全厂共用的电能汇集和分配设施，包括GIS组合电器、高压断路器、隔离开关、电流/电压互感器、避雷器等 |
| 消防系统 | 公用系统 | 全厂消防保护和火灾报警设施，包括火灾探测报警系统、消防水泵、消防水管路、气体灭火系统、消防车辆等 |
| 通信系统 | 公用系统 | 全厂内外通信设施，包括行政电话、调度电话、广播系统、应急通信、无线对讲系统等，保障运行调度和应急响应 |
| 暖通空调系统（BOP） | 公用系统 | 非放射性区域的通风空调系统，为常规岛厂房、BOP厂房、控制室、办公室等提供环境温湿度控制 |
| 给排水系统 | 公用系统 | 全厂生活用水、工业用水供给及雨水、污水排放系统，包括取水设施、水处理设备、污水处理设施 |
| 气象监测系统 | 公用系统 | 监测厂址区域的气象参数（风速、风向、温度、湿度、降雨量等），为放射性排放评价和应急决策提供气象数据 |
| 环境辐射监测系统 | 公用系统 | 在厂区及周边布设辐射监测站点，实时监测环境γ辐射剂量率和放射性核素浓度，评估核电站运行对环境的影响 |
| 辅助蒸汽系统 | 公用系统 | 全厂共用的辅助蒸汽供应系统，在机组启停期间或正常运行时提供辅助蒸汽，用于除氧器加热、蒸汽发生器预热等 |
