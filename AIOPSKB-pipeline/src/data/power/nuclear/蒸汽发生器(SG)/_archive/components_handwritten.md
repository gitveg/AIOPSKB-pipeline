| 一次侧封头 | — | 蒸汽发生器下部半球形封头，与一回路主管道连接，是反应堆冷却剂系统压力边界的一部分。内部分隔为热端腔室（进口）和冷端腔室（出口），冷却剂从热端流入U形管一次侧向冷端流出。设计压力17MPa/350°C，核安全一级。 | 否 | 每次换料大修打开人孔检查封头内壁不锈钢堆焊层状态；检查分隔板焊缝；检查人孔密封面；在役检查进行VT和UT检查；10年水压试验验证一次侧压力边界完整性。 | 封头母材出现超标缺陷无法修复；堆焊层大面积剥离。整体更换封头需由厂家执行（极罕见，等同重大改造），旧封头按放射性废物处置。 |
| 封头壳体 | 一次侧封头 | 半球形或半椭球形锻造承压壳，Mn-Mo-Ni低合金钢（SA-508 Gr.3 Cl.2），内壁堆焊≥5mm不锈钢或镍基合金衬里。分隔热端（进口）和冷端（出口）冷却剂。设计寿命≥40年。 | 否 | 大修时VT检查内壁堆焊层有无剥离和点蚀；UT检查母材和堆焊层结合面；关注热端管板孔附近的冷却剂流动加速腐蚀（FAC）；检查管板与封头焊接区域。 | 封头母材发现不可修复缺陷；大面积堆焊层剥离。需由厂家评估现场修复或整体更换（后者属重大改造）。 |
| 分隔板 | 一次侧封头 | 安装在封头中央的垂直隔板，将一次侧封头分隔为热端腔室（与反应堆热管段连接）和冷端腔室（与反应堆冷管段连接）。冷却剂经热端→U形管→冷端通道，不可短路。材质为不锈钢或镍基合金。 | 否 | 大修时VT检查分隔板有无变形和裂纹；检查分隔板与封头/管板的密封焊缝状态（是否存在旁路泄漏，通过温度监测间接判断）。 | 分隔板严重变形或焊缝出现贯穿性裂纹导致冷热端旁路泄漏。需由厂家评估水下修复可行性。 |
| 人孔盖 | 一次侧封头 | 封头底部的检修开孔盖板，换料大修时打开供人员进入封头进行检查和维护（堵管、涡流检测、目视检查等）。配有人孔密封垫，高压密封结构。 | 否 | 每次开盖后更换人孔密封垫；检查人孔盖密封面和螺栓螺纹状态；安装时按设计力矩均匀紧固螺栓；水压试验时检查人孔密封性。 | 人孔盖密封面严重损伤无法修复；螺栓螺纹大面积损坏。更换同规格人孔盖（需确认与原封头配合兼容）。 |
| 人孔密封垫 | 一次侧封头 | 人孔盖与封头法兰之间的高压密封垫片，通常为金属缠绕垫或金属O形环（镍基合金材质）。保证一次侧压力边界完整性。 | 是 | 每次开启人孔后必须更换新密封垫；安装前检查密封垫和密封面无损伤和杂质；按规定力矩均匀紧固。 | 每次开盖即报废。旧密封垫按放射性废物处置。 |
| 管板 | — | 蒸汽发生器中分隔一次侧与二次侧的核心结构件，大型圆形锻件（SA-508 Gr.3 Cl.2），厚度500~700mm，直径3.5~4.5m。钻有数千个精密通孔，U形传热管两端分别穿入并胀接/焊接固定。一次侧表面堆焊镍基合金。管板承受一次侧与二次侧之间的全压差。 | 否 | 每次换料大修从一次侧进行管板表面VT检查（检查堆焊层、管孔周围、泥渣沉积）；涡流检测（ECT）评估传热管在管板全厚度段的降质；二次侧管板上表面泥渣检查和冲洗（通过检查手孔或专用冲洗设备）；管板与筒体焊接区域检查。 | 管板母材出现超标缺陷不可修复；多个管孔因腐蚀或机械损伤无法与传热管密封连接。管板不可单独更换，需整体更换蒸汽发生器（极大型维修项目）。 |
| 管束组件 | — | SG核心换热单元，由数千根倒U形传热管、管支撑板和防振条组成。一次侧高温冷却剂在管内流动，二次侧给水在管外侧沸腾产生蒸汽。传热总面积5000~7000m²，是SG中设计要求和制造精度最高的组件。管束设计寿命与SG本体同步≥40年。 | 否 | 每次换料大修对100%传热管进行涡流检测（ECT/Bobbin+旋转探头），评估壁厚减薄、凹陷、裂纹、磨损等降质；根据ECT结果进行堵管（超标管）或降额运行评估；二次侧检查管支撑板区域的泥渣沉积和腐蚀；大修中进行二次侧管板上表面高压水冲洗（泥渣清除）。 | 累积堵管数量超过设计允许堵管率（通常>10~15%）导致热功率不足；管束大面积降质（ODSCC/PWSCC/磨损）超出堵管策略可补偿范围。管束不可修复，需整体更换蒸汽发生器。 |
| U形传热管 | 管束组件 | 倒U形无缝镍基合金管（Inconel 690 TT，早期为Inconel 600），外径约19mm，壁厚约1.09mm，长度数十米。一次侧冷却剂在管内流过，将热量传递给管外侧的二次侧给水。数量3000~10000+根。是SG中数量最多、服役环境最严苛的部件。 | 是 | 每次换料大修采用涡流检测（ECT）对100%传热管全长度进行检查，重点关注管板胀管区、管支撑板交叉处、U形弯头段和管顶泥渣堆积区；检测壁厚减薄（磨损、腐蚀）、裂纹（ODSCC/PWSCC）、凹陷（denting）、点蚀（pitting）；超标管进行机械堵管（两端打入堵头）。 | 单根管壁厚减薄≥40%原始壁厚或涡流信号超验收准则→机械堵管；累积堵管数量≥堵管限值（通常>10%总数）。单管不更换（采用堵管策略），管束不可局部更换，堵管超限需整体更换SG。 |
| 管支撑板 | 管束组件 | 沿管束高度等距分布的多层不锈钢孔板（通常6~10层），每层钻有与传热管排列对应的开孔（三叶孔或四叶孔），支撑传热管防止流致振动。开孔与传热管之间有设计间隙，允许二次侧汽水混合物自由通过。 | 否 | 大修时通过ECT检测管支撑板交叉处的传热管壁厚（该区域是磨损和凹陷高发区）；通过二次侧检查手孔VT检查管支撑板有无变形和腐蚀；泥渣堆积评估。 | 管支撑板严重腐蚀或变形导致大面积传热管支撑失效。管支撑板不可单独更换，严重降质需整体更换SG。 |
| 防振条（AVB） | 管束组件 | 安装在U形管弯头段的抗振条组件，通常为不锈钢条带。限制U形弯头段在汽水横流作用下的振动幅度，防止传热管相互碰撞和弯头段疲劳开裂。 | 否 | 大修时ECT重点检查U形弯头段传热管有无磨损和疲劳裂纹（AVB接触区域）；VT检查AVB有无松动和移位（如果可及）。 | AVB松动或脱落导致传热管振动幅度增大和相邻管磨损。AVB不可单独更换，需结合SG整体维护策略评估。 |
| 二次侧壳体/筒体 | — | SG上部的承压壳体，由下筒体（管束段）、锥形过渡段和上筒体（汽水分离段）焊接组成。材质为Mn-Mo-Ni低合金钢（SA-508或SA-533），内壁无堆焊层（二次侧介质为给水/蒸汽，腐蚀性较低）。设计压力约7~8MPa，设计温度约300°C。 | 否 | 大修时VT检查筒体内壁有无腐蚀和冲刷痕迹；UT检查关键焊缝；检查给水环管和蒸汽接管区域的内壁状态（重点关注给水入口的热冲击和蒸汽出口的冲蚀）；水压试验验证承压完整性。 | 筒体母材出现超标缺陷不可修复；关键焊缝出现贯穿性裂纹。筒体不可单独更换，需整体更换SG。 |
| 下筒体 | 二次侧壳体/筒体 | 包容管束段和下降通道的筒体，外径较上筒体略小。给水从给水环管进入下降环形通道，沿着管束外壁向下流动到达管板，然后折返进入管束区域沸腾产生蒸汽（自然循环）。 | 否 | 检查下筒体内壁（特别是管束区域对应位置）有无冲刷和腐蚀；检查给水环管和下降通道入口状态；关注管板二次侧泥渣堆积对下降通道入口的影响。 | 同筒体整体。 |
| 上筒体 | 二次侧壳体/筒体 | 包容汽水分离器和干燥器的大型筒体，外径3.5~4.5m。汽水混合物从管束上部进入汽水分离器，分离出的蒸汽经干燥器进一步除湿后从顶部蒸汽接管输出。 | 否 | 检查上筒体内壁有无冲刷腐蚀（特别是蒸汽出口区域）；检查汽水分离器和干燥器支撑结构；检查蒸汽接管内壁冲蚀状态。 | 同筒体整体。 |
| 给水环管 | 二次侧壳体/筒体 | 安装在下筒体上部下降通道中的环形给水分配管，沿圆周均布出水孔。将来自主给水泵的高压给水（~7MPa，~230°C）均匀注入下降环形通道，与再循环饱和水混合后进入管束区域。 | 否 | 大修时VT检查给水环管出水孔有无堵塞（异物、腐蚀产物）；检查环管内部有无腐蚀和壁厚减薄；检查环管支撑和定位装置。 | 给水环管严重腐蚀或出水孔大面积堵塞无法清除。给水环管可在SG大修中局部更换（通过检查手孔操作）。 |
| 给水接管 | 二次侧壳体/筒体 | 主给水管道与SG筒体的连接管座，贯穿筒体壁将给水引入给水环管。焊接于SG上筒体或下筒体，承受给水压力与筒体压力之间的压差。 | 否 | 在役检查时UT检查给水接管安全端焊缝和接管内壁；检查接管与筒体焊接区域；关注给水温度变化引起的热疲劳（启停工况）。 | 接管安全端焊缝出现贯穿性缺陷。需由厂家评估修复方案（接管修复涉及SG筒体焊接，操作难度极高）。 |
| 蒸汽接管 | 二次侧壳体/筒体 | 蒸汽在干燥器除湿后汇集至顶部蒸汽出口接管，输出至主蒸汽管道。通常为1~2根大直径接管（DN700~DN900），内壁可能堆焊不锈钢防冲蚀。 | 否 | 在役检查时UT检查蒸汽接管焊缝和接管内壁（重点关注蒸汽高速流动引起的冲蚀-腐蚀）；检查接管安全端与主蒸汽管道的连接焊缝。 | 蒸汽接管焊缝出现贯穿性缺陷或内壁严重冲蚀减薄。需由厂家评估修复方案。 |
| 汽水分离装置 | — | 安装在管束上方二次侧壳体内的两级汽水分离系统。第一级：旋叶式汽水分离器利用离心力去除≥90%的水滴；第二级：波形板干燥器去除细小水滴。保证出口蒸汽湿度≤0.25%，保护汽轮机叶片免受水蚀。 | 否 | 每次换料大修通过蒸汽出口人孔或打开上封头检查汽水分离器和干燥器的完好性；检查旋叶式分离器有无堵塞和变形；检查干燥器波形板有无腐蚀和积垢；检查分离器排水通道是否畅通。 | 汽水分离器大量堵塞或变形导致出口蒸汽湿度超标；干燥器波形板严重腐蚀损坏。汽水分离器和干燥器为可拆卸模块，可在SG大修中局部更换（通过上封头开口吊出）。 |
| 旋叶式汽水分离器 | 汽水分离装置 | 多个并联安装在管束上方的离心式分离器，利用旋转叶片使汽水混合物产生强旋转离心力，水滴被甩至壁面后经排水管回流至下降通道。分离效率>90%，处理汽水混合物流量大。 | 否 | 大修时通过检查孔VT检查旋叶叶片有无堵塞、变形和腐蚀；检查排水管是否畅通；检查旋叶轴承（如果有，多数为无轴承设计）和支撑。 | 多个分离器叶片严重变形、腐蚀或排水管堵塞影响汽水分离效率。可局部更换损坏的分离器模块。 |
| 波形板干燥器（Chevron Dryer） | 汽水分离装置 | 安装在汽水分离器上方的大型波形板组件，蒸汽通过曲折的波形板通道时携带的微小水滴因惯性撞击板壁被捕获、聚集成大水滴后重力回流。出口蒸汽湿度≤0.25%。由多层平行波形板按一定间距排列组成。 | 否 | 大修时VT检查波形板有无腐蚀、变形和积垢；检查波形板间隙有无异物堵塞；检查排水回流通道是否畅通；必要时局部蒸汽取样测量出口湿度验证干燥效果。 | 波形板大面积腐蚀或严重变形导致出口蒸汽湿度超标；排水通道堵塞且无法清除。可整体吊出更换干燥器模块。 |
| 支撑/支座 | — | SG的机械支撑和固定结构，包括下部垂直支撑（重型锻件支撑）或裙式支撑、上部横向支撑和导向结构、地震/事故支撑和液压阻尼器/防甩约束装置。承受SG本体自重（300~500吨）、地震载荷和管道破裂动态载荷。 | 否 | 大修时检查支撑结构焊缝有无裂纹；检查支撑与SG筒体和基础的连接螺栓紧固状态；检查横向支撑和导向装置的间隙是否在设计范围内；检查液压阻尼器油位和功能。 | 支撑结构出现不可修复裂纹或严重腐蚀；阻尼器功能丧失且无法修复。支撑结构可在SG更换项目中同步更换。 |
| 水位测量接管 | — | 贯穿SG上筒体和下筒体壁的多个仪表接管，安装蒸汽发生器水位变送器（差压式或导波雷达式）。SG水位是核安全关键参数——水位过高影响蒸汽品质，水位过低导致传热管裸露丧失冷却，是二回路控制的核心参数。 | 否 | 每次换料大修校验水位变送器（与参比水位柱比对）；检查仪表接管有无堵塞（泥渣、异物）；检查接管根阀状态；确认水位高/低报警和保护动作值设定正确。 | 水位接管严重堵塞无法清除；接管焊缝泄漏。可局部更换接管段。 | 
| 排污管 | — | 安装在管板上方二次侧的排污/排泥管线接口，用于定期或连续排出管板表面沉积的泥渣（腐蚀产物和给水杂质），减缓管板上方泥渣堆积导致的传热管腐蚀（ODSCC/TSP crevice corrosion）。 | 否 | 每次换料大修通过排污管进行管板表面高压水冲洗（泥渣清除）；检查排污管有无堵塞和腐蚀；监测排污流量是否正常；结合ECT结果评估排污效果。 | 排污管严重堵塞或腐蚀穿孔无法修复。可局部更换排污管线。 |
| 安全阀接管 | — | SG二次侧的超压保护接口，连接弹簧加载式安全阀（通常2~3台），在蒸汽管道隔离等事故工况下自动开启排出蒸汽，防止SG二次侧超压导致传热管或壳体破裂。排放能力覆盖全部蒸汽流量。 | 否 | 每次换料大修校验安全阀整定压力和排放能力（离线和在线校验）；检查安全阀接管有无冲蚀和变形；检查安全阀与接管的法兰密封面状态。 | 安全阀接管腐蚀或变形影响安全阀密封。可局部修复或更换接管段。 |
