| CRDM管座 | 顶盖组件 | 控制棒驱动机构（CRDM）的穿顶盖管座，杯形座结构（套管+法兰），与顶盖焊接。每台RPV约61~69根，为CRDM耐压壳提供安装界面和压力边界。 | 是 | 每次换料大修对所有CRDM管座进行目视和涡流/超声检查，重点检测J型焊缝和管座内壁；检测硼结晶（PWSCC泄漏指示）；视频内窥镜检查管座内表面；必要时进行UT检查贯穿段。 | 管座出现贯穿性PWSCC裂纹无法修复；管座母材降质超出验收标准。需更换顶盖组件（CRDM管座与顶盖一体），更换周期受管座PWSCC风险评估驱动。 |
| 排气管管座 | 顶盖组件 | RPV顶部排气用的贯穿管座（通常1根），用于充水排气和正常运行时的高点放气，与顶盖焊接。 | 否 | 大修时进行VT和UT检查焊缝；检查管座内壁有无腐蚀和裂纹；水压试验时检查密封性。 | 管座焊缝出现贯穿性缺陷无法修复。随顶盖整体更换。 |
| 吊耳 | 顶盖组件 | 顶盖吊运用的立柱管式吊耳（通常3个），焊接于顶盖外表面。换料大修时用于整体吊运顶盖（含CRDM），设计载荷需覆盖顶盖+CRDM总重。 | 否 | 每次吊运前目视检查吊耳焊缝和表面状态；定期进行PT或MT无损检测；检查吊耳有无变形和磨损。 | 吊耳焊缝出现裂纹或吊耳本体塑性变形。需由厂家评估修复（补焊后热处理）或随顶盖整体更换。 |
| O形密封环 | 顶盖组件 | 安装于顶盖法兰密封槽内的两道同心金属密封环（不锈钢管或镍基合金Inconel 718管材，外镀银）。内环保证密封，外环作为二次密封。两道环之间有泄漏探测管。 | 是 | 每次开盖后必须更换两道O形密封环；安装前检查新密封环表面镀银层完好、无划痕；安装时确保密封环正确落位于密封槽内；清洁法兰密封面至无杂质残留。 | 每次开盖即报废（一次性使用件）。旧密封环按放射性废物处置。 |
| 泄漏探测管 | 顶盖组件 | 连接两道O形密封环之间环隙的探测管路，引出至RPV外部。通过温度传感器或湿度传感器监测内环是否泄漏（正常运行内环不应泄漏，启停工况允许≤20L/h）。 | 否 | 每次换料大修时检查探测管是否畅通；检查温度传感器/湿度传感器读数；启停过程监测泄漏量；确认泄漏探测系统报警功能正常。 | 探测管堵塞或传感器故障无法修复。需更换探测管段或传感器组件。 |
| 容器组件 | — | RPV下部主体承压结构，由筒体法兰、管嘴段、堆芯筒体、过渡段和下封头组成，包容整个堆芯和堆内构件，承受17MPa/350°C高温高压放射性冷却剂。 | 否 | 每次换料大修进行筒体内壁VT和UT检查堆焊层状态；定期进行筒体焊缝和母材UT检查；辐照监督试样按计划取出测试；管嘴安全端焊缝进行特殊UT检查（异种金属焊缝）；水压试验按10年周期执行。 | 筒体母材因辐照脆化导致RT_NDT超限；堆焊层大面积剥离且修复不可行；筒体发现超标缺陷经断裂力学评估不能满足服役至下个检查周期。整体更换RPV在经济上不可行，通常导致机组提前退役。 |
| 筒体法兰 | 容器组件 | 容器组件上端法兰，外径与顶盖法兰匹配。开有58个未穿透螺纹孔（安装主螺栓）和4个键槽（与顶盖对准）。法兰内壁有支承台肩，承载堆内构件全部重量。 | 否 | 换料大修清洁法兰面和螺纹孔；检查螺纹孔有无损伤和腐蚀（螺纹孔检查采用专用量规和VT）；测量法兰平面度；检查台肩承载面无异常变形。 | 螺纹孔大面积损伤无法修复（如螺纹拉脱或严重腐蚀）；台肩变形影响堆内构件支承。需由厂家评估严重性，极端情况可导致RPV不可用。 |
| 管嘴段 | 容器组件 | 筒体中段带有进出口管嘴的筒节。管嘴在同一水平面布置（三代核电进口管嘴高于出口），连接一回路主管道。管嘴内孔与堆内构件吊篮的冷/热管段密封环配合。 | 否 | 在役检查重点检查管嘴安全端异种金属焊缝（低合金钢-不锈钢/镍基焊缝，采用UT和射线RT）；检查管嘴内壁堆焊层状态；管嘴与主管道连接的焊缝纳入在役检查大纲。 | 管嘴安全端焊缝出现超标缺陷；管嘴母材发现裂纹且断裂力学评估不满足要求。需由厂家评估现场修复可行性。 |
| 进口管嘴 | 管嘴段 | 一回路冷却剂进入RPV的接口，连接主泵出口→主管道冷管段→RPV进口管嘴。管嘴内孔与吊篮冷管段密封环配合，将冷却剂导入吊篮与RPV筒体之间的环形下降通道。 | 否 | 在役检查时检查进口管嘴内壁堆焊层和密封面状态；检查与主管道连接焊缝；流量分配检查（结合堆芯入口温度分布监测）。 | 管嘴密封面严重损伤影响与吊篮密封环的配合。需由厂家评估修复方案。 |
| 出口管嘴 | 管嘴段 | 一回路冷却剂流出RPV的接口，连接RPV出口管嘴→主管道热管段→蒸汽发生器进口。传热后的高温冷却剂从堆芯上部流出汇集进入出口管嘴。 | 否 | 在役检查内容同进口管嘴；出口管嘴温度较进口高约30~40°C，重点关注热疲劳和异种金属焊缝降质。 | 同进口管嘴。管嘴安全端焊缝不可修复性缺陷需评估机组安全性。 |
| 堆芯筒体 | 容器组件 | 包容堆芯和堆内构件的核心筒体段，是RPV壁厚最厚、承受快中子辐照最强的区域。内壁堆焊不锈钢衬里，外壁有保温层。快中子积分通量可达10^19 n/cm²以上。 | 否 | 辐照监督试样按计划取出测试（1/4寿命、1/2寿命、3/4寿命、设计末期），跟踪RT_NDT变化和上平台能量下降；筒体内壁VT和UT检查堆焊层；结合辐照监督数据评估断裂韧性安全裕度。 | 辐照脆化导致RT_NDT超过允许值（如AP1000要求<93.3°C），或上平台能量低于68J。不可修复，意味着RPV寿命到期，通常导致机组提前退役。 |
| 过渡段 | 容器组件 | 连接堆芯筒体与下封头的锥形或环形过渡筒节，承受轴向和弯曲应力。内壁堆焊不锈钢衬里。 | 否 | 在役检查时检查过渡段内壁堆焊层和母材（UT）；关注几何不连续处的应力集中和疲劳。 | 母材发现超标缺陷且断裂力学评估不通过。不可修复，随RPV寿命到期退役。 |
| 下封头 | 容器组件 | 半球形底部封头，与过渡段焊接连接。二代机组下封头贯穿50根因科镍导向套管（中子通量测量），三代核电取消下封头贯穿件（测量从顶盖进入），利于严重事故下IVR（熔融物堆内滞留）。 | 否 | 二代机组重点检查下封头贯穿件（导向套管）焊缝和管座（VT、ET/UT）；检查下封头内壁堆焊层状态；三代机组下封头检查相对简化；定期测量下封头外壁温度（严重事故管理用）。 | 二代机组多个贯穿管座出现超标缺陷；下封头母材出现不可修复缺陷。随RPV整体退役，不可单独更换。 |
| 径向支承块 | 容器组件 | 焊于堆芯筒体内壁的4个周向分布键块，与堆内构件吊篮的径向支承键配合。限制吊篮的径向和周向摆动，传递地震和管道破裂等事故载荷至RPV筒体。 | 否 | 大修时目视检查支承块焊缝和配合面磨损状态；测量支承块与吊篮键的配合间隙。 | 支承块焊缝出现裂纹或配合面严重磨损导致间隙超标。需由厂家评估修复（现场补焊后局部热处理）。 |
| 内壁不锈钢堆焊层 | 容器组件 | 堆焊在RPV内壁所有与冷却剂接触表面的不锈钢（308L/309L）或镍基合金衬里，厚度3~6mm，防止低合金钢母材被冷却剂腐蚀，同时作为辐照监督试样的载体焊层。 | 否 | 大修时VT检查堆焊层有无剥离、鼓泡和划伤；UT检查堆焊层与母材结合面的剥离（disbonding）；PT检查表面裂纹。 | 堆焊层大面积剥离或鼓泡影响母材保护功能；堆焊层出现贯穿性裂纹。局部损伤可打磨补焊修复，大面积损伤需由厂家评估修复方案。 |
| 主螺栓/螺母 | — | 连接顶盖法兰与容器筒体法兰的大型高强度螺栓（约58根），材料为低合金钢（如SA-540 B23/B24）或不锈钢。通过螺栓拉伸器均匀预紧，保证O形密封环的密封比压。螺栓长度可达1.5~2m，承受高温循环载荷。 | 是 | 每次开盖后检查螺栓螺纹有无损伤（VT+PT+专用量规）；检查螺栓有无弯曲和表面腐蚀；测量螺栓残余伸长量（塑性变形超限需报废）；安装时清洁螺纹并涂抹防咬合剂（钼基润滑脂）；使用螺栓拉伸器按设计预紧力分批均匀拉伸；定期进行超声波检查螺栓内部缺陷。 | 螺栓塑性伸长超过允许值（通常检测长度变化>0.2%）；螺纹损伤超过修复余量；超声波探伤发现内部超标缺陷；应力腐蚀裂纹。不可修复，必须更换同规格主螺栓。 |
| 堆内构件下部组件 | — | 安装于RPV筒体内的下部堆芯支承和导向结构，由堆芯吊篮、热屏蔽、堆芯围筒、下栅格板、流量分配孔板、二次支承组件等组成。承载燃料组件和堆芯的全部重量，提供冷却剂流道和堆芯定位。核安全二级设备，RCC-M规范制造。 | 否 | 每次换料大修对可及部位进行VT检查；定期（通常10年）进行水下UT和ET检查关键焊缝和连接螺栓；检查吊篮导向键和径向支承配合状态；检查二次支承组件的间隙和完好性；紧固件防松检查和力矩校验。 | 堆内构件整体寿命与RPV相当（≥40年），关键焊缝出现不可修复裂纹或二次支承功能丧失需评估修复或局部更换。重大降质由厂家制定修复方案（水下修复或整体更换）。 |
| 堆芯吊篮组件 | 堆内构件下部组件 | 堆内构件下部组件的核心结构，由吊篮法兰、多个筒节、堆芯支撑板和出口管嘴等组成。承担堆芯围筒定位、燃料组件载荷传递（约100吨）、中子屏蔽和冷却剂流道导向。吊篮上法兰支承在RPV筒体法兰的台肩上。 | 否 | 检查吊篮法兰与RPV台肩的接触面状态；检查吊篮筒节焊缝（水下VT和UT）；检查导向键/定位销磨损和配合间隙；检查出口管嘴与RPV出口管嘴的密封环间隙。 | 吊篮法兰严重变形或焊缝出现不可修复缺陷；导向键/销严重磨损导致堆芯对中偏差超标。需由厂家评估水下修复或整体更换（极罕见，等同重大改造）。 |
| 热屏蔽 | 堆内构件下部组件 | 由4块不锈钢板组成的不连续圆筒，安装在吊篮外围与RPV堆芯筒体内壁之间。吸收和散射快中子，降低RPV筒体的快中子辐照通量（可降低约一个数量级），减缓RPV辐照脆化。辐照监督试样管焊接在其外侧。 | 否 | 大修时VT检查热屏蔽板有无翘曲变形和螺栓松动；检查热屏蔽板与吊篮的连接焊缝和紧固件；通过辐照监督试样取出时评估热屏蔽中子衰减效果。 | 热屏蔽板严重翘曲或连接失效导致无法有效屏蔽。需由厂家评估修复方案（水下更换热屏蔽板理论上可行但操作极其复杂）。 |
| 堆芯围筒 | 堆内构件下部组件 | 由不锈钢板焊接组成的八边形或圆筒形结构，安装在吊篮内部，形成堆芯燃料区边界。二代采用螺栓连接围板结构（存在螺栓脱落风险），三代采用全焊接堆芯围筒。将进入堆芯的冷却剂和旁通冷却剂分隔。 | 否 | 检查围筒/围板连接螺栓（二代）有无松动和脱落——脱落的螺栓可能冲击燃料组件和RPV内壁；三代全焊接结构检查焊缝；检查围筒内壁有无磨损和变形。 | 围板螺栓大批量松动或脱落（二代机组重点问题）；焊缝出现不可修复缺陷。需由厂家评估修复方案（螺栓更换需水下操作；围板更换等同重大改造）。 |
