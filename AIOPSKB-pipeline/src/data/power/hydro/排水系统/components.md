| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 排水系统 | — | 水电站厂房排水系统的总称，负责排除厂房渗漏水、检修积水和生产废水，保障厂房安全运行。 | 否 | 定期巡检系统运行状态，监测各排水泵运行电流和出口压力，核对液位开关定值，检查管路阀门密封性，开展系统联调试验 | 系统整体老化多次改造仍无法满足排水要求、大范围设备损坏不具备修复价值 |
| 渗漏排水泵 | — | 排除厂房各部位渗漏水，保持集水井水位在安全范围 | 否 | 定期测量电机绝缘电阻和水泵流量扬程，检查密封和轴承状态，核对液位控制开关动作水位，定期切换运行泵和备用泵，检查叶轮磨损 | 泵体严重腐蚀穿孔漏水、叶轮严重磨损导致流量低于额定值60%、电机绕组烧毁且无修复价值 |
| 检修排水泵 | — | 机组检修时排除蜗壳、尾水管等部位的积水，为大修排水专用 | 否 | 定期进行试运行检查流量和扬程，检查水泵密封和轴承状态，核对出口阀门和逆止阀功能，检修前确认设备完好可用 | 泵体严重腐蚀、叶轮损坏流量严重不足、电机烧毁、密封严重泄漏 |
| 水泵电机 | 渗漏排水泵 | 驱动水泵运转的电动机，通常为三相异步电机 | 否 | 定期测量电机绕组绝缘电阻和直流电阻，检查轴承运行声音和温度，核对运行电流是否平衡，检查冷却风扇和接线端子 | 电机绕组烧毁或绝缘严重老化、轴承严重损坏抱死、运行电流严重不平衡 |
| 水泵叶轮 | 渗漏排水泵 | 旋转做功将机械能转化为水流动能的核心部件 | 否 | 定期检查叶轮磨损和气蚀情况，测量叶轮与密封环间隙（不超过厂家规定值），清除缠绕的杂物，检查动平衡 | 叶轮严重磨损导致流量扬程显著下降、出现裂纹或气蚀穿孔、动平衡严重超标 |
| 机械密封 | 渗漏排水泵 | 防止泵轴处漏水，由动静环组成 | 是 | 定期检查密封泄漏量（滴漏不超过规定标准），监测密封水温，检查密封面磨损状态，按运行时间预防性更换 | 密封面严重磨损导致泄漏量超标、弹簧失效密封力不足、多次更换仍反复泄漏 |
| 集水井 | — | 汇集和储存厂房渗漏水和废水的地下集水容器 | 否 | 定期清理井底淤泥和沉积物，检查井壁有无裂缝和渗漏，核对有效容积，检查拦污栅和爬梯完好性 | 井壁严重开裂影响结构安全、严重淤积清淤后仍无法满足容积要求、结构损坏无法修复 |
| 液位传感器 | 集水井 | 监测集水井水位，为排水泵启停和报警提供信号 | 是 | 定期校验液位测量精度（与实际水位比对），检查传感器探头清洁度，核对高水位报警和超高水位告警定值，检查信号传输线 | 测量偏差严重超差经校准仍不合格、探头损坏无法修复、信号输出不稳定 |
| 液位控制开关 | 集水井 | 根据集水井水位自动控制排水泵启停，高水位时启动备用泵和报警 | 是 | 定期校验各水位开关动作值（停泵水位、启泵水位、报警水位、超高水位），检查浮球或电极式探头状态，测试与水泵控制回路的联锁功能 | 开关动作定值严重偏移、浮球卡死或电极短路、信号回路故障导致水泵无法自动启停 |
| 排水管路 | — | 输送渗漏水和检修积水的管道系统 | 否 | 定期检查管路有无泄漏和腐蚀，核对管路支架和固定件完好性，检查伸缩节状态，监测管路振动情况 | 管路严重锈蚀多处泄漏、管路支架严重损坏影响安全、大范围管段报废需更换 |
| 闸阀 | 排水管路 | 截断或接通管路水流的阀门 | 否 | 定期操作检查阀门灵活性，检查阀杆和填料函密封性，加注润滑脂，核对开关指示与实际位置一致 | 阀体严重锈蚀穿孔、阀杆弯曲无法操作、密封面严重损坏关不严 |
| 逆止阀（止回阀） | 排水管路 | 防止排水泵停机后管路中水倒流，保护水泵 | 是 | 定期检查阀瓣密封性和铰链灵活性，检查阀体内壁磨损和结垢，测试关闭响应速度 | 阀瓣严重磨损导致关不严、铰链损坏阀瓣脱落、阀体严重腐蚀 |
| 滤水器 | 排水管路 | 过滤水中杂物，防止堵塞水泵和管路 | 是 | 定期清洗滤网，检查滤网有无破损和变形，核对前后压差，清理收集的杂物 | 滤网严重破损失去过滤功能、壳体锈蚀穿孔、滤网堵塞严重且清洗无效 |
| 离心泵轴承 | 渗漏排水泵 | 支撑泵轴旋转，承受径向和轴向载荷 | 是 | 定期检查轴承运行声音和温度，按运行小时数加注润滑脂，测量轴承振动值，检查轴承游隙 | 轴承严重磨损导致振动超标、滚道出现剥落和点蚀、轴承温升异常且润滑无效 |
| 联轴器 | 渗漏排水泵 | 连接电机轴与泵轴，传递扭矩并补偿对中偏差 | 否 | 定期检查联轴器弹性垫磨损状态，核对电机与水泵对中精度，检查连接螺栓紧固力矩 | 弹性垫严重碎裂失去缓冲功能、对中严重偏移导致振动异常、联轴器本体出现裂纹 |
| 控制柜 | — | 排水泵的电气控制设备，实现自动/手动启停、保护和信号功能 | 否 | 定期检查柜内元器件状态，核对保护整定值，测试自动启停功能，检查接线端子紧固性，清扫柜内灰尘 | 柜体严重锈蚀变形、控制回路大面积故障、经多次修复仍无法满足自动控制要求 |
| 接触器 | 控制柜 | 控制水泵电机启停的电磁开关 | 是 | 定期检查触头磨损和表面状态，检查灭弧罩完整性，测量线圈电阻，核对吸合和释放电压 | 触头严重烧损厚度低于允许值、灭弧罩破损、线圈烧毁 |
| 热继电器 | 控制柜 | 对水泵电机进行过载保护 | 否 | 定期核对整定电流与电机额定电流匹配，检查辅助触点状态，校验动作特性 | 热元件严重变形或烧损、脱扣特性严重偏移经校验仍不合格 |
| 控制电源 | 控制柜 | 为控制回路提供工作电源，通常由厂用电经变压器或开关电源供电 | 否 | 定期检查电源电压是否在允许范围内，测量输出电压和纹波，检查熔断器和接线状态 | 电源模块烧毁且无同型号备件、输出电压严重不稳导致控制系统异常 |
