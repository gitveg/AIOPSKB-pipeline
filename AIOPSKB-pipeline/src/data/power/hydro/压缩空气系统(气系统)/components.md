| --- | --- | --- | --- | --- | --- |
| 压缩机 | — | 将机械能转化为气体压力能，提升压缩空气的压力，是整个系统的核心动力源。 | 否 | 定期检查运行声音和振动，监测排气压力和温度，核对润滑油位和油质，检查各连接部位密封性，按厂家规定的运行小时数进行大修保养 | 主机转子严重磨损导致排气量持续下降且大修无法恢复、机体出现裂纹、经大修后仍无法达到额定参数 |
| 螺杆主机 | 压缩机 | 通过阴阳螺杆转子啮合完成吸气、压缩和排气过程，是压缩机内部的主要做功部件。 | 否 | 定期检查润滑油品质（黏度、酸值），监测排气温度和振动，按运行小时数更换润滑油，大修时检查转子型面磨损和间隙 | 转子型面严重磨损导致容积效率显著下降、轴承位磨损超标、阴阳转子咬合或卡死、壳体严重磨损 |
| 螺杆转子 | 螺杆主机 | 一对精密配合的螺旋齿形转子，完成气体压缩的关键运动部件。 | 否 | 在大修时测量转子型面磨损量和啮合间隙，检查表面有无拉伤和腐蚀，进行动平衡校验 | 型面严重磨损或拉伤导致排气量低于额定值80%、动平衡严重超标无法校正、转子出现裂纹或变形 |
| 轴承 | 螺杆主机 | 支撑转子并承受径向与轴向载荷，确保转子平稳旋转。 | 是 | 定期监测轴承振动值和温度，按运行小时数（通常2万-3万小时）预防性更换轴承，检查润滑脂状态 | 轴承严重磨损导致振动值超标、滚道或滚动体出现剥落点蚀、轴承温升异常经更换后仍反复故障 |
| 轴封 | 螺杆主机 | 防止压缩腔体内的油气混合物沿转轴向外泄漏。 | 是 | 定期检查轴封处有无明显漏油迹象，监测压缩机油消耗量是否异常增大，大修时检查密封唇口磨损状态 | 密封唇口严重磨损导致持续漏油且更换后仍泄漏、轴封安装位轴颈严重磨损、弹簧失效密封力不足 |
| 进气阀 | 压缩机 | 控制压缩机的进气量，实现加卸载或容量调节，满足下游用气需求变化。 | 是 | 定期检查阀体内部积碳和油泥，清洗阀芯和阀座，检查密封面完好性，校验容量调节控制管路，测试加卸载响应速度 | 阀芯严重磨损导致无法密封、阀体变形或裂纹、调节弹簧疲劳失效无法稳定调节 |
| 油气分离器 | 压缩机 | 将压缩空气中的润滑油分离出来，使排出压缩空气的含油量降至极低水平。 | 是 | 定期监测分离前后压差（压差超标即需更换滤芯），检查排气的含油量，按运行小时数（通常3000-6000小时）更换分离滤芯 | 滤芯严重堵塞压差持续超标、滤材破损导致排气含油量严重超标、筒体锈蚀穿孔漏油 |
| 油过滤器 | 压缩机 | 滤除润滑油中的金属颗粒与杂质，保障润滑系统和转子清洁。 | 是 | 定期检查过滤器前后压差，按运行小时数（通常2000-4000小时）更换滤芯，取样检查润滑油清洁度，更换时排净旧油 | 滤芯堵塞严重导致供油不足报警、滤芯破损失去过滤功能、壳体变形泄漏 |
| 温控阀 | 压缩机 | 根据油温控制润滑油流向冷却器或直接返回主机，维持润滑油在最佳工作温度。 | 否 | 定期检查温控阀动作温度是否准确，清洗阀体内部油泥，检查阀芯运动灵活性，校验旁通和直通切换温度 | 阀芯卡死导致油温无法调节（持续过高或过低）、阀体严重泄漏、温控元件失效 |
| 空气滤清器 | 压缩机 | 过滤进入压缩机的环境空气，去除灰尘和颗粒物，保护压缩主机。 | 是 | 定期检查滤芯积尘程度，按运行环境清洁或更换滤芯（通常每500-2000小时），清理进气管道，检查密封圈完好性 | 滤芯严重堵塞导致进气阻力增大、滤材破损失去过滤保护作用、密封圈老化无法密封 |
| 传感器 | 压缩机 | 包含压力与温度传感器，用于监测喷油压力、排气温度等关键参数并提供给控制器。 | 是 | 定期校验传感器测量精度（与标准仪表比对），检查传感器接线端子紧固和绝缘，清洁传感器探头表面污垢 | 传感器测量偏差超过允许范围且无法校准、信号输出不稳定、探头损坏或外壳破裂 |
| 后冷却器 | — | 冷却压缩机排出的高温压缩空气，使水蒸气和油雾凝结，便于后续分离。 | 否 | 定期检查冷却效果（进出气温差），清扫冷却翅片和散热表面，检查冷却水管路有无堵塞和泄漏，监测排气温度 | 冷却管束严重结垢或堵塞导致冷却效率严重下降且清洗无效、壳体锈蚀穿孔泄漏、换热面积损坏超过30% |
| 气水分离器 | 后冷却器 | 利用离心力或挡板将冷凝水和大颗粒油滴从气流中分离并排出。 | 否 | 定期检查分离器内部挡板和旋风叶片完好性，清理内部积油和杂质，检查排水口通畅性，测试分离效率 | 内部挡板严重变形或脱落导致分离效率显著下降、壳体锈蚀穿孔、长期运行后结构损坏无法修复 |
| 疏水阀 | 后冷却器 | 自动排放聚积的冷凝水，防止液态水进入下游管路。 | 是 | 定期检查阀芯和密封面有无磨损，测试自动排水功能是否正常，清理阀体内部杂质和积垢，校验排水灵敏度 | 阀芯严重磨损导致持续漏气或无法排水、密封面损坏无法密封、阀体腐蚀穿孔 |
| 干燥器 | — | 进一步去除经冷却分离后的压缩空气中的水蒸气，达到工艺要求的压力露点。 | 否 | 定期检查干燥器出口露点温度，检查切换周期是否正常，核对再生排气温度，检查控制器运行状态，每年校验露点仪 | 干燥效率严重下降出口露点持续超标且更换干燥剂无效、控制器损坏无法修复、筒体严重锈蚀泄漏 |
| 干燥剂（吸附剂） | 干燥器 | （仅吸干机）利用活性氧化铝或分子筛等多孔材料吸附水分。 | 是 | 定期取样检测干燥剂吸附容量和强度，观察干燥剂颜色变化（变色指示），按运行时间（通常2-3年）更换干燥剂，补充损耗量 | 干燥剂粉化严重导致气流阻力增大、吸附容量下降导致露点超标、强度严重不足产生粉尘污染下游 |
| 控制器/阀门 | 干燥器 | 控制双塔切换、再生气流与干燥时序，确保连续供气。 | 否 | 定期检查电磁阀动作是否灵活可靠，校验切换时序控制器参数，检查先导气路通畅性，核对阀门密封性 | 阀门内漏严重导致干燥效率下降、控制器故障无法修复、阀体严重磨损或腐蚀 |
| 管路过滤器 | — | 安装于干燥器前后或用气点前，分级过滤掉压缩空气中的颗粒、水分和油雾。 | 否 | 定期检查各级过滤器前后压差，检查滤芯状态，核对出口空气质量（颗粒含量和含油量），检查排污阀工作状态 | 壳体严重锈蚀泄漏、内部结构变形损坏、过滤效率严重下降且更换滤芯无效 |
| 粗滤芯 | 管路过滤器 | 位于前级，用于拦截较大颗粒物和大量液态水，保护下游高精度滤芯。 | 是 | 定期检查前后压差（超过初始值0.07MPa即需更换），按运行时间或压差指示更换滤芯，清理壳体内部 | 滤芯严重堵塞压差超标、滤材破损变形失去过滤能力、骨架变形或塌陷 |
| 精滤芯 | 管路过滤器 | 位于后级，用于聚结并去除微小油雾和微粒，提供高洁净度压缩空气，通常由玻璃纤维或烧结材料制成。 | 是 | 定期检查前后压差（超过初始值0.14MPa即需更换），监测出口含油量指标，按运行时间更换滤芯，检查密封圈状态 | 滤芯堵塞压差超标影响系统运行、滤材破损出口含油量超标、滤芯结构塌陷 |
| 储气罐 | — | 储存压缩空气，消除压力脉动，缓冲用气高峰，并利用重力沉降继续分离冷凝水。 | 否 | 每年进行内外部检查，测量壁厚核算腐蚀裕量，定期排污排除底部积水和油污，检查安全阀和压力表，按规程进行定期检验（通常3-6年一次耐压试验） | 壁厚减薄超过允许值无法通过强度核算、罐体出现裂纹或严重变形、内壁严重腐蚀超标、超过设计使用年限且检验不合格 |
| 安全阀 | 储气罐 | 当罐内压力超过设定限值时自动开启泄压，防止超压爆炸。 | 是 | 每年校验安全阀整定压力和回座压力（送有资质的检验机构），定期手动扳动阀杆检查灵活性，检查阀体和密封面完好性 | 整定压力偏移超标且无法校准、阀芯严重磨损导致泄漏或回座压力不合格、阀体出现裂纹 |
| 压力表 | 储气罐 | 直观显示储气罐内部的工作压力。 | 否 | 每年校验压力表精度等级，检查表盘指示是否清晰，校验零位和量程，检查表接头密封性 | 指示偏差超过精度等级允许范围、表盘模糊或指针脱落、表内游丝损坏或弹簧管泄漏 |
| 手动排污阀 | 储气罐 | 定期手动打开，排出罐底积存的冷凝水与油污。 | 否 | 定期手动操作排污阀排出积水和油污，检查阀芯密封面和填料函，操作后确认阀门关闭严密无泄漏 | 阀芯严重磨损导致关不严持续泄漏、阀杆锈蚀弯曲无法操作、阀体腐蚀穿孔 |
| 控制管路与调节阀 | — | 将压缩空气送至各用气点，并对压力、流量进行终端调节。 | 否 | 定期巡检管路有无泄漏和腐蚀，检查各接头紧固性，核对终端压力和流量是否满足用气设备需求，检查管路支撑和膨胀节 | 管路严重锈蚀多处泄漏、管路支架严重损坏影响安全、大范围管路报废更换 |
| 压力调节器 | 控制管路与调节阀 | 将管路压力减至并稳定在工作需求值，保护用气设备。 | 否 | 定期检查输出压力稳定性，校验调压范围和精度，清洗阀体内部，检查膜片和弹簧状态 | 输出压力严重波动无法稳定、调压弹簧疲劳失效、膜片破损无法调节 |
| 电磁阀 | 控制管路与调节阀 | 利用电信号控制气路的通断和方向。 | 是 | 定期检查电磁阀动作响应速度，测量线圈电阻和绝缘电阻，检查阀芯密封性和运动灵活性，清洁阀体内部 | 线圈烧毁、阀芯卡死或严重磨损导致内漏、密封件老化失效无法关断 |
| 气管与接头 | 控制管路与调节阀 | 构成输送气体的网络，通过快插或螺纹接头实现密封连接。 | 是 | 定期检查管路有无老化龟裂和机械损伤，检查各接头密封性（皂液检漏），更换老化变硬的管段，紧固松动的接头 | 管路老化龟裂多处泄漏、接头严重变形或滑丝无法密封、管路内壁严重脱落堵塞 |
