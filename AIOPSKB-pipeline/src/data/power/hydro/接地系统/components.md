| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 接地系统整体 | — | 将电气设备的中性点、外壳或构架通过导体与大地可靠连接，用以泄放故障电流、限制电位升高、保障人身与设备安全的完整装置。 | 否 | 每年在干燥季节测量接地电阻值，检查接地网完整性，核实各设备接地线连接可靠，对接地网进行开挖抽检 | 接地电阻持续超标且无法通过扩建接地网改善、接地网大面积腐蚀断裂无法修复时全面改造更换 |
| 接地体 | 接地系统整体 | 埋入土壤或导电介质中，直接与大地接触并提供电流散流通道的金属或非金属导体的总称。 | 否 | 每年检查接地体引出线连接状况，定期开挖抽查接地体腐蚀程度，核实热稳定截面满足要求 | 接地体截面腐蚀减薄超过原截面积30%、多处断裂无法可靠散流时更换接地体 |
| 自然接地体 | 接地体 | 利用建筑物基础钢筋、金属管道、电缆铅包等既有金属物作为接地极，需满足热稳定和接触可靠要求。 | 否 | 每年检查自然接地体与接地干线的连接是否可靠，核实利用的金属管道未因检修断开 | 自然接地体因建筑改造被破坏、连接不可靠或腐蚀严重失去散流能力时补充人工接地体替代 |
| 人工接地体 | 接地体 | 专门埋设的接地极，包括垂直接地极（角钢、钢管、圆钢）和水平接地体（扁钢、圆钢）。 | 否 | 每三年进行一次开挖抽样检查，测量导体腐蚀减薄情况，检查焊接点完好性 | 接地体大面积腐蚀断裂、截面减薄超过允许值或多处脱焊且无法补焊时重新埋设 |
| 垂直接地极 | 人工接地体 | 垂直打入土壤的角钢、钢管等，顶端离地面不小于0.6m，长度通常为2.5m，多根时通过水平接地带连接。 | 是 | 每年检查引出线连接点有无松动腐蚀，核实顶端埋深，在接地电阻不合格时增设接地极 | 接地极严重锈蚀截面减薄超标、被打断或引出连接处断裂无法修复时重新打入新极 |
| 水平接地带 | 人工接地体 | 埋设于土壤表层的扁钢、圆钢等，连接垂直接地极或单独用作散流，埋深一般0.6-0.8m。 | 是 | 每三年开挖抽检扁钢/圆钢腐蚀程度，检查搭接焊接质量，核实埋深未被冲刷暴露 | 水平接地带严重锈蚀断裂、截面损失超过允许值或大面积外露时重新敷设 |
| 降阻模块／降阻剂 | 人工接地体 | 填充于接地极周围的低电阻率材料，用于减小接地电阻并减缓接地极腐蚀，常见有化学降阻剂和物理降阻模块。 | 是 | 每三年检查降阻模块有无碎裂流失，降阻剂有无干涸流失，必要时补充更换 | 降阻模块碎裂失效、降阻剂流失殆尽或降阻效果明显衰减时重新填充或更换模块 |
| 接地线 | 接地系统整体 | 连接设备接地端子与接地体或接地母线的导体，将设备电位引向接地网。 | 否 | 每年检查接地线有无机械损伤、腐蚀和断裂，核实导线截面满足短路电流热稳定要求 | 接地线严重腐蚀断裂、截面不足或绝缘层老化脱落时更换接地线 |
| 接地干线 | 接地线 | 沿建筑或设备区域敷设的主接地导体，汇集各分支接地线后将电流导入接地体或接地母线，常采用铜排、镀锌扁钢。 | 否 | 每年检查干线连接点紧固和防腐情况，测量干线导通电阻，核实支撑固定牢靠 | 干线严重腐蚀截面减薄超标、连接点多处失效或因厂房改造无法保留时重新敷设 |
| 接地支线 | 接地线 | 从设备接地端子连接到接地干线的分支导体，常用多股铜芯线或镀锌圆钢，截面满足机械强度和热稳定要求。 | 否 | 每年检查支线与设备端子及干线的连接紧固性，核实导线有无损伤 | 支线腐蚀断股、截面不足或连接不可靠时更换接地支线 |
| 接地母排／等电位连接排 | 接地线 | 安装在配电柜或墙壁上的铜排，多个接地线在此汇接，实现等电位连接与集中接地。 | 否 | 每年检查铜排表面氧化情况并清理，紧固所有连接螺栓，核实支持绝缘子完好 | 铜排严重氧化发黑接触不良、连接孔滑丝或绝缘子破损时更换母排 |
| 连接与防护件 | 接地系统整体 | 实现导体间可靠电气连接并防止电化腐蚀、机械损伤的各类附件。 | 否 | 每年检查各类连接件的紧固状态和腐蚀情况，核实防腐措施完好 | 连接件大面积锈蚀失效、无法保证电气连接可靠性时批量更换 |
| 焊接接头／夹具 | 连接与防护件 | 采用热熔焊接（放热焊）、压接或螺栓压接的接地线连接点，要求接触电阻低且耐腐蚀。 | 是 | 每年检查焊接点有无裂纹脱焊，螺栓连接点有无松动，测量接头过渡电阻 | 焊接点开裂脱焊、螺栓连接点严重锈蚀导致接触电阻超标时重新焊接或更换夹具 |
| 防腐护层 | 连接与防护件 | 涂覆于接地线、接地极外表面的沥青漆、防锈漆或缠绕防腐带，用以减缓土壤或空气腐蚀。 | 是 | 每年检查防腐层有无脱落起皮，对裸露金属及时补涂沥青漆或缠绕防腐带 | 防腐层大面积脱落导致金属严重腐蚀时清除旧涂层重新防腐处理 |
| 接地端子 | 连接与防护件 | 设备外壳或机架上的专用接线螺栓或端子板，用于紧固接地支线，需保持良好接触和防松。 | 是 | 每年检查端子螺栓紧固力矩，清洁接触面氧化物，核实防松弹簧垫圈完好 | 端子严重锈蚀接触不良、螺纹滑丝无法紧固或端子板断裂时更换端子 |
| 接地断开点／测试卡子 | 连接与防护件 | 设置于接地线引上端的可断开连接点，用于断开测量接地电阻，平时保持紧固。 | 否 | 每年在测量接地电阻时操作断开点检查其动作灵活性，平时核实紧固状态 | 断开点锈蚀卡涩无法断开、连接螺栓滑丝或外壳破损时更换测试卡子 |
