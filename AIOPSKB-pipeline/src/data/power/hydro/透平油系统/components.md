| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 油箱 | — | 储存透平油，进行回油沉淀、初步分离水分和气体。 | 否 | 定期检查油箱外观有无锈蚀、渗漏和变形；每年清洗油箱内部，清除底部沉积的水分和机械杂质；检查油箱液位计指示是否准确；检查呼吸器或通气滤网是否畅通；大修时对油箱内壁进行防腐处理。 | 油箱壁板严重锈蚀减薄出现针孔或裂纹；箱体焊缝开裂且补焊后仍反复渗漏；内部防腐涂层大面积脱落导致油质持续劣化；箱体严重变形影响安装和使用时，应更换油箱。 |
| 油箱加热器 | 油箱 | 低温时加热油液，保证启动与运行所需油温。 | 是 | 定期检查加热器供电是否正常，控制温度设定值是否准确；每月检查加热器表面有无油垢积碳，清洁加热元件；大修时测量加热器电阻值和绝缘电阻是否合格；检查温控器和过热保护装置动作是否可靠。 | 加热器电阻丝断路或绝缘电阻严重下降；加热管穿孔导致油液浸入引起短路；加热功率严重衰减无法在规定时间内将油温提升至设定值；温控器损坏导致温度失控时，应更换油箱加热器。 |
| 液位计 | 油箱 | 显示油箱油位，并输出高低液位报警信号。 | 否 | 定期检查液位计显示是否清晰准确，与实际油位是否一致；每月清洁液位计表面油污；大修时校验液位计报警设定值和输出信号精度；检查液位计连接法兰有无渗漏；检查磁翻板或浮子运动是否灵活。 | 液位计指示严重失真且无法校准；浮子或磁翻板卡死无法正常跟随油位变化；传感器元件损坏导致无法输出报警信号；玻璃管或视窗破裂导致渗漏时，应更换液位计。 |
| 排烟风机 | 油箱 | 排出油箱内的油烟及水蒸气，维持油箱微负压。 | 是 | 定期检查风机运转是否平稳无异响；每月清洁风机叶轮和风道积油；大修时检查风机电机绝缘和轴承磨损状况；检查风道连接是否密封良好；验证风机启停控制逻辑是否正常。 | 风机电机烧毁或轴承严重损坏；叶轮腐蚀变形导致风量严重不足；运行噪声和振动急剧增大；经维修后仍无法维持油箱正常通风和微负压时，应更换排烟风机。 |
| 回油滤网 | 油箱 | 安装在回油管口，拦截系统回油携带的大颗粒杂质。 | 是 | 定期检查回油滤网有无堵塞和破损；每月清洗滤网，清除拦截的杂质和油泥；大修时检查滤网骨架有无变形和腐蚀；检查滤网与回油管口的配合密封是否良好。 | 滤网严重破损无法有效拦截大颗粒杂质；骨架变形或腐蚀导致滤网无法正常安装和密封；经多次清洗后网孔仍严重堵塞导致回油阻力过大时，应更换回油滤网。 |
| 主油泵 | — | 为机组提供连续、稳定的压力油，用于润滑、冷却和控制。 | 否 | 定期检查油泵出口压力和流量是否正常；监听运行声音有无异常噪音或振动；每月检查轴封有无渗漏；大修时检测泵内部件磨损量，测量齿轮或螺杆配合间隙；定期检查联轴器对中情况。 | 泵体出现裂纹；齿轮或螺杆磨损导致容积效率显著下降且无法通过更换部件恢复；轴承损坏导致转子磨损严重；多次维修后仍无法达到额定压力和流量时，应报废更换主油泵。 |
| 主泵驱动电机 | 主油泵 | 驱动主油泵旋转，提供动力输入。 | 是 | 定期检查电机运行电流和温升是否正常；每月监听电机运转声音，检查轴承有无异响；每半年测量电机绝缘电阻是否合格；大修时检查电机轴承磨损状况，必要时更换润滑脂或轴承；检查接线端子紧固和电缆状况。 | 电机绕组烧毁或绝缘电阻严重下降无法恢复；轴承多次损坏导致转子扫膛；电机效率严重下降导致过热运行；经大修后仍无法满足驱动油泵的正常运行要求时，应更换驱动电机。 |
| 主泵机械密封 | 主油泵 | 防止泵轴端油液泄漏的轴向密封组件。 | 是 | 定期检查密封处有无滴漏，发现渗漏及时调整或更换；大修时检查密封面磨损情况和弹簧预紧力；检查密封冷却冲洗水路是否畅通；更换密封时选用与油品和工作温度匹配的材质。 | 密封面严重磨损导致泄漏量持续增大；弹簧断裂或疲劳导致密封力不足；密封材料老化硬化失去弹性；经多次调整和更换仍无法消除泄漏时，应更换机械密封。 |
| 主泵轴承 | 主油泵 | 支撑泵转子，承受径向与轴向载荷。 | 是 | 定期监测轴承温度和振动是否在正常范围内；每月检查润滑状况，按周期补充或更换润滑脂；大修时拆卸检查轴承滚道和滚动体表面有无磨损、剥落和裂纹；测量轴承游隙是否在允许范围内。 | 轴承滚道或滚动体表面出现严重剥落、磨损或裂纹；轴承游隙严重超标导致转子晃动；运行中持续高温或异响且润滑无法改善；保持架断裂或变形时，应更换轴承。 |
| 联轴器弹性块 | 主油泵 | 传递扭矩并补偿安装偏差，吸收振动冲击。 | 是 | 定期检查弹性块有无老化、变形、龟裂或磨损；大修时测量弹性块尺寸变化，判断是否需要更换；检查联轴器对中偏差是否在允许范围内；发现弹性块有裂纹时立即更换。 | 弹性块严重老化开裂或变形失去弹性；齿面磨损过量导致传动间隙过大；因老化导致减振性能显著下降；出现裂纹或碎片脱落时，应立即更换联轴器弹性块。 |
| 辅助油泵 | — | 在主油泵出力不足或事故状态下自动投入，保证供油。 | 否 | 定期进行辅助油泵启停试验，验证自动投入功能是否正常；每月检查泵体有无渗漏和异常振动；大修时解体检查泵内部件磨损状况；检查联轴器和密封件状态；长期备用时每月试运转一次。 | 泵体出现裂纹或严重锈蚀；内部齿轮或叶片磨损导致出力严重不足；多次维修后仍无法在事故状态下可靠投入；容积效率低于允许下限时，应更换辅助油泵。 |
| 辅助泵驱动电机 | 辅助油泵 | 驱动辅助油泵旋转。 | 是 | 定期检查电机运行电流和温升；每月测量电机绝缘电阻；大修时检查轴承和接线状况；长期备用时每月试运行检查启动性能；检查电机防护等级是否符合安装环境要求。 | 电机绕组烧毁；绝缘电阻持续下降且低于安全标准；轴承严重损坏导致无法正常运转；经检修后仍无法可靠启动和运行时，应更换辅助泵驱动电机。 |
| 辅助泵机械密封 | 辅助油泵 | 防止辅助泵轴端泄漏。 | 是 | 定期检查密封处有无渗漏；大修时检查密封面磨损和弹簧状态；检查密封材料是否与油品兼容；发现泄漏增大时及时更换。 | 密封面严重磨损导致持续泄漏；弹簧断裂或疲劳；密封材料老化硬化失去弹性时，应更换机械密封。 |
| 油冷却器 | — | 将透平油热量传递给冷却水，控制油温在规定范围。 | 否 | 定期检查冷却器进出口油温差和冷却水流量是否正常；每月检查冷却水管路有无渗漏；大修时清洗冷却器水侧和油侧，清除水垢和沉积物；检查端盖密封状况；冬季停用时应排空冷却水防止冻裂。 | 冷却器管束腐蚀穿孔导致油水混合；壳体严重锈蚀变形；换热效率严重下降且清洗后无法恢复；多次堵管后冷却面积不足时，应更换油冷却器。 |
| 冷却器芯子 | 油冷却器 | 管束或板片结构，实现油-水高效热交换。 | 是 | 定期检查换热效率是否满足运行要求；大修时清洗管束内外壁水垢和油垢；检查管束有无腐蚀和渗漏；检查板片有无变形和结垢；检查管板焊缝有无裂纹。 | 管束大面积腐蚀穿孔导致反复泄漏；板片严重变形或腐蚀导致换热效率急剧下降；多次堵管后剩余冷却面积严重不足；管板焊缝开裂无法修复时，应更换冷却器芯子。 |
| 冷却器端盖密封垫 | 油冷却器 | 确保水侧、油侧各腔室隔离，防止内漏。 | 是 | 每次拆卸端盖后检查密封垫有无老化变形和压痕；大修时全部更换密封垫；安装时确保密封面清洁平整，均匀拧紧螺栓；发现端盖结合面有渗漏痕迹时及时检查和更换密封垫。 | 密封垫老化硬化失去弹性；表面出现深压痕或裂纹导致密封不可靠；材料被油或水腐蚀膨胀变形；已达到规定的更换周期时，应直接报废更换新的密封垫。 |
| 油过滤器 | — | 滤除油中固体颗粒及杂质，保持系统油清洁度。 | 否 | 定期检查过滤器压差指示器，压差报警时及时切换或更换滤芯；每月检查过滤器壳体有无渗漏；大修时清洗过滤器壳体内部；检查切换阀和排气阀动作是否灵活。 | 过滤器壳体严重锈蚀或变形；内部通道损坏导致油流短路失去过滤功能；安装座损坏导致密封不可靠；经多次维修后仍无法保证过滤精度时，应更换油过滤器。 |
| 过滤器滤芯 | 油过滤器 | 拦截固体污染物的核心元件，需定期更换。 | 是 | 当压差指示器报警时及时更换滤芯；按规程规定的周期定期更换（通常3-6个月）；更换时确保新滤芯规格型号正确，安装密封可靠；废弃滤芯按环保要求处理；记录更换日期和压差数值。 | 滤芯达到规定的更换周期；压差报警显示滤芯已堵塞；滤芯破损或变形失去过滤功能；滤材塌陷或脱落导致过滤精度不达标时，应直接报废更换新的滤芯。 |
| 切换阀 | 油过滤器 | 在双联过滤器上不停机切换工作与备用滤筒。 | 是 | 定期操作切换阀进行工作与备用滤筒切换，验证动作是否灵活可靠；大修时检查阀芯密封面和O型圈磨损状况；检查切换手柄和定位机构是否可靠；切换操作后确认无泄漏。 | 阀芯密封面严重损坏导致内泄无法隔离工作滤筒；阀体出现裂纹或严重腐蚀；切换机构卡涩无法完成切换操作；经检修后仍无法可靠切换和密封时，应更换切换阀。 |
| 排气阀 | 油过滤器 | 充油或运行时排出滤筒内气体，防止油压波动。 | 是 | 每次更换滤芯或切换滤筒后操作排气阀排出空气；定期检查排气阀密封是否可靠，有无油液渗漏；大修时检查阀芯和弹簧状态；检查排气孔是否畅通。 | 阀芯密封面损坏导致持续渗漏；弹簧断裂导致阀门无法关闭；阀体螺纹损坏无法安装密封；排气后仍无法密封导致空气持续进入系统时，应更换排气阀。 |
| 油净化装置 | — | 在线或离线处理，除去油中水分、气体和细微杂质。 | 否 | 定期检查净化装置运行状态和处理效果；每月检查进油和出油品质指标变化；大修时全面检修各功能模块，更换耗材部件；检查管路连接和阀门密封状况。 | 净化装置主要功能模块严重损坏无法修复；处理效率严重下降无法将油质恢复至合格标准；经多次大修后仍频繁故障；技术淘汰且无备件支持时，应报废更换净化装置。 |
| 净化装置滤芯 | 油净化装置 | 拦截杂质或聚结分离水分的可更换元件。 | 是 | 按规程规定周期或压差报警时更换滤芯；定期检查处理前后油品指标以评估滤芯效果；更换时确保滤芯规格正确安装密封可靠；记录更换日期和处理油量。 | 滤芯达到规定更换周期或处理量限额；压差报警显示堵塞；处理后油品指标仍不达标说明滤芯失效；滤芯破损或塌陷时，应直接报废更换新的滤芯。 |
| 净化装置真空泵 | 油净化装置 | 建立负压环境，辅助油中水分和气体析出。 | 是 | 定期检查真空泵运行声音和振动是否正常；每月检查真空泵油质和油位；大修时检查泵内部件磨损情况，测量极限真空度；检查密封件和进排气阀片状态。 | 真空泵内部严重磨损导致极限真空度无法达到要求；泵体出现裂纹；多次维修后仍无法提供足够的真空度；运行噪声和振动急剧增大时，应更换真空泵。 |
| 蓄能器 | — | 吸收压力脉动、补偿泄漏并稳定控制系统油压。 | 否 | 定期检查蓄能器充气压力是否在规定范围内；每月检查蓄能器接口有无渗漏；大修时检查壳体有无变形和锈蚀；校验安全阀或爆破片；检查安装支架是否牢固可靠。 | 壳体出现裂纹或严重变形；疲劳寿命超过厂家规定年限；充气后压力持续快速下降表明内部严重泄漏；经检验机构认定不合格时，应报废更换蓄能器。 |
| 蓄能器皮囊 | 蓄能器 | 隔离气液介质，靠气体压缩储存压力能。 | 是 | 定期监测蓄能器保压性能，判断皮囊有无内泄；按规定周期（通常2-3年）更换皮囊；充气时严格按照规定压力操作避免超压；检查气侧有无油味以判断皮囊是否破裂。 | 皮囊破裂导致气油混合；皮囊老化硬化失去弹性；表面出现裂纹或永久变形；充气后短时间内压力迅速下降确认皮囊失效时，应更换皮囊。 |
| 蓄能器充气阀 | 蓄能器 | 用于充入或补充氮气，维持预定充气压力。 | 是 | 定期检查充气阀有无气体泄漏；每次充气后确认阀门关闭密封可靠；大修时检查阀芯密封面和弹簧状态；充气操作使用专用充气工具，避免损伤阀芯。 | 充气阀阀芯密封面损坏导致持续漏气无法保压；阀体螺纹损坏无法连接充气工具；弹簧断裂导致阀门无法关闭；经更换密封件后仍无法密封时，应更换充气阀。 |
| 调节阀 | — | 自动或手动调节润滑油/控制油压力至设定值。 | 否 | 定期检查调节阀输出压力是否稳定在设定值；每月检查阀体有无渗漏和异常振动；大修时解体检查阀芯密封面和弹簧状态；校验压力设定值是否准确。 | 阀体出现裂纹或严重腐蚀；阀芯密封面严重损坏导致无法维持设定压力；弹簧断裂或严重疲劳；经研磨和调整后仍无法恢复调压精度时，应更换调节阀。 |
