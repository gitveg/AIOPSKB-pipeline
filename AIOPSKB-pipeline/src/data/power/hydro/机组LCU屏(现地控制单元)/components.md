| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 机组LCU屏 | — | 现地控制单元核心设备，集成数据采集、逻辑控制、通信等功能，实现水轮发电机组自动启停与保护。 | 否 | 每季度检查屏内各模块运行状态，核实通信链路正常，测试紧急停机功能，检查柜体密封和散热 | 屏体严重锈蚀变形、核心控制功能丧失且多次改造仍无法满足自动化要求时整屏报废更换 |
| 可编程逻辑控制器 | 机组LCU屏 | 执行控制逻辑与顺序流程的核心处理器，接收传感器信号并输出控制指令。 | 否 | 每季度检查PLC运行指示灯和故障诊断信息，核实程序完整性，监测CPU温度和内存使用率 | PLC硬件多次故障、程序频繁丢失或处理能力无法满足控制需求时更换PLC |
| CPU模块 | 可编程逻辑控制器 | 中央处理单元，运行用户程序，进行数据运算与通信管理。 | 否 | 每季度检查CPU运行状态和电池电量，备份用户程序和参数，核实看门狗功能 | CPU芯片损坏、程序反复丢失或运行速度严重滞后影响控制实时性时更换CPU模块 |
| 数字量输入模块 | 可编程逻辑控制器 | 采集开关量信号，如断路器状态、按钮信号等。 | 否 | 每半年用信号发生器逐通道测试输入响应，检查光电隔离完好性，核实滤波参数 | 通道损坏数量超过总通道数20%、光电隔离击穿或输入阻抗异常时更换模块 |
| 数字量输出模块 | 可编程逻辑控制器 | 输出开关量控制信号，驱动继电器、指示灯等。 | 否 | 每半年逐通道测试输出驱动能力，检查继电器动作可靠性，核实输出隔离完好性 | 输出通道损坏或驱动能力不足导致执行器拒动时更换模块 |
| 模拟量输入模块 | 可编程逻辑控制器 | 采集温度、压力、液位、转速等模拟量信号。 | 否 | 每季度加注标准信号校验各通道精度，检查A/D转换线性度，核实信号隔离完好 | 采样精度超差无法校准、通道损坏或隔离击穿时更换模块 |
| 通信模块 | 可编程逻辑控制器 | 实现与上位机、保护装置、调速器等智能设备的通信接口。 | 否 | 每季度检查通信端口数据收发状态，监测通信误码率和响应时间，核实协议配置 | 通信端口硬件损坏、协议无法适配或通信频繁超时中断时更换模块 |
| 电源模块 | 可编程逻辑控制器 | 为PLC各模块提供稳定工作电源，将直流220V/110V转换为内部所需电压。 | 是 | 每季度检查各路输出电压精度和纹波，测试冗余切换功能，清洁散热风道 | 输出电压持续超差、纹波过大或模块过热频繁保护时更换电源模块 |
| 人机界面 | 机组LCU屏 | 提供本地操作与监视的触摸屏或文本显示器，显示机组状态与报警信息。 | 否 | 每季度检查显示清晰度和触控响应灵敏度，核实画面数据刷新正常 | 人机界面硬件老化严重、显示大面积失灵或触控完全失效时更换HMI |
| 触摸屏 | 人机界面 | 显示面板，支持触控操作，长期运行后可能出现触控漂移或背光老化。 | 是 | 每季度校准触控精度，检查背光亮度均匀性，清洁屏幕表面 | 背光严重老化影响读数、触控大面积失灵或显示花屏时更换触摸屏 |
| 通信线缆 | 人机界面 | 连接HMI与PLC的专用电缆，常因频繁移动或老化导致接触不良。 | 是 | 每季度检查线缆接头紧固性和屏蔽层完整性，核实通信稳定性 | 线缆断芯、接头严重氧化或通信频繁中断时更换通信线缆 |
| 中间继电器 | 机组LCU屏 | 信号隔离与功率放大元件，将PLC输出的小信号转换为控制断路器等设备的大电流信号。 | 是 | 每季度测试各继电器线圈电阻和触点接触电阻，核实动作电压和释放电压 | 线圈烧断、触点严重烧蚀粘连或动作不可靠导致控制拒动或误动时更换继电器 |
| 继电器底座 | 中间继电器 | 固定继电器并提供电气连接的插座，易因振动导致接触簧片疲劳。 | 是 | 每季度检查底座簧片弹性和接触状态，紧固底座安装螺栓 | 簧片疲劳变形导致接触不良、插孔扩大松动或底座破裂时更换底座 |
| 开关电源 | 机组LCU屏 | 将交流或直流输入转换为稳定的直流24V，为HMI、传感器、继电器等供电。 | 是 | 每季度检查输出电压和纹波，测试过流保护和短路保护功能，清洁散热风道 | 输出电压持续超差、保护功能失效或内部电容鼓包漏液时更换开关电源 |
| 直流开关 | 开关电源 | 内置或外置的直流输出部分，长时满载运行易发热老化。 | 是 | 每季度检查触头烧蚀情况和操作机构灵活性，核实过载保护整定值 | 触头严重烧蚀、操作卡涩或保护特性偏移导致无法可靠分断时更换 |
| 接线端子 | 机组LCU屏 | 用于外部电缆的汇聚与分配，实现电气连接。 | 否 | 每年检查端子接线紧固性，核实端子排无过热变色痕迹，检查绝缘隔板完好性 | 端子排严重烧蚀碳化、绝缘隔板破损或大面积接触不良时更换端子排 |
| 标记条 | 接线端子 | 标识端子用途的塑料标签，易脱落褪色。 | 是 | 每年核对标记条内容与图纸一致性，发现褪色模糊或脱落及时重新标注 | 标记条大面积褪色脱落无法辨认或信息与实际不符时全面更换标记条 |
| 柜体及附件 | 机组LCU屏 | 提供物理防护、电磁屏蔽及散热环境的封闭机柜。 | 否 | 每季度检查柜门密封条和电磁屏蔽接地，核实柜体接地良好，检查防腐涂层 | 柜体严重锈蚀变形影响防护等级、门锁损坏无法关闭或接地断裂时维修或更换柜体 |
| 冷却风扇 | 柜体及附件 | 强制排风散热的风扇单元，轴承润滑油干涸后产生噪音并失效。 | 是 | 每季度清洁扇叶和防护网灰尘，检查轴承运转有无异响，测试转速是否正常 | 风扇转速显著下降、轴承严重磨损异响或完全停转时更换风扇 |
| 过滤网 | 柜体及附件 | 阻止灰尘进入柜内的无纺布或金属网，需定期清洗或更换。 | 是 | 每月检查过滤网积尘情况，清洗或更换滤网，保持进风畅通 | 过滤网严重堵塞无法清洗恢复、框架变形损坏或多次清洗后过滤效率下降时更换 |
| 柜门行程开关 | 柜体及附件 | 控制柜内照明，并检测柜门开闭状态，机械动作频繁。 | 是 | 每季度测试行程开关动作可靠性和接点通断，检查安装位置和触发机构 | 开关触点烧蚀、动作卡涩或触发机构变形导致信号丢失时更换行程开关 |
| 加热器 | 柜体及附件 | 用于高湿度环境下的除湿防凝露，通常配合温湿度控制器自动投切。 | 是 | 每季度检查加热器工作状态和温湿度控制器投切逻辑，核实表面无过热变色 | 加热管断路不发热、温湿度控制器失灵导致加热器持续投切或柜内结露严重时更换 |
| 防雷器 | 机组LCU屏 | 浪涌保护装置，吸收电源或信号线路上的瞬态过电压，保护后端设备。 | 是 | 每季度检查防雷器状态指示窗口，核实接地连接可靠，测试泄漏电流 | 防雷器窗口变红指示失效、泄漏电流超标或遭受强雷击后动作时立即更换 |
| 同期装置 | 机组LCU屏 | 检测机组与电网的电压、频率、相位差，在条件满足时发出合闸指令，实现自动准同期并网。 | 否 | 每季度检查同期装置参数设置，测试同期捕捉功能，核实导前时间设置合理 | 同期装置频繁误并网或拒并网、核心芯片损坏或技术落后无法满足并网要求时更换装置 |
| 同期控制器 | 同期装置 | 核心控制模块，计算导前时间并预测过零点，触点因频繁动作易产生电弧烧蚀。 | 是 | 每季度检查出口继电器触点状态，校验同期条件判断精度，测试合闸脉冲宽度 | 触点严重烧蚀粘连导致非同期合闸、计算精度超差或合闸脉冲异常时更换控制器 |
| 转速信号装置 | 机组LCU屏 | 接收齿盘或残压测速信号，实时监测机组转速，用于判断机组状态及过速保护。 | 否 | 每季度校验转速显示精度，检查各转速接点信号正确性，核实过速保护定值 | 装置精度严重超差、测速功能异常或过速保护拒动时更换装置 |
| 测速探头 | 转速信号装置 | 安装于机端的一次传感元件，通过电磁感应或霍尔效应产生转速脉冲信号。 | 是 | 每季度检查探头安装间隙和紧固情况，清洁探头端面，测试输出信号波形 | 探头损坏无信号输出、安装支架断裂或信号幅值过低无法可靠检测时更换探头 |
| 自动准同期装置 | 机组LCU屏 | 自动调节调速器和励磁装置，以满足同期条件，其内部出口继电器为易损件。 | 是 | 每季度检查出口继电器触点状态，校验同期条件（电压差、频率差、相位差）定值 | 继电器触点烧蚀粘连、同期精度超差或调节功能异常时更换装置 |
| 交采表 | 机组LCU屏 | 高精度交流采样装置，直接采集CT/PT二次侧电流电压，计算功率、频率等电气量。 | 否 | 每季度校验交流采样精度，检查PT/CT二次回路接线可靠性，核实通信数据 | 精度超差无法校准、采样通道损坏或通信功能异常时更换交采表 |
| 温度巡检仪 | 机组LCU屏 | 轮询检测机组轴瓦、定子、油槽等多路热电阻温度信号，超限时报警或跳闸。 | 否 | 每季度校验各通道温度采样精度，检查多路切换继电器动作可靠性，核实报警定值 | 采样精度严重超差、通道批量损坏或多路切换功能异常时更换巡检仪 |
| 按钮及指示灯 | 机组LCU屏 | 提供手动分合闸、紧急停机等硬接线操作，以及电源、故障状态指示。 | 是 | 每季度检查按钮动作手感和自复位功能，测试指示灯亮灭状态，核实紧急停机回路 | 按钮卡涩无法操作、触点接触不良或指示灯批量烧毁不亮时更换相应部件 |
| 小型断路器 | 机组LCU屏 | 用于柜内控制回路、照明、加热器等支路的短路与过载保护。 | 是 | 每季度操作一次分合闸检查机构灵活性，核实保护整定值与设计一致 | 操作机构卡涩、触点严重烧蚀或保护特性偏移导致误动拒动时更换断路器 |
