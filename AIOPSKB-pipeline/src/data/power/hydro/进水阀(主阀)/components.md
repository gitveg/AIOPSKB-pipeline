| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 进水阀(主阀) | — | 水电站进水口主截止阀，用于切断或接通机组进水流道，在事故和检修时截断水流。 | 否 | 定期检查阀体外观有无锈蚀、渗漏和异常振动；每年进行阀门全行程动作试验，验证开关灵活性；大修时检查阀体内部冲蚀和腐蚀状况；检查操作机构和密封组件；监测运行中阀前阀后压差变化。 | 阀体严重锈蚀减薄或出现裂纹；多次大修后密封性能仍无法满足要求；操作机构严重损坏导致阀门无法可靠动作；技术鉴定确认无法安全使用时，应报废更换整台进水阀。 |
| 阀体 | 进水阀(主阀) | 承受水压的承压壳体，通常为铸钢或钢板焊接结构，内部设有阀芯运动导向和密封面。 | 否 | 定期检查阀体外表面有无锈蚀、裂纹和渗漏痕迹；大修时进行壁厚测量，检查内壁冲蚀和腐蚀程度；检查阀体法兰密封面平整度；对重点部位进行无损探伤检查；进行水压试验验证承压能力。 | 阀体壁厚因腐蚀减薄至设计壁厚的80%以下；阀体出现裂纹且补焊修复后仍反复开裂；法兰密封面严重损伤无法修复；水压试验不合格时，应报废更换阀体。 |
| 阀芯(阀瓣) | 进水阀(主阀) | 直接截断或开启水流通道的活动部件，与阀座配合形成密封副。 | 否 | 定期检查阀芯运动是否灵活无卡涩；大修时检查阀芯密封面有无冲蚀沟痕、压痕和磨损；测量阀芯导向面与阀体导向槽的配合间隙；检查阀芯有无变形和裂纹；研磨密封面恢复密封性能。 | 阀芯密封面冲蚀深度过大研磨后仍无法保证密封；阀芯严重变形或出现裂纹；导向面磨损严重导致运动晃动和卡涩；多次研磨后密封面剩余厚度不足时，应更换阀芯。 |
| 阀座 | 进水阀(主阀) | 与阀芯配合的固定密封部件，嵌入阀体内壁，承受水流冲刷和密封压力。 | 是 | 大修时检查阀座密封面有无冲蚀、压痕和腐蚀；研磨密封面恢复光洁度和密封线宽度；检查阀座镶嵌是否牢固有无松动；测量密封面内径尺寸变化评估冲蚀程度。 | 阀座密封面冲蚀深度过大无法通过研磨修复；阀座出现裂纹或与阀体镶嵌松动；内径因冲蚀严重扩大超出公差范围；经多次研磨后剩余有效厚度不足时，应更换阀座。 |
| 密封环 | 阀芯(阀瓣) | 安装在阀芯或阀座上的弹性或塑性密封元件，确保阀门在全关位置零泄漏。 | 是 | 定期检查阀门关闭后的泄漏量是否在允许范围内；大修时检查密封环有无磨损、老化和变形；发现密封不良时优先更换密封环；确保密封环材料与水质和工作温度匹配。 | 密封环老化硬化失去弹性；表面严重磨损导致阀门关闭后泄漏超标；材料被腐蚀或冲蚀导致缺损；已达到规定的更换周期时，应更换密封环。 |
| 阀轴(阀杆) | 进水阀(主阀) | 连接阀芯与操作机构，传递操作力矩使阀芯旋转或升降运动的传动轴。 | 否 | 定期检查阀轴有无弯曲和异常振动；大修时测量阀轴直线度和表面粗糙度；检查轴颈磨损情况和与轴承的配合间隙；检查阀轴与阀芯连接键或销钉有无松动；检查轴表面防腐涂层完好性。 | 阀轴严重弯曲无法校直；轴颈磨损严重导致配合间隙超标；轴表面出现裂纹（不允许补焊继续使用）；键槽或销孔严重变形无法可靠传递力矩时，应更换阀轴。 |
| 轴承 | 阀轴(阀杆) | 支撑阀轴旋转运动的滑动或滚动轴承，承受径向和轴向载荷。 | 是 | 定期检查轴承运转是否灵活，有无异响和发热；大修时拆卸检查轴承滚道和滚动体表面有无磨损、剥落和锈蚀；测量轴承游隙；检查润滑状况并补充或更换润滑脂；检查轴承密封件状态。 | 轴承滚道或滚动体表面出现严重剥落、磨损或裂纹；轴承游隙严重超标导致阀轴晃动和运动精度下降；运转中持续高温或异响；保持架断裂时，应更换轴承。 |
| 填料密封组件 | 阀轴(阀杆) | 安装在填料函中，防止高压水沿阀轴泄漏的多层密封填料及压盖组件。 | 是 | 定期检查填料函处有无滴漏，发现泄漏时适当拧紧压盖螺母；大修时全部更换密封填料；检查阀轴表面与填料接触区域的磨损情况；选择耐磨损、耐腐蚀的合适填料材料；压紧填料时对称均匀施力避免偏斜。 | 填料老化硬化失去密封弹性；多次压紧后仍无法阻止泄漏；填料函内壁严重冲蚀导致填料无法有效密封；阀轴表面磨损严重导致填料无法贴合密封时，应更换填料密封组件。 |
| 操作机构 | 进水阀(主阀) | 驱动阀轴旋转或阀芯升降的整套机构，包括液压缸、接力器或电动执行器。 | 否 | 定期检查操作机构动作是否灵活可靠；每月检查液压管路或电气连接有无异常；大修时全面检查操作机构各运动部件磨损状况；进行全行程动作试验验证开关时间；检查行程开关和限位装置是否准确。 | 操作机构严重损坏导致无法正常驱动阀门；多次大修后仍频繁出现拒动或卡涩；关键部件损坏且无备件可更换；技术更新改造更为经济合理时，应报废更换操作机构。 |
| 液压接力器 | 操作机构 | 利用高压液压油驱动活塞产生直线运动，通过连杆机构带动阀轴旋转的执行元件。 | 否 | 定期检查接力器动作是否平稳无爬行；每月检查液压管路接头有无渗漏；大修时检查缸体内壁和活塞杆表面磨损状况；测量活塞密封间隙；检查行程限位和缓冲机构功能。 | 缸体内壁严重拉伤或锈蚀；活塞杆弯曲或表面镀铬层大面积剥落；多次更换密封件后仍持续内泄外漏；动作特性经调试仍不满足要求时，应报废更换接力器。 |
| 接力器密封件 | 液压接力器 | 防止接力器高低压腔之间和外部泄漏的活塞密封和杆密封组件。 | 是 | 定期监测接力器在保压状态下活塞有无缓慢漂移，判断密封件磨损程度；大修时全部更换活塞密封和杆密封；检查密封件材料是否与液压油兼容；安装时注意密封件方向正确和润滑。 | 密封件老化硬化失去弹性；严重磨损导致接力器内泄增大活塞漂移超标；密封表面出现深划痕或局部缺损；已达到规定的更换周期时，应更换接力器密封件。 |
| 电动执行器 | 操作机构 | 以电动机为动力，通过减速机构驱动阀轴旋转的电动操作装置。 | 否 | 定期检查电动执行器动作是否灵活，手动/电动切换是否可靠；每月检查电机运行电流和温升；大修时检查减速箱齿轮磨损和润滑状况；校验行程限位和力矩开关设定值；检查手轮操作机构。 | 电机烧毁且无法修复；减速箱齿轮严重损坏无法传递力矩；行程限位和力矩开关频繁失灵；经大修后仍无法可靠驱动阀门时，应更换电动执行器。 |
| 旁通阀 | 进水阀(主阀) | 安装在主阀进水侧与出水侧之间的旁通管路上，在主阀开启前平衡前后压差以减少开启力矩。 | 否 | 定期检查旁通阀动作是否灵活密封是否可靠；大修时检查旁通阀内部密封面和阀杆状况；验证旁通阀与主阀的联锁逻辑是否正确；检查旁通管路有无渗漏和堵塞。 | 旁通阀体严重锈蚀或出现裂纹；密封面严重损坏导致关不严；阀杆弯曲或操作机构损坏无法动作；经检修后仍无法可靠密封和操作时，应更换旁通阀。 |
| 空气阀(补气阀) | 进水阀(主阀) | 安装在阀后管路最高点，在阀门关闭排水时补入空气防止管内负压，充水时排出空气。 | 是 | 定期检查空气阀动作是否灵活，补气和排气功能是否正常；大修时检查阀内浮球或阀芯密封面磨损状况；检查阀体内部有无锈蚀和异物；检查防虫网罩是否完好。 | 阀内浮球或阀芯损坏导致无法正常补气或排气；密封面严重损坏导致漏水；阀体锈蚀穿孔；经检修后仍无法可靠工作时，应更换空气阀。 |
| 伸缩节 | 进水阀(主阀) | 安装在阀门与管道连接处，补偿管道热膨胀和安装误差，降低法兰接口应力。 | 否 | 定期检查伸缩节有无变形、渗漏和异常位移；大修时检查密封圈状况和压紧力；测量伸缩节补偿量是否在设计允许范围内；检查限位螺栓和导向结构是否可靠。 | 伸缩节本体严重变形或锈蚀穿孔；密封结构损坏导致反复泄漏；波纹管或伸缩元件疲劳开裂；补偿能力丧失无法有效吸收管道位移时，应更换伸缩节。 |
| 连接法兰及紧固件 | 进水阀(主阀) | 进水阀与上下游管道连接的法兰盘、螺栓螺母及密封垫片。 | 否 | 定期检查法兰结合面有无渗漏痕迹；大修时检查法兰密封面平整度和有无损伤；按规定力矩检查紧固螺栓状态；检查螺栓螺母有无锈蚀和变形；检查密封垫片老化状况。 | 法兰密封面严重损伤无法通过研磨修复；螺栓出现裂纹或严重锈蚀（螺纹损坏）；多次紧固后法兰仍持续泄漏；法兰本体变形导致密封面无法贴合时，应更换法兰或紧固件。 |
