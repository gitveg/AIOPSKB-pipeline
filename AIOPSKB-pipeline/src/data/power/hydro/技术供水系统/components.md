| 循环水泵组 | — | 输送冷却介质，维持系统压力和流量，通常包含主泵和备泵。 | 否 | 每月检查泵组运行振动和噪声，监测进出口压力和流量是否正常，定期切换主备泵运行 | 泵组壳体开裂、叶轮严重损坏或效率降至额定值60%以下且维修成本过高时报废 |
| 水泵电机 | 循环水泵组 | 驱动水泵叶轮旋转，将电能转化为机械能。 | 否 | 每季度测量电机三相电流平衡度，检查绝缘电阻，清洁散热风道，监测轴承温度 | 电机绕组烧毁、铁心严重损坏或效率严重下降且重绕成本超过新机60%时报废 |
| 水泵轴承 | 水泵电机 | 支撑转子并保证其平稳旋转，承受径向与轴向载荷。 | 是 | 每月监测轴承温度和振动值，定期加注或更换润滑脂，检查油封完好性 | 轴承游隙超差、滚道剥落、保持架断裂或温升持续超标时更换轴承 |

| 联轴器 | 循环水泵组 | 连接电机轴与泵轴，传递动力并补偿安装偏差，含弹性元件。 | 是 | 每季度检查弹性元件磨损和老化情况，校正对中度，紧固连接螺栓 | 弹性元件严重磨损碎裂、对中偏差无法调整或柱销断裂时更换联轴器 |
| 泵底座 | 循环水泵组 | 固定和支撑泵组，承受重力与运行振动，确保对中稳定。 | 否 | 每年检查地脚螺栓紧固情况，核实基础有无沉降或裂纹，检查减振垫完好性 | 底座严重锈蚀变形影响安装精度或基础无法修复时报废并重建基础 |
| 机械密封 | 循环水泵组 | 依靠弹性元件和介质压力在动环与静环端面间形成液膜，防止泵轴处泄漏。 | 是 | 每月检查泄漏量，发现滴漏增大时及时检查密封面磨损情况，保持冷却冲洗水畅通 | 密封端面严重磨损、弹簧失效或泄漏量超过允许标准时更换机械密封 |
| 泵体叶轮 | 循环水泵组 | 高速旋转产生离心力，将吸入的液体甩出，实现动能到压能的转换。 | 否 | 每年大修时检查叶轮流道磨损和汽蚀情况，测量叶轮口环间隙 | 叶轮严重汽蚀穿孔、流道堵塞无法清理或口环间隙超过允许值时更换叶轮 |
| 进水滤网 | — | 安装在系统入口，拦截固体杂质，防止管路和换热器堵塞或磨损。 | 是 | 每周检查滤网前后压差，压差增大时及时清洗或反冲洗，检查网面有无破损 | 滤网大面积破损、框架严重腐蚀变形或多次清洗后过滤效率仍不达标时更换 |
| 止回阀 | — | 阻止介质倒流，防止水泵反转或高位水回流冲击叶轮。 | 否 | 每季度检查阀瓣动作灵活性，测试关闭密封性，检查阀座有无冲蚀 | 阀瓣变形卡涩无法正常关闭、阀座严重冲蚀导致关不严时更换止回阀 |
| 电动调节阀 | — | 根据控制信号调节系统流量或压力，实现变工况匹配。 | 否 | 每季度检查阀位反馈与实际开度一致性，测试全行程动作时间，润滑阀杆 | 阀体严重内漏、电动执行器损坏无法修复或调节特性恶化时更换整阀 |
| 热交换单元 | — | 将被冷却设备的热量传递给冷却水，实现热量交换。 | 否 | 每年检查换热效率和端差，清洗换热表面，检查壳体及连接件有无泄漏 | 换热效率严重下降、壳体开裂或多根换热管泄漏且堵管率超过10%时报废 |
| 换热管束 | 热交换单元 | 冷热介质分隔与热量传递的通道，受水流冲刷和腐蚀。 | 是 | 每年进行管束涡流探伤检查，清洗管内水垢和生物粘泥，检查管板胀接处有无泄漏 | 管束泄漏管数超过总管数10%、管壁减薄超过原壁厚40%或堵塞严重时更换管束 |
| 管板与密封垫 | 热交换单元 | 固定管束并分隔两侧介质，密封垫防止不同介质相互渗透。 | 是 | 每次拆卸检修时更换密封垫，检查管板腐蚀和变形情况，清理密封面 | 管板严重腐蚀减薄、密封面损伤无法修复或密封垫反复泄漏时更换 |
| 壳体 | 热交换单元 | 容纳换热管束并构成壳程流道，承受介质压力。 | 否 | 每年检查壳体外壁防腐涂层，测厚检查壳体壁厚减薄情况 | 壳体壁厚减薄超过允许值、出现裂纹或承压能力不满足设计要求时报废 |
| 封头/水室 | 热交换单元 | 导流管程介质，分配流体进出管束，便于检修清洗。 | 否 | 每年检查封头内壁防腐层，清理积存的泥沙和杂物，检查法兰密封面 | 封头严重腐蚀穿孔、法兰密封面损伤无法修复时更换封头 |
