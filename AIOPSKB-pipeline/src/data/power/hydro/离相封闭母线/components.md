| 导体连接件 | 导体系统 | 软连接、焊接或螺栓连接的过渡件，用于补偿热膨胀或连接不同段导体 | 否 | 大修期间重点检查螺栓连接部位的紧固力矩是否满足设计要求；检查软连接片有无断裂、氧化或变色过热；测量连接部位接触电阻，与历史数据比对；检查焊接接头有无裂纹或虚焊；对过热痕迹部位进行处理。 | 软连接片多片断裂导致有效截面减小，螺栓连接面严重烧蚀无法修复，焊接接头开裂，或接触电阻持续增大且多次紧固处理后仍不合格时报废更换。 |
| 外壳系统 | 离相封闭母线 | 为导体提供电磁屏蔽和防护的金属封闭外壳，通常采用铝合金 | 否 | 定期检查外壳表面有无锈蚀、变形、裂纹或漆面脱落，及时除锈补漆；检查外壳接地连接是否可靠；大修期间检查外壳气密性，验证微正压保持能力；检查外壳法兰连接是否紧固，有无变形或渗漏；检查外壳防腐涂层是否完好。 | 外壳大面积锈蚀穿孔无法保证气密性和防护等级，结构严重变形影响导体安装和对中，或经评估修复成本超过更换新母线造价时报废更换。 |
| 外壳筒体 | 外壳系统 | 圆筒形铝制壳体，分段焊接或法兰连接，实现相间隔离和防护 | 否 | 定期检查筒体表面有无凹陷、变形或裂纹；检查焊缝有无开裂或渗漏；检查法兰接合面是否平整，密封是否良好；大修期间进行气密性试验，验证筒体密封性能；检查筒体支撑和固定是否牢靠。 | 筒体出现裂纹或严重变形无法修复，大面积腐蚀减薄影响结构强度，焊缝反复开裂经多次补焊仍不满足密封要求，或筒体截面变形导致导体对中超差时报废更换。 |
| 外壳波纹管 | 外壳系统 | 补偿外壳因温度变化产生变形的弹性元件 | 是 | 大修期间检查波纹管有无裂纹、腐蚀或变形；测量波纹管自由长度和压缩量是否在设计范围内；检查波纹管与筒体焊接接头是否完好；运行中监测波纹管附近有无异常振动或泄漏；注意安装方向与补偿方向一致。 | 波纹管出现裂纹导致泄漏无法维持气密性，波纹严重变形或疲劳断裂失去补偿能力，腐蚀减薄影响承压能力，或补偿量超出设计极限导致永久变形时报废更换。 |
| 外壳法兰连接件 | 外壳系统 | 用于分段外壳之间的对夹连接，含螺栓、螺母及跨接导电排 | 否 | 大修期间逐一检查法兰螺栓紧固力矩是否满足设计要求；检查法兰面密封状态有无泄漏痕迹；检查跨接导电排连接是否可靠，接触面有无氧化；检查法兰面有无变形影响密封；更换老化密封垫圈。 | 法兰严重变形导致无法保证密封，螺栓孔损坏无法修复，跨接导电排烧损断裂影响外壳电气连续性，或法兰连接失效经多次处理仍泄漏时报废更换。 |
| 绝缘与支撑系统 | 离相封闭母线 | 保证导体对外壳及相间的电气绝缘，并固定导体位置 | 否 | 大修期间测量绝缘电阻和进行交流耐压试验，验证绝缘水平是否满足要求；检查绝缘件有无裂纹、放电痕迹或受潮现象；检查导体支撑位置是否正确，有无位移；清洁绝缘件表面灰尘和污秽；检查微正压系统防止潮气侵入。 | 绝缘与支撑系统整体老化，绝缘电阻持续下降且无法通过干燥或更换个别绝缘件恢复，多处绝缘件存在裂纹或放电痕迹，或经耐压试验不合格时评估整体更换。 |
| 支柱绝缘子 | 绝缘与支撑系统 | 安装在导体与外壳之间，承受导体重力及短路电动力的瓷或环氧树脂绝缘件 | 是 | 大修期间逐个检查绝缘子有无裂纹、破损或放电痕迹；测量绝缘电阻是否满足标准要求；检查绝缘子与导体和外壳的配合面有无磨损或位移；清洁绝缘子表面污秽；检查绝缘子固定螺栓紧固是否可靠。 | 绝缘子出现裂纹或破损影响绝缘和机械支撑性能，绝缘电阻低于标准要求且烘干处理无效，表面严重放电碳化，或机械强度下降无法承受短路电动力时报废更换。 |
| 密封圈/密封垫 | 绝缘与支撑系统 | 位于法兰、外壳开孔、绝缘子安装处的橡胶或氟硅材料，防止湿气灰尘进入 | 是 | 大修期间检查所有密封圈和密封垫有无老化、硬化、开裂或永久变形；检查密封面是否清洁平整；按维护周期（通常3-5年）预防性更换所有密封件；安装时确保密封圈位置正确，压缩量均匀；使用规定材质的密封件，不可随意替换。 | 密封圈老化硬化失去弹性无法保证密封，出现裂纹或断裂导致泄漏，密封面严重损伤无法配合密封圈，或压缩永久变形率超过设计允许值时更换新品，旧件报废。 |
| 微正压装置接口 | 绝缘与支撑系统 | 为充气或干燥空气正压系统提供的管路及阀门接口，保证内部气压 | 否 | 定期检查微正压装置接口管路有无泄漏或堵塞；检查接口阀门开关是否灵活，有无锈蚀或卡涩；检查接口与母线外壳连接处密封是否良好；监测微正压系统运行参数（压力、流量）是否正常；大修期间进行管路通畅性检查。 | 接口管路严重锈蚀或变形导致无法保证气密性，阀门损坏无法正常开关，接口螺纹损坏无法可靠连接，或多次维修后仍存在泄漏隐患时报废更换。 |
| 母线伸缩节 | 离相封闭母线 | 安装在长距离母线的分段处，吸收导体和外壳的热胀冷缩 | 否 | 大修期间检查伸缩节整体状态，有无变形、裂纹或异常位移；检查导体伸缩节和外壳伸缩节的补偿量是否在设计范围内；检查伸缩节与母线的连接是否可靠；运行中监测伸缩节附近有无异常振动或温升。 | 伸缩节严重变形或疲劳断裂失去补偿能力，导体伸缩节过热变色或软连接片断裂，外壳伸缩节泄漏无法维持气密性，或补偿量超出设计极限时报废更换。 |
| 导体伸缩节 | 母线伸缩节 | 多层薄铜片叠制而成的软连接，柔性补偿导体热位移 | 是 | 大修期间检查铜片有无断裂、氧化或过热变色；测量伸缩节接触电阻，与历史数据比对分析劣化趋势；检查铜片层间有无异物或腐蚀；检查伸缩节两端连接螺栓紧固力矩是否满足要求。 | 铜片多片断裂导致有效截面减小和载流能力下降，接触电阻持续增大超过允许值，过热烧损导致材质劣化，或经多次处理仍反复过热时报废更换。 |
| 外壳伸缩节 | 母线伸缩节 | 外壳部分的波纹管或滑动套筒结构，补偿外壳热位移 | 否 | 大修期间检查波纹管或滑动套筒有无裂纹、变形或磨损；检查滑动面润滑是否良好（滑动套筒型）；检查密封结构是否完好，有无泄漏；测量伸缩节自由长度是否在设计范围内；运行中监测伸缩节工作状态。 | 波纹管裂纹导致泄漏，滑动套筒严重磨损或卡死失去补偿功能，结构变形影响正常伸缩，或多次维修后仍无法保证密封和补偿功能时报废更换。 |
| 接地系统 | 离相封闭母线 | 保证外壳可靠接地，防止悬浮电位，提供短路电流回流路径 | 否 | 大修期间检查接地铜排和接地引线的连接是否可靠，紧固螺栓力矩是否满足要求；测量接地电阻是否在设计值范围内；检查接地铜排有无腐蚀、断裂或变色过热；检查短路板连接是否良好；每年进行一次接地系统巡检。 | 接地铜排严重腐蚀或断裂影响接地可靠性，接地电阻持续超标且无法通过改善接地连接恢复，或接地系统多处损坏经评估修复不经济时报废更换。 |
| 外壳接地铜排 | 接地系统 | 沿外壳敷设的铜排，将各段外壳连接并与地网可靠连接 | 否 | 定期检查铜排有无腐蚀、氧化或机械损伤；检查铜排与外壳和接地网的连接螺栓紧固是否可靠；测量铜排导通电阻，与历史数据比对；检查铜排表面有无过热变色痕迹；大修期间进行连接面清理和防氧化处理。 | 铜排严重腐蚀减薄影响载流能力，多处断裂无法可靠接地，连接面严重烧蚀无法修复，或经测量导通电阻严重超标时更换铜排，旧件报废。 |
| 短路板 | 接地系统 | 在发电机端或变压器端将三相外壳短路接地的铜板，防止轴电流 | 否 | 大修期间检查短路板与三相外壳的连接是否可靠，紧固螺栓力矩是否满足要求；检查短路板有无过热、烧蚀或裂纹；测量短路板导通电阻；检查短路板接地连接是否良好；运行中监测短路板温升是否正常。 | 短路板严重过热烧蚀影响导通性能，出现裂纹或变形导致连接不可靠，连接面多次烧蚀经处理仍反复过热，或材质劣化导致电阻明显增大时报废更换。 |
| 辅助监测装置 | 离相封闭母线 | 在线监测封闭母线运行状态的各种传感器及显示装置 | 否 | 定期检查各监测装置运行状态是否正常，数据是否准确；校验传感器测量精度；检查监测装置供电和通讯是否正常；大修期间对传感器进行校准或比对测试；检查监测装置防护外壳是否完好。 | 监测装置整体老化，传感器精度严重下降且无法校准，显示和通讯功能失效，或经评估修复成本超过更换新装置造价时报废更换。 |

| 温度测量元件 | 辅助监测装置 | 测量导体或外壳连接点温度的热电阻或热电偶，预防过热 | 是 | 定期检查温度测量值是否合理，与红外测温数据比对验证精度；检查测量元件安装位置是否正确，与被测部位接触是否良好；检查引线和接线端子是否可靠；每年进行一次校准，超差时更换。 | 测量元件断路或短路导致温度数据异常，校验精度超出允许范围且无法修正，引线老化断裂无法修复，或感温元件响应特性严重退化时报废更换。 |
| 窥视孔/检修人孔 | 辅助监测装置 | 设置在外壳上的观察窗或检修入口，便于检查绝缘子及导体状态 | 否 | 定期检查窥视孔玻璃是否清洁透明，有无裂纹或密封不良；检查检修人孔盖板密封是否良好，螺栓是否紧固；检查人孔门铰链和锁扣是否灵活可靠；大修期间通过窥视孔检查内部状态并记录。 | 窥视孔玻璃严重老化或破裂影响观察，密封结构损坏无法保证气密性，人孔盖板变形无法正常开合或密封，或结构损坏无法修复时报废更换。 |
| 干燥呼吸器 | 辅助监测装置 | 安装在充气系统或换气口，内置硅胶等吸湿剂，防止外部湿气进入 | 是 | 定期检查硅胶变色程度，变色超过2/3时应更换硅胶（蓝色变粉红色或橙色变墨绿色）；检查呼吸器外壳有无裂纹或破损；检查呼吸器与管路的连接密封是否良好；大修期间更换全部硅胶并清洁内部；确保排气通畅无堵塞。 | 呼吸器外壳破裂无法保证密封，接口损坏导致漏气，或内部结构堵塞无法正常呼吸排气时更换新品，旧件报废。 |
