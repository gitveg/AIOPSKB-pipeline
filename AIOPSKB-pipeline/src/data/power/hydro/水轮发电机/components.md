| 绝缘垫片 | 定子铁心 | 置于定子铁心叠片段间，防止铁心内部产生涡流过热，由环氧玻璃布板等构成 | 是 | 每年大修时检查绝缘垫片有无位移、变形和老化开裂，测量段间绝缘电阻 | 绝缘垫片严重老化开裂、碳化或绝缘电阻显著下降导致铁心局部过热时更换绝缘垫片 |
| 定子绕组 | 定子 | 切割转子磁场感生交流电动势并输出电功率，由外包绝缘的铜股线构成 | 是 | 每年测量绕组绝缘电阻、吸收比和直流泄漏电流，大修时检查线棒端部和槽部有无电晕放电痕迹 | 绕组绝缘严重老化（泄漏电流持续增大）、线棒击穿或股线断股超过允许数量时评估重绕或更换线棒 |
| 引出线 | 定子绕组 | 将发电机内部电能通过绝缘套管引出至外部母线的连接导体，外部绝缘层易老化 | 是 | 每年检查引出线绝缘层有无老化和电晕痕迹，测量绝缘电阻，核实连接紧固 | 绝缘层严重老化开裂、电晕放电痕迹明显或引出线接头过热变色时更换引出线 |
| 挡风板 | 定子 | 构成发电机内部密闭循环通风路径，引导冷却气流按设计通道流动 | 否 | 每年大修时检查挡风板固定和密封状态，核实无裂纹变形和松动 | 挡风板严重变形破裂影响通风路径、固定螺栓断裂或密封不良导致冷热风混合时更换 |
| 密封压板 | 定子 | 固定定子绕组端部并防止端部漏磁通在铁心齿部边缘产生过热松动 | 否 | 每年大修时检查密封压板紧固状态和绕组端部固定可靠性 | 密封压板严重变形、紧固螺栓松动脱落或端部固定失效导致绕组振动增大时更换或加固 |
| 弹性支撑件 | 定子 | 金属橡胶复合构件，用于浮动连接定子铁心与机座，吸收铁心热膨胀并降低磁噪声 | 否 | 每年大修时检查弹性支撑件有无老化开裂和变形，核实隔振效果 | 弹性元件严重老化失去弹性、橡胶开裂脱落或隔振效果显著下降时更换弹性支撑件 |
| 线棒槽楔 | 定子 | 打入定子槽口以径向固定线圈，防止电磁振动与电动力引起的线圈松动和磨损 | 是 | 每年大修时检查槽楔紧固状态，敲击检查有无松动脱出，核实槽楔与线圈间无间隙 | 槽楔松动脱出数量超过总槽数5%、大面积磨损断裂或线圈在槽内松动时更换槽楔 |
| 转子 | 水轮发电机 | 产生励磁磁场，由磁极、磁轭、转轴、转子支架及励磁绕组构成 | 否 | 每年大修时检查转子各部件紧固状态和磁极连接，测量励磁绕组绝缘电阻 | 转子支架出现裂纹、磁轭严重松动或多个磁极损坏无法修复时评估大修或更换 |
| 磁极铁心 | 转子 | 构成转子磁路主体并集中安装励磁绕组，承受高速旋转离心力 | 否 | 每年大修时检查磁极铁心紧固和表面状态，核实与励磁绕组的绝缘 | 铁心严重变形、叠片段松动或与绕组绝缘击穿时更换磁极铁心 |
| 磁极线圈 | 转子 | 通入直流励磁电流以建立主磁场，由绝缘铜排绕制而成，承受离心力和热应力 | 是 | 每年测量线圈绝缘电阻和直流电阻，检查匝间绝缘和表面有无过热变色痕迹 | 匝间绝缘击穿短路、直流电阻异常或铜排变形开裂时更换磁极线圈 |
| 集电环系统 | 转子 | 通过静止电刷与旋转滑环的滑动接触，将励磁电流导入高速旋转的磁极线圈 | 否 | 每月检查集电环表面光洁度和碳刷磨损情况，测量碳刷电流分配均匀性，清理碳粉 | 集电环表面严重磨损偏心、出现沟槽或温升超标无法车削修复时更换集电环 |
| 碳刷 | 集电环系统 | 作为传导励磁电流的滑动摩擦触点，石墨材质，属高频消耗件，需定期检查更换 | 是 | 每月检查碳刷长度和弹簧压力，测量各碳刷电流分配，及时更换磨损到限的碳刷 | 碳刷磨损至最小允许长度、弹簧压力不足或电刷碎裂时更换碳刷 |
| 制动环 | 转子 | 在磁轭下端形成平滑的环形摩擦面，接受制动块施加的制动力矩 | 否 | 每年大修时检查制动环摩擦面磨损和平整度，测量厚度减薄量 | 制动环厚度减薄超过允许值、摩擦面严重不平或出现裂纹时更换制动环 |
| 转子引线 | 转子 | 将励磁电流从滑环引入磁极线圈的导体，承受旋转离心力和振动，易发生绝缘开裂 | 是 | 每年大修时检查引线绝缘有无开裂和磨损，核实固定夹紧固可靠 | 引线绝缘严重开裂导致接地故障、导体断股或固定失效导致振动摩擦时更换转子引线 |
| 推力轴承 | 水轮发电机 | 承受立式机组转动部分全部重量及水推力，维持轴向定位，通常包含镜板、推力瓦、油槽及冷却器 | 否 | 每月监测瓦温和油温，检查油质和冷却水系统，大修时检查瓦面磨损和油膜厚度 | 推力瓦大面积烧损、镜板严重损伤或承载力不足导致温度持续超标时更换推力轴承部件 |
| 推力瓦 | 推力轴承 | 在镜板上形成承载油膜以承受巨大轴向载荷，通常为巴氏合金瓦面 | 是 | 每月监测瓦温和油槽油位，大修时检查瓦面合金有无脱胎、裂纹和磨损，测量瓦厚 | 巴氏合金大面积脱胎、瓦面烧损出现沟槽或磨损厚度超过允许值时更换推力瓦 |
| 镜板 | 推力轴承 | 随主轴旋转的高精度平面推力盘，与推力瓦构成承载油膜，表面光洁度要求极高 | 否 | 每年大修时检查镜板表面光洁度和平整度，测量表面粗糙度和偏摆值 | 表面出现深划痕或烧伤无法研磨修复、偏摆超标或出现裂纹时更换镜板 |
| 导轴承 | 水轮发电机 | 约束主轴径向摆动，保证转动中心稳定，常用分块瓦或筒式结构 | 否 | 每月监测导瓦温度和油位，大修时检查瓦面磨损和间隙，核实冷却水系统 | 导瓦大面积烧损、间隙严重超标或结构变形无法调整时更换导轴承 |
| 导轴瓦 | 导轴承 | 在轴颈或滑转子表面形成油膜以承受径向力，巴氏合金表面易磨损 | 是 | 每月监测瓦温和油温，大修时检查巴氏合金表面有无脱胎、烧损和拉伤，测量间隙 | 巴氏合金严重脱胎、烧损面积超过允许范围或间隙增大导致摆度超标时更换导轴瓦 |
| 滑转子 | 导轴承 | 热套于主轴轴颈上，为导轴瓦提供精密且耐磨的旋转接触表面 | 否 | 每年大修时检查滑转子表面光洁度和磨损情况，测量外径和圆度 | 表面严重磨损拉伤、外径减小导致间隙超标或出现裂纹时更换滑转子 |
| 制动装置 | 水轮发电机 | 机组停机时通过高压气体驱动制动块摩擦制动环，实现快速制动和顶起转子 | 否 | 每季度测试制动系统气压和制动块动作，核实制动时间和顶起转子功能 | 制动缸严重漏气漏油无法修复、管路系统严重损坏或制动功能异常时更换制动装置 |
| 制动块 | 制动装置 | 摩擦制动环以产生制动力矩的耐磨材料，长期使用后会磨损减薄 | 是 | 每年大修时测量制动块厚度，检查摩擦面有无碎裂和金属嵌入，核实退距 | 制动块磨损至最小允许厚度、摩擦面碎裂脱落或制动力矩不足导致制动时间延长时更换制动块 |
| 机架 | 水轮发电机 | 安装导轴承、推力轴承等部件并传递径向与轴向载荷至基础的承重构件 | 否 | 每年大修时检查机架焊缝有无裂纹，测量机架中心和水品，核实地脚螺栓紧固 | 机架焊缝出现裂纹、中心偏移超标或基础螺栓断裂时评估修复或更换 |

| 冷却水管 | 空气冷却器 | 通入循环冷却水以吸收空气中的热量，铜管或不锈钢管制成，长期运行易结垢或腐蚀泄漏 | 是 | 每季度检查水管连接密封性和水压，每年清洗管内水垢和生物粘泥 | 水管腐蚀穿孔泄漏、结垢严重堵塞或管壁减薄超过允许值时更换冷却水管 |
