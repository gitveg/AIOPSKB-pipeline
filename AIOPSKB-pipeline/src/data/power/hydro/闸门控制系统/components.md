| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 闸门控制系统 | — | 水电站闸门的成套控制设备，实现闸门启闭操作、开度调节、状态监测及保护联锁功能。 | 否 | 定期检查系统整体运行状态，验证各闸门启闭操作是否正常；每年进行全面功能试验，包括开度控制精度、保护联锁逻辑和紧急停机功能；大修时全面检查电气接线和液压管路；定期备份控制程序和定值数据。 | 系统主要功能部件大范围老化损坏；多次大修后控制精度和保护功能仍无法满足规程要求；技术升级改造方案经论证更为经济合理时，经技术鉴定委员会评估可整体报废更换。 |
| 控制柜 | 闸门控制系统 | 安装控制设备的标准机柜，提供防护、屏蔽及散热功能，内含控制器、继电器、接线端子等。 | 否 | 定期检查控制柜外观有无变形和锈蚀；每月检查柜内温度和湿度是否在允许范围内；每年清洁柜内灰尘；大修时检查柜门密封条和屏蔽接地是否可靠；检查柜内照明和通风设备是否正常。 | 控制柜严重变形或锈蚀穿孔失去防护能力；屏蔽性能严重下降导致设备频繁受干扰；内部安装结构损坏导致设备无法可靠固定；修复费用接近更换成本时，应更换控制柜。 |
| 可编程控制器(PLC) | 闸门控制系统 | 系统核心控制单元，执行闸门启闭逻辑、开度控制算法、保护联锁和数据通信。 | 否 | 定期检查PLC运行状态指示灯和自诊断信息是否正常；每月检查各模块工作状态和通信是否正常；大修时备份程序和配置参数；检查I/O模块信号精度；进行功能测试验证控制逻辑正确性。 | PLC CPU模块损坏且无法修复；程序存储器损坏且无备份可恢复；经多次维修后仍频繁出现控制异常或通信中断；厂商已停产该型号且无兼容替代品时，应更换PLC。 |
| 电源模块 | 控制柜 | 为控制系统各部件提供稳压直流电源，含过压过流保护和备用电源切换功能。 | 是 | 定期检查输出电压是否在额定范围内；每月检查散热风扇运转是否正常；大修时清洁电源模块内部积尘，检查电解电容有无鼓包漏液；测试备用电源切换功能是否可靠。 | 输出电压持续超出允许偏差范围且无法调节恢复；模块内部有烧焦痕迹或明显损坏；备用电源切换功能失效；多次发生因电源不稳定导致的系统异常时，应更换电源模块。 |
| 操作员站/触摸屏 | 闸门控制系统 | 本地人机交互界面，用于闸门操作指令下达、开度显示、状态监视和参数设置。 | 否 | 定期检查显示内容和按键/触摸响应是否正常；每月清洁屏幕表面；大修时校验显示数据与实际值的一致性；检查通信电缆和接线端子是否可靠；验证操作权限和联锁功能。 | 显示功能完全失效且无法修复；触摸屏或按键大面积失灵无法进行操作；通信接口损坏无法与PLC通信；修复费用接近更换成本时，应更换操作员站。 |
| 开度传感器 | 闸门控制系统 | 测量闸门实际开度位置，提供模拟量或数字量反馈信号用于闭环控制。 | 是 | 定期校验传感器输出信号与实际闸门开度的对应关系；每月检查传感器安装紧固状态和防护罩是否完好；大修时进行全量程精度校准；检查传感器电缆有无破损和屏蔽接地是否可靠。 | 传感器输出信号严重漂移且无法校准；感测元件损坏无信号输出；外壳破损导致内部受潮损坏；经校准后精度仍不满足开度控制要求时，应更换开度传感器。 |
| 编码器 | 开度传感器 | 将闸门机械位移转换为数字脉冲或编码信号的高精度位置检测元件。 | 是 | 定期检查编码器输出脉冲数与实际位移的对应关系；每月检查编码器安装对中和紧固状态；大修时进行精度校验；检查编码器轴和联轴器有无松动；清洁编码器外壳防止灰尘和油污侵入。 | 编码器输出信号异常或丢失脉冲；内部光栅或磁栅元件损坏；轴弯曲或轴承损坏导致转动不灵活；精度校验不合格且无法修复时，应更换编码器。 |
| 水位传感器 | 闸门控制系统 | 测量闸门前后的水位，为闸门自动控制提供水位信号输入。 | 是 | 定期校验水位传感器测量精度；每月检查传感器探头有无附着物和损伤；大修时进行全量程精度校准；检查信号电缆和接线端子状态；清洁传感器测量通道。 | 传感器输出信号严重漂移且无法校准；感测元件损坏导致无法正确测量水位；外壳破损导致进水损坏；精度不满足自动控制要求时，应更换水位传感器。 |
| 液压泵站 | 闸门控制系统 | 为液压启闭机提供高压液压动力源，包括油泵、油箱、电机、阀门组及附件。 | 否 | 定期检查油箱油位和油温是否正常；每月检查油泵运行声音和振动是否异常；按周期化验油液清洁度；大修时清洗油箱和管路，更换全部滤芯；检查安全阀和溢流阀设定压力是否准确。 | 油箱严重锈蚀穿孔；主油泵多次故障且整体性能劣化；管路系统老化渗漏严重；无法提供液压启闭机所需的压力和流量时，应报废更换液压泵站。 |
| 液压油泵 | 液压泵站 | 将机械能转换为液压能，为系统提供高压工作油。 | 否 | 定期检查油泵出口压力和流量是否正常；监听运行声音有无异常；每月检查轴封有无渗漏；大修时检测泵内部件磨损量；定期检查联轴器对中情况。 | 泵体出现裂纹；内部磨损导致容积效率显著下降；轴承损坏导致转子磨损严重；多次维修后仍无法达到额定压力和流量时，应更换液压油泵。 |
| 油泵电机 | 液压泵站 | 驱动液压油泵运转的三相异步电动机。 | 是 | 定期检查电机运行电流和温升是否正常；每月监听电机轴承有无异响；每半年测量电机绝缘电阻；大修时检查轴承磨损状况，更换润滑脂；检查接线端子和电缆状态。 | 电机绕组烧毁或绝缘电阻严重下降；轴承多次损坏导致转子扫膛；效率严重下降导致过热运行；经大修后仍无法满足驱动要求时，应更换油泵电机。 |
| 电磁换向阀 | 液压泵站 | 接收控制信号切换液压油路方向，控制液压缸活塞运动方向实现闸门启闭。 | 是 | 定期进行电磁阀动作试验，验证换向是否迅速可靠；每月检查电磁线圈有无过热和异响；大修时测量线圈电阻和绝缘电阻；检查阀芯密封面和弹簧状态；清洗阀体内壁和油道。 | 线圈烧毁或断路；阀芯卡死在某一位置无法换向；密封面严重损坏导致内泄无法建立工作压力；动作响应时间严重超标时，应更换电磁换向阀。 |
| 溢流阀 | 液压泵站 | 调节和稳定系统压力，防止超压损坏管路和设备。 | 是 | 定期校验溢流阀设定压力是否准确；每月检查阀体有无渗漏；大修时解体检查阀芯和阀座密封面、弹簧状态；校验动作压力整定值。 | 阀芯密封面严重损坏导致无法维持设定压力；弹簧断裂或严重疲劳；经研磨和调整后仍无法恢复调压精度时，应更换溢流阀。 |
| 液压锁 | 液压泵站 | 在液压缸停止运动时锁定油路，防止闸门因自重或水压下滑。 | 是 | 定期检查液压锁保压性能，监测闸门在停止状态有无缓慢下滑；大修时检查阀芯密封面和弹簧状态；检查液控单向阀动作是否可靠；进行保压泄漏测试。 | 阀芯密封面严重损坏导致无法可靠锁死油路；弹簧断裂导致单向阀无法关闭；保压测试中压力持续快速下降；经检修后闸门仍出现异常下滑时，应更换液压锁。 |
| 滤油器 | 液压泵站 | 滤除液压油中颗粒污染物，保证系统油液清洁度。 | 是 | 当压差指示器报警时及时更换滤芯；定期检查滤油器壳体有无渗漏；大修时清洗壳体内部，更换全部滤芯；检查旁通阀动作是否灵活。 | 滤油器壳体严重锈蚀或变形；内部旁通阀损坏且无法修复；安装座损坏导致密封不可靠时，应更换滤油器。 |
| 蓄能器 | 液压泵站 | 储存压力能，补偿泄漏并维持压力稳定，在油泵故障时提供应急操作动力。 | 是 | 定期检查充气压力是否在规定范围内；每月检查接口有无渗漏；大修时检查壳体有无变形和锈蚀；验证蓄能器在油泵停机后能否提供足够的应急操作油量。 | 壳体出现裂纹或严重变形；疲劳寿命超过厂家规定年限；充气后压力持续快速下降；经检验机构认定不合格时，应报废更换蓄能器。 |
| 液压缸(启闭机) | 闸门控制系统 | 将液压能转换为机械能，通过活塞杆伸缩运动驱动闸门启闭的直线执行元件。 | 否 | 定期检查液压缸动作是否平稳无爬行和抖动；每月检查活塞杆表面有无拉伤和腐蚀；大修时检查缸体内壁磨损、活塞密封和导向环状态；测量活塞杆直线度。 | 缸体内壁严重拉伤或锈蚀无法修复；活塞杆弯曲或表面镀铬层大面积剥落；多次更换密封件后仍持续内泄外漏；无法提供足够的启闭力时，应报废更换液压缸。 |
| 活塞密封 | 液压缸(启闭机) | 防止液压缸高低压腔之间内泄漏的密封环组合。 | 是 | 定期监测液压缸在保压状态下活塞有无缓慢漂移，判断密封磨损程度；大修时测量密封环尺寸，检查有无变形、硬化和表面损伤；按规定周期更换密封环。 | 密封环严重磨损导致内泄增大活塞漂移超标；材料老化硬化失去弹性；表面出现深划痕或局部缺损；已达到规定的更换周期时，应更换活塞密封。 |
| 活塞杆密封 | 液压缸(启闭机) | 防止液压油沿活塞杆外泄漏的防尘圈和密封圈组合。 | 是 | 定期检查活塞杆伸出端有无油液渗漏；大修时检查防尘圈和密封圈磨损状况，全部更换；检查活塞杆表面与密封接触区域的磨损和粗糙度。 | 密封件老化硬化失去弹性；严重磨损导致活塞杆处持续泄漏；防尘圈损坏导致灰尘和水分侵入加速密封和活塞杆磨损时，应更换活塞杆密封组合。 |
| 行程开关 | 闸门控制系统 | 检测闸门全开和全关极限位置的限位开关，提供位置信号和行程保护。 | 是 | 定期检查行程开关动作是否灵活可靠，触点状态是否正常；大修时校验开关动作位置是否与闸门实际极限位置一致；检查开关接线和安装紧固状态。 | 开关触点严重烧蚀导致接触不良或粘连；动作位置严重偏移且无法调整；外壳破损失去防护性能；校验不合格且无法修复时，应更换行程开关。 |
| 力矩限制器 | 闸门控制系统 | 在闸门运行阻力超过设定力矩时动作，切断动力防止设备过载损坏。 | 是 | 定期校验力矩限制器设定值是否准确；大修时进行力矩标定试验；检查力矩传感器或机械弹簧状态；验证过载保护动作是否可靠切断动力。 | 力矩传感器损坏导致无法正确检测力矩；弹簧断裂或严重疲劳导致设定值漂移；校验不合格且无法调整恢复；保护动作不可靠存在设备损坏风险时，应更换力矩限制器。 |
| 闸门开度指示仪 | 闸门控制系统 | 现场显示闸门开度值和运行状态的仪表装置。 | 否 | 定期检查开度指示仪显示是否清晰准确，与实际开度是否一致；每月清洁仪表表面；大修时校验显示精度和信号输出；检查仪表电源和接线状态。 | 显示功能完全失效且无法修复；显示精度严重偏差且无法校准；通信接口损坏无法传输数据；经校验后仍不满足监测要求时，应更换开度指示仪。 |
| 信号防雷器 | 闸门控制系统 | 保护控制系统信号线路免受雷电感应和浪涌电压损害的保护器件。 | 是 | 雷雨季节前检查防雷器外观和状态指示是否正常；大修时测量防雷器钳位电压和漏电流是否在允许范围内；检查接地连接是否可靠。 | 防雷器因雷击动作后失效；钳位电压升高或漏电流增大超出允许范围；状态指示器显示失效；外观有烧灼痕迹或破裂时，应更换信号防雷器。 |
