| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 传感器子系统 | — | 负责采集水位、雨量等水文参数，是系统的数据源头 | 否 | 每季度检查各传感器安装状态和信号输出，清洁传感器探头和承雨器，核实采样精度 | 传感器子系统整体老化损坏、测量精度严重超差且多个传感器无法修复时报废 |
| 遥测终端机（RTU） | — | 对传感器信号进行采集、处理、存储并控制通信传输 | 否 | 每季度检查RTU运行状态指示灯，核实数据采集和存储功能正常，测试通信链路 | RTU主板损坏、数据频繁丢失或通信功能完全丧失且维修成本过高时更换终端机 |
| 通信子系统 | — | 实现遥测站与中心站之间的数据传输 | 否 | 每季度检查各通信链路信号强度和传输质量，核实数据完整率和传输延迟 | 通信设备批量损坏、多种通信方式同时失效或技术标准落后无法升级时整体改造 |
| 供电系统 | — | 为现场设备提供稳定、持续的电力供应 | 否 | 每季度检查太阳能板输出功率和蓄电池容量，核实充电控制器工作状态 | 供电系统整体老化无法保障设备连续运行、太阳能板和蓄电池同时需更换时评估是否整体改造 |
| 中心站系统 | — | 接收、处理、存储数据并提供水情分析和预警功能 | 否 | 每季度检查服务器运行状态和数据库完整性，核实预警功能和报表生成正常 | 服务器硬件严重老化、软件系统无法升级或数据库多次损坏影响数据完整性时升级改造 |
| 雨量计 | 传感器子系统 | 测量降水量，常用翻斗式雨量计 | 否 | 每月检查雨量计安装水平度和承雨器清洁度，每季度用标准量筒校验翻斗计量精度 | 雨量计结构严重变形、计量精度超差无法校准或翻斗机构损坏时更换雨量计 |
| 水位计 | 传感器子系统 | 实时测量水体水位高度 | 否 | 每季度用标准水位参考点校验测量精度，检查传感器安装固定和线缆完好性 | 测量精度超差无法校准、传感器损坏或安装结构严重锈蚀时更换水位计 |
| 承雨器 | 雨量计 | 收集雨水并导入翻斗 | 否 | 每月清理承雨器内落叶和杂物，检查漏嘴畅通性，核实安装高度符合规范 | 承雨器严重变形影响集水面积、漏嘴损坏或内壁防腐层脱落时更换 |
| 翻斗 | 雨量计 | 通过翻转次数计量降雨量，长期使用后易磨损变形 | 是 | 每月检查翻斗翻转灵活性和限位螺钉状态，每季度校验翻转计量精度 | 翻斗轴孔磨损导致翻转卡涩、斗壁变形影响计量精度或限位机构损坏时更换翻斗 |
| 磁钢与干簧管 | 雨量计 | 将翻斗翻转转换为脉冲信号，干簧管触点易氧化或疲劳 | 是 | 每季度用万用表测试干簧管通断可靠性，检查磁钢磁力是否衰减 | 干簧管触点氧化接触不良、磁钢退磁或信号漏计超过允许范围时更换磁钢和干簧管组件 |
| 压力式水位传感器 | 水位计 | 通过测量水压换算水位，膜片和密封易老化 | 是 | 每季度检查传感器膜片完好性和密封状态，用标准水位校验测量精度 | 膜片破裂渗漏、密封老化进水或测量精度超差无法校准时更换传感器 |
| 浮子式水位传感器 | 水位计 | 利用浮子随水位升降带动编码器工作 | 否 | 每月检查浮子和配重的运动灵活性，清洁导轨和滑轮，核实编码器输出 | 浮子破损进水、编码器损坏或滑轮卡涩影响测量精度时更换相应部件 |
| 雷达水位计 | 水位计 | 非接触式测量，天线罩和密封部件需维护 | 否 | 每季度检查天线罩清洁度和密封完好性，核实测量精度和安装角度 | 天线罩严重损坏影响电磁波发射接收、内部电路故障或精度持续超差时更换雷达水位计 |
| 数据采集模块 | 遥测终端机（RTU） | 采集传感器脉冲或数字信号，进行A/D转换 | 否 | 每季度用标准信号源校验各通道采集精度，检查接线端子紧固性 | 采集精度超差、通道批量损坏或A/D转换芯片故障时更换采集模块 |
| 控制主板 | 遥测终端机（RTU） | 运行程序，控制定时采集、存储和通信逻辑 | 否 | 每季度检查主板运行状态和程序版本，核实实时时钟精度，清洁板面灰尘 | 主板芯片损坏、程序频繁跑飞或时钟严重偏差无法校准时更换主板 |
| 存储模块 | 遥测终端机（RTU） | 本地保存数据，防止通信中断丢失 | 否 | 每季度检查存储容量使用和数据完整性，测试读写速度 | 存储芯片损坏导致数据丢失、存储容量不足或读写错误率升高时更换存储模块 |
| 通信接口板 | 遥测终端机（RTU） | 提供RS-485/RS-232/SDI-12等接口连接传感器和通信设备 | 否 | 每季度检查各接口通信功能，核实接口电平和协议参数 | 接口硬件损坏、通信端口批量失效或协议转换异常时更换接口板 |
| GPRS/4G DTU | 通信子系统 | 通过移动公网将数据发送至中心站 | 否 | 每季度检查SIM卡状态和信号强度，核实数据传输完整率和延迟 | DTU硬件损坏、通信模块老化不支持当前网络制式或数据传输频繁中断时更换DTU |
| 北斗卫星通信终端 | 通信子系统 | 在无公网覆盖区域使用短报文传输数据 | 否 | 每季度检查卫星信号锁定和数据发送成功率，核实通信卡有效期 | 终端硬件故障无法锁定卫星信号、通信卡失效或数据发送成功率持续低于要求时更换终端 |
| 通信天线 | 通信子系统 | 发射和接收无线信号，长期暴露易受腐蚀、接触不良 | 是 | 每季度检查天线安装固定和外观完好性，测试馈线接头和驻波比 | 天线严重腐蚀变形、馈线接头氧化接触不良或驻波比超标导致信号衰减严重时更换天线 |
| 太阳能电池板 | 供电系统 | 将光能转化为电能，转换效率逐年衰减，封装老化 | 是 | 每季度清洁太阳能板表面灰尘，检查封装有无气泡脱层，测量输出功率和转换效率 | 转换效率衰减至额定值70%以下、封装严重老化破损或输出功率不足以维持供电时更换太阳能板 |
| 蓄电池 | 供电系统 | 存储电能供设备夜间或阴雨天使用，寿命约3-5年 | 是 | 每季度测量蓄电池端电压和内阻，核对容量衰减情况，检查外壳有无鼓胀变形 | 电池容量衰减至额定值60%以下、内阻显著增大或外壳鼓胀漏液时更换蓄电池组 |
| 充电控制器 | 供电系统 | 管理太阳能对蓄电池充放电，防止过充过放，电子元件可能老化 | 是 | 每季度检查充放电电压和电流是否在设定范围内，核实过充过放保护功能 | 控制器输出电压持续超差、保护功能失效或电路板严重老化时更换充电控制器 |
| 电源防雷模块 | 供电系统 | 保护电路免受雷电感应浪涌冲击，易损坏 | 是 | 每季度检查防雷模块状态指示，核实接地线连接可靠，测试钳位电压 | 防雷模块状态指示失效、钳位电压超标或遭受强雷击后立即更换 |
| 信号防雷模块 | 通信子系统 | 保护传感器、通信接口免遭雷击损坏，易损坏 | 是 | 每季度检查信号防雷模块状态和接线，核实保护功能 | 模块损坏失效、信号传输异常或遭受雷击后立即更换 |
| 数据服务器 | 中心站系统 | 运行数据库软件，存储和处理遥测数据 | 否 | 每季度检查服务器硬件运行状态和磁盘空间，核实数据库备份策略和完整性 | 服务器硬件严重故障、磁盘阵列损坏导致数据丢失或性能严重不足时更换服务器 |
| 应用软件 | 中心站系统 | 实现数据查询、报表、洪水预报等功能 | 否 | 每季度检查软件功能完整性，核实预报模型参数和数据展示正常 | 软件系统严重老化无法升级、数据库结构不合理或功能不满足需求时升级或更换软件 |
| 机箱与机柜 | — | 安装和保护内部设备，需具备防水、防尘和散热能力 | 否 | 每季度检查机箱密封性和散热通风，清洁内部积尘，核实安装螺栓紧固 | 机箱严重锈蚀变形丧失防护能力、密封失效导致内部进水或散热结构损坏时更换 |
| 线缆与接插件 | — | 连接各部件，长期户外使用易老化、氧化导致接触不良 | 是 | 每季度检查线缆外皮有无老化开裂，检查接插件有无氧化松动，核实信号传输质量 | 线缆绝缘层大面积老化开裂、接插件严重氧化接触不良或信号传输不稳定时更换线缆 |
