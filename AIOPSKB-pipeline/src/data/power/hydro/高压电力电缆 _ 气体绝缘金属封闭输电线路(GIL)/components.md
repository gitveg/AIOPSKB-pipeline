| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 外壳系统 | — | 采用铝合金或钢制筒体，构成气密性封闭空间，承受内部气体压力和机械应力。 | 否 | 定期巡检外壳表面有无锈蚀、变形、漆层脱落和机械损伤；每年检查外壳接地连接是否可靠；大修时测量外壳对地绝缘电阻和法兰连接力矩；检查外壳防腐涂层完好性，局部损伤时及时修补。 | 外壳严重变形或锈蚀穿孔影响气密性和结构强度；法兰结合面严重损伤无法保证密封；防腐涂层大面积失效导致持续腐蚀；筒体出现裂纹且无法修复时，应报废更换外壳段。 |
| 导体系统 | — | 包括导电杆、触头、滑动触指等，用于大电流传输，由支柱绝缘子支撑。 | 否 | 定期监测导体回路电阻是否在允许范围内；大修时检查导体表面有无氧化、变色和过热痕迹；检查导体连接部位紧固力矩；测量各相导体的接触电阻分布；利用红外测温监测运行中导体连接点温度。 | 导体严重氧化或过热烧损导致载流能力显著下降；导电杆出现裂纹或严重变形；接触电阻持续增大且无法通过紧固和清洁恢复；载流截面因烧蚀减小超出安全裕度时，应报废更换导体段。 |
| 绝缘支撑系统 | — | 包含盆式绝缘子、支柱绝缘子，实现导体对地绝缘、气室分隔及机械定位。 | 否 | 定期进行局部放电检测，监测绝缘状态；大修时检查绝缘子表面有无裂纹、放电痕迹和异物附着；测量绝缘电阻和介质损耗因数；进行工频耐压试验验证绝缘强度；检查绝缘子嵌件和导体连接部位有无异常。 | 绝缘子出现贯通性裂纹或严重放电烧伤；介质损耗因数严重超标；工频耐压试验击穿；局部放电量持续增大超过标准限值；机械强度因老化或损伤显著下降时，应报废更换绝缘子。 |
| 气体绝缘介质 | — | 通常为SF6或SF6/N₂混合气体，提供主绝缘和灭弧能力，填充于外壳内部。 | 否 | 定期监测气室压力和密度是否在正常范围；每季度进行微水含量检测；每年检测气体分解产物含量；大修时进行气体纯度全面分析；按规定周期进行检漏测试；发现压力下降时及时排查泄漏点并补充合格气体。 | 气体严重劣化（微水、分解产物超标）且净化处理无法恢复；气室存在不可修复的泄漏导致补气周期过短；气体纯度低于允许下限且反复处理后仍不达标；气体已达到规定的更换周期时，应回收旧气并充入合格新气。 |
| 微粒陷阱 | 外壳系统 | 安装于壳体底部，利用电场或结构捕获并限制内部金属微粒运动，防止闪络。 | 否 | 定期通过局部放电监测评估微粒陷阱工作效果；大修时在气室开盖检修时检查微粒陷阱内部捕获的金属微粒数量和类型；检查陷阱结构有无变形和损坏；清理已捕获的微粒。 | 微粒陷阱结构严重变形或损坏失去捕获能力；电场结构失效导致微粒无法有效收集；多次清理后仍频繁出现因自由微粒导致的局部放电超标；结构损坏无法修复时，应更换微粒陷阱。 |
| 伸缩节/波纹管 | 外壳系统 | 补偿热胀冷缩、基础沉降及安装误差，维持母线同轴度和密封应力。 | 否 | 定期检查波纹管有无变形、裂纹和异常位移；大修时测量波纹管补偿量和预拉伸/预压缩状态；检查波纹管两端法兰连接力矩和密封状况；检查波纹管外部保护罩是否完好。 | 波纹管出现裂纹或穿孔导致气体泄漏；波纹管因疲劳产生永久变形失去补偿能力；波纹管外部严重锈蚀减薄；补偿量超出设计极限导致密封失效时，应更换伸缩节/波纹管。 |
| 防爆膜/压力释放装置 | 外壳系统 | 在内部故障电弧导致气压骤升时定向破裂，释放压力，防止壳体爆炸。 | 是 | 定期检查防爆膜外观有无变形、锈蚀和机械损伤；大修时检查防爆膜安装密封和排放通道是否畅通；检查防爆膜铭牌参数是否与设计一致；严禁在防爆膜上施加额外载荷或覆盖物品。 | 防爆膜因长期受压出现塑性变形或微裂纹；达到厂家规定的更换周期（通常5-10年）；发现防爆膜有锈蚀穿透隐患；防爆膜曾动作释放过压力后，应立即更换防爆膜。 |
| 密封圈/O型圈 | 外壳系统 | 安装在法兰、绝缘子及孔盖处，防止气体泄漏和潮气侵入。 | 是 | 每次拆卸法兰或孔盖后必须检查密封圈有无变形、硬化和表面损伤；大修时按规程全部更换密封圈；安装前清洁密封槽和密封面，涂抹适量密封脂；检查密封圈材料是否适合SF6环境；储存备用密封圈时注意避光避热防老化。 | 密封圈老化硬化失去弹性；表面出现裂纹、切口或永久压缩变形；材料被SF6分解产物腐蚀变质；已达到规定的更换周期时，应直接报废更换新的密封圈。 |
| 盆式绝缘子 | 绝缘支撑系统 | 圆盘形环氧树脂浇注件，分隔相邻气室，提供导体贯穿和径向绝缘支撑。 | 否 | 定期进行局部放电检测和介质损耗测量；大修时检查绝缘子表面有无裂纹、放电痕迹和金属粉末附着；检查绝缘子两侧气室压差是否在设计允许范围内；进行绝缘电阻和耐压试验；检查嵌件与导体连接有无过热变色。 | 绝缘子出现贯通性裂纹或严重放电烧伤痕迹；介质损耗因数或局部放电量持续严重超标；耐压试验击穿；因机械损伤或老化导致绝缘强度显著下降；出现气室间串气现象时，应报废更换盆式绝缘子。 |
| 支柱绝缘子 | 绝缘支撑系统 | 支撑导体的柱状环氧树脂件，承受自重、电动力及短路机械力。 | 否 | 定期检查支柱绝缘子表面状态和支撑稳定性；大修时检查有无裂纹、放电痕迹和机械损伤；测量绝缘电阻和介质损耗；进行耐压试验验证绝缘强度；检查绝缘子与导体和外壳的连接紧固状态。 | 绝缘子出现裂纹（特别是根部应力集中区域）；表面严重放电烧伤；介质损耗因数严重超标；耐压试验不合格；因短路电动力导致机械损伤或变形时，应报废更换支柱绝缘子。 |
| 三相导体单元 | 导体系统 | 为三相共箱式时包含三根分开的铝合金管型导体，单相式则为单根导体。 | 否 | 定期测量导体回路电阻值，与历史数据比对分析变化趋势；大修时检查导体表面有无氧化、变色和过热痕迹；检查导体直线度和支撑状态；测量各相导体的接触电阻分布均匀性。 | 导体严重氧化或过热变色导致载流能力下降；导电杆出现裂纹或严重弯曲变形；回路电阻持续增大且无法通过清洁和紧固恢复；载流截面因烧蚀或腐蚀显著减小时，应报废更换导体单元。 |
| 滑动触指/表带触指 | 导体系统 | 多片弹性银镀层触指，安装在导体连接处，允许导体热伸缩并维持良好接触。 | 是 | 定期测量触指接触电阻，监测变化趋势；大修时检查触指有无氧化、磨损和弹簧片疲劳；检查银镀层有无剥落；清洁触指表面氧化物；检查触指对导体的抱紧力是否正常；利用红外测温监测运行中触指部位温度。 | 触指银镀层严重磨损或剥落导致接触电阻增大；弹簧片疲劳失去弹性导致抱紧力不足；触指严重烧损或变形；接触电阻持续增大引起过热且无法通过清洁恢复时，应更换滑动触指组件。 |
| 屏蔽罩 | 导体系统 | 安装在绝缘子嵌件和导体连接处，均化电场，降低局部放电风险。 | 否 | 定期通过局部放电监测评估屏蔽罩均压效果；大修时检查屏蔽罩表面有无毛刺、变形和异物附着；检查屏蔽罩安装位置是否正确，紧固件是否可靠；检查屏蔽罩与导体和绝缘子的配合间隙。 | 屏蔽罩严重变形导致电场分布异常；表面出现毛刺或烧伤痕迹引起局部放电超标；因短路电动力导致位移或变形；紧固件损坏导致屏蔽罩松动无法可靠固定时，应更换屏蔽罩。 |
| 吸附剂/分子筛 | 气体绝缘介质 | 置于壳体内或专用容器中，吸附内部水分和SF₆分解产物，维持气体纯度。 | 是 | 定期通过气体质量分析评估吸附剂效能；大修时检查吸附剂外观有无粉化和变色；按规定周期更换吸附剂（通常在气室开盖检修时更换）；更换后在烘箱中活化处理或直接使用预活化产品；记录更换日期和气室编号。 | 吸附剂达到规定的更换周期；气体分析显示水分或分解产物持续升高表明吸附剂已饱和；吸附剂严重粉化或结块失去吸附能力；吸附剂变色表明已大量吸附有害物质时，应更换吸附剂/分子筛。 |
| 密度继电器/压力表 | 气体绝缘介质 | 监测气室密度或压力，当低于阈值时发出报警或闭锁信号。 | 否 | 定期检查密度继电器指示值是否与实际气体状态一致；每月校验报警和闭锁设定值是否准确；大修时进行密度继电器校验，检查温度补偿功能是否正常；检查接线端子和信号传输是否可靠；检查压力表指示精度。 | 密度继电器指示严重失真且无法校准；温度补偿功能失效导致误报警或漏报警；接点烧蚀或粘连导致信号不可靠；校验不合格且无法修复时，应更换密度继电器/压力表。 |
| 电压监测接口 | 气体绝缘介质 | 提供现场或在线微水、分解物及纯度检测的取气接口，便于状态评估。 | 否 | 定期检查接口密封帽和阀门是否完好密封；每次取气检测后确保接口可靠密封恢复；大修时检查接口阀门动作是否灵活密封是否可靠；检查接口连接螺纹有无损伤；校验取气管路无堵塞和泄漏。 | 接口阀门损坏导致无法可靠密封存在泄漏隐患；连接螺纹严重损伤无法密封；接口内部堵塞无法进行取气检测；阀门密封面严重损坏经研磨无法恢复时，应更换电压监测接口。 |
