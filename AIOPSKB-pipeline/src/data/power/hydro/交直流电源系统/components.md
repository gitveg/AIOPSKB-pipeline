| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 交流输入单元 | — | 接入市电或发电机电源，包含接线端子、断路器、防雷及EMI滤波等，提供交流电能入口和保护。 | 否 | 每年检查交流输入接线端子紧固力矩；测量三相电压平衡度和频率；检查防雷器状态指示；大修时测量各开关触头接触电阻。 | 交流输入单元多部件同时损坏（断路器、防雷器、滤波器均需更换），修复成本超过更换整单元。更换时断电操作，核对相序和容量。 |
| 输入断路器 | 交流输入单元 | 实现交流侧过载和短路保护，可手动分合，具备热磁脱扣功能。 | 是 | 每年检查断路器分合操作是否正常；测量触头接触电阻；做脱扣特性测试；检查接线端子紧固。 | 触头严重烧蚀导致接触电阻超标；脱扣特性偏移无法校准；机构卡涩无法分合。更换同规格断路器后测试分合和脱扣功能。 |
| 防雷器（SPD） | 交流输入单元 | 抑制雷电过电压和操作过电压，保护后级设备免受瞬态浪涌损害。 | 是 | 每季度检查防雷器状态指示窗（绿色正常/红色失效）；每年测量压敏电压和漏电流；雷雨季节前专项检查。运行中如指示变红需立即更换。 | 状态指示窗变红（失效）；压敏电压漂移超过±10%；外壳出现裂纹或烧蚀痕迹。更换同规格SPD并检查后备熔断器。 |
| 交流防雷熔断器 | 交流输入单元 | 当防雷器失效短路时，熔断器断开以防止系统短路故障。 | 是 | 每年检查熔断器状态（导通测试）；检查底座夹紧力和弹簧状态；检查有无过热变色。 | 熔断器熔断；底座严重氧化导致接触不良。更换同规格熔断器后检查底座状态。 |
| 整流模块 | — | 将交流电转换为稳定直流电，包含功率因数校正、高频开关变换及输出整流滤波。 | 否 | 每季度检查模块输出电压、电流和均流度；检查散热风扇运转状态；每年测量模块效率；大修时清理内部灰尘。运行中如均流度超标应排查模块故障。 | 模块输出不稳定或效率严重下降；功率器件多路损坏。更换整流模块时选用同型号模块，核对通信协议和均流参数。 |
| IGBT/IPM功率模块 | 整流模块 | 核心高频开关器件，实现AC-DC变换和功率因数校正。 | 是 | 每半年检查IGBT/IPM模块与散热器连接是否紧固；测量导通压降和绝缘电阻；检查驱动信号波形。运行中如模块温度异常升高应停机排查。 | IGBT/IPM模块击穿短路或导通压降严重超标；驱动管脚断裂。更换模块时注意防静电，安装后做轻载功能测试。 |
| 直流母线电容 | 整流模块 | 电解电容组，平滑整流输出直流电压，提供瞬时能量缓冲。 | 是 | 每半年测量电容容量和ESR值；检查电容顶部防爆阀有无鼓包；运行中监控直流母线电压纹波。 | 容量衰减超过额定值20%或ESR增大超过初始值2倍；外壳鼓包。更换时选用同规格电容并注意极性。 |
| 散热风扇 | 整流模块 | 强制风冷，将功率器件及磁性元件热量排出模块，确保温升合格。 | 是 | 每季度检查风扇运转有无异响和振动；清理扇叶积灰；测量电机电流。运行中如模块温度异常升高应优先检查风扇。 | 风扇电机烧毁或轴承卡死；扇叶断裂。更换同规格风扇后检查转向和风量。 |
| 输入滤波板 | 整流模块 | 包括X/Y安规电容、共模电感，抑制传导干扰，满足EMC要求。 | 否 | 每年检查滤波板元器件外观有无变色和烧蚀；测量X/Y电容容量；检查焊接质量。 | 滤波板PCB烧蚀或安规电容多只失效导致EMI超标。更换滤波板后做EMC测试。 |
| 直流输出单元 | — | 将整流模块或蓄电池的直流电分配至负载，包含母排、保护元件及隔离器件。 | 否 | 每年检查直流母排连接螺栓紧固力矩；测量各支路绝缘电阻；检查各保护元件状态；大修时清理母排表面氧化层。 | 母排严重氧化或烧蚀；多个保护元件同时损坏。需整体更换直流输出单元及相关连接部件。 |
| 直流熔断器 | 直流输出单元 | 用于负载支路过流保护，熔断后需更换。 | 是 | 每年检查熔断器有无熔断（导通测试）；测量底座接触电阻；检查有无过热变色。保持备件库存充足（不少于使用量的30%）。 | 熔断器熔断；底座严重氧化或弹簧松弛导致接触不良。更换同规格熔断器。 |
| 输出隔离开关 | 直流输出单元 | 手动隔离直流母线与负载回路，便于安全检修。 | 否 | 每年操作隔离开关检查分合是否正常；测量触头接触电阻；检查操作手柄有无损坏。 | 触头严重烧蚀或机构卡涩无法操作。更换同规格隔离开关后测试分合和接触电阻。 |
| 防反接二极管 | 直流输出单元 | 防止蓄电池或外接电源极性接反造成系统损坏。 | 是 | 每年测量二极管正向压降和反向漏电流；检查散热器安装是否紧固；检查接线端子。 | 二极管击穿短路或正向压降严重超标。更换同规格二极管并涂抹导热硅脂。 |
| 蓄电池组 | — | 后备储能装置，在交流输入异常时通过化学能提供直流电，保障负载不间断供电。 | 否 | 每季度做蓄电池组核对性充放电试验；测量单体电压、内阻和温度；检查连接条紧固力矩；保持蓄电池室通风和温度适宜。每年做容量测试。 | 蓄电池组容量衰减至额定容量80%以下，经活化处理后仍不恢复；多只单体电池失效。整组更换时确保新旧电池不混用，安装后做充放电试验。 |
| 蓄电池单体 | 蓄电池组 | 铅酸或锂电池单体，将化学能转化为电能，寿命受充放电次数和环境温度影响。 | 是 | 每季度测量单体电压和内阻，与基准值对比；检查外壳有无鼓包、渗液和极性柱腐蚀；核对性充放电时记录每只单体放电曲线。 | 单体电压或内阻严重偏离整组平均值；外壳鼓包或渗液；容量低于标称值80%。更换单体时确保与同组电池型号、批次和性能一致。 |
| 电池连接条 | 蓄电池组 | 铜排或电缆，串联各单体电池，连接处可能因氧化或松动引起故障。 | 是 | 每季度检查连接条紧固力矩；检查连接面有无氧化和过热变色；测量连接条两端电压降（接触电阻）。 | 连接条严重氧化腐蚀导致接触电阻超标的，或出现裂纹。更换同规格连接条并清洁接触面后紧固。 |
| 电池巡检模块 | 蓄电池组 | 实时监测每节电池的电压、内阻和温度，向监控单元上传数据。 | 是 | 每年校验巡检模块各通道测量精度（电压、内阻）；检查通信状态；清洁接线端子。 | 巡检模块多通道失效或通信故障无法修复。更换巡检模块后重新配置通道参数和通信地址。 |
| 电池熔断器 | 蓄电池组 | 电池组总输出保护，防止电池外短路时引起火灾或爆炸。 | 是 | 每年检查熔断器状态（导通测试）；测量底座接触电阻；检查有无过热变色。 | 熔断器熔断；底座严重氧化。更换同规格熔断器，注意直流灭弧要求。 |
| 逆变模块 | — | 将直流电转换为固定频率和电压的交流电，供交流负载或并网使用。 | 否 | 每季度检查模块输出电压、频率和波形质量；检查散热风扇状态；每年测量逆变效率；大修时清理内部灰尘并检查功率器件。 | 逆变模块输出波形严重畸变或功率器件多路损坏；效率严重下降。更换逆变模块后核对与直流输入和交流输出的参数匹配。 |
| 逆变功率管 | 逆变模块 | IGBT或MOSFET，通过SPWM控制实现DC-AC变换，承受高电压和电流。 | 是 | 每半年检查功率管与散热器连接状态；测量导通压降和绝缘电阻；检查驱动信号波形。运行中如输出波形畸变应排查功率管。 | 功率管击穿或导通压降严重超标；驱动损坏。更换功率管时注意防静电和散热硅脂涂抹。 |
| 输出滤波电感 | 逆变模块 | 与电容构成LC滤波器，平滑PWM波输出，减小谐波畸变。 | 否 | 每年检查滤波电感有无过热变色和绝缘损伤；测量电感量；检查接线端子。 | 铁芯过热导致电感量偏移超标；匝间短路。更换同规格滤波电感。 |
| 输出滤波电容 | 逆变模块 | 吸收谐波电流，稳定输出电压波形，长期运行可能容量衰减。 | 是 | 每半年测量电容容量和ESR值；检查外壳有无鼓包；运行中如输出电压谐波含量超标应排查电容。 | 容量衰减超过额定值20%；外壳鼓包或漏液。更换同规格电容。 |
| 监控单元 | — | 采集系统模拟量和开关量，实现逻辑控制、通信和故障诊断，提供人机交互。 | 否 | 定期通过软件检查运行参数和告警记录；核对设置参数；备份配置数据；检查各I/O接口通信状态。 | 主控板损坏且无备件替代；系统频繁误报或死机。更换监控单元后重新配置全部参数和通信协议。 |
| 主控板 | 监控单元 | 包含MCU/DSP、存储器、电源芯片，运行控制算法和协议栈。 | 是 | 每年检查主控板运行状态（指示灯、自检报告）；备份程序和配置；检查板卡有无过热变色。 | MCU/DSP芯片损坏或程序丢失无法恢复；PCB烧蚀。更换同型号主控板后下载程序和配置。 |
| 显示屏/触摸屏 | 监控单元 | 显示电压、电流、告警等信息，接收操作人员设置指令。 | 是 | 定期检查屏幕显示完整性和触摸灵敏度；清洁屏幕表面；检查背光亮度。 | 屏幕大面积坏点或完全黑屏；触摸失灵无法操作。更换同型号显示屏后核对显示参数。 |
| 通信接口板 | 监控单元 | 提供RS485/以太网等接口，用于与上位机或动环系统通讯。 | 否 | 定期检查通信状态和数据传输正确性；检查接口端子紧固和指示灯状态。 | 通信接口全部失效；接口芯片损坏无法修复。更换通信接口板后重新配置协议参数。 |
| 配电单元 | — | 汇集各回路电源，通过母排和分支开关进行功率分配，并实现机械支撑和接线。 | 否 | 每年检查各回路开关分合状态；测量开关触头接触电阻；检查母排连接紧固力矩和绝缘电阻。 | 配电单元母排和多个开关同时损坏，修复成本超过更换整单元。更换时逐路标记接线后拆除，安装后逐路恢复并测试。 |
| 汇流铜排 | 配电单元 | 大电流导体，连接整流模块输出、电池支路和负载支路，发热和绝缘需重点关注。 | 否 | 每年检查铜排连接螺栓紧固力矩；检查铜排表面有无氧化和过热变色（热点温度）；用红外热像仪检查各连接点温度。 | 铜排严重氧化或腐蚀导致截面损失超过20%；多处连接点长期过热变色。更换铜排时清洁连接面并按规定力矩紧固。 |
| 分支断路器 | 配电单元 | 为每个负载支路或充电模块提供过载和短路保护，机械寿命受操作次数限制。 | 是 | 每年检查断路器分合操作是否正常；测量触头接触电阻；检查接线端子紧固。 | 触头严重烧蚀；机构卡涩无法分合；机械寿命次数到达厂家规定上限。更换同规格断路器后测试分合功能。 |
| 保护接地与绝缘监测 | — | 保障人身安全与系统可靠，包括接地母排、绝缘监测装置等。 | 否 | 每年测量接地电阻（≤4Ω）；检查接地连接是否可靠；测试绝缘监测装置功能是否正常（模拟接地故障测试）。 | 接地母排严重腐蚀断裂；绝缘监测装置故障且无法修复。更换相应部件后重新测试接地电阻和绝缘监测功能。 |
| 绝缘监测仪 | 保护接地与绝缘监测 | 向直流母线注入低频信号，检测正负极对地绝缘电阻，发生接地时告警。 | 是 | 每年校验绝缘监测仪测量精度（用标准电阻模拟接地故障）；检查注入信号幅度是否正常；检查告警功能。 | 测量精度严重超差无法校准；注入信号电路故障。更换绝缘监测仪后重新校准和测试告警功能。 |
| 接地检测电阻 | 保护接地与绝缘监测 | 与绝缘监测仪配合，限制漏电流，可能因长期工作漂移或烧坏。 | 是 | 每年测量接地检测电阻阻值，与出厂值对比；检查外观有无烧蚀和变色。 | 阻值偏移超过允许范围；电阻烧坏。更换同规格同功率电阻。 |
