| 进水管装配 | — | 连接进水阀与机组本体的压力引水管道，包含伸缩节以补偿安装误差和热变形，将压力水引入喷管或蜗壳。 | 否 | 每年枯水期停机检查管道外壁腐蚀、焊缝裂纹及法兰密封情况，定期测量壁厚；运行中监测管道振动和渗漏，伸缩节每年检查位移补偿能力，发现异常及时更换密封件。 | 管壁减薄超过设计壁厚的30%，焊缝出现不可修复的裂纹，法兰严重变形导致反复漏水无法密封，管道整体锈蚀穿孔或多处补焊后仍渗漏时应报废更换。 |
| 进水阀 | 进水管装配 | 装于进水管道上的主控制阀，在停机或事故检修时切断水源。 | 否 | 每季度检查阀体密封面磨损情况，手动操作阀门确认开关灵活性；每年停机后检查阀座与阀芯配合面，清除水生物和泥沙沉积；定期润滑阀杆和铰接部位，测试旁通阀和锁定机构。 | 阀体出现贯穿性裂纹，密封面严重冲刷损坏无法研磨修复，阀杆弯曲变形导致无法正常启闭，经大修后仍存在严重内漏时应报废。 |
| 伸缩节 | 进水管装配 | 安装于管道连接处的补偿器，用于吸收管道因温度、压力变化产生的变形，并便于阀门拆装。 | 是 | 每月检查伸缩节外露部分的位移刻度，确认在允许范围内；每季度检查密封填料或波纹管状况，发现渗漏及时拧紧或更换填料；每年测量轴向和径向位移量，核对设计补偿能力。 | 波纹管出现疲劳裂纹导致反复泄漏，填料函本体严重腐蚀变形，伸缩量超出设计极限且无法恢复，密封结构失效经多次维修仍漏水时应报废更换。 |
| 蜗壳 | — | 反击式水轮机的引水部件，使水流以较小的水力损失均匀、轴对称地进入转轮。 | 否 | 每年停机后进入蜗壳内部检查混凝土与钢板衬砌的结合面、焊缝和防腐涂层状况；定期排水检查蜗壳底部淤积和磨损情况，测量关键部位壁厚；每5年进行一次全面的无损探伤检查。 | 蜗壳钢板严重腐蚀减薄超过设计壁厚的25%，焊缝出现大面积裂纹且无法补焊修复，混凝土与钢板脱空范围超过总面积的30%，结构变形影响水力性能时应评估报废或大修。 |
| 座环/固定导叶 | 蜗壳 | 连接蜗壳与顶盖、底环的承重与过流部件，承受机组大部分轴向载荷并将其传递至混凝土基础。 | 否 | 每年检查固定导叶表面磨损、空蚀和裂纹情况；定期测量座环与顶盖、底环的配合间隙；检查地脚螺栓紧固力矩；每5年进行一次超声波探伤检查内部缺陷。 | 固定导叶翼型严重空蚀损坏影响水流均匀性，座环出现贯穿性裂纹，地脚螺栓断裂或基础混凝土严重损坏导致无法传递载荷，经评估无法修复时应报废。 |
| 尾水管 | — | 装于转轮出口的扩散形管道，用于回收转轮出口水流剩余动能，并将水流平稳排至下游。 | 否 | 每年停机后进入尾水管内部检查钢板衬砌磨损、空蚀和焊缝情况；检查尾水管与基础混凝土的接触面；监测运行时尾水管压力脉动和振动值；每5年进行壁厚测量和无损探伤。 | 尾水管衬里钢板大面积空蚀穿孔，锥管段或肘管段严重变形导致水力效率显著下降，混凝土基础严重冲刷淘空，结构完整性无法保证时应报废修复或更换。 |
| 进人门 | 尾水管/蜗壳 | 用于检修人员进入流道内部进行检查和维修作业的可开启密封门，直径通常不小于500mm。 | 否 | 每季度检查进人门密封圈老化及变形情况，确认密封面无锈蚀和损伤；每次打开后重新安装时清理密封面并涂抹密封脂；定期检查螺栓紧固力和铰链灵活性。 | 门体严重变形无法密封，密封面大面积腐蚀无法研磨修复，螺栓孔滑丝导致无法紧固，铰链断裂无法正常开闭时应报废更换。 |
| 真空破坏阀 | 尾水管/顶盖 | 补气装置。当机组紧急停机导叶快速关闭时，向转轮室内补入空气，防止真空度过大破坏尾水管或引起机组抬机。 | 否 | 每季度手动测试真空破坏阀的动作灵活性，检查阀芯与阀座的密封性；每年拆检清洗阀体内部，检查弹簧刚度和阀杆磨损情况；核对动作真空度设定值是否准确。 | 阀芯严重锈蚀卡死无法动作，弹簧疲劳断裂或刚度严重下降，阀体出现裂纹，多次检修后仍无法可靠开启或关闭时应报废更换。 |
| 导水机构 | — | 反击式水轮机中引导水流按规定方向进入转轮，并调节水轮机流量以控制机组出力与转速的装置。 | 否 | 每年停机后全面检查导水机构各部件的磨损、间隙和配合状况；测量导叶开度和同步偏差；检查控制环、连杆机构的磨损和间隙；定期调整导叶端面和立面间隙至设计值。 | 导水机构整体变形严重导致无法正常调节流量，多个导叶不同步偏差超过允许值且无法调整修复，控制环轨道严重磨损无法保证运行稳定性时应综合评估报废或整体更换。 |
| 顶盖 | 导水机构 | 位于转轮上方的圆环形承压盖板，与座环连接，支撑导水机构和导轴承，构成过流通道的一部分。 | 否 | 每年检查顶盖与座环的连接螺栓紧固力矩；检查顶盖内壁抗磨层磨损和腐蚀情况；监测运行中顶盖排水量和振动值；检查顶盖与导叶的上端面密封间隙。 | 顶盖出现贯穿性裂纹导致严重漏水，抗磨层大面积脱落且无法重新敷设，法兰面严重变形导致与座环无法密封配合，结构强度不满足安全运行要求时应报废更换。 |
| 底环 | 导水机构 | 位于导叶下方的环形基础部件，与顶盖、座环配合，为导叶提供下部支撑和止水密封面。 | 否 | 每年停机后检查底环抗磨面磨损和空蚀情况；测量导叶下端面与底环的密封间隙；检查底环与座环的连接紧固情况；定期检查抗磨板固定螺栓是否松动。 | 底环抗磨面严重磨损导致导叶端面间隙超标且无法修复，出现贯穿性裂纹，法兰面严重变形，地脚螺栓孔损坏导致无法紧固时应报废更换。 |
| 活动导叶 | 导水机构 | 可绕自身轴心转动的流线型叶片，通过改变开度调节过流量。上、下端面及立面是密封控制点。 | 否 | 每年停机后检查导叶型线磨损、空蚀和裂纹情况；测量端面和立面间隙；检查导叶轴颈磨损量；定期进行导叶开度同步性测试和调整。 | 导叶型线严重磨损或空蚀导致水力效率显著下降，叶片出现裂纹无法补焊修复，轴颈磨损量超过允许公差，多片导叶严重不同步时应报废更换。 |
| 导叶轴套 | 导水机构 | 支撑导叶轴颈并保证其灵活转动的滑动轴承，通常由自润滑材料制成，设有止水密封。 | 是 | 每季度检查导叶转动灵活性，有无卡滞和异响；每年停机后测量轴套与轴颈的配合间隙，检查密封圈磨损情况；发现漏水增大或转动阻力增加时及时更换轴套和密封圈。 | 轴套内孔磨损导致配合间隙超过设计允许值，自润滑材料剥落或碎裂，密封结构失效导致严重漏水，轴套与轴颈发生金属接触磨损时应报废更换。 |
| 导叶密封件 | 导水机构 | 装于导叶端面及立面，用于在导叶全关时减少漏水量，常用橡胶或金属材质，属易磨易老化件。 | 是 | 每季度在导叶全关位置检查漏水量，超过允许值时安排更换；每年停机后检查密封件的弹性、变形和磨损情况；保持密封面清洁，防止异物嵌入加速磨损。 | 橡胶密封件老化硬化失去弹性，金属密封面磨损超过修复余量，密封件变形或断裂导致漏水量超过设计允许值的1.5倍时应更换。 |
| 导叶剪断销 | 导水机构 | 安全保护销。当导叶间卡入异物、操作力矩超限时会自行剪断，使导叶与操作机构脱开，保护其他传动件不被损坏。 | 是 | 每季度检查剪断销的外观完整性，确认无裂纹和变形；每次机组启动前核对剪断销信号装置状态；备足备件，发现剪断后立即查明原因、清除异物并更换新销。 | 剪断销断裂后必须更换新件，不可修复 reused；同一位置反复断裂时应分析导叶机构是否存在卡阻等根本性故障；库存备件超过保质期或材质不合格时应报废。 |
| 导叶限位装置 | 导水机构 | 机械锁定装置，限制导叶最大开度，防止调节失控导致导叶进入全开危险位置。 | 否 | 每年停机后检查限位装置的机械限位块或螺栓是否松动、变形；核对限位开度与设计值的一致性；在调整导叶开度范围后需重新校准限位装置。 | 限位块或螺栓严重变形无法准确限位，安装座开裂导致限位不可靠，经多次调整仍无法维持设定开度时应报废更换。 |
| 接力器 | 导水机构 | 液压驱动执行机构，由压力油推动活塞，通过连杆和控制环操作导叶转动，实现开停机与负荷调节。 | 否 | 每季度检查接力器动作是否灵活、有无爬行和抖动现象；每年测量接力器行程和开启/关闭时间是否符合设计要求；检查缸体内壁和活塞杆表面磨损情况；定期校验过速关闭和紧急关闭时间。 | 接力器缸体严重磨损导致内泄增大、操作无力，活塞杆弯曲或镀层大面积剥落，缸体出现裂纹，经大修后仍无法满足关闭时间要求时应报废更换。 |
| 接力器活塞环/密封 | 接力器 | 装于接力器活塞上的密封件，防止压力油从高压腔串流至低压腔，其磨损会导致操作无力或摆动。 | 是 | 每季度监测接力器两腔压差和内泄量，判断密封磨损程度；每年停机后检查活塞环开口间隙和弹性；发现接力器操作无力或开度漂移时优先检查密封件状况。 | 活塞环开口间隙超过设计允许值，密封圈老化变形失去密封能力，活塞环断裂或弹力不足导致两腔串油严重时应报废更换。 |
| 转轮 | — | 水轮机的核心做功部件，将水流的动能和势能转换为旋转的机械能，通过主轴传递给发电机。 | 否 | 每年停机后进行全面检查：叶片型线测量、空蚀和裂纹检查、叶片进出口边磨损评估；每3至5年进行一次叶片修型和补焊；运行中监测机组振动、效率和异常噪声。 | 叶片大面积空蚀和磨损导致效率下降超过设计值的5%，叶片出现不可修复的裂纹（尤其是根部区域），转轮整体变形或平衡破坏无法通过动平衡修复时应报废更换。 |
| 转轮体 | 转轮 | 转桨式水轮机的核心承载壳体，连接叶片与主轴，内部安装叶片操作机构，承受巨大水压力和扭矩。 | 否 | 每年停机后检查转轮体外壁磨损和空蚀情况；定期通过检修孔检查内部操作机构的润滑和磨损状况；检查叶片枢轴与转轮体的配合间隙；监测运行中转轮体温升。 | 转轮体出现贯穿性裂纹，枢轴配合孔严重磨损导致叶片晃动超标，内部操作机构无法正常传递力矩，外壁严重空蚀减薄影响结构强度时应报废更换。 |
| 转轮叶片 | 转轮 | 直接承受水流冲击/绕流的曲面部件，其线型与表面质量决定能量转换效率。混流式叶片固定，转桨式叶片可绕轴转动。 | 否 | 每年停机后对叶片进行目视和无损探伤检查，重点检查进出水边、叶片根部区域；评估空蚀面积和深度，必要时进行不锈钢补焊和修型；转桨式叶片还需检查密封和转动灵活性。 | 叶片型线严重损坏导致效率下降超过设计允许值，叶片根部出现深裂纹危及结构安全，叶片厚度减薄超过原设计厚度的20%，经多次补焊修复后材质劣化严重时应报废更换。 |
| 止漏环 | 转轮 | 装于转轮上冠和下环外缘的环形密封件，与对应的固定止漏环形成细小间隙，减少高压水向低压侧的容积损失，其间隙随磨损而变大。 | 是 | 每年停机后测量止漏环间隙，与设计值和上次记录对比评估磨损趋势；检查止漏环表面磨损和偏磨情况；间隙接近或超过允许极限值时安排更换；运行中监测容积效率和机组振动变化。 | 止漏环间隙超过设计允许值的2倍导致容积效率显著下降，环体严重偏磨或局部脱落，表面硬化层磨穿导致磨损急剧加速时应报废更换。 |
| 泄水锥 | 转轮 | 连接于转轮上冠下方的锥形导流体，引导经转轮流出的水流平顺轴向进入尾水管，减小涡流损失。 | 否 | 每年停机后检查泄水锥连接螺栓是否松动，锥面有无空蚀和裂纹；检查泄水锥与转轮的连接稳固性；运行中监测尾水管入口涡带和压力脉动情况。 | 泄水锥脱落或严重变形导致尾水管涡流增大和机组振动加剧，锥面大面积空蚀穿孔，连接部位损坏无法可靠固定时应报废更换。 |
| 主轴 | — | 将转轮产生的机械转矩传递给发电机转子的主要承载旋转部件，需承受扭矩、轴向水推力和径向力。 | 否 | 每年停机后检查主轴表面磨损、腐蚀和裂纹情况；测量主轴摆度和同心度；检查法兰连接螺栓紧固力矩；定期进行超声波探伤检查内部缺陷；监测运行中主轴温度和振动值。 | 主轴出现深度裂纹或疲劳缺陷无法通过加工消除，轴颈磨损严重导致无法维持轴承间隙，法兰面损坏或螺栓孔变形导致连接不可靠，弯曲变形超标无法校直时应报废更换。 |
| 水轮机导轴承 | 主轴 | 承受水轮机转子径向负荷的滑动轴承，确保主轴回转中心稳定。常用稀油润滑分块瓦或筒式瓦结构。 | 否 | 每季度检查油位、油色和油温，定期取样进行油质化验；每年停机后测量轴承间隙和轴瓦磨损量；检查冷却器工作状态和密封情况；运行中监测轴瓦温度和油槽油位。 | 轴承间隙超过设计允许值导致主轴摆度超标，轴瓦合金层大面积脱落或烧损，轴承体出现裂纹，油槽严重变形导致漏油无法控制时应报废更换。 |
| 轴瓦 | 水轮机导轴承 | 轴承中与主轴轴颈直接接触的环形或瓦块状零件，材质通常为巴氏合金或工程塑料，承受摩擦并保证润滑。 | 是 | 每季度监测轴瓦温度和油膜压力，温度异常升高时立即停机检查；每年停机后检查轴瓦表面合金层的磨损、划痕和脱层情况；测量轴瓦与轴颈的间隙；保持润滑油清洁并及时更换。 | 轴瓦合金层磨损超过设计允许厚度，出现大面积脱层或烧熔，表面严重拉伤无法刮研修复，间隙超过允许值导致无法建立正常油膜时应报废更换。 |
| 轴承冷却器 | 水轮机导轴承 | 装于油槽内的热交换器，通入冷却水带走轴承因摩擦产生的热量，控制润滑油温。可能导致漏水或堵塞。 | 是 | 每季度检查冷却水进出口温差，判断换热效率；每年停机后对冷却器进行水压试验检查泄漏；清洗冷却水管路内的泥沙和水垢；冬季停机时排空冷却水防止冻裂。 | 冷却器管束出现多处泄漏无法补焊修复，管内严重结垢堵塞导致换热效率下降超过30%，管壁腐蚀减薄低于安全壁厚，承压能力不满足要求时应报废更换。 |
| 主轴密封 | 主轴 | 装于主轴穿过顶盖处，防止压力水从转动部件与固定部件之间的间隙沿主轴大量泄漏至厂房。 | 否 | 每月监测主轴密封漏水量，超过正常值时及时调整或更换密封件；每年停机后检查密封装置的整体结构完整性和弹簧预紧力；检查密封水供给系统是否正常；调整密封间隙至设计值。 | 密封装置整体变形或损坏导致漏水量严重超标且无法通过更换密封件修复，弹簧系统疲劳失效无法维持密封压力，密封腔体严重腐蚀影响安装精度时应报废更换整套密封装置。 |
| 密封环/盘根 | 主轴密封 | 与主轴直接接触的耐磨、自润滑密封材料，工作状态下轻微漏水以润滑和冷却，长期运行必然磨损导致漏水量增大。 | 是 | 每周目视检查密封处漏水情况，记录漏水量变化趋势；每季度调整密封压盖的压紧力，保持适度滴水润滑；每年停机后更换磨损的密封环或盘根；清理密封腔内杂质和结垢。 | 密封环磨损至无法通过调整压盖控制漏水量，盘根老化碎裂失去密封能力，密封材料硬化后划伤主轴表面，多次更换后仍无法维持正常密封时应报废更换。 |
| 喷嘴装配 | — | 冲击式水轮机中将压力水流的势能转换为高速射流动能，并冲击转轮水斗的装置。 | 否 | 每年停机后拆检喷嘴内部，检查喷针头和喷嘴口的磨损情况；测量喷针与喷嘴口的配合间隙；检查喷针接力器密封和动作灵活性；清洗喷管内部和滤水装置。 | 喷嘴体出现裂纹或严重变形，内部流道严重冲刷损坏影响射流质量，喷针与喷嘴口配合间隙过大无法修复，整体装配精度丧失时应报废更换。 |
| 喷针头 | 喷嘴装配 | 连接在喷针杆前端的锥形头，与喷嘴口配合形成环形过流面积，通过前后移动调节射流直径和流量。 | 是 | 每年停机后检查喷针头锥面的磨损和空蚀情况，测量型线偏差；对轻微磨损进行研磨修复，严重磨损时堆焊不锈钢后重新加工；运行中监测喷针位置和开度反馈信号。 | 喷针头锥面严重空蚀或磨损导致型线破坏，表面出现深坑或裂纹，经多次修复后尺寸超出公差范围，与喷嘴口配合间隙无法恢复至设计值时应报废更换。 |
| 喷嘴口 | 喷嘴装配 | 喷嘴末端的环形出口部件，与喷针头共同形成高速射流，其内孔型线和表面光洁度对效率影响极大，易受泥沙磨损。 | 是 | 每年停机后检查喷嘴口内孔的磨损、空蚀和表面粗糙度；测量内孔直径和圆度偏差；对磨损表面进行研磨抛光恢复光洁度；高泥沙电站应缩短检查周期。 | 喷嘴口内孔磨损导致射流发散、效率显著下降，表面出现深槽或裂纹无法研磨修复，内孔圆度偏差超标影响射流聚焦，经评估修复成本超过新件价值时应报废更换。 |
| 喷针接力器 | 喷嘴装配 | 内置于喷管中的液压缸活塞组件，自动操作喷针开启和关闭，响应调速器指令。其密封件为关键易损件。 | 否 | 每季度检查接力器动作是否灵活平稳，有无爬行和滞涩现象；每年测量接力器行程和响应时间；检查缸体内壁和活塞杆磨损情况；定期更换密封件。 | 接力器缸体严重磨损导致内泄增大，活塞杆弯曲或表面镀层大面积脱落，缸体出现裂纹，经大修后仍无法满足喷针调节精度和响应速度要求时应报废更换。 |
