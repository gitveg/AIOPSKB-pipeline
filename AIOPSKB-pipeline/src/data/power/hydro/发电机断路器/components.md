| 灭弧室总成 | — | 容纳触头系统并实现电弧熄灭的核心压力容器，内充SF6气体或真空介质。 | 否 | 定期检查灭弧室外观有无异常和漏气迹象，监测SF6气体压力/密度是否在正常范围，核对累计开断电流和操作次数，按厂家规定周期进行大修检查 | 累计开断电流达到厂家规定限值、SF6气体泄漏率严重超标、灭弧室内部严重烧损或污染 |
| 触头系统 | 灭弧室总成 | 包括静触头和动触头，承载和开断电流，是电弧产生和熄灭的直接部件。 | 是 | 在检修时测量触头行程、超行程和接触电阻，检查触头表面烧损程度（轻微烧蚀可修磨），核对合闸同期性，按厂家规定检查磨损量是否在允许范围内 | 触头烧损量超过厂家允许值、接触电阻严重超标且修磨无效、触头严重变形或熔焊 |
| 喷口 | 灭弧室总成 | 控制气流方向和速度，辅助电弧冷却和熄灭，通常由耐高温材料制成。 | 是 | 检修时检查喷口内表面有无严重烧蚀和碳化沉积物，测量喷口内径变化量，清除表面沉积物，核对尺寸是否在允许范围内 | 喷口内壁严重烧蚀导致内径超标、材料碳化碎裂、尺寸变化影响气流特性 |
| 均压电容 | 灭弧室总成 | 并联在断口间，改善电压分布，降低恢复电压上升率，防止重击穿。 | 否 | 定期测量电容量和介质损耗角正切值（tanδ），核对与初始值的变化（电容量偏差不超±5%），检查外观有无渗漏和裂纹 | 电容量偏差超过±10%、介质损耗严重超标、瓷套破裂或渗漏油、绝缘电阻不合格 |
| 合闸电阻 | 灭弧室总成 | 合闸时先接入以限制涌流和过电压，随后被辅助触头短接，保护设备绝缘。 | 是 | 定期测量电阻值并与出厂值比对，检查辅助触头动作时序，核对合闸电阻接入时间是否满足要求 | 电阻值偏差超过厂家允许范围、电阻片碎裂或烧损、辅助触头动作不协调 |
| 吸附剂 | 灭弧室总成 | 吸收SF6气体中的水分和电弧分解物，维持灭弧室内部干燥和洁净。 | 是 | 在灭弧室解体检修时检查吸附剂状态，按厂家规定或开断次数更换吸附剂（通常在灭弧室打开检修时更换），确保干燥剂密封保存至安装前 | 吸附剂严重粉化或变色失效、吸附容量饱和无法再吸收水分、灭弧室大修时必须更换 |
| 防爆膜 | 灭弧室总成 | 内部压力异常时破裂泄压，防止灭弧室壳体爆裂，为压力释放薄弱点。 | 是 | 定期外观检查防爆膜有无变形、裂纹和腐蚀痕迹，核对防爆膜刻痕方向和安装方向正确，严禁在防爆膜上施加外力 | 防爆膜出现裂纹或严重腐蚀（可能导致提前破裂）、变形影响泄压方向、到达厂家规定更换周期 |
| 绝缘外壳 | 灭弧室总成 | 提供对地及相间绝缘，承受机械应力和内部压力，材料通常为瓷或复合材料。 | 是 | 定期清扫绝缘外壳表面，检查有无裂纹、破损和放电痕迹，进行超声波探伤检查，测量外绝缘泄漏电流 | 外壳出现贯穿性裂纹、严重放电痕迹或碳化、绝缘耐压试验不合格、机械损伤影响承压能力 |
| 操作机构总成 | — | 提供断路器分合闸所需动力，并保持触头在规定位置，常见弹簧、液压或气动机构。 | 否 | 定期检查分合闸速度和时间特性，测量分合闸线圈电阻，加注润滑脂，检查弹簧储能状态或液压/气动压力，核对辅助开关切换时机，按操作次数进行大修 | 操作次数达到厂家规定的机械寿命、机构严重卡涩经大修仍无法消除、分合闸特性严重偏离标准值 |
| 分合闸线圈 | 操作机构总成 | 接收电气指令，触发机构动作，控制分闸或合闸过程。 | 是 | 定期测量线圈直流电阻并与初始值比对（偏差不超±5%），检查接线端子紧固性，测试动作电压（应在额定电压的65%-120%可靠动作） | 线圈电阻异常表明匝间短路或断线、动作电压严重偏移经调整仍不合格、线圈烧毁且无同型号替代 |
| 储能电机 | 操作机构总成 | 为弹簧机构储能，确保随时具备操作所需能量。 | 是 | 定期检查电机运转声音和碳刷磨损情况，测量电机绝缘电阻，检查传动链条/齿轮状态，核对储能时间（应在规定时间内完成储能） | 电机绕组烧毁、碳刷严重磨损且无法更换、储能时间严重超标、绝缘电阻持续下降 |
| 传动连杆 | 操作机构总成 | 将机构输出力传递至灭弧室动触头，实现同步运动。 | 否 | 定期检查连杆有无变形和裂纹，检查销轴和轴套磨损情况，加注润滑脂，核对传动灵活性和同步性 | 连杆严重变形或出现裂纹、销轴严重磨损导致间隙过大影响传动精度、多次调整仍无法保证同步 |
| 辅助开关 | 操作机构总成 | 反映断路器分合位置，提供电气联锁和信号指示。 | 是 | 定期检查辅助开关切换时机与断路器分合闸位置对应正确性，测量触点接触电阻，检查接线可靠性 | 触点严重烧蚀导致接触不良或信号丢失、切换时机严重偏移、机械传动件损坏 |
| 极限开关 | 操作机构总成 | 限制机构运动范围，防止过度储能或行程超限。 | 是 | 定期检查极限开关安装位置和动作可靠性，核对限位精度，检查触点状态和接线 | 开关失灵导致储能电机过储能或行程超限、触点严重氧化接触不良、机械件损坏无法调整 |
| 计数器 | 操作机构总成 | 机械或电子式记录分合闸操作次数，辅助制定维护计划。 | 否 | 定期核对计数器指示值与实际操作记录一致，检查计数器动作是否可靠，清洁表面积灰 | 计数功能失效无法正确记录操作次数、表盘损坏无法读取、电子式计数器显示异常 |
| 控制及监视单元 | — | 包含继保接口、SF6密度监视、分合闸控制回路等，实现断路器的智能控制和状态感知。 | 否 | 定期检查控制回路完好性，核对SF6密度监视报警和闭锁定值，测试防跳和非全相保护逻辑，检查加热驱潮装置，清扫汇控柜内部 | 控制回路严重故障导致断路器无法正常操作、SF6监视功能完全丧失、汇控柜严重损坏 |
| SF6密度继电器 | 控制及监视单元 | 实时监测灭弧室内气体密度，发出补气或闭锁信号。 | 是 | 每年校验密度继电器报警和闭锁定值（送有资质机构），检查温度补偿功能正确性，核对指示值与实际压力，检查接线端子 | 定值严重偏移经校验仍不合格、温度补偿功能失效、指针卡死或指示异常 |
| 控制电路板 | 控制及监视单元 | 处理指令和状态信号，管理防跳、三相不一致等逻辑。 | 否 | 定期检查电路板有无过热和虚焊迹象，核对防跳和非全相保护逻辑参数，检查板卡接插件接触可靠性，除尘处理 | 电路板严重烧损或核心芯片损坏、逻辑功能异常且无法通过更换芯片修复、厂家停产无备件 |
| 汇控柜 | 控制及监视单元 | 集中安装控制、监视和保护元件的金属柜体，防护现场环境影响。 | 否 | 定期检查柜体密封性和门锁完好性，清扫内部灰尘，检查接线端子和走线整齐性，核对柜内温湿度，检查接地连接 | 柜体严重锈蚀变形影响防护等级、内壁严重腐蚀、经事故后结构强度不足 |
| 机构箱加热器 | 控制及监视单元 | 安装在机构箱或汇控柜内，驱除潮气，防止凝露导致绝缘下降或元件锈蚀。 | 是 | 定期检查加热器工作状态和表面温度，核对温控器整定值，检查绝缘电阻，清扫表面积灰，检查电源线和接线端子 | 加热丝烧断无法加热、绝缘电阻下降有漏电风险、温控器失灵导致持续加热或无法启动 |
| 绝缘子 | — | 支撑灭弧室和导电部分，提供对地绝缘，承受机械载荷。 | 是 | 定期清扫绝缘子表面，检查有无裂纹、破损和放电痕迹，测量绝缘电阻和泄漏电流，进行超声波或紫外检测 | 绝缘子出现贯穿性裂纹、严重放电碳化痕迹、绝缘电阻持续不合格、机械破损影响承载能力 |
| 导电回路 | — | 包括主回路接线端子、软连接等，承载额定电流和短时耐受电流。 | 否 | 定期用红外热像仪监测导电回路温度分布，测量回路电阻，检查端子紧固力矩，核对温升是否在允许范围内 | 回路电阻严重超标、端子严重烧损、多处发热且紧固处理无效 |
| 软连接 | 导电回路 | 补偿触头行程位移，确保动静触头间可靠电连接，柔韧性承受反复弯折。 | 是 | 定期检查软连接有无断股和疲劳裂纹，测量接触电阻，检查两端紧固状态，核对有无变色发热迹象 | 软连接断股超过规定比例、严重变色氧化、接触电阻超标、失去柔韧性出现明显裂纹 |
| 主接线端子 | 导电回路 | 断路器进出线连接点，承受电气和机械应力，接触面需防氧化。 | 否 | 定期检查端子接触面有无氧化和变色，用扭矩扳手紧固连接螺栓，测量接触电阻，清理接触面并涂抹导电膏 | 端子严重烧损变色、螺纹损坏无法达到规定紧固力矩、接触面严重氧化且处理后仍发热 |
| 气动/液压管路 | — | 输送高压气体或液压油至操作机构，含阀组、接头和蓄压器。 | 否 | 定期检查管路有无泄漏和腐蚀，核对工作压力是否在正常范围，检查各接头和密封件状态，监测蓄压器预充氮气压力 | 管路多处泄漏无法修复、严重锈蚀影响承压安全、接头损坏无法密封 |
| 高压阀组 | 气动/液压管路 | 控制气流或液流方向，实现快速分合闸，内部密封件易老化。 | 是 | 定期检查阀组动作灵活性和密封性，测量阀芯和阀座磨损量，更换老化密封件，校验压力设定值 | 阀芯严重磨损导致内漏、密封件老化严重无法密封、阀体出现裂纹、动作响应时间严重超标 |
| 滤网 | 气动/液压管路 | 过滤介质中杂质和水分，保持操作机构清洁运行。 | 是 | 定期清洗或更换滤芯，检查滤网前后压差，核对介质清洁度，检查滤网壳体有无损坏和泄漏 | 滤网严重堵塞影响系统工作、滤材破损失去过滤功能、壳体损坏泄漏 |
| 蓄压器 | 气动/液压管路 | 储存液压能量，补偿压力波动，确保操作压力稳定。 | 否 | 定期检查蓄压器外观有无渗漏和变形，核对预充氮气压力（按厂家规定周期检查），测量液压油位，检查连接管路密封性 | 蓄压器皮囊破裂导致无法保压、壳体严重变形或锈蚀、预充压力持续下降表明内漏 |
