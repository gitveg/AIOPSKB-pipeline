| 测温模块 | 测温制动屏 | 采集各测点温度传感器信号，进行放大、滤波和模数转换，实现多通道温度实时监测与报警判断。 | 否 | 定期校准各通道测量精度，比对标准温度源检查偏差；清洁模块电路板表面灰尘，检查接插件接触状态；每年进行通道一致性测试，超差通道应及时调整或更换元件。 | 模块出现多通道损坏无法修复，或核心芯片失效且无备件供应，或经校验精度超出允许范围且无法调校恢复时，整块模块报废更换。 |
| 温度传感器 | 测温模块 | 通常为铂热电阻或热电偶，直接接触被测部位（如轴瓦、定子），将温度转换为电阻或毫伏信号。 | 是 | 定期检查传感器外观有无机械损伤、引线有无折断；每半年用标准温度源校验测量精度，偏差超过允许值应更换；检查传感器安装位置是否松动，确保与被测部位良好接触；注意防水密封，防止接线盒进水受潮。 | 传感器元件断路或短路无法修复，校验偏差超出允许范围且无法修正，引线严重老化破损，或感温元件响应特性严重退化时，整支传感器报废更换。 |
| 信号变送器 | 测温模块 | 将温度传感器的微小信号转换为标准的4-20mA电流或0-10V电压信号，便于远传与处理。 | 否 | 定期校验变送器输出线性度和零点漂移，用标准信号源检查输入输出对应关系；检查接线端子是否氧化松动；清洁外壳和散热部位；每年进行一次全面精度校准。 | 输出信号严重漂移超出可调范围，内部电路板损坏无法维修，或多次校准仍无法恢复精度时报废更换。 |
| 报警输出继电器 | 测温模块 | 根据报警逻辑驱动外部声光报警装置，提供干接点信号，触点频繁动作易烧蚀。 | 是 | 定期检查继电器动作是否可靠，触点有无烧蚀、氧化或粘连；测量触点接触电阻，超标时更换；检查线圈绝缘电阻是否满足要求；在大修期间进行动作次数统计，接近寿命上限时预防性更换。 | 触点严重烧蚀导致接触不良或粘连无法修复，线圈断路或绝缘击穿，或机械寿命已达到额定动作次数时报废更换。 |
| 制动控制模块 | 测温制动屏 | 接收停机指令和转速信号，按预设逻辑控制制动系统投入与退出，完成机组制动。 | 否 | 定期检查控制逻辑是否正确执行，模拟停机信号验证制动投入与退出时序；检查输入输出信号通道是否正常；核对制动参数设置，确保与设计值一致；清洁模块内部及连接器，检查有无虚焊或过热痕迹。 | 控制逻辑出现紊乱且软件无法恢复，核心处理器或存储器损坏无法更换，或模块整体性能退化经多次维修仍不满足制动安全要求时报废。 |
| 制动接触器/继电器 | 制动控制模块 | 控制制动电磁阀或电机电源的通断，实现制动力矩的施加与释放，频繁动作易导致触头磨损。 | 是 | 定期检查触头表面有无烧蚀、磨损或氧化，轻微烧蚀可用细砂纸打磨修复；检查灭弧装置是否完好；测量吸合与释放电压是否在正常范围；统计动作次数，接近机械寿命时预防性更换；检查线圈温升是否异常。 | 触头严重磨损烧蚀无法修复导致接触不良或粘连，线圈烧毁或绝缘老化，机械机构卡涩无法调整，或累计动作次数达到额定寿命时报废更换。 |
| 制动逻辑控制器 | 制动控制模块 | 通常为小型PLC或嵌入式控制器，执行制动联锁逻辑、延时控制，确保可靠制动。 | 否 | 定期检查控制器运行状态指示灯，核对程序版本；检查各I/O通道响应是否正常；备份控制程序和参数设置；检查通信接口数据交换是否正常；每两年对控制器电池进行更换（如有），防止程序丢失。 | 控制器硬件故障无法修复（如CPU损坏、存储器失效），程序无法正常运行且无法重新烧录，或设备停产无备件来源时报废更换。 |
| 人机接口模块 | 测温制动屏 | 提供现场数据显示、参数设置、手自动操作及故障指示功能，包含显示屏与输入设备。 | 否 | 定期检查显示屏显示是否清晰完整，有无缺划、花屏现象；检查各按键和操作元件响应是否灵敏；清洁显示屏表面和操作面板；检查面板密封是否良好，防止灰尘和水汽侵入；每年验证声光报警功能是否正常。 | 显示功能严重退化无法正常读数，操作面板多数按键失灵，接口电路损坏无法修复，或模块整体老化经更换主要部件后仍不满足使用要求时报废。 |
| 显示屏 | 人机接口模块 | LCD或LED显示各通道温度、制动状态及报警信息，背光及液晶材料随使用时长老化。 | 是 | 定期检查显示亮度和对比度，调整至最佳可视状态；检查有无坏点、缺划或闪烁现象；清洁屏幕表面，避免使用有机溶剂；检查背光灯管或LED背光是否均匀；运行中避免长时间显示同一静态画面以防烧屏。 | 屏幕出现大面积坏点、严重缺划导致无法读取数据，背光完全失效无法更换，或液晶材料老化导致对比度极差无法辨认显示内容时报废更换。 |
| 操作按钮/指示灯 | 人机接口模块 | 完成手/自动切换、复位、紧急操作等功能，并指示运行、故障状态，机械及发光元件为易损点。 | 是 | 定期检查按钮操作手感是否正常，有无卡涩或失灵；检查指示灯亮度是否正常，有无闪烁或不亮；对紧急操作按钮进行定期功能测试，确保关键时刻可靠动作；清洁按钮周围灰尘，防止积尘导致接触不良。 | 按钮机械结构损坏导致无法操作或误动作，触点严重氧化导致接触不良，指示灯烧毁或灯座损坏无法修复，或多个元件同时失效影响安全操作时报废更换。 |
| 电源模块 | 测温制动屏 | 为屏内各部件提供所需的直流24V、5V等稳定工作电源，具有滤波和隔离功能。 | 否 | 定期测量各路输出电压是否在允许偏差范围内，用示波器检查输出纹波是否合格；检查模块散热是否良好，温升是否正常；检查输入端接线是否牢固；每年进行一次电源容量和负载能力测试；大修期间对电源进行预防性更换（按运行年限）。 | 输出电压严重偏差超出可调范围且伴随纹波增大，电源调整管或变换器损坏无法修复，多次出现故障影响屏柜正常运行，或运行年限超过设计寿命时报废更换。 |
| 电源滤波器 | 电源模块 | 抑制来自电网的传导干扰，保证电源品质，内部电容元件会随环境老化。 | 否 | 定期检查滤波器外观有无鼓包、漏液或异味；测量共模和差模抑制比是否符合技术指标；检查接线端子有无过热变色痕迹；每两年进行一次绝缘电阻测试，确认电容和电感元件性能正常。 | 内部电容元件鼓包漏液导致滤波功能失效，电感线圈短路或断路，外壳破损影响安全防护，或经测试滤波性能严重退化无法满足电磁兼容要求时报废更换。 |
| 保险丝/断路器 | 电源模块 | 提供短路和过载保护，故障时熔断或跳脱，属于一次性保护器件。 | 是 | 定期检查保险丝座有无氧化、松动或过热痕迹；核对保险丝熔体额定值是否与设计一致，严禁随意加大规格；检查断路器操作机构是否灵活，有无卡涩；大修期间校验断路器保护动作值是否准确。 | 保险丝熔断后查明故障原因并排除，更换同规格新品，原熔断件报废；断路器多次跳闸后机构磨损导致动作不可靠，或经校验保护特性偏离标准值无法调整时报废更换。 |
| 电源防雷器 | 电源模块 | 并联在电源进线，将雷击浪涌电流泄放入地，保护后级设备，核心元件劣化后需更换。 | 是 | 每年雷雨季节前检查防雷器状态指示窗口是否变红（劣化指示）；测量接地电阻是否满足要求；检查接线端子是否紧固；雷击事件后立即检查防雷器状态，必要时更换；定期用防雷器测试仪检测残压和漏电流。 | 状态指示窗口显示红色（已劣化），或经测试漏电流超标、残压升高不满足保护要求，或经历严重雷击事件后芯体损坏时，将防雷器芯体或模块报废更换。 |
| 通信模块 | 测温制动屏 | 通过现场总线或以太网与电厂监控系统交换数据，实现远程监视和控制。 | 否 | 定期检查通信链路是否稳定，统计通信中断和误码率；检查模块运行状态指示灯是否正常；定期测试与监控系统的数据交换功能，验证遥测、遥信数据准确性；检查通信线缆屏蔽和接地是否良好；每年进行通信协议一致性测试。 | 通信模块硬件损坏无法修复，通信芯片失效且无备件，或通信协议版本与监控系统不兼容且无法升级时报废更换。 |
| 通信接口板 | 通信模块 | 实现RS485、ProfiBus或Modbus TCP等协议转换，包含隔离元件和防雷器件。 | 否 | 定期检查接口板各通道通信是否正常，数据传输有无丢帧或错误；检查板卡与底板的插接是否可靠；检查板卡表面有无过热或烧蚀痕迹；定期测试隔离元件的绝缘性能；防雷器件劣化指示变色时及时更换。 | 接口板多通道损坏无法修复，核心通信芯片烧毁，隔离变压器或光耦损坏导致通信中断且无法局部更换，或板卡整体老化频繁故障时报废更换。 |
| 柜体及附件 | 测温制动屏 | 提供物理防护、屏蔽、散热及布线支撑，通常为冷轧钢板喷塑结构。 | 否 | 定期检查柜体外观有无锈蚀、变形或漆面脱落，及时除锈补漆；检查柜门密封条是否老化破损；检查接地连接是否可靠；检查柜体安装螺栓有无松动；每年进行一次柜内全面清洁和布线整理。 | 柜体严重锈蚀穿孔导致防护等级不满足要求，结构变形影响柜门正常开合或内部设备安装，或经评估修复成本超过新柜体造价时报废更换。 |
