| 高压开关柜 | — | 用于接收和分配电能的金属封闭开关设备，集成断路器、隔离开关、互感器、保护装置等，实现线路控制、保护和测量功能。 | 否 | 定期检查开关柜外观有无变形、锈蚀和漆层脱落；每年进行柜内清洁和除尘；大修时全面检查各功能单元状态，进行绝缘电阻测量和工频耐压试验；检查各操作机构和联锁装置动作可靠性；核对保护定值。 | 开关柜整体严重老化锈蚀；绝缘水平严重下降且无法通过检修恢复；主要功能部件大面积损坏修复费用接近更换成本；技术升级改造方案经论证更为合理时，经技术鉴定可整体报废更换。 |
| 柜体 | 高压开关柜 | 金属封闭外壳，提供各功能单元的安装支撑、防护及隔离，具备IP防护等级和内部燃弧耐受能力。 | 否 | 定期检查柜体外观有无变形、锈蚀和渗水痕迹；每年检查柜门密封条和铰链锁具是否完好；大修时检查柜体接地连接和门接地编织线是否可靠；检查各隔室之间隔离板完好性；检查柜内照明是否正常。 | 柜体严重变形或锈蚀穿孔影响防护等级；门密封结构严重损坏导致无法有效隔离；内部燃弧耐受能力因结构老化而降低；修复费用接近更换成本时，应更换柜体或评估整柜报废。 |
| 断路器 | 高压开关柜 | 能在正常和故障条件下接通、承载和开断电流的核心开关设备，是线路保护的主要执行元件。 | 否 | 定期检查断路器动作次数和累计开断电流是否在允许范围内；每年进行机械特性试验（合分闸时间、速度、行程和同期性）；大修时检查触头烧损状况、灭弧室性能和操作机构状态；进行绝缘试验和回路电阻测量。 | 断路器累计开断次数或开断电流达到厂家规定寿命；机械特性严重劣化且无法通过检修恢复；绝缘水平严重下降；主要部件损坏且无备件可更换时，应报废更换断路器。 |
| 真空灭弧室 | 断路器 | 利用真空作为绝缘和灭弧介质，在触头分离时熄灭电弧的密封管状元件。 | 否 | 定期进行真空度检测（通常采用工频耐压法或磁控法）；大修时检查灭弧室外壳有无裂纹、变色和放电痕迹；测量触头烧损量和超行程；进行绝缘耐压试验。 | 真空度严重下降导致绝缘和灭弧能力不足；外壳出现裂纹或破损导致真空丧失；触头烧损量超过允许限值；绝缘耐压试验不合格时，应更换真空灭弧室。 |
| SF6灭弧室 | 断路器 | 利用SF6气体作为绝缘和灭弧介质，在触头分离时通过气吹熄灭电弧的密封元件。 | 否 | 定期监测SF6气体压力和密度是否在正常范围；每年检测气体微水含量和分解产物；大修时检查灭弧室内部触头和喷口烧损状况；进行气体泄漏检测；校验密度继电器。 | SF6气体严重泄漏无法维持额定压力；触头严重烧损超出允许范围；喷口烧蚀导致灭弧能力下降；气体质量严重劣化且净化处理无效时，应更换SF6灭弧室或整台断路器。 |
| 断路器触头 | 断路器 | 在合闸时接通电路、分闸时分离并承受电弧烧灼的导电触点组件。 | 是 | 定期测量触头接触电阻是否在允许范围内；大修时检查触头表面烧蚀程度和磨损量；检查触头弹簧压力是否正常；测量超行程和开距是否满足要求；轻微烧蚀时可用细砂纸打磨修复。 | 触头烧损量超过厂家规定允许值；表面严重烧蚀出现大面积熔焊痕迹；接触电阻持续增大且无法通过打磨恢复；触头合金层脱落或变形时，应更换断路器触头。 |
| 操作机构 | 断路器 | 驱动断路器合闸和分闸的机械传动机构，包括弹簧、连杆、锁扣和缓冲器等。 | 否 | 定期检查操作机构动作是否灵活可靠，有无卡涩和异常声响；每年进行机械特性试验；大修时检查弹簧疲劳状态、各铰接点磨损和润滑状况；检查合分闸线圈和脱扣机构；检查缓冲器性能。 | 操作机构频繁出现拒合、拒分或误动；弹簧严重疲劳导致操作速度下降；关键传动部件严重磨损或变形；经多次检修后机械特性仍不合格时，应更换操作机构或断路器。 |
| 合分闸线圈 | 操作机构 | 接收控制指令产生电磁力驱动脱扣机构动作的电磁线圈。 | 是 | 定期测量线圈电阻值是否在允许范围内；大修时检查线圈绝缘电阻和铁芯动作灵活性；测试线圈在最低操作电压下的可靠动作性能；检查接线端子紧固状态。 | 线圈断路或短路；绝缘电阻严重下降导致接地或匝间短路；铁芯卡涩导致动作不可靠；在最低操作电压下无法可靠动作时，应更换合分闸线圈。 |
| 储能弹簧 | 操作机构 | 储存合闸或分闸能量的螺旋弹簧或碟簧组件，释放时驱动断路器快速动作。 | 是 | 定期检查储能指示器和储能电机工作是否正常；大修时检查弹簧自由高度和刚度有无变化；检查弹簧表面有无锈蚀和裂纹；测量储能时间和操作速度是否在允许范围内。 | 弹簧断裂导致机构无法正常储能和操作；自由高度显著减小或刚度严重下降导致操作速度不合格；表面出现裂纹或严重锈蚀；经检测疲劳寿命接近厂家规定极限时，应更换储能弹簧。 |
| 隔离开关 | 高压开关柜 | 在无负荷电流条件下隔离电源、建立明显断点的开关设备，配合断路器实现检修隔离。 | 否 | 定期检查隔离开关操作是否灵活，有无卡涩和不到位现象；大修时检查触头和刀闸有无氧化、变色和过热痕迹；测量接触电阻；检查绝缘子和操作拉杆状态；验证与断路器的联锁功能。 | 刀闸或触头严重氧化烧损导致接触不良；绝缘子出现裂纹或放电烧伤；操作机构严重损坏无法可靠操作；接触电阻持续增大引起过热且无法修复时，应更换隔离开关。 |
| 接地开关 | 高压开关柜 | 在检修时将设备可靠接地的开关装置，与隔离开关和柜门实现安全联锁。 | 否 | 定期检查接地开关操作是否灵活，合闸后接触是否良好；大修时检查触头有无烧蚀和磨损；测量接地回路电阻；验证与隔离开关和柜门的联锁功能是否可靠；检查操作机构和传动连杆。 | 触头严重烧蚀导致接地不可靠；操作机构损坏导致无法正常合分；联锁机构失效存在安全隐患；接地回路电阻超标且无法修复时，应更换接地开关。 |
| 电流互感器(CT) | 高压开关柜 | 将一次侧大电流按比例转换为二次侧小电流，供测量和保护装置使用。 | 否 | 定期检查互感器外观有无裂纹、渗漏和放电痕迹；大修时测量绕组直流电阻、绝缘电阻和介质损耗因数；进行变比和极性校验；检查二次回路接线是否可靠；确保运行中二次侧不得开路。 | 互感器绝缘电阻严重下降或介质损耗因数严重超标；绕组断路或短路；铁芯饱和导致变比误差超出精度等级要求；外观出现裂纹或渗漏时，应更换电流互感器。 |
| 电压互感器(PT) | 高压开关柜 | 将一次侧高电压按比例转换为二次侧低电压，供测量和保护装置使用。 | 否 | 定期检查互感器外观有无异常；大修时测量绕组绝缘电阻和介质损耗因数；进行变比和极性校验；检查熔断器是否完好；检查二次回路接线和熔丝状态；确保运行中二次侧不得短路。 | 互感器绝缘电阻严重下降或介质损耗因数严重超标；绕组烧毁或断路；变比误差超出精度等级要求；铁磁谐振导致内部损伤时，应更换电压互感器。 |
| 避雷器 | 高压开关柜 | 限制操作过电压和雷电过电压幅值，保护柜内设备绝缘免受过电压损害。 | 否 | 定期检查避雷器外观有无破裂、闪络和计数器动作记录；每年测量绝缘电阻和直流参考电压下的泄漏电流；大修时进行交流参考电压测试和阻性电流测量；检查接地引下线连接是否可靠。 | 避雷器绝缘电阻严重下降；直流参考电压下泄漏电流显著增大超过规定值；外观出现裂纹或防爆片动作；阻性电流持续增大表明阀片老化时，应更换避雷器。 |
| 继电保护装置 | 高压开关柜 | 检测电力系统故障并发出跳闸指令，切除故障元件的保护设备。 | 否 | 定期检查保护装置运行状态指示灯和自检报告是否正常；每年进行保护定值校验和整组传动试验；大修时进行全面功能测试，校验各项保护逻辑和动作时间；备份保护定值和动作记录。 | 保护装置核心板损坏且无法修复；程序存储器损坏且无备份可恢复；多次发生保护拒动或误动且原因在装置本身；厂商已停产且无兼容替代品时，应更换继电保护装置。 |
| 带电显示器 | 高压开关柜 | 显示开关柜内高压导体带电状态的指示装置，配合接地开关联锁确保操作安全。 | 是 | 定期检查带电显示器指示是否与实际带电状态一致；大修时校验显示器的感应电压和指示灯亮度；检查传感器安装和接线状态；验证与接地开关的联锁功能。 | 显示器指示灯全部损坏无法显示带电状态；传感器失效导致指示与实际带电状态不一致；联锁接点损坏导致安全联锁失效；校验不合格且无法修复时，应更换带电显示器。 |
| 加热除湿装置 | 高压开关柜 | 防止柜内因温度变化产生凝露导致绝缘下降的加热器和温湿度控制器。 | 是 | 定期检查加热器工作是否正常，柜内温湿度是否在控制范围内；每月检查温湿度控制器设定值和动作是否准确；大修时检查加热器电阻值和绝缘电阻；清洁加热器表面污垢。 | 加热器电阻丝断路不发热；温湿度控制器损坏无法自动控制加热；加热功率严重衰减无法有效防潮；绝缘电阻下降存在安全隐患时，应更换加热除湿装置。 |
| 母线及连接件 | 高压开关柜 | 各功能单元之间及与外部电路连接的载流母线排和连接紧固件。 | 否 | 定期利用红外测温检查母线连接点温度是否异常；大修时检查母线表面有无氧化、变色和过热痕迹；测量主回路电阻；检查连接螺栓紧固力矩；检查绝缘护套和相间隔离板状态。 | 母线严重氧化或过热烧损导致载流能力下降；连接螺栓因过热反复松动无法紧固；绝缘护套老化开裂失去绝缘保护作用；载流截面因烧蚀显著减小时，应更换母线及连接件。 |
| 绝缘件 | 高压开关柜 | 包括绝缘隔板、绝缘套管、支撑绝缘子等，实现带电体之间及对地的绝缘隔离。 | 否 | 定期检查绝缘件表面有无裂纹、放电痕迹和积污；大修时进行绝缘电阻测量和耐压试验；清洁绝缘件表面污秽；检查绝缘件有无老化和变形。 | 绝缘件出现贯通性裂纹；表面严重放电烧伤；绝缘电阻或耐压试验不合格；老化导致绝缘性能显著下降时，应更换绝缘件。 |
| 二次接线端子排 | 高压开关柜 | 连接控制、保护、测量等二次回路导线的接线端子，实现柜内外信号传输。 | 是 | 定期检查端子排接线是否紧固可靠，有无松动和过热变色；大修时逐一检查端子接线状态，拧紧松动的螺钉；检查端子排有无腐蚀和绝缘老化；检查接线标识是否清晰完整。 | 端子排绝缘老化导致端子间爬电或短路；多个端子因过热烧毁变形；端子排整体腐蚀严重导致接触不可靠；修复工作量大且费用接近更换成本时，应更换二次接线端子排。 |
| 联锁机构 | 高压开关柜 | 实现断路器、隔离开关、接地开关和柜门之间的安全操作联锁，防止误操作。 | 否 | 定期检查各联锁机构动作是否灵活可靠，验证联锁逻辑是否正确（防止带负荷操作隔离开关、防止带电合接地开关、防止接地合闸送电等）；大修时检查联锁板、锁销和传动部件磨损状况；润滑活动部位。 | 联锁机构严重变形或损坏导致联锁功能失效；关键锁销和联锁板断裂或严重磨损；经检修后仍无法可靠实现安全联锁存在误操作风险时，应更换联锁机构。 |
