| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 主控机箱 | — | 装置的主体结构，提供物理支撑、电磁屏蔽及内部总线接口，承载所有核心模件。 | 否 | 每年检查机箱外观有无变形锈蚀，紧固各安装螺栓，清洁散热通风孔，核实电磁屏蔽密封条完好性 | 机箱严重变形影响模件安装、屏蔽性能丧失或多次出现结构性故障时整箱报废 |
| 电源模件 | 主控机箱 | 将外部交流/直流电源转换为装置内部所需的多路低压直流电，支持冗余配置，含输入滤波与保护电路。 | 是 | 每季度检查输出电压是否在允许范围内，监测纹波系数，检查冗余切换功能是否正常 | 输出电压持续超差、纹波过大或冗余切换失效且无法修复时更换模件 |
| 主处理器模件 | 主控机箱 | 执行稳定控制策略判据、逻辑运算和系统调度，集成高性能CPU、内存、存储及看门狗电路。 | 否 | 每年核对定值参数完整性，检查程序版本一致性，测试看门狗复位功能，监测CPU温度 | 处理器频繁死机复位、存储器数据丢失或芯片损坏导致控制策略无法执行时更换模件 |
| 模拟量输入模件 | 主控机箱 | 采集来自电压/电流互感器的模拟信号，经隔离、滤波、采样后转换为数字量供主处理器使用。 | 是 | 每季度加注标准信号校验各通道精度，检查零点漂移，核实隔离性能 | 采样精度超差、通道损坏或隔离击穿导致误采样时更换模件 |
| 开关量输入模件 | 主控机箱 | 采集站内断路器、刀闸等位置信号以及外部硬接点告警信号，进行光电隔离和去抖处理。 | 否 | 每半年检查各通道光电隔离完好性，测试动作门槛电压，核实去抖时间设置 | 光耦击穿、通道误报或拒报导致状态量丢失时更换模件 |
| 出口继电器模件 | 主控机箱 | 根据控制策略输出跳闸、合闸或切机命令，采用多级防误动设计，包含大容量继电器及动作指示。 | 是 | 每季度测试各出口继电器动作可靠性，检查触点接触电阻，核实防误动逻辑 | 继电器触点严重烧蚀粘连、动作不可靠或防误动功能失效时更换模件 |
| 通信接口模件 | 主控机箱 | 实现与站内监控系统、远方调度中心及其他稳控装置之间的数据交换，支持多种规约和物理接口。 | 否 | 每季度检查各通信端口数据收发是否正常，监测通信误码率，核实规约配置参数 | 通信端口硬件损坏、规约无法适配或通信频繁中断且排除外部原因时更换模件 |
| 人机界面模件 | 主控机箱 | 提供液晶显示屏、按键或触摸屏，用于本地参数设置、状态查看和事件记录调阅。 | 是 | 每半年检查显示清晰度、按键/触控响应灵敏度，核实操作权限设置 | 显示严重老化影响读数、触控大面积失灵或按键全部卡死时更换模件 |
| 背板总线模件 | 主控机箱 | 集成于机箱背板的无源高速并行总线，为各功能模件提供标准的电气与信号连接通道。 | 否 | 每年停电检修时检查背板印制线有无断路短路，清洁插槽接点，核实各模件插入到位 | 背板总线印制线烧损、插槽严重氧化变形或多次出现总线通信异常时更换 |
| 散热风扇组件 | 主控机箱 | 装于机箱内或箱体上的轴流风扇，强制风冷以维持装置内部温度在允许范围。 | 是 | 每季度清洁扇叶及防护网灰尘，检查轴承运转有无异响，测试风扇转速是否正常 | 风扇转速显著下降、轴承严重磨损异响或完全停转时更换风扇组件 |
| 电源输入滤波器 | 电源模件 | 抑制从交流电网传入的共模和差模干扰，保护后级电路。 | 是 | 每半年检查滤波器外观有无鼓包漏液，测试共模和差模抑制比是否满足要求 | 滤波电容鼓包漏液、抑制性能显著下降或出现短路时更换滤波器 |
| DC/DC变换器 | 电源模件 | 高频开关电源转换核心，实现电压隔离、稳压输出，含功率管、变压器及整流滤波环节。 | 是 | 每季度检查各路输出电压精度及纹波，测试负载调整率，检查功率管散热情况 | 输出电压持续超差、功率管损坏或变压器异常发热时更换变换器 |
| 出口压板 | 出口继电器模件 | 连接在跳闸回路中的可断开式连接片，便于在检修时解开保护出口与跳闸线圈的电气联系。 | 否 | 每次操作前后检查压板接触可靠性，核实投入/退出状态标识与实际一致 | 压板严重氧化变色、连接片断裂或螺纹滑丝无法紧固时更换 |
| 跳闸保持线圈 | 出口继电器模件 | 提供继电器动作自保持功能，确保在接点抖动或短暂命令下可靠完成跳闸过程。 | 是 | 每半年测试线圈直流电阻和绝缘电阻，验证自保持功能可靠性 | 线圈断线、绝缘电阻低于允许值或自保持功能失效时更换线圈 |
| 信号继电器 | 出口继电器模件 | 通过机械掉牌或LED显示特定保护出口动作状态，辅助故障与动作行为分析。 | 是 | 每季度测试信号继电器动作可靠性，检查指示显示是否清晰准确 | 掉牌机构卡涩、LED显示故障或触点严重氧化导致信号丢失时更换 |
| 交流采样插件 | 模拟量输入模件 | 包含精密电压/电流变换器、低通滤波器和A/D转换器，将二次侧额定信号转换为数字信号。 | 是 | 每季度注入标准工频信号校验幅值精度和相位精度，检查A/D转换线性度 | 精度超差无法校准、变换器损坏或A/D芯片故障时更换插件 |
| 光电耦合器 | 开关量输入模件 | 利用光信号实现电气隔离，将强电开入信号转换为弱电数字电平供CPU读取。 | 是 | 每半年测试传输比和隔离耐压，检查响应时间是否正常 | 传输比严重下降、隔离击穿或响应迟缓导致信号丢失时更换光耦 |
| 液晶显示屏背光灯管 | 人机界面模件 | 为液晶显示提供背光光源，常为冷阴极荧光灯管或LED灯条，长期点亮后亮度衰减。 | 是 | 每半年检查背光亮度均匀性，发现亮度明显衰减时及时调整或准备备件 | 背光灯管严重发黑、亮度低于可读阈值或LED灯条大面积失效时更换 |
