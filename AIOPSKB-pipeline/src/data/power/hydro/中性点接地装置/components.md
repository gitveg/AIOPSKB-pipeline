| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|---|---|---|---|---|---|
| 接地变压器 | — | 为中性点不接地系统引出人工中性点，提供接地电流回路，可带二次绕组供站用负荷 | 否 | 每年测量接地变压器绝缘电阻和直流电阻；检查油浸式的油位和油色（如适用）；定期检查接线端子有无过热和氧化；测量中性点位移电压是否在正常范围。 | 绝缘电阻严重下降且干燥处理后仍不达标，绕组直流电阻不平衡率超过2%，油浸式内部严重受潮或油质劣化，铁芯或绕组出现不可修复的故障时应报废更换。 |
| 消弧线圈 | — | 通过电感电流补偿接地故障时的电容电流，使故障点电弧自行熄灭，防止间歇性弧光过电压 | 否 | 每年测量消弧线圈各分接位置的直流电阻和电感值；检查油浸式的油位和油质；检查线圈外观有无过热变色和放电痕迹；定期进行实际接地试验验证补偿效果。 | 线圈匝间短路导致电感值严重偏离设计值，铁芯严重损坏影响导磁性能，油浸式内部绝缘严重劣化，补偿电流无法满足系统电容电流要求时应报废更换。 |
| 自动跟踪控制器 | — | 实时测量系统电容电流，在线调节消弧线圈电感量，使补偿度保持在设定范围，并记录故障信息 | 否 | 每年校验控制器的测量精度和调节响应时间；检查各设定参数是否正确；模拟接地故障测试控制器动作逻辑；检查通讯功能和人机界面是否正常；备份运行参数和故障记录。 | 控制器CPU或核心电路故障导致无法正常工作，测量精度严重偏差且无法校准，多次维修后仍频繁死机或误动，功能丧失无法满足自动跟踪补偿要求时应报废更换。 |
| 阻尼电阻箱 | — | 限制消弧线圈补偿后残余的有功分量及谐振过电压，防止中性点位移电压过高 | 否 | 每季度检查电阻箱外观有无过热变色和放电痕迹；每年测量阻尼电阻值是否在允许偏差范围内；检查箱体密封和通风散热情况；检查投切接触器的动作可靠性。 | 电阻元件烧毁导致阻值偏离设计值，箱体严重过热变形影响散热和绝缘，多次更换电阻元件后仍反复烧损，投切机构故障导致阻尼电阻无法可靠投退时应报废更换。 |
| 中性点避雷器 | — | 保护中性点设备免受过电压损害，限制大气过电压和操作过电压的幅值 | 否 | 每年测量避雷器的绝缘电阻和直流参考电压下的泄漏电流；检查外观有无裂纹、闪络痕迹和伞裙破损；进行阻性电流测试评估老化程度；检查接地引下线连接。 | 直流参考电压下泄漏电流超过允许值，阻性电流显著增大表明阀片严重老化，瓷套或复合外套出现贯穿性裂纹，绝缘电阻严重下降时应报废更换。 |
| 隔离开关 | — | 用于投入或切除整套接地装置，提供可见断口，保障检修安全 | 否 | 每年检查隔离开关触头的接触情况和弹簧压力；测量回路电阻；检查操作机构和传动连杆的灵活性和润滑状况；检查支持绝缘子有无裂纹和污秽。 | 触头严重烧损导致接触电阻超标，操作机构卡死无法正常操作，绝缘子出现裂纹影响绝缘安全，经检修后仍无法可靠分合时应报废更换。 |
| 电压互感器 | 接地变压器 | 测量中性点位移电压和相电压，为控制器提供电压信号及电源 | 否 | 每年测量电压互感器的变比和极性；检查绝缘电阻和介质损耗；检查二次接线端子的接触和密封情况；核对控制器显示电压与实际电压的一致性。 | 变比偏差超过允许范围影响测量准确性，绝缘电阻严重下降表明内部受潮，二次绕组开路或短路导致信号异常，经检修仍不合格时应报废更换。 |
| 电流互感器 | 消弧线圈 | 测量接地故障电流和补偿电流，为控制器提供电流采样信号 | 否 | 每年校验电流互感器的变比和精度；检查绝缘电阻；检查二次接线端子和接地状况；核对控制器显示电流与实际电流的一致性；确保二次侧不得开路运行。 | 变比偏差超过允许范围，绝缘电阻严重下降，铁芯饱和导致大电流时测量严重失真，二次绕组损坏导致信号丢失时应报废更换。 |
| 温度传感器 | 消弧线圈 | 监测消弧线圈绕组及铁芯温度，防止过热损坏，实现超温报警或跳闸 | 否 | 每年校验温度传感器的测量精度；检查探头安装位置和引线完好性；核对超温报警和跳闸设定值是否正确；检查信号传输回路的可靠性。 | 传感器输出信号漂移超出允许范围且无法校准，探头损坏导致温度信号丢失，信号传输线断路或短路导致数据异常时应报废更换。 |
| 分接开关 | 消弧线圈 | 通过改变绕组匝数调节电感量，实现补偿电流的有载或无载调节 | 是 | 每年操作分接开关往返数次清除触头氧化膜；测量各分接位置的接触电阻；检查操动机构的灵活性和位置指示准确性；检查密封和绝缘状况。 | 触头严重烧损导致接触电阻超标，机械结构变形导致无法正常切换，绝缘水平下降导致分接段间放电，经检修仍不合格时应报废更换。 |
| 铁芯 | 消弧线圈 | 导磁回路部件，由硅钢片叠装而成，承载主磁通，长期运行可能因振动或过载导致绝缘老化 | 否 | 吊检时检查铁芯有无过热变色和片间短路；测量铁芯对地绝缘电阻；检查铁芯紧固状态和接地情况；运行中监测空载损耗和噪声。 | 铁芯片间绝缘严重劣化导致局部过热，空载损耗显著增大，铁芯严重变形或硅钢片大面积损坏，多点接地故障反复发生且无法彻底消除时应报废更换。 |
| 绕组 | 消弧线圈 | 铜或铝导线绕制，通过电磁感应产生补偿电感电流，易受潮、过热导致匝间短路 | 是 | 每年测量绕组直流电阻和绝缘电阻；检查绕组外观有无过热变色和绝缘劣化；定期进行匝间耐压试验；监测运行中绕组温度和补偿电流。 | 绕组匝间短路导致电感值严重偏差，绝缘电阻急剧下降，直流电阻不平衡率超标，外观检查发现严重过热变形时应报废更换。 |
| 阻尼电阻 | 阻尼电阻箱 | 消耗有功功率，抑制谐振及中性点位移过电压，频繁动作或过流时易烧损 | 是 | 每季度检查电阻元件表面有无过热变色和氧化；每年测量电阻值是否在允许偏差范围内；检查连接螺栓紧固力矩和接触面氧化情况；监测运行中电阻温度。 | 电阻元件烧断或阻值偏差超过允许范围，电阻片大面积氧化剥落，多次烧损后评估系统存在设计缺陷时应报废更换并优化参数。 |
| 滤波电容器 | 阻尼电阻箱 | 滤除高频谐波，防止电阻发热并提高测量准确度，长期运行易老化、容量衰减 | 是 | 每年测量电容值和介质损耗，与原始值对比评估老化程度；检查外观有无鼓包和渗液；检查接线端子接触和绝缘状况；发现容量衰减超过10%时密切关注。 | 电容值衰减超过标称值的20%影响滤波效果，介质损耗显著增大，外观出现鼓包或渗液，绝缘电阻下降导致无法正常运行时应报废更换。 |
| 控制电源模块 | 自动跟踪控制器 | 将站用交流或直流电源转换为控制器所需电压等级，含整流、滤波、稳压回路 | 是 | 每季度检查电源模块输出电压是否稳定；检查散热和通风状况；测量各路输出电压的纹波；检查接线端子和保险丝状态。 | 输出电压严重偏离额定值且无法调整，纹波过大导致控制器工作异常，功率器件烧毁导致供电中断，经更换元器件仍无法稳定输出时应报废更换。 |
| 信号采集板 | 自动跟踪控制器 | 调理电压、电流互感器二次信号，经滤波、放大后送入主控芯片，含精密运放等易损元件 | 是 | 每年进行通道校准，检查信号调理精度；检查板上精密运放和阻容元件有无虚焊和老化；测量各通道增益和偏移；清洁板面灰尘和氧化物。 | 信号调理精度严重下降超出校准范围，多路通道同时故障导致无法正常采集信号，板上精密元件批量老化且更换后仍不稳定时应报废更换。 |
| 驱动继电器 | 自动跟踪控制器 | 输出接点控制分接开关电机、阻尼电阻投切接触器，触点频繁动作易氧化、粘连 | 是 | 每季度检查继电器动作是否可靠，有无卡滞和异响；检查触点有无烧蚀和粘连；测量触点接触电阻；定期更换动作次数达到寿命的继电器。 | 触点严重烧蚀或粘连导致误动或拒动，线圈断路或短路导致无法动作，经清洁打磨触点后仍无法可靠工作，达到厂家规定动作次数寿命时应报废更换。 |
| 绝缘子 | 接地变压器 | 支撑接地变压器高、低压引出线，提供对地绝缘，易积污受潮导致沿面闪络 | 是 | 每季度检查绝缘子表面有无裂纹、放电痕迹和严重污秽；定期清扫或带电清洗绝缘子表面；测量绝缘电阻；检查安装固定是否牢固。 | 绝缘子出现贯穿性裂纹危及绝缘安全，表面严重放电烧伤无法修复，瓷件脱落或复合外套严重老化，绝缘电阻不满足运行要求时应报废更换。 |
| 油枕及呼吸器 | 消弧线圈 | 油浸式消弧线圈的储油和补油装置，呼吸器内硅胶吸湿，维持油箱内外压力平衡 | 是 | 每月检查油枕油位是否正常；检查呼吸器内硅胶颜色，变色超过三分之二时更换；每年检查油枕与油箱连接管路是否畅通；检查密封情况。 | 油枕严重锈蚀穿孔导致渗漏油，呼吸器连接管路堵塞导致油箱无法正常呼吸，胶囊破裂导致油质直接接触空气加速劣化时应报废更换。 |
| 密封件 | 消弧线圈 | 各法兰、阀门的密封垫圈，防止变压器油渗漏及潮气侵入，长期受热受压易老化开裂 | 是 | 每季度巡检各密封部位有无渗漏油痕迹；发现渗漏时及时标记并安排更换密封垫；大修时整体更换所有密封件；检查密封垫材质是否满足耐油耐温要求。 | 密封垫老化变硬失去弹性导致反复渗漏，耐油性能下降导致膨胀变形或碎裂，多处密封同时失效表明密封件已到寿命末期应批量更换。 |
