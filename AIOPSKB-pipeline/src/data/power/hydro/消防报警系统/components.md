| 火灾报警控制器 | — | 系统核心处理单元，接收探测器信号，控制声光报警及消防联动设备，显示报警位置与状态。 | 否 | 制定月度巡检计划，检查控制器运行状态、指示灯和液晶屏显示是否正常；每季度进行一次系统自检功能测试，验证声光显示及打印记录功能；每年由专业消防维保单位进行全面检测，包括联动控制功能测试；定期清洁机箱内部灰尘，检查各板卡插接是否可靠；核对系统时钟和事件记录功能。 | 控制器主板严重损坏无法修复且无同型号备件，系统软件版本过旧无法满足现行消防规范要求，或经评估大修成本超过更换新设备造价时，经消防主管部门批准后整台报废更换。 |
| 主控板 | 火灾报警控制器 | 中央处理器与存储器，运行火警逻辑程序，分析探测器数据，输出控制指令。 | 是 | 定期检查主控板运行指示灯状态是否正常；检查板卡插接是否牢固，有无松动或氧化；每年备份一次系统配置和事件记录；检查板上元器件有无过热、鼓包或烧蚀痕迹；雷雨季节前检查防雷措施是否完好。 | 主控板CPU或存储器芯片损坏导致系统无法启动或频繁死机，板上关键元器件烧毁且无法局部更换，或经多次维修后系统运行不稳定时报废更换。 |
| 显示/操作面板 | 火灾报警控制器 | 液晶显示屏幕及物理按键，提供人机交互界面，显示故障、火警等系统状态。 | 是 | 定期清洁液晶屏表面，检查显示是否清晰完整；逐一测试各按键响应是否灵敏；检查面板背光是否均匀；检查面板与主控板的连接排线是否可靠；每年进行一次全面功能测试，确保各项操作响应正常。 | 液晶屏大面积损坏无法正常显示火警和故障信息，按键多数失灵影响应急操作，面板连接排线损坏且无法修复，或面板整体老化经更换显示模组后仍不稳定时报废更换。 |
| 通信接口板 | 火灾报警控制器 | 管理总线通讯，负责与探测器、模块等现场部件的数据交换与巡检。 | 是 | 定期检查通信接口板与各回路的通信状态，统计通讯故障率；检查板上指示灯是否正常；检查回路末端电压是否在设计范围内；清洁板卡金手指接插件；每年进行一次回路通讯测试，验证巡检功能。 | 通信芯片烧毁导致多回路通讯中断，光电耦合器或隔离器件批量损坏，板卡经多次维修仍频繁出现通讯故障，或板上关键集成电路停产无备件供应时报废更换。 |
| 电源模块 | 火灾报警控制器 | 提供控制器内部各类工作电压，管理主备电切换及蓄电池充电。 | 是 | 定期测量各路输出电压是否在允许偏差范围内；检查主备电切换功能是否可靠，模拟主电断电验证备电自动投入；检查蓄电池充电电压和充电电流是否正常；检查模块散热是否良好；每年进行一次电源模块满载测试。 | 电源模块输出电压严重偏差无法调整，主备电切换功能失效且无法修复，内部变压器或功率器件烧毁，或电源模块使用年限超过设计寿命且频繁故障时报废更换。 |
| 打印机模块 | 火灾报警控制器 | 微型热敏打印机，用于实时打印火警、故障、联动动作等事件记录。 | 是 | 定期检查打印功能是否正常，打印内容是否清晰；检查热敏打印头有无污垢或磨损，必要时用酒精棉清洁；检查纸卷余量并及时补充；检查打印机连接线缆是否可靠；每年验证打印内容与系统事件的一致性。 | 打印头严重磨损导致打印内容无法辨认，步进电机损坏导致走纸异常，控制电路板烧毁，或机械结构严重变形卡死无法修复时报废更换。 |
| 回路卡 | 通信接口板 | 单个回路驱动与通讯子板，挂载探测器与模块，实现回路短路、开路监测。 | 是 | 定期检查回路卡运行指示灯状态是否正常；检查回路巡检功能是否可靠，验证短路和开路报警功能；测量回路终端电压是否在正常范围；清洁板卡接插件；每年进行一次回路负载能力测试，确保满载探测器数量下通讯正常。 | 回路通讯芯片或驱动电路损坏导致整回路通讯中断，板上多处元件损坏无法局部修复，或回路卡经多次维修后仍频繁出现误报警和通讯故障时报废更换。 |
| 探测器 | — | 感知火灾物理现象的前端传感器总称，安装于保护区域。 | 否 | 制定季度巡检计划，检查各类探测器外观是否完好、安装是否牢固；每年由专业消防维保单位进行一次全面检测，包括模拟火灾试验验证响应功能；检查探测器地址编码是否正确；对积尘严重的区域增加清洁频率；建立探测器使用台账，跟踪安装年限。 | 探测器整体老化导致误报率或漏报率显著升高，外壳破损影响防护等级且无修复价值，或使用年限超过国家消防规范规定的有效期时，整批报废更换。 |
| 感烟探测器 | 探测器 | 通过光电散射或离子原理，监测空气中烟雾浓度，达到阈值后发出火警信号。 | 是 | 每季度进行一次现场吹烟测试，检查报警响应是否正常；定期用专用工具清洁探测室内部灰尘，防止灰尘积聚导致误报；检查探测器指示灯闪烁是否正常；每年进行一次报警阈值校验；注意避免在探测器附近进行产生大量粉尘的作业。 | 探测器经清洁后仍频繁误报或对标准烟雾无响应，光电元件或离子源老化导致灵敏度严重下降，使用年限超过10年（或厂家规定寿命），或外壳破损导致防护等级不满足要求时报废更换。 |
| 感温探测器 | 探测器 | 利用热敏元件探测环境温度异常，分为定温、差温或复合型。 | 是 | 每年进行一次加热测试，用热风枪或专用测试仪模拟温升，验证报警响应；检查热敏元件有无受潮或腐蚀；清洁探测器外壳和进气口；检查安装位置是否避开热源干扰；核对探测器类型（定温/差温）是否与设计一致。 | 热敏元件老化导致响应温度严重偏差，经校验灵敏度超出允许范围且无法调整，使用年限超过12年（或厂家规定寿命），或机械损伤导致内部结构损坏时报废更换。 |
| 感光（火焰）探测器 | 探测器 | 检测火焰产生的紫外或红外辐射，用于油库、化学品仓库等快速响应场合。 | 是 | 每半年进行一次火焰模拟测试（用标准火焰源或专用测试灯），验证响应时间和灵敏度；定期清洁光学窗口，确保无灰尘油污遮挡；检查安装角度是否正确，视野范围内有无新增遮挡物；核对灵敏度等级设置是否合适。 | 光敏元件老化导致灵敏度严重下降或频繁误报，光学窗口划伤或腐蚀无法修复影响光路透过率，使用年限超过厂家规定寿命，或经测试无法探测标准火焰源时报废更换。 |
| 复合式探测器 | 探测器 | 集成烟、温两种及以上传感方式，通过内置逻辑判断提高报警准确性。 | 是 | 每半年进行复合测试，同时模拟烟雾和温升信号，验证复合逻辑判断功能是否正常；定期清洁烟雾检测腔和温度传感部位；检查探测器自检功能是否正常；每年核对复合判断逻辑参数是否与设计一致。 | 复合传感功能中任一通道失效且无法修复，内置逻辑芯片损坏导致判断功能异常，使用年限超过厂家规定寿命，或多次维修后仍频繁误报或漏报时报废更换。 |
| 手动报警按钮 | — | 人工确认火灾后击碎玻璃或按下压片，产生报警电信号。 | 是 | 每季度检查外观是否完好，玻璃有无破损；每半年进行一次模拟触发测试，验证报警信号能否正常上传至控制器；检查复位功能是否正常（可复位型）；检查接线端子是否牢固；确保安装位置标识清晰、无遮挡。 | 按钮机械结构损坏导致无法触发或误触发，触点严重氧化导致接触不良，玻璃片破损且无备件更换，或外壳严重老化开裂影响使用时报废更换。 |
| 消火栓按钮 | — | 安装在消火栓箱内，按下后直接启动消防水泵并反馈至控制器。 | 是 | 每季度检查按钮外观和安装状态是否完好；每半年进行一次触发测试，验证水泵启动指令和反馈信号是否正常；检查接线端子有无松动或氧化；检查消火栓箱内指示灯和警铃是否正常；确保按钮不被杂物遮挡。 | 按钮触点失效导致无法可靠启动消防泵，机械结构损坏无法触发，接线端子严重锈蚀，或防水防尘性能丧失时报废更换。 |
| 声光报警器 | — | 接收控制器指令，发出高分贝警笛声和高亮度频闪灯光，警示人员疏散。 | 是 | 每季度进行一次声光报警功能测试，检查声压级是否满足要求（通常不低于85dB），闪光频率是否正常；检查安装是否牢固，接线是否可靠；清洁声孔和灯罩，确保声光输出无遮挡；检查外壳有无破损进水痕迹。 | 声压级严重下降导致无法满足疏散要求，闪光灯烧毁或声源元件损坏且无法修复，外壳破损影响防护等级，或经多次维修后仍不稳定工作时报废更换。 |
| 消防广播（音箱/喇叭） | — | 火灾确认后，用于播放疏散语音和警报音，通常为3W-5W定压喇叭。 | 是 | 每季度进行一次广播播放测试，检查音量和音质是否清晰；检查喇叭纸盆或振膜有无破损或受潮变形；检查安装支架是否牢固；检查接线端子有无氧化松动；每年测试应急广播切换功能是否正常。 | 喇叭振膜破损或音圈烧毁导致声音严重失真或无声，变压器损坏导致阻抗失配，外壳锈蚀严重影响防护性能，或经测试声压级不满足疏散要求时报废更换。 |
| 消防电话分机/插孔 | — | 设于重要机房、走道，供消防作业人员与控制中心通话的专用电话部件。 | 是 | 每季度进行一次通话测试，检查通话音质是否清晰、有无杂音或中断；检查插孔和分机的机械结构是否完好；检查电话线路是否通畅；清洁插孔内部触点，防止氧化接触不良；确保消防电话标识清晰可见。 | 分机通话电路损坏无法正常通话，插孔触点严重氧化弹性失效，电话手柄或话筒损坏且无备件修复，或外壳破损影响使用时报废更换。 |
| 输入模块 | — | 接收水流指示器、防火阀状态等外部无源触点信号，并传送至控制器。 | 是 | 每半年进行一次输入信号测试，模拟外部触点动作，验证信号能否正确上传至控制器；检查模块指示灯状态是否正常；检查接线端子有无松动或氧化；检查模块地址编码是否正确；清洁模块外壳。 | 模块内部电路损坏导致无法正确接收和上传信号，通讯芯片失效，接线端子严重锈蚀无法修复，或经多次维修后仍频繁故障时报废更换。 |
| 输出模块 | — | 依据控制器指令，输出有源信号以启动排烟阀、防火卷帘、消防泵等设备。 | 是 | 每半年进行一次输出控制测试，验证模块能否正确输出启动信号驱动受控设备；检查输出触点容量是否与负载匹配；检查模块动作指示灯是否正常；检查接线端子紧固度；每年进行一次联动控制功能验证。 | 输出继电器触点烧蚀粘连或接触不良导致无法可靠控制设备，输出电路损坏，或经多次维修后仍无法满足联动控制要求时报废更换。 |
| 输入/输出模块 | — | 兼具信号接收与输出控制功能，用于控制并确认风机、水泵等设备的动作状态。 | 是 | 每半年同时测试输入和输出功能，验证信号接收和控制输出是否均正常；检查模块指示灯显示是否与实际状态一致；检查接线端子有无过热或松动；核对模块地址和类型设置；每年进行联动测试。 | 输入或输出任一通道损坏且无法局部修复，内部继电器和通讯电路同时故障，或多次维修后仍无法稳定工作导致联动功能异常时报废更换。 |
| 模块箱 | — | 集中安装输入、输出模块的金属或非金属箱体，内部接线，防护等级IP30以上。 | 否 | 定期检查箱体外观有无锈蚀、变形或破损；检查箱门密封和锁具是否完好；检查箱内接线是否整齐、端子是否紧固；清洁箱体内部灰尘；确保箱体安装牢固，周围无杂物堆放；检查箱体接地是否可靠。 | 箱体严重锈蚀穿孔导致防护等级不满足要求，结构变形影响密封和安装，或箱内布线空间不足无法满足系统扩展需求时报废更换。 |
| 总线隔离器 | — | 串联在报警总线上，当局部线路短路时自动隔离该回路，保障系统其余部分正常。 | 是 | 每半年进行一次隔离功能测试，模拟总线短路验证隔离器是否可靠动作；检查隔离器指示灯状态是否正常；检查接线端子有无松动或过热；核对隔离器安装位置和数量是否符合设计；短路故障排除后验证自动恢复功能。 | 隔离器动作后无法自动恢复或频繁误隔离，内部电路损坏导致无法检测和隔离短路故障，或外壳破损影响正常使用时报废更换。 |
| 终端电阻 | — | 并联在探测回路末端或模块信号接收端，用于线路完整性监视。 | 是 | 每年进行一次阻值测量，核对是否与设计值一致（常见为4.7kΩ或6.8kΩ）；检查电阻外观有无烧蚀或变色；检查焊接或接线是否可靠；确保终端电阻安装在回路末端正确位置。 | 电阻值偏差超出允许范围，电阻体烧毁或引线断裂，或因环境腐蚀导致阻值不稳定时更换新品，旧件报废。 |
| 备用蓄电池 | — | 密封铅酸电池组，在主电源断电后向系统持续供电，保障持续运行。 | 是 | 每月检查蓄电池外观有无鼓包、漏液或变形；测量电池端电压是否在正常范围；每季度进行一次放电容量测试，验证备用供电时间是否满足设计要求（通常不少于8小时）；检查电池连接条有无腐蚀或松动；检查充电电压和浮充电流是否正常；蓄电池使用3-5年后应考虑预防性更换。 | 蓄电池鼓包漏液或外壳破裂存在安全隐患，放电容量测试低于额定容量的80%，端电压异常无法正常充电，或使用年限超过5年（或厂家规定寿命）时整组报废更换。 |
| 接线端子排 | — | 用于汇集和连接外部信号线、电源线、控制线，确保电气导通。 | 否 | 定期检查端子排接线是否紧固，用螺丝刀逐一检查拧紧；检查端子有无变色、过热或碳化痕迹；核对端子标注是否清晰；检查电流回路端子运行中有无异常温升；大修期间测量端子接触电阻。 | 端子排严重碳化或变形影响绝缘性能，多次出现过热故障且无法根治，塑料基座老化开裂，或端子数量无法满足系统改造需求时整排报废更换。 |
