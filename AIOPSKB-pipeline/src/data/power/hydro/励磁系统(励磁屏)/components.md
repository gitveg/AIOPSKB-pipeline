| 励磁系统(励磁屏) | — | 为水力发电机提供可调节的直流励磁电流，维持机端电压恒定，实现无功功率调节及灭磁保护的整套励磁装置。 | 否 | 定期检查AVR调节精度和各项保护定值；校验灭磁回路动作可靠性；检查功率整流桥元件特性和冷却系统；核对TV/TA接线正确性；大修时对整套励磁系统做静态和动态特性试验。运行中监控励磁电压、电流波动和机端电压稳定性。 | 励磁系统核心部件（励磁变压器、功率整流桥、AVR）同时严重损坏，修复费用超过新系统价格的60%。整体更换时需核对与发电机的电气和机械接口参数，安装后做空载阶跃响应、灭磁试验和保护联调。 |
| 励磁屏柜体 | 励磁系统(励磁屏) | 金属外壳，提供防护、电磁屏蔽及设备安装支撑，通常为屏式结构。 | 否 | 每年检查屏柜体有无变形和锈蚀；检查门锁和密封条完好性；检查接地铜排连接可靠；紧固各装置安装螺丝。 | 屏柜体严重变形或大面积锈蚀影响防护等级。更换时需将内部设备逐台移出重新安装。 |
| 励磁变压器 | 励磁系统(励磁屏) | 为励磁系统提供独立的交流电源，一次侧接发电机出口或厂用电，二次侧接功率整流桥。 | 否 | 每年测量绕组直流电阻和绝缘电阻；检查高低压侧接线端子有无过热变色；检查本体有无渗油（油浸式）或异常温升（干式）；大修时进行绕组变形测试和油中溶解气体分析。 | 绕组绝缘击穿或直流电阻严重不平衡；铁芯严重过热导致片间绝缘损坏。更换时断开高低压侧接线，吊装新变压器后恢复接线并做交接试验。 |
| 励磁变压器高压绕组 | 励磁变压器 | 一次侧绕组，接入发电机出口或厂用电电源。 | 是 | 每年测量高压绕组直流电阻和绝缘电阻；检查绕组表面有无过热变色和绝缘损伤；检查接线端子紧固。 | 绕组匝间短路或绝缘击穿；局部放电量超标。需返厂重绕或更换变压器。 |
| 励磁变压器低压绕组 | 励磁变压器 | 二次侧绕组，为功率整流桥提供交流输入。 | 否 | 同高压绕组。定期测量直流电阻和绝缘电阻；检查绕组状态和接线端子。 | 匝间短路或绝缘损伤。需与高压绕组同步处理。 |
| 励磁变压器铁芯与夹件 | 励磁变压器 | 构成磁路并夹紧绕组，降低振动和噪声。 | 否 | 每年检查铁芯接地是否可靠（单点接地）；测量铁芯对地绝缘电阻；检查夹件紧固螺栓。 | 铁芯多点接地导致环流严重且无法消除；硅钢片大面积锈蚀。需更换铁芯或整台变压器。 |
| 功率整流桥 | 励磁系统(励磁屏) | 采用可控硅或整流元件，将交流电转换为直流电，是励磁功率输出的核心通道。 | 是 | 定期测量各桥臂可控硅正反向阻断特性；检查散热器与元件接触面导热硅脂；检查冷却风道通畅；紧固各接线端子。大修时逐个做可控硅触发特性测试。 | 可控硅击穿短路或正向压降严重超标；散热器严重氧化影响散热。更换可控硅时注意规格、耐压和触发电流参数一致，安装后做触发测试。 |
| 可控硅元件 | 功率整流桥 | 实现整流和控制的功率半导体器件，通过触发角调节直流输出电压。 | 是 | 每年测量可控硅正反向阻断电压和正向压降；检查与散热器接触面导热硅脂状态；测量门极触发特性。 | 可控硅击穿短路或正向压降超过允许值；门极触发失效。更换同规格可控硅并涂抹导热硅脂，安装后做触发测试。 |
| 快速熔断器 | 功率整流桥 | 串联在功率整流元件支路中，用于短路或严重过载时迅速熔断。 | 是 | 定期巡检检查熔断器指示器是否弹出；测量熔断器两端电压降；每次大修检查熔断器夹紧力和弹簧状态。备件库存保持充足（不少于使用量的30%）。 | 熔断器熔断（指示器弹出）；底座或夹持件严重氧化。更换时选用同型号同规格产品，检查底座清洁后装入。 |
| 整流桥散热器 | 功率整流桥 | 铝型材散热器，通过风冷或自然冷却将可控硅热量散出。 | 否 | 每年检查散热器表面有无氧化和积灰；清理散热片间灰尘；检查与可控硅接触面平整度和导热硅脂状态。 | 散热器严重氧化或变形导致散热效果下降，可控硅温度持续超标。更换同规格散热器。 |
| 自动电压调节器(AVR) | 励磁系统(励磁屏) | 实时检测发电机输出电压，自动调节励磁电流，在不同负载工况下维持电压稳定。 | 否 | 定期通过软件或面板检查运行参数和故障记录；核对控制参数和保护定值；做手动/自动切换试验和阶跃响应试验；检查各I/O端口接线可靠性；备份参数设定。大修时做完整的静态特性和动态特性试验。 | 核心控制板损坏且无备件替代；多次故障导致运行不可靠。更换AVR后需通过专用软件下载参数并做空载和负载工况下的电压调节试验。 |
| AVR电源模块 | 自动电压调节器(AVR) | 将外部输入的交流或直流电源转换为AVR工作所需的稳定直流电压。 | 是 | 每年测量电源模块各路输出电压是否在允许范围内；检查电容有无鼓包；检查散热片温度。运行中如AVR频繁复位应优先排查电源模块。 | 输出电压严重偏移或纹波超标导致AVR工作异常；模块内部元器件烧毁。更换同型号电源模块后测量输出电压确认正常。 |
| AVR主控板 | 自动电压调节器(AVR) | 包含DSP/MCU的数字式核心控制板，运行控制算法和通信协议。 | 否 | 定期备份控制程序和参数配置；检查运行日志和自检报告；检查板卡外观有无过热变色。 | DSP/MCU芯片损坏或程序丢失无法恢复；PCB烧蚀。更换同型号主控板后下载程序和参数。 |
| AVR显示面板 | 自动电压调节器(AVR) | 液晶显示及按键操作面板，用于就地参数整定、状态显示和操作。 | 是 | 定期检查屏幕显示完整性和按键功能；清洁面板表面；检查背光亮度。 | 屏幕大面积坏点或完全黑屏；按键失灵无法操作。更换显示面板后核对显示参数与实际值一致。 |
| 灭磁回路 | 励磁系统(励磁屏) | 在正常停机或故障时快速切断励磁电流并吸收磁场能量，保护发电机转子绝缘。 | 否 | 每年做灭磁试验验证动作可靠性和灭磁时间；检查磁场断路器主触头磨损和灭弧栅片状态；测量非线性电阻伏安特性。大修时全面检测灭磁回路各部件。 | 灭磁回路多个关键部件（磁场断路器、非线性电阻、跨接器）同时损坏。需整体更换灭磁回路组件并做灭磁试验。 |
| 磁场断路器 | 灭磁回路 | 安装在励磁回路中，用于正常停机切断励磁电流或故障时执行快速灭磁操作。 | 是 | 每年检查主触头磨损和烧蚀情况；检查灭弧栅片有无严重烧损；测量合闸和跳闸线圈直流电阻；定期做合分闸操作试验。 | 主触头严重烧损经打磨后仍无法保证良好接触；灭弧栅片大面积烧损；操作机构卡涩。更换断路器时核对额定电流和灭磁参数，安装后做合分闸试验。 |
| 非线性电阻 | 灭磁回路 | 在灭磁过程中吸收磁场能量，限制灭磁过电压，保护发电机转子绝缘。 | 是 | 大修时测量非线性电阻伏安特性，与出厂值对比判断劣化程度；检查外观有无裂纹、变色和放电痕迹；测量绝缘电阻。 | 伏安特性严重偏移（残余电压显著升高或漏电流增大）；外观可见裂纹或贯穿性击穿痕迹。更换同型号备件，注意安装极性和绝缘距离。 |
| 可控硅跨接器 | 灭磁回路 | 用于在灭磁或特定保护动作时将灭磁电阻接入励磁回路，实现快速灭磁或过电压保护。 | 是 | 大修时测量跨接器可控硅触发特性和正反向阻断电压；检查散热器安装是否牢固；定期做灭磁试验验证动作可靠性。 | 可控硅击穿或触发特性劣化无法可靠触发；散热器严重变形。更换可控硅后做触发试验和灭磁试验。 |
| 风机与冷却系统 | 励磁系统(励磁屏) | 安装在功率整流柜内，强制通风散热，确保可控硅等功率元件在允许温度内运行。 | 否 | 定期检查风机运转是否平稳无异响；检查叶片有无积灰和变形；测量电机绝缘电阻；轴承按周期加注润滑脂；风道和滤网保持通畅清洁。 | 风机电机烧毁或轴承损坏无法运转；风道严重堵塞。更换相应部件后测试通风散热效果。 |
| 冷却风机 | 风机与冷却系统 | 轴流风机，强制风冷散热，排出功率整流桥产生的热量。 | 是 | 每季度检查风机运转有无异响和振动；清理扇叶积灰；测量电机电流和绝缘电阻。运行中如整流桥温度异常升高应优先检查风机。 | 风机电机烧毁或轴承卡死；扇叶断裂。更换同规格风机后检查转向和风量。 |
| 整流柜滤网 | 风机与冷却系统 | 过滤进入整流柜的空气中的灰尘和杂质，防止绝缘件爬电和风道堵塞。 | 是 | 根据环境粉尘情况每月至每季度清洗一次滤网；清洗后晾干再装回；滤网破损时及时更换。 | 滤网框架变形无法有效密封；滤材大面积破损丧失过滤功能。更换同规格滤网。 |
| 控制端子排 | 励磁系统(励磁屏) | 屏内电气连接的接线端子，提供外部电缆接入和回路配线。 | 是 | 每年逐个紧固端子螺丝；检查端子有无过热变色和氧化；测量端子间及对地绝缘电阻。 | 端子排大面积氧化或烧蚀导致接触不良；绝缘件开裂。更换时逐线标记再拆除，安装后逐线恢复并紧固。 |
| 电压互感器(TV) | 励磁系统(励磁屏) | 测量发电机端电压，提供与电压成比例的低压信号给AVR用于电压调节和反馈。 | 否 | 每年校验TV变比和准确度；检查接线端子有无松动和过热；测量绝缘电阻；检查外壳有无渗漏和锈蚀。 | TV绕组击穿或变比严重偏移超过允许误差。更换TV后需重新校验变比和接线极性。 |
| 电流互感器(TA) | 励磁系统(励磁屏) | 测量发电机定子电流或励磁变压器电流，提供电流信号用于控制与保护。 | 否 | 同TV。定期校验变比和准确度；检查接线和端子状态；测量绝缘电阻。 | 绕组绝缘击穿或变比严重偏移。更换后重新校验并核对接线。 |
