| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|---|---|---|---|---|---|
| 铁芯 | — | 由硅钢片叠装而成，构成变压器的主磁路，用于磁耦合传递能量，减少涡流损耗。 | 否 | 每年进行空载损耗测试和振动监测，检查铁芯紧固状态；定期测量铁芯接地电流，确认仅有一点可靠接地；吊罩检修时检查硅钢片有无过热变色和片间短路；测量铁芯对地绝缘电阻。 | 铁芯出现大面积片间短路导致局部过热且无法修复，空载损耗显著增大超过设计值的15%，铁芯严重变形或硅钢片大面积损坏，接地片断裂导致多点接地故障反复发生时应评估报废。 |
| 绕组 | — | 由铜或铝导线绕制而成，通过电磁感应实现电压和电流的变换，分为高压和低压绕组。 | 否 | 每年测量绕组直流电阻并与历史数据对比分析；定期进行绕组变形测试（频率响应法）；吊罩检修时检查绕组外观有无变形、位移和绝缘劣化；监测运行中绕组温度和负荷电流。 | 绕组直流电阻不平衡率超过2%，频率响应测试显示严重变形，匝间或层间短路导致绝缘电阻急剧下降，绕组整体位移或变形影响电气性能且无法修复时应报废更换。 |
| 绝缘介质 | — | 包括变压器油、SF6气体或环氧树脂等，填充在器身内部，提供主绝缘和散热功能。 | 是 | 每年对变压器油进行简化分析（耐压、微水、酸值、界面张力等）；按周期进行油中溶解气体分析（DGA）判断内部是否存在过热或放电故障；油质不达标时进行滤油或换油处理。 | 变压器油各项指标严重劣化且经多次处理仍不达标，油中溶解气体含量持续快速增长表明内部存在不可逆故障，SF6气体泄漏无法维持额定压力，绝缘介质整体老化丧失绝缘功能时应报废。 |
| 油箱及储油柜 | — | 油箱容纳器身和绝缘油；储油柜安装在油箱上方，为油的热胀冷缩提供空间，减少油与空气的接触。 | 否 | 每季度巡检油箱焊缝、法兰和阀门有无渗漏油；每年检查储油柜油位是否正常，胶囊或隔膜有无破损；定期清理油箱表面污垢和锈蚀并补涂防腐漆；检查油箱接地连接。 | 油箱壁严重腐蚀减薄导致承压能力不足，焊缝多处裂纹且补焊后仍渗漏，储油柜严重变形影响油位指示和呼吸功能，法兰面大面积损伤无法密封时应报废更换。 |
| 冷却系统 | — | 由散热器、冷却风扇或油泵等组成，负责将变压器运行产生的热量散发出去，控制内部温度。 | 否 | 每季度检查散热器表面清洁度，清除灰尘和杂物；定期检查风扇电机运行电流和振动；检查油泵运转是否正常，油流指示器是否动作；每年清洗冷却器管束，检查控制回路。 | 冷却系统整体失效导致变压器温升持续超过允许值，散热器大面积腐蚀穿孔无法修复，多台冷却设备同时损坏且不具备修复价值时应报废更换整套系统。 |
| 套管 | — | 将变压器内部绕组引线连接到外部电网的绝缘装置，承担电气连接与机械支撑，分为高压与低压套管。 | 是 | 每季度检查套管外绝缘表面有无放电痕迹和污秽；每年测量套管介质损耗和电容量，与历史数据比对分析趋势；定期进行红外测温检查接头和本体有无异常发热；检查末屏接地是否可靠。 | 套管介损值超标且持续增大，电容量变化超过5%表明内部电容屏击穿，瓷套出现裂纹或复合外套严重老化龟裂，末屏绝缘下降无法修复，渗漏油严重时应报废更换。 |
| 无励磁分接开关 | — | 在变压器不带电状态下切换绕组分接头，用于调整二次侧电压，适应电网电压波动。 | 否 | 每年在停电检修时操作分接开关往返数次，清除触头表面氧化膜；测量各分接位置的直流电阻，检查接触是否良好；检查操作机构灵活性和定位准确性；检查密封情况。 | 触头严重烧损导致接触电阻超标且无法研磨修复，操作机构卡死无法正常切换，密封结构失效导致内部受潮，多次检修后直流电阻仍不平衡时应报废更换。 |
| 有载分接开关 | — | 在变压器带负载运行时切换绕组分接头，实现动态电压调节。 | 是 | 每季度检查切换开关油室油位和油色，定期取样化验；每年检查电动操动机构的行程和力矩；按厂家规定周期更换切换开关触头和灭弧材料；检查过渡电阻有无过热变色。 | 切换开关触头严重烧损超出允许范围，油室内绝缘油严重劣化且切换中产生大量碳粒，电动操动机构多次故障无法可靠操作，过渡电阻烧断时应报废更换开关本体。 |
| 保护装置 | — | 包含气体继电器、压力释放阀、速动油压继电器等，用于监测并保护变压器免受内部故障损害。 | 是 | 每季度检查气体继电器内有无积气和油位是否正常；每年校验压力释放阀的动作压力和密封性；检查速动油压继电器的动作定值；定期校验测温装置的准确度。 | 气体继电器动作不灵敏或拒动，压力释放阀弹簧疲劳导致动作值偏移且无法调整，保护装置整体老化导致误动或拒动频繁发生时应报废更换。 |
| 密封件 | — | 涵盖油箱箱沿、套管座、阀门等各处使用的耐油橡胶或软木橡胶垫，防止变压器渗漏油和进气受潮。 | 是 | 每季度巡检各密封部位有无渗漏油痕迹；发现轻微渗漏时标记观察并安排检修；每年评估密封件老化状况，对重点渗漏部位进行更换；大修时整体更换所有密封垫。 | 密封垫老化变硬失去弹性导致反复渗漏，耐油性能下降导致膨胀变形或碎裂，多处密封失效表明密封件已到使用寿命末期，应批量更换报废。 |
| 放气塞 | 冷却系统/套管 | 安装在管道、冷却器、套管升高座等高点位置，用于手动排空聚集的气体，防止气塞导致局部过热或绝缘下降。 | 否 | 每年在检修或更换冷却器、套管后打开放气塞排气至出油为止；定期检查放气塞密封垫和螺纹完好性；排气后确认拧紧力矩适当防止渗漏。 | 放气塞螺纹滑丝无法密封，密封垫老化碎裂导致反复渗漏，塞体腐蚀严重导致强度不足，经更换密封垫后仍渗漏时应报废更换放气塞。 |
| 硅钢片 | 铁芯 | 铁芯的基本叠装单元，为高导磁硅钢薄片，用于构成低损耗磁路。 | 否 | 吊罩检修时检查硅钢片有无锈蚀、片间短路和过热痕迹；测量铁芯局部损耗分布；保持铁芯干燥，防止受潮导致片间绝缘劣化；运行中监测空载损耗和噪声变化。 | 硅钢片大面积锈蚀导致片间绝缘劣化，局部过热导致硅钢片变色损坏，导磁性能严重下降导致空载损耗显著增大，片间短路区域无法通过绝缘处理修复时应报废更换铁芯。 |
| 铁芯夹件及拉板 | 铁芯 | 紧固铁芯叠片的结构件，保证铁芯机械强度并抑制运行振动和噪声。 | 否 | 每年测量夹件对地绝缘电阻，确认无多点接地；吊罩检修时检查夹件和拉板的紧固螺栓力矩；检查有无异常振动导致的松动和磨损；检查夹件与铁芯之间的绝缘垫块。 | 夹件严重变形导致无法有效夹紧铁芯，绝缘垫块老化失效导致铁芯多点接地故障反复发生，夹件螺栓断裂或滑丝导致紧固失效时应报废更换。 |
| 铁芯接地片 | 铁芯 | 确保铁芯在运行中仅有一点可靠接地，防止悬浮电位导致的间歇性放电。 | 是 | 每年测量铁芯接地电流，正常值应小于0.1A；接地电流异常增大时排查是否存在多点接地；吊罩检修时检查接地片的连接可靠性和铜皮有无断裂。 | 接地片铜皮断裂导致铁芯失去接地保护，连接点严重氧化腐蚀导致接触不良，接地片安装位置硅钢片损坏导致无法可靠压接时应报废更换。 |
| 高压绕组 | 绕组 | 匝数较多的绕组，在升压或降压变换中连接至高电压侧，承受系统高电压。 | 否 | 每年测量高压绕组直流电阻和绝缘电阻；定期进行绕组变形测试；吊罩检修时检查绕组外观有无变形、垫块位移和绝缘老化；监测运行中高压侧负荷和温度。 | 高压绕组匝间或层间短路，频率响应法检测显示严重变形，绝缘纸严重老化变脆导致绝缘电阻急剧下降，绕组烧损或变形不可修复时应报废。 |
| 低压绕组 | 绕组 | 匝数较少的绕组，连接至低电压侧，承载较大的负荷电流。 | 否 | 每年测量低压绕组直流电阻和绝缘电阻；检查引出线和连接部位的接触情况；吊罩检修时检查绕组绝缘状态和机械支撑；监测低压侧电流和温度。 | 低压绕组匝间短路或严重变形，直流电阻不平衡率超标，绝缘严重老化导致电气强度不足，绕组烧损无法修复时应报废。 |
| 匝间绝缘 | 绕组 | 绕组导线本身或其间的绝缘层（如绝缘漆、纸包绝缘），防止匝间或层间短路。 | 是 | 每年进行绕组绝缘电阻和吸收比测量；定期进行匝间耐压或感应耐压试验；油中溶解气体分析重点关注乙炔和乙烯含量变化；运行中监测局部放电水平。 | 匝间绝缘击穿导致匝间短路故障，绝缘纸严重老化变脆（聚合度低于250），局部放电量持续超标，DGA显示内部存在电弧放电特征时应报废绕组。 |
| 撑条及垫块 | 绕组 | 构成绕组内部的油道或气道，保证散热介质流通，同时提供机械支撑。 | 是 | 吊罩检修时检查撑条和垫块有无位移、变形和破损；检查绕组轴向压紧力是否均匀；垫块松动时重新调整压紧；检查撑条表面绝缘完好性。 | 撑条和垫块大面积老化收缩导致绕组轴向松动严重，绝缘纸层脱落导致机械支撑失效，绕组在短路电动力的作用下变形且撑条垫块无法提供有效支撑时应报废更换。 |
| 绝缘油 | 绝缘介质 | 矿物油或合成酯，充满油箱，具有绝缘、冷却和熄灭电弧的作用。 | 是 | 每年取样进行简化分析（击穿电压、微水、酸值、界面张力）；按周期进行油中溶解气体色谱分析；定期检测油介质损耗因数；油质不合格时进行真空滤油或更换新油。 | 击穿电压低于30kV且经多次滤油处理仍不达标，微水含量持续超标，酸值和油泥含量严重偏高，油中溶解气体总烃持续快速增长表明内部存在严重故障时应报废换油。 |
| 油箱本体 | 油箱及储油柜 | 密封的钢制容器，用于浸放器身和绝缘油，承受内部压力与真空。 | 否 | 每季度检查油箱外壁有无渗漏油和锈蚀；每年检查箱沿螺栓紧固情况和密封垫状态；大修时对油箱内部进行清洗和防腐处理；定期检查油箱接地连接。 | 油箱壁大面积腐蚀减薄影响机械强度和密封性能，焊缝多处裂纹且补焊后仍渗漏，箱体严重变形导致无法正常密封，真空试验不合格时应报废更换。 |
| 储油柜胶囊/隔膜 | 油箱及储油柜 | 安装在储油柜内，将变压器油与外部空气完全隔离，防止油受潮和氧化。 | 是 | 每年检查储油柜油位和胶囊呼吸是否畅通；定期检查胶囊内部有无积水和破损；大修时对胶囊进行气密性试验；发现油位异常变化时优先检查胶囊完好性。 | 胶囊老化破裂导致变压器油直接与空气接触，气密性试验不合格，胶囊材料变硬龟裂失去隔离作用，导致油质加速劣化时应报废更换。 |
| 吸湿器 | 油箱及储油柜 | 连接储油柜呼吸口，内部装有变色硅胶等干燥剂，吸附进入储油柜空气中的水分。 | 是 | 每月检查硅胶颜色变化，变色超过三分之二时及时更换干燥硅胶；每季度检查吸湿器连接管路密封性；清理吸湿器底部油杯，保持适当油封高度。 | 吸湿器壳体破裂导致干燥剂外泄和空气短路进入，连接管路腐蚀穿孔失去呼吸过滤功能，虽然不属于主要报废件但失效后应及时更换以保证油质保护效果。 |
| 油位计 | 油箱及储油柜 | 直观显示储油柜或油箱内的油面高度，通常带有温度补偿标线。 | 是 | 每季度核对油位计指示与实际油位的一致性；检查油位计玻璃管或磁翻板有无污染和损坏；大修时校准油位计的零点和满度；检查温度补偿机构是否正常。 | 油位计玻璃管破裂或严重污染导致无法观察，磁翻板机构卡死导致指示失灵，浮子泄漏下沉导致指示错误，经校准后仍无法准确指示油位时应报废更换。 |
| 净油器 | 油箱及储油柜 | 内部充满吸附剂的容器，循环净化变压器油中的水分、酸和氧化物，延长油的使用寿命。 | 是 | 每季度检查净油器进出口油的温度差，判断吸附剂活性；每年取样检查吸附剂是否饱和失效；定期更换吸附剂并清洗净油器内部；检查阀门和管路密封性。 | 净油器壳体腐蚀穿孔导致渗漏油，吸附剂更换周期急剧缩短表明内部堵塞或通道短路，阀门密封失效导致变压器油未经净化旁路流过时应报废更换。 |
| 散热片/管 | 冷却系统 | 焊接或安装在油箱壁上，通过自然对流增大油与空气的散热面积。 | 否 | 每季度检查散热片表面清洁度，清除灰尘和污物；每年检查散热片焊缝有无渗漏油；检查片间有无变形和堵塞；保持散热通道畅通。 | 散热片大面积腐蚀穿孔导致多处渗漏油，片间严重变形堵塞影响散热效果超过30%，焊缝多处裂纹无法补焊修复，散热能力严重下降导致变压器温升超标时应报废更换。 |
| 冷却风扇 | 冷却系统 | 安装在散热器下方或侧面，强制吹风以提高散热效率，常用于强迫风冷变压器。 | 是 | 每季度检查风扇电机运行电流、振动和噪声；定期检查叶片有无裂纹和变形；检查电机轴承润滑情况；每年测量电机绝缘电阻；检查控制回路和热继电器。 | 风扇电机绕组烧毁，轴承损坏导致剧烈振动和异响，叶片断裂或严重变形，电机绝缘电阻低于允许值，经检修后仍无法正常运行时应报废更换。 |
| 油泵 | 冷却系统 | 安装在冷却管道中，驱动绝缘油在油箱与外部冷却器之间强制循环，用于强迫油循环冷却。 | 是 | 每季度检查油泵运行电流、振动和出口压力；定期检查油泵密封有无渗漏；每年测量电机绝缘电阻；检查油流指示器是否正常指示；监测油泵轴承温度。 | 油泵电机绕组烧毁或绝缘电阻严重下降，泵体密封失效导致大量渗漏油，轴承损坏导致异常振动和噪声，叶轮磨损导致流量严重不足时应报废更换。 |
| 油流继电器 | 冷却系统 | 安装在油泵出口管路，监测油流的循环状态，当油泵故障或油流中断时发出报警信号。 | 是 | 每季度检查油流继电器指示是否与油泵运行状态一致；每年校验油流继电器的动作流量定值；检查接线端子和信号回路是否正常；核对报警信号上传是否正确。 | 油流继电器挡板卡死无法动作导致信号失灵，触点严重氧化导致接触不良，本体渗漏油导致绝缘下降，经校验后动作值偏差超过允许范围时应报废更换。 |
| 瓷套/复合外套 | 套管 | 套管的外部绝缘体，提供对地爬电距离，承受户外环境及污秽条件。 | 是 | 每季度检查瓷套表面有无裂纹、放电痕迹和严重污秽；污秽地区定期清扫或带电水冲洗；检查复合外套有无粉化和龟裂；测量外绝缘的爬电距离是否满足污秽等级要求。 | 瓷套出现贯穿性裂纹影响绝缘和机械强度，复合外套严重老化龟裂导致憎水性丧失，表面放电烧伤深度超标，爬电距离不满足所在污秽等级要求时应报废更换。 |
| 导电杆 | 套管 | 套管的中心导体，载流传导电流，连接内部引线与外部接线端子。 | 否 | 每年检查导电杆与引线的连接部位有无过热和氧化；红外测温检查导电杆端部接头温度；大修时检查导电杆螺纹和接触面的完好性；测量回路电阻。 | 导电杆严重过热变形，螺纹损坏导致连接不可靠，载流截面因腐蚀减小导致温升超标，经检修后回路电阻仍不合格时应报废更换。 |
| 末屏 | 套管 | 电容型套管的电压最外层测量端子，运行时需可靠接地，用于绝缘监测与介损测试。 | 是 | 每季度检查末屏接地引下线连接是否可靠；每年测量末屏对地绝缘电阻和介质损耗；预防性试验时进行末屏耐压试验；检查末屏密封防潮保护罩。 | 末屏引出线断线导致无法接地运行，绝缘电阻严重下降表明内部受潮，密封结构损坏导致末屏进水，接地不良导致悬浮放电损坏电容芯子时应报废更换套管。 |
| 开关本体 | 无励磁分接开关 | 安装在器身内的静、动触头系统，通过改变连接来切换绕组分接段匝数。 | 否 | 每年停电时操作开关往返多次清除触头氧化膜；检查动静触头的接触压力和烧伤情况；测量各分接位置的接触电阻；必要时研磨修复触头表面。 | 触头严重烧损导致接触电阻超标且无法研磨修复，机械结构变形导致无法正常切换，绝缘筒开裂导致分接段间绝缘下降时应报废更换开关本体。 |
| 操作机构 | 无励磁分接开关 | 安装在油箱盖或侧壁的机械传动机构，在停电时由人工操作进行电压分接变换。 | 否 | 每年检查操作手柄的灵活性和定位准确性；检查传动连杆和销轴有无松动和磨损；润滑运动部件；检查位置指示器与实际分接位置的一致性。 | 操作机构严重卡涩无法正常操作，传动连杆断裂或变形导致无法切换，定位装置失效导致分接位置不确定，经检修后仍无法可靠操作时应报废更换。 |
| 切换开关（选择器） | 有载分接开关 | 浸在单独油室内的快速切换机构，带负载进行分接的瞬间切换动作。 | 是 | 按厂家规定的操作次数或周期进行吊芯检查；检查过渡触头和主触头的烧损情况，必要时更换；检查过渡电阻有无过热变色；更换切换开关油室的绝缘油。 | 过渡触头和主触头烧损超出允许范围，切换过程中出现熄弧失败或过渡电阻烧断，油室内绝缘油严重劣化且碳粒含量极高，切换机构机械故障无法修复时应报废更换。 |
| 电动操动机构 | 有载分接开关 | 提供动力和逻辑控制，实现遥信、遥测、遥控远方或就地的自动调压操作。 | 是 | 每季度检查电动机构的动作计数器和运行状态；每年检查电机碳刷、齿轮传动机构和限位装置；检查电气控制回路和位置指示器；校验就地和远方操作功能。 | 电机烧毁且不具备修复价值，齿轮传动机构严重磨损导致切换不到位，电气控制回路故障频发且更换部件后仍不稳定，限位装置失效导致越限操作时应报废更换。 |
| 气体继电器 | 保护装置 | 安装在储油柜与油箱之间的连接管上，检测内部故障产生的气体，提供轻、重瓦斯报警与跳闸信号。 | 是 | 每季度检查气体继电器内有无积气和油位；每年校验轻瓦斯和重瓦斯的动作定值；检查接线端子箱密封和防潮；大修时进行气体继电器动作特性试验。 | 气体继电器浮筒或挡板机械卡涩导致拒动，触点系统老化导致信号不可靠，壳体渗漏油导致绝缘下降，经校验后动作值偏差超过允许范围时应报废更换。 |
| 压力释放阀 | 保护装置 | 安装在油箱盖顶部，当内部压力异常升高时，自动开启释放压力，压力降低后自动关闭。 | 是 | 每季度检查压力释放阀外观有无渗漏油和动作指示标志；每年校验动作压力值是否符合设计要求；检查导油管和防雨罩完好性；确认信号接点回路正常。 | 弹簧疲劳导致动作压力值偏移且无法调整复位，密封件老化导致常漏油，动作后无法自动关闭导致持续渗漏，经校验不合格时应报废更换。 |
| 测温装置 | 保护装置 | 包括油面温度计和绕组温度计，通过热电偶或热电阻测量温度，提供就地显示和远方报警信号。 | 是 | 每季度核对就地温度指示与远方显示的一致性；每年校验温度计的测量精度和报警跳闸定值；检查温包或热电阻的安装和密封；核对温度补偿功能。 | 温度计测量偏差超过允许范围且无法校准，感温元件损坏导致温度信号丢失，报警或跳闸接点失效导致保护功能丧失，经校验仍不合格时应报废更换。 |
