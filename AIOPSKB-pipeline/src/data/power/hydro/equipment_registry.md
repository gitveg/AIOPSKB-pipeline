| 设备名称 | 设备类型 | 描述 |
|----------|----------|------|
| 水轮机 | 主设备 | 将水流能量转换为旋转机械能，主要有混流式、轴流转桨式、灯泡贯流式、水斗式等类型，适用于不同水头和流量条件。 |
| 水泵水轮机 | 主设备 | 可逆式水力机械，兼具水轮机与水泵功能，用于抽水蓄能电站实现发电与抽水工况的转换。 |
| 水轮发电机 | 主设备 | 将水轮机输出的机械能转换为电能，大型机组效率可达98%以上，是水电站电力产生的核心。 |
| 主变压器 | 主设备 | 将发电机电压升高至输电电压，降低输电损耗，连接发电机电压设备与高压配电装置。 |
| 离相封闭母线 | 辅助设备 | 大容量机组发电机电压回路的连接导体，用于传输大电流，保证高电压、大电流回路的安全隔离。 |
| 发电机断路器 | 主设备 | 装设于水轮发电机出口，用于机组的频繁投切和故障隔离，适应调峰运行要求。 |
| 气体绝缘金属封闭开关设备（GIS） | 主设备 | 高压配电装置，具有结构紧凑、可靠性高、占地少的特点，广泛应用于场地受限的水电站，最高电压等级达800kV。 |
| 高压电力电缆 / 气体绝缘金属封闭输电线路（GIL） | 辅助设备 | 水电站高压引出线，将电能从主变压器输送至高压配电装置或出线场。 |
| 进水阀（主阀） | 主设备 | 安装在水轮机蜗壳入口，用于机组事故停机和检修时快速截断水流。 |
| 中性点接地装置 | 辅助设备 | 用于主变压器及发电机中性点的接地保护，包括接地电阻柜或消弧线圈，限制单相接地故障电流。 |
| 高压开关柜 | 辅助设备 | 用于厂用电系统或发电机电压侧，对高电压线路进行闭合、切断和保护，作为动力中心的主配电装置。 |
| 低压开关柜 | 辅助设备 | 作为低压动力中心和主配电装置，对400V辅机、照明线路和设备进行控制、监视、测量与保护。 |
| 调速系统 | 辅助设备 | 通过调节水轮机导叶开度控制机组转速和有功功率，包含调速器及液压执行机构，并具备一次调频、甩负荷控制等功能。 |
| 励磁系统（励磁屏） | 辅助设备 | 向发电机转子提供可调励磁电流，维持机端电压恒定，合理分配无功功率，是发电机的核心控制设备。 |
| 发电机保护测控屏 | 辅助设备 | 配设差动保护、接地保护、后备保护等装置，对发电机进行全面的电气量保护与测量。 |
| 主变线路保护测控屏 | 辅助设备 | 包含主变压器差动保护、后备保护以及线路保护装置，实现对主变和送出线路的综合保护。 |
| 机组LCU屏（现地控制单元） | 辅助设备 | 实时采集机组电气参数（电压、电流、功率等）和非电量参数（温度、转速、开度等），执行现地监控与远方通信。 |
| 公用LCU屏 | 辅助设备 | 采集主变线路、上下游水位、站用电以及气、水、油等公用系统数据，实现公用设备的集中监视与控制。 |
| 测温制动屏 | 辅助设备 | 监测发电机定转子、轴瓦及冷却系统的温度，同时控制机组刹车系统（风闸）的投入与退出。 |
| 交直流电源系统 | 辅助设备 | 为全站继电保护、控制、通信、事故照明等提供可靠的直流和交流不间断电源。 |
| 水电站综合自动化监控系统 | 辅助设备 | 实现全站数据采集、运行监视、自动控制及调度通信，支持“无人值班、少人值守”运行模式。 |
| 远动通信设备 | 辅助设备 | 将保护、测控、励磁、PLC等设备的数据转换为调度规约，实现与上级调度的信息交互和远方遥控。 |
| 电力仪表（电压、电流、功率、电度表等） | 辅助设备 | 就地或屏柜安装，用于显示和计量发电机、主变及线路的电气运行参数。 |
| 故障录波装置 | 辅助设备 | 自动记录电力系统故障或异常时的电气量波形和时序，为事故分析提供精确数据依据。 |
| 同步系统（同期屏） | 辅助设备 | 实现发电机与系统之间或系统两部分之间的电压、频率、相位同期并列操作，防止非同期合闸冲击。 |
| 安全稳定控制装置 | 辅助设备 | 在电网发生扰动或故障时执行切机、切负荷等紧急控制策略，保持系统暂态和电压稳定。 |
| 继电保护测试仪 | 辅助设备（试验） | 用于校验水电站各类继电保护装置的逻辑、定值和动作时间，确保保护系统可靠。 |
| 绝缘电阻测试仪 | 辅助设备（试验） | 测量电气设备绕组、电缆等绝缘电阻，评估设备绝缘状态。 |
| 水轮机综合测试仪 | 辅助设备（试验） | 检测调速器静特性、甩负荷、频率死区及一次调频等性能，验证调节系统品质。 |
| 直流电阻测试仪 | 辅助设备（试验） | 测量变压器绕组、断路器导电回路等的直流电阻，用于检查焊接质量和连接状态。 |
| 介质损耗测试仪 | 辅助设备（试验） | 测量电气设备绝缘的介质损耗角正切值和电容量，判断绝缘整体受潮、老化劣化状态。 |
| 高压开关动特性测试仪 | 辅助设备（试验） | 测量断路器分合闸时间、速度、行程及不同期性等机械特性参数，评估操动机构性能。 |
| 回路电阻测试仪 | 辅助设备（试验） | 输出大电流（如200A）测量隔离开关、断路器导电回路的微欧级接触电阻，评估连接质量。 |
| 串联谐振耐压设备 | 辅助设备（试验） | 用于GIS、电力电缆、主变压器等大容量设备的现场交流耐压试验，检验设备绝缘强度。 |
| SF6密度继电器校验仪 | 辅助设备（试验） | 校验GIS和断路器中SF6气体密度继电器的报警和闭锁压力，确保气室密封和绝缘安全。 |
| 厂用电系统 | 公用系统 | 从机组或电网取得电源，经厂用变压器和开关柜向机组辅机、照明、公用设备等供电。 |
| 接地系统 | 公用系统 | 利用水库水、水下钢结构及自然接地体降低接地电阻，保证电气设备和人身安全。 |
| 技术供水系统 | 公用系统 | 为水轮发电机组冷却、轴承润滑、主轴密封等提供足量、合格的冷却水。 |
| 排水系统 | 公用系统 | 排除厂房渗漏水、机组检修积水和尾水管内的积水，保证厂房和设备安全。 |
| 压缩空气系统（气系统） | 公用系统 | 提供机组制动、调速器及进水阀油压装置补气、检修维护等用气。 |
| 油压系统 | 公用系统 | 为水轮机调速器和进水阀的操作机构提供压力油源，实现导叶和阀门可靠动作。 |
| 透平油系统 | 公用系统 | 提供机组轴承润滑、液压操作用油，负责油的循环、冷却、净化和再生处理。 |
| 消防报警系统 | 公用系统 | 对厂房、电缆廊道等重点区域进行火灾探测并发出报警，联动消防设施。 |
| 视频监视系统 | 公用系统 | 通过摄像头对主厂房、高压配电室、上下游库区等进行远程实时图像监视。 |
| 上下游水位测量装置 | 公用系统 | 监测水库上下游水位，为水情测报、发电调度和闸门控制提供重要数据。 |
| 水情自动测报系统 | 公用系统 | 实时收集流域内雨量、水位等水文信息，进行洪水预报和水库优化调度决策。 |
| 闸门控制系统 | 公用系统 | 控制溢洪道、泄洪洞、进水口等水工闸门的启闭，执行防洪和引水调度指令。 |
| 暖通空调系统（HVAC） | 公用系统 | 维持厂房、控制室、开关站等区域的温度、湿度和空气质量，保障设备和人员环境。 |
