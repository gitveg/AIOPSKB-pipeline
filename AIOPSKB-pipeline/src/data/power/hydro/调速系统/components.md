| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
|----------|--------|------|----------|----------|----------|
| 调速系统 | — | 控制和调节原动机（如汽轮机、水轮机、内燃机）转速与功率输出的总成。 | 否 | 定期检查系统整体运行参数，包括转速波动率、迟缓率、不灵敏度等指标是否满足规程要求；每年进行一次系统特性试验，校验静特性曲线与动态响应性能；大修期间全面检查液压系统密封性、油质清洁度及控制回路接线状态；定期备份控制器参数与定值数据。 | 调速系统整体报废需经技术鉴定委员会评估，当系统主要功能部件大范围老化损坏、多次大修后性能指标仍无法恢复到规程要求、备件长期停产无法获取、或技术升级改造方案经论证更为经济合理时，方可批准整体报废。 |
| 控制器 | 调速系统 | 接收转速设定值与反馈信号，进行PID运算并输出控制指令的电子或数字装置。 | 否 | 定期检查控制器供电电压是否稳定，各通道信号指示是否正常；每季度清洁控制器机箱内部灰尘，检查接线端子紧固情况；每年校验PID参数与定值是否与设计值一致；大修时进行全面功能测试，包括手自动切换、负荷限制及频率调节功能验证。 | 当控制器主板严重损坏且无法修复、核心芯片或关键元器件停产且无替代方案、多次故障导致保护动作而原因无法消除、或技术淘汰无法满足新的控制精度要求时，应整体更换控制器。 |
| 电源模块 | 控制器 | 为控制器内部电子元件提供稳压直流电源的变换模块。 | 是 | 定期测量输出电压是否在额定范围内（通常±5%以内），检查模块散热是否良好；每半年清洁散热风扇及通风口；观察电源指示灯状态，异常时及时更换；运行中若发现电压波动较大，应在线监测并记录。 | 输出电压持续超出允许偏差范围且无法通过调节恢复；模块内部有烧焦痕迹或明显异响；多次发生因电源不稳定导致的控制器异常复位；散热风扇损坏且模块整体温度持续过高时，应更换电源模块。 |
| 主控单元(CPU) | 控制器 | 执行控制算法、逻辑运算和数据处理的中央处理模块。 | 否 | 定期检查CPU运行状态指示灯及自诊断信息是否正常；每年进行一次程序完整性校验，比对运行版本与备份版本；大修时清除历史故障记录并备份当前配置参数；监视CPU温度，确保散热良好；定期更新控制程序至经过验证的最新版本。 | CPU芯片损坏导致控制器完全失灵且无法通过更换芯片修复；程序存储器损坏且无备份可恢复；经多次维修后仍频繁出现运算错误或死机；厂商已停产该型号且无兼容替代品时，应更换主控单元或整体控制器。 |
| I/O接口卡 | 控制器 | 接收传感器信号并输出控制指令的模拟量与开关量接口板。 | 是 | 定期检查各通道输入输出信号是否与现场实际值一致，校验模拟量精度；每半年检查接线端子紧固状态和接触可靠性；大修时进行通道精度校准，检查光电隔离器件绝缘状况；发现通道偏差超标时及时校准或更换。 | 当I/O通道出现持续性漂移且无法校准、多个通道同时故障、接口卡上元器件烧毁或腐蚀严重、或经反复维修后仍无法保证信号采集精度时，应更换I/O接口卡。 |
| 执行机构 | 调速系统 | 将控制器输出的电信号或液压信号转换为机械位移，驱动调节阀动作。 | 否 | 定期检查执行机构动作是否灵活，有无卡涩、爬行现象；每月检查液压管路接头有无渗漏；每季度测试执行机构响应时间是否符合设计要求；大修时解体清洗检查各运动部件磨损情况，更换老化密封件。 | 当执行机构频繁出现拒动或卡涩、解体检查发现缸体或活塞严重磨损拉伤、多次更换密封件后仍无法消除内漏、或动作特性经反复调试仍不满足系统要求时，应报废更换。 |
| 油动机 | 执行机构 | 液压缸组件，在高压动力油作用下产生直线运动，直接带动调节阀。 | 否 | 定期检查油动机动作行程是否平滑无卡涩，活塞杆表面有无拉伤或腐蚀；每月检查各油口接头密封状况，确保无外泄；每季度进行静态与动态行程试验，验证全行程动作时间；大修时解体检查缸体磨损、活塞密封及导向环状态。 | 缸体内壁严重拉伤或锈蚀无法修复；活塞杆弯曲或表面镀铬层大面积剥落；多次更换密封件后仍持续内泄外漏；经大修后行程特性仍不满足设计要求时，应整体报废油动机。 |
| 伺服阀 | 油动机 | 电液转换元件，精确控制进入油动机的油量及方向，响应控制信号。 | 是 | 定期检查伺服阀零偏电流是否在允许范围内，运行中有无异常振动或啸叫；每季度进行静态流量特性测试；严格控制系统油液清洁度，滤油器滤芯按规定周期更换；大修时送专业检测机构校验，不合格则更换。 | 当伺服阀零偏持续增大且无法通过调整恢复；阀内泄漏量超过允许标准；频率响应特性明显下降；经专业检测机构判定不合格且无法修复；或油液污染导致喷嘴挡板副和滑阀副严重磨损时，应更换伺服阀。 |
| 力矩马达 | 伺服阀 | 将电信号转换为力矩并驱动挡板或阀芯的电磁部件。 | 是 | 定期检查力矩马达线圈电阻值是否在规定范围内，绝缘电阻是否合格；检查衔铁运动是否灵活有无卡滞；运行中监视控制电流是否稳定，异常波动时排查力矩马达性能；大修时进行静态特性测试。 | 线圈断路或短路且无法修复；衔铁永久变形或磁性衰减导致输出力矩不足；经测试力矩-电流特性严重偏离设计曲线且无法调整恢复时，应更换力矩马达或连同伺服阀整体更换。 |
| 喷嘴挡板副 | 伺服阀 | 通过间隙变化改变控制油压的精密节流组件。 | 是 | 严格控制液压油清洁度，按规程定期化验油质并更换滤芯；运行中监视伺服阀控制油压是否稳定，异常波动时排查喷嘴挡板间隙是否被异物堵塞；大修时在洁净环境下拆检清洗喷嘴和挡板，检查有无磨损或冲蚀。 | 喷嘴或挡板表面出现严重冲蚀沟痕导致流量特性劣化；因油液污染造成堵塞经反复清洗仍无法恢复；配合间隙超出设计公差范围且无法修复时，应更换伺服阀或喷嘴挡板组件。 |
| 滑阀阀芯套 | 伺服阀 | 通过滑动改变油路通断和流量的圆柱形阀芯与阀套。 | 是 | 确保液压油清洁度达标，定期更换滤油器滤芯；运行中监视伺服阀输出流量和压力的线性度；大修时专业检测机构进行流量增益和线性度测试；日常严禁在油质不合格情况下长时间运行。 | 阀芯与阀套配合间隙因磨损增大导致内泄漏超标；阀芯表面出现轴向拉伤划痕影响控制精度；经专业检测流量特性严重偏离标准且研磨修复无法恢复时，应更换伺服阀。 |
| 内置滤网 | 伺服阀 | 保护喷嘴挡板副和滑阀副免受大颗粒污染的精密过滤元件。 | 是 | 按厂家规定的检修周期拆检清洗内置滤网；日常维护中严格保证系统油液清洁度在NAS等级要求以内；发现伺服阀工作不稳定时优先排查滤网是否堵塞；清洗时使用专用溶剂，禁止用锐器刮擦滤网表面。 | 滤网破损、变形或孔径扩大无法有效拦截颗粒；滤网经多次清洗后仍频繁堵塞且流通能力明显下降；滤网材质老化脆裂失去过滤功能时，应更换同规格内置滤网。 |
| 位移传感器 | 油动机 | 检测油动机活塞行程，提供反馈信号以实现闭环控制。 | 否 | 定期校验位移传感器输出信号与实际行程的对应关系，检查线性度和灵敏度；每月检查传感器安装紧固状况，确保无松动和移位；大修时进行全量程精度校准；检查传感器电缆有无破损、屏蔽层接地是否良好。 | 传感器输出信号严重漂移且无法校准；线圈断路或短路导致无信号输出；铁芯或测杆弯曲变形影响测量精度；经多次校准后精度仍无法满足闭环控制要求时，应更换位移传感器。 |
| LVDT线圈 | 位移传感器 | 产生次级感应电势以反映铁芯位置的差动变压器绕组。 | 是 | 定期测量线圈电阻和绝缘电阻是否合格；检查线圈外壳有无机械损伤或油液侵蚀；运行中监视LVDT输出信号的对称性和线性度；大修时进行全量程校准试验，记录灵敏度变化趋势。 | 线圈绝缘电阻持续下降且低于安全标准；绕组断路或匝间短路导致输出信号异常；外壳破损导致线圈受潮或油浸损坏；经校准试验确认线性度或灵敏度严重偏离设计值且无法修复时，应更换LVDT线圈。 |
| 快速卸荷阀 | 油动机 | 在紧急停机时快速卸掉油动机内的压力油，使阀门迅速关闭。 | 是 | 定期进行快速卸荷阀动作试验，验证开启时间是否满足设计要求（通常小于0.1秒）；每月检查阀体密封状况和弹簧预紧力；大修时解体检查阀芯与阀座密封面、弹簧疲劳状态及各油口通道是否畅通。 | 阀芯密封面严重损坏导致关不严；弹簧断裂或严重疲劳导致动作不可靠；动作试验中开启时间严重超标；经多次研磨修复后仍无法保证密封性和快速响应性能时，应报废更换。 |
| 活塞动密封 | 油动机 | 防止油动机高低压腔之间内泄漏的密封环。 | 是 | 定期监测油动机在保压状态下活塞有无缓慢漂移，判断密封环磨损程度；大修时测量密封环尺寸，检查有无变形、硬化或表面损伤；按规定周期在检修中更换活塞密封环；保持油液清洁度以减少对密封件的磨损。 | 密封环严重磨损导致油动机内泄增大、活塞漂移超出允许范围；密封环材料老化硬化失去弹性；密封环表面出现深划痕或局部缺损无法保证密封效果时，应更换活塞动密封。 |
| 供油装置 | 调速系统 | 为执行机构提供稳定压力和清洁度的液压动力源。 | 否 | 定期检查油箱油位和油温是否在正常范围；每月检查油泵运行声音和振动是否异常；按周期化验油液清洁度、水分含量和酸值，不合格时及时换油或净化处理；定期检查管路系统有无渗漏；大修时全面清洗油箱和管路，更换所有滤芯。 | 当油箱严重锈蚀穿孔、主油泵多次故障且整体性能劣化、管路系统老化渗漏严重且修复费用接近更换成本、或供油装置已无法提供系统所需的压力和流量时，经技术鉴定可报废更换整台供油装置。 |
| 油箱 | 供油装置 | 储存、沉降杂质和逸出气泡的液压油容器。 | 否 | 定期检查油箱外观有无锈蚀、渗漏和变形；每年清洗油箱内部，清除底部沉积的水分和杂质；检查油箱呼吸器或空气滤清器是否畅通；大修时对油箱内壁进行防腐处理；保持油位在正常范围，避免过低导致吸入空气或过高导致溢油。 | 油箱壁板严重锈蚀减薄出现针孔或裂纹；箱体焊缝开裂且补焊后仍反复渗漏；内部防腐涂层大面积脱落导致油质持续劣化；箱体变形严重影响安装和使用时，应更换油箱。 |
| 主油泵 | 供油装置 | 提供系统所需的高压工作油。 | 否 | 定期检查油泵出口压力和流量是否正常；监听运行声音有无异常噪音或振动；每月检查轴封有无渗漏；大修时检测泵内部件磨损量，测量齿轮或柱塞配合间隙；定期检查联轴器对中情况。 | 泵体出现裂纹；齿轮或柱塞磨损导致容积效率显著下降且无法通过更换部件恢复；轴承损坏导致转子磨损严重；多次维修后仍无法达到额定压力和流量时，应报废更换主油泵。 |
| 联轴器 | 主油泵 | 连接电机或原动机主轴与油泵轴，传递扭矩的挠性或刚性元件。 | 是 | 定期检查联轴器弹性元件有无老化、变形或撕裂；测量联轴器对中偏差，超标时重新找正；检查紧固螺栓有无松动；大修时检查联轴器齿面或柱销磨损情况。 | 弹性元件严重老化开裂、齿面磨损过量导致传动间隙过大、柱销断裂或变形、联轴器本体出现裂纹或严重锈蚀时，应更换联轴器。 |
| 溢流阀 | 供油装置 | 调节并稳定供油压力，保护系统免于超压。 | 是 | 定期校验溢流阀设定压力是否准确，动作是否灵活可靠；每月检查阀体有无渗漏；大修时解体检查阀芯和阀座密封面磨损情况，检查弹簧有无永久变形。 | 阀芯密封面严重损坏导致无法维持设定压力；弹簧断裂或严重疲劳导致设定压力漂移；经反复研磨和调整仍无法恢复调压精度；阀体内壁严重拉伤时，应更换溢流阀。 |
| 蓄能器 | 供油装置 | 储存压力能，补偿泄漏并维持压力稳定，缓冲压力波动。 | 是 | 定期检查蓄能器充气压力是否在规定范围内，低于下限时及时补充氮气；每月检查蓄能器接口有无渗漏；大修时检查壳体有无变形和锈蚀，校验安全阀或爆破片。 | 壳体出现裂纹或严重变形；疲劳寿命超过厂家规定年限；充气后压力持续快速下降表明内部严重泄漏；经检验机构认定不合格时，应报废更换蓄能器。 |
| 蓄能器皮囊 | 蓄能器 | 分离气体与液压油的弹性隔离膜，承受交变压力。 | 是 | 定期监测蓄能器保压性能，判断皮囊有无内泄；按规定周期（通常2-3年）更换皮囊；充气时严格按照规定压力操作，避免超压损坏皮囊；检查气侧有无油味以判断皮囊是否破裂。 | 皮囊破裂导致气油混合；皮囊老化硬化失去弹性；皮囊表面出现裂纹或永久变形；蓄能器充气后短时间内压力迅速下降确认皮囊失效时，应更换皮囊。 |
| 滤油器 | 供油装置 | 滤除液压油中的颗粒污染物，保证油液清洁度。 | 是 | 当压差指示器报警时及时更换滤芯；定期检查滤油器壳体和密封有无渗漏；大修时清洗滤油器壳体内部，更换全部滤芯；检查旁通阀动作是否灵活可靠。 | 滤油器壳体严重锈蚀或变形；内部旁通阀损坏且无法修复；滤芯安装座损坏导致密封不可靠；经多次维修后仍无法保证过滤精度和通流能力时，应更换滤油器。 |
| 冷却器 | 供油装置 | 控制液压油温度，防止过热导致油液劣化。 | 否 | 定期检查冷却器进出口油温差是否在正常范围；每月检查冷却水管路有无渗漏；大修时清洗冷却器水侧和油侧，清除水垢和沉积物；冬季停用时应排空冷却水防止冻裂。 | 冷却器管束腐蚀穿孔导致油水混合；端盖或壳体严重锈蚀变形；换热效率严重下降且清洗后无法恢复；多次堵管后冷却面积不足时，应更换冷却器。 |
| 温控阀 | 冷却器 | 根据油温自动切换油流路径，控制流过冷却器流量的感温阀门。 | 是 | 定期检查温控阀动作温度设定是否准确；每月检查阀体有无渗漏；大修时校验感温元件特性，检查阀芯运动是否灵活；运行中监视油温变化曲线，判断温控阀是否正常工作。 | 感温元件失效导致阀门无法正常切换；阀芯卡死在某一位置无法动作；阀体内部严重腐蚀或泄漏；经校验动作温度偏差超出允许范围且无法调整时，应更换温控阀。 |
| 转速传感器 | 调速系统 | 测量原动机实际转速，提供转速反馈信号。 | 是 | 定期校验传感器输出信号精度，检查与实际转速的一致性；每月检查传感器安装间隙和紧固状态；大修时进行全量程精度校准；检查传感器电缆有无破损，屏蔽接地是否可靠。 | 传感器输出信号严重失真或漂移且无法校准；线圈断路或短路无信号输出；外壳破损导致内部受潮损坏；经多次校准后精度仍不满足转速测量要求时，应更换转速传感器。 |
| 测速探头 | 转速传感器 | 感应齿轮盘齿顶通过时产生脉冲信号的磁电或涡流敏感元件。 | 是 | 定期检查探头安装间隙是否符合厂家规定（通常0.5-1.5mm）；每月检查探头表面有无油污或金属屑附着并清洁；大修时测量探头线圈电阻和绝缘电阻，校验输出脉冲幅度和波形。 | 探头线圈断路或短路导致无脉冲输出；探头端面磨损或损伤导致信号异常；输出脉冲幅度严重衰减且无法通过调整安装间隙恢复；绝缘电阻持续下降不合格时，应更换测速探头。 |
| 调节阀 | 调速系统 | 受执行机构驱动，改变进入原动机的工质（蒸汽、水、燃油等）流量。 | 否 | 定期检查阀杆运动是否灵活无卡涩；每月检查阀体密封状况，有无外泄漏；大修时解体检查阀芯和阀座密封面状况，测量各部位间隙；进行阀门全行程动作试验，验证线性度和死区。 | 阀体出现裂纹或严重腐蚀减薄；阀杆弯曲变形无法修复；阀座冲蚀严重无法通过研磨恢复密封；多次大修后仍无法满足调节精度和密封要求时，应报废更换调节阀。 |
| 阀杆 | 调节阀 | 连接执行机构与阀芯，传递推拉力的长杆。 | 否 | 定期检查阀杆表面有无腐蚀、拉伤或磨损痕迹；大修时测量阀杆直线度和表面粗糙度；检查阀杆与填料函配合间隙是否在允许范围内；保持填料压盖适度压紧，避免过紧导致阀杆磨损。 | 阀杆严重弯曲无法校直；表面大面积腐蚀或拉伤导致与密封件配合间隙超标；因疲劳出现裂纹；多次修复后仍无法满足密封和运动精度要求时，应更换阀杆。 |
| 阀芯 | 调节阀 | 直接改变流道面积的节流元件。 | 是 | 定期检查阀芯型面和密封面有无冲蚀、磨损或积垢；大修时研磨阀芯密封面恢复光洁度；测量阀芯与阀座接触线宽度和吻合度；运行中注意监听阀门有无异常汽流噪声。 | 阀芯型面严重冲蚀导致流量特性曲线偏离设计值；密封面磨损过深无法通过研磨修复；阀芯出现裂纹或变形；多次研磨后阀芯尺寸减小超出公差范围时，应更换阀芯。 |
| 阀座 | 调节阀 | 与阀芯配合形成密封线且承受工质冲刷的固定元件。 | 是 | 大修时检查阀座密封面有无冲蚀沟痕和压痕；研磨密封面恢复光洁度和密封线宽度；测量阀座内孔尺寸，检查是否因冲蚀扩大；每次研磨后测量剩余厚度以评估剩余寿命。 | 阀座密封面冲蚀深度过大，研磨后仍无法保证密封；阀座内孔严重扩大超出公差；阀座出现裂纹或松动；经多次研磨后剩余厚度不足时，应更换阀座或整体更换调节阀。 |
| 密封组件 | 调节阀 | 防止工质沿阀杆泄漏的填料或密封环。 | 是 | 定期检查填料函有无泄漏，发现渗漏时适当压紧填料压盖；大修时全部更换密封填料或密封环；检查阀杆表面状况，避免因阀杆粗糙导致密封件加速磨损；选择耐高温、耐磨的合适材料。 | 密封材料老化硬化失去弹性；多次压紧后仍无法阻止泄漏；密封面出现深划痕或烧蚀痕迹；填料或密封环被介质腐蚀变质无法继续使用时，应更换密封组件。 |
| 危急遮断器 | 调速系统 | 当转速超过安全极限时，通过机械或电子方式触发紧急停机。 | 否 | 定期进行危急遮断器动作试验，验证动作转速是否在设定范围内（通常为额定转速的110%-112%）；每月检查遮断器机械部件有无锈蚀和卡涩；大修时解体检查飞锤或离心机构，校验弹簧预紧力和动作整定值。 | 遮断器弹簧严重疲劳导致动作转速漂移超出允许范围；飞锤或离心机构严重磨损导致动作不可靠；经多次调整仍无法在规定转速下可靠动作；外壳或支架出现裂纹影响安装稳定性时，应报废更换。 |
| 飞锤 | 危急遮断器 | 在超速离心力作用下飞出，撞击跳闸装置。 | 是 | 定期检查飞锤表面有无锈蚀、裂纹和磨损；大修时测量飞锤质量偏差和偏心距是否在允许范围内；检查飞锤导槽磨损情况，确保飞锤运动灵活无卡涩；每次超速试验后检查飞锤有无变形。 | 飞锤表面出现裂纹（不允许继续使用）；质量偏差超出允许范围影响动作精度；导槽磨损严重导致飞锤运动不稳定；飞锤端部撞击面变形或崩损时，应更换飞锤。 |
| 复位装置 | 危急遮断器 | 将脱离的遮断机构重新挂闸，恢复正常运行状态。 | 否 | 定期检查复位装置动作是否灵活可靠；大修时检查复位弹簧有无疲劳变形、复位杠杆和连杆有无磨损；检查挂闸机构的保持力是否足够；操作复位时确认遮断器可靠挂闸且自保持。 | 复位弹簧断裂或严重疲劳变形；挂闸机构严重磨损导致无法可靠自保持；复位杠杆或连杆出现裂纹或严重变形；经检修后仍无法可靠完成挂闸操作时，应更换复位装置。 |
| 试验滑阀 | 危急遮断器 | 可在运行中手动或遥控引压，模拟超速动作以检验遮断功能的阀组。 | 否 | 定期利用试验滑阀进行危急遮断器在线试验，验证功能正常；大修时解体检查阀芯与阀座密封面、弹簧状态及油路通道是否畅通；操作试验后确认滑阀可靠复位，不影响正常保护功能。 | 阀芯密封面严重损坏导致内泄无法建立试验压力；弹簧断裂或疲劳导致滑阀无法可靠复位；阀体出现裂纹或内壁严重拉伤；经检修后仍无法可靠完成试验功能时，应更换试验滑阀。 |
| 配汽机构 | 调速系统 | 连接油动机与多个调节阀的杠杆、凸轮或连杆系统，实现顺序开启。 | 否 | 定期检查配汽机构各连杆和杠杆有无变形、裂纹和磨损；每月检查各铰接点润滑状况，及时加注润滑脂；大修时测量各铰接轴承间隙，检查凸轮型面磨损程度；校验各调节阀开启顺序和重叠度是否符合设计要求。 | 配汽机构主要连杆或杠杆出现裂纹或严重变形；凸轮型面严重磨损导致阀门开启特性偏离设计曲线；多个铰接轴承损坏导致系统运动精度严重下降；整体修复费用接近更换成本时，应报废更换。 |
