| 水泵水轮机 | — | 可逆式水力机械，兼具水泵与水轮机功能，实现抽水与发电双向运行 | 否 | 每年进行机组全面检查，监测运行振动、噪声和效率变化，检查各过流部件磨蚀情况，核实导水机构和密封工作状态 | 转轮严重损坏、蜗壳或座环出现裂纹且无法修复或整机效率严重下降且改造不经济时报废 |
| 转轮 | 水泵水轮机 | 核心能量转换部件，通过叶片与水流相互作用实现动能与机械能的双向转换 | 否 | 每年检查叶片表面空蚀和磨损情况，测量叶片型线变化，进行无损探伤检查 | 叶片大面积空蚀穿孔、裂纹无法补焊修复或型线严重变形导致效率显著下降时更换转轮 |
| 叶片 | 转轮 | 直接承受水力矩的曲面部件，其型线决定机组效率与空化性能，高流速下易发生空蚀 | 是 | 每年检查叶片进出水边空蚀深度和面积，进行打磨修型和补焊处理，核实叶片型线与设计偏差 | 空蚀深度超过叶片厚度1/3、补焊修复面积累计超过叶片面积30%或裂纹扩展无法修复时更换叶片或转轮 |
| 上冠 | 转轮 | 转轮上部轮毂结构，传递扭矩并连接主轴，承受轴向水推力 | 否 | 每年检查上冠与主轴连接螺栓紧固力矩，检查密封面和配合面磨损情况 | 上冠出现裂纹、与主轴配合面严重磨损或连接螺栓孔变形无法修复时更换上冠 |
| 下环 | 转轮 | 转轮外缘环形结构，与叶片出水边连接，保持叶片位置并引导水流 | 否 | 每年检查下环外圆面磨蚀情况和变形量，测量与止漏环的间隙 | 下环严重磨蚀变形导致与止漏环间隙超标、出现裂纹或影响机组效率时更换下环 |
| 止漏环 | 转轮 | 安装于转轮上冠与下环处的密封环，减小高压水泄漏造成的容积损失，受磨蚀间隙增大 | 是 | 每年测量止漏环间隙并与原始值比较，检查环面磨蚀和偏磨情况，间隙超限时更换 | 间隙增大至设计值2倍以上、环面严重磨蚀出现沟槽或偏磨超标导致效率显著下降时更换止漏环 |
| 主轴 | 水泵水轮机 | 连接转轮与发电机/电动机的旋转轴，传递扭矩并承受轴向与径向载荷 | 否 | 每年大修时检查轴颈表面磨损和圆度，检查法兰连接螺栓紧固力矩，进行超声波探伤 | 主轴出现裂纹、轴颈磨损超标导致摆度不合格或法兰面严重损伤无法修复时更换主轴 |
| 主轴密封 | 主轴 | 阻止压力水沿主轴泄漏至机坑的动密封装置，通常由工作密封与检修密封组成 | 是 | 每月检查密封泄漏量，监测密封水压和温度，检查密封环磨损厚度 | 密封环磨损量超过允许值、泄漏量持续增大或密封水系统异常导致密封失效时更换密封组件 |
| 水导轴承 | 主轴 | 承受径向水推力引起的轴系摆度，保证主轴旋转精度，瓦面材料需耐磨损 | 是 | 每月监测轴瓦温度和油位，检查油质和冷却水流量，大修时检查瓦面磨损和间隙 | 瓦面巴氏合金严重磨损脱胎、间隙超过允许值或温度持续超标无法通过调整恢复时更换轴瓦 |
| 推力轴承 | 主轴 | 承受机组全部转动部件的轴向水推力及重力，布置于发电机端或直接作用于水轮机顶盖上 | 是 | 每月监测瓦温和油温，检查油质和冷却系统，大修时测量瓦面磨损和油膜厚度 | 推力瓦巴氏合金大面积烧损、瓦面磨损严重或承载力不足导致温度持续超标时更换推力瓦 |
| 主轴中心孔补气管 | 主轴 | 通过主轴中心孔向转轮出口补入空气，改善压力脉动与空化，其密封与逆止阀易失效 | 是 | 每年检查补气管密封和逆止阀动作灵活性，核实补气效果和管路畅通 | 逆止阀卡涩导致水倒灌、密封失效严重泄漏或管路腐蚀穿孔时更换补气管组件 |
| 导水机构 | 水泵水轮机 | 调节通过转轮的流量与环量，实现机组启停、功率调节及工况转换 | 否 | 每年检查导叶开度同步性和关闭严密性，测试剪断销状态，核实接力器动作平稳 | 导水机构整体损坏严重、多数导叶不同步或关闭不严且维修成本过高时大修或整体更换 |
| 活动导叶 | 导水机构 | 圆周均布的可转动导叶，通过改变开度控制流量，其端面及立面间隙密封为易损点 | 否 | 每年检查导叶表面空蚀和磨损，测量端面和立面间隙，核实开关灵活无卡涩 | 导叶严重空蚀穿孔、变形导致关闭不严或轴颈磨损超标影响旋转精度时更换导叶 |
| 导叶端面密封 | 活动导叶 | 安装于导叶上下端面的耐磨密封条，防止水泄露，长时间运行后易磨损 | 是 | 每年检查密封条磨损量和压紧力，间隙超限时调整或更换密封条 | 密封条磨损超过允许厚度、硬化失去弹性或导叶关闭时漏水量超标时更换密封条 |
| 导叶立面密封 | 活动导叶 | 相邻导叶搭接处的接触密封，停止时需严密闭合，随磨损密封性能下降 | 是 | 每年检查立面接触状态和密封压力，测量全关时导叶漏水量 | 立面密封严重磨损导致漏水量超过允许标准、导叶接触面损伤无法修复时更换密封或研磨导叶 |
| 导叶轴套 | 活动导叶 | 支撑导叶轴颈的滑动轴承套，保证转动灵活，磨损后间隙增大导致水力振动 | 是 | 每年测量轴套间隙和导叶偏斜量，检查轴套表面磨损和润滑水畅通性 | 轴套间隙超过允许值导致导叶晃动、表面严重拉伤或润滑水路堵塞无法疏通时更换轴套 |
| 导叶操作机构 | 导水机构 | 由控制环、连杆、拐臂组成，将接力器位移转换为各导叶的同步转动 | 否 | 每年检查各连杆销轴和拐臂磨损量，测量配合间隙，润滑各铰接点 | 销轴严重磨损导致导叶不同步、连杆变形或拐臂断裂时更换操作机构零件 |
| 控制环 | 导叶操作机构 | 外圆周安装的环形构件，接收接力器推拉力并通过连杆同步驱动所有导叶 | 否 | 每年检查控制环滑动面磨损和润滑情况，核实与接力器连接销轴间隙 | 滑动面严重磨损导致运动不平稳、销轴孔变形或出现裂纹时更换控制环 |
| 接力器 | 导水机构 | 液压活塞式执行器，输出大扭矩摆动或直线运动，驱动控制环实现导叶启闭 | 否 | 每季度检查接力器密封和活塞杆磨损，监测动作速度和行程，核实关闭时间和压紧行程 | 活塞杆严重拉伤漏油、密封老化导致内泄严重或输出力不足无法驱动导叶时更换接力器 |
| 底环 | 导水机构 | 安装于座环下方，用于支撑导叶下轴颈并形成过流表面，承受水流冲刷 | 否 | 每年检查底环过流面磨蚀情况和导叶轴孔磨损量，核实与座环连接紧固 | 过流面严重磨蚀出现深沟、导叶轴孔磨损超标或连接螺栓松动无法紧固时更换底环 |
| 座环 | 水泵水轮机 | 整体承重件，将机组上部重量及座环上混凝土重量传递至厂房基础，并为导水机构提供支撑 | 否 | 每年检查座环固定导叶表面磨蚀和裂纹情况，核实基础螺栓紧固状态 | 座环出现裂纹影响结构安全、固定导叶严重损坏或基础沉降导致中心偏移时评估修复或更换 |
| 座环固定导叶 | 座环 | 连接座环上下环的固定叶片，引导水流进入活动导叶并传递轴向载荷 | 否 | 每年检查固定导叶表面磨蚀和进出水边空蚀情况，进行无损探伤检查 | 固定导叶出现裂纹、表面严重空蚀影响水流形态或型线变形导致效率下降时评估修复方案 |
| 蜗壳 | 水泵水轮机 | 圆形断面的引水部件，均匀分配水流至座环周围，保证导叶入口流场均匀 | 否 | 每年检查蜗壳内壁磨蚀和防腐层状态，测量壁厚减薄情况，检查进人门密封 | 蜗壳壁厚减薄超过允许值、出现裂纹或防腐层大面积脱落导致严重锈蚀时评估补强或更换 |
| 蜗壳进人门 | 蜗壳 | 蜗壳上的检修通道孔，供人进入内部检查清洗，密封垫圈易老化漏水 | 是 | 每年检查进人门密封垫圈老化情况，核实螺栓紧固力矩，检查门体铰链灵活性 | 密封垫圈老化硬化导致反复漏水、门体严重锈蚀变形或铰链断裂无法密封时更换密封件或进人门 |
| 尾水管 | 水泵水轮机 | 回收转轮出口水流余速动能并引导至下游，水泵工况时作为进水管 | 否 | 每年检查尾水管里衬磨蚀情况和混凝土壁面状态，核实排水阀密封 | 尾水管里衬大面积脱落、混凝土严重冲刷或变形影响水力效率时评估修复方案 |
| 尾水管里衬 | 尾水管 | 尾水管锥管段内的钢板衬砌，保护混凝土壁面，承受含沙水流冲刷与空蚀破坏 | 是 | 每年检查里衬钢板磨蚀和空蚀情况，测量壁厚减薄，检查与混凝土结合状态 | 钢板壁厚减薄超过允许值、大面积空蚀穿孔或与混凝土脱空严重时更换里衬 |
| 顶盖 | 水泵水轮机 | 封闭转轮上冠区域的压力腔，支撑导叶上轴颈，安装主轴密封及水导轴承 | 否 | 每年检查顶盖内腔磨蚀情况和排水管畅通性，核实与座环连接密封和导叶轴孔磨损 | 顶盖出现裂纹、导叶轴孔严重磨损或密封面损伤导致漏水严重时更换顶盖 |
