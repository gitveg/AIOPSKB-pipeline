| 主变线路保护测控屏 | — | 安装于变电站内，集主变压器保护、线路测控、操作、通信于一体的屏柜系统。 | 否 | 每年全面检查屏柜接地、各装置运行状态和指示灯；核对保护定值和通信参数；大修时对整套保护系统做传动试验和定值校验；保持屏内清洁干燥，温湿度控制器功能正常。 | 屏柜内核心装置（保护装置、测控装置、操作箱）同时严重损坏，经技术经济评估整体更换。拆除前备份全部定值和配置，断电后依次拆除各装置和接线。 |
| 屏柜体 | 主变线路保护测控屏 | 采用冷轧钢板制作，提供电磁屏蔽、接地保护及设备安装固定的结构件。 | 否 | 每年检查屏柜体有无变形和锈蚀；检查门锁和密封条完好性；紧固各装置安装螺丝；检查接地铜排连接可靠。 | 屏柜体严重变形或大面积锈蚀影响防护等级；门体密封失效导致灰尘进入无法修复。整体更换屏柜体时需将内部装置逐台移出重新安装。 |
| 保护装置 | 主变线路保护测控屏 | 微机保护单元，实现主变差动保护、后备保护及非电量保护等功能。 | 否 | 定期核对保护定值并做定值单管理；每年做保护功能校验（差动、过流、零序等）；大修时进行全面传动试验；备份保护程序和配置参数；检查各板卡工作状态指示灯。 | 保护装置核心板卡损坏且型号停产无替代；多次保护误动或拒动经厂家维修仍不合格。更换保护装置后重新下载定值和配置，做全部保护功能传动试验。 |
| CPU板 | 保护装置 | 内置数字信号处理器，执行保护算法、逻辑判别和数据处理的中央核心模块。 | 否 | 每年检查CPU板工作指示灯状态；通过调试软件检查运行日志和自检报告；备份保护程序和定值文件。 | CPU板故障导致装置频繁死机或重启，且无法通过更换板卡修复。更换时核对硬件版本和固件兼容性，换后下载程序。 |
| 电源板 | 保护装置 | 将直流220V/110V输入转换为装置所需的各等级低压直流电源的模块。 | 是 | 每年测量电源板各路输出电压是否在允许范围内；检查电解电容有无鼓包；检查散热片温度。运行中如装置频繁复位应优先排查电源板。 | 输出电压严重偏移或纹波超标导致装置工作异常；电容鼓包或PCB变色。更换同型号电源板后测量输出电压确认正常。 |
| 交流采样板 | 保护装置 | 通过电压/电流互感器采集模拟量，进行模数转换，为保护计算提供数据。 | 否 | 每年校验采样精度（幅值、相位），超差时校准或更换；检查接线端子紧固。 | 采样精度持续超差且无法通过校准恢复；A/D转换芯片损坏。更换采样板后重新校准全通道精度。 |
| 开入板 | 保护装置 | 光电隔离的开关量输入模块，用于采集断路器位置、压板状态等外部信号。 | 否 | 每年检查各开入通道响应是否正常（逐一变位测试）；检查光耦有无老化（输入电流阈值偏移）。 | 多个通道失效导致开入信号采集错误；光耦大面积老化。更换开入板后验证全部通道功能。 |
| 开出板 | 保护装置 | 通过继电器输出跳闸、合闸、告警等开关量信号的驱动模块。 | 是 | 每年检查继电器输出触点接触电阻；做开出传动试验验证各通道动作可靠性；检查继电器底座有无过热变色。 | 多个继电器触点严重烧蚀导致接触电阻超标；继电器线圈烧毁。更换开出板后做全通道传动试验。 |
| 液晶面板 | 保护装置 | 集液晶显示屏与按键于一体的人机界面，用于定值整定、报文查看和实时显示。 | 是 | 定期检查液晶屏显示是否清晰完整、背光是否正常；按键功能是否灵敏；清洁面板表面。 | 液晶屏大面积坏点或完全黑屏；按键失灵无法操作。更换液晶面板后核对显示参数与装置一致。 |
| 测控装置 | 主变线路保护测控屏 | 负责对线路进行电气参数测量、遥信采集和遥控执行的自动化装置。 | 否 | 定期校验遥测精度（电压、电流、功率）；检查遥信和遥控功能是否正常；核对通信参数；备份配置数据。 | 核心板卡损坏且无法替代；测量精度持续超差影响调度监控。更换测控装置后重新校准和对点。 |
| 通信板 | 测控装置 | 具备以太网口、RS-485等接口，实现与站控层或调度端的IEC61850等规约通信。 | 否 | 定期检查通信状态指示灯和数据传输是否正常；用网络测试工具检查通信报文；检查接口端子紧固。 | 通信接口全部失效或协议栈异常无法恢复。更换通信板后重新配置通信参数和协议。 |
| 操作箱 | 主变线路保护测控屏 | 包含分合闸回路、防跳回路及位置监视回路，执行断路器出口操作的控制单元。 | 否 | 每年做分合闸操作试验；检查防跳回路功能是否正常；测量跳合闸线圈电流和动作时间；检查继电器底座和接线有无过热变色。 | 操作箱内部继电器大面积损坏或回路板烧毁；多次操作失灵经维修仍不可靠。更换操作箱后做完整的分合闸和防跳功能试验。 |
| 防跳继电器 | 操作箱 | 在合闸于故障时，防止断路器发生多次"合-跳"循环的专用继电器。 | 是 | 每年校验防跳继电器动作电压和返回电压；检查触点接触电阻；做防跳功能试验验证动作逻辑。 | 继电器动作电压偏移导致不可靠动作；触点严重烧蚀。更换同规格继电器后做防跳功能试验。 |
| 跳闸保持继电器 | 操作箱 | 即使外部跳闸脉冲消失，仍可保持跳闸出口信号，确保回路可靠断开的继电器。 | 是 | 每年检查触点接触电阻和动作时间；做保持功能试验；检查线圈电阻。 | 保持功能失效或触点接触电阻超标。更换同规格继电器后做功能试验。 |
| 打印机 | 主变线路保护测控屏 | 针式或热敏打印机，用于实时或召唤打印保护动作报告、事件顺序及录波记录。 | 否 | 每季度检查打印头清洁度和打印清晰度；检查纸张和色带/碳带余量；做自检打印测试。 | 打印头严重磨损导致打印不清晰且无法更换；控制板故障。更换同型号打印机后配置通信参数。 |
| 交换机 | 主变线路保护测控屏 | 用于屏内装置间及与站控层网络的工业以太网数据交换设备。 | 是 | 每季度检查交换机运行状态灯；检查端口通信是否正常；清理散热孔灰尘；备份配置。 | 交换机端口大面积失效或频繁死机；电源模块故障。更换交换机后重新配置VLAN和端口参数。 |
| 端子排 | 主变线路保护测控屏 | 屏内电气连接的接线端子，提供外部电缆接入、回路配线和电气隔离节点。 | 否 | 每年检查端子紧固力矩（逐个紧固）；检查端子有无过热变色和氧化；清理端子表面灰尘；测量绝缘电阻。 | 端子排大面积氧化或烧蚀导致接触不良；绝缘件老化开裂。更换端子排时逐线标记再拆除，安装后逐线恢复并紧固。 |
| 空气开关 | 主变线路保护测控屏 | 对各装置电源回路、控制回路提供过载和短路保护的低压断路器。 | 是 | 每年检查空气开关分合操作是否正常；测量触头接触电阻；检查接线端子紧固。运行中如频繁跳闸需排查回路负载。 | 触头严重烧蚀导致接触电阻超标；机构卡涩无法分合。更换同规格空气开关后测试分合功能。 |
| 压板 | 主变线路保护测控屏 | 用以投退保护功能或控制出口回路的连接片，实现运行方式的灵活管理。 | 否 | 每年检查压板接触是否良好（测量接触电阻）；检查压板标签是否清晰完整；清洁压板表面氧化层。 | 压板接触片严重氧化或变形导致接触不可靠；绝缘座开裂。更换同规格压板后核对标签。 |
| 指示灯 | 主变线路保护测控屏 | LED信号灯，指示装置电源、运行状态、保护动作、事故及预告信号。 | 是 | 每季度检查指示灯亮度是否正常，有无不亮或常暗；检查灯座接触是否良好。 | 多个LED灯珠烧毁导致状态指示不完整；灯座腐蚀接触不良。更换同规格指示灯组件。 |
| 温湿度控制器 | 主变线路保护测控屏 | 监测屏内温湿度，并自动控制加热器与风扇以防止凝露、过热的控制器。 | 是 | 每季度检查温湿度传感器读数是否准确（与标准仪表比对）；检查加热器和风扇控制输出是否正常；清洁传感器表面。 | 传感器失效导致控制失灵；控制板损坏且无备件。更换温湿度控制器后重新整定控制阈值并做联动试验。 |
| 加热器 | 温湿度控制器 | 铝合金加热元件，在湿度高或低温时启动加热，驱除湿气，保持设备绝缘。 | 是 | 每年检查加热器表面温度是否正常（通电测试）；测量绝缘电阻；检查接线端子有无过热变色。 | 加热丝断路导致无法加热；绝缘击穿。更换同功率加热器后测试加热功能。 |
| 风扇 | 温湿度控制器 | 轴流风扇，用于屏内温度过高时强制通风散热，保障元件可靠运行。 | 是 | 每季度检查风扇运转有无异响和振动；清理扇叶积灰；检查运转电流。 | 风扇电机烧毁或轴承卡死；扇叶断裂变形。更换同规格风扇后检查转向和风量。 |
