| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 基础本体 | — | 将风电机组和塔筒的全部载荷（自重、风载、地震等）传递至地基的结构，常见型式有重力式扩展基础（陆上主流）、桩基础（海上/软土）和岩石锚杆基础。混凝土强度C35~C60。 | 否 | 每年检查基础表面有无裂缝、沉降和倾斜；每2~3年进行沉降观测；检查排水系统是否通畅；大修时进行混凝土强度和碳化深度检测。 | 基础不均匀沉降超限无法纠偏、大面积结构性裂缝、混凝土严重碳化或腐蚀导致强度不足。需重新浇筑，废混凝土破碎后作建筑填料。 |
| 锚栓笼/基础环 | 基础本体 | 连接塔筒底部法兰与基础的预埋金属构件。锚栓笼由上锚板、下锚板和高强度锚栓组成；基础环为预埋钢筒。 | 否 | 大修时检查锚栓预紧力；无损检测锚栓有无疲劳裂纹；检查灌浆层有无开裂和剥离；检查基础环水平度（误差≤3mm）。 | 锚栓断裂或疲劳裂纹、基础环严重变形或腐蚀穿孔。更换需破除基础局部混凝土，施工难度大。 |
| 预应力锚栓 | 锚栓笼/基础环 | 连接上下锚板的高强度锚栓（M36~M48），张拉力250~400kN，承担塔筒与基础的拉压交变载荷。 | 是 | 按运行年限定期抽检预紧力（每年10%~20%）；大风季或台风后检查；检查防腐状态（涂黄油或防锈剂保护）。 | 锚栓断裂、螺纹滑丝、疲劳裂纹超过允许值。更换同规格锚栓，重新张拉至设计值。 |
| 灌浆层 | 基础本体 | 填充塔筒底法兰与基础顶面之间的高强度无收缩灌浆料层，厚度30~50mm，抗压强度≥80MPa，确保均匀传力。 | 是 | 大修时检查灌浆层有无开裂、破碎和剥离；敲击检查有无空鼓；必要时取芯检测抗压强度。 | 灌浆层大面积破碎或剥离、空鼓面积超过20%。凿除旧灌浆层后重新灌注，养护期间禁止加载。 |
| 排水系统 | 基础本体 | 基础周边的排水沟和集水井，防止雨水积聚浸泡基础地基，导致承载力下降。 | 否 | 定期清理排水沟和集水井内杂物；雨季前后重点检查；检查排水坡度是否有效。 | 排水沟严重破损、集水井坍塌。修复排水设施，重新硬化。 |
| 防冲刷保护 | 基础本体 | 海上或沿海风电机组基础周边防海流冲刷设施（抛石、砂被、固化土、仿生草），防止基础裸露和承载力丧失。 | 是 | 每年水下检测或声呐扫测基础周边冲刷深度；抛石区检查石块位移；台风或大浪后重点检查。 | 抛石被冲散、砂被破损、冲刷深度超过设计警戒值。重新补抛石或铺设砂被。 |
