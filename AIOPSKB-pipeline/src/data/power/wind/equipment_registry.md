| 设备类型名称 | 设备属性 | 描述 |
|----------|----------|------|
| 风电机组 | 主设备 | 将风能转化为电能的成套主机设备，包含叶轮、传动链、发电机、机舱等集成单元，整机采购（金风/明阳/远景/运达），整体运维。内部子系统（润滑、冷却、避雷、振动监测等）随整机集成供货。 |
| 箱式变压器（风电用） | 主设备 | 每台风电机组专属的紧凑型升压变压器，将风机出口低压（690V）升至集电线路电压（35kV），一机一变，故障直接导致对应风机停运。 |
| 风速风向仪 | 辅助设备 | 实时测量风电机组处的风速和风向，为主控和偏航提供输入 |
| 塔筒 | 辅助设备 | 支撑机舱至设计高度的锥形或柱形钢结构，内含电缆及攀爬设施 |
| 基础 | 辅助设备 | 将塔筒及机组载荷传递至地基的混凝土或钢结构承台 |
| 环网柜/负荷开关柜 | 辅助设备 | 设置于塔筒内或箱变旁，实现风电机组与集电线路的连接、隔离与保护 |
| 集电线路（电缆/架空线） | 辅助设备 | 汇集多台风电机组的电能至风电场升压站的电力线路 |
| 塔筒内部升降机/免爬器 | 辅助设备 | 供运维人员登塔进行检修维护的机械提升装置 |
| 消防系统 | 辅助设备 | 检测并扑灭机舱、塔筒、箱变等区域的火灾，含烟感、灭火器和自动灭火装置 |
| 电能质量监测装置 | 辅助设备 | 监测谐波、电压波动、闪变等指标，确保电能质量满足标准，通常在各箱变及并网点测量 |
| 主变压器 | 公用系统 | 将集电线路电压（35kV）升至电网接入电压（110kV/220kV等）的升压站核心设备 |
| GIS/断路器 | 公用系统 | 高电压侧的气体绝缘开关设备或断路器，实现线路和变压器的投切与保护 |
| 高压开关柜 | 公用系统 | 用于风电场35kV配电系统，实现集电线路进线、馈线、无功补偿等回路的控制与保护 |
| 无功补偿装置（SVG/电容器） | 公用系统 | 动态调节无功功率，维持并网点电压稳定，满足电网无功需求与功率因数要求 |
| 站用变压器 | 公用系统 | 为升压站及风机辅助设备提供低压工作电源的降压变压器 |
| 继电保护装置 | 公用系统 | 对升压站内变压器、线路、母线等的一次设备进行故障检测和快速隔离的保护系统 |
| 综合自动化系统 | 公用系统 | 实现风电场升压站监视、控制、测量和保护的计算机监控系统 |
| 风电场SCADA | 公用系统 | 集中监控全场风机、升压站、箱变等设备，完成数据采集、报警和远程控制 |
| 远程通信设备 | 公用系统 | 传输风电场运行数据至远方集控中心或电网调度的光纤、载波或无线通信装置 |
| 风功率预测系统 | 公用系统 | 结合数值天气预报和历史数据预测风电场短期及超短期输出功率，支持调度 |
| 视频监控系统 | 公用系统 | 监视风电场内关键区域及设备运行环境，提供全场级安防及运维视觉支持 |
| 环境监测站（风电场级） | 公用系统 | 测量风电场代表性高度的风速、风向、温度、湿度和气压，用于风能资源评估和功率预测 |
| 场用备用电源/柴发 | 公用系统 | 全场失电时提供应急电力的柴油发电机组或蓄电系统 |
| 防雷接地网 | 公用系统 | 全场区域统一的大地网，降低接地电阻，均衡电位，保障设备和人身安全 |
| 消防水泵及管网 | 公用系统 | 为升压站内架构筑区域提供消防用水的泵房和管道系统 |
