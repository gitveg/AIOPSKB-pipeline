| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 变压器器身 | — | 升压站核心设备，将集电线路35kV升至并网电压110kV/220kV。三相油浸式有载调压电力变压器，容量50~180MVA，冷却方式ONAN/ONAF。 | 否 | 每季度巡查油位、油温、绕组温度、运行声音；大修时进行油色谱分析、绝缘电阻、直流电阻、变比测试、介损测量。 | 绕组绝缘严重老化（聚合度<250）、油色谱持续异常且确认内部放电故障、整体效率下降且大修无法恢复。整台返厂或就地拆解，按铜线、硅钢片和钢材分类回收。 |
| 铁芯 | 变压器器身 | 磁路部分，高导磁冷轧硅钢片叠装（片厚0.23~0.35mm），芯式三柱结构。铁芯通过夹件一点接地，防止多点接地引起环流和局部过热。 | 否 | 大修时测量铁芯接地电流（正常<100mA）；测量铁芯对地绝缘电阻（>100MΩ）；检查夹件和穿芯螺栓绝缘。 | 片间短路导致严重局部过热无法修复、铁芯严重锈蚀变形。通常不单独更换，随变压器整体报废。 |
| 高压绕组 | 变压器器身 | 110kV/220kV侧的绕组，采用饼式绕制结构（纠结式或内屏蔽式），漆包铜导线换位绕制，改善冲击电压分布。 | 否 | 大修时测量直流电阻（相间差<2%）；测量绝缘电阻和吸收比（R60/R15≥1.3）；进行频率响应法变形测试。 | 匝间或层间短路、绝缘电阻严重下降、绕组严重变形超出允许值。需返厂重绕或整体更换。 |
| 低压绕组 | 变压器器身 | 35kV侧的绕组，采用圆筒式或连续式绕制结构，铜箔或铝导线。位于铁芯柱内侧，绝缘等级A级（允许温升65K）。 | 否 | 大修时测量直流电阻和绝缘电阻；检查引出线绝缘状态和接头过热；监测运行中绕组温度（报警115°C、跳闸125°C）。 | 匝间短路、绝缘严重老化、引出线接头开裂。处理方法同高压绕组。 |
| 绝缘油 | 变压器器身 | 矿物油（25号或45号变压器油），兼作绝缘和冷却介质。油量数十吨（如75MVA变压器的油约20~30吨）。 | 是 | 定期取样检测击穿电压（≥50kV/2.5mm）、酸值（≤0.1mgKOH/g）、微水（≤25mg/L）；每年油色谱分析（DGA）监测H₂/CH₄/C₂H₂/C₂H₄/CO含量；每5年简化分析。 | 击穿电压持续低于标准、酸值超限或大量油泥、乙炔（C₂H₂）出现表明内部电弧。旧油须按危险废物交由专业机构回收，严禁随意倾倒。 |
| 有载分接开关(OLTC) | 变压器器身 | 带负载调节变压器变比的分接开关，含分接选择器、切换开关（过渡电阻式或真空式）、电动机构。调压范围±8×1.25%（±2×2.5%）。 | 是 | 大修时检查切换开关触头烧蚀和过渡电阻值；进行切换特性试验（过渡时间和同期性）；取油样检测；清洗油箱、更换绝缘油；检查电动机构传动。 | 触头严重烧蚀、过渡电阻断路、机械卡涩、油质严重劣化。更换OLTC需排油吊芯操作，故障占变压器总故障约26%。 |
| 切换开关芯体 | 有载分接开关(OLTC) | OLTC中完成"先通后断"无弧切换的核心组件，含动/静触头、过渡电阻/电抗和灭弧室。真空式用真空泡替代传统油中触头。 | 是 | 按切换次数或运行年限（通常7~10万次或5~8年）吊芯检修；检查触头烧损量和过渡电阻值；真空型检查真空泡完好性。 | 触头烧损超限、过渡电阻烧断、真空泡漏气。更换切换开关芯体，更换后做切换特性试验。 |
| 电动机构箱 | 有载分接开关(OLTC) | 驱动OLTC分接选择器和切换开关的电动机传动装置（如CMA7、ED型），含电机、传动齿轮、位置指示和限位开关。 | 否 | 每年检查电机运转和传动机构灵活性；检查分接位置指示与就地档位一致；润滑传动部件；检查箱内加热器和密封。 | 电机烧毁、传动齿轮严重磨损、位置指示失准。更换电动机构需重新对位。 |
| 高压套管 | 变压器器身 | 高压绕组引出线的油纸电容式套管（110kV/220kV），电容芯子由电缆纸和铝箔交替卷制（串联电容均压），含储油柜、末屏和均压球。 | 是 | 大修时测量介损tanδ（≤0.7%）和电容量（与出厂值比偏差≤3%）；检查末屏绝缘和接地；检查储油柜油位；红外测温检查接头发热。 | 介损超标或电容量偏差过大、末屏放电、渗漏油严重。更换套管需排油操作，更换后进行绝缘试验。 |
| 低压套管 | 变压器器身 | 35kV侧绕组的引出线套管，通常为纯瓷套管。连接35kV共箱母线或电缆。 | 是 | 大修时测量绝缘电阻；检查瓷件有无裂纹和放电痕迹；检查连接端子和接头温度；清洁瓷件表面。 | 瓷件裂纹或破损、严重爬电痕迹。更换低压套管需排油操作。 |
| 储油柜（油枕） | — | 油箱外部油膨胀容器（容积约为油箱1/10），为变压器油热胀冷缩提供缓冲空间并减少油与空气接触面积。波纹管式（内油/外油）全密封结构。 | 否 | 定期检查油位计指示与实际油温对应关系；检查管路和阀门有无渗漏；大修时检查波纹管/胶囊有无破损和密封性。 | 波纹管破损漏油、胶囊老化破裂。更换储油柜需排油后进行。 |
| 吸湿器（呼吸器） | 储油柜（油枕） | 过滤进入储油柜空气中水分的干燥装置，内装变色硅胶（蓝色干燥→粉红色吸湿饱和），下置油杯过滤杂质。 | 是 | 定期检查硅胶颜色变化，变色超过2/3时应更换；检查油杯内变压器油液位和清洁度；检查连接管路密封。 | 硅胶全部变色饱和、外壳破损。更换硅胶时先关闭呼吸器阀门防止空气直接进入。旧硅胶按一般废物处置。 |
| 气体继电器（瓦斯） | — | 安装于油箱与储油柜连接管中部的变压器主保护装置。轻瓦斯（气体积聚250~300mL）发报警，重瓦斯（油流速>0.8m/s）跳闸。 | 是 | 每年进行瓦斯继电器保护功能试验（模拟注气和模拟油流）；检查接线端子；若有积气取气分析。 | 浮子卡涩导致拒动、接点接触不良、接线端子腐蚀。更换瓦斯继电器需排油操作。 |
| 压力释放阀 | — | 安装于油箱顶部的安全泄压装置。内部压力超限（35~55kPa）时2ms内迅速开启泄压，压力降低后自动关闭保持油箱正压。动作后标志杆弹出需手动复位。 | 是 | 定期检查有无渗漏和机械损伤；检查信号接点接线；大修时校验开启压力（升压法测试）。 | 阀膜老化失效、动作后不复位、密封圈老化渗漏。更换压力释放阀需停电操作。 |
| 温度控制器 | — | 监测变压器运行温度的保护装置。油面温度计（毛细管式）测量顶层油温；绕组温度计通过CT电流加热元件模拟绕组热点温度。提供冷却启动、报警和跳闸接点。 | 是 | 每年校验温度指示精度和各接点动作值（报警105°C、跳闸115°C）；检查毛细管有无折断和泄漏；大修时送检计量。 | 温度指示偏差超±3°C、毛细管断裂、接点动作值漂移。更换同型号温度控制器。 |
| 油位计 | — | 指示储油柜内变压器油液位的装置（磁力式或玻璃管式），刻度标注对应油温下的正常油位范围。 | 是 | 定期检查油位与环境温度匹配；检查有无渗漏和卡滞；大修时校验准确性。 | 油位计玻璃管破裂、指示失准、密封渗漏。更换油位计需短暂隔离管路。 |
| 冷却系统 | — | 散发变压器运行热量的装置。ONAN方式为散热片自然冷却（无辅助设备）；ONAF方式加装风扇于散热器上，低负荷时风扇可停运。 | 否 | 定期检查散热器表面清洁和翅片变形；ONAF型检查风扇电机绝缘和轴承；检查温控启停功能；清洁散热器表面积灰。 | 散热器大面积锈蚀渗漏、风扇电机烧毁。更换散热器需排油操作。 |
| 散热片/散热器 | 冷却系统 | 焊接于油箱壁或独立安装的波纹翅片式散热器（片式），增大散热表面积。 | 否 | 定期检查散热片有无变形、积灰和堵塞；检查焊缝有无渗油；ONAF型检查风扇安装支架紧固。 | 散热片大面积变形或锈蚀穿孔。更换散热器需排油后进行。 |
| 冷却风扇 | 冷却系统 | 安装于散热器的轴流风扇（ONAF方式），油温达到设定值（通常65~75°C）自动启动，温度下降后自动停止。 | 是 | 每年检查风扇电机绝缘和运转声音；检查扇叶平衡和积灰；检查温控启动回路。 | 电机绕组烧毁、扇叶断裂。更换同规格风扇电机，核对电压等级和旋转方向。 |
| 油箱 | 变压器器身 | 容纳铁芯、绕组和绝缘油的密封钢板容器（Q235B），全密封结构，通过波纹片或膨胀器补偿油体积变化。 | 否 | 定期检查油箱焊缝和法兰有无渗漏；检查防腐涂层；大修时进行油箱密封试验（充油加压）。 | 油箱严重锈蚀穿孔无法补焊、焊接缝大面积开裂。需返厂更换油箱。 |
