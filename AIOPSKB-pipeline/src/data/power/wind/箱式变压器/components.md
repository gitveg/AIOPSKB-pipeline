| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 变压器本体 | — | 箱变核心升压单元，将风电机组出口低压（690V）升至集电线路电压（35kV）。采用三相油浸式双绕组无励磁调压变压器，额定容量通常为1600~4200kVA。包含铁芯、绕组、绝缘油等核心组件，密封于油箱内。 | 否 | 定期检查油位、油温、绕组温度；大修时进行油色谱分析、绝缘电阻测量、绕组直流电阻测量、变比测试；定期取油样检测击穿电压、酸值、微水含量。 | 绕组绝缘严重老化（聚合度<250），油色谱异常且经多种检测确认内部故障；铁芯严重多点接地或局部过热无法修复。整体更换变压器本体，旧变压器交由专业机构拆解回收。 |
| 铁芯 | 变压器本体 | 磁路部分，采用高导磁率冷轧硅钢片叠装。芯柱和铁轭组成闭合磁路，通常为三柱式结构。铁芯通过绝缘夹件固定，一点接地。 | 否 | 大修时测量铁芯接地电流（正常应<100mA）；检查铁芯对地绝缘电阻（应>100MΩ）；检查有无多点接地故障。 | 铁芯片间短路导致局部过热；硅钢片严重锈蚀或变形。铁芯通常不单独更换，随变压器本体报废。 |
| 铁芯接地片 | 铁芯 | 铁芯的电气接地连接铜片，确保铁芯仅一点接地，防止感应电压和环流。 | 否 | 定期检查接地片连接是否紧固；大修时测量铁芯接地电流。 | 接地片断裂或接触不良导致铁芯悬浮电位放电。更换接地片需吊芯操作。 |
| 绕组（线圈） | 变压器本体 | 电路部分，由低压绕组和高压绕组组成。低压绕组通常为圆筒式或螺旋式（铜箔/铝箔），高压绕组为连续式或层式（漆包铜线）。绝缘等级通常为A级（105°C）。 | 否 | 大修时测量绕组直流电阻（相间差应<2%）；测量绕组绝缘电阻和吸收比；进行绕组变形测试（频率响应法）。运行中监测绕组温度（通常设115°C报警、125°C跳闸）。 | 绕组匝间或层间短路；绝缘电阻严重下降无法恢复；绕组变形超出允许范围。绕组损坏通常需返厂重绕或整体更换变压器。 |
| 低压绕组 | 绕组（线圈） | 连接风电机组输出侧的绕组，额定电压690V（个别机型为660V或800V）。通常采用铜箔圆筒式结构，位于铁芯柱内侧。 | 否 | 大修时测量直流电阻，与出厂值比对；检查引出线有无过热和绝缘老化。 | 绝缘老化导致匝间短路；铜箔焊接口开裂。需返厂修复或更换。 |
| 高压绕组 | 绕组（线圈） | 连接35kV集电线路侧的绕组，额定电压35kV。通常采用漆包铜线连续式绕制，位于低压绕组外侧。 | 否 | 大修时测量直流电阻和绝缘电阻；进行交流耐压试验（出厂试验值的80%）。 | 匝间短路或对地绝缘击穿；引出线接头过热氧化。需返厂修复或更换。 |
| 绝缘油 | 变压器本体 | 变压器内部绝缘和冷却介质，通常采用25号或45号变压器油（矿物油）。同时起绝缘、灭弧和散热作用。油量通常为数百至上千公斤。 | 是 | 定期取样检测击穿电压（应>=35kV/2.5mm）、酸值（应<=0.1mgKOH/g）、微水含量（应<=30mg/L）；运行中通过油色谱分析（DGA）监测溶解气体（H2、CH4、C2H2、C2H4、CO等）；每3~5年进行一次简化分析。 | 绝缘油击穿电压持续低于标准值且经真空滤油处理无法恢复；酸值严重超标或油泥大量生成；油色谱出现乙炔（C2H2）表明内部电弧放电。旧油须按危险废物交由专业机构回收处理，严禁随意倾倒。 |
| 分接开关 | 变压器本体 | 用于调整变压器变比的调压装置，调节高压绕组抽头以补偿电网电压偏差。风电箱变通常采用无励磁分接开关（无载调压），调压范围±5%（±2×2.5%）。 | 是 | 大修时检查分接开关触头接触状态，测量接触电阻；切换档位后重新测量绕组直流电阻和变比，确认接触良好。 | 触头严重烧蚀或氧化导致接触不良；机械定位装置损坏无法准确切换。更换分接开关需排油后进行。 |
| 油箱 | 变压器本体 | 容纳变压器铁芯、绕组和绝缘油的密封金属容器，采用Q235钢板焊接。箱壁外侧焊接散热翅片或安装散热器。全密封结构，通过波纹片或膨胀器补偿油体积变化。 | 否 | 定期检查油箱焊缝有无渗漏；检查箱壁防腐涂层状态；大修时进行油箱密封试验。 | 油箱严重锈蚀穿孔无法补焊修复；焊缝大面积开裂。更换油箱需返厂。 |
| 散热器 | 变压器本体 | 散发变压器运行损耗产生的热量，维持油温在允许范围内。通常为片式散热器（波纹翅片式），焊接或法兰连接于油箱壁。部分大容量箱变配有风冷散热风扇。 | 否 | 定期检查散热翅片有无变形和积灰堵塞；检查连接处有无渗漏；风冷型需检查风扇电机运行状态。 | 散热翅片大面积变形或锈蚀影响散热效果；连接法兰渗漏无法修复。更换散热器需排油后进行。 |
| 散热风扇 | 散热器 | 强制风冷散热的电动机驱动风扇，安装于散热器侧面。当油温达到设定值（通常75°C）自动启动，温度下降后自动停止。 | 是 | 定期检查风扇电机运行声音和振动；检查扇叶有无变形和积灰；测量电机绝缘电阻；检查温控启动功能。 | 电机绕组烧毁；扇叶严重变形或断裂。更换风扇电机时核对电压等级和旋转方向。 |
| 油位计 | 变压器本体 | 指示变压器油箱内绝缘油液位的装置，通常为磁力式或玻璃管式油位计。刻度标注对应油温下的正常油位范围。 | 是 | 定期检查油位指示是否与环境温度匹配；检查有无渗漏；大修时校验油位计准确性。 | 油位计玻璃管破裂或指示失准。更换油位计需短暂排油或关闭连接阀门。 |
| 油温/绕组温度控制器 | 变压器本体 | 监测变压器油温和绕组温度的温控装置。油温控制器采用毛细管式温度计，绕组温度控制器通过电流互感器模拟绕组热点温度。提供冷却风扇启动、报警和跳闸三组温度接点。 | 是 | 定期检查温度指示与实际温度是否一致；大修时校验温度控制器精度和各接点动作值；检查毛细管有无折断和泄漏。 | 温度指示偏差超过±3°C；毛细管断裂导致指示失灵；接点动作值漂移。更换温控器时需核对毛细管长度和接点设定值。 |
| 呼吸器（吸湿器） | 变压器本体 | 连接油枕（或油箱气室）与外界大气的干燥装置，内装变色硅胶干燥剂。过滤进入油箱的空气中的水分，防止绝缘油受潮。硅胶由蓝色变为粉红色时表示已饱和。 | 是 | 定期检查硅胶颜色变化，变色超过2/3时应更换；检查油杯内变压器油液位；检查连接管路密封。 | 硅胶全部变色失效。更换硅胶时需先关闭呼吸器与油枕之间的阀门，防止空气直接进入。旧硅胶按一般废物处置。 |
| 气体继电器（瓦斯继电器） | 变压器本体 | 安装于油箱与油枕（或膨胀器）连接管路上的保护装置。轻瓦斯动作（气体积聚）发报警信号，重瓦斯动作（油流冲击）跳闸。风电箱变多为全密封结构，部分型号用压力释放阀替代。 | 是 | 定期检查气体继电器内有无积聚气体（若有需取气分析）；大修时校验轻瓦斯和重瓦斯动作值；检查接线端子是否可靠。 | 浮子机构卡涩导致保护拒动；接线端子接触不良。更换气体继电器需排油操作。 |
| 压力释放阀 | 变压器本体 | 安装于油箱顶部的安全保护装置。当变压器内部故障导致压力急剧升高时，阀膜瞬间开启释放压力（开启压力通常为35~55kPa），防止油箱爆裂。带信号接点，动作时发出报警。 | 是 | 定期检查压力释放阀有无渗漏和机械损伤；检查信号接点接线是否可靠；大修时校验开启压力。 | 阀膜老化失效或动作后未正确复位；密封圈老化渗漏。更换压力释放阀需停电操作。 |
| 高压负荷开关 | — | 安装于箱变高压室（35kV侧）的开关设备，用于箱变高压侧的合分操作。通常采用SF6气体绝缘的两位置（合/分）负荷开关，可开断额定负荷电流但不能开断短路电流，短路保护由高压熔断器配合完成。 | 否 | 定期检查操作次数记录；大修时测量回路电阻；检查SF6气体压力（若为SF6型）；检查触头状态；进行机械特性试验。 | 累计操作次数达到机械寿命额定值（通常2000~5000次）；SF6气体泄漏无法维持额定压力。更换负荷开关需停电后进行。 |
| 负荷开关触头 | 高压负荷开关 | 负荷开关的导电触头系统，由动触头和静触头组成。材质为铜基镀银，承担负荷电流的通断。 | 是 | 大修时检查触头表面有无烧蚀和氧化；测量接触电阻；检查触头压力和超行程。 | 触头表面严重烧蚀导致接触电阻超标；镀银层大面积脱落。更换触头组件需停电后拆卸操作机构。 |
| 负荷开关操作机构 | 高压负荷开关 | 驱动负荷开关合分操作的机械装置，通常为弹簧储能手动/电动操作机构。具备就地手动操作和远程电动操作两种方式。 | 否 | 定期检查操作机构动作是否灵活；大修时检查弹簧状态和传动部件磨损情况；检查辅助开关触点。 | 弹簧疲劳断裂；传动部件严重磨损导致操作不可靠。更换操作机构需停电后进行。 |
| 高压熔断器 | — | 安装于高压负荷开关上游的短路保护器件，采用高压限流熔断器（如XRNT型）。当变压器内部或高压侧发生短路故障时，熔体快速熔断切除故障。通常为三相一组，额定电流按变压器容量选定。 | 是 | 定期检查熔断器指示器（撞击器）状态；大修时测量熔体直流电阻，与标准值比对；检查熔管有无裂纹和放电痕迹。 | 熔体熔断（无论单相或多相）；熔管表面有裂纹或严重放电痕迹。熔体熔断后需查明故障原因，排除后方可更换同规格新熔断器。严禁使用铜丝等替代熔体。 |
| 熔体 | 高压熔断器 | 熔断器内的核心熔断元件，由银或铜合金制成，内置多个窄颈。过载或短路电流通过时窄颈熔化形成多段电弧，石英砂填料迅速熄灭电弧实现限流。 | 是 | 大修时测量直流电阻；外观检查有无异常。 | 熔体熔断。必须查明故障原因后更换同规格同型号熔体。 |
| 避雷器 | — | 安装于高压侧和/或低压侧的过电压保护装置，采用金属氧化物避雷器（MOA）。限制雷电过电压和操作过电压，保护变压器绕组绝缘。高压侧通常为35kV HY5WZ型。 | 是 | 定期检查避雷器外观有无破损和放电痕迹；大修时测量绝缘电阻和直流1mA下电压（U1mA）及75%U1mA下泄漏电流，与初始值比对；检查接地引线连接。 | 阀片老化导致U1mA下降超过5%或泄漏电流显著增大；瓷套或硅橡胶伞裙严重破损。更换避雷器需停电后进行，旧避雷器按含锌废物处置。 |
| 低压断路器（框架断路器） | — | 安装于箱变低压室（690V侧）的开关设备，连接风电机组输出与变压器低压绕组。采用智能型万能式断路器（ACB），具备过载长延时、短路短延时、短路瞬动三段保护，额定电流2000~6300A。 | 否 | 定期检查断路器操作次数和触头磨损指示；大修时测量主触头回路电阻；检查电子脱扣器保护定值；进行机械操作试验。 | 累计操作次数达到机械寿命额定值（通常10000~20000次）；主触头磨损达到限值；电子脱扣器故障。更换断路器需停电后进行。 |
| 断路器触头系统 | 低压断路器（框架断路器） | 断路器的导电触头，由动触头和静触头组成。每相包含主触头（长期通流）和弧触头（承担合分电弧），采用银合金材料。 | 是 | 大修时检查触头磨损指示器状态；测量接触电阻；检查触头表面有无严重烧蚀。 | 触头磨损指示达到更换限值；表面严重烧蚀。更换触头组件通常由厂家提供配件。 |
| 电子脱扣器 | 低压断路器（框架断路器） | 断路器的智能保护控制单元，基于微处理器实现过载长延时（L）、短路短延时（S）、短路瞬动（I）保护功能。可显示电流、电压、功率等参数，支持通信接口。 | 是 | 定期检查保护定值是否正确；大修时校验保护动作特性（施加模拟电流验证动作时间和电流精度）；检查显示屏和通信功能。 | 保护动作特性偏离设定值超过允许范围；显示屏故障或通信中断。更换脱扣器需核对型号和定值。 |
| 保护与测控装置 | — | 箱变的二次保护测控系统，通常采用微机保护测控一体化装置（如许继、南瑞、四方等品牌）。实现差动保护、过流保护、温度保护等，以及遥测、遥信、遥控功能。 | 否 | 定期检查保护装置运行指示灯和自检状态；大修时校验保护定值和动作特性；检查通信链路和后台数据是否正常。 | 保护装置硬件故障（CPU板、电源板损坏）；软件版本过旧无法满足需求。更换保护装置需重新整定保护定值并校验。 |
| 电流互感器 | 保护与测控装置 | 安装于高压侧和低压侧的电流传感器，为保护和测量提供二次电流信号。高压侧通常配置计量绕组（0.2级）和保护绕组（5P10/10P10），低压侧配置保护绕组。 | 否 | 定期检查二次回路接线完整性和接地状态；大修时测量绕组直流电阻和绝缘电阻；校验变比和准确级。运行中确保二次回路不得开路。 | 环氧浇注体出现裂纹或放电痕迹；绕组绝缘电阻严重下降。更换互感器需停电拆卸。 |
| 温度巡检仪 | 保护与测控装置 | 采集和显示变压器多点温度的监测装置。连接Pt100铂电阻温度传感器，实时显示油温和绕组温度，提供远程通信接口（RS485/以太网）。 | 是 | 定期检查温度显示是否与就地温度计一致；大修时校验各通道精度；检查通信链路。 | 温度指示偏差超过允许范围；通信功能失效。更换巡检仪需核对传感器类型和通信协议。 |
| 高压套管/电缆接头 | — | 变压器高压绕组引出线与外部35kV电缆的连接部件。采用肘型插拔式电缆接头（如600A肘型头）或套管式引出。提供电气连接和绝缘隔离。 | 是 | 定期检查电缆接头有无发热和放电痕迹（红外测温）；检查肘型头插拔力是否正常；大修时测量接头接触电阻和绝缘电阻。 | 电缆接头过热变色或烧蚀；肘型头绝缘老化开裂；接触电阻超标。更换电缆接头需停电后进行，需使用专用工具。 |
| 低压电缆接头 | — | 变压器低压绕组引出线与风电机组输出电缆（690V）的连接部件。采用铜母排或电缆终端头连接。 | 是 | 定期检查连接处有无发热和氧化（红外测温）；检查紧固螺栓力矩；大修时测量接触电阻。 | 连接处严重氧化或过热变色；铜母排变形或裂纹。更换低压电缆接头需停电后进行。 |
