| 子系统名称 | 描述 |
|------------|------|
| 风轮系统 | 包含叶片、轮毂与导流罩，负责将风能转化为旋转机械扭矩，实现气动功率捕获，紧急时可配合变桨系统提供气动刹车。功能边界限于气动结构件，不包含变桨执行机构。 |
| 变桨系统 | 包含变桨驱动（电机-减速器-小齿轮）、变桨轴承、控制柜及后备电源，根据主控指令独立调节各叶片桨距角，实现气动效率调节与紧急顺桨保护。 |
| 传动系统 | 由主轴、主轴承、多级齿轮箱、高速轴及机械制动器构成，将风轮低速高扭矩增速至双馈发电机所需转速，覆盖从轮毂输出到发电机转子输入的机械能路径。 |
| 发电系统 | 以绕线式双馈异步发电机为核心，包括定子、转子绕组、滑环及碳刷，实现机械能到电能的转换。定子直接并网，转子通过变流器馈电（双馈机型特征）。 |
| 变流与并网系统 | 包含转子侧/网侧变流器、直流母线、滤波器、升压变压器及并网开关，负责转子滑差功率的双向流动控制、网侧电能质量调节及机组升压并网（DFIG 为部分功率变流）。 |
| 偏航系统 | 由偏航驱动、偏航轴承和制动器组成，根据风向信号调整机舱方向，使风轮对准风向。 |
| 控制系统 | 涵盖主控PLC、变桨/变流/偏航执行器接口及保护硬件（如Crowbar），执行最大功率跟踪、并网调节、故障穿越与安全连锁。 |
| 塔架与支撑系统 | 包括塔筒、基础、主机架（机舱底板支承）及机舱罩，提供整机重力与风推力载荷传递路径，确保各子系统在预定高度和姿态下稳定工作。 |
| 冷却与散热系统 | 为发电机、变流器等发热设备提供空气或水冷却，含发电机空冷器、冷却风扇、变流器散热风机、冷却水泵及循环管路。齿轮箱油冷归润滑与液压系统。 |
| 润滑与液压系统 | 为齿轮箱、主轴承等运动部件提供强制润滑，并为偏航/主轴制动提供液压动力，含润滑油泵、滤芯、油冷器、液压站、分配管路及油箱。 |
