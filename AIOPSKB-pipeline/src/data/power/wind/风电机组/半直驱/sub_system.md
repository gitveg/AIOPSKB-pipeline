| 子系统名称 | 描述 |
|------------|------|
| 风轮系统 | 包括叶片、轮毂和导流罩，将风动能转化为主轴上的机械扭矩，通过气动设计实现功率捕获，紧急时可提供气动刹车。功能边界为轮毂与主轴法兰面，是风能至机械能的入口。 |
| 变桨系统 | 包括变桨电机、减速器、变桨轴承、备用电源（超级电容或电池）及分控单元，根据主控指令独立调节叶片节距角，用于气动功率控制、启停平衡和紧急顺桨制动。边界覆盖从变桨控制柜到叶片根部的完整执行链路。 |
| 传动系统 | 包括主轴、主轴承、中速齿轮箱和高速联轴器，传递风轮扭矩并将转速提升至发电机所需工作转速，同时承受气动推力与弯矩。功能边界从主轴与轮毂接口至齿轮箱输出轴与发电机接口。 |
| 发电系统 | 包括永磁同步发电机及其内置冷却装置，将传动系统输入的机械能转换为频率和电压变化的交流电，无需外部励磁。功能边界为转子输入轴至定子输出接线盒，仅含发电机本体及内置冷却，外置冷却回路归冷却与散热系统。 |
| 变流与并网系统 | 包括全功率变流器（机侧/网侧）、网侧滤波器和升压变压器，将发电机输出的变频变压交流电转换为符合电网要求的恒频恒压电能，实现有功/无功调节与低电压穿越。边界覆盖发电机电缆至风电场集电网连接点。 |
| 偏航系统 | 包括偏航驱动电机、偏航轴承、减速器及液压制动器，根据风向信号驱动机舱围绕塔架中心线转动，实现主动对风和解缆，并依靠制动器提供偏航阻尼与定位保持。 |
| 控制系统 | 包括主控PLC、机舱控制柜、塔基控制柜、各类传感器（风速、温度、振动等）、场内通信网络及消防报警系统，负责整机状态监控、逻辑调度、安全保护链执行、远程通信与机舱火灾防护。 |
| 塔架与支撑系统 | 包括主机架、塔筒、基础、机舱罩等结构承载件，提供整机重力与风推力载荷传递路径，确保各子系统在预定高度和姿态下稳定工作。 |
| 冷却与散热系统 | 为发电机、变流器、齿轮箱等发热设备提供强制散热，含散热风机、冷却水泵及循环管路，覆盖冷却介质的循环与热量交换。 |
| 润滑与液压系统 | 为齿轮箱、发电机等运动部件提供强制润滑，并为偏航制动、主轴制动提供液压动力，含集中液压站、润滑泵站、管路阀门、油冷器及油箱。 |
