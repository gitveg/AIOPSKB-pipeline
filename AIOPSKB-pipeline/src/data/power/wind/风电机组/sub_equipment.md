| 子设备名称 | 描述 |
|------------|------|
| 双馈异步风电机组（DFIG） | 采用多级齿轮箱增速，双馈异步发电机通过变频器控制转子电流实现变速恒频运行，技术成熟、成本较低。 |
| 直驱永磁同步风电机组（PMSG） | 无齿轮箱，风轮直连永磁同步发电机，通过全功率变流器并网，结构简单、可靠性高、维护量低。 |
| 半直驱（中速永磁）风电机组 | 采用一级或两级齿轮箱与永磁同步发电机结合，兼顾紧凑性与效率，转速介于直驱与双馈之间。 |
| 鼠笼异步风电机组（SCIG） | 定速或有限变速，使用笼型异步发电机直接并网或通过软启动器，早期机型，结构简单但效率较低。 |
| 高速永磁风电机组 | 通过多级齿轮箱高速驱动永磁发电机，配合全功率变流器，功率密度高，适用于紧凑型机舱设计。【小众技术路线，市场份额不足1%】 |
| 异步双馈混合型机组 | 结合异步电机与变流器技术，可实现无功调节与故障穿越，适用于电网适应性要求较高的场景。【试验性技术，尚未大规模商用】 |
| 直驱电励磁同步风电机组（EESG） | 风轮直接驱动电励磁同步发电机，全功率变流器并网，无永磁体，励磁可调，适合低风速和高温环境。【小众技术路线，如Vensys部分机型，市场份额极低】 |
| 液压传动型风电机组 | 用液压泵-马达系统替代主齿轮箱，实现无级变速和机舱重量转移至塔底，降低顶部重量但效率略低。【极小众技术路线，如WinDrive，市场份额极低】 |
| 无刷双馈风电机组 | 采用无刷双馈电机替代有刷双馈电机，取消滑环和电刷，转子可靠性高，维护需求更低，仍可变速恒频。【技术验证阶段，尚未大规模商用】 |
