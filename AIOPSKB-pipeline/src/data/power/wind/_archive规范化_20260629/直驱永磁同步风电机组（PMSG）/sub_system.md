| 子系统名称 | 描述 |
|------------|------|
| 风轮系统 | 实现风能捕获并转换为旋转机械能，包含叶片、轮毂及导流罩。通过气动设计实现功率捕获，紧急情况下配合变桨系统提供气动刹车，覆盖从气流到主轴输入端的功能边界。 |
| 变桨系统 | 包含变桨轴承、变桨驱动装置（电机-减速箱-齿轮）及变桨控制柜（含超级电容后备电源），根据主控指令独立调节桨距角，实现气动功率控制与紧急顺桨制动。 |
| 传动系统 | 将风轮的低速旋转直接传递给发电机转子，无齿轮箱。包含主轴、主轴承、联接部件及主轴机械制动器，承担支撑风轮、传递扭矩与轴向推力，覆盖从风轮接口到发电机转子的机械连接。 |
| 发电系统 | 将机械能转换为变频变压交流电能，采用永磁同步发电机制。转子永磁体与定子绕组耦合，输出全功率变流器所需的变频电源，覆盖从转子输入端到变流器输入端的功能。 |
| 变流与并网系统 | 将发电机输出的变频交流电通过全功率变流器转换为恒频恒压电能并馈入电网。包含机侧/网侧变流器、直流环节、滤波器及升压变压器，覆盖从发电机输出到电网连接点的电力变换与并网控制。 |
| 偏航系统 | 根据风向变化驱动机舱绕塔架轴线旋转，保持风轮准确对风。包含偏航电机、偏航轴承、偏航制动及齿圈，覆盖机舱方位调节与大风解缆保护。 |
| 控制系统 | 实时监控机组运行状态，协调各子系统动作，完成发电控制、安全保护与通信。包含主控制器、变桨/变流/偏航控制器、风速风向仪、编码器等传感器，覆盖全机决策逻辑与闭环调节。 |
| 塔架与支撑系统 | 包括主机架、塔筒、基础连接及机舱罩等结构承载件，提供整机重力与风推力载荷传递路径，确保各子系统在预定高度和姿态下稳定工作。 |
| 冷却与散热系统 | 为发电机、变流器等发热设备提供水冷/风冷散热，包含水冷散热器、冷却液循环泵、膨胀罐、冷却液管路及温度监测，覆盖冷却介质循环与热量交换。 |
| 润滑与液压系统 | 为主轴承、偏航轴承等运动部件提供自动注油润滑，并为主轴制动、偏航制动提供液压动力，含液压站、自动注油润滑泵、递进分配器及管路。 |
