| 风轮系统 | — | 捕获风能并转化为机械能，包含叶片、轮毂、变桨机构等。 | 否 | 制定风轮系统综合维护方案：每年进行叶片外观巡检（地面望远镜/无人机），检查前缘侵蚀、后缘开裂、雷击损伤；每2年进行叶片内部检查；定期检查轮毂螺栓紧固力矩；监测风轮不平衡振动；检查变桨系统功能；定期进行防雷系统检测。 | 当风轮系统整体性能严重下降、多只叶片同时出现严重损伤、轮毂出现不可修复的裂纹、修复成本超过新系统价值的50%时，应评估整体大修或更换。报废时按各部件材质分类回收处理。 |
| 叶片 | 风轮系统 | 气动外形件，利用风压差产生扭矩；承受交变载荷，需监测裂纹、腐蚀。 | 是 | 每年进行叶片外部巡检：检查前缘有无侵蚀和开裂、后缘粘接缝状态、表面涂层有无脱落和起泡、防雷接闪器状态；每2年进行内部结构检查；发现损伤及时修补；监测叶片不平衡振动；定期进行无损检测评估内部结构状态。 | 当叶片出现贯穿性裂纹或大面积分层、主梁结构损伤导致承载能力严重下降、气动性能严重下降影响发电效率超过20%、修复成本超过新叶片价值的50%时，应报废更换。报废叶片按复合材料废物处理。 |
| 轮毂 | 风轮系统 | 连接叶片与主轴，传递扭矩；承受复杂交变应力。 | 否 | 每1~2年对轮毂进行无损检测（磁粉或超声波），检查有无裂纹；检查叶片安装法兰面状态；检查与主轴的连接螺栓紧固力矩；检查防腐涂层状态；运行中监测轮毂振动和温度；检查内部有无积水。 | 当轮毂出现不可修复的裂纹（深度超过壁厚的30%）、法兰面严重变形、铸件内部出现大面积缺陷影响结构强度时，应报废更换。报废轮毂按铸钢废料回收。 |
| 变桨轴承 | 风轮系统 | 实现叶片桨距角调节，承受倾覆力矩与振动。 | 是 | 按规定周期补充极压润滑脂，通过自动或手动润滑系统注脂；定期检查齿面和滚道有无点蚀、剥落和磨损；监测运转有无异响和卡滞；大修时测量游隙；检查密封件状态；检查与叶片和轮毂的连接螺栓紧固力矩。 | 当齿面严重磨损或断齿、滚道大面积剥落、游隙超过允许值、密封失效导致内部污染和腐蚀、内外圈出现裂纹时，应报废更换。报废轴承按大型轴承钢废料回收。 |
| 变桨驱动电机 | 风轮系统 | 驱动小齿轮旋转带动叶片变桨，含电机、编码器。 | 是 | 定期检查电机运行电流和温度；检查编码器信号是否准确；检查电机绝缘电阻；检查电机轴承润滑状态；检查与减速机的联轴器连接；检查电机安装螺栓紧固状态；定期进行功能测试。 | 当电机绕组烧毁或绝缘严重老化、编码器损坏、轴承严重损坏、运行电流持续异常且检修无效时，应报废更换。报废电机按铜线、硅钢片和铸铁分类回收。 |
| 变桨控制柜 | 风轮系统 | 集成伺服驱动器、备用电池，接收主控指令控制变桨。 | 否 | 定期检查柜内各模块运行状态和指示灯；检查接线端子紧固情况；检查柜内温湿度和加热器工作状态；检查备用电池电压和容量；进行柜内清灰；检查通信是否正常；定期备份控制参数。 | 当控制柜严重锈蚀或变形、多个核心模块同时损坏、柜体结构损坏无法安装时，应评估整体更换。报废时回收可用模块，其余按电子废弃物处理。 |
| 变桨齿轮箱 | 风轮系统 | 减速增扭，将电机动力传递至变桨轴承；存在齿面磨损。 | 是 | 定期检查润滑油油位和品质，按周期换油；检查齿轮啮合有无异响和振动；检查输入和输出轴密封；检查箱体有无渗漏；检查安装螺栓紧固状态；大修时检查齿面磨损量和齿轮间隙。 | 当内部齿轮严重磨损或断齿、箱体出现裂纹、轴承损坏导致运转异常、密封反复泄漏时，应报废更换。报废齿轮箱排空残油后按金属废料回收。 |
| 变桨滑环 | 风轮系统 | 为轮毂内变桨系统传输电力与通信信号，碳刷及环道易磨损。 | 是 | 每半年检查滑环电刷磨损情况，剩余长度不足原长的1/3应更换；检查环道表面有无烧蚀、沟槽和氧化；检查电刷弹簧压力；检查绝缘电阻；清理碳粉和灰尘；检查密封防护状态。 | 当环道严重烧蚀或磨损导致导电不良、多处电刷接触不良、绝缘电阻低于标准值、密封失效导致内部严重污染时，应报废更换。报废滑环按铜材和电子废料分类回收。 |
| 主轴系统 | — | 支撑风轮，传递扭矩至齿轮箱或发电机。 | 否 | 制定主轴系统综合维护方案：定期检查主轴运行温度和振动；每半年检查轴承润滑和密封状态；每年测量轴承游隙和轴向窜动；大修时进行无损检测检查主轴关键部位；监测主轴挠度和偏心；检查锁紧盘和联轴器连接状态。 | 当主轴系统整体性能下降、主轴与轴承同时达到报废标准、修复成本超过新件价值的60%时，应评估整体报废。报废总成拆解后按材质分类回收。 |
| 主轴 | 主轴系统 | 锻造合金钢轴，承受弯矩和扭矩，连接轮毂与齿轮箱。 | 否 | 大修时进行超声波探伤和磁粉探伤检查有无疲劳裂纹；测量轴颈尺寸和形位公差；检查键槽和花键配合状态；检查与轮毂和齿轮箱的连接面；检查轴颈表面粗糙度和有无磨损；监测运行挠度。 | 当主轴出现疲劳裂纹、轴颈磨损严重导致配合间隙超差、键槽严重压溃、弯曲变形超过允许值时，应报废更换。报废主轴按合金锻钢废料回收。 |
| 主轴承 | 主轴系统 | 双列圆锥滚子轴承或三排圆柱滚子轴承，承受径向和轴向载荷。 | 是 | 按运行小时数定期补充极压润滑脂；用振动分析仪监测轴承特征频率幅值；监测轴承温度，温升超过40K应停机检查；大修时测量径向和轴向游隙；检查密封件状态；用听音棒检查运转声音。 | 当滚道或滚动体出现大面积剥落、游隙超过允许值、运转噪声严重异常、保持架断裂、内外圈出现裂纹时，应报废更换。废旧主轴承按轴承钢废料回收。 |
| 轴承座及密封 | 主轴系统 | 安装主轴承，密封件防止油脂泄漏与污染物侵入。 | 是 | 定期检查轴承座有无裂纹和变形；检查与机架连接螺栓紧固状态；检查密封件有无老化和泄漏；检查润滑通道是否畅通；大修时测量轴承座内孔尺寸和圆度；更换老化密封件。 | 当轴承座出现裂纹、内孔磨损导致配合松动、密封面严重损伤、油路堵塞无法疏通时，应报废更换。报废轴承座按铸铁或铸钢废料回收。 |
| 锁紧盘 | 主轴系统 | 用于主轴与齿轮箱输入轴的无键连接，传递扭矩。 | 否 | 定期检查锁紧盘紧固螺栓力矩是否在规定值；检查锁紧盘内外环有无滑移痕迹；检查端面有无磨损和变形；大修时拆卸检查接触面状态；检查有无松动导致振动增大。 | 当锁紧盘内外环出现严重滑移磨损、螺栓多次紧固后仍反复松动、接触面严重损伤导致无法传递额定扭矩时，应报废更换。报废锁紧盘按合金钢废料回收。 |
| 主轴接地碳刷 | 主轴系统 | 通过碳刷将电刷接触主轴，释放轴电流、保护轴承，碳刷磨损需更换。 | 是 | 每季度检查碳刷磨损长度，剩余长度不足原长的1/3应更换；检查碳刷与主轴的接触压力是否均匀；检查碳刷弹簧状态；检查引线连接是否可靠；检查碳刷支架绝缘是否良好；检查主轴接触面是否光滑。 | 当碳刷磨损至极限标记以下、碳刷碎裂、弹簧疲劳断裂、支架绝缘下降、引线断裂时，应报废更换。废旧碳刷按含碳废料处理。 |
| 齿轮箱 | — | 增速增扭，将低速旋转提升至发电机所需转速；多级平行轴/行星结构。 | 否 | 制定齿轮箱综合维护方案：定期监测油液品质（粘度、酸值、水分、金属磨粒）；按规定周期更换润滑油和滤芯；定期进行振动和噪声分析；每年检查齿轮啮合状态；监测油温、油压和冷却系统效率；大修时进行内部检查。 | 当齿轮箱内部齿轮大面积磨损或断齿、箱体出现裂纹、轴承多处损坏、传动效率严重下降、油液金属磨粒浓度持续异常升高、修复成本超过新件价值的50%时，应报废更换。报废齿轮箱排空残油后按金属废料回收。 |
| 行星级齿圈 | 齿轮箱 | 内齿圈，承受高扭矩，易发生齿面点蚀、剥落。 | 是 | 大修时检查内齿面状态：有无点蚀、剥落和磨损；测量齿厚变化；检查齿根有无裂纹；结合油液分析监测磨损趋势；运行中监测齿轮啮合噪声和振动频谱。 | 当内齿面出现大面积剥落（超过齿面面积的20%）、发生断齿、齿面严重磨损导致侧隙超过设计值的2倍时，应报废更换。报废齿圈按合金钢废料回收。 |
| 行星轮及太阳轮 | 齿轮箱 | 传递动力核心齿轮，接触应力大，常出现断齿、磨损。 | 是 | 大修时检查齿面状态：有无点蚀、剥落、磨损和胶合；测量齿厚减薄量；检查齿根有无疲劳裂纹（磁粉探伤）；检查轴承配合面；结合振动分析和油液分析评估磨损状态。 | 当齿面大面积剥落、发生断齿、齿根出现疲劳裂纹、齿厚减薄超过原齿厚的15%、严重胶合时，应报废更换。报废齿轮按合金钢废料回收。 |
| 高速轴轴承 | 齿轮箱 | 支撑高速轴，承受径向载荷与轴向力；散落异物和润滑不良致失效。 | 是 | 按规定周期补充润滑脂或监测润滑油供给；用振动分析仪监测轴承特征频率；监测轴承温度；大修时测量游隙；检查滚道和滚动体状态；检查保持架状态。 | 当滚道或滚动体出现大面积剥落和点蚀、游隙超过允许值、保持架断裂、运转噪声严重异常时，应报废更换。废旧轴承按轴承钢废料回收。 |
| 箱体及油路 | 齿轮箱 | 润滑油存储、过滤、冷却循环，包含滤清器、散热器、泵。 | 否 | 定期检查箱体有无渗漏和裂纹；检查油路系统各部件功能是否正常；检查滤清器压差，按周期更换滤芯；检查油冷却器散热效果；检查油泵出口压力和流量；定期清洗油箱底部沉积物；检查管路和接头有无泄漏。 | 当箱体出现裂纹导致泄漏、油路系统严重损坏无法保障齿轮箱润滑冷却、整体修复不经济时，应评估报废更换。报废时排空润滑油，按各部件材质分类回收。 |
| 齿轮箱弹性支撑 | 齿轮箱 | 橡胶或复合材料减震支撑，吸收振动与冲击，橡胶老化开裂。 | 是 | 每年检查弹性支撑有无老化、开裂和变形；检查橡胶与金属粘接有无脱层；测量压缩永久变形量；检查安装螺栓紧固状态；监测齿轮箱振动值变化，异常增大时排查弹性支撑状态。 | 当橡胶大面积开裂或与金属脱层、永久压缩变形超过原高度的15%、弹性严重下降失去减震功能时，应报废更换。废旧弹性支撑按橡胶和金属分类处理。 |
| 高速轴联轴器 | — | 连接齿轮箱输出与发电机输入，补偿不对中与扭振。 | 是 | 定期检查联轴器对中状态，偏差超过允许值需重新找正；检查弹性元件有无老化和变形；检查膜片或弹性垫状态；检查法兰连接螺栓紧固力矩；检查有无异常振动和噪声；检查扭转刚度是否正常。 | 当弹性元件严重老化或碎裂、膜片出现疲劳裂纹、法兰变形导致无法对中、扭转刚度严重变化、多次对中后仍反复出现异常振动时，应报废更换。报废联轴器按金属和弹性元件分类处理。 |
| 发电机 | — | 将机械能转化为电能，双馈异步或永磁直驱；包含定子、转子、绝缘系统。 | 否 | 制定发电机综合维护方案：每季度检查绝缘电阻和运行参数；每半年检查轴承润滑状态；每年进行绕组温度监测和保护功能测试；检查冷却系统运行状态；监测输出电压、电流和功率品质；定期进行振动分析。 | 当发电机绕组严重烧毁或绝缘老化、转轴弯曲无法校直、铁芯严重烧损、整体效率下降超过额定值的15%且经大修无法恢复时，应报废。报废发电机拆解回收铜线、硅钢片和结构件。 |
| 发电机定子 | 发电机 | 三相绕组，产生旋转磁场，绝缘老化、局部放电易发故障。 | 是 | 每半年测量定子绕组绝缘电阻，R≥1MΩ（热态）为合格；测量三相直流电阻，不平衡度应小于2%；运行中监测绕组温度；定期进行匝间耐压试验；大修时检查绕组端部绑扎和槽楔状态；检查引出线绝缘。 | 当绕组绝缘电阻持续低于标准值且无法恢复、匝间或相间短路烧毁、绝缘严重老化大面积脱落、直流电阻严重不平衡（超过5%）时，应报废更换或重新绕制。报废绕组回收铜导线。 |
