| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 塔筒本体 | — | 支撑机舱与风轮至设计高度的锥形或柱形钢结构，分为全钢塔筒（多节法兰连接）和混塔（下部混凝土+上部钢塔筒），高度80~160m。 | 否 | 每年外观检查筒壁有无裂纹、腐蚀和变形；每2年壁厚超声波测量；检查法兰连接螺栓紧固力矩（分次对称紧固）；检查防腐涂层（环氧富锌底漆+环氧中间漆+聚氨酯面漆）；检查塔筒垂直度。 | 壁厚因腐蚀减薄超过设计值15%、法兰严重变形、焊缝裂纹不具备修复条件、塔筒弯曲超出允许值。按结构钢废料回收。 |
| 塔筒法兰 | 塔筒本体 | 连接相邻塔筒节段及塔筒与机舱/基础的环形锻件，厚度80~120mm，外径4~6m。 | 否 | 大修时检查法兰面平面度和变形量；无损检测检查焊缝有无裂纹；检查螺栓孔有无裂纹和磨损。 | 法兰变形超差导致无法对中连接、法兰面严重腐蚀、螺栓孔裂纹。更换法兰需整节塔筒返厂处理。 |
| 连接螺栓 | 塔筒本体 | 连接各塔筒节段法兰的高强度预应力螺栓（M36~M72），每法兰约48~80根，张拉力300~450kN。 | 是 | 按运行年限定期抽检螺栓紧固力矩（通常每年抽检20%）；大风季后全面检查；检查螺栓防腐涂层；加装防松标记。 | 螺栓断裂、螺纹滑丝、预紧力持续丧失、疲劳裂纹。更换需使用同规格同等级螺栓，重新按力矩值交叉对称紧固。 |
| 防腐涂层系统 | 塔筒本体 | 塔筒外壁多层防护涂层（环氧富锌底漆80μm+环氧中间漆120μm+聚氨酯面漆60μm，总厚≥260μm），盐雾试验≥1000h。 | 是 | 每年检查涂层有无脱落、起泡、粉化和锈蚀；对局部损伤部位除锈补漆（St3级）；大修时对腐蚀严重区域重新喷砂处理。 | 涂层大面积脱落导致基材严重锈蚀。重新喷砂除锈后按涂装工艺逐层恢复。 |
| 塔筒门及密封 | 塔筒本体 | 塔筒底部进出检修门，配备密封橡胶条和门锁，防护等级≥IP54。 | 是 | 定期检查门扇开关灵活性；检查密封条弹性和老化状态；检查门锁和门接地带完好。 | 门体严重变形、密封条老化龟裂、门锁损坏。更换密封条时需清洁密封面。 |
| 内部平台及爬梯 | — | 塔筒内部各层钢结构平台和垂直爬梯/斜梯，供运维人员登塔和休息，含防坠安全导轨。 | 否 | 定期检查平台板和爬梯焊缝有无开裂；检查平台连接螺栓紧固；检查防坠导轨完好性；检查扶手和护栏。 | 焊缝大面积开裂、平台板严重腐蚀穿孔。更换平台板按结构钢废料处理。 |
| 电缆支架及电缆夹 | — | 塔筒内部固定动力电缆和控制电缆的支架和夹具，防止电缆因机组偏航和塔筒振动而磨损。 | 否 | 定期检查电缆支架紧固状态；检查电缆夹具有无老化松动；检查电缆有无异常摩擦痕迹。 | 支架严重锈蚀断裂、夹具老化松动。更换支架和夹具，重新固定电缆。 |
| 塔筒照明系统 | — | 塔筒内部各层平台的LED照明灯具和线路，含应急照明。 | 是 | 定期检查灯具工作状态；检查应急照明电池和功能；检查线路和开关完好。 | LED灯具损坏或光衰严重、线路老化。按电子和金属废料分类处理。 |
