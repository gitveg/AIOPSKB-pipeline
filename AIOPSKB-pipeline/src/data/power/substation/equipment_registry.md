| 设备类型名称 | 设备属性 | 描述 |
|----------|----------|------|
| 变压器 | 主设备 | 变电站核心设备，用于在两个电压等级之间进行功率传输的升压、降压或联络变换，是变电站中体积最大、造价最高的设备。包括主变压器（单元制电压变换）和联络变压器（连接不同电压等级母线实现功率交换），本体结构和故障模式相同，在属性层区分运行角色 |
| GIS（气体绝缘组合电器） | 主设备 | 将断路器、隔离开关、接地开关、互感器、避雷器、母线等封闭在SF6气体绝缘的金属壳体内的组合电器，具备独立整体KKS编码、独立SF6检修班组，结构紧凑、可靠性高 |
| 断路器 | 主设备 | 唯一能开断短路电流的主回路开关设备，是电力系统最重要的开关设备。按灭弧介质分为SF6断路器和真空断路器等，不同灭弧介质属技术路线差异，在部件层区分 |
| 隔离开关 | 主设备 | 在主回路中建立可见绝缘断开点的高压开关设备，保证检修安全，有独立KKS编码、独立操作机构，故障或卡涩直接导致对应间隔停运 |
| 负荷开关 | 主设备 | 能在正常回路条件下关合、承载和开断负荷电流的开关设备，具备独立产品标准（GB/T 3804），常用于10~35kV配电装置作为进出线主开关 |
| 母线（汇流排） | 主设备 | 变电站中汇集和分配电能的导体，是连接各进出线回路和变压器的核心节点，分为硬母线（铝管母线）和软母线（导线），故障影响全站或半站停电 |
| 互感器 | 主设备 | 将一次侧高电压/大电流按比例转换为二次侧标准信号的变换设备，为测量、计量和保护装置提供信号。包括电流互感器(CT)、电压互感器(PT/VT)和电容式电压互感器(CVT)，不同原理在部件层区分 |
| 并联电抗器 | 主设备 | 并联连接于变电站母线上用于吸收容性无功功率的电抗器，限制工频过电压和操作过电压，主要用于超高压和特高压变电站，一次主回路设备 |
| 串联电抗器 | 主设备 | 串联于回路中用于限制短路电流的电抗器，包括限流电抗器和滤波电抗器，串联于主回路承载全电流，故障直接导致所串回路停运 |
| 并联电容器组 | 主设备 | 并联于变电站母线上用于提供容性无功、提高功率因数和改善电压水平的电容器装置，通常配有串联电抗器限制合闸涌流 |
| 串联补偿装置 | 主设备 | 串联于输电线路中的电容器组装置，缩短线路电气距离、提高输送能力和系统稳定性。按控制方式分为固定串补(FSC)和可控串补(TCSC)，在部件层区分 |
| 接地开关（快速接地开关） | 辅助设备 | 用于将停电设备可靠接地的开关设备，快速接地开关还具有合闸于短路时快速关合的能力，属于检修安全措施，配合线路侧检修和感应电压泄放 |
| 避雷器（氧化锌避雷器MOA） | 辅助设备 | 以氧化锌阀片为核心的非线性电阻元件，用于限制雷电过电压和操作过电压，保护变电站设备绝缘不受损害 |
| 穿墙套管 | 辅助设备 | 用于将导体从户内穿墙引至户外的绝缘套管，功能依附于墙体两侧的一次设备 |
| 动态无功补偿装置（SVC/SVG） | 辅助设备 | 动态无功补偿设备，包括SVC（晶闸管控制电抗器+电容器组）和SVG/STATCOM（基于IGBT的电压源型补偿器），用于电能质量治理和电压支撑 |
| 继电保护装置 | 辅助设备 | 检测电力系统故障或异常并发出跳闸指令的保护系统，按保护对象分为线路保护、变压器保护、母线差动保护、断路器失灵保护、电抗器保护等，在部件层区分保护对象和原理 |
| 测控装置 | 辅助设备 | 实现遥测（电气量测量）、遥信（状态采集）、遥控（开关操作）和遥调（参数设置）功能的装置，功能依附于对应一次设备 |
| 电力电缆（站内电缆） | 辅助设备 | 变电站内用于各设备之间电气连接的电力电缆 |
| 站用变压器 | 辅助设备 | 为变电站内低压用电设备供电的降压变压器 |
| 中性点接地装置 | 辅助设备 | 用于变压器中性点接地的成套装置，包括中性点隔离开关、避雷器、放电间隙等 |
| 故障录波器 | 辅助设备 | 记录变电站故障前后各回路电气量波形和开关量状态的装置 |
| 保护信息管理子站 | 辅助设备 | 采集和管理全站继电保护装置运行信息的子站系统 |
| 电能量计量装置 | 辅助设备 | 包括关口电能表和计量用互感器，用于电能量精确计量和贸易结算 |
| 同期装置 | 辅助设备 | 并网合闸时检测同期条件的自动装置 |
| 备用电源自动投入装置（BZT） | 辅助设备 | 当工作电源断开后自动投入备用电源的装置 |
| 电压无功自动控制装置（VQC） | 辅助设备 | 自动调节变压器分接头和无功补偿装置投切的自动控制装置 |
| 变压器冷却系统 | 辅助设备 | 为主变压器提供冷却的成套装置，包括风冷或强迫油循环系统 |
| 变压器有载分接开关 | 辅助设备 | 在变压器带负荷情况下切换分接头以调节电压比的装置 |
| 变压器非电量保护装置 | 辅助设备 | 基于瓦斯继电器、压力释放阀等非电气量信号动作的保护装置 |
| 变压器在线监测装置 | 辅助设备 | 在线监测变压器绝缘油中溶解气体（油色谱）和局部放电信号的装置，评估绝缘状态 |
| SF6气体监测系统 | 辅助设备 | 监测GIS等设备中SF6气体密度、压力和微水含量的在线监测系统 |
| 监控与数据采集系统（SCADA） | 公用系统 | 变电站综合自动化系统的监控核心，实现全站运行参数监视、设备操作控制、事件报警和数据存储 |
| 远动通信装置 | 公用系统 | 将变电站运行数据上传调度中心并接收调度指令的通信装置 |
| 微机五防系统 | 公用系统 | 实现防止误分误合断路器等五防闭锁功能的系统 |
| 站用交流配电系统 | 公用系统 | 由站用变压器、交流配电屏和低压开关柜组成，为全站交流负荷供电 |
| 直流电源系统 | 公用系统 | 由蓄电池组、充电装置和直流配电屏组成，为保护、控制、信号回路提供不间断直流电源 |
| 蓄电池组 | 公用系统 | 直流电源系统的储能单元，在交流失电时提供后备电源 |
| UPS不间断电源 | 公用系统 | 为监控主机、通信设备等重要负荷提供交流不间断电源 |
| 通信设备（光端机/交换机） | 公用系统 | 用于站间数据通信的设备，包括SDH光端机、工业以太网交换机等 |
| 消防系统 | 公用系统 | 包括火灾探测器、火灾报警控制器、灭火装置和消防水泵等 |
| 安防与视频监控系统 | 公用系统 | 包括摄像头、门禁、红外入侵探测器、电子围栏等安防设施 |
| 环境监测系统 | 公用系统 | 监测站内温度、湿度、水位、SF6气体泄漏等环境参数的系统 |
| 接地网 | 公用系统 | 由水平接地体和垂直接地极组成的全站接地系统 |
| 给排水系统 | 公用系统 | 站内供水和排水设施 |
| 通风与空调系统 | 公用系统 | 控制控制室、开关室和蓄电池室内温湿度的系统 |
| 照明系统 | 公用系统 | 包括正常照明、应急照明和事故照明 |
| 预制舱/模块化建筑 | 公用系统 | 用于智能变电站的预制式模块化设备舱体，实现工厂化加工和现场快速安装 |
