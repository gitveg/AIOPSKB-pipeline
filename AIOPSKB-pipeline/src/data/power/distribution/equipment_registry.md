|----------|----------|------|
| 配电变压器 | 主设备 | 将10kV/20kV中压降至380V/220V低压的配电变压器，包括柱上变压器、配电室变压器、地下变压器等，不同安装环境和绝缘型式（油浸/干式）在部件层区分 |
| 箱式变电站 | 主设备 | 将高压开关设备、配电变压器和低压配电装置集成为一体的工厂预制户外紧凑型配电设备（GB 17467），容量50~2500kVA，是系统级集成设备，故障模式为多专业耦合 |
| 中压开关柜 | 主设备 | 12kV/24kV金属封闭开关设备和控制设备（GB 3906范畴），包括环网柜、中压断路器柜、负荷开关柜等，不同主开关类型和绝缘介质在部件层区分 |
| 柱上开关 | 主设备 | 安装在架空配电线路电杆上的户外中压开关设备，包括柱上断路器和柱上负荷开关，户外工况导致故障模式（雷击、覆冰、鸟害）与户内开关柜显著不同 |
| 电缆分支箱 | 主设备 | 用于10kV/20kV电缆配电线路分支连接的户外箱体设备，具有独立箱体和基础，是电缆线路的主动分接节点 |
| 架空配电线路 | 主设备 | 以导线、杆塔和绝缘子组成的中低压架空配电线路，电压等级10kV/20kV（中压）和380V/220V（低压），是配电网络中常见的线路形式 |
| 电缆配电线路 | 主设备 | 以电力电缆和电缆附件（终端头、中间接头）组成的中低压地下配电线路，城市配电网络中广泛使用，供电可靠性高 |
| 低压开关柜 | 辅助设备 | 380V/220V低压配电系统中的开关柜设备（GGD/GCK/MNS等），用于变压器低压侧的电能接收和分配 |
| 配电箱 | 辅助设备 | 建筑内部低压末级配电设备（XL-21型等），将电能分配到各个用电回路 |
| 低压断路器 | 辅助设备 | 用于低压配电线路保护和控制的开关电器，包括框架式断路器(ACB)、塑壳断路器(MCCB)和微型断路器(MCB)，作为低压配电装置的保护控制元件 |
| 互感器 | 辅助设备 | 将配电系统中的高电压/大电流按比例转换为标准信号的变换设备，包括电流互感器(CT)和电压互感器(PT)，为保护和测量提供信号 |
| 避雷器 | 辅助设备 | 金属氧化物避雷器(MOA)，用于配电系统过电压保护，限制雷电和操作过电压 |
| 继电保护装置 | 辅助设备 | 配电系统的保护继电器和微机保护装置，在故障时快速切除故障元件 |
| 配电自动化终端 | 辅助设备 | 包括馈线终端(FTU)、站所终端(DTU)和台区终端(TTU)，实现配电设备的监测和控制，在属性层区分应用类型 |
| 故障指示器 | 辅助设备 | 安装在配电线路上检测故障电流并指示故障方向的装置，配合配电自动化定位故障区段 |
| 电容器组 | 辅助设备 | 配电网无功补偿的并联电容器装置，提高功率因数、改善电压质量 |
| 静止无功发生器SVG | 辅助设备 | 基于电力电子器件的动态无功补偿装置，连续快速提供无功功率 |
| 智能电表 | 辅助设备 | 具备双向计量、远程抄表和费控功能的智能电能表 |
| 集中器 | 辅助设备 | 低压台区电能数据采集和传输的集中抄表设备 |
| 配电自动化主站 | 公用系统 | 配电自动化系统的中央控制平台（SCADA/DA主站），实现对配电网的实时监控、故障研判和自愈控制 |
| 接地装置 | 公用系统 | 配电系统接地系统，包括接地极、接地引下线和接地网 |
| 通信设备 | 公用系统 | 配电自动化通信基础设施，包括光纤、无线专网、5G模块和电力线载波等 |
