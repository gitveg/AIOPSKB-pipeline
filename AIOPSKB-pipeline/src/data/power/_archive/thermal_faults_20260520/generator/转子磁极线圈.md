| 转子磁极线圈匝间短路 | 电气/绝缘 | 严重 | 磁极线圈匝间绝缘损坏，导致部分线匝被短接，有效匝数减少。通常由制造缺陷、绝缘老化、热应力、机械振动或过电压冲击引起。 | 1. 机组振动随励磁电流增大而加剧。 2. 在相同工况下，励磁电流明显大于历史值。 3. 无功功率受限或下降。 4. 磁极表面有不均匀灼伤痕迹。 | 1. 交流阻抗值[电气]: 故障磁极阻抗值显著低于正常值(如不到正常值的10%)。 2. 功率损耗[电气]: 短路点发热导致损耗异常。 3. 轴电压升高[电气]: 转子磁化，轴电压>10×10⁻⁴T(参考值)。 | 1. 探测线圈法[离线]: 监测槽漏磁通波形异常。 2. 交流阻抗与功率损耗试验[离线]: 测量单个磁极数据，与历史值对比。 3. 重复脉冲法(RSO)试验[离线]: 诊断定位短路点。 | 1. 对比各磁极交流阻抗值，符合“V”形分布逻辑的即为故障磁极。 2. 重复脉冲法(RSO)试验波形出现特征性畸变，可定位匝间短路。 3. 在线监测励磁电流增长超过2.5%阈值，并伴随振动增加。 | 根本处理：1. 解体转子，吊出故障磁极。 2. 拆除磁极线圈绝缘，清理匝间绝缘残留物。 3. 更换新的匝间绝缘垫条(NOMEX纸等)。 4. 回装线圈，进行匝间绝缘耐压试验。 5. 工具: 吊车、绝缘材料、耐压测试仪。 | 1. 加装转子绕组匝间短路在线监测装置。 2. 定期(建议缩至1-2年)开展转子交流阻抗及功率损耗试验。 3. 加强转子制造过程质量管控，防止异物落入。 |
| 转子磁极线圈主绝缘老化/磨损/接地 | 绝缘 | 危急 | 磁极线圈对铁心(地)的绝缘(主绝缘)损坏，形成金属性接地或低阻通道。由绝缘老化、安装工艺不当、异物搭桥、磨损等造成。 | 1. 发电机转子一点接地保护报警或跳闸。 2. 转子绝缘电阻值异常降低(如低于80kΩ报警值)。 3. 停机状态下绝缘电阻可能恢复正常。 4. 绝缘监测仪读数跳变。 | 1. 转子绝缘电阻[物理]: 用1000V兆欧表测量，对地电阻<0.5MΩ或报警值。 2. 绝缘吸收比[物理]: 吸收比不应小于1.3(沥青浸胶及烘卷云母绝缘)。 3. 绝缘对地电压[电气]: 正负极对地电压不平衡。 | 1. 转子一点接地保护装置[在线]: 实时监测对地绝缘。 2. 绝缘电阻测试仪(兆欧表)[离线]: 停机后断开连接进行测量。 3. 二分法排查[离线]: 逐段解开磁极连接线，缩小故障范围。 | 1. 停机后先检查外部励磁回路是否接地。 2. 若外部回路正常，使用二分法断开极间连接线，确定绝缘最低的磁极。 3. 若绝缘电阻随施加电压升高而击穿，则存在隐形接地。 4. 若转子旋转时报警，静止时恢复，可能为异物离心力搭桥。 | 根本处理：1. 吊出故障磁极，彻底清扫或清洗。 2. 检查并处理绝缘压板、托板、NOMEX纸有无损伤、碳化，更换损坏绝缘件。 3. 检查磁极铁心与线圈间的空气间隙，清除金属屑、润滑脂等异物。 4. 采用专用绝缘修复材料填充或包裹破损处并固化。 5. 回装后做直流耐压试验。 | 1. 加强机组安装、检修现场环境控制，防止金属屑、焊渣、润滑脂进入。 2. 大修时用内窥镜检查绝缘状态。 3. 机组启动前进行额定转速下动态绝缘试验。 4. 停机时采取防潮、防尘措施。 |
| 转子磁极线圈变形与松动 | 机械 | 一般 | 由于热膨胀、离心力作用、绝缘材料收缩或固定部件失效，导致线圈在磁极铁心上发生位移或松动。 | 1. 转子振动随转速或温度变化。 2. 线圈绝缘电阻周期性或不稳定变化。 3. 可听到异物碰撞声(严重时)。 4. 线圈之间有肉眼可见的位移。 | 1. 振动幅值[物理]: 转频或倍频振动幅值(X, Y方向)增大。 2. 振动相位[物理]: 相位不稳定。 3. 绝缘电阻[物理]: 阻值跳动。 | 1. 振动在线监测系统[在线]: 分析历史数据趋势。 2. 停机锤击检查[离线]: 检查线圈与铁心间的紧固程度。 3. 内窥镜检查[离线]: 观察极间连线、垫块和线圈端部状态。 | 1. 发现振动值与励磁电流、温度正相关。 2. 锤击线圈或压板有空响或松动感。 3. 测量线圈与铁心间的间隙，大于设计值(如7mm空气间隙变大)。 | 根本处理：1. 解体转子，吊出磁极。 2. 检查线圈底部的弹簧状况，更换失效弹簧并重新压紧。 3. 更换老化收缩的绝缘板、垫块。 4. 紧固或更换线圈固定架及螺丝，打紧防松措施。 5. 加热固化新绝缘材料，使其与线圈紧密贴合。 | 1. 大修时重点检查绝缘压板、固定螺栓及弹簧。 2. 运行中加强转子振动监测。 3. 使用抗蠕变性能更好的绝缘材料。 |
| 转子磁极极间连接线/引线故障 | 电气/热 | 严重 | 磁极之间的连接铜排或转子引线，因结构设计缺陷、焊接不良、应力集中或振动导致过热、裂纹甚至断裂。常见于根部、弯曲处或接头处。 | 1. 转子直流电阻明显增大。 2. 励磁电流与无功功率异常下降。 3. 连接处过热变色、绝缘烧焦。 4. 机组振动增大。 5. 严重的出现放电或拉弧。 | 1. 直流电阻[电气]: 转子直流电阻值比历史值明显增大。 2. 红外测温[物理]: 接头或引线弯曲处温度异常升高。 3. 励磁电流与机端电压[电气]: 在一定无功功率下，励磁电流不升反降。 | 1. 直流电阻测量[离线]: 大修时测量转子绕组整体及分段的直流电阻。 2. 红外热成像仪[离线]: 对非带电部分进行外观测温。 3. 内窥镜检查[离线]: 重点检查根部、弯曲处有无裂纹。 4. 励磁电流、无功功率趋势分析[在线]。 | 1. 测量转子绕组直流电阻，若与历史数据偏差较大，需分段测量定位高阻区域。 2. 用内窥镜发现铜排表面有裂纹、过热变色痕迹。 3. 机组运行时励磁电流与无功功率关系曲线异常，反推引线过热的可能。 | 根本处理：1. 对于裂纹或断裂处，用氧-乙炔火焰加热取下连接铜排。 2. 在裂纹两侧切出坡口，用银基焊料或磷铜焊条进行补焊。 3. 补焊后校正外形，打磨光滑，酸洗去氧化皮。 4. 对于应力集中导致的频繁故障，应优化设计，增大弯曲半径R≥2d，并加装软连接补偿装置。 | 1. 抽蓄机组新机设计采用整板加工一体铜排，避免拼焊。 2. 磁极连接线设计补偿装置以吸收振动位移。 3. 大修时检查连接线根部等应力集中部位有无裂纹。 4. 安装及检修时保持铜排在自由状态下连接固定。 |
| 阻尼绕组故障(开焊/断裂/变形) | 机械/电气 | 一般 | 阻尼绕组(笼条与端环)受频繁启停、失磁运行、制造缺陷等影响，导致开焊、断裂或变形。端环强度不足或固定不牢是变形主因。 | 1. 电机启动困难，启动时间显著延长。 2. 启动时伴有振动和噪声。 3. 严重时电机无法启动。 4. 故障点有放电火花或金属氧化变色痕迹。 | 1. 启动时间[物理]: 启动时间超过正常设计值。 2. 启动电流[电气]: 启动电流波形异常或持续时间延长。 3. 局部温度[物理]: 焊接点或端环局部过热。 | 1. 停机状态下的目视及锤击检查[离线]: 检查焊缝有无裂纹、变色，敲击听声判断是否断裂。 2. 开口变压器检测[离线]: 检查笼条焊接质量。 3. 启动特性监测[在线]: 记录启动电流和时间。 | 1. 电机启动时间明显长于正常，且启动过程振动剧烈。 2. 敲击疑似断裂处有断裂的哑声。 3. 用开口变压器逐槽检查笼条，感应电流显著降低即为有开焊或断裂。 | 根本处理：1. 用氧-乙炔火焰加热端环与笼条的焊缝，将端环从阻尼条上脱下。 2. 更换有裂纹或断裂的阻尼条，确保与槽配合间隙合适(0.1~0.2mm)。 3. 对变形端环进行加热校正，对断裂端环进行坡口补焊并加工。 4. 清理槽内，重装合格的阻尼条，用银焊将端环与阻尼条焊牢。 | 1. 避免频繁连续启动或失磁运行。 2. 确保安装时阻尼条在槽内固定牢固，端环与笼条焊接饱满。 3. 使用强度更高的端环材料或改进结构。 |
| 转子磁极线圈表面脏污受潮 | 绝缘/环境 | 轻微 | 碳粉、灰尘、油污、金属屑等杂物附着在磁极线圈端部表面，吸收水分后形成导电通道，导致绝缘电阻降低。 | 1. 转子绝缘电阻偏低或波动。 2. 转子接地保护装置可能报警(低阻但不为零)。 3. 潮湿天气时绝缘下降更明显。 | 1. 绝缘电阻[物理]: 转子对地绝缘低于正常值，但无明确的金属接地点。 2. 绝缘吸收比[物理]: 吸收比降低。 3. 目视检查[状态量]: 表面有明显的脏污、积灰或油迹。 | 1. 绝缘电阻测试仪[离线]: 定期测量，跟踪变化趋势。 2. 目视及内窥镜检查[离线]: 检查线圈表面及通风道清洁度。 | 1. 绝缘电阻低于历史同期正常值，但排除永久性接地故障。 2. 对怀疑部位进行清理后，绝缘电阻显著回升，即可确诊。 | 根本处理：1. 抽出转子或进入定子膛内。 2. 采用带电清洗剂配合高压水或蒸汽冲洗，彻底清除线圈表面及缝隙内的油污、碳粉。 3. 冲洗后进行烘干处理(烘箱或热风干燥)，直至绝缘电阻合格。 4. 若不具备解体条件，可用压缩空气吹扫。 | 1. 保持发电机密封油系统、轴承等无泄漏，防止油污进入。 2. 控制发电机内部湿度，防止结露。 3. 停机检修时彻底清理风道内部。 |
| 转子磁极铁心及附件机械故障 | 机械 | 严重 | 磁极铁心斜键松动、风扇叶裂纹/脱落、阻尼端环连接板固定螺丝松脱等。由安装不当、材料疲劳或应力集中引起。 | 1. 机组振动突然增大或变化。 2. 转子转动时有金属摩擦或撞击的异音。 3. 检查发现固定件松脱、位移或裂纹。 | 1. 振动幅值[物理]: 振动分量突变。 2. 声发射[物理]: 出现特征性高频信号。 3. 紧固件力矩检查[状态量]: 力矩值低于标准。 4. 目视检查[状态量]: 部件有裂纹、变形。 | 1. 振动在线监测[在线]: 分析频谱和趋势。 2. 停机后的目视及锤击检查[离线]: 检查斜键、风扇叶、螺栓等是否紧固。 3. 着色探伤[离线]: 检查怀疑有裂纹的部件。 | 1. 振动值突变，且频率与转频或极频相关。 2. 锤击斜键小头端有空响声或松动感。 3. 着色探伤发现部件存在裂纹。 | 根本处理：1. 对于松动的斜键，剔开焊点，用专用工具重新打紧，确保接触面>75%，然后点焊牢固。 2. 更换有裂纹的风扇叶片，紧固所有固定螺栓并锁死防松垫片。 3. 采用加热校正或补焊方式修复变形的端环或连接板。 4. 对转子进行动平衡试验，确保平衡。 | 1. 大修时检查所有固定件的紧固情况。 2. 优化风扇叶片和连接部件的焊接与热处理工艺。 3. 对斜键等关键部件进行无损探伤。 |
