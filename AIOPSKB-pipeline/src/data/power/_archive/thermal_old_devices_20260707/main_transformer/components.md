| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 器身 | — | 由铁芯和绕组构成，是变压器的核心电磁部分，实现电压、电流和阻抗的变换。 | 否 | 定期进行油色谱分析（DGA）监控内部放电和过热趋势；大修时吊芯检查铁芯、绕组和绝缘结构状态；测量绕组直流电阻、绝缘电阻和介质损耗；进行绕组变形测试。运行中监控顶层油温、负载电流和冷却系统运行状态。 | 器身严重故障（绕组烧毁、铁芯大面积损坏或绝缘系统严重老化），经吊芯检查确认修复费用超过新变压器的60%。更换变压器需制定运输和吊装专项方案，安装后做全套交接试验。 |
| 铁芯 | 器身 | 由硅钢片叠装而成，构成变压器的磁路，为磁通提供低磁阻路径。 | 否 | 大修时测量铁芯对地绝缘电阻（应大于100MΩ）；检查铁芯接地片是否可靠；检查铁芯有无局部过热痕迹（通过油中溶解气体分析CH4、C2H4判断）；检查夹件和拉带紧固状态。运行中定期进行油色谱分析。 | 铁芯多点接地导致局部过热且无法消除；硅钢片片间绝缘大面积损坏导致空载损耗严重增加；铁芯严重变形。铁芯故障通常需返厂或整体更换变压器。 |
| 绕组 | 器身 | 由铜或铝导线绕制而成，构成变压器的电路部分，通过电磁感应传递能量。 | 否 | 大修时测量绕组直流电阻（三相不平衡率应小于2%）；测量绕组绝缘电阻和吸收比；进行绕组变形测试（频率响应法）；检查绕组端部垫块和撑条有无松动位移。运行中监控负载电流和顶层油温。 | 绕组变形严重导致阻抗电压偏移超标；直流电阻严重不平衡确认匝间短路；绝缘老化击穿。绕组故障通常需返厂检修或更换变压器。 |
| 绝缘结构 | 器身 | 包括绝缘纸、纸板、绝缘筒、撑条等，用于将绕组、铁芯等不同电位部件隔开。 | 否 | 运行中通过油色谱分析（CO、CO2生成速率）和油中糠醛含量评估绝缘老化程度；大修吊芯时检查绝缘纸有无变脆、撑条垫块有无松动和碎裂、绝缘筒有无爬电痕迹；控制运行温度和负载防止加速老化。 | 绝缘系统整体严重老化（聚合度低于250、局部放电量严重超标），需整体更换绕组绝缘或返厂大修。 |
| 绝缘纸 | 绝缘结构 | 用于匝间、层间绝缘，在油浸式变压器中与变压器油配合提供主要绝缘保障，长期运行会老化变脆。 | 是 | 运行中通过油色谱分析（CO、CO2生成速率）和油中糠醛含量间接判断绝缘纸老化程度；控制顶层油温不超过允许值；避免长期过载运行加速老化。大修时可通过油样测试和绝缘电阻测量评估整体绝缘状态。 | 糠醛含量或聚合度测试表明绝缘纸严重老化（聚合度低于250）；绝缘电阻严重下降且无法通过干燥恢复。绝缘纸老化到一定程度后通常需整体更换绕组或变压器。 |
| 撑条与垫块 | 绝缘结构 | 用于支撑和压紧绕组，形成散热油道和绝缘间隙，承受短路电动力，易受机械应力损伤。 | 是 | 大修时检查撑条和垫块有无松动、位移和碎裂；检查绕组压紧力是否足够（可通过压钉调整）；检查油道是否通畅。运行中如经历近区短路故障，应检查垫块状态。 | 撑条或垫块大面积碎裂导致绕组松动；短路后位移严重无法通过调整压钉恢复。需吊芯检修，更换损坏的撑条垫块并重新压紧绕组。 |
| 绝缘筒及角环 | 绝缘结构 | 用于分隔绕组与铁芯或相邻绕组，并延长端部爬电距离，承受高场强，长期运行或受潮后绝缘性能易下降。 | 是 | 大修时检查绝缘筒有无变形、开裂和表面爬电痕迹；检查角环有无破损和位移；测量绝缘电阻。运行中通过油色谱和局部放电监测判断绝缘状态。 | 绝缘筒出现贯穿性裂纹或严重爬电痕迹；角环破损导致端部绝缘距离不足。需吊芯更换，注意安装位置和间隙。 |
| 油箱及附件 | — | 作为器身的容器和安装基础，容纳绝缘和冷却介质，并起到机械支撑和散热作用。 | 否 | 定期检查油箱及各附件的密封性，发现渗漏及时处理；检查储油柜油位与油温曲线是否对应；检查吸湿器硅胶颜色及时更换；定期取样化验绝缘油品质；大修时对所有密封胶垫进行评估更换。 | 油箱本体严重锈蚀穿孔且多处渗漏无法修补，需更换箱体（等同于更换变压器）。 |
| 油箱本体 | 油箱及附件 | 储存绝缘油并容纳器身，表面通过辐射和对流散热。 | 否 | 定期检查油箱外壁有无渗漏和锈蚀；检查焊缝和法兰密封面；防腐涂层维护；检查接地连接可靠。大修时对油箱进行试漏检查。 | 油箱严重锈蚀穿孔或焊缝开裂导致大量漏油且无法修复。局部腐蚀可补焊，大面积损伤需更换箱体。 |
| 储油柜（油枕） | 油箱及附件 | 位于油箱上部，用于调节因油温变化引起的油体积膨胀与收缩，减少油与空气的接触，延缓油质劣化。 | 否 | 定期检查油位指示是否正常；检查呼吸管路是否通畅；检查胶囊或隔膜（如有）有无破损漏气；检查与油箱连接管路阀门和密封。 | 储油柜严重锈蚀穿孔或内部胶囊破损导致油与空气直接接触加速劣化。更换时需关闭联管阀门排空储油柜油后施工。 |
| 油位计 | 储油柜 | 固定在储油柜端部，直观指示变压器油的受控液面高度，分磁针式或管式，密封失效易导致油位指示失准或渗漏。 | 是 | 每次巡检核对此油位与油温曲线是否对应；检查有无渗漏；定期校验油位计指示准确性；磁针式油位计检查浮球动作灵活性。 | 油位计指示严重偏差且无法校准；玻璃管破裂或密封失效漏油。更换油位计时需关闭储油柜联管阀门，排空局部油后拆卸更换。 |
| 吸湿器（呼吸器） | 储油柜 | 内装硅胶等干燥剂，用于吸附进入储油柜空气中的水分和杂质，干燥剂失效变色需更换。 | 否 | 定期观察硅胶变色情况，超过2/3变色应更换硅胶；检查油封杯油位和油色；检查吸湿器与储油柜连接管路密封；确保呼吸通道通畅无堵塞。 | 吸湿器壳体破裂或连接管路严重腐蚀导致密封失效。更换时注意管道密封和油封杯油位。 |
| 变色硅胶 | 吸湿器 | 作为干燥剂吸附进入储油柜的水分，未吸潮前呈蓝色，吸湿饱和后变为粉红色，需更换或烘干再生。 | 是 | 每月巡检观察硅胶颜色变化，超过2/3变为粉红色时应更换；更换时记录变色比例和周期趋势；旧硅胶可在130~150℃烘箱中烘干再生4~6小时恢复蓝色。 | 硅胶吸湿饱和变为粉红色超过总量的2/3。更换时打开吸湿器上部法兰倒出旧硅胶，装入新硅胶至适当高度（留出膨胀空间），密封法兰。 |
| 吸湿器油封杯 | 吸湿器 | 位于吸湿器底部盛装变压器油的玻璃或金属杯，用于过滤空气中的灰尘并形成油封隔离，需定期更换杯内油。 | 否 | 每季度检查油封杯内油位和油色；油色变深或出现水分时应更换；保持油位在刻度线以上；检查油封杯有无裂纹。 | 油封杯破裂无法密封。更换时倒出旧油清洗杯体，注入合格的变压器油至规定油位。 |
| 密封胶垫/圈 | 油箱及附件 | 用于油箱法兰、阀门等连接处的密封，防止渗漏油和潮气进入，材质为耐油橡胶，长期使用易老化开裂。 | 是 | 每次大修应重点检查所有密封胶垫状态，发现硬化、开裂和永久变形应更换；渗漏点处的胶垫应立即更换。运行中巡检关注各法兰接口有无油迹。 | 胶垫老化开裂或失去弹性导致渗漏。更换时彻底清理法兰面旧胶和油污，新胶垫就位后对角均匀紧固螺栓。重要密封面建议每次大修全部更换胶垫。 |
| 蝶阀 | 油箱及附件 | 安装在散热器与油箱连接管路上，用于在检修散热器时隔离油路，避免大量放油。 | 否 | 定期检查蝶阀开关位置指示是否正确；检查阀体有无渗漏；大修时做开关操作试验确认动作灵活；检查密封面。 | 阀体裂纹或密封面严重损坏导致关不严漏油。更换蝶阀时需关闭相关管路并局部排油，安装后检查密封性。 |
| 绝缘油 | 油箱及附件 | 充满整个油箱，承担绝缘和散热的双重作用，主要成分为矿物油，在运行中会因受潮、氧化而劣化。 | 是 | 定期取样进行油质化验（击穿电压、酸值、水分、介质损耗因数）；根据化验结果进行滤油或换油处理；保持密封防止受潮；监控油温。运行中油质不合格时应及时真空滤油处理。 | 绝缘油严重劣化（酸值超标、击穿电压严重下降、介质损耗因数过大），经真空滤油处理后仍无法恢复合格指标。需全部更换新油，旧油交有资质单位回收处理，注新油后进行真空脱气和油质化验。 |
| 净油器（滤油器） | 油箱及附件 | 内部装有硅胶或活性氧化铝等吸附剂，在变压器油循环时滤除水分、酸和杂质，延缓油质劣化。 | 是 | 定期检查净油器进出口油温差（温差减小说明吸附剂饱和）；定期取样化验油质判断吸附剂是否失效；大修时更换吸附剂；检查连接管路和阀门无渗漏。 | 吸附剂完全失效且内部滤网堵塞；壳体渗漏。更换吸附剂时关闭进出口阀门，打开净油器取出旧吸附剂，装入新硅胶或活性氧化铝，排气后打开阀门恢复运行。 |
| 保护及监测装置 | — | 负责对变压器内部故障、油位、温度、压力等进行监测与保护，确保设备安全运行。 | 否 | 每年校验气体继电器动作定值、温度计指示和压力释放阀动作压力；定期测量铁芯接地电流；检查各保护装置接线可靠、动作灵敏；大修时全面检查和校验所有保护装置。运行中轻瓦斯动作应及时取样分析。 | 保护系统整体老化或多次拒动/误动影响运行安全。需整套更换保护装置并重新校验。 |
| 气体继电器（瓦斯继电器） | 保护及监测装置 | 安装于油箱与储油柜之间，当内部发生轻微故障产生气体或严重故障导致油流涌动时，动作于信号或跳闸。 | 否 | 每年校验气体继电器动作定值（轻瓦斯气体容积和重瓦斯油流速）；定期检查接线端子绝缘和密封；检查观察窗有无渗漏；大修时排空内部气体。运行中轻瓦斯信号动作应及时取样分析气体成分。 | 气体继电器本体出现裂纹渗漏；动作定值严重偏移且无法调整；浮筒或挡板机械损坏。更换时需关闭联管阀门排油后拆装，安装后重新校验动作定值。 |
| 温度计（油面/绕组） | 保护及监测装置 | 监测变压器顶层油温和模拟最热点绕组温度，用于启停冷却器或发出告警、跳闸信号。 | 是 | 每年校验温度计准确性（与标准温度计比对）；检查毛细管有无折弯和损伤；检查报警和跳闸接点动作值；检查温包插入深度和密封。运行中比对两组温度计读数一致性。 | 温度计指示偏差超过允许误差且无法校准；毛细管折断；接点失效。更换温度计时注意温包插入深度和毛细管弯曲半径。 |
| 压力释放阀 | 保护及监测装置 | 当内部压力因故障急剧升高超过整定值时，快速打开释放压力，防止油箱变形或爆炸。 | 否 | 每年检查压力释放阀有无渗漏和动作指示器状态；大修时校验动作压力值；检查阀体密封和导向管通畅；动作指示器复位。 | 阀体渗漏或密封面损坏；动作压力偏移超过允许范围。更换时注意法兰密封和动作压力标定。 |
| 铁芯/夹件接地线 | 保护及监测装置 | 将铁芯与夹件经箱盖上的小套管引出并接地，便于监测铁芯绝缘状况及接地电流，防止多点接地。 | 否 | 定期测量铁芯接地电流（正常应小于0.1A）；检查接地线连接可靠无锈蚀；大修时测量铁芯对地绝缘电阻。接地电流异常增大应排查铁芯多点接地故障。 | 接地线断裂导致铁芯悬空放电；套管绝缘击穿。更换接地线或套管时注意密封。 |
| 冷却系统 | — | 负责将变压器运行中产生的热量散发出去，确保绝缘材料和部件工作在允许的温度范围内。 | 否 | 定期检查冷却风扇和潜油泵运转状态；监控顶层油温和绕组温度；清洗散热器和滤尘网保持散热效率；检查油流继电器指示正常；定期做冷却系统全停试验验证报警功能。 | 冷却系统整体老化（多台风扇和潜油泵同时故障），散热能力严重不足导致变压器限负荷运行。需整套更换冷却设备。 |
| 散热器/冷却器 | 冷却系统 | 增加油箱散热面积，通过空气自然对流或强制风冷将热量带走。 | 否 | 定期检查散热器翅片有无变形和积灰，堵塞时清洗；检查与油箱连接管路蝶阀和密封；检查散热片有无渗油；运行中监控进出口油温差评估散热效果。 | 散热器大面积翅片损坏或管路严重腐蚀渗漏，散热能力严重不足。更换散热器时关闭联管蝶阀，局部排油后拆装。 |
| 冷却风扇 | 散热器 | 安装在散热器底部或侧面，强制吹风以增强散热效果，常用于大型或强迫油循环风冷变压器。 | 是 | 定期检查风扇运转是否平稳无异响；检查叶片有无裂纹和积灰；测量电机绝缘电阻；轴承定期加注润滑脂；检查风扇防护罩完好。运行中如风扇故障应及时投备用风扇并安排检修。 | 风机电机烧毁或轴承损坏；叶片断裂或严重变形。更换时核对电压、功率和转向，安装后检查风量和振动。 |
| 滤尘网 | 散热器 | 安装于散热器风道或风机进风口，用于阻挡柳絮、粉尘等异物进入散热翅片间隙，堵塞时影响散热效果。 | 是 | 每月检查滤尘网积灰情况，堵塞时用水冲洗或压缩空气吹净；检查框架有无变形和破损；清洗晾干后装回。运行中监控油温，异常升高应检查滤尘网。 | 滤网框架严重变形或滤材大面积破损。更换时核对尺寸和过滤精度。 |
| 潜油泵 | 冷却系统 | 用于强迫油循环冷却系统，加速变压器油在油箱与散热器间的循环流动，提高散热效率。 | 是 | 定期检查潜油泵运转声音和振动；检查油流指示器；测量电机绝缘电阻；检查密封有无渗漏；轴承按周期维护。运行中如油流停止或泵体过热应立即停用并投备用泵。 | 电机绕组烧毁；轴承严重磨损导致振动超标；密封失效导致漏油。更换潜油泵时关闭进出口阀门，更换后打开阀门排气，检查转向和油流。 |
