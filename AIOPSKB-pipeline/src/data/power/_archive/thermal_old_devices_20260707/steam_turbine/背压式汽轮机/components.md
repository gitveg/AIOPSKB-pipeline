| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 汽轮机本体 | — | 将蒸汽的热能转换为机械能的原动机，主要由转动部分（转子）和静止部分（静子）组成。 | 否 | 运行中监控振动、轴向位移、胀差、缸温和油温油压等关键参数；按周期执行大修（通常6~8年）和小修（通常1~2年）；大修时全面解体检查通流部分、轴承、汽封和滑销系统；定期进行调节系统静态特性试验和保安系统动作试验。 | 汽缸严重裂纹或变形、通流部分大面积损坏、转子出现不可修复的缺陷，经技术经济评估后整机更换或返厂改造。退役前排空润滑油系统，拆除保温层，分解各大部件依次吊出。 |
| 主汽阀/调节阀 | — | 控制进入汽轮机的蒸汽流量。主汽阀用于快速切断汽源实现紧急停机；调节阀用于调整进汽量以适应负荷变化。 | 是 | 每次大修解体检查阀杆有无拉痕、弯曲和腐蚀；检查阀碟与阀座密封面磨损情况，必要时研磨；检查弹簧自由高度和刚度；阀杆填料每次大修更换。运行中监控阀杆漏汽量，异常增大时安排检修。 | 阀杆严重弯曲或拉痕深度超过允许值无法修复；阀碟或阀座密封面经多次研磨后配合间隙超标；弹簧出现裂纹或永久变形超过5%。拆除时先拆除阀体与管道连接法兰，吊出阀芯组件，注意保护密封面。阀体内部裂纹需评估更换整阀。 |
| 转子 | 汽轮机本体 | 汽轮机中所有转动部件的组合体，负责将蒸汽的动能转换为旋转机械能并向外输出扭矩。 | 否 | 大修时做转子全面无损检测（超声波、磁粉探伤）；测量轴弯曲度和轴颈尺寸；检查叶片、围带和拉筋状态；校验危急保安器动作转速；做动平衡试验。运行中严密监控轴振动、轴向位移和轴承温度。 | 转子出现不可修复的缺陷（超标裂纹、严重弯曲、轴颈严重磨损），需整根转子返厂检修或更换新转子。 |
| 静子 | 汽轮机本体 | 汽轮机的所有静止部件的总称，与转子配合形成封闭的蒸汽做功通道。 | 否 | 大修时全面检查汽缸、隔板、喷嘴、汽封和滑销系统状态；测量动静间隙；检查法兰螺栓有无裂纹；检查保温层完好性。运行中监控缸温和胀差，异常应排查滑销卡涩或保温脱落。 | 汽缸大面积裂纹或严重变形无法修复；通流部分严重损坏导致整机效率大幅下降。需整体返厂或更换。 |
| 主轴 | 转子 | 承受转子部件的重量和巨大的扭矩，支撑叶轮和联轴器等部件。 | 否 | 大修时进行主轴无损检测（超声波、磁粉探伤），检查轴颈表面有无拉伤、腐蚀和疲劳裂纹；测量轴颈椭圆度和锥度；检查轴弯曲度。运行中监控轴振动和轴向位移趋势。 | 主轴发现超标缺陷：超声波探伤发现当量大于验收标准的内部缺陷且无法消除；轴颈磨损严重无法通过镀铬或刷镀修复至允许尺寸；轴弯曲超过允许校直值。主轴报废通常意味着整根转子报废，需返厂或更换整机转子。 |
| 叶轮 | 转子 | 安装动叶片的圆盘结构，将叶片受到的汽流作用力传递给主轴。 | 否 | 大修时检查叶轮轮槽（叶根槽）有无裂纹、腐蚀和磨损；检查叶轮端面及平衡孔周围有无裂纹（磁粉探伤）；检查叶轮与主轴过盈配合有无松动迹象（通过振动监测判断）。 | 叶轮轮槽出现裂纹且深度超过允许打磨深度；轮缘或平衡孔处发现疲劳裂纹；叶轮与主轴配合松动无法重新热套。报废叶轮需连同叶片一起更换，由制造厂或专业检修公司执行。 |
| 动叶片 | 转子 | 安装在叶轮上，接受喷嘴喷出的高速汽流，将蒸汽动能转变为转子旋转的机械能，是汽轮机最关键的部件之一。 | 是 | 大修时逐级检查叶片有无裂纹、冲蚀、碰磨和变形；末级和次末级叶片重点检查水刷侵蚀；无损检测（渗透探伤）叶根过渡区和进出汽边；测量叶片频率变化，与出厂值对比判断有无松动或裂纹。运行中避免长期低负荷运行以防末级叶片颤振。整级叶片作为组件，维护时需关注围带、拉筋、叶根的整体连接状态。 | 叶片发现裂纹且位置不允许打磨消除（如叶根R处、叶型进出汽边根部）；进汽边水刷侵蚀深度超过叶片厚度的30%；叶片断裂（即使仅断一片，应检查同级其余叶片，通常整级更换）。整级叶片报废时按编号逐片取出，新叶片需做动平衡和频率测试。 |
| 围带 | 动叶片 | 安装在叶片顶部，将多个叶片连成组，增加叶片刚性、改变自振频率，并可构成封闭通道、减少叶顶漏汽。 | 是 | 大修时检查围带铆接是否牢固，有无翘起、裂纹或断裂；围带与围带汽封的间隙是否符合要求；发现铆钉头磨损或松动时应重新铆接。 | 围带断裂或出现贯穿裂纹，铆钉孔严重扩孔无法重新铆紧。更换围带需将叶片组整体处理，由专业检修单位执行，更换后需做叶片组频率测试。 |
| 拉筋 | 动叶片 | 连接叶片中部的金属杆或拉筋，用于增加叶片刚性、改善振动特性，但会增加蒸汽流动损失。 | 是 | 大修时检查拉筋焊接处有无脱焊、裂纹；拉筋本身有无断裂或严重腐蚀；发现脱焊时可补焊，但需严格控制焊接工艺防止叶片热损伤。 | 拉筋断裂或腐蚀严重，与叶片焊接处反复脱焊。更换拉筋需叶片制造单位配合，焊接后需做频率测定确认叶片组振动特性合格。 |
| 叶根 | 动叶片 | 将叶片固定在叶轮上的连接部分，常见型式有T形、菌形、叉形、枞树形，保证在各种工况下的牢固连接。 | 否 | 大修时检查叶根与轮槽配合间隙，渗透探伤检查叶根过渡圆角处有无裂纹；检查叶根锁紧件是否完好。 | 叶根出现疲劳裂纹；叶根与轮槽配合面严重磨损导致叶片松动，无法通过加垫或更换锁紧件修复。通常需更换整片叶片。 |
| 叶型 | 动叶片 | 叶片的工作部分，相邻叶型构成蒸汽通道，将蒸汽的动能转换为机械能。 | 否 | 大修时检查叶型表面冲蚀、腐蚀和积盐情况；进出汽边有无碰磨痕迹；型线测量与原始型线对比检查变形量。 | 叶型严重变形或大面积冲蚀导致通流效率明显下降；型线偏离设计值超过允许公差。严重冲蚀的叶片应整级更换。 |
| 联轴器 | 转子 | 连接汽轮机各转子及发电机转子，用于传递扭矩。分为刚性、半挠性和挠性联轴器。 | 是 | 大修时解体检查联轴器螺栓有无裂纹、拉伤和永久伸长；检查法兰面有无磨损和腐蚀；测量联轴器晃度和瓢偏；螺栓按力矩要求紧固，必要时做螺栓超声波探伤。 | 联轴器法兰面出现裂纹；螺栓孔严重椭圆化无法铰孔修复；螺栓多次出现裂纹或断裂。联轴器更换需返厂加工，确保与两端转子配合精度。 |
| 危急保安器 | 转子 | 超速保护装置的感应机构，在转速超过额定值110%~112%时动作，触发保护系统切断进汽。 | 是 | 每次大修校验危急保安器动作转速（在线注油试验或检修后超速试验）；检查撞击子（飞锤）和弹簧有无磨损、腐蚀和变形；检查导向套和壳体配合间隙。运行中定期进行注油试验验证动作可靠性。 | 弹簧疲劳变形导致动作转速偏移且无法通过调整恢复；撞击子卡涩经清理打磨后仍动作不灵活；壳体内部严重磨损。更换撞击子和弹簧组件后需重新做超速试验标定。 |
| 汽缸 | 静子 | 汽轮机的外壳，将通流部分与大气隔开，形成封闭汽室，并支撑内部静子部件。常分为高压缸、中压缸、低压缸。 | 否 | 大修时检查汽缸结合面间隙（塞尺检查，全长0.05mm塞尺不入）；检查内壁有无裂纹、冲蚀和腐蚀；检查法兰螺栓有无裂纹（超声波探伤）；检查保温层是否完好。 | 汽缸结合面大面积变形经反复研磨仍无法消除间隙导致漏汽；汽缸本体出现深度裂纹且位置不适宜补焊（如缸体法兰过渡圆角处）；严重热疲劳导致缸体整体变形。汽缸报废需更换整台缸体，由制造厂供货。 |
| 喷嘴室 | 静子 | 单独设置的安装第一级喷嘴（调节级）的腔室，与各调速汽门相连，用于分配进汽。 | 否 | 大修时检查喷嘴室内壁有无冲蚀和裂纹；喷嘴组有无变形、脱落和焊缝开裂；检查与汽缸连接焊缝。 | 喷嘴室内壁大面积冲蚀穿孔或出现深裂纹；喷嘴组变形严重导致通流面积偏差超标。更换喷嘴组需专业检修单位执行。 |
| 喷嘴/静叶栅 | 静子 | 固定在汽缸或隔板上，将蒸汽的热能转换为动能，并以特定方向喷射到动叶片上。 | 否 | 大修时检查静叶栅有无损伤、变形、结垢和冲蚀；出汽边有无碰磨或开裂；清理通流部分盐垢（化学清洗或机械清理）。 | 静叶大面积冲蚀或变形导致通流效率显著下降；静叶根部焊缝开裂且叶片脱落。静叶栅更换通常随隔板或缸体整体处理。 |
| 隔板 | 静子 | 用于安装静叶片，并将汽缸内部分隔成多个汽室，形成多级做功单元。 | 否 | 大修时检查隔板有无变形、裂纹和腐蚀；静叶有无脱落和冲蚀；隔板汽封槽有无磨损；测量隔板与转子之间的动静间隙。 | 隔板本体出现贯穿性裂纹；静叶大面积脱落导致级效率严重下降；隔板严重变形导致动静间隙超标。隔板更换需按级配做通流间隙调整。 |
| 隔板套 | 静子 | 用于安装和固定隔板，便于隔板的整体拆装和定位。 | 否 | 大修时检查隔板套与汽缸的配合面有无磨损；定位键和止动销是否完好；检查隔板套有无裂纹和变形。 | 隔板套严重变形或开裂导致隔板定位不准；与汽缸配合面严重磨损无法修复定位。需更换同规格备件。 |
| 汽封 | 静子 | 安装在转子与静子之间的间隙处，用于减少蒸汽泄漏（内部）或防止空气漏入（排汽端），分为轴端汽封、隔板汽封和围带汽封。 | 否 | 大修时测量各类汽封间隙，超标时调整或更换汽封块；检查汽封齿磨损情况；检查弹簧片弹性。运行中如真空下降或级间效率降低应排查汽封间隙增大。 | 汽封系统整体老化导致间隙普遍超标，大量汽封块需更换；需整批更换汽封块并重新调整全部间隙。 |
| 轴端汽封 | 汽封 | 安装在汽缸两端轴孔处，减少高压端蒸汽外漏或防止低压端空气漏入，维持排汽真空。 | 是 | 大修时检查汽封齿有无磨损、倒伏和卷边；测量汽封间隙，超标时调整或更换汽封块；检查汽封体弹簧片弹性。运行中如轴封供汽压力异常升高应排查汽封间隙变化。 | 汽封齿严重磨损或多次碰磨导致齿高不足，间隙无法通过调整恢复到设计值；汽封块本体裂纹或变形。拆除旧汽封块后清理汽封槽，装入新汽封块时注意对号入座，间隙调整合格后方可扣缸。 |
| 隔板汽封 | 汽封 | 安装在隔板内孔与转子之间，减少各级之间的蒸汽泄漏，提高级效率。 | 是 | 大修时检查汽封齿磨损情况，测量径向间隙；间隙超标时调整或更换；注意汽封块弹簧片有无疲劳失效。 | 同轴端汽封。汽封齿磨损过多无法有效密封，更换新汽封块后需重新调整间隙。 |
| 围带汽封 | 汽封 | 安装在围带与静子之间，减小叶片顶部的漏汽损失。 | 是 | 大修时检查围带汽封齿磨损情况；测量与围带的间隙；磨损严重时更换汽封块。 | 围带汽封齿严重磨损失去密封效果，汽封块变形或断裂。更换时按级对号装配。 |
| 轴承 | 静子 | 支撑转子的全部重量（径向轴承）并承受轴向推力（推力轴承），确保转子在汽缸中的正确位置。 | 否 | 运行中严密监控轴承温度、回油温度和轴向位移；保证润滑油系统供油压力和油质合格；大修时全面检查径向和推力轴承乌金面、间隙和推力瓦块厚度差。轴承温度异常升高时应立即排查原因。 | 轴承系统整体损坏（多道轴承同时烧瓦）导致转子下沉与静子碰磨，需全面更换轴承组件并检查转子轴颈状态。 |
| 径向支撑轴承 | 轴承 | 承受转子的径向载荷，维持转子的旋转中心。常见型式有椭圆瓦、多油楔、可倾瓦轴承。 | 是 | 大修时检查轴瓦乌金表面有无磨损、拉丝、脱胎和裂纹；测量轴瓦间隙和油楔尺寸；检查轴颈表面状态；回装时确保油路清洁。运行中监控轴瓦温度和油膜压力，温升超标时应检查供油系统。 | 乌金大面积脱落或严重烧瓦，轴瓦间隙超过设计允许值；油楔几何形状严重变形无法修复。更换轴瓦时需检查轴颈状态，必要时研磨轴颈。新瓦就位后需做间隙测量和油楔检查。 |
| 推力轴承 | 轴承 | 承受转子的轴向推力，防止转子发生不允许的轴向位移。常见型式有密切尔式和金斯伯里式可倾瓦轴承。 | 是 | 大修时检查推力瓦块乌金面有无磨损、烧蚀和脱胎；测量推力间隙和瓦块厚度差；检查均载块和基环。运行中严密监视轴向位移和推力瓦温度，超限立即停机。 | 推力瓦块乌金大面积烧损或脱落；瓦块厚度差超标导致载荷严重不均；均载机构损坏无法修复。更换推力瓦块时需逐块测量厚度，选配组确保厚度差在允许范围内。 |
| 滑销系统 | 静子 | 用于引导汽缸、轴承座等部件在受热膨胀或冷却收缩时，按规定的方向和中心移动，确保机组动静间隙不发生变化。 | 否 | 大修时检查各滑销有无卡涩、锈蚀和磨损；测量膨胀间隙是否符合设计值；清理滑销配合面并涂覆二硫化钼润滑脂；检查死点固定是否可靠。运行中定期核对膨胀指示器读数，发现异常应排查滑销卡涩。 | 滑销严重磨损导致膨胀导向失效，或销槽开裂无法修复。更换滑销时需按设计间隙配做，安装后确认膨胀自由无卡涩。 |
