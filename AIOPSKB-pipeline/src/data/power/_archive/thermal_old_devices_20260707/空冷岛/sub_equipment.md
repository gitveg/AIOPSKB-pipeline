| 子设备名称 | 描述 |
| :--- | :--- |
| 直接空冷系统（ACC） | 汽轮机排汽直接进入翅片管束由空气冷凝，系统简单，广泛应用于大型空冷电厂。 |
| 间接空冷系统（ISC） | 汽轮机排汽先经喷射式凝汽器与冷却水混合，冷却水再经空冷塔翅片管束散热，采用混合式或表面式凝汽器。 |
| 海勒式间接空冷系统 | 采用喷射式混合凝汽器，冷却水与蒸汽直接接触换热，冷却水经空冷塔散热后返回。 |
| 哈蒙式间接空冷系统 | 采用表面式凝汽器，冷却水与蒸汽间接换热，冷却水在密闭回路中循环经空冷塔散热。 |
| 干湿联合冷却系统 | 由干式（翅片管）和湿式冷却单元串联或并联组合，兼具节水消雾功能。 |
