| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 定子总成 | — | 由机座、定子铁芯和定子绕组构成。机座为整体焊接，铁芯由冷轧硅钢片叠压而成。绕组为三相对称嵌线，产生感应电动势。 | 否 | 定期测量定子绕组绝缘电阻和吸收比；大修时进行直流耐压和介质损耗测试；测量定子铁芯温度分布和振动值；检查绕组端部固定和绝缘状态；运行中监控定子电流和铁芯温度。 | 定子铁芯严重烧损或绕组绝缘大面积老化击穿，需返厂进行铁芯更换或绕组重绕，费用接近新机时应评估整机更换。 |
| 机座 | 定子总成 | 整体式钢板焊接结构，与定子铁芯焊为一体。提供高刚性和稳定性，降低整机振动，保护内部电磁部件。 | 否 | 大修时检查机座焊缝有无裂纹；检查各固定螺栓有无松动；测量机座振动值。运行中监控机座振动趋势，超过标准值应排查原因。 | 机座出现影响安全的结构性裂纹或严重变形，无法通过补焊修复。机座报废通常意味着整机报废。 |
| 定子铁芯 | 定子总成 | 由优质冷轧硅钢片（如50W470）冲制叠压，采用斜槽设计。用于嵌放定子绕组，构成低铁损磁路，并抑制谐波及电压波形畸变。 | 否 | 大修时测量铁芯温度分布（红外热成像），检查有无局部过热点；检查铁芯紧固是否松动；检查齿压板有无位移。运行中监控定子铁芯温度，异常升高应排查通风和绝缘问题。 | 铁芯大面积烧损或硅钢片片间绝缘严重老化导致铁损大幅增加，局部过热无法消除。铁芯故障通常需返厂大修或整机更换。 |
| 定子绕组 | 定子总成 | 采用特定节距（如5/6节距）的多匝线圈，星形连接。通过切割磁力线产生三相交流电，需经绝缘浸漆处理。 | 是 | 定期测量绕组绝缘电阻和吸收比，每年不少于一次；大修时进行直流泄漏电流和介质损耗测试；检查绕组端部固定有无松动、绝缘有无变色和放电痕迹。运行中监控定子电流和绕组温度，避免过载运行。 | 绝缘电阻持续下降至安全值以下，介质损耗角正切值严重超标，直流泄漏电流呈非线性增长；绕组端部出现严重电晕放电痕迹或绝缘击穿。更换绕组需返厂进行，包括拆除旧绕组、清理铁芯槽、重新嵌线和VPI浸漆固化。 |
| 转子总成 | — | 整体凸极或分布式结构，包含转子轴、转子铁芯/磁极、励磁绕组及阻尼系统。用于建立旋转的主磁场。 | 否 | 大修时测量转子绕组直流电阻和绝缘电阻；进行动平衡校验；检查磁极线圈绝缘和阻尼绕组状态；检查轴颈表面和轴承配合；运行中监控转子温度和轴振动趋势。 | 转子轴出现超标缺陷或严重弯曲无法校直；磁极线圈绝缘严重老化需大批量更换；转子整体动平衡无法恢复。需整根转子返厂检修或更换。 |
| 转子轴 | 转子总成 | 采用45号钢等材料经调质处理的高强度轴。传递机械扭矩，需承受高速旋转和动平衡考验。 | 否 | 大修时检查轴颈表面有无拉伤和腐蚀；测量轴颈尺寸和圆度；进行超声波探伤检查内部缺陷；检查动平衡状态。运行中监控轴振动。 | 轴颈磨损严重无法通过磨削修复至允许尺寸；超声波探伤发现超标内部缺陷；轴弯曲超过允许校直值。转子轴报废需整根转子返厂或更换。 |
| 转子磁极线圈 | 转子总成 | 缠绕在磁极上的励磁绕组，经涂刷胶或VPI浸漆处理。通入直流电以产生磁场，绝缘层易受热和离心力影响老化。 | 是 | 大修时测量磁极线圈直流电阻和绝缘电阻，与出厂值比对；检查线圈表面绝缘有无变色、裂纹和脱落；检查极间连线绝缘和紧固情况。运行中监控转子温度和励磁电流。 | 线圈匝间短路导致直流电阻偏差超过允许值，绝缘电阻低于安全限值且无法通过干燥恢复；线圈变形严重或绝缘大面积脱落。更换磁极线圈需拆卸磁极，重新绕制并VPI浸漆。 |
| 阻尼绕组 | 转子总成 | 位于磁极铁芯外圆，由阻尼条和端环构成类似鼠笼的结构。抑制转子动态过电压，增强发电机带不平衡负载能力。 | 否 | 大修时检查阻尼条与端环焊接处有无裂纹、脱焊和变色；检查阻尼条有无断裂和位移。运行中如发现发电机带不平衡负载能力下降，应排查阻尼绕组状态。 | 阻尼条断裂多根或端环出现严重裂纹；焊接处反复脱焊无法修复。更换阻尼条和端环需磁极返厂处理。 |
| 轴承 | 转子总成 | 采用滑动轴承（椭圆瓦/可倾瓦），轴瓦内浇铸巴氏合金（乌金），靠润滑油膜支承转子旋转。大型汽轮发电机轴承为强制润滑方式，润滑油由主油箱经冷油器供给。 | 是 | 定期检测轴承进油温度、回油温度和瓦温；大修时检查轴瓦巴氏合金面有无磨损、龟裂、脱胎和烧灼痕迹；测量轴承间隙和油膜厚度；检查钨金（巴氏合金）与瓦胎结合是否牢固；定期化验润滑油质。运行中监视轴振动和瓦温趋势。 | 巴氏合金面大面积烧损或脱胎（乌金与瓦体剥离）；轴瓦间隙超过允许值且无法通过修刮恢复；瓦胎出现裂纹。更换轴瓦需吊出转子，新瓦需研刮配合，安装后测量间隙符合标准。 |
| 散热风扇 | 转子总成 | 安装于转子轴上，通常为钢板冲制或铝合金压铸。随转子旋转产生轴向或径向气流，强制发电机内部冷却。 | 否 | 大修时检查风扇叶片有无裂纹、变形和松动；检查紧固螺栓力矩；清理叶片表面积灰。运行中注意通风声音是否异常。 | 叶片出现裂纹或严重变形；轮毂与轴配合松动。更换风扇需做动平衡试验。 |
| 接线盒 | — | 防护式金属接线箱体，内含绝缘端子排。连接定子绕组引出线、外部主回路及辅助回路电缆，保护电气连接并隔绝异物。 | 否 | 定期检查接线盒密封是否完好，有无进水和积尘；检查端子排有无变色、氧化和松动；紧固所有接线螺栓。 | 接线盒严重变形或腐蚀影响防护等级；端子排烧毁。更换接线盒时恢复全部接线并核对相序。 |
| 端盖及联接法兰 | — | 安装于机座两端，用于安装轴承、构成风路通道，并提供与发动机飞轮壳连接的接口。支持单轴承或双轴承结构配置。 | 否 | 大修时检查端盖与机座配合面有无磨损；检查轴承室尺寸是否在公差范围内；检查密封件有无老化；紧固螺栓力矩检查。 | 端盖轴承室严重磨损导致轴承跑外圈，无法通过喷涂或镶套修复；端盖出现裂纹。更换端盖时需校核轴承室尺寸和同心度。 |
| 绝缘件 | — | 包含槽楔、绝缘衬垫、层间垫条、引线套管及绕组绑扎带。确保绕组与铁芯、机座间及相间/匝间的可靠电气隔离。 | 是 | 大修时检查槽楔有无松动、位移和碳化；检查引线套管有无裂纹和爬电痕迹；检查绑扎带是否松弛；对绝缘薄弱处进行补强处理。 | 槽楔大面积松动或碳化；引线套管击穿或严重爬电；绝缘衬垫严重老化变脆。更换绝缘件需拆除相关绕组，工作量较大。 |
| 空气滤清器 | — | 安装在发电机进风口处，多为纤维或无纺布材质。过滤进入内部的冷却空气，防止灰尘、水分和异物磨损或击穿绝缘层。 | 是 | 每月检查滤芯积灰情况，根据环境清洁度每1~3个月清洗或更换一次；安装时注意密封，防止旁路漏气。 | 滤芯破损、框架变形或过滤效率严重下降。拆除旧滤芯后清洁滤网框架，安装新滤芯注意气流方向标识。 |
| 碳刷（或电刷） | — | 用于有刷励磁结构，多为碳基石墨材质。静态安装于刷握内，与转子滑环滑动接触，导入或导出励磁电流，属摩擦损耗件。 | 是 | 每周检查碳刷磨损长度，磨损至原长1/3时应更换；检查碳刷与滑环接触面是否光亮平整（接触面积应大于75%）；检查刷压弹簧压力是否均匀；碳刷磨损粉末及时清理。 | 碳刷磨损至允许最小长度或出现碎裂、掉块；刷体出现偏磨导致接触面积严重不足。更换碳刷时选用同型号，新刷需研磨弧面使其与滑环吻合。 |
| 滑环（集电环） | — | 安装于转子轴上，多为铜质或钢质环状导电体。与电刷配合构成滑动接触，为旋转的转子绕组提供或导出励磁电流，接触面会磨损。 | 是 | 定期检查滑环表面有无沟槽、烧痕和偏心；检查滑环温升；大修时测量滑环外径，磨损超标时上车床精车表面恢复粗糙度；确保滑环表面清洁无油污。 | 滑环外径磨损至低于允许最小值；表面多次精车后仍无法消除偏心和沟槽；滑环与轴配合松动。更换滑环需拆卸转子，压出旧环后热装新环，精车外圆后做动平衡。 |
| 密封圈（件） | — | 包括各类O形圈、油封及端盖密封垫。防止轴承润滑脂泄漏及外部灰尘/潮气侵入发电机内部，多由橡胶或毛毡制成，易老化硬化。 | 是 | 大修时全部密封圈原则上应更换；检查密封槽尺寸是否满足压缩量要求；安装时涂抹适量润滑脂防止装配损伤。运行中发现渗油或结露应及时排查密封件。 | 密封圈老化、硬化、变形或断裂导致密封功能丧失。拆除旧密封件后彻底清洁密封槽，新密封件安装时注意方向和压缩量。 |
