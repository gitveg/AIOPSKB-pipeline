| 子设备名称 | 描述 |
| :--- | :--- |
| 开式湿式冷却塔 | 通过水与空气直接接触蒸发散热，配有填料以增加接触面积，分为横流、逆流等结构，是应用最广泛的常规冷却塔。 |
| 闭式冷却塔 | 管内热流体与管外喷淋水及空气进行间壁换热，水质不受污染，适合在严寒或对介质洁净度要求高的场合使用。 |
| 自然通风冷却塔 | 依靠塔内热空气与外界冷空气的密度差形成自然对流，无需电力风机，常见于大型火电厂双曲线型塔。 |
| 机械通风冷却塔 | 通过轴流风机强制空气流动进行热交换，分为引风式与鼓风式，适用于各类工业与商业场合。 |
| 逆流式冷却塔 | 空气自下而上流动，水自上而下喷淋，利用垂直方向逆向接触进行高效换热。 |
| 横流式冷却塔 | 空气水平横向穿过垂直落下的水流，配有重力配水盆，进风百叶位于侧面。 |
| 冷凝模块式冷却塔 | 在常规塔上方加装冷凝模块，将湿热空气中的水蒸气冷凝回收，兼具节水与消雾双重效果。 |
| 无填料喷雾冷却塔 | 取消传统填料，利用高效低压离心雾化装置喷射水雾与空气进行热交换，具有风阻小、维修量少的特点。 |
| 混流式冷却塔 | 空气和水按混合流向进行换热，兼顾逆流与横流的流动特点，结构布置灵活。 |
| 混合通风冷却塔 | 结合自然通风与机械通风两种方式，可根据环境温度或负荷切换、协同运行以降低能耗和提升适应性。 |
| 喷流式冷却塔（无风机冷却塔） | 利用高压喷射水流引射空气形成气流进行热交换，取消传统电力风机，运行噪声低且无风机维护需求。 |
