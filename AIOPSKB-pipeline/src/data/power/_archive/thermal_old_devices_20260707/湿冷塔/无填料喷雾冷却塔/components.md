| 部件名称 | 父部件 | 描述 | 易损标识 | 维护方法 | 报废方法 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 塔体结构 | — | 构成湿式冷却塔的外部框架和支撑体系，为内部组件提供安装基础和保护，确保结构稳定。 | 否 | 每年全面检查塔体结构完整性：外壳有无裂纹和渗漏、支撑平台有无变形、集水盆有无渗漏、钢基墩有无锈蚀、安全附件是否完好；防腐涂层每3~5年补涂；冬季注意防冻保护。 | 塔体结构严重损坏（大面积外壳破损、支撑结构严重锈蚀变形、集水盆大面积开裂），修复费用超过新建成本的50%，经评估后整体重建。拆除时自上而下逐层分解，注意环境保护。 |
| 外壳/风筒 | 塔体结构 | 引导空气流通并形成封闭的循环风道，通常由玻璃钢、镀锌钢或混凝土制成，保证气流均匀通过填料。 | 否 | 每年检查外壳有无裂纹、渗漏、腐蚀和变形；检查玻璃钢部件有无分层和起泡；钢结构防腐涂层每3~5年补涂一次；紧固连接螺栓。 | 外壳大面积破损或严重腐蚀导致结构强度不足；混凝土风筒出现贯穿性裂缝且修补无效；玻璃钢严重分层。更换需搭设脚手架分段拆装，确保新风筒密封性和结构强度。 |
| 风扇甲板/支撑平台 | 塔体结构 | 用于承载风机、减速机和电动机等驱动系统的平台，为机械设备提供稳固的安装和检修基础。 | 否 | 每年检查平台水平度和结构完整性；检查焊接件有无裂纹；检查紧固件有无松动和锈蚀；防腐涂层维护。运行中注意振动情况，异常振动应检查平台刚度。 | 平台出现结构性裂纹或严重变形影响设备安装精度；钢构件大面积锈蚀导致截面损失超过允许值。更换或加固需停塔施工。 |
| 集水盆 | 塔体结构 | 位于塔体底部的蓄水装置，专门收集经填料冷却后落下的循环水，并作为系统供水的缓冲容器。 | 否 | 每年检查集水盆有无渗漏、裂纹和腐蚀；清理底部淤泥和沉积物；检查防水层和防腐涂层完好性；保持水位计畅通。冬季注意防冻保护。 | 盆体严重开裂导致大量漏水且局部修补无效；防腐层大面积脱落导致钢结构严重腐蚀。修复或更换需排空盆体后施工。 |
| 钢基墩台 | 塔体结构 | 焊接支撑结构，将塔体整体垫高，为底部配管和排水提供足够空间，并确保设备水平安装。 | 否 | 每年检查钢基墩焊缝有无开裂；检查地脚螺栓有无松动；检查防腐涂层；检查基础有无不均匀沉降。 | 钢构件严重锈蚀导致截面损失超过30%；基础严重不均匀沉降影响塔体安全。需重新制作基础并校正塔体水平。 |
| 安全附件/检修设施 | 塔体结构 | 包含护栏、爬梯、安全笼和检修门等，为日常巡检、维护和维修提供安全的进出通道和作业平台。 | 否 | 每季度检查护栏、爬梯和安全笼有无变形、锈蚀和松动；检查检修门密封和锁具功能；紧固松动的连接件；防腐涂层维护。 | 护栏或爬梯严重变形或锈蚀影响安全通行，且无法通过局部加固修复。更换时按安全标准施工。 |
| 传动系统 | — | 驱动风机旋转的动力总成，包含电机、减速机和传动部件，是调节风量和冷却效果的核心执行单元。 | 否 | 定期检查电机、减速机和传动皮带的运行状态；监控振动、噪声和温度；按周期更换减速机齿轮油；检查皮带张紧度和磨损；定期做电机绝缘测试；备用传动系统保持可用。 | 传动系统整体老化（电机、减速机和皮带同时故障），经评估整组更换比逐项维修更经济。更换时核对安装尺寸和接口参数。 |
| 电动机 | 传动系统 | 将电能转换为机械能，为风机提供旋转动力，常见为全封闭风扇冷却(TEFC)电机，含定子绕组、转子及接线盒。 | 否 | 定期测量电机绝缘电阻和三相电流平衡度；检查轴承温度和运转声音；检查接线盒密封和端子紧固；检查散热风扇和防护罩；按周期维护轴承润滑。运行中电流异常增大应排查机械卡涩或绕组故障。 | 电机绕组烧毁或转子扫膛，修复费用超过新电机的50%。更换时核对功率、转速、电压和安装尺寸，就位后检查转向和电流。 |
| 电动机轴承 | 电动机 | 支撑电机转子，减小旋转摩擦，承受径向和轴向负载，其失效会导致电机振动、异响甚至扫膛。 | 是 | 按厂家规定周期补充润滑脂（通常运行2000~4000小时）；大修时检查轴承游隙和滚道状态；运行中监听轴承声音和监控温度，温升超过80℃应排查原因。 | 滚道严重剥落或点蚀；保持架断裂；游隙严重超标导致振动加剧。用拉拔器拆除旧轴承，热装新轴承（加热至80~100℃），注意轴承型号和游隙等级与原设计一致。 |
| 电动机接线盒/绝缘 | 电动机 | 电源连接与电机内部绕组的电气绝缘部分，受潮、积尘或高温易导致绝缘老化、短路或接线烧毁。 | 是 | 每次小修检查接线盒密封性和端子紧固情况；测量电机绝缘电阻（不低于1MΩ/kV）；保持接线盒内部干燥清洁；发现端子氧化变色时打磨处理。 | 绕组绝缘击穿或老化导致绝缘电阻持续不合格；端子排烧毁。绕组报废需重绕或更换电机；端子排烧毁可局部更换。 |
| 减速机 | 传动系统 | 将电动机的高转速、小扭矩转换为适合风机运转的低转速、大扭矩，常见有皮带减速和行星齿轮减速。 | 否 | 按规定周期更换齿轮油（通常半年至一年）；定期检查油质（水分、磨粒、酸值）；大修时开盖检查齿面和轴承；监控运行振动和噪声，异常增大应停机检查。 | 齿轮箱壳体开裂或多级齿轮严重损坏，解体维修费用接近新机价格。更换减速机后需重新对中找正。 |
| 减速机齿轮/轴承 | 减速机 | 齿轮传递扭矩实现减速；轴承支撑齿轮轴，承受巨大径向力。长期重载下易发生油膜失效、点蚀和磨损。 | 是 | 按规定周期更换齿轮油（通常运行2000~4000小时或半年）；定期检查油质（水分、磨粒、酸值）；大修时开盖检查齿轮齿面有无点蚀、磨损和胶合；检查轴承游隙和滚道。运行中监控减速机振动和油温。 | 齿面大面积点蚀或剥落导致噪声和振动严重超标；轴承滚道严重磨损或保持架断裂。更换齿轮或轴承需解体减速机，组装后做跑合试验。 |
| 减速机油封/密封件 | 减速机 | 防止减速机内部润滑油泄漏及外部灰尘、水分进入，失效会导致缺油磨损、齿轮损坏或进水乳化润滑剂。 | 是 | 每次换油时检查油封唇口有无硬化、裂纹和磨损；检查密封面有无划痕；发现渗油应及时更换油封。安装新油封时注意唇口方向和配合面清洁。 | 油封唇口严重磨损或老化导致漏油；密封面损伤。拆除旧油封时避免划伤轴颈，新油封安装时唇口涂抹润滑脂。 |
| 机械设备支撑件 | 减速机 | 刚性钢结构支架，支撑电机和带槽轮，抵抗因对准误差和振动产生的应力，确保传动精度。 | 否 | 每年检查支撑件焊缝有无裂纹；检查地脚螺栓紧固力矩；检查对中状态；防腐涂层维护。 | 支撑件严重变形或焊缝开裂影响对中精度。需更换或加固支撑件后重新对中找正。 |
| 传动皮带 | 传动系统 | 连接电机轴与皮带轮或减速机轴的柔性传动件，通过摩擦力传递动力。长期使用易出现松弛、磨损、断裂或打滑。 | 是 | 每月检查皮带张紧度（拇指按压法，挠度约15~20mm）；检查有无裂纹、磨损和油污；定期调整张紧度；成组更换时必须同一批次皮带。运行中监听有无打滑尖叫声。 | 皮带出现多处裂纹、断丝或严重磨损导致打滑；拉伸变形无法通过调整张紧恢复。拆除旧皮带后清洁带轮，安装新皮带时避免硬撬，调整张紧后试运行检查有无跑偏。 |
| 风机总成 | — | 产生强制气流的旋转组件，通过叶片推动空气流过填料或管束，强制带走热量，是实现热交换的关键动力装置。 | 否 | 定期检查叶片、轮毂和紧固件状态；大修时做叶片无损检测和动平衡校验；检查轮毂与输出轴配合；运行中监控振动和噪声，异常应立即停机排查。 | 风机轮毂出现裂纹或严重磨损，多片叶片同时损坏。更换后需做动平衡试验。 |
| 风机叶片 | 风机总成 | 铝合金或玻璃钢制成的翼型结构，通过旋转切割空气，产生压差形成气流。受交变应力，易出现裂纹或断裂。 | 是 | 每季度检查叶片表面有无裂纹、缺口和腐蚀；大修时做无损检测（渗透探伤）；检查叶片安装角度和螺栓紧固力矩；测量叶片尖部与风筒间隙均匀性。冬季停运前清除叶片结冰。 | 叶片出现裂纹、缺口面积超过叶片截面的5%或严重腐蚀减薄；叶根连接处出现疲劳裂纹。更换叶片时需成组更换（或严格按重量选配），安装后做静平衡和动平衡试验。 |
| 风机轮毂 | 风机总成 | 将叶片固定并与减速机输出轴相连的承载部件，传递全部扭矩，需保证叶片安装角度精确以保证平衡。 | 否 | 大修时检查轮毂与叶片连接螺栓紧固力矩；检查轮毂与输出轴配合锥面有无磨损；检查轮毂本体有无裂纹；防腐涂层维护。 | 轮毂出现裂纹或锥面严重磨损导致无法可靠连接叶片；键槽严重挤压变形。更换轮毂后需重新安装叶片并做动平衡。 |
| 热力/收水组件 | — | 增加水与空气接触的换热核心区，以及防止水滴被气流带走的节水装置，直接影响冷却效率和水耗。 | 否 | 定期检查填料有无塌陷、堵塞和结垢；检查收水器有无变形和破损；检查进风百叶窗通畅性；大修时清洗或更换严重结垢的填料；监控冷却效率下降趋势，与设计值对比判断填料老化程度。 | 填料大面积塌陷或结垢导致冷却效率严重下降，收水器大面积破损导致飘水率超标。需整体更换填料和收水器。 |
| 填料 | 热力/收水组件 | 将热水溅散成水膜或细小水滴，极大增加水-气接触面积，延长换热时间。污垢、泥沙及化学腐蚀会导致堵塞或塌陷。 | 否 | 定期检查填料有无结垢、堵塞、变形和塌陷；监控冷却效率变化趋势；保持循环水质处理正常，控制悬浮物和生物粘泥；大修时高压水清洗或化学清洗填料表面污垢。 | 填料大面积塌陷或严重结垢堵塞，经清洗后冷却效率仍显著低于设计值。更换填料时需逐层铺设，确保铺放均匀无间隙。 |
| 填料支架/悬挂件 | 填料 | 热浸镀锌钢管或非金属构件，用于悬挂或支撑填料，承受填料自重和结垢后的额外重量，易被腐蚀。 | 是 | 每年检查支架有无锈蚀、变形和断裂；检查与塔体连接是否牢固；对严重锈蚀部位打磨补涂防腐漆；检查填料铺放是否均匀无塌陷。 | 支架严重锈蚀导致截面损失超过30%或断裂导致填料塌陷；非金属支架老化开裂。更换支架时需先移除上部填料，安装新支架后重新铺设填料。 |
| 收水器/飘水控制器 | 热力/收水组件 | 安装在填料上方的波纹板组件，改变湿空气流向，将夹带的大水滴分离回收，降低漂滴损失率。 | 否 | 每年检查收水器有无变形、破损和结垢；清理表面水垢和生物附着；检查安装是否平整无翘曲。 | 大面积变形或破损导致飘水率严重超标；结垢严重无法清洗恢复。更换时拆除旧收水器片，清洁支撑梁后铺设新片。 |
| 进风百叶窗 | 热力/收水组件 | 安装在进风口处的导流或挡水板，控制气流均匀进入，同时阻止塔内水滴外溅和外部碎屑进入，冬季防止结冰。 | 否 | 每季度检查百叶窗叶片有无变形、脱落和严重结垢；冬季注意防冻除冰；清理进风面堆积的树叶和杂物。 | 大面积叶片脱落或严重变形影响进风均匀性。更换叶片时注意安装角度一致。 |
| 配水系统 | — | 将需冷却的高温热水均匀喷洒在填料顶层的布水装置，其均匀性直接影响填料的冷却利用效率。 | 否 | 定期检查喷头出水均匀性，发现堵塞和偏流及时清洗或更换喷头；检查管道和阀门有无渗漏；大修时彻底清理管道内壁水垢和生物膜；冬季停运前排空管道防冻。 | 配水管道大面积腐蚀穿孔，多个喷头同时损坏，配水均匀性严重下降。需整体更换管道和喷头系统。 |
| 热水盆/分配管 | 配水系统 | 接收外部高温回水，作为一级缓冲，或通过主管道将水初步分流。通常在横流塔中为开式水盆。 | 否 | 定期检查热水盆内壁防腐涂层和积垢情况；清理盆底沉积物；检查盆盖过滤网和密封性；检查分配管各出口是否通畅。 | 热水盆严重腐蚀穿孔或防腐层大面积脱落导致壳体损坏。更换时排空盆体后施工。 |
| 热水盆盖 | 热水盆/分配管 | 覆盖热水盆的盖板，可过滤空气中的悬浮物，防止杂物堵塞配水喷头，同时最大限度抑制盆内藻类滋生。 | 否 | 每季度检查盆盖有无破损、变形；清理盖面过滤网上的杂物和藻类；保持盖板密封。 | 盖板严重破损导致大量杂物进入热水盆。更换时注意尺寸匹配和密封。 |
| 喷头/喷嘴 | 配水系统 | 将水分配系统中的水以小孔喷溅或重力滴落的方式，均匀分布于填料顶部。小孔极易被杂物堵塞，是重点维护对象。 | 是 | 每月检查喷头出水状态，发现堵塞、偏流或水量明显不均时应拆下清洗；用软毛刷和清水疏通喷孔，禁止用铁丝硬捅；定期检查喷头有无磨损、变形和脱落。 | 喷头本体开裂或喷孔严重磨损导致布水不均匀无法修复。拆除旧喷头后清理安装座，拧入新喷头确认牢固和出水角度。 |
| 配水管道/阀门 | 配水系统 | 连接热水盆与喷头的管路及流量调节阀，通过阀门开度控制各区域喷淋水量，保证填料布水的均匀性。 | 否 | 每季度检查管道有无渗漏、腐蚀和结垢；阀门动作灵活无卡涩；大修时彻底清理管道内壁水垢和生物膜。 | 管道严重腐蚀穿孔或阀门卡死无法修复。更换管段时注意防腐处理，阀门更换后需重新调节各区域水量。 |
| 滤网/旁滤器 | 配水系统 | 安装在供水管路上的过滤装置，拦截循环水中的悬浮物、碎屑等杂质，防止喷头堵塞，自身需定期清洗。 | 是 | 每周检查滤网前后压差，压差增大说明堵塞；每季度拆下滤网清洗，清除拦截的杂物和生物附着；检查滤网有无破损和变形。 | 滤网大面积破损丧失过滤功能；框架严重腐蚀。更换时核对过滤精度和安装尺寸。 |
