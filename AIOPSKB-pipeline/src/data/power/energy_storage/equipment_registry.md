| 设备名称 | 设备类型 | 描述 |
|----------|----------|------|
| 电池簇 | 主设备 | 由多个电池模组串联组成的高压电池单元，集成BMS从控和温度传感，具备独立充放电功能，是锂电池储能系统的最小功能实体和核心能量存储载体。 |
| 储能变流器(PCS) | 主设备 | 实现电池直流电与电网交流电之间的双向变换（DC/AC），负责充放电控制、功率调节、并网/离网切换，承担执行层角色。 |
| 升压变压器 | 主设备 | 将PCS输出的低压交流电（如315V/690V）升至并网电压等级（10kV/35kV/110kV）的电力变压器，是储能单元并网的唯一功率拓扑接口，与风电/光伏箱变功能对等。 |
| 液流电池电堆 | 主设备 | 全钒液流电池等液流储能系统中发生氧化还原电化学反应的核心部件，由离子交换膜、电极、双极板、集流体等组成，决定系统的功率输出能力。 |
| 电解液储罐 | 主设备 | 液流电池系统中分别储存正极和负极电解液的容器，电解液为活性储能介质，储罐容量直接决定系统储能时长，功率与容量可独立扩展。 |
| 电解水制氢电解槽 | 主设备 | 利用富余电能将水电解为氢气和氧气的核心设备，技术路线包括碱性电解槽（ALK）、质子交换膜电解槽（PEM）和固体氧化物电解槽（SOEC）。 |
| 储氢罐/储氢设施 | 主设备 | 氢储能系统中用于安全储存氢气的设施，包括高压气态储氢罐、低温液态储氢罐或固态储氢装置，是氢储能路线的能量存储环节。 |
| 氢燃料电池发电系统 | 主设备 | 将储存的氢气化学能通过电化学反应转化为电能的发电装置，常见类型包括质子交换膜燃料电池（PEMFC）和固体氧化物燃料电池（SOFC）。 |
| 空气压缩机 | 主设备 | 压缩空气储能（CAES）系统中的核心设备，在用电低谷时将空气压缩至高压并存储于储气装置中，将电能转化为空气内能。 |
| 透平膨胀机 | 主设备 | 压缩空气储能系统中的核心发电设备，在用电高峰时释放高压空气推动透平膨胀机做功发电。 |
| 储气装置 | 主设备 | 压缩空气储能系统中用于存储高压空气的设施，包括人工盐穴、废弃矿井或高压压力容器，是CAES路线的能量存储环节。 |
| 飞轮转子 | 主设备 | 飞轮储能系统中通过高速旋转将能量以动能形式储存的核心旋转质量体，采用高强度复合材料制成，真空腔体作为其密封壳体部件。 |
| 飞轮电机/电力转换系统 | 主设备 | 飞轮储能中实现电能与机械能相互转换的电动/发电互逆式电机及其功率变换系统。 |
| 电池舱/电池集装箱 | 辅助设备 | 集成安装电池模组、BMS、汇流柜等设备的标准化集装箱或预制舱体，具备防护、密封和运输便利性。 |
| 电池架 | 辅助设备 | 用于固定和支撑电池模组的金属支架结构，提供标准化安装接口和电气连接。 |
| 汇流柜/直流配电柜 | 辅助设备 | 将多个电池簇的直流输出汇流后统一连接至PCS的电气配电设备，含直流断路器、熔断器和防雷器件。 |
| 电池管理系统(BMS) | 辅助设备 | 对电池簇的电压、温度、SOC/SOH等参数进行实时监测、评估、保护和均衡管理的电子控制系统，依附于电池簇的专用控制保护系统，类比发电机励磁。 |
| 液冷机组 | 辅助设备 | 采用液冷方式对电池舱进行精确温度控制的核心设备，包括液冷主机、冷却液循环泵和管路系统，保持电池在最佳工作温度范围（15~35°C）。 |
| 风冷空调系统 | 辅助设备 | 采用强制风冷或工业空调对电池舱进行温度调节的设备，结构简单、维护方便，适用于中低功率密度的储能系统。 |
| 消防探测报警装置 | 辅助设备 | 包括感烟探测器、感温探测器、可燃气体（CO、H₂）探测器，用于电池热失控的早期预警和火灾报警。 |
| 自动灭火装置 | 辅助设备 | 采用七氟丙烷（FM200）、全氟己酮或水消防等灭火介质，与BMS和消防报警系统联动实现自动灭火。 |
| 排风泄压装置 | 辅助设备 | 电池热失控时排出舱内有毒有害气体和热量，防止压力积聚导致爆炸的通风泄压设备。 |
| 氢气压缩机 | 辅助设备 | 氢储能系统中将电解产生的低压氢气压缩至储运所需压力的机械设备。 |
| 电解液循环泵 | 辅助设备 | 液流电池系统中推动正负极电解液在储罐与电堆之间循环流动的外接泵送设备。 |
| 换热器 | 辅助设备 | 压缩空气储能系统中实现压缩热回收利用和膨胀前空气预热的装置，提高系统整体电-电转换效率。 |
| 高压开关柜 | 辅助设备 | 用于储能电站中压配电系统，实现并网线路、站用变压器、无功补偿等回路的控制与保护。 |
| 并网保护装置 | 辅助设备 | 包括防孤岛保护、过/欠压保护、频率保护等，确保储能系统并网运行安全，在电网异常时快速解列。 |
| 继电保护装置 | 辅助设备 | 检测储能电站电气系统故障或异常运行状态，发出跳闸或告警指令，快速隔离故障点以保护主设备。 |
| 无功补偿装置(SVG) | 辅助设备 | 动态调节无功功率输出，维持并网点电压稳定，满足电网对功率因数和电能质量的要求。 |
| 磁悬浮轴承 | 辅助设备 | 飞轮储能系统中支撑高速旋转飞轮转子的非接触式轴承，降低摩擦损耗并提高旋转精度和寿命。 |
| SCADA监控系统 | 公用系统 | 对储能电站所有设备进行远程集中监控、数据采集与可视化展示的计算机监控系统。 |
| 站用变压器 | 公用系统 | 从并网侧引接电源，降压后为站内辅助设备（空调、照明、消防等）提供低压工作电源的变压器。 |
| UPS不间断电源 | 公用系统 | 为BMS、EMS、通信设备等关键负荷提供不间断交流电力的电源装置，保障系统监控与控制不断电。 |
| 直流电源系统/蓄电池组 | 公用系统 | 由蓄电池组和充电装置组成，为保护、控制、信号等二次设备提供可靠的操作电源。 |
| 能量管理系统(EMS) | 公用系统 | 对全站设备进行协调控制、数据采集分析、能量调度和策略优化的上位计算机系统，全站共享的能量管理与调度平台，与SCADA/DCS同类。 |
| 远程通信设备 | 公用系统 | 传输储能电站运行数据至远方集控中心或电网调度中心的光纤通信、载波通信或无线通信装置。 |
| 电能质量监测装置 | 公用系统 | 监测并网点的谐波、电压波动、闪变、频率偏差等电能质量指标，确保满足并网标准要求。 |
| 视频监控系统 | 公用系统 | 监视储能电站内电池舱、升压站等关键区域的安防及设备运行环境的视频摄像和录像系统。 |
| 消防水泵及管网 | 公用系统 | 为储能电站全站提供消防用水的水泵房和管道网络系统。 |
| 接地系统 | 公用系统 | 储能电站全站接地网络，包括接地极、接地母线和各设备接地连接线，为全站共享的基础安全设施。 |
