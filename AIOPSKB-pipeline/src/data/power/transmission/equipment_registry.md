| 设备类型名称 | 设备属性 | 描述 |
|----------|----------|------|
| 导线 | 主设备 | 架空输电线路核心载流导体，承担电能传输功能。按材质/结构分为钢芯铝绞线(ACSR)、铝合金绞线、碳纤维复合芯导线、扩径导线、耐热铝合金导线等，适用于110kV~1000kV各电压等级，不同材质为工程选型差异，在部件层区分 |
| 避雷线（架空地线） | 主设备 | 架设在导线上方的钢绞线或铝包钢绞线，用于保护导线免受直击雷，提供雷电流泄放通道，是线路防雷的第一道屏障 |
| OPGW光缆（光纤复合架空地线） | 主设备 | 将光纤单元复合于架空地线中，兼具地线防雷保护和光纤通信双重功能，结构上不可分割，是输电线路通信通道的主要形式 |
| 绝缘子 | 主设备 | 导线与杆塔之间的电气绝缘和机械支撑元件，构成主绝缘通路的关键环节。按材质分为瓷质、玻璃、复合绝缘子等，不同材质为工程选型差异，在部件层区分 |
| 杆塔 | 主设备 | 支撑导线、地线并实现安全对地距离的核心结构，倒塔为输电行业最严重的灾难性故障之一。按结构分为角钢塔、钢管塔、钢管杆、钢筋混凝土杆等，不同型式在部件层区分 |
| 电力电缆 | 主设备 | 电缆输电线路的载流核心，用于城市和跨江等无法架设架空线路的输电场景。按绝缘型式分为XLPE电缆和充油电缆等，适用于110kV~500kV电压等级 |
| 电缆终端头 | 主设备 | 安装在电力电缆末端的附件，实现电缆与架空线、变压器或GIS等设备的可靠电气连接，电场集中、故障率高，是电缆系统主绝缘通路上的关键节点，有独立的施工资质要求和检修标准 |
| 电缆中间接头 | 主设备 | 连接两段电力电缆的附件，恢复电缆的绝缘、屏蔽和护层结构，是电缆线路中绝缘薄弱环节和故障高发点，有独立的施工资质要求和检修标准 |
| 换流阀 | 主设备 | HVDC系统中实现交直流电能转换的核心设备（L1能量转换）。按拓扑分为LCC晶闸管换流阀（常规直流）和MMC模块化多电平换流阀（柔性直流），适用于±500kV~±1100kV高压直流输电工程 |
| 换流变压器 | 主设备 | 连接交流电网与换流阀的专用变压器，承受交直流叠加电场，提供适当的阀侧电压和换相电抗，是换流站中体积最大、造价最高的设备之一（L1能量转换） |
| 平波电抗器 | 主设备 | 串联在HVDC直流回路中的大型电抗器，平抑直流电流纹波、限制故障电流上升率，是直流主回路核心感性元件，故障直接导致直流系统停运 |
| 直流断路器 | 主设备 | 直流系统中切断故障电流的开关设备，分为机械式、固态式和混合式三种技术路线，是多端柔性直流输电和直流电网的关键设备（L2主工艺链关键控制节点） |
| 线路并联电抗器 | 主设备 | 安装于超高压输电线路两端或中间变电站的大型并联电抗器，吸收长线路容性无功功率、限制工频过电压和潜供电流，直接关系到线路能否安全合闸和轻载运行 |
| 串联补偿装置 | 主设备 | 串联于输电线路中的电容器组装置，缩短线路电气距离、提高输送能力和系统稳定性。按控制方式分为固定串补(FSC)和可控串补(TCSC)，广泛应用于500kV及以上长距离输电线路 |
| 绝缘子（支柱绝缘子） | 辅助设备 | 用于支撑硬母线或引下线的绝缘子，常见于换流站直流场和线路终端塔跳线支撑，非主绝缘通路上的串联元件 |
| 金具（悬垂线夹） | 辅助设备 | 将导线悬挂于直线杆塔绝缘子串上的金具，承受导线垂直荷载，分为提包式、防晕式、预绞式等多种型式 |
| 金具（耐张线夹） | 辅助设备 | 将导线锚固于耐张杆塔上的金具，承受导线全张力，分为螺栓式、液压压缩式、楔型等型式，是耐张段的关键连接件 |
| 金具（连接金具） | 辅助设备 | 用于绝缘子串、线夹与杆塔之间相互连接的金具，包括球头挂环、U型挂环、碗头挂板、联板、延长环等 |
| 金具（接续金具） | 辅助设备 | 用于导线接续和修补的金具，包括液压压接管、补修管、并沟线夹、跳线线夹等 |
| 防振锤 | 辅助设备 | 安装于导线上的防振装置，抑制风致导线振动，防止导线在线夹出口处因疲劳断股 |
| 间隔棒 | 辅助设备 | 用于保持分裂导线各子导线之间规定间距，防止子导线碰撞和舞动，分为刚性间隔棒和柔性间隔棒 |
| 防舞动装置 | 辅助设备 | 安装于导线上用于抑制覆冰或风激励下导线大幅低频振荡的装置，如防舞动偏心重锤、失谐摆等 |
| 均压环/屏蔽环 | 辅助设备 | 安装于绝缘子串两端的金属环，改善绝缘子串电压分布、防止电晕放电和无线电干扰 |
| 杆塔基础（灌注桩基础） | 辅助设备 | 采用钻孔灌注桩施工的基础型式，适用于软弱土层和地下水位较高地区，承载力大 |
| 杆塔基础（掏挖基础） | 辅助设备 | 在原状土中机械或人工掏挖成型后浇筑混凝土的基础，适用于黏性土和砂土地质 |
| 杆塔基础（岩石锚杆基础） | 辅助设备 | 在基岩中钻孔后插入锚杆并灌注砂浆的基础型式，适用于山区岩石地基 |
| 杆塔基础（装配式基础） | 辅助设备 | 由预制构件在现场组装的基础型式，适用于缺水地区或冬季施工 |
| 接地装置 | 辅助设备 | 由接地体和接地引下线组成的装置，用于将杆塔接地电阻降至合格范围，为雷电流和故障电流提供泄放通道 |
| 电缆金属护层接地箱 | 辅助设备 | 用于电力电缆金属护层接地保护的装置，包含护层保护器、接地刀闸等，实现电缆护层的交叉互联和接地保护 |
| 电缆分支箱 | 辅助设备 | 用于电缆线路分支和连接的户外箱式设备，实现多路电缆的汇集和分配 |
| 直流隔离开关 | 辅助设备 | 用于直流回路无负荷情况下隔离设备的开关，为检修维护提供可见的断开点，不具备灭弧能力 |
| 直流转换开关 | 辅助设备 | 用于直流输电系统中运行方式切换的开关设备，如金属回线转换开关、大地回线转换开关等 |
| 直流滤波器 | 辅助设备 | 安装于换流站直流场中的滤波装置，由电容器、电抗器和电阻器组合而成，用于滤除直流侧的谐波电流 |
| 直流穿墙套管 | 辅助设备 | 将直流电流从换流站户内引至户外的绝缘套管，需承受高压直流电压，功能依附于阀厅建筑和两侧主设备 |
| 直流分压器 | 辅助设备 | 用于测量直流电压的传感设备，将高电压按比例转换为低压信号供保护和测量装置使用 |
| 直流电流互感器 | 辅助设备 | 用于测量直流电流的传感设备，采用零磁通或霍尔效应原理，为保护和控制系统提供电流信号 |
| 交流滤波器 | 辅助设备 | 安装于换流站交流场的滤波装置，吸收换流阀产生的谐波电流并提供无功支撑，部分退出不立即中断输电 |
| 线路保护装置 | 辅助设备 | 输电线路的继电保护系统，按保护原理分为电流差动保护、距离保护、纵联保护等，220kV及以上通常双重化配置，用于检测线路故障并快速切除，在部件层区分保护原理 |
| 自动重合闸装置 | 辅助设备 | 线路故障跳闸后自动重新合闸的装置，可瞬时或延时动作，用于提高输电线路供电可靠性 |
| 线路避雷器 | 辅助设备 | 安装于输电线路杆塔上的避雷器，用于限制雷电过电压沿线路侵入变电站，提高线路耐雷水平 |
| 故障录波器 | 辅助设备 | 记录输电线路故障前后电气量波形的装置，用于事故分析和保护动作行为评价 |
| 故障测距装置 | 辅助设备 | 根据故障录波数据或行波信号计算输电线路故障点位置的装置，为线路巡线和故障修复提供定位参考 |
| 输电线路在线监测装置（覆冰监测） | 辅助设备 | 安装于输电线路杆塔上，通过传感器和图像识别技术实时监测导线覆冰厚度和类型 |
| 输电线路在线监测装置（导线测温/弧垂监测） | 辅助设备 | 实时监测导线温度和弧垂，用于动态增容评估和导线安全状态预警 |
| 输电线路在线监测装置（微气象监测） | 辅助设备 | 安装于杆塔上，监测沿线风速、风向、温度、湿度、降雨等气象参数 |
| 输电线路在线监测装置（杆塔倾斜/沉降监测） | 辅助设备 | 实时监测杆塔倾斜角度和不均匀沉降，主要用于采空区、滑坡易发区等地质不良地段 |
| 输电线路在线监测装置（图像/视频监控） | 辅助设备 | 安装于杆塔上的高清摄像头和视频监控装置，用于远程巡视、外力破坏监视和自然灾害评估 |
| 输电线路在线监测装置（舞动监测） | 辅助设备 | 实时监测导线舞动幅度、频率和轨迹，为防舞动治理和预警提供数据支撑 |
| 线路CVT（电容式电压互感器） | 辅助设备 | 利用电容分压原理测量线路电压的互感器，同时可兼作高频载波通信的耦合装置 |
| 线路电流互感器 | 辅助设备 | 安装于线路侧用于将大电流按比例转换为标准小电流的互感器，为保护和测量装置提供电流信号 |
| 电缆敷设通道（排管/沟道/隧道） | 公用系统 | 用于敷设和保护电力电缆的地下通道设施，包括电缆排管、电缆沟、电缆隧道和竖井等 |
| 通信设备（电力载波机） | 公用系统 | 利用输电线路导线作为传输通道的载波通信设备，用于线路保护和远动信号的传输 |
| 通信设备（光端机） | 公用系统 | 利用OPGW光缆进行光纤通信的终端设备，为输电线路保护和调度自动化提供高速、可靠的通信通道 |
