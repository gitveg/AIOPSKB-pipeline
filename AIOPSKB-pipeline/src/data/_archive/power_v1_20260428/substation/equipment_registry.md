整合后的设备清单如下：

| 设备名称 | 设备类型 | 功能描述 | 关键参数 | 所属子系统 |
| :--- | :--- | :--- | :--- | :--- |
| **电力变压器** | 主设备 | 变电所核心设备，通过电磁感应原理改变电压等级，实现电能的升压远距离传输或降压分配。 | 额定容量(kVA/MVA)、电压等级/变比、绝缘类型(油浸式/干式)、冷却方式 | 一次系统 / 电能变换 |
| **断路器** | 主设备 | 在正常或故障情况下接通或断开电路，能快速切断故障电流，是保障电网安全的第一道防线。 | 额定电压、额定开断电流、操作机构类型(弹簧/液压/气动) | 一次系统 / 开关设备 |
| **隔离开关** | 主设备 | 在无负荷电流时，将需要检修的设备与带电部分形成明显断开点，确保检修安全；也可用于母线倒闸操作。 | 额定电压、额定电流、动/热稳定电流 | 一次系统 / 开关设备 |
| **负荷开关** | 辅助设备 | 用于正常运行时接通和断开负荷电流，但不能开断短路电流，常与熔断器组合使用。 | 额定电压、额定电流、操作机构类型 | 一次系统 / 开关设备 |
| **电流互感器** | 主设备 | 将一次侧大电流按比例变换为二次侧小电流，用于测量、计量和保护装置。 | 额定变比、准确级(如0.2/5P)、额定容量 | 一次系统 / 测量与保护 |
| **电压互感器** | 主设备 | 将一次侧高电压按比例变换为二次侧低电压，供测量、计量和保护装置使用，并隔离高电压。 | 额定变比、准确级、额定容量 | 一次系统 / 测量与保护 |
| **母线** | 主设备 | 汇流和分配电能，连接变压器、进出线回路，是变电站的“血管”。 | 额定电压、额定电流、动/热稳定电流 | 一次系统 / 电能汇集 |
| **电力电容器（组）** | 辅助设备 | 提供无功功率补偿，提高功率因数，降低线路损耗，改善电压质量。 | 额定容量(kvar)、额定电压、连接方式(星形/三角形) | 一次系统 / 无功补偿 |
| **电抗器** | 辅助设备 | 限制短路电流，补偿线路容性无功，抑制谐波，维持系统电压稳定。 | 额定容量(kvar)、额定电压、电抗率 | 一次系统 / 无功补偿 |
| **消弧线圈** | 辅助设备 | 在中性点不直接接地系统中，补偿单相接地时的电容电流，加速灭弧。 | 额定容量(kVA)、额定电压、补偿电流调节范围 | 一次系统 / 接地保护 |
| **避雷器** | 辅助设备 | 限制雷电过电压和操作过电压，保护电气设备绝缘免受损害。 | 额定电压、标称放电电流、残压 | 一次系统 / 过电压保护 |
| **熔断器** | 辅助设备 | 用于保护电压互感器、电力电容器等设备，在故障电流过大时熔断，切断电路，是简单的后备保护。 | 额定电压、额定开断电流、熔体额定电流 | 一次系统 / 开关与保护 |
| **箱式变电站** | 主设备（集成） | 将变压器、高低压开关、保护等设备预装在一个箱体内，用于户外配电，安装简便、占地小。 | 额定容量、电压等级、外壳防护等级(最低IP23D) | 一次系统 / 成套设备 |
| **气体绝缘金属封闭开关设备 (GIS)** | 主设备（集成） | 将断路器、隔离开关、互感器、母线等一次设备封闭在充有SF6气体的金属壳体内，占地小，可靠性高。 | 额定电压，间隔组合方式，气体压力 | 一次系统 / 成套设备 |
| **阻波器** | 辅助设备 | 串联在输电线上，利用其高频阻抗特性，阻止高频载波通信信号向变电站母线分流，同时让工频电流顺利通过。 | 额定电流、额定电感、阻塞频段 | 一次系统 / 通信与保护 |
| **继电保护装置** | 主设备（二次） | 实时监测一次设备状态，当发生故障时，迅速、准确地发出跳闸命令或告警信号。 | 保护功能类型(差动/距离/过流)、动作时间、通信协议(IEC 61850) | 二次系统 / 保护与控制 |
| **测控装置** | 主设备（二次） | 采集、测量一次设备的电压、电流、功率等电气量，并执行遥控、遥调指令。 | 测量精度(有功/无功0.5级)、输入/输出点数、通信接口 | 二次系统 / 监控与测量 |
| **合并单元** | 辅助设备（二次） | 在智能变电站中，采集多个互感器的模拟量信号并合并转换为数字信号，通过光纤网络共享给保护、测控等装置。 | 采样率、通道数、通信协议(IEC 61850-9-2)、对时精度 | 二次系统 / 过程层 |
| **智能终端** | 辅助设备（二次） | 在智能变电站中，作为断路器、隔离开关的操作控制接口，接收GOOSE命令执行分合闸操作，并上传开关状态。 | 开关量输入/输出点数、操作回路数量、通信接口 | 二次系统 / 过程层 |
| **SCADA监控系统** | 辅助设备（二次） | 实现变电站的实时数据采集、设备状态监视、远方控制和数据分析，是自动化管理的核心。 | 系统容量、通信规约(IEC 61850)、高级应用功能(如顺序控制) | 二次系统 / 综合自动化 |
| **保护信息子站** | 辅助设备（二次） | 收集、管理、分析和转发全站继电保护装置的动作信息、告警记录和定值，是保护设备与调度端通信的桥梁。 | 接入保护装置数量、通信协议、信息处理速度 | 二次系统 / 综合自动化 |
| **同步相量测量装置 (PMU)** | 辅助设备（二次） | 同步测量全网电压、电流的幅值和相角，为电网动态监测、低频振荡分析等提供高精度、带时标的数据。 | 采样率(≥100Hz)、相角测量精度、对时方式(GPS/北斗) | 二次系统 / 监控与分析 |
| **故障录波装置** | 辅助设备（二次） | 记录电网故障发生前后电流、电压及保护动作等瞬间变化过程，为事后故障分析提供数据。 | 模拟量/开关量录波通道数、记录长度、采样率 | 二次系统 / 监控与分析 |
| **直流电源系统** | 公用系统 | 为控制、保护、信号、事故照明等二次设备提供可靠的工作电源，含充电模块和蓄电池组。 | 直流额定电压(如110V/220V)、蓄电池容量(Ah)、组屏方式 | 公用系统 / 站用电源 |
| **站用变压器（站用变）** | 公用系统 | 为变电站内部的照明、空调、风机、水泵、直流充电机等站内负荷提供交流低压电源。 | 额定容量(kVA)、电压变比(如10/0.4kV) | 公用系统 / 站用电源 |
| **交流不间断电源 (UPS)** | 公用系统 | 当站用交流电源中断时，通过蓄电池逆变，为不允许瞬间断电的关键设备（如监控主机、服务器）提供纯净、连续的交流电。 | 额定容量(kVA)、后备时间、输入/输出电压 | 公用系统 / 站用电源 |
| **火灾报警与消防系统** | 公用系统 | 探测并警示火灾，通过自动或手动方式启动灭火设备，保障变电站消防安全。 | 探测器类型(烟感/温感)、保护区域、灭火介质(水喷雾/气体) | 公用系统 / 安防与消防 |
| **图像监视与安防系统** | 公用系统 | 对变电站周界、出入口及主要设备区域进行视频监控和入侵探测，实现远程巡视和安防管理。 | 摄像头数量与类型、存储容量、智能识别功能(如区域入侵) | 公用系统 / 安防与消防 |
| **暖通空调系统** | 公用系统 | 控制室内环境温度和湿度，确保电气设备在允许的温湿度范围内可靠运行。 | 制冷/制热量、风量、环境控制精度 | 公用系统 / 环境控制 |
| **排水与供水系统** | 公用系统 | 排除电缆沟、地下室等低洼处积水，并为消防、生活提供用水，防止设备受潮和保障消防安全。 | 水泵流量/扬程、管道材质、控制方式(自动/手动) | 公用系统 / 环境控制 |
| **对时系统** | 公用系统 | 为全站所有需要精确时间的设备（保护、测控、故障录波等）提供统一、高精度的时间基准，实现事件顺序记录。 | 授时方式(GPS+北斗)、输出接口(IRIG-B/NTP/PTP)、对时精度(≤1μs) | 公用系统 / 辅助系统 |
