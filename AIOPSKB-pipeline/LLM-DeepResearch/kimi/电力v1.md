# 电力行业设备智能运维知识库大纲

## 编制说明
- **适用范围**：覆盖发电（火电、水电、风电、光伏、核电、抽水蓄能）、输变电、配电、储能全环节
- **索引维度**：工业（发电/输变/配电/储能）→ 设备 → 部件 → 故障
- **故障知识维度**：故障定义、故障机理、故障特征参数、监测手段、诊断手段、检修方法、预防措施、相关标准

## 1.1 锅炉系统

### 1.1.1 本体结构
| 部件 | 功能描述 | 子部件细分 |
|------|---------|-----------|
| 炉膛 | 燃料燃烧空间 | 水冷壁、燃烧器、折焰角、冷灰斗 |
| 汽包 | 汽水分离、储水、排污 | 汽水分离器、加药管、排污管、水位计接口 |
| 水冷壁 | 吸收辐射热、保护炉墙 | 上升管、下降管、联箱、节流圈 |
| 过热器 | 将饱和蒸汽加热为过热蒸汽 | 顶棚过热器、包墙过热器、屏式过热器、末级过热器、联箱 |
| 再热器 | 高压缸排汽重新加热 | 低温再热器、高温再热器、联箱 |
| 省煤器 | 利用烟气余热加热给水 | 省煤器管束、联箱、防磨装置、吹灰器 |
| 空气预热器 | 预热燃烧空气 | 蓄热元件、转子、密封装置、传动机构 |
| 燃烧系统 | 组织燃料燃烧 | 燃烧器、磨煤机、给煤机、一次风机、二次风机 |
| 制粉系统 | 煤粉制备输送 | 磨煤机、分离器、煤粉管道、给煤机 |

### 1.1.2 故障知识 — 炉膛/水冷壁
| 维度 | 内容 |
|------|------|
| **故障名称** | 水冷壁爆管/泄漏 |
| **故障机理** | 高温腐蚀、飞灰磨损、应力腐蚀开裂、材质老化、超温运行、水质不良导致结垢 |
| **故障特征参数** | 炉膛负压突变、汽包水位下降速率、给水流量异常大于蒸汽流量、排烟温度降低、泄漏声发射信号（30-50kHz）、炉膛出口烟温偏差 |
| **监测手段** | 炉膛看火电视、声波泄漏监测仪、炉膛压力监测、汽包水位监测、给水流量监测、烟气温度场监测、红外热成像 |
| **诊断手段** | 声学检测定位（声发射传感器阵列）、四管泄漏仪分析、炉膛负压波动分析、水冷壁壁厚超声检测、金相分析、蠕胀测量 |
| **检修方法** | 1. 临时封堵（带压堵漏）→ 降负荷运行；2. 计划停炉后割管更换；3. 大面积腐蚀时整体换管；4. 喷涂防腐蚀涂层 |
| **预防措施** | 控制燃煤硫分、优化燃烧配风、定期吹灰、水质监督（pH、电导率、溶解氧）、壁厚定期检测、防磨防爆检查 |
| **相关标准** | DL/T 438-2021《火力发电厂金属技术监督规程》、DL/T 939《火力发电厂锅炉受热面管监督检验技术导则》 |

### 1.1.3 故障知识 — 过热器/再热器
| 维度 | 内容 |
|------|------|
| **故障名称** | 过热器/再热器超温爆管 |
| **故障机理** | 热偏差导致局部超温、氧化皮剥落堵塞、飞灰磨损、高温蠕变、材质老化、蒸汽品质不良 |
| **故障特征参数** | 管壁温度超限（金属壁温>设计值）、出口汽温偏差>10℃、氧化皮厚度>0.1mm、蒸汽阻力异常增大、蠕胀量超标 |
| **监测手段** | 金属壁温测点（热电偶）、蒸汽温度监测、氧化皮检测（涡流/超声）、烟气温度场监测、蒸汽流量分配监测 |
| **诊断手段** | 超温统计及趋势分析、蠕胀测量（电子卡规）、氧化皮检测（内窥镜+电磁超声）、金相组织分析、壁厚测量 |
| **检修方法** | 1. 堵管处理（切除故障管屏）；2. 换管（同材质或升级材质）；3. 优化蒸汽流量分配；4. 调整燃烧配风减少热偏差 |
| **预防措施** | 优化燃烧器摆角、定期吹灰、蒸汽吹管、控制升温升压速率、氧化皮监测预警、材质升级（T92、Super304H等） |

### 1.1.4 故障知识 — 汽包/省煤器
| 维度 | 内容 |
|------|------|
| **故障名称** | 省煤器磨损泄漏 / 汽包疲劳裂纹 |
| **故障机理** | 省煤器：飞灰磨损、烟气走廊形成、防磨护瓦脱落；汽包：交变应力疲劳、应力集中、水质不良导致腐蚀 |
| **故障特征参数** | 省煤器：局部管壁减薄>30%、泄漏声发射、给水流量异常、排烟温度降低；汽包：水位波动异常、焊缝裂纹（UT检测）、应力集中部位磁粉探伤缺陷 |
| **监测手段** | 省煤器：管壁温度监测、壁厚超声检测、泄漏声发射监测、排烟温度监测；汽包：水位监测、应力监测、无损检测（UT/MT/PT） |
| **诊断手段** | 壁厚扫查（超声波测厚仪）、磁粉/渗透检测表面裂纹、声发射定位、疲劳寿命评估、有限元应力分析 |
| **检修方法** | 省煤器：局部换管、加装防磨护瓦、防磨喷涂；汽包：裂纹打磨补焊、降应力处理、更换汽包（严重情况） |

### 1.1.5 辅助系统故障知识
- **制粉系统**：磨煤机振动异常、磨辊磨损、煤粉细度超标、一次风管堵塞、煤粉自燃
- **燃烧系统**：燃烧器烧损、结焦/结渣、火焰检测失灵、点火系统故障
- **风烟系统**：引风机振动、一次风机失速、空预器堵塞（硫酸氢铵）、空预器转子卡涩、烟道积灰

### 1.2.2 故障知识 — 转子/叶片
| 维度 | 内容 |
|------|------|
| **故障名称** | 转子振动异常（不平衡/不对中/摩擦/油膜涡动） |
| **故障机理** | 动平衡破坏（叶片结垢/脱落）、热弯曲（上下缸温差）、油膜涡动/振荡（轴承失稳）、动静摩擦（胀差超限）、联轴器不对中 |
| **故障特征参数** | 轴振/瓦振幅值超标（>0.125mm报警）、相位变化、频谱特征（1X不平衡、2X不对中、0.42-0.48X油膜涡动）、轴心轨迹异常、胀差超限（>±3mm） |
| **监测手段** | 轴振传感器（涡流传感器）、瓦振传感器（速度/加速度）、键相传感器、轴位移监测、胀差监测、缸体膨胀监测、润滑油温度/压力监测 |
| **诊断手段** | 振动频谱分析（FFT）、波特图、轴心轨迹分析、趋势分析、模态分析、动平衡试验、激光对中检测、油膜特性分析 |
| **检修方法** | 1. 现场动平衡（加配重/去重）；2. 重新找正（激光对中仪）；3. 轴承检修/更换（调整间隙、换瓦）；4. 转子直轴；5. 叶片更换 |
| **预防措施** | 严格控制启停温升率（<5℃/min）、避免冷水进入汽缸、定期振动监测、轴承温度监控、润滑油品质监督、超速试验 |

### 1.2.3 故障知识 — 轴承/润滑系统
| 维度 | 内容 |
|------|------|
| **故障名称** | 轴承乌金磨损/温度高 / 润滑油劣化 |
| **故障机理** | 润滑油膜破坏、轴瓦磨损、供油不足、油质劣化（水分/颗粒/酸值超标）、轴电流腐蚀、轴承间隙不当 |
| **故障特征参数** | 轴瓦温度>90℃报警、回油温度>65℃、润滑油水分>100ppm、酸值>0.3mgKOH/g、颗粒度>NAS8级、振动频谱中出现轴承特征频率 |
| **监测手段** | 瓦温监测（热电阻）、油温监测、油压监测、润滑油在线监测仪（水分/颗粒/粘度）、振动监测、轴电流监测 |
| **诊断手段** | 润滑油理化分析+铁谱分析+光谱分析、轴瓦间隙测量、轴电流测量、振动频谱轴承故障频率分析、超声波探伤 |
| **检修方法** | 1. 换油/滤油（真空滤油机）；2. 刮瓦/换瓦；3. 调整轴承间隙；4. 处理轴电流（绝缘处理/接地电刷） |

### 1.2.4 故障知识 — 调节保安系统
| 维度 | 内容 |
|------|------|
| **故障名称** | 调节系统摆动/卡涩 / 保安系统拒动 |
| **故障机理** | 油动机卡涩（油质不良）、调节阀阀杆结盐/磨损、调速器失灵、危急遮断器误动/拒动、EH油系统泄漏 |
| **故障特征参数** | 负荷波动>±2%、调节阀开度摆动、转速波动、EH油压下降（<11.2MPa报警）、危急遮断器动作转速偏差>±2% |
| **监测手段** | 转速监测、油动机行程监测、EH油压监测、调节阀位置反馈、AST电磁阀状态监测、挂闸状态监测 |
| **诊断方法** | 调节系统静态试验、阀门活动试验、危急遮断器注油试验、EH油质分析、阀门严密性试验、超速试验 |
| **检修方法** | 1. 清洗油动机/伺服阀；2. 研磨/更换调节阀；3. 调整危急遮断器；4. 更换EH油、处理密封件 |

## 1.3 发电机系统

### 1.3.1 本体结构
| 部件 | 功能描述 | 子部件细分 |

| 冷却系统 | 散热 | 氢冷（氢气系统/密封油系统）、空冷、水内冷（定子线棒水冷/转子水冷） |

### 1.3.2 故障知识 — 定子绕组
| 维度 | 内容 |
|------|------|
| **故障名称** | 定子绕组绝缘劣化/接地/匝间短路 |
| **故障机理** | 热老化（长期高温）、电老化（局部放电）、机械振动（绕组松动）、受潮（密封不良）、油污污染 |
| **故障特征参数** | 绝缘电阻下降（<1MΩ/kV）、吸收比<1.3、介质损耗因数tgδ增大、局部放电量>500pC、泄漏电流增大、定子铁芯温度异常、定子槽楔松动 |
| **监测手段** | 绝缘电阻监测、介损测试、局部放电在线监测（电容耦合器/UHF）、定子绕组温度监测、槽楔松紧度检测（敲击法/超声波）、局放超声检测 |
| **诊断手段** | 绝缘电阻/吸收比/极化指数测试、介质损耗及电容量测试、局部放电试验（脉冲电流法）、直流耐压/交流耐压试验、绕组变形测试、绝缘材料的频域介电谱（FDS）分析 |
| **检修方法** | 1. 干燥处理（热油循环/真空干燥）；2. 局部绝缘修复（更换线棒）；3. 整体浸漆处理；4. 铁芯损耗试验（ELCID） |
| **预防措施** | 控制绕组温度（极限130℃）、定期局放监测、防油密封检查、定期绝缘试验、保持氢气纯度/湿度（氢冷机组） |

### 1.3.3 故障知识 — 转子/励磁系统
| 维度 | 内容 |
|------|------|
| **故障名称** | 转子绕组匝间短路 / 转子接地 / 护环裂纹 |
| **故障机理** | 热应力疲劳、离心力作用、材质缺陷、励磁电流冲击、护环应力腐蚀 |
| **故障特征参数** | 转子绕组直流电阻不平衡>2%、匝间短路时无功功率异常波动、振动1X分量增大且与励磁电流相关、转子接地报警（绝缘电阻<20kΩ）、护环超声探伤缺陷波 |
| **监测手段** | 转子绝缘监测、转子直流电阻监测、气隙磁通探测线圈（探测线圈法）、振动监测、轴电压/轴电流监测、护环超声/磁粉探伤 |
| **诊断手段** | 重复脉冲法（RSO）匝间短路检测、交流阻抗及功率损耗法、极间电压分布测量、气隙磁通波形分析、护环无损检测 |
| **检修方法** | 1. 匝间短路：重新绕线/更换转子绕组；2. 转子接地：查找接地点修复绝缘；3. 护环裂纹：更换护环 |

# 第二篇 水力发电设备

## 2.1 水轮机系统

### 2.1.1 分类与结构
| 类型 | 适用水头 | 主要部件 |
|------|---------|---------|
| 混流式（弗朗西斯式） | 30~700m | 蜗壳、座环、导叶机构、转轮（叶片+上冠+下环）、尾水管、主轴、导轴承、推力轴承 |
| 轴流式（定桨/转桨） | 3~80m | 导叶、转轮（叶片+轮毂体）、转轮室、尾水管、主轴、叶片操作系统（转桨式） |
| 斜流式 | 40~200m | 类似混流+轴流混合结构、转轮叶片可调 |
| 贯流式（灯泡式/竖井式） | 1~25m | 流道、转轮、导叶、增速齿轮箱（部分机组）、发电机 |
| 冲击式（水斗式） | 300~1800m | 喷嘴、喷针机构、转轮（水斗+轮盘）、机壳、偏流器 |

### 2.1.2 故障知识 — 转轮/导水机构
| 维度 | 内容 |
|------|------|
| **故障名称** | 转轮汽蚀/磨损 / 导叶卡涩/磨损 |
| **故障机理** | 汽蚀：局部压力低于汽化压力产生气泡溃灭；磨损：泥沙冲刷；导叶卡涩：异物卡阻、间隙不当、锈蚀、连杆机构变形 |
| **故障特征参数** | 转轮：振动频谱中出现宽带高频能量、效率下降>3%、噪声增大（汽蚀噪声）、叶片表面汽蚀坑深度>2mm；导叶：接力器行程与导叶开度非线性、调速器波动、剪断销断裂 |

## 5.3 常规岛设备（二回路）

核电厂常规岛设备与火电厂汽轮发电机组类似，包括汽轮机、发电机、凝汽器、给水泵等。其故障模式与火电有共通性，但需注意核汽轮机特点：
- **湿蒸汽腐蚀**：核蒸汽为饱和蒸汽，低压缸湿度大，导致叶片水蚀
- **汽水分离再热器（MSR）故障**：分离器效率下降、再热器管束泄漏
- **放射性污染**：一回路向二回路泄漏导致蒸汽放射性异常

| 燃油/燃气系统 | 油罐、供油泵、加热器、燃气调压站 | 油泄漏、雾化不良、燃气压力波动、调压阀故障 |

## 11.3 化学水处理系统
| 系统 | 部件 | 故障 |
|------|------|------|
| 补给水 | 反渗透膜、混床、除碳器 | 膜污染/结垢/氧化、树脂老化/污染、出水水质超标 |
| 凝结水精处理 | 前置过滤器、高速混床 | 树脂粉化、过滤器压差增大、出水氢电导率超标 |
| 废水处理 | 中和池、絮凝装置 | 处理能力下降、排放超标 |

## 11.4 厂用电系统
| 设备 | 故障 |
|------|------|
| 高压厂用变压器 | 类似主变压器故障（见7.1） |
| 低压厂用变压器/MCC | 绕组过热/断路器故障/抽屉接触不良 |
| 变频器 | IGBT故障/电容老化/控制板故障/谐波干扰 |
| UPS/应急电源 | 蓄电池失效/逆变器故障/切换失灵 |

# 第十二篇 故障知识通用维度定义

为了使知识库结构化和可检索，每个故障条目应包含以下标准维度：

| 维度编号 | 维度名称 | 说明 | 示例 |
|---------|---------|------|------|
| D1 | 故障编码 | 唯一标识符 | TRF-WDG-DEF-001（变压器-绕组-变形-001） |
| D2 | 故障名称 | 中英文 | 绕组变形（Winding Deformation） |
| D3 | 所属行业 | 发电/输变/配电/储能等 | 输变电 |
| D4 | 所属设备 | 具体设备名称 | 油浸式电力变压器 |
| D5 | 所属部件 | 具体部件名称 | 绕组（高压绕组/低压绕组/调压绕组） |
| D6 | 故障类别 | 机械/电气/绝缘/热/化学/控制 | 电气+机械 |
| D7 | 故障等级 | 轻微/一般/严重/危急 | 严重 |
| D8 | 故障定义 | 现象描述 | 变压器绕组在短路电动力或机械冲击下发生轴向/径向尺寸变化 |
| D9 | 故障机理 | 根本原因分析 | 径向短路电动力使绕组向心压缩/离心拉伸，轴向力使绕组弯曲或线饼错位 |
| D10 | 诱发因素 | 外部触发条件 | 近区短路冲击、运输冲击、安装不当、支撑件松动 |
| D11 | 故障特征参数-电气 | 可电气测量的参数 | 短路阻抗变化>±2%、绕组电容量变化>±3%、直流电阻不平衡 |
| D12 | 故障特征参数-物理 | 可物理测量的参数 | 绕组尺寸变化（吊罩检查）、线饼错位（内窥镜） |
| D13 | 故障特征参数-化学 | 化学分析参数 | 油中溶解气体可能伴随增长（电弧放电时C2H2产生） |
| D14 | 故障特征参数-状态量 | 运行状态变化 | 绕组振动异常、噪声增大、油温异常 |
| D15 | 在线监测手段 | 不停电监测方法 | 绕组变形在线监测（频率响应法/短路阻抗在线）、油色谱在线 |
| D16 | 离线检测手段 | 停电检测方法 | 频率响应分析法（FRA）、低电压短路阻抗测量、电容量测试 |
| D17 | 带电检测手段 | 带电巡检方法 | 红外测温（间接）、振动检测 |
| D18 | 诊断方法 | 综合分析判断逻辑 | FRA相关系数<0.6且短路阻抗变化>2%可判定绕组变形，需结合历史数据比对 |
| D19 | 检修方法-临时 | 不停电/短期处理 | 加强油色谱监测频次、限制短路电流（投入串联电抗器） |
| D20 | 检修方法-根本 | 彻底修复方法 | 吊罩检查→重新压紧绕组/更换撑条/严重时返厂重新绕线 |
| D21 | 预防措施 | 如何避免发生 | 安装冲击记录仪、运输固定可靠、加强绕组压紧力设计、避免近区短路 |
| D22 | 相关标准 | 引用标准 | DL/T 911-2004《电力变压器绕组变形的频率响应分析法》 |
| D23 | 典型案例 | 故障案例简述 | 某110kV变压器遭受近区短路后，FRA相关系数从0.98降至0.35，吊罩发现高压绕组整体塌陷 |
| D24 | 风险后果 | 故障进一步发展 | 绝缘距离改变→局部放电→匝间短路→主绝缘击穿→变压器烧毁 |
| D25 | 关联故障 | 可能并发或继发故障 | 匝间短路、绕组绝缘击穿、局部放电加剧 |

# 第十三篇 知识库索引体系设计

## 13.1 四维度索引结构

```
索引维度1：行业（Industry）
  ├── I1 火力发电
  ├── I2 水力发电
  ├── I3 风力发电
  ├── I4 光伏发电
  ├── I5 核能发电
  ├── I6 抽水蓄能
  ├── I7 输变电
  ├── I8 配电
  ├── I9 储能
  └── I10 辅助与公用系统

索引维度2：设备（Equipment）
  按行业展开，例如火力发电下：
  ├── E1 锅炉
  ├── E2 汽轮机
  ├── E3 发电机
  ├── E4 凝汽及回热系统
  ├── E5 燃料及制粉系统
  └── E6 脱硫脱硝除尘（环保设备）

索引维度3：部件（Component）
  按设备展开，例如锅炉下：
  ├── C1 水冷壁
  ├── C2 过热器
  ├── C3 再热器
  ├── C4 省煤器
  ├── C5 汽包
  ├── C6 燃烧器
  ├── C7 空气预热器
  └── C8 制粉系统

索引维度4：故障（Fault）
  按部件展开，例如水冷壁下：
  ├── F1 高温腐蚀
  ├── F2 飞灰磨损
  ├── F3 应力腐蚀开裂
  ├── F4 爆管/泄漏
  ├── F5 结焦/结渣
  └── F6 超温蠕变
```

## 13.2 交叉索引设计

为了支持智能诊断检索，建立以下关联索引：

| 关联类型 | 说明 | 示例 |
|---------|------|------|
| 同源故障索引 | 同一原因导致多部件故障 | 燃煤硫分过高→水冷壁腐蚀+空气预热器腐蚀+除尘器布袋腐蚀 |
| 级联故障索引 | 故障引发的连锁反应 | 汽轮机转子不平衡→轴承磨损→油膜振荡→轴瓦烧毁 |
| 相似故障索引 | 不同设备上的同类故障 | 变压器绕组变形 vs 电机定子绕组变形 vs 发电机定子线棒位移 |
| 共用标准索引 | 同一标准覆盖多设备 | DL/T 596《电力设备预防性试验规程》覆盖变压器、断路器、互感器等 |
| 监测方法索引 | 同一手段监测多故障 | 油色谱分析→变压器内部故障+断路器触头过热（油断路器）+电抗器故障 |
| 部件关联索引 | 功能关联的部件群 | 汽轮机转子-轴承-联轴器-发电机转子构成轴系关联组 |

## 13.3 特征参数快速检索表

为LLM诊断支持，建立特征参数到故障的倒排索引：

| 特征参数/现象 | 可能关联故障（Top 5） |
|--------------|---------------------|
| 振动1倍频主导 | 转子不平衡、轴弯曲、基础松动 |
| 振动2倍频突出 | 转子不对中、机械松动、联轴器故障 |
| 振动0.4~0.5倍频 | 油膜涡动/油膜振荡、流体激振 |
| 油中乙炔(C2H2)升高 | 电弧放电、绕组短路、分接开关接触不良 |
| 油中乙烯(C2H4)升高 | 高温过热（>300℃）、油过热 |
| 油中甲烷(CH4)+乙烷(C2H6) | 低温过热（<300℃）、油纸绝缘老化 |
| SF6压力下降 | 密封泄漏、阀门故障、焊缝缺陷 |
| 局部放电异常 | 绝缘缺陷、金属微粒、悬浮电位、毛刺 |
| 温度异常热点（红外） | 接触不良、过载、内部故障、绝缘劣化 |
| 直流电阻不平衡 | 绕组接头松动、匝间短路、分接开关接触不良 |

# 附录：知识库数据表设计建议

为满足工业检索和LLM调用需求，建议采用以下关系型数据模型：

```sql
-- 核心实体表
TB_INDUSTRY(行业ID, 行业名称, 行业描述)
TB_EQUIPMENT(设备ID, 行业ID, 设备名称, 设备类型, 额定参数)

TB_FAULT_KNOWLEDGE(知识ID, 故障ID, 维度编号D1-D25, 内容, 数据来源, 更新日期)

TB_FEATURE_INDEX(特征ID, 特征名称, 特征单位, 正常范围, 报警阈值, 危急阈值, 关联故障IDs)

-- 监测手段库
TB_MONITORING_METHOD(方法ID, 方法名称, 方法类型[在线/离线/带电], 适用设备, 检测原理, 仪器工具)

-- 标准规范库
TB_STANDARD(标准ID, 标准编号, 标准名称, 适用范围, 关键条款, 试验周期)
```
